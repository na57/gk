3.25 实验方案设计与评价

高中化学 · 深度学习材料 · 面向 2029 届云南高考

实验方案的设计与评价是化学实验能力的最高层次，也是高考实验大题区分度最大的设问。前面几章教你"会做实验"，本章教你"会想实验、会说实验"——面对一个实验目的，能沿着"目的→原理→装置→操作→现象→结论"的框架设计出完整方案；面对别人给出的方案，能从科学性、安全性、可行性、绿色化学等角度评头论足、指出改进方向。

一、知识全景

知识点 核心内容 高考要求
实验方案设计 科学性、安全性、可行性、简约性原则；目的—原理—装置—操作—现象—结论的完整链条 能设计完整的实验方案，考虑全面
实验方案评价 原理评价、操作评价、误差评价、绿色化学评价 能从多个角度评价实验方案的优劣并提出改进
实验探究 提出假设→设计实验→实验验证→得出结论；控制变量思想 具备实验探究能力，能完成探究性实验题
绿色化学 原子经济性、减少污染、循环利用、源头减量 有绿色化学意识，能提出改进建议
学法提示

方案设计题的本质是"带着镣铐跳舞"：镣铐是实验目的和限定试剂仪器，舞蹈是你的设计。评分看三件事——原理对不对、干扰排没排、表述全不全。平时训练时，每设计一步就追问自己："这一步是为了证明什么？有没有别的物质会搅局？"养成这个习惯，设计题就稳了。

二、核心概念精讲

2.1 实验方案设计的四大原则

核心概念

科学性、安全性、可行性、简约性

  • 科学性：实验原理正确，现象与结论之间有严密的逻辑。反例：用燃着的木条检验某气体是 CO2——不科学，因为 N2 等不支持燃烧的气体也能使木条熄灭，现象与结论不唯一对应。
  • 安全性：防爆炸（可燃气体点燃前验纯）、防倒吸（易溶气体吸收）、防中毒（毒气通风与尾气处理）、防暴沸（加碎瓷片）、防腐蚀（强酸强碱规范操作）。方案中若存在明显安全隐患，直接一票否决。
  • 可行性：所用试剂、仪器是中学实验室（或题目给定）条件能实现的，反应条件温和可控。反例：常温常压下用 N2 和 H2 合成 NH3——原理对但条件不可行。
  • 简约性：步骤少、装置简单、药品用量省、现象明显。两个方案都能达到目的时，选操作简单、干扰少、成本低的那个。

近年高考还强调第五原则——绿色化学：原子利用率高、少产生或不产生污染物、原料尽量无毒、溶剂可回收。

2.2 设计答题框架：六步走

核心框架（必背）

目的 → 原理 → 装置 → 操作 → 现象 → 结论

  1. 明确目的：把题目要求翻译成一句"我要验证/制备/测定什么"。目的决定一切——所有设计都为它服务。
  2. 确定原理：写出核心反应的化学方程式（或离子方程式）。原理是方案的灵魂，先写方程式再选装置。
  3. 选择装置：由反应物状态和条件定发生装置，由物质性质定检验/收集装置，注意连接顺序（先除杂后干燥、先验水后验其他）。
  4. 规范操作：写清"取样→加试剂→如何操作（振荡/加热/静置）"，取样要有量（"取少量××于试管中"），加试剂要说明用量和顺序。
  5. 描述现象：具体到颜色、状态、气味、气泡——"溶液由无色变为浅红色""产生白色沉淀""有无色无味气体逸出"。现象必须唯一指向结论。
  6. 得出结论：结论与现象严格对应，回答最初的目的。格式："若出现××现象，则说明/证明××"。

检验类表述模板："取少量待测液于试管中，滴加××试剂，若观察到××现象，则证明含有××；反之则不含。"这个模板覆盖了操作、现象、结论三个采分点。

2.3 干扰排除：设计题的"第二灵魂"

核心概念

先想"谁会搅局"，再设计实验

一个方案是否严密，关键看有没有排除干扰。常见干扰类型与排除方法：

干扰类型 典型实例 排除方法
共存离子干扰 检验 Cl− 时 CO32− 也能与 AgNO3 生成沉淀 先加稀硝酸酸化（除去 CO32− 等），再加 AgNO3
试剂引入干扰 用盐酸酸化会引入 Cl−，干扰后续 Cl− 检验 改用稀硝酸酸化；检验 SO42− 用盐酸酸化后加 BaCl2
空气成分干扰 O2 氧化 Fe2+、Na2SO3；CO2 使石灰水变浑 煮沸蒸馏水除氧、液封、装置末端接碱石灰防空气中 CO2/H2O 倒灌
挥发性物质干扰 制 CO2 时盐酸挥发出的 HCl 使石灰水先浑后清 先通过饱和 NaHCO3 溶液除 HCl
检验顺序干扰 同时检验 H2O(g) 和其他气体产物，后续溶液会带出水 先验水（无水 CuSO4 放最前），验其他气体后再处理；除水放最后

经典顺序口诀：混合气体检验——"先验水，后验他；除杂在后水在前"；例如验证 C 与浓硫酸反应产物（H2O、SO2、CO2）：无水 CuSO4（验水）→ 品红（验 SO2）→ 酸性 KMnO4（除 SO2）→ 品红（确认 SO2 除尽）→ 澄清石灰水（验 CO2）。少一步"确认除尽"，方案就不严密。

2.4 探究型实验与控制变量

核心概念

探究四步与控制变量法

探究流程：提出问题 → 作出假设（可证伪，如"假设该固体含 Fe2+"）→ 设计实验验证 → 根据现象得出结论。答题时假设宁多勿漏，但每个假设都要有对应的验证实验。

控制变量法（探究反应条件影响的核心方法）：每次只改变一个条件（自变量），保持其他条件完全相同，观察因变量的变化。设计时落实为三个"同"：同浓度、同体积、同温度（探究哪一个，哪一个才允许不同）。

反例：探究"浓度对反应速率的影响"时，一组用 5 mL 1 mol/L 盐酸、另一组用 10 mL 2 mol/L 盐酸与锌反应——浓度和体积都变了，变量不唯一，结论无效。高考评价题中"没有控制变量"是高频扣分点。

对照实验：验证某因素的作用时，设置空白对照（如"加催化剂"与"不加催化剂"），用对比现象说话。

2.5 方案评价的四个角度与绿色化学

核心概念

评价话术：从四个角度"挑毛病"

  1. 原理评价：反应能否发生？现象与结论是否唯一对应？（如用 BaCl2 检验 SO42− 时不酸化——Ag+、SO32−、CO32− 都会生成白色沉淀，结论不可靠。）
  2. 操作评价：步骤是否简便安全？是否需要复杂装置或苛刻条件？有没有防倒吸、防污染措施？
  3. 误差评价（针对定量方案）：装置漏气、试剂挥发、称量误差会不会系统性地影响结果？哪个方案误差更小？
  4. 绿色化学评价：是否产生有毒气体/废液？原子利用率高不高？药品是否便宜易得？能否循环利用？

绿色化学经典判例：铜与浓硫酸直接加热制 CuSO4（Cu + 2H2SO4(浓) → CuSO4 + SO2↑ + 2H2O）——产生有毒 SO2 且硫酸利用率低；改进方案 Cu → CuO → CuSO4——无污染、硫酸全部转化为产品、原子利用率高。比较两条路线时从"污染、原料利用率、能耗"三点作答。

改进建议的句式："该方案存在××不足（如产生有毒气体 ××），可改为××，这样既××又××。"

三、三重表征贯通

第 1 组：检验 Fe2+ 与 Fe3+——试剂顺序里的科学

宏观（装置·操作·现象）

检验 Fe3+：取少量待测液，滴加 KSCN 溶液，若溶液变为（血）红色，证明含 Fe3+。

检验 Fe2+：取少量待测液，先加 KSCN 溶液，无现象；再滴加氯水，溶液变红，证明原溶液含 Fe2+。

注意顺序绝对不能颠倒：先加氯水再加 KSCN，则无法区分 Fe2+ 和 Fe3+（氯水会把 Fe2+ 氧化成 Fe3+，无论原来有没有 Fe3+ 都会变红）。

微观（原理解释）

Fe3+ 与 SCN− 结合生成红色的配合物 Fe(SCN)3，这是 Fe3+ 的特征反应，灵敏度高。

Fe2+ 不与 SCN− 显色，但它具有还原性，可被 Cl2 氧化为 Fe3+ 后再显色——"先无现象后变红"这组对比现象才能唯一地证明原来是 Fe2+ 而非 Fe3+。

设计的逻辑：先证明"没有 Fe3+"（排除干扰），再制造 Fe3+ 并观察到它——让现象与结论一一对应。

符号（方程式）

显色反应：Fe3+ + 3SCN− → Fe(SCN)3（红色）

氧化反应：2Fe2+ + Cl2 → 2Fe3+ + 2Cl−

设计要点：

① 顺序：先 KSCN，后氯水；

② 现象对比：无现象 → 变红；

③ 氯水可用 H2O2 替代（2Fe2+ + H2O2 + 2H+ → 2Fe3+ + 2H2O），不引入新杂质。

第 2 组：验证碳与浓硫酸的反应产物——装置顺序设计

宏观（装置·操作·现象）

装置顺序：发生装置（C＋浓硫酸，加热）→ 无水 CuSO4（白色变蓝，验 H2O）→ 品红溶液①（褪色，验 SO2）→ 酸性 KMnO4 溶液（除去 SO2）→ 品红溶液②（不褪色，确认 SO2 已除尽）→ 澄清石灰水（变浑浊，验 CO2）。

现象链条：白色粉末变蓝 → 品红褪色 → KMnO4 紫色变浅 → 品红不变色 → 石灰水产生白色浑浊。

微观（原理解释）

浓硫酸在加热时表现强氧化性，把 C 氧化为 CO2，自身被还原为 SO2，同时生成 H2O，三种产物混在一起。

顺序的必然性：气体通过任何水溶液都会带出水蒸气，所以验水必须放第一；SO2 和 CO2 都能使石灰水变浑（生成 CaSO3、CaCO3 沉淀），所以必须先验并除尽 SO2，才能用石灰水确认 CO2；品红②是"确认关卡"——没有它，就无法保证石灰水的浑浊一定来自 CO2。

符号（方程式）

主反应：C + 2H2SO4(浓) → CO2↑ + 2SO2↑ + 2H2O

除 SO2：5SO2 + 2KMnO4 + 2H2O → K2SO4 + 2MnSO4 + 2H2SO4

验 CO2：CO2 + Ca(OH)2 → CaCO3↓ + H2O

设计逻辑：验水在前、除杂在中、确认除尽、最后验证。

四、典型例题分步拆解

例 1 · 性质验证型【基础】：设计实验验证氯水的漂白性来自 HClO 而非 Cl2

题目：氯水能使有色布条褪色。有同学认为是 Cl2 起漂白作用，有同学认为是 HClO 起漂白作用。请设计实验验证哪种观点正确（可供选择的试剂和用品：氯水、干燥的有色布条、湿润的有色布条、干燥的 Cl2、集气瓶）。

【思路点拨】这是"提出假设→控制变量验证"的经典题。关键在于设置两组对照：干燥的 Cl2（无 HClO）与氯水（含 HClO），分别接触干布条，观察是否褪色。

1

明确目的：证明漂白作用来自 HClO（即 Cl2 与水反应的产物），而不是 Cl2 本身。核心变量：布条接触的物质是否含 HClO。

2

实验一：将干燥的有色布条放入盛有干燥 Cl2 的集气瓶中。现象：布条不褪色。结论：干燥的 Cl2 没有漂白性。

3

实验二：将湿润的有色布条放入同一集气瓶（或将干燥布条浸入氯水后取出）。现象：布条褪色。

4

得出结论：对比两组实验，变量是"是否有水参与"。褪色必须 Cl2 与 H2O 同时存在，说明起漂白作用的是二者反应生成的 HClO，而不是 Cl2 本身。

【答案】干燥 Cl2 不能使干燥布条褪色，氯水（或 Cl2＋水）能使布条褪色，故漂白性来自 HClO：Cl2 + H2O ⇌ HCl + HClO。

【方法总结】"验证是谁在起作用"类设计的通用套路：分离变量，逐一对照——让体系分别只含 A、只含 B、含 A+B，比较现象。此题还附带两个考点：干燥的 Cl2 无漂白性；新制氯水的漂白性久置后消失（2HClO → 2HCl + O2↑）。

例 2 · 气体制备与净化型【基础】：实验室制取纯净干燥的 Cl2

题目：实验室用 MnO2 与浓盐酸在加热条件下制取 Cl2。提供的装置有：A．固液加热发生装置；B．盛饱和食盐水的洗气瓶；C．盛浓硫酸的洗气瓶；D．向上排空气法收集装置；E．盛 NaOH 溶液的尾气吸收装置。（1）写出制取 Cl2 的化学方程式。（2）要制得纯净、干燥的 Cl2，装置接口的连接顺序是什么？（3）B 中为什么用饱和食盐水而不用水？B、C 的顺序能否颠倒？

【思路点拨】气体净化顺序的通法：先除杂、后干燥——经过任何水溶液都会带出水蒸气，所以干燥永远放最后；尾气处理放最末端。

1

(1) MnO2 + 4HCl(浓) → MnCl2 + Cl2↑ + 2H2O。注意"浓盐酸、加热"两个条件缺一不可，稀盐酸不反应。

2

(2) 连接顺序：A → B → C → D → E。A 中逸出的 Cl2 混有 HCl 气体和水蒸气：B 中饱和食盐水除去 HCl，C 中浓硫酸除去水蒸气，D 收集（Cl2 密度大于空气，用向上排空气法），E 中 NaOH 溶液吸收尾气：Cl2 + 2NaOH → NaCl + NaClO + H2O。

3

(3) 用饱和食盐水的原因：HCl 极易溶于水被除去，而饱和食盐水中高浓度的 Cl− 抑制了 Cl2 + H2O ⇌ HCl + HClO 平衡正向移动，减少 Cl2 的溶解损失。B、C 不能颠倒——若先干燥再通过食盐水，气体又会带出水蒸气，干燥前功尽弃。

【答案】(1) MnO2 + 4HCl(浓) → MnCl2 + Cl2↑ + 2H2O；(2) A→B→C→D→E；(3) 饱和食盐水吸收 HCl 且抑制 Cl2 溶解；不能颠倒，否则气体经水溶液会重新带出水蒸气。

【方法总结】装置连接题的万能顺序：发生 → 除杂 → 干燥 → 收集（或性质验证）→ 尾气处理。除杂试剂的选择原则是"只吸收杂质、不与目标气体反应、不引入新杂质"。

例 3 · 离子检验型【基础】：检验久置 Na2SO3 溶液是否变质、是否完全变质

题目：Na2SO3 溶液久置易被空气中的 O2 氧化。请设计实验：（1）检验某久置 Na2SO3 溶液是否已经变质；（2）进一步检验其是否完全变质，并说明不能选用哪些试剂及原因。

【思路点拨】变质的本质是生成了 SO42−。检验 SO42− 前必须排除 SO32− 的干扰（它也能与 Ba2+ 生成白色 BaSO3 沉淀）；判断是否"完全"变质则是反过来检验 SO32− 是否还有剩余。

1

(1) 检验是否变质：取少量待测液于试管中，加入足量稀盐酸酸化（除去 SO32−：Na2SO3 + 2HCl → 2NaCl + SO2↑ + H2O），静置后滴加 BaCl2 溶液。若产生白色沉淀（BaSO4），证明已变质。

2

干扰排除的逻辑：若不加足量盐酸，SO32− 会与 BaCl2 生成白色 BaSO3 沉淀，无法区分沉淀来自 BaSO3 还是 BaSO4。足量盐酸让 SO32− 全部以 SO2 逸出，剩下的白色沉淀只能是 BaSO4。

3

(2) 检验是否完全变质：另取少量待测液，滴加稀盐酸。若产生气泡（SO2，可使品红溶液褪色验证），说明仍含 SO32−，即部分变质；若无气泡产生，说明 SO32− 已不存在，即完全变质。

4

试剂禁区：不能用稀硝酸酸化、不能用 Ba(NO3)2——HNO3 及酸性条件下的 NO3− 有强氧化性，会把 SO32−（或 BaSO3）氧化为 SO42−（或 BaSO4），未变质也会"被变质"，造成误判。

【答案】(1) 加足量稀盐酸酸化后滴加 BaCl2，产生白色沉淀则已变质；(2) 另取样加稀盐酸，有气泡为部分变质、无气泡为完全变质；禁用稀硝酸和 Ba(NO3)2，因其强氧化性会把 SO32− 氧化为 SO42− 造成误判。

【方法总结】"是否变质"检验的是新物质（SO42−），"是否完全变质"检验的是原物质是否还有剩余（SO32−）——两问方向相反，试剂与现象都不同，答题时务必看清问的是哪一个。

例 4 · 实验安全与尾气处理型【基础】：评价并改进 SO2 制备与性质实验装置

题目：某同学用 Na2SO3 固体与 70% 硫酸反应制取 SO2，设计了如下装置：发生装置 → 盛品红溶液的试管（验证漂白性）→ 气体直接排入空气。请指出该装置的两处缺陷，提出改进措施，并说明如何用实验证明 SO2 的漂白是"可逆的"。

【思路点拨】评价装置先看"有没有毒气外排"，再看"会不会倒吸"——SO2 极易与 NaOH 溶液反应，吸收时导管若直接插入液面下会因压强骤降发生倒吸。

1

缺陷一：缺少尾气处理装置。SO2 是有刺激性气味的有毒气体，直接排放会污染空气。改进：装置末端连接盛有 NaOH 溶液的吸收装置：SO2 + 2NaOH → Na2SO3 + H2O。

2

缺陷二：吸收时未防倒吸。SO2 与 NaOH 溶液反应速率快，若导管直接插入液面以下，装置内压强骤降，液体会沿导管倒吸入前面的试管，可能炸裂热的玻璃仪器。改进：使用倒置漏斗（边缘恰好接触液面）或在吸收装置前加安全瓶（短进短出的空洗气瓶）。

3

验证漂白可逆：SO2 通入品红溶液，品红褪色；取褪色后的溶液加热，溶液恢复红色。说明 SO2 与有色物质结合生成的是不稳定的无色物质，受热分解又释放出有色物质——这与 HClO 的氧化型漂白（不可逆，加热不恢复）形成鲜明对比。

4

补充：选用 70% 硫酸而不用 98% 浓硫酸的原因——98% 浓硫酸中 H+ 浓度太低（主要以分子形式存在），反应太慢；也不用太稀的硫酸，因为 SO2 易溶于水，溶液太稀不利于 SO2 逸出。反应方程式：Na2SO3 + H2SO4 → Na2SO4 + SO2↑ + H2O。

【答案】缺陷：①无尾气处理，应接 NaOH 溶液吸收（SO2 + 2NaOH → Na2SO3 + H2O）；②未防倒吸，应改用倒置漏斗或加装安全瓶。验证可逆：褪色品红溶液加热后恢复红色。

【方法总结】装置评价"三看"：看安全（毒气、倒吸、爆炸）、看杂质（除杂与干燥是否齐备且顺序正确）、看环保（尾气是否处理）。防倒吸的三种经典手段：倒置漏斗、安全瓶、导管口悬于液面上方。

例 5 · 成分探究型【中档】：探究 Na2O2 与水反应的产物

题目：某学习小组探究 Na2O2 与 H2O 反应的产物。取少量 Na2O2 粉末于试管中，加入适量水，剧烈反应。请设计实验完成下列探究：（1）证明有 O2 生成；（2）证明溶液呈碱性；（3）有同学发现反应后的溶液中滴加酚酞先变红后褪色，提出假设"反应中生成了具有漂白性的中间产物 H2O2"，请设计实验验证该假设。

【思路点拨】(1)(2) 是常规检验；(3) 是探究题的精髓——利用 MnO2 对 H2O2 的催化分解来"捕捉"中间产物。

1

(1) 验 O2：将带火星的木条伸入试管口，木条复燃，证明有 O2 生成。反应方程式：2Na2O2 + 2H2O → 4NaOH + O2↑。

2

(2) 验碱性：取少量反应后的溶液于另一试管，滴加酚酞溶液，溶液变红（或用玻璃棒蘸取溶液点在 pH 试纸上，pH＞7），证明生成了 NaOH。

3

(3) 验 H2O2：取少量反应后的溶液于试管中，加入少量 MnO2 粉末，若有气泡迅速产生，且用带火星的木条检验气体能使木条复燃，证明溶液中存在 H2O2（2H2O2 → 2H2O + O2↑），假设成立。"先变红后褪色"正是 H2O2 漂白酚酞所致。

4

补充说明：Na2O2 与水反应实际分两步——先生成 H2O2（Na2O2 + 2H2O → 2NaOH + H2O2），H2O2 再分解（2H2O2 → 2H2O + O2↑），总反应即 2Na2O2 + 2H2O → 4NaOH + O2↑。

【答案】(1) 带火星木条伸入试管口，复燃，证明有 O2；(2) 滴加酚酞变红（或测 pH＞7），证明生成碱；(3) 加 MnO2 后迅速产生气泡且气体使带火星木条复燃，证明含 H2O2。

【方法总结】探究"看不见的中间产物"，要找一个只与该中间产物反应的"探针"（此处 MnO2 只催化 H2O2 分解，不与 NaOH、O2 作用），并给出可观察的现象（气泡＋复燃）。"假设—探针—现象—结论"四件套是探究题的标准答案结构。

例 6 · 氧化还原滴定型【中档】：KMnO4 法测定双氧水中 H2O2 的含量

题目：用 KMnO4 标准溶液滴定法测定某双氧水中 H2O2 的浓度。量取 25.00 mL 双氧水试液于锥形瓶中，加入适量稀硫酸酸化，用 0.02000 mol/L KMnO4 标准溶液滴定，平行滴定三次，平均消耗 KMnO4 溶液 20.00 mL。（1）写出滴定反应的化学方程式。（2）酸化时为什么选用稀硫酸，能否用盐酸或硝酸？（3）本实验需要外加指示剂吗？终点现象是什么？（4）计算试液中 H2O2 的物质的量浓度。（5）若盛装 KMnO4 的滴定管未用标准液润洗，测定结果偏高还是偏低？

【思路点拨】KMnO4 滴定的三个自带考点：酸化用硫酸、自身指示剂（KMnO4 紫色→Mn2+ 无色）、装在酸式滴定管（氧化性会腐蚀橡胶）。

1

(1) 酸性条件下 MnO4− 被还原为 Mn2+，H2O2 被氧化为 O2：2KMnO4 + 5H2O2 + 3H2SO4 → K2SO4 + 2MnSO4 + 5O2↑ + 8H2O。计量比 n(KMnO4)∶n(H2O2) = 2∶5。

2

(2) 只能选稀硫酸。不能用盐酸——Cl− 有还原性，会被 KMnO4 氧化（2MnO4− + 10Cl− + 16H+ → 2Mn2+ + 5Cl2↑ + 8H2O），多消耗标准液使结果偏高；不能用硝酸——HNO3 本身有强氧化性，会参与氧化 H2O2，干扰计量关系。

3

(3) 不需要外加指示剂——KMnO4 是自身指示剂：滴定过程中紫色 MnO4− 被还原为几乎无色的 Mn2+，溶液保持无色；到达终点时，滴入最后半滴 KMnO4 溶液后，溶液恰好变为浅红色（浅紫色），且半分钟内不褪色。

4

(4) n(KMnO4) = 0.02000 mol/L × 0.02000 L = 4.000×10−4 mol；n(H2O2) = 4.000×10−4 mol × (5/2) = 1.000×10−3 mol；c(H2O2) = 1.000×10−3 mol ÷ 0.02500 L = 0.04000 mol/L。

5

(5) 滴定管未用标准液润洗，残留水稀释了 KMnO4，消耗体积偏大 → 计算出的 H2O2 浓度偏高。

【答案】(1) 2KMnO4 + 5H2O2 + 3H2SO4 → K2SO4 + 2MnSO4 + 5O2↑ + 8H2O；(2) 用稀硫酸，盐酸会被氧化、硝酸有氧化性均干扰测定；(3) 不需要指示剂，终点为浅红色且半分钟不褪；(4) 0.04000 mol/L；(5) 偏高。

【方法总结】氧化还原滴定方案评价四问：酸化用什么酸（防副反应）、指示剂要不要（找自身指示剂）、装什么滴定管（看氧化性）、误差看谁（仍套 c待 = k·c标V标/V待）。注意计量比不再是 1∶1，列式先写方程式。

例 7 · 中和滴定方案评价型【中档】：NaOH 标准液的配制方案是否可行

题目：某小组要测定食醋中醋酸的浓度，设计了如下方案："用托盘天平称取 4.0 g NaOH 固体，溶于水配成 1 L 溶液，即得 0.1 mol/L 的 NaOH 标准溶液；取 25.00 mL 食醋稀释液，以酚酞为指示剂，用上述标准液滴定。"请评价该方案的可行性；若不可行，说明原因并给出改进方案；并分析若配制的 NaOH 溶液中含有 Na2CO3 杂质，测定结果将如何偏差。

【思路点拨】方案评价先看"基准物质合不合格"——能直接配制标准液的物质必须组成固定、性质稳定、易称量。NaOH 恰恰三条都不满足。

1

可行性判断：不可行。原因有二：①NaOH 固体易潮解，称量过程中吸收空气中的水分，实际称得的 NaOH 少于 4.0 g；②NaOH 会吸收空气中的 CO2 变质（2NaOH + CO2 → Na2CO3 + H2O），样品组成不固定。因此 NaOH 不是基准物质，不能直接称量配制准确浓度的标准液。

2

改进方案：先配制近似浓度的 NaOH 溶液，再用基准物质标定——常用邻苯二甲酸氢钾（KHC8H4O4，组成固定、稳定、摩尔质量大）：准确称取基准物，用待标定的 NaOH 溶液滴定（酚酞指示），由基准物的物质的量算出 NaOH 溶液的准确浓度。

3

杂质误差分析：若 NaOH 中含 Na2CO3，以酚酞为指示剂时，Na2CO3 只被中和到 NaHCO3（CO32− + H+ → HCO3−），1 mol Na2CO3 只提供 1 mol 中和能力（不足 2 mol NaOH 的当量）。标准液的实际中和能力低于名义浓度，滴定醋酸时消耗的体积偏大，按名义浓度计算 → 醋酸测定结果偏高。

4

方案中的合理之处：指示剂选择正确——NaOH 滴定醋酸，终点生成 CH3COONa，溶液呈碱性，变色范围（8.2~10.0）落在突跃内的酚酞是正确选择，若误用甲基橙会在终点前提前变色，使结果偏低。

【答案】不可行：NaOH 易潮解、易吸收 CO2，不是基准物质，不能直接配制标准液；改进：先配近似浓度，再用邻苯二甲酸氢钾标定；含 Na2CO3 杂质时实际碱浓度偏低、消耗体积偏大，测定结果偏高。

【方法总结】滴定方案评价"三查"：查基准（标准液是否可直接配制，盐酸、NaOH、KMnO4 都不能直接配）、查指示剂（变色范围要落在突跃内，匹配终点酸碱性）、查误差（顺着 c待 公式推方向）。

例 8 · 方案评价型【中档】：比较两种制备 CuSO4 的方案

题目：以铜屑为原料制备 CuSO4，有两种方案。

方案甲：Cu → CuSO4（直接法）

方案乙：Cu → CuO → CuSO4（间接法）

请从绿色化学和经济效益角度评价两个方案的优劣。

【思路点拨】先写出两个方案的完整方程式，再逐角度对比：污染、原子利用率、原料消耗、能耗。

1

方案甲：Cu + 2H2SO4(浓) → CuSO4 + SO2↑ + 2H2O。生成 1 mol CuSO4 消耗 2 mol H2SO4（1 mol 作氧化剂被还原为 SO2，1 mol 提供 SO42−），并放出有毒的 SO2。

2

方案乙：2Cu + O2 → 2CuO；CuO + H2SO4(稀) → CuSO4 + H2O。生成 1 mol CuSO4 只消耗 1 mol H2SO4，氧化剂是空气中的 O2（免费），不产生有害气体。

3

绿色化学评价：甲产生污染性气体 SO2，且硫元素一半进入 SO2 被浪费，原子利用率低；乙无污染气体排放，硫酸全部转化为产品，原子利用率高。乙更绿色。

4

经济性评价：甲硫酸消耗量大且需要处理尾气（额外成本）；乙硫酸用量减半，氧化剂 O2 取自空气，原料成本低。乙更经济。综合看方案乙优于方案甲。

【答案】方案乙优。理由：①不产生 SO2 等污染物；②硫酸利用率高（甲中一半硫酸被还原浪费）；③氧化剂 O2 廉价易得，成本低。

【方法总结】方案比较题的"三板斧"——写全方程式（发现隐藏的消耗）→ 比污染（气体、废液、能耗）→ 比原料利用率与成本。答题时要落到具体的物质和数字（"生成 1 mol CuSO4 甲耗 2 mol 硫酸、乙只耗 1 mol"），不要空喊"甲不环保"。

例 9 · 定量测定多方案评价型【压轴】：测定 Na2CO3 与 NaHCO3 混合物的组成

题目：现有一份 Na2CO3 和 NaHCO3 的固体混合物样品，三位同学分别设计了测定其组成的方案：

方案 A（气体法）：称取 m g 样品与足量盐酸反应，用排水法收集生成的 CO2，测其体积换算组成。

方案 B（沉淀法）：称取 10.00 g 样品溶于水，加入足量 BaCl2 溶液，过滤、洗涤、干燥，称得 BaCO3 沉淀 9.85 g。

方案 C（加热法）：称取 5.00 g 样品，充分加热至恒重，冷却后称得剩余固体 4.38 g。

（1）指出方案 A 的原理性缺陷并改进；（2）方案 B 中为什么只有 Na2CO3 产生沉淀？如何判断沉淀已"洗涤干净"？并计算混合物中 Na2CO3 的质量分数；（3）计算方案 C 中 NaHCO3 的质量分数；（4）从误差来源与可行性角度比较三个方案，选出最优方案并说明理由。（相对原子质量：Na 23　C 12　O 16　H 1　Ba 137）

【思路点拨】三个方案分别利用三种性质差异：都能与酸放 CO2（总量）、只有 CO32− 与 Ba2+ 沉淀（选择性）、只有 NaHCO3 受热分解（热稳定性）。评价时抓住每个方案独有的误差通道。

1

(1) 方案 A 的原理性缺陷：CO2 能溶于水并与水反应，用排水法收集会使测得的体积偏小，结果失真。改进：改用排饱和 NaHCO3 溶液的方法收集（饱和 NaHCO3 溶液中 CO2 溶解度很小），并注意读数前恢复至室温、调节量气管与水准管液面相平、视线与凹液面最低处相切。

2

(2) 选择性原理：BaCO3 难溶于水，而 Ba(HCO3)2 易溶于水，所以加入 BaCl2 时只有 Na2CO3 沉淀（Na2CO3 + BaCl2 → BaCO3↓ + 2NaCl），NaHCO3 留在溶液中——这正是沉淀法能"分开称"的原因。

3

洗涤干净的判断：取最后一次洗涤液少许于试管中，滴加 AgNO3 溶液（或稀硫酸），若不产生白色沉淀，说明洗液中已不含 Cl−（或 Ba2+），沉淀已洗净。若未洗净，附着 NaCl 等会使沉淀质量偏大、结果偏高。

4

方案 B 计算：M(BaCO3) = 137 + 12 + 48 = 197 g/mol，n(BaCO3) = 9.85 g ÷ 197 g/mol = 0.0500 mol = n(Na2CO3)，m(Na2CO3) = 0.0500 mol × 106 g/mol = 5.30 g，w(Na2CO3) = 5.30 g ÷ 10.00 g × 100% = 53.0%。

5

(3) 方案 C 计算：加热时只有 NaHCO3 分解：2NaHCO3 → Na2CO3 + H2O↑ + CO2↑。每 2 mol（168 g）NaHCO3 分解失去 1 mol H2O + 1 mol CO2 共 62 g。质量减少 5.00 − 4.38 = 0.62 g，故 m(NaHCO3) = 0.62 g × (168 ÷ 62) = 1.68 g，w(NaHCO3) = 1.68 g ÷ 5.00 g × 100% = 33.6%。

6

(4) 三方案评价与选优：

  • 方案 A：CO2 溶解、装置漏气、读数条件（温度、压强、视线）三个误差通道，系统误差大，需改进集气方法后才可用，操作最繁；
  • 方案 B：误差来自过滤损失、洗涤不净（偏高）、干燥不充分（偏高），步骤多但计量关系直接、干扰少（NaHCO3 不沉淀）；
  • 方案 C：只需称量两次，操作最简单；误差来自加热不充分（未恒重，偏低）或空气中吸水（偏低），通过"恒重操作＋干燥器冷却"可有效控制；且 Na2CO3 受热稳定不分解，原理干净。

综合误差可控性与操作可行性，方案 C 最优：误差通道最少、操作最简单、只需普通加热与称量设备，中学实验室完全可行。（若样品中含受热易分解或挥发的其他杂质，则 C 不适用，应选 B。）

【答案】(1) CO2 能溶于水，排水法测体积偏小，应改用排饱和 NaHCO3 溶液法；(2) Ba(HCO3)2 易溶于水故只有 Na2CO3 沉淀；取最后一次洗涤液滴加 AgNO3，无白色沉淀则已洗净；w(Na2CO3) = 53.0%；(3) w(NaHCO3) = 33.6%；(4) 方案 C 最优：误差通道少（恒重＋干燥器冷却即可控制）、操作最简单、原理干净；A 系统误差大，B 步骤多但计量直接可作备选。

【方法总结】定量测定方案的比较框架：先比原理干净度（有没有选择性、有没有系统偏差）→ 再比误差通道（每一步操作会不会丢、会不会多）→ 最后比可行性（设备、步骤、时间）。沉淀法看"过滤洗涤干燥"，气体法看"溶解、漏气、读数三条件"，加热法看"恒重与冷却"，各有命门。

五、易错点与成因

易错点 1

易错表现：检验 Fe2+ 时先加氯水、后加 KSCN 溶液；或检验 SO42− 时用稀硝酸酸化、用 Ba(NO3)2 作试剂。

错误成因：只记住"要加哪两种试剂"，没理解顺序本身就是实验逻辑的一部分——先氧化后显色，无法区分 Fe2+ 与 Fe3+；稀硝酸会把 SO32− 氧化成 SO42−，Ba(NO3)2 在酸性条件下 NO3− 也有强氧化性，同样造成误判。

正确理解：检验 Fe2+ 必须"先 KSCN 无现象、再氯水变红"；检验 SO42− 的标准操作是"先加足量稀盐酸酸化（无现象，排除 Ag+、CO32−、SO32−），再加 BaCl2 溶液，产生白色沉淀"。

避坑口诀："试剂顺序即逻辑，先排干扰再验证"。

易错点 2

易错表现：现象描述笼统——"有现象""产生沉淀""溶液变色"；或者现象与结论对不上（如用"溶液变蓝"证明淀粉存在）。

错误成因：平时不注意观察实验细节，答题时凭印象写；不理解现象是结论的唯一证据链，含糊的现象无法支撑严密的结论。

正确理解：现象描述必须包含试剂、颜色、状态变化三要素："滴加 KSCN 溶液后，溶液由（浅绿）色变为血红色"。并自查逻辑：现象是否唯一指向结论？N2、CO2 都能熄灭木条，所以"木条熄灭"不能证明气体是 CO2——必须用澄清石灰水（变浑浊）来确认。

避坑口诀："现象说到色态味，结论唯一才算对"。

易错点 3

易错表现：探究题中变量不唯一——比较浓度影响时，两组实验的浓度、体积、温度都不一样；或者没有设置对照组。

错误成因：把"做两个实验"等同于"做对照实验"，不理解控制变量的本质是让两组之间只有一个差别，这样现象差别才能归因于那个变量。

正确理解：设计探究实验时，先确定自变量（要研究什么），然后把其余条件全部锁定（同浓度、同体积、同温度、同表面积）。答题时主动写明"控制其他条件相同，仅改变××"，这句话本身就是采分点。

避坑口诀："一组实验变一样，其余条件全锁上"。

易错点 4

易错表现：方案评价只会说"好/不好""不环保"，说不出具体理由；或改进建议空洞（"改进装置"）。

错误成因：没有建立评价的角度清单，凭感觉作答；对方案的反应方程式没写出来，发现不了隐藏的污染物和原料浪费。

正确理解：评价先写方程式，再按"原理是否严密→操作是否安全简便→误差是否可控→是否符合绿色化学（污染、原子利用率、成本）"四个角度逐项过一遍，每个角度都落实到具体物质。改进建议要给出替代方案并说明优点："可改用××，这样既避免××，又提高××"。

避坑口诀："评价先写方程式，四个角度逐项批"。

易错点 5

易错表现：混合气体检验的装置顺序错误——先通过石灰水验 CO2 再验水；或除 SO2 后不经确认直接验 CO2。

错误成因：只记住各气体的检验试剂，没有站在"气体流过装置"的视角推演——气体经过任何水溶液都会带出水蒸气，使后续验水失去意义；SO2 与 CO2 性质相似（都使石灰水变浑），不确认 SO2 除尽，CO2 的检验就没有排他性。

正确理解：多组分气体检验的总原则是"验水最先、除杂在中、确认除尽、目标最后"。每接一个洗气瓶，都问一句："从这里出去的气体会不会污染下一个检验？"

避坑口诀："先验水，后验他，除尽确认再验下"。

六、章末自检清单

  • 我能说出实验方案设计的四大原则（科学性、安全性、可行性、简约性）并各举一个反面例子。
  • 我能按"目的—原理—装置—操作—现象—结论"六步框架完整设计一个检验或制备实验。
  • 我能熟练使用检验类表述模板："取样→加试剂→现象→结论"，且现象描述具体到颜色和状态。
  • 我能在设计前主动分析干扰（共存离子、试剂引入、空气成分、挥发物），并给出排除方法。
  • 我能正确排列混合气体的检验顺序（先验水、验 SO2、除 SO2、确认除尽、验 CO2）并说明理由。
  • 我能正确写出 Fe2+（先 KSCN 后氯水）、SO42−（先盐酸后 BaCl2）的检验操作顺序并解释顺序的逻辑。
  • 我能用控制变量法设计探究实验，并指出变量不唯一的方案为什么无效。
  • 我能从原理、操作、误差、绿色化学四个角度评价实验方案，理由落实到具体反应和物质。
  • 我能排出 Cl2 制备中"除 HCl（饱和食盐水）→ 干燥（浓硫酸）→ 收集 → 尾气吸收"的装置顺序，并说明"先除杂后干燥"的道理。
  • 我能评价滴定方案：判断基准物质是否合格（NaOH、盐酸、KMnO4 都不能直接配制标准液），说出 KMnO4 滴定的酸化选择与自身指示剂原理。
  • 我能比较沉淀法、气体法、加热法测定混合物组成的误差来源与可行性，并选出最优方案说明理由。
  • 我能写出 Cu 制 CuSO4 两条路线的方程式，并从污染与原子利用率角度比较优劣。
  • 我能针对有缺陷的方案提出具体的改进建议，并说明改进后的优点。

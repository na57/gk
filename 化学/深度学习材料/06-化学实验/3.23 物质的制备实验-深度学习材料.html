3.23 物质的制备实验

高中化学 · 深度学习材料 · 面向 2029 届云南高考

物质制备是化学实验的"集大成者"：一个完整的制备实验，把反应原理、装置选择、除杂干燥、收集验满、尾气处理全部串联起来。高考实验大题几乎年年以制备为背景。本章以"气体制备八种＋无机物制备＋有机物制备"为主线，帮你建立"发生→除杂→收集→尾气"的通用分析框架——掌握了框架，任何陌生的制备实验都能拆解。

二、核心概念精讲

2.1 气体制备的总思路：四大环节环环相扣

核心概念

（1）发生装置：由"反应物状态＋反应条件"决定

装置类型 特征 典型气体
固固加热型 大试管，管口略向下倾斜（防冷凝水回流炸裂试管） O2（加热 KClO3 或 KMnO4）、NH3（NH4Cl＋Ca(OH)2）
固液不加热型 锥形瓶/大试管＋长颈漏斗（须液封）或分液漏斗；块状固体可用启普发生器（随开随用、随关随停） H2、CO2、SO2、NO、NO2、C2H2（电石＋饱和食盐水）
固液（液液）加热型 圆底烧瓶＋分液漏斗＋酒精灯 Cl2（MnO2＋浓盐酸）、HCl（NaCl＋浓硫酸微热）、C2H4（乙醇＋浓硫酸 170 ℃，温度计插入液面下）

启普发生器的适用条件（三个同时满足）：块状固体＋液体反应；反应不需加热；生成气体难溶于反应液。能用启普发生器的典型气体：H2、CO2、H2S。粉末状固体（如 Na2SO3 制 SO2）会从多孔隔板漏下，不能用。

核心概念

（2）净化与干燥：先除杂、后干燥

除杂原则：除杂试剂只与杂质反应，不与目标气体反应。常见组合：

  • Cl2 中混 HCl——饱和食盐水（Cl2 在饱和食盐水中溶解度小，HCl 极易溶）；
  • CO2 中混 HCl——饱和 NaHCO3 溶液（NaHCO3 + HCl → NaCl + CO2↑ + H2O，还能增产 CO2）；
  • CO2 中混 SO2——饱和 NaHCO3 溶液或酸性 KMnO4 溶液。

干燥剂选择的"酸碱匹配"：干燥剂不能与气体反应。

  • 浓硫酸（酸性、强吸水性）：可干燥 H2、O2、CO2、Cl2、SO2、HCl 等；不能干燥 NH3（2NH3 + H2SO4 → (NH4)2SO4）和还原性气体 H2S、HBr、HI（被浓硫酸氧化）。
  • 碱石灰（CaO＋NaOH，碱性）：可干燥 NH3、H2、O2 等；不能干燥 CO2、SO2、Cl2、HCl 等酸性气体。
  • 无水 CaCl2（中性）：可干燥多数气体，但不能干燥 NH3（生成 CaCl2·8NH3 络合物）。
核心概念

（3）收集方法：由气体的溶解性和密度决定

方法 适用气体 典型实例
排水法 难溶于水且不与水反应 O2、H2、NO（只能用排水法）、CH4、C2H4
向上排空气法（长进短出） 密度比空气大、不与空气成分反应 CO2、Cl2、SO2、NO2（只能用排空气法，因与水反应）、HCl
向下排空气法（短进长出） 密度比空气小、不与空气成分反应 H2、NH3（只能用排空气法，因极易溶于水）、CH4

判断密度的快捷方法：空气的平均摩尔质量约 29 g/mol，气体相对分子质量大于 29 则比空气重。NO（30）虽略重于空气，但因与 O2 反应（2NO + O2 → 2NO2）绝不能用排空气法——化学性质优先于物理性质。Cl2 还可以用排饱和食盐水法收集（减少溶解损失）。

（4）尾气处理：有毒、有污染的气体（Cl2、SO2、NO2、NO、H2S、HCl、NH3）必须处理。易溶于水的气体（HCl、NH3）用水吸收时要防倒吸（倒置漏斗/安全瓶）；Cl2、SO2、NO2 用 NaOH 溶液吸收；CO 等可燃性毒气可点燃转化为 CO2 或用气球收集。

深度辨析

气体制备中的"为什么"三连问

① CO2 为什么用盐酸不用硫酸？CaCO3 与 H2SO4 反应生成的 CaSO4 微溶于水，覆盖在石灰石表面形成致密薄膜，阻止酸与内部 CaCO3 继续接触，反应很快停止。也不用浓盐酸（挥发性太强，CO2 中混入大量 HCl 气体），更不用 Na2CO3 粉末（反应太快来不及收集）。

② 制 NH3 为什么用 Ca(OH)2 而不用 NaOH？NaOH 易吸湿结块，加热时对玻璃腐蚀性强（高温下 OH− 腐蚀 SiO2），Ca(OH)2 碱性弱、疏松多孔，利于 NH3 逸出。同理，干燥 NH3 用碱石灰不用浓硫酸（酸碱中和）、不用无水 CaCl2（生成络合物）。

③ 实验室也用 H2O2 制 O2，装置有何不同？2H2O2 → 2H2O + O2↑，过氧化氢是液体、MnO2 是粉末状催化剂，常温即反应——属固液不加热型，与制 H2、CO2 同装置。这正说明：装置由反应物状态与条件决定，而不是由气体本身决定。

2.3 典型无机物的制备

核心概念

（1）Fe(OH)3 胶体的制备——"沸水、饱和、少量、不停加热"

操作：向沸腾的蒸馏水中逐滴加入 5~6 滴饱和 FeCl3 溶液，继续煮沸至液体呈红褐色，立即停止加热。

FeCl3 + 3H2O → Fe(OH)3(胶体) + 3HCl

要点与原理：①必须用蒸馏水——自来水中的电解质会使胶体聚沉；②不能一次性大量倒入 FeCl3（局部浓度过大直接生成沉淀）；③不能长时间持续煮沸（胶体受热聚沉变成沉淀）；④不能用玻璃棒搅拌（破坏胶体稳定性）。产物是胶体不是沉淀，方程式中写"Fe(OH)3(胶体)"，不标沉淀符号↓。

核心概念

（2）Fe(OH)2 的制备——一切为了隔绝氧气

原理：FeSO4 + 2NaOH → Fe(OH)2↓（白色）+ Na2SO4。难点在于 Fe(OH)2 极易被空气中的 O2 氧化：4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3，白色沉淀迅速变为灰绿色、最终变为红褐色，现象转瞬即逝。

隔氧四招（高考常考改进措施）：

  1. 配制溶液的蒸馏水先煮沸，除去溶解的 O2，冷却后立即使用；
  2. 在 FeSO4 溶液液面上加一层植物油（或苯），隔绝空气；
  3. 用长胶头滴管吸取 NaOH 溶液，将滴管尖端伸入 FeSO4 溶液液面以下再挤出，避免 NaOH 溶液在下落过程中带入空气；
  4. FeSO4 溶液中预先加少量铁粉，防止 Fe2+ 被氧化（2Fe3+ + Fe → 3Fe2+）。

改进后可在较长时间内观察到白色絮状沉淀。颜色变化的完整描述（白色→灰绿色→红褐色）本身是高考现象描述题的采分点。

核心概念

（3）Al(OH)3 的制备——为什么用氨水不用 NaOH

Al2(SO4)3 + 6NH3·H2O → 2Al(OH)3↓ + 3(NH4)2SO4

离子方程式：Al3+ + 3NH3·H2O → Al(OH)3↓ + 3NH4+。

为什么不用 NaOH：Al(OH)3 是两性氢氧化物，能溶于过量的强碱：Al(OH)3 + OH− → AlO2− + 2H2O。用 NaOH 时用量难以控制，稍过量沉淀就溶解，产率下降。而 NH3·H2O 是弱碱，不能溶解 Al(OH)3，即使过量沉淀也不会消失——"弱碱制两性氢氧化物"是试剂选择"防过量"思想的经典体现。

（4）CuSO4·5H2O 晶体的制备：CuO 溶于稀硫酸得 CuSO4 溶液后，经"蒸发浓缩 → 冷却结晶 → 过滤 → 洗涤（少量冷水）→ 低温干燥"获得蓝色胆矾晶体。不能直接蒸干——CuSO4·5H2O 受热会失去结晶水变成白色粉末。

2.4 典型有机物的制备

核心概念

（1）乙酸乙酯的制备——酯化反应的经典实验

CH3COOH + C2H5OH ⇌ CH3COOC2H5 + H2O

装置与操作：试管中加入乙醇、浓硫酸、乙酸（先加乙醇，再沿器壁慢慢加入浓硫酸并振荡冷却，最后加乙酸），加几片碎瓷片，用酒精灯小心加热，产生的蒸气经长导管通到盛有饱和 Na2CO3 溶液的试管中，导管末端悬于液面上方（不能插入液面以下，防倒吸）。

现象：饱和 Na2CO3 溶液的液面上出现无色透明的油状液体，并可闻到香味。

各角色分析（高频考点）：

  • 浓硫酸：催化剂＋吸水剂（吸收生成的水，使平衡正向移动，提高产率）；
  • 饱和 Na2CO3 溶液三重作用：①溶解挥发出的乙醇；②中和挥发出的乙酸（Na2CO3 + 2CH3COOH → 2CH3COONa + CO2↑ + H2O）；③降低乙酸乙酯在水中的溶解度，便于分层析出；
  • 长导管：导气兼冷凝（不能伸入液面下——蒸气中含易溶于水的乙醇、乙酸，且受热不均匀会倒吸）。
核心概念

（2）溴苯的制备——取代反应的"细节大户"

C6H6 + Br2 → C6H5Br + HBr↑

装置与操作：苯与液溴在铁粉（实际起催化作用的是生成的 FeBr3）作用下反应，装置带长直导管（兼冷凝回流作用——苯和溴都易挥发，冷凝后回流到反应瓶），导管末端悬于 AgNO3 溶液（或水）液面上方。

现象与验证：反应放热，液体微沸，有红棕色溴蒸气；生成的 HBr 气体遇 AgNO3 溶液产生淡黄色 AgBr 沉淀——这正是证明"发生的是取代反应而非加成反应"的关键证据（加成不产生 HBr）。注意：挥发出的 Br2 蒸气也能与 AgNO3 溶液产生浅黄色沉淀，所以 HBr 气体须先通过盛有 CCl4（或苯）的洗气瓶除去 Br2 再检验。

产物提纯：粗溴苯呈褐色（溶有 Br2），用 NaOH 溶液洗涤（Br2 + 2NaOH → NaBr + NaBrO + H2O）至无色，分液取下层（溴苯密度大于水），再蒸馏提纯。

边界：苯与溴的取代必须用液溴，不能用溴水（苯只萃取溴水中的溴，不发生取代）。

核心概念

（3）硝基苯的制备——水浴控温的代表作

C6H6 + HNO3(浓) → C6H5NO2 + H2O

操作要点：

  1. 加药顺序：先取浓硝酸，再沿器壁缓缓注入浓硫酸（酸入酸，及时散热），摇匀冷却至 50~60 ℃以下后，再逐滴加入苯（防止苯大量挥发及发生副反应）；
  2. 水浴加热 55~60 ℃：温度过低反应慢，温度过高硝酸分解、苯挥发，且易生成二硝基苯等副产物；水浴加热的优点是受热均匀、温度易于控制，温度计插入水浴中（不是插入反应液！）；
  3. 长导管兼冷凝回流作用；
  4. 浓硫酸作催化剂和吸水剂。

产物：纯净的硝基苯是无色、有苦杏仁气味、密度比水大的油状液体；实验室粗产品常因溶有 NO2 而呈淡黄色，用 NaOH 溶液洗涤、分液除去杂质。

2.5 制备实验的通用流程框架

核心框架

发生 → 除杂 → 干燥 → 性质/收集 → 尾气处理

任何气体制备综合题都可以按这个框架"过一遍"：

  1. 发生装置：看反应物状态（固/液）与条件（是否加热）定类型；
  2. 除杂装置：分析产物中混有什么杂质（挥发出来的反应物、副产物、水蒸气），选只除杂质不伤目标的试剂；
  3. 干燥装置：按酸碱性匹配选干燥剂，洗气瓶"长进短出"；
  4. 收集/性质装置：排水法 or 排空气法（上/下），或验证某性质（漂白、氧化等）；
  5. 尾气处理：有毒气体必须处理，易溶气体防倒吸。

装置接口顺序口诀："先除杂、后干燥；洗气长进又短出；干燥管要粗进细出；收集看密度；毒气要收尾"。答题时装置作用要具体到"除去××气体，防止其干扰××"的程度，不能只写"除杂"两个字。

三、三重表征贯通

第 1 组：实验室制 Cl2——氧化还原在制备中的应用

宏观（装置·操作·现象）

装置：分液漏斗＋圆底烧瓶（固液加热型）→ 盛饱和食盐水的洗气瓶 → 盛浓硫酸的洗气瓶 → 向上排空气法集气瓶 → NaOH 溶液尾气吸收。

现象：向烧瓶中的 MnO2 黑色粉末滴入浓盐酸并加热，立即产生大量气泡，生成黄绿色、有刺激性气味的气体，集气瓶中气体颜色逐渐加深；湿润的淀粉 KI 试纸靠近瓶口变蓝。

微观（原理解释）

MnO2 中 Mn 为 +4 价，具有较强氧化性；浓盐酸中的 Cl− 具有还原性。加热提供能量后，Cl− 失去电子被氧化为 Cl 原子，两个 Cl 原子结合成 Cl2 分子逸出；Mn 得到电子降为 +2 价（Mn2+）。

注意：4 mol HCl 中只有 2 mol 被氧化（另 2 mol 起酸的作用提供 Cl−），所以方程式中盐酸前标"浓"，且随着反应进行盐酸变稀，反应会自行停止——稀盐酸不与 MnO2 反应。

符号（方程式）

MnO2 + 4HCl(浓) → MnCl2 + Cl2↑ + 2H2O

离子方程式：MnO2 + 4H+ + 2Cl− → Mn2+ + Cl2↑ + 2H2O

尾气吸收：Cl2 + 2OH− → Cl− + ClO− + H2O

第 2 组：实验室制 NH3——唯一碱性气体的"特殊待遇"

宏观（装置·操作·现象）

装置：大试管（固固加热型，管口略向下倾斜）→ 盛碱石灰的干燥管 → 向下排空气法集气瓶（瓶口塞一团棉花，减少与空气对流使收集更纯）→ 倒置漏斗用水吸收尾气（防倒吸）。

现象：加热 NH4Cl 与 Ca(OH)2 的混合物，产生无色、有刺激性气味的气体；湿润的红色石蕊试纸放在瓶口变蓝；蘸浓盐酸的玻璃棒靠近瓶口产生大量白烟。

微观（原理解释）

NH4+ 中的 N—H 键在 OH− 作用下断裂，NH4+ 与 OH− 结合生成 NH3·H2O，加热使 NH3·H2O 分解放出 NH3 分子。

NH3 是极性很强的分子且与水形成氢键，故极易溶于水（1 体积水溶 700 体积 NH3），只能用排空气法收集；NH3 是碱性气体，会与浓硫酸、CaCl2 反应，只能用碱性干燥剂碱石灰。不能用 NaOH 代替 Ca(OH)2 加热制取——NaOH 高温下严重腐蚀玻璃。

符号（方程式）

2NH4Cl(s) + Ca(OH)2(s) → CaCl2 + 2NH3↑ + 2H2O

验满原理：NH3 + H2O ⇌ NH3·H2O ⇌ NH4+ + OH−（碱性使石蕊变蓝）

白烟原理：NH3(g) + HCl(g) → NH4Cl(s)

第 3 组：乙酸乙酯的制备——可逆反应的产率攻略

宏观（装置·操作·现象）

装置：大试管＋长导管（导气兼冷凝），导管末端悬于饱和 Na2CO3 溶液液面上方。

现象：加热乙醇、乙酸与浓硫酸的混合物，右侧试管中溶液液面上逐渐出现一层无色油状液体，振荡后油层变小、有气泡产生（Na2CO3 中和乙酸），可闻到水果香味；静置后液体分为两层。

微观（原理解释）

酯化反应的断键规律是"酸脱羟基醇脱氢"：乙酸分子断裂 C—O 键脱去 —OH，乙醇分子断裂 O—H 键脱去 —H，二者结合成水；剩余的 CH3CO— 与 —OC2H5 结合成酯（可用 18O 同位素示踪证实：18O 出现在酯中而非水中）。

该反应是可逆反应，速率慢、程度小。浓硫酸一方面催化加快速率，另一方面吸收生成的水使平衡正向移动；加热既加速反应又把沸点低（77 ℃）的酯蒸出，进一步拉动平衡。

符号（方程式）

CH3COOH + CH3CH218OH ⇌ CH3CO18OC2H5 + H2O

要点：

①浓硫酸：催化剂＋吸水剂；

②饱和 Na2CO3：溶乙醇、除乙酸、降溶解度；

③导管不插入液面下——防倒吸。

四、典型例题分步拆解

例 1 · 发生装置与收集方法选择

题目：实验室制备下列气体时，发生装置与收集方法均相同的一组是（　　）

A．O2 和 NH3　　B．H2 和 CO2　　C．Cl2 和 SO2　　D．NO 和 NO2

【思路点拨】分别写出每种气体的反应物状态＋条件确定发生装置，再由溶解性、密度、化学活性确定收集方法，逐项比对。

1

A 项：O2（加热 KClO3/KMnO4）与 NH3（NH4Cl＋Ca(OH)2 加热）都是固固加热型发生装置；收集上 O2 可排水法/向上排空气，NH3 只能向下排空气。发生装置相同但收集方法不同（若以"排水法"为标准则 NH3 不行）——需注意题目要求"均相同"，A 不符合。

2

B 项：H2（Zn＋稀硫酸）与 CO2（CaCO3＋盐酸）都是固液不加热型；收集上 H2 排水法/向下排空气，CO2 向上排空气。收集方法不同，不符合。

3

C 项：Cl2 用固液加热型，SO2（Na2SO3＋浓硫酸）用固液不加热型，发生装置不同，不符合。

4

D 项：NO（Cu＋稀硝酸）与 NO2（Cu＋浓硝酸）都是固液不加热型；收集上 NO 只能排水法，NO2 只能向上排空气法。收集方法不同，不符合。

【答案】无（按题干严格判定）。若题目改为"发生装置相同"，则 A、B、D 均可入选；若再放宽收集方式（如 O2 用向上排空气），则需具体题目具体分析。本题设计为"找茬型"，训练点是：任何一对气体都要同时核对'发生'与'收集'两个维度。

【方法总结】做这类题先列两列——左列"反应物状态＋条件 → 发生装置"，右列"溶解性＋密度＋化学活性 → 收集方法"，两列都一致才可选。NO 与空气反应、NO2 与水反应这两个"唯一选择"是命题人最爱挖的坑。

例 2 · Cl2 制备综合

题目：实验室用 MnO2 与浓盐酸反应制取纯净、干燥的 Cl2，并对尾气进行处理。请回答：

（1）写出制取 Cl2 的化学方程式，并指出氧化剂。

（2）从发生装置出来的 Cl2 中混有哪些杂质气体？依次用什么试剂除去？

（3）用向上排空气法收集时，如何验满？

（4）尾气用什么吸收？写出离子方程式。

（5）若用含 4 mol HCl 的浓盐酸与足量 MnO2 反应，能否制得 1 mol Cl2？为什么？

【思路点拨】这是"制备链"全流程设问，按"发生→除杂→收集→尾气"框架逐问作答；第(5)问考查"浓盐酸变稀反应停止"的深层理解。

1

(1) MnO2 + 4HCl(浓) → MnCl2 + Cl2↑ + 2H2O；Mn 元素由 +4 价降为 +2 价，氧化剂是 MnO2。

2

(2) 杂质：浓盐酸挥发出的 HCl 气体和水蒸气。先通过饱和食盐水除去 HCl（Cl2 在饱和食盐水中溶解度小），再通过浓硫酸除去水蒸气。顺序不能颠倒——先干燥再除 HCl 会重新带出水蒸气。

3

(3) 将湿润的淀粉 KI 试纸放在集气瓶口，试纸变蓝则已集满（Cl2 + 2I− → I2 + 2Cl−，I2 遇淀粉变蓝）。

4

(4) 用 NaOH 溶液吸收：Cl2 + 2OH− → Cl− + ClO− + H2O。

5

(5) 不能。由方程式知 4 mol HCl（浓）完全反应可生成 1 mol Cl2，但随着反应进行，盐酸不断消耗且生成水，盐酸浓度逐渐降低变为稀盐酸，而稀盐酸不与 MnO2 反应，故实际生成的 Cl2 小于 1 mol。

【答案】见各步解析。

【方法总结】制备综合题按"五连问"自查：原理写对了吗？杂质想全了吗（挥发的反应物＋水蒸气）？除杂顺序对吗（先除杂后干燥）？验满试剂对准瓶口了吗？尾气处理了吗？另外记住两类"量变引起质变"：浓盐酸制 Cl2、浓硫酸与 Cu 反应，反应物都不可能完全转化。

例 3 · 制备实验的计算

题目：实验室用含杂质 20% 的石灰石 25.0 g 与足量稀盐酸反应制取 CO2。计算：（1）理论上可生成 CO2 多少克？（2）标准状况下体积为多少升？（相对原子质量：Ca 40　C 12　O 16　H 1　Cl 35.5）

【思路点拨】先扣除杂质算出纯 CaCO3 质量，再按方程式比例计算；盐酸"足量"意味着 CaCO3 完全反应，是限量试剂。

1

纯 CaCO3 质量：m(CaCO3) = 25.0 g × (1 − 20%) = 20.0 g；物质的量 n(CaCO3) = 20.0 g ÷ 100 g/mol = 0.200 mol。

2

方程式 CaCO3 + 2HCl → CaCl2 + CO2↑ + H2O 中，CaCO3 与 CO2 的化学计量数之比为 1∶1，故 n(CO2) = 0.200 mol。

3

(1) m(CO2) = 0.200 mol × 44 g/mol = 8.8 g。

4

(2) 标准状况下 V(CO2) = 0.200 mol × 22.4 L/mol = 4.48 L。

【答案】(1) 8.8 g；(2) 4.48 L。

【方法总结】制备计算三步走：纯化（扣杂质）→ 物质的量（除以摩尔质量）→ 按比例（方程式系数）→ 换算目标量。注意"足量"确定限量试剂；气体体积必须强调"标准状况"才能用 22.4 L/mol。

例 4 · Fe(OH)2 制备的改进

题目：用常规方法（向 FeSO4 溶液中滴加 NaOH 溶液）制备 Fe(OH)2，观察到的现象是"白色沉淀迅速变为灰绿色，最终变为红褐色"。某同学进行如下改进：①配制溶液所用的蒸馏水先煮沸后冷却；②在 FeSO4 溶液表面加一层植物油；③用长胶头滴管吸取 NaOH 溶液，伸入 FeSO4 溶液液面以下再挤出。请分别说明三条改进措施的作用，并写出白色沉淀变红褐色的化学方程式。

【思路点拨】三条措施的目标一致——隔绝 O2。分别从"除去已溶解的氧""阻断空气进入""防止加料带入空气"三个角度回答；变色方程式是必背方程式。

1

措施①：气体在水中的溶解度随温度升高而减小，煮沸可除去蒸馏水中溶解的 O2，防止其氧化 Fe(OH)2。

2

措施②：植物油密度比水小且不溶于水，浮在液面上形成液封，隔绝溶液与空气的接触。

3

措施③：常规滴加时 NaOH 液滴穿过空气会溶入 O2；伸入液面以下挤出，避免滴加过程带入空气中的 O2。

4

变色反应：4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3。Fe(OH)2 中 +2 价 Fe 被空气中 O2 氧化为 +3 价。

【答案】①除去水中溶解的 O2；②液封隔绝空气；③防止滴加过程带入 O2；4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3。

【方法总结】"改进措施类"问题的回答套路：先说常规操作有什么问题（引入了什么干扰），再说改进措施如何消除该干扰。凡制备易被氧化的物质（Fe2+ 化合物、亚硫酸盐等），"隔氧、除氧、还原剂保护"三板斧都要想到。

五、易错点与成因

易错点 1

易错表现：收集 NO 用排空气法，收集 NO2 用排水法。

错误成因：只按"密度比空气略大就用排空气法""能溶于水才用排水法"的物理标准机械套用，忽视了化学性质的优先地位——NO 会与 O2 反应（2NO + O2 → 2NO2），NO2 会与水反应（3NO2 + H2O → 2HNO3 + NO）。

正确理解：收集方法的选择顺序是——先看是否与空气成分反应、是否与水反应，再看溶解性和密度。NO 只能排水法，NO2 只能向上排空气法。同理，NH3 极易溶于水只能排空气法，HCl 只能向上排空气法。

避坑口诀："NO 排水、NO2 排气，化学性质定收集"。

易错点 2

易错表现：用浓硫酸或无水 CaCl2 干燥 NH3；用碱石灰干燥 CO2、Cl2。

错误成因：只记"浓硫酸是常用干燥剂""碱石灰能吸水"，没有把干燥剂与被干燥气体当作一对可能反应的试剂来审视——NH3 是碱性气体，与浓硫酸发生中和；NH3 还能与 CaCl2 生成络合物 CaCl2·8NH3；CO2、Cl2 是酸性（或与水反应呈酸性）气体，会被碱石灰吸收。

正确理解：干燥剂选择第一原则是"干燥剂不与气体反应"。干燥 NH3 只能用碱石灰；干燥酸性/中性气体（CO2、Cl2、SO2、H2、O2）可用浓硫酸；碱石灰只干燥中性和碱性气体。

避坑口诀："酸碱相配才干燥，氨气只认碱石灰"。

易错点 3

易错表现：制 CO2 用稀硫酸代替盐酸，或用 Na2CO3 粉末代替石灰石。

错误成因：认为"酸都能提供 H+，碳酸盐都能提供 CO32−，随便组合都行"，忽视了产物溶解度对反应进程的影响和反应速率对可收集性的影响。

正确理解：稀硫酸与 CaCO3 生成的 CaSO4 微溶于水，覆盖在石灰石表面阻止反应继续，气体"虎头蛇尾"；Na2CO3 是易溶粉末，与酸接触面积极大，反应太剧烈，气体来不及收集。实验室制 CO2 的标准搭配是块状石灰石（或大理石）＋稀盐酸——块状减缓速率、盐酸不生成覆盖膜。

避坑口诀："硫酸盖上盖，粉末跑太快；块石加盐酸，气流稳又长"。

易错点 4

易错表现：制备乙酸乙酯时把导管插入饱和 Na2CO3 溶液液面以下；认为 Na2CO3 溶液的作用只是"吸收杂质"。

错误成因：对倒吸的触发条件不敏感——乙醇、乙酸蒸气极易溶于水溶液，受热不均时导管内压强骤降引发倒吸；对三重作用记忆不全，回答片面丢分。

正确理解：导管末端应悬于液面上方（既导气冷凝又防倒吸）。饱和 Na2CO3 溶液的作用是"三合一"：溶解乙醇、中和乙酸、降低乙酸乙酯的溶解度便于分层。振荡后油层变小正是因为乙醇、乙酸被洗去。

避坑口诀："导管悬空防倒吸，碳酸钠液三重功"。

易错点 5

易错表现：制备 Fe(OH)3 胶体时写成 FeCl3 + 3NaOH 反应，或给胶体方程式标注沉淀符号；用自来水代替蒸馏水。

错误成因：混淆"Fe(OH)3 胶体"与"Fe(OH)3 沉淀"两条不同的制备路线——加碱得到的是沉淀而不是胶体；不理解胶体粒子是分子聚集体、并未形成宏观沉淀；不知道自来水中的电解质离子会中和胶粒电荷使胶体聚沉。

正确理解：Fe(OH)3 胶体的制备是向沸水中滴加饱和 FeCl3 溶液继续煮沸至红褐色，方程式写 FeCl3 + 3H2O → Fe(OH)3(胶体) + 3HCl，产物注明"(胶体)"且不标↓；必须用蒸馏水，不能搅拌、不能久煮。

避坑口诀："沸水滴铁红褐止，胶体不写沉淀符"。

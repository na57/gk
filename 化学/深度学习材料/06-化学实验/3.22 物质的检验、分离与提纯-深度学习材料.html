3.22 物质的检验、分离与提纯

高中化学 · 深度学习材料 · 面向 2029 届云南高考

检验与分离是化学实验的两大核心任务："它是谁？"靠检验，"怎么把它单独拿出来？"靠分离提纯。本章把常见离子、气体、有机物的检验方法系统成表，把物理分离与化学除杂的逻辑讲透——这部分是高考选择题和工业流程题的必考内容，掌握程度直接决定你实验题的得分下限。

学法提示

检验类知识最怕"背而不通"：每个检验方法都要想清楚三件事——特征反应是什么（依据）、有哪些离子会捣乱（干扰）、怎么把捣乱的请出去（排除）。分离提纯则要养成"先物理、后化学"的选择习惯：能用过滤、蒸馏等物理方法解决的，优先物理方法；必须转化的，再考虑化学方法，且严格遵守除杂四原则。

二、核心概念精讲

2.1 常见阳离子的检验

核心概念

阳离子检验一览（原理＋试剂＋现象）

离子 检验试剂/方法 现象与反应原理 干扰与排除
NH4+ 加浓 NaOH 溶液并加热 产生有刺激性气味、能使湿润红色石蕊试纸变蓝的气体：NH4+ + OH− → NH3↑ + H2O NH3 是中学阶段唯一的碱性气体，现象几乎无干扰
Fe3+ KSCN 溶液 溶液变为血红色：Fe3+ + 3SCN− ⇌ Fe(SCN)3 灵敏度高，干扰少；也可加 NaOH 生成红褐色 Fe(OH)3 沉淀
Fe2+ 先加 KSCN 溶液，再加氯水（或 H2O2） 加 KSCN 无现象，加氯水后变血红色：2Fe2+ + Cl2 → 2Fe3+ + 2Cl− 顺序不能颠倒；也可用铁氰化钾生成蓝色沉淀，或加 NaOH 观察"白色→灰绿→红褐"变色过程
Al3+ 逐滴加入 NaOH 溶液 先产生白色絮状沉淀，NaOH 过量后沉淀溶解：Al3+ + 3OH− → Al(OH)3↓；Al(OH)3 + OH− → AlO2− + 2H2O 与 Mg2+（沉淀不溶于过量碱）相区别，体现 Al(OH)3 的两性
Cu2+ 观察颜色或加 NaOH 蓝色溶液；加碱生成蓝色絮状 Cu(OH)2 沉淀 蓝色溶液是重要直观线索
Ba2+ 稀硫酸（或可溶性硫酸盐） 生成不溶于稀盐酸的白色 BaSO4 沉淀 与 BaCO3（溶于酸）相区别
Ag+ 稀盐酸（或可溶性氯化物） 生成不溶于稀硝酸的白色 AgCl 沉淀 —
Na+、K+ 焰色反应（物理方法） Na+ 黄色火焰；K+ 透过蓝色钴玻璃观察为紫色 K+ 必须透过蓝色钴玻璃观察，滤去 Na+ 黄色的干扰；焰色反应是元素的性质，单质和化合物现象相同

2.2 常见阴离子的检验

核心概念

阴离子检验一览（重点是干扰排除）

离子 检验操作（顺序很重要） 现象与原理
Cl− 先加稀硝酸酸化，再加 AgNO3 溶液 生成不溶于稀硝酸的白色沉淀：Ag+ + Cl− → AgCl↓。加稀硝酸是为了排除 CO32− 等干扰（CO32− + 2H+ → CO2↑ + H2O，Ag2CO3 溶于稀硝酸）
Br− 先加稀硝酸酸化，再加 AgNO3 溶液 生成不溶于稀硝酸的淡黄色沉淀：Ag+ + Br− → AgBr↓
I− 先加稀硝酸酸化，再加 AgNO3 溶液（或加氯水后加淀粉/四氯化碳） 生成不溶于稀硝酸的黄色沉淀：Ag+ + I− → AgI↓；或 2I− + Cl2 → I2 + 2Cl−，I2 遇淀粉变蓝（溶于 CCl4 显紫红色）
SO42− 先加稀盐酸酸化（无现象），再加 BaCl2 溶液 生成白色沉淀：Ba2+ + SO42− → BaSO4↓。先加盐酸排除 Ag+（生成 AgCl 会误解）、CO32−、SO32−（其钡盐均溶于盐酸）的干扰
CO32− 加稀盐酸，产生的气体通入澄清石灰水 无色无味气体使石灰水变浑浊：CO32− + 2H+ → CO2↑ + H2O；Ca(OH)2 + CO2 → CaCO3↓ + H2O。注意与 HCO3−、SO32− 的区分
HCO3− 加 CaCl2 溶液无沉淀，再加盐酸 先无现象（区别于 CO32−：Ca2+ + CO32− → CaCO3↓），加盐酸产生使石灰水变浑浊的气体：HCO3− + H+ → CO2↑ + H2O
SO32− 加稀盐酸，产生的气体通入品红溶液 产生有刺激性气味、能使品红溶液褪色的气体：SO32− + 2H+ → SO2↑ + H2O（区别于 CO32−）
NO3− 加铜片和浓硫酸并加热（棕色环试验为其特征反应） 产生红棕色气体：Cu + 4HNO3(浓) → Cu(NO3)2 + 2NO2↑ + 2H2O

为什么检验顺序如此讲究：检验的本质是"让目标离子发生一个别人模仿不了的特征反应"。当体系里可能存在"模仿者"（如 CO32− 模仿 SO42− 与 Ba2+ 生成白色沉淀）时，必须先用一种试剂把模仿者"请出场"（酸化），再让目标离子登台。顺序反了，干扰离子就会混淆视听——这正是高考考查"先加盐酸，再加 BaCl2"的原因。

2.3 常见气体的检验

核心概念

气体检验一览（现象必须具体到颜色、气味、变化过程）

气体 检验方法 现象
O2 将带火星的木条伸入集气瓶中 木条复燃（剧烈燃烧）
H2 点燃（先验纯），火焰上方罩冷而干燥的小烧杯 安静燃烧，发出淡蓝色火焰，烧杯内壁出现无色液滴
CO2 通入澄清石灰水 石灰水变浑浊：Ca(OH)2 + CO2 → CaCO3↓ + H2O；继续通入 CO2，浑浊又变澄清（生成可溶的 Ca(HCO3)2）
Cl2 观察颜色、闻气味（扇闻），或用湿润的淀粉 KI 试纸 黄绿色、有刺激性气味；使湿润淀粉 KI 试纸变蓝：Cl2 + 2I− → I2 + 2Cl−
NH3 用湿润的红色石蕊试纸靠近，或用蘸有浓盐酸的玻璃棒靠近 试纸变蓝（唯一的碱性气体）；遇浓盐酸产生大量白烟：NH3 + HCl → NH4Cl
SO2 通入品红溶液 品红褪色，加热后恢复红色（与 Cl2 漂白的不可逆性相区别）
NO 暴露在空气中（或与 O2 接触） 无色气体立即变为红棕色：2NO + O2 → 2NO2
NO2 观察颜色，通入水中 红棕色、刺激性气味；溶于水后气体变为无色，溶液显酸性：3NO2 + H2O → 2HNO3 + NO
CO 点燃（或通过灼热 CuO 后检验产物） 蓝色火焰；还原黑色 CuO 为红色固体，生成的气体使澄清石灰水变浑浊：CO + CuO → Cu + CO2
C2H4（乙烯） 通入溴水或酸性 KMnO4 溶液 溴水（橙黄色）褪色；酸性 KMnO4 溶液（紫色）褪色
重要辨析

CO2 与 SO2 都能使澄清石灰水变浑浊（CaSO3 也是白色沉淀），所以检验 CO2 前若混有 SO2，必须先通过酸性 KMnO4 溶液（或溴水）除去 SO2，再用品红溶液确认 SO2 已除尽，最后通入石灰水。这是实验综合题的经典设问顺序："除 SO2 → 验 SO2 除尽 → 验 CO2"。

2.5 物理分离法：适用范围是选择依据

核心概念

六种物理分离方法的选择逻辑

方法 利用的性质差异 适用混合物类型 典型实例
过滤 颗粒大小（溶解性） 不溶性固体＋液体 粗盐中除去泥沙
蒸发结晶 溶解度受温度影响小 可溶性固体＋溶剂（溶解度随温度变化不大的溶质） NaCl 溶液获得 NaCl 晶体
冷却结晶（降温结晶） 溶解度受温度影响大 溶解度随温度升高显著增大的溶质 KNO3 溶液获得 KNO3 晶体；KNO3 中混少量 NaCl 的提纯
蒸馏（分馏） 沸点差异 互溶液体（沸点差较大）或从溶液中回收溶剂 自来水制蒸馏水；石油分馏
萃取分液 溶质在两种互不相溶溶剂中的溶解度差异 溶质＋溶剂（用萃取剂富集溶质） CCl4 萃取碘水中的碘
升华 是否易升华 易升华固体＋不升华固体 I2 与 NaCl 的分离
渗析 粒子直径（胶体粒子不能透过半透膜，离子小分子能透过） 胶体＋溶液 Fe(OH)3 胶体中除去 NaCl

选择逻辑：先分析混合物各组分性质差异在哪里（溶解度？沸点？颗粒大小？），再选对应的分离方法。例如 NaCl 与 KNO3 都是可溶性固体，过滤不行；二者沸点极高，蒸馏不行；但 KNO3 溶解度随温度变化剧烈而 NaCl 平缓——所以用"蒸发浓缩、冷却结晶"把 KNO3 析出来。性质差异决定分离方法，这就是"结构决定性质、性质决定分离"的化学思维。

2.6 化学除杂法与除杂四原则

核心概念

化学除杂：让杂质"变身"为易分离的物质

常用化学除杂方法：

  • 沉淀法：加试剂使杂质转化为沉淀过滤除去。例：NaCl 中混 Na2SO4，加适量 BaCl2：Na2SO4 + BaCl2 → BaSO4↓ + 2NaCl。
  • 气化法：加试剂使杂质转化为气体逸出。例：Na2SO4 中混 Na2CO3，加适量稀硫酸：Na2CO3 + H2SO4 → Na2SO4 + CO2↑ + H2O。
  • 转化法：把杂质转化为目标物质（一石二鸟，最优方案）。例：Na2CO3 固体中混 NaHCO3，加热：2NaHCO3 → Na2CO3 + CO2↑ + H2O；CO2 中混 CO，通过灼热 CuO：CO + CuO → Cu + CO2。
  • 酸碱法：利用酸碱性差异。例：Mg 粉中混 Al 粉，加足量 NaOH 溶液过滤：2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2↑，Mg 不反应。
  • 氧化还原法：例：FeCl3 溶液中混 FeCl2，通入适量 Cl2：2FeCl2 + Cl2 → 2FeCl3；FeCl2 溶液中混 FeCl3，加足量铁粉：2FeCl3 + Fe → 3FeCl2。
  • 加热法：例：CaO 中混 CaCO3，高温煅烧：CaCO3 → CaO + CO2↑。
核心原则

除杂四原则：不增、不减、易分离、易复原

  1. 不增——不引入新的杂质。除杂试剂中的离子必须能被后续步骤除去或与原物质相同。例：除去 NaCl 中的 MgCl2 应加适量 NaOH，不能用 KOH（会引入 K+）。
  2. 不减——不能消耗或减少被提纯的物质。例：除去 CO2 中混有的少量 HCl，不能用 NaOH 溶液（CO2 也会被吸收：2NaOH + CO2 → Na2CO3 + H2O），应用饱和 NaHCO3 溶液（吸收 HCl 并放出 CO2，且 CO2 在其中溶解度小）。
  3. 易分离——杂质转化后的产物应与目标物质容易分离（生成沉淀、气体或进入另一相）。
  4. 易复原——若分离过程中目标物质被转化，应容易恢复原来的形态（如萃取后还要蒸馏回收）。

试剂量的问题：为保证杂质除尽，除杂试剂通常要过量；而过量的试剂本身又成了新杂质，所以多步除杂中——先加的过量试剂必须能被后加的试剂除去。经典案例：粗盐（含 Ca2+、Mg2+、SO42−）精制中，BaCl2 必须在 Na2CO3 之前加入，这样过量的 Ba2+ 才能被后加的 CO32− 沉淀除去，最后用盐酸除去过量的 CO32− 和 OH−。

三、三重表征贯通

第 1 组：Cl− 的检验——特征沉淀反应

宏观（操作·现象）

取少量待测液于试管中，先滴加稀硝酸，无气泡、无沉淀产生；再滴加 AgNO3 溶液，立即产生白色沉淀，振荡后沉淀不溶解。

若待测液中含 CO32− 而不先酸化，加 AgNO3 也会出现白色沉淀（Ag2CO3），但滴加稀硝酸后沉淀溶解并产生气泡。

微观（原理解释）

Ag+ 与 Cl− 结合生成的 AgCl 溶解度极小（25 ℃时约 1.5×10−4 g/100 g 水），且不溶于稀硝酸，是"双重保险"的特征沉淀。

Ag2CO3 虽也难溶，但 CO32− 能与 H+ 结合生成 H2CO3（分解为 CO2 和 H2O），使沉淀溶解平衡正向移动而溶解——稀硝酸先出场就是为了清除 CO32− 这个"模仿者"。

符号（方程式）

Ag+ + Cl− → AgCl↓（白色，不溶于稀硝酸）

干扰排除：CO32− + 2H+ → CO2↑ + H2O

Ag2CO3 + 2HNO3 → 2AgNO3 + CO2↑ + H2O

答题模板：取样 → 加稀硝酸酸化 → 加 AgNO3 → 白色沉淀 → 含 Cl−。

第 2 组：SO42− 的检验——顺序决定成败

宏观（操作·现象）

取少量待测液，先滴加足量稀盐酸，无沉淀、无气泡产生；再滴加 BaCl2 溶液，产生白色沉淀。

若先加 BaCl2 后加盐酸：含 SO32− 或 CO32− 时也先出现白色沉淀（加盐酸后才溶解），无法一步得出结论；含 Ag+ 时生成的 AgCl 加盐酸不溶解，会被误判为含 SO42−。

微观（原理解释）

BaSO4 溶解度极小且不溶于盐酸；而 BaSO3、BaCO3 中的弱酸根能与 H+ 反应生成气体脱离体系，沉淀随之溶解。

先加盐酸的"无现象"排除了三个嫌疑：无气泡→无 CO32−、SO32−；无沉淀→无 Ag+。此时再加 Ba2+ 产生的白色沉淀只能是 BaSO4。

特别注意：不能用稀硝酸酸化，也不能用 Ba(NO3)2——NO3− 在酸性条件下有强氧化性，会把 SO32− 氧化为 SO42− 造成误判。

符号（方程式）

Ba2+ + SO42− → BaSO4↓（白色，不溶于稀盐酸）

干扰排除：BaSO3 + 2H+ → Ba2+ + SO2↑ + H2O

答题模板：取样 → 加盐酸酸化（无现象）→ 加 BaCl2 → 白色沉淀 → 含 SO42−。

第 3 组：Fe2+ 的检验——"先无现象，后变红"的时序逻辑

宏观（操作·现象）

取少量待测液，先滴加 KSCN 溶液，溶液无现象（不变红）；再滴加少量新制氯水，溶液变为血红色。

若顺序颠倒（先加氯水再加 KSCN），即使原溶液含 Fe3+ 也变红，无法证明 Fe2+ 原本存在。

另一方案：滴加 NaOH 溶液，生成白色絮状沉淀，迅速变为灰绿色，最终变为红褐色。

微观（原理解释）

Fe2+ 与 SCN− 不能形成稳定的血红色配合物，故第一阶段"无现象"证明体系中无 Fe3+。

氯水中 Cl2 是氧化剂，把 Fe2+（还原性）氧化为 Fe3+，新生的 Fe3+ 立即与 SCN− 结合生成血红色的 Fe(SCN)3——颜色变化"从无到有"，证据链完整。

加碱方案中 Fe(OH)2 极易被空气中 O2 氧化：白色的 Fe(OH)2 表面先生成灰绿色的中间产物，最终全部转化为红褐色的 Fe(OH)3。

符号（方程式）

2Fe2+ + Cl2 → 2Fe3+ + 2Cl−

Fe3+ + 3SCN− ⇌ Fe(SCN)3（血红色）

Fe2+ + 2OH− → Fe(OH)2↓（白色）

4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3（红褐色）

四、典型例题分步拆解

例 1 · 离子检验与干扰排除

题目：某无色溶液中可能含有 Na+、Ba2+、Cl−、CO32−、SO42−。进行如下实验：

①取少量溶液，加入足量稀盐酸，有气泡产生；

②向①反应后的溶液中加入 BaCl2 溶液，有白色沉淀生成。

根据以上实验，下列判断正确的是（　　）

A．一定含有 CO32−、SO42−，一定不含 Ba2+　　B．一定含有 CO32−、SO42−、Na+，一定不含 Ba2+，可能含 Cl−

C．一定含有 CO32−，可能含有 SO42−　　D．无法确定是否含 Na+

【思路点拨】离子推断题的核心是"每步现象锁定谁、排除谁"，还要考虑离子共存（Ba2+ 与 CO32−/SO42− 不能大量共存）和电荷守恒（溶液必须有阳离子）。

1

实验①加盐酸有气泡：五种离子中只有 CO32− 能与 H+ 产生气体（CO2），故一定含 CO32−。溶液无色且含 CO32−，则与之不共存的 Ba2+ 一定不存在（否则早已生成 BaCO3 沉淀）。

2

实验②：①中盐酸足量，CO32− 已全部转化为 CO2 逸出，此时加 BaCl2 仍产生白色沉淀，该沉淀只能是 BaSO4，故一定含 SO42−。

3

电荷守恒：溶液中阴离子（CO32−、SO42−）必须有阳离子配平，Ba2+ 不存在，故Na+ 一定存在。Cl− 与所有实验现象无冲突，不能确定。

【答案】B

【方法总结】离子推断三把钥匙：特征反应（谁产生这个现象）、离子共存（谁能和谁在一起）、电荷守恒（溶液必然电中性）。注意"足量"二字的作用——它保证了前一步的离子不会干扰后一步。

例 2 · 除杂试剂的选择

题目：下列除杂方案（括号内为杂质）正确的是（　　）

A．NaCl 溶液（Na2CO3）：加入适量稀盐酸，至不再产生气泡

B．CO2（HCl）：通过盛有 NaOH 溶液的洗气瓶

C．FeCl2 溶液（FeCl3）：加入足量铜粉，充分反应后过滤

D．N2（O2）：通过灼热的铜网

【思路点拨】用除杂四原则逐项检验：不增（是否引入新杂质）、不减（是否损耗目标物质）、易分离（产物好不好处理）。

1

A 项：Na2CO3 + 2HCl → 2NaCl + CO2↑ + H2O，杂质转化为目标物质 NaCl 本身，不引入新杂质，"适量至不再产生气泡"控制用量精准。正确。

2

B 项：NaOH 在吸收 HCl 的同时也会吸收 CO2（2NaOH + CO2 → Na2CO3 + H2O），违反"不减"原则。应改用饱和 NaHCO3 溶液。错误。

3

C 项：2FeCl3 + Cu → 2FeCl2 + CuCl2，虽然除去了 Fe3+，但引入了新杂质 Cu2+（还有过量的铜粉），违反"不增"原则。应加入足量铁粉：2FeCl3 + Fe → 3FeCl2。错误。

4

D 项：2Cu + O2 → 2CuO，O2 被铜网吸收，N2 不与铜反应，无新杂质气体引入。正确。

【答案】AD

【方法总结】除杂题的黄金自问："试剂跟谁反应？生成什么？生成物去哪了？目标物质动没动？"四问都满意，方案才成立。高频"标准答案试剂"要记牢：CO2 中除 HCl 用饱和 NaHCO3；CO2 中除 SO2 用饱和 NaHCO3 或酸性 KMnO4；Cl2 中除 HCl 用饱和食盐水。

例 3 · 分离方法的选择

题目：选择合适的方法分离下列混合物（填序号：①过滤　②蒸发结晶　③冷却结晶　④蒸馏　⑤萃取分液　⑥升华）：

（1）除去 Ca(OH)2 溶液中悬浮的 CaCO3：________

（2）从食盐水中获得食盐晶体：________

（3）从硝酸钾溶液（含少量氯化钠）中提纯硝酸钾：________

（4）分离乙醇（沸点 78 ℃）与水的混合物：________

（5）提取溴水中的溴：________

（6）除去食盐中混有的少量碘：________

【思路点拨】先分析每组混合物中各组分的性质差异，再对号入座——溶解性差异用过滤/结晶，沸点差异用蒸馏，分配差异用萃取，升华性差异用升华。

1

(1) CaCO3 不溶于水，Ca(OH)2 微溶于水形成溶液——不溶固体与液体，用过滤（①）。

2

(2) NaCl 溶解度受温度影响很小，降温析不出多少，必须把水蒸掉——蒸发结晶（②）。

3

(3) KNO3 溶解度随温度变化剧烈，NaCl 平缓——蒸发浓缩后冷却，KNO3 大量析出而 NaCl 留在母液中——冷却结晶（③）。

4

(4) 乙醇与水互溶且沸点差异明显——蒸馏（④）。

5

(5) Br2 在 CCl4（或苯）中溶解度远大于在水中——萃取分液（⑤）。

6

(6) I2 受热易升华，NaCl 不升华——加热使碘升华收集——升华（⑥）。

【答案】(1)①　(2)②　(3)③　(4)④　(5)⑤　(6)⑥

【方法总结】分离方法速查口诀："不溶过滤，盐析蒸发，温差结晶，沸差蒸馏，分配萃取，易升加热，胶体渗析"。遇到陌生混合物，先列出各组分的物理性质表，差异一目了然。

例 4 · 气体鉴别

题目：现有三瓶失去标签的无色气体：CO2、SO2、O2。请用化学方法将它们一一鉴别出来（写出操作、现象和结论）。

【思路点拨】鉴别题要"先易后难、分层推进"：先用操作简便、现象独特的方法区分出一种，再鉴别剩下两种。SO2 有刺激性气味且能使品红褪色、O2 支持燃烧、CO2 不支持燃烧——利用性质差异设计两步即可。

1

第一步（鉴别 SO2）：分别取少量三种气体通入品红溶液，使品红溶液褪色、加热后又恢复红色的，原气体为 SO2。（或扇闻气味：有刺激性气味的为 SO2。）

2

第二步（区分 O2 与 CO2）：将带火星的木条分别伸入剩余两瓶气体中，木条复燃的原气体为 O2；木条熄灭的为 CO2。

3

验证（可选）：把熄灭木条的那瓶气体通入澄清石灰水，石灰水变浑浊，进一步确认是 CO2。

【答案】①将三种气体分别通入品红溶液，品红褪色且加热后恢复红色的为 SO2；②将带火星的木条伸入剩余两瓶气体，复燃者为 O2，熄灭者为 CO2（CO2 可使澄清石灰水变浑浊验证）。

【方法总结】鉴别题的规范表述格式是"取样 → 操作 → 现象 → 结论"四段式，每瓶气体都要说到。选择试剂的原则：一种试剂（或一组操作）产生的现象组必须互不相同。

五、易错点与成因

易错点 1

易错表现：检验 SO42− 时，用稀硝酸酸化后再加 BaCl2 溶液，或直接用 Ba(NO3)2 溶液加稀盐酸检验。

错误成因：认为"酸化用什么酸都行""钡盐用什么钡盐都行"，忽视了 NO3− 在酸性条件下具有强氧化性。

正确理解：若溶液中含 SO32−（而非 SO42−），NO3−（H+ 存在时）会把 SO32− 氧化为 SO42−，照样生成白色 BaSO4 沉淀，造成"假阳性"。正确操作是先用稀盐酸酸化（无现象），再加 BaCl2 溶液。

避坑口诀："硫酸根，盐酸引路氯化钡；硝酸硝钡要回避"。

易错点 2

易错表现：检验 Cl− 时，直接向待测液中滴加 AgNO3 溶液，看到白色沉淀就断定含 Cl−。

错误成因：只记得"AgCl 是白色沉淀"，忽略了 CO32−、OH− 等也能与 Ag+ 生成白色（或浅色）沉淀（Ag2CO3、AgOH 分解为 Ag2O）。

正确理解：AgCl 的特征是"白色沉淀且不溶于稀硝酸"，两个条件缺一不可。规范操作：先加稀硝酸酸化，再加 AgNO3 溶液——酸化排除了能产生溶于酸的沉淀的干扰离子。

避坑口诀："白色沉淀不算数，硝酸不溶才作数"。

易错点 3

易错表现：用焰色反应检验 K+ 时，直接观察火焰呈紫色就下结论；或者认为焰色反应是化学变化。

错误成因：不知道 Na+ 的黄色火焰极强，微量 Na+（玻璃、试剂中普遍存在）就会掩盖 K+ 的紫色；不理解焰色反应是原子中电子跃迁释放光子的物理过程。

正确理解：观察 K+ 的焰色必须透过蓝色钴玻璃，钴玻璃吸收黄光，滤掉 Na+ 的干扰；焰色反应没有生成新物质，是物理变化，且是元素的性质（单质、化合物中同种元素焰色相同）。

避坑口诀："钠黄钾紫钴玻璃，物理变化要牢记"。

易错点 4

易错表现：用澄清石灰水检验 CO2 时，认为"使石灰水变浑浊的气体一定是 CO2"；或在 CO2 与 SO2 共存时直接用石灰水检验 CO2。

错误成因：不知道 SO2 与石灰水反应同样生成白色沉淀（CaSO3），现象完全雷同。

正确理解：使澄清石灰水变浑浊的气体可能是 CO2 或 SO2。检验混合气中的 CO2 必须按"三步走"：先通过酸性 KMnO4 溶液除去 SO2 → 再通过品红溶液确认 SO2 已除尽（品红不褪色）→ 最后通入澄清石灰水，变浑浊才证明含 CO2。

避坑口诀："二氧化硫先赶尽，品红确认再验碳"。

易错点 5

易错表现：除去 FeCl2 溶液中混有的少量 FeCl3，选用铜粉或通入 Cl2；除去 CO2 中的少量 CO，选用点燃法。

错误成因：只盯着"除掉杂质"，没用除杂四原则完整检验方案——铜粉引入 Cu2+ 新杂质；Cl2 会把 FeCl2 也氧化掉（方向反了）；CO2 中少量 CO 因 CO 浓度太低、且 CO2 不支持燃烧，根本无法点燃。

正确理解：除 FeCl3 用足量铁粉（2Fe3+ + Fe → 3Fe2+，把杂质转化为目标物质）；CO2 中除 CO 应通过灼热的 CuO（CO + CuO → Cu + CO2，杂质变目标）。

避坑口诀："除杂首选转化法，杂质变身成自家"。

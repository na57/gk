二、核心概念精讲

2.1 弱电解质的电离平衡与电离常数

核心概念

是什么：弱酸、弱碱（如 CH3COOH、NH3·H2O）溶于水后只有一小部分分子电离成离子，且电离出的离子又能重新结合成分子，最终达到动态平衡——这就是电离平衡。以醋酸为例：

CH3COOH(aq) ⇌ CH3COO−(aq) + H+(aq)

电离常数（25 ℃时 HAc 的 Ka ≈ 1.8×10−5）：

Ka = c(CH3COO−)·c(H+) / c(CH3COOH)

为什么（微观解释）：弱电解质分子内化学键较强，水分子只能"拆散"其中一小部分；电离与结合两个过程速率相等时达到平衡。K 越小，说明平衡越靠左，酸（碱）越弱。

重要规律——越稀越电离：加水稀释，平衡右移，电离度 α 增大。但注意：电离度增大 ≠ 离子浓度增大——溶液体积增大的幅度更大，c(H+) 反而减小，pH 升高（对弱酸而言）。这是选择题最爱考的"坑"。

适用边界与常见混淆：

  • K 只与温度有关（电离吸热，升温 K 增大），与浓度无关；
  • 强酸强碱盐（NaCl 等）在水中完全电离，不存在电离平衡；
  • 多元弱酸分步电离，且 Ka1 ≫ Ka2 ≫ Ka3，酸性主要由第一步决定。如 H2CO3：Ka1 ≈ 4.3×10−7，Ka2 ≈ 5.6×10−11；
  • 比较两种酸的强弱：同温度下 Ka 大的酸性强（25 ℃：HF 的 Ka ≈ 6.8×10−4 > CH3COOH 的 1.8×10−5，故 HF 酸性更强）。

常见弱酸电离常数（25 ℃，数量级印象）：

弱酸Ka弱酸Ka
HF6.8×10−4CH3COOH1.8×10−5
H2CO3（Ka1）4.3×10−7H2S（Ka1）9.1×10−8
HClO3.0×10−8HCN6.2×10−10

由表可知酸性强弱：HF > CH3COOH > H2CO3 > HClO > HCN。由此推出两条高考常客：① 醋酸能与碳酸盐反应放出 CO2（强酸制弱酸），而苯酚不能；② CO2 通入 NaClO 溶液只能生成 HClO 和 HCO3−（因为 H2CO3 的 Ka1 > HClO 的 Ka > H2CO3 的 Ka2）。

2.2 水的电离与水的离子积 Kw

核心概念

是什么：纯水也会微弱电离：

H2O(l) ⇌ H+(aq) + OH−(aq)　　ΔH > 0

定义水的离子积：

Kw = c(H+)·c(OH−)　　25 ℃时 Kw = 1×10−14

三个关键理解：

  1. 任何水溶液中都同时存在 H+ 和 OH−，且 25 ℃时二者乘积恒为 10−14。酸溶液中 c(H+) > c(OH−)，碱溶液中反之，但乘积不变；
  2. 水电离出的 c(H+) 恒等于水电离出的 c(OH−)（1∶1 产生）。酸溶液中 OH− 全部来自水，故水电离出的 c(H+) = 溶液中 c(OH−) = Kw/c(H+)——酸、碱都抑制水的电离；
  3. Kw 随温度升高而增大（电离吸热）：100 ℃时 Kw ≈ 10−12，此时纯水 c(H+) = 10−6 mol/L，pH = 6，但纯水仍是中性——因为 c(H+) 仍等于 c(OH−)。

促进水电离的方法：升温；加入能水解的盐（如 CH3COONa、NH4Cl）——弱离子"吃掉"水电离出的 H+ 或 OH−，拉动水的电离平衡右移。

2.3 溶液的 pH 及其计算

核心概念

pH = −lg c(H+)　　pOH = −lg c(OH−)　　25 ℃时 pH + pOH = 14

计算模型清单（25 ℃）：

情形方法示例
强酸（一元，浓度 c）c(H+) = c0.01 mol/L HCl → pH = 2
强碱（一元，浓度 c）先求 c(OH−) = c，再用 Kw 换算0.01 mol/L NaOH → c(H+) = 10−12 → pH = 12
强酸稀释 10n 倍pH 增大 n 个单位（但始终 < 7）pH = 2 的盐酸稀释 100 倍 → pH = 4
强酸 + 强碱混合先中和，谁过量算谁见例题一
弱酸（浓度 c，Ka）近似 c(H+) ≈ √(Ka·c)（α < 5% 时可用）见例题一方法延伸

常用对数速记：lg 2 = 0.30，lg 3 = 0.48，lg 5 = 0.70。c(H+) = 2×10−4 → pH = 4 − lg 2 = 3.70。

稀释对照小表（25 ℃）：

溶液操作pH 变化原因要点
pH = 2 的盐酸稀释 10 倍pH = 3强酸完全电离，c(H+) 直接除以 10
pH = 2 的醋酸稀释 10 倍2 < pH < 3稀释促进电离，补充了一部分 H+，pH 增幅小于 1
pH = 12 的 NaOH 溶液稀释 10 倍pH = 11先算 c(OH−) = 10−3，再用 Kw 换算
pH = 12 的氨水稀释 10 倍11 < pH < 12同理，弱碱电离被促进

由此可推出高频考法：pH 相同的盐酸与醋酸分别稀释相同倍数，醋酸的 pH 更小；要使其 pH 仍相等，醋酸需要加更多的水。

边界提醒：酸无论怎么稀释，pH 只能无限接近 7，永远小于 7；碱同理永远大于 7。因为无限稀释后溶液中 H+ 主要来自水的电离。

2.4 酸碱中和滴定

核心概念

原理：利用已知浓度的酸（碱）标准液滴定未知浓度的碱（酸），当恰好完全中和时：

c(待测) = c(标准)·V(标准) / V(待测)（一元酸对一元碱）

仪器与操作要点：

  • 滴定管读数精确到 0.01 mL（量筒只有 0.1 mL）；酸式滴定管有玻璃活塞（不能装碱液），碱式滴定管下端是橡皮管（不能装酸液和强氧化性溶液如 KMnO4）；
  • 操作顺序：检漏 → 洗涤 → 润洗 2~3 次（用待装液，不能用蒸馏水润洗完就直接装液） → 装液、赶气泡、调零 → 取待测液（移液管或滴定管）→ 加指示剂 → 滴定（左手控活塞、右手摇锥形瓶、眼睛盯锥形瓶内颜色变化）→ 终点判断：最后一滴使颜色突变且半分钟内不恢复原色；
  • 锥形瓶只用蒸馏水洗净即可，不能用待测液润洗（否则待测物偏多，结果偏高）；
  • 滴定管读数：平视凹液面最低点。滴定前仰视、滴定后俯视 → 读数差偏小 → 结果偏低。

指示剂选择（滴定突跃范围决定）：

滴定类型恰好中和时溶液选用指示剂
强酸滴强碱（或反之）中性（pH = 7）酚酞或甲基橙均可
强酸滴弱碱酸性（生成强酸弱碱盐）甲基橙（变色范围 3.1~4.4，酸性区变色）
强碱滴弱酸碱性（生成强碱弱酸盐）酚酞（变色范围 8.2~10，碱性区变色）

注意：石蕊变色不敏锐（红→紫→蓝过渡太宽），中和滴定中不用石蕊作指示剂。

误差分析通法：一切误差都归结到"V(标准) 的读数偏大还是偏小"——凡是让标准液消耗偏多的操作，测得浓度就偏高。例如：酸式滴定管未用标准酸润洗（标准液被稀释，用量偏多，结果偏高）；锥形瓶中有少量蒸馏水（无影响，物质的量不变）。

2.5 盐类的水解

核心概念

是什么：盐电离出的弱酸根或弱碱阳离子，与水电离出的 H+ 或 OH− 结合生成弱电解质，破坏水的电离平衡，使溶液显酸性或碱性。如 CH3COONa 溶液显碱性：

CH3COO−(aq) + H2O(l) ⇌ CH3COOH(aq) + OH−(aq)

水解规律口诀：有弱才水解，无弱不水解；越弱越水解；谁强显谁性；同强显中性。

  • 有弱才水解：NaCl（强酸强碱盐）不水解，溶液中性；
  • 越弱越水解：组成盐的酸（碱）越弱，对应离子水解程度越大。如同浓度时 Na2CO3 碱性 > NaHCO3（因为 HCO3− 的酸性弱于 H2CO3，CO32− 水解更强）；
  • 谁强显谁性：CH3COONH4 中 Ka(HAc) ≈ Kb(NH3·H2O)，溶液接近中性；而 NH4HCO3 溶液显碱性（H2CO3 的 Ka1 < NH3·H2O 的 Kb，CO3 系水解占优）。

书写注意：水解程度微弱，用 ⇌ 连接；一般不标 ↓↑（不写 Fe(OH)3↓）；多元弱酸根分步水解、以第一步为主：

CO32− + H2O ⇌ HCO3− + OH−（主）　HCO3− + H2O ⇌ H2CO3 + OH−（次）

影响因素：升温促进水解（水解是中和的逆反应，吸热）；越稀越水解（但溶液酸碱性减弱——与弱电解质稀释同理）；加酸抑制弱碱阳离子水解、加碱抑制弱酸根水解。配制 FeCl3 溶液时加入少量盐酸，就是为了抑制 Fe3+ 水解：Fe3+ + 3H2O ⇌ Fe(OH)3 + 3H+。

双水解（相互促进）：Al3+ 与 HCO3−、CO32−、S2−、AlO2− 等相遇时水解互相促进进行到底，写等号并标 ↓↑：

Al3+ + 3HCO3− = Al(OH)3↓ + 3CO2↑　（泡沫灭火器原理）

酸式盐溶液的酸碱性（电离与水解的"拔河"）：多元弱酸的酸式酸根既能电离又能水解，溶液酸碱性取决于二者的相对强弱：

  • 水解 > 电离（显碱性）：HCO3−、HS−、HPO42−——所以 NaHCO3 溶液显碱性；
  • 电离 > 水解（显酸性）：HSO3−、H2PO4−、HC2O4−——所以 NaHSO3 溶液显酸性；
  • 强酸的酸式盐（NaHSO4）只电离不水解，水溶液中完全拆成 Na+、H+、SO42−，相当于一元强酸。

2.6 离子浓度大小比较与三大守恒

核心概念

三大守恒是解这类题的唯一可靠工具。以 0.1 mol/L Na2CO3 溶液为例：

① 电荷守恒（溶液电中性，阳离子正电荷总数 = 阴离子负电荷总数，注意乘电荷数）：

c(Na+) + c(H+) = c(OH−) + c(HCO3−) + 2c(CO32−)

② 物料守恒（某元素投料总量 = 溶液中该元素各种存在形式之和）：Na 与 C 投料比 2∶1：

c(Na+) = 2[c(CO32−) + c(HCO3−) + c(H2CO3)]

③ 质子守恒（水电离出的 H+ 总量 = 水电离出的 OH− 总量，得质子产物与失质子产物列两边）：

c(OH−) = c(H+) + c(HCO3−) + 2c(H2CO3)

质子守恒可由"电荷守恒与物料守恒消去不参与质子转移的 Na+"得到——忘掉写法时就现场推导。

排序思维模板（单一盐溶液）：

  1. 盐的"骨架离子"最多（不水解的那个通常排第一）；
  2. 水解产生酸碱性：显什么性，对应的 H+ 或 OH− 就大于另一个；
  3. 水解产物（如 HCO3−）次之，H+ 或 OH− 中"弱的那个"最少。

于是 Na2CO3 溶液：c(Na+) > c(CO32−) > c(OH−) > c(HCO3−) > c(H+)。

三大守恒书写速查表（建议默写到滚瓜烂熟）：

溶液电荷守恒物料守恒质子守恒
Na2CO3c(Na+)+c(H+) = c(OH−)+c(HCO3−)+2c(CO32−)c(Na+) = 2[c(CO32−)+c(HCO3−)+c(H2CO3)]c(OH−) = c(H+)+c(HCO3−)+2c(H2CO3)
NaHCO3c(Na+)+c(H+) = c(OH−)+c(HCO3−)+2c(CO32−)c(Na+) = c(CO32−)+c(HCO3−)+c(H2CO3)c(OH−)+c(CO32−) = c(H+)+c(H2CO3)
NH4Clc(NH4+)+c(H+) = c(Cl−)+c(OH−)c(Cl−) = c(NH4+)+c(NH3·H2O)c(H+) = c(OH−)+c(NH3·H2O)
CH3COONac(Na+)+c(H+) = c(CH3COO−)+c(OH−)c(Na+) = c(CH3COO−)+c(CH3COOH)c(OH−) = c(H+)+c(CH3COOH)

观察规律：质子守恒式中，"得质子产物"和"失质子产物"分列两边，每得/失一个质子系数加一（如 H2CO3 是 CO32− 得两个质子的产物，系数为 2）。

混合溶液先判断"发生什么反应、剩余什么"，再按单一溶液思路比较。例如等物质的量的 CH3COOH 与 CH3COONa 混合，电离大于水解，溶液显酸性：c(CH3COO−) > c(Na+) > c(H+) > c(OH−)。

2.7 难溶电解质的溶解平衡与溶度积 Ksp

核心概念

是什么：AgCl 虽"难溶"，但并非不溶——溶解与沉淀两个过程达到动态平衡：

AgCl(s) ⇌ Ag+(aq) + Cl−(aq)　　Ksp = c(Ag+)·c(Cl−)

通式：对 MmAn(s) ⇌ mMn+(aq) + nAm−(aq)，Ksp = cm(Mn+)·cn(Am−)。固体不写入表达式。

沉淀生成与溶解的判断（离子积 Q 与 Ksp 比较）：

  • Q > Ksp：过饱和，生成沉淀直至 Q = Ksp；
  • Q = Ksp：恰好饱和，处于平衡；
  • Q < Ksp：不饱和，沉淀继续溶解。

沉淀的转化：溶解度小的沉淀更容易生成，沉淀可向更难溶的方向转化。如向 AgCl 悬浊液中加 KI 溶液，白色沉淀转化为黄色 AgI：

AgCl(s) + I−(aq) ⇌ AgI(s) + Cl−(aq)　K = Ksp(AgCl)/Ksp(AgI) = 1.8×10−10 / 8.5×10−17 ≈ 2.1×106

K 很大，说明转化几乎完全。注意边界：只有"同类型"难溶物（离子比相同）才能直接用 Ksp 比溶解度；不同类型（如 AgCl 与 Ag2CrO4）必须通过计算比较。

2.8 电离平衡的影响因素（动态分析表）

核心概念

以 0.1 mol/L 醋酸溶液（CH3COOH ⇌ CH3COO− + H+）为例，逐项分析条件改变的结果：

条件改变平衡移动电离度 αc(H+)Ka
升温（电离吸热）右移增大增大增大
加水稀释右移增大减小不变
加入 CH3COONa 固体（同离子效应）左移减小减小不变
加入少量 NaOH 固体右移（H+ 被消耗）增大减小不变
加入锌粒（消耗 H+）右移增大减小不变
加入冰醋酸（增大浓度）右移减小增大不变

两个关键提醒：

  • Ka 只随温度变化，其余条件再怎么折腾它都不变——表格最后一列是最容易被出成判断题的地方；
  • 加冰醋酸时平衡虽然右移，但电离度反而减小——浓度越大电离度越小，这正是"越稀越电离"的另一面。判断电离度看"电离的分子占分子的比例"，判断 c(H+) 看"体积与总量的赛跑"，二者经常背离。

2.9 滴定曲线与突跃（深入理解指示剂选择）

核心概念

用 0.1000 mol/L NaOH 溶液滴定 20.00 mL 0.1000 mol/L 盐酸，几个关键点的 pH（25 ℃）：

  • 未滴加时：c(H+) = 0.1 mol/L，pH = 1.0；
  • 加入 19.98 mL（差半滴到终点）：剩余 H+ = 0.1000 × 0.02/1000 = 2×10−6 mol，总体积约 39.98 mL，c(H+) ≈ 5×10−5 mol/L，pH ≈ 4.3；
  • 加入 20.00 mL（恰好中和）：pH = 7.0；
  • 加入 20.02 mL（多半滴）：过量 OH− 同理 c(OH−) ≈ 5×10−5 mol/L，pOH ≈ 4.3，pH ≈ 9.7。

突跃：从 19.98 mL 到 20.02 mL，只加了 0.04 mL（约一滴）NaOH，pH 却从 4.3 跳到 9.7——这个急剧变化的区间叫滴定突跃。指示剂的变色范围只要落在突跃范围内（酚酞 8.2~10、甲基橙 3.1~4.4 都落在 4.3~9.7 之内），终点误差就在允许范围内。

用强碱滴定弱酸时：起点 pH 较高（弱酸只部分电离）、计量点因生成强碱弱酸盐而偏碱性（pH > 7）、突跃范围变小且整体上移——所以只能选酚酞，不能选甲基橙。反过来强酸滴弱碱只能选甲基橙。指示剂选择的本质就是"让变色点尽量贴近计量点"。

2.10 盐类水解的应用（高考常考清单）

核心概念
  • 明矾净水：KAl(SO4)2·12H2O 溶于水后 Al3+ 水解生成 Al(OH)3 胶体，吸附悬浮杂质：Al3+ + 3H2O ⇌ Al(OH)3(胶体) + 3H+；
  • 泡沫灭火器：Al2(SO4)3 溶液与 NaHCO3 溶液混合发生双水解：Al3+ + 3HCO3− = Al(OH)3↓ + 3CO2↑，CO2 和泡沫覆盖可燃物隔绝空气；
  • 配制易水解盐溶液：配 FeCl3、SnCl2 溶液时先溶于较浓的相应酸中，再加水稀释，抑制水解防止浑浊；
  • 蒸干与灼烧产物的判断：AlCl3 溶液蒸干灼烧最终得到 Al2O3（HCl 挥发拉动水解到底，Al(OH)3 再分解）；而 Al2(SO4)3 溶液蒸干仍得原溶质（H2SO4 难挥发，冷却后水解逆向复原）。判断依据是看对应酸是否挥发；
  • 热纯碱去油污：升温促进 CO32− 水解，碱性增强，油脂在碱性条件下水解更彻底；
  • 化肥混用禁忌：草木灰（主要成分 K2CO3，水解显碱性）不能与铵态氮肥混用，否则 NH4+ + OH− → NH3↑ + H2O，肥效流失；
  • Mg 与 NH4Cl 溶液反应放 H2：NH4+ 水解使溶液显酸性，Mg 与其中的 H+ 反应：Mg + 2NH4+ → Mg2+ + 2NH3↑ + H2↑。

2.11 沉淀溶解平衡的应用（除杂与转化）

核心概念

① 调 pH 除杂（工业流程高频考点）：除去 CuCl2 溶液中混有的少量 FeCl3，可加入 CuO（或 Cu(OH)2、CuCO3）调节 pH。依据是两种氢氧化物 Ksp 的巨大差异（25 ℃，Ksp[Fe(OH)3] ≈ 2.8×10−39，Ksp[Cu(OH)2] ≈ 2.2×10−20）：

  • Fe3+ 沉淀完全（c ≤ 10−5 mol/L）时：c(OH−) ≥ (2.8×10−39/10−5)1/3 ≈ 6.5×10−12 mol/L，即 pOH ≤ 11.2，pH ≥ 2.8；
  • 0.1 mol/L Cu2+ 开始沉淀时：c(OH−) = (2.2×10−20/0.1)1/2 ≈ 4.7×10−10 mol/L，即 pH ≈ 4.7；
  • 所以把 pH 调到 3~4.7 之间，Fe3+ 沉淀完全而 Cu2+ 留在溶液中。选 CuO 而不选 NaOH 的原因：CuO 消耗 H+ 抬升 pH 且不引入新杂质（过量的 CuO 过滤即可除去）。

② 沉淀转化用于除垢：锅炉水垢中的 CaSO4 致密且难溶于酸，处理方法是先用 Na2CO3 溶液浸泡：CaSO4(s) + CO32−(aq) ⇌ CaCO3(s) + SO42−(aq)（Ksp：CaSO4 ≈ 9.1×10−6 > CaCO3 ≈ 2.8×10−9，转化可行），再用盐酸溶解 CaCO3。

③ 钡餐的选择：医学造影用 BaSO4 而不用 BaCO3——BaCO3 会与胃酸反应 BaCO3 + 2H+ → Ba2+ + CO2↑ + H2O，产生有毒的可溶性钡盐；BaSO4 的 Ksp 极小且不与酸反应，Ba2+ 浓度低到无害。

④ 分步沉淀：向等浓度的 Cl−、I− 混合液中逐滴加入 AgNO3，Ksp 更小的 AgI（8.5×10−17）先沉淀，AgCl（1.8×10−10）后沉淀——沉淀顺序由"达到 Ksp 所需的 Ag+ 浓度"决定，不是由 Ksp 的绝对大小直接决定（同类型时两者一致）。

三、三重表征贯通

第 1 组：醋酸溶液中的电离平衡

宏观表征

0.1 mol/L 醋酸使紫色石蕊试液变红，但与同浓度盐酸相比：pH 更大（约 2.9 vs 1）、与镁带反应产生气泡更慢、导电能力更弱、稀释时 pH 变化更缓慢。说明醋酸中 H+ 浓度小，且"存货"多——反应消耗 H+ 后还能继续电离补充。

微观表征

溶液中大量 CH3COOH 分子保持分子形态，只有约 1.3% 电离为 CH3COO− 和 H+；同时离子又不断结合回分子，电离与结合速率相等，形成动态平衡。加水稀释时，平衡正向移动，电离的分子比例上升，但单位体积内 H+ 数目仍减少。

符号表征

CH3COOH(aq) ⇌ CH3COO−(aq) + H+(aq)

Ka = c(CH3COO−)·c(H+)/c(CH3COOH) ≈ 1.8×10−5（25 ℃）

离子方程式中醋酸不可拆：CH3COOH + OH− → CH3COO− + H2O

第 2 组：碳酸钠溶液为什么显碱性

宏观表征

纯碱（Na2CO3）明明是一种盐，水溶液却能使酚酞变红、能洗去油污（碱性条件利于油脂水解）。加热后红色加深——升温促进水解，碱性增强。向其中滴入盐酸，先无气泡，加盐酸到一定量后才开始大量冒气泡（先生成 HCO3−，再生成 CO2）。

微观表征

CO32− 不断"抢夺"水电离出的 H+ 生成 HCO3−（少量再进一步生成 H2CO3），使溶液中 c(OH−) > c(H+)；水的电离平衡被拉动右移。粒子浓度格局：Na+ 最多，CO32− 次之（只水解掉一小部分），OH− 多于 HCO3−（水解还叠加水的电离），H+ 最少。

符号表征

CO32− + H2O ⇌ HCO3− + OH−（主要）

HCO3− + H2O ⇌ H2CO3 + OH−（次要）

分步滴加盐酸：CO32− + H+ → HCO3−；HCO3− + H+ → CO2↑ + H2O

第 3 组：氯化银沉淀的生成、溶解与转化

宏观表征

向 NaCl 溶液中滴加 AgNO3 溶液，立即生成白色沉淀；继续加入氨水，白色沉淀逐渐溶解（得到无色溶液）；若改加 KI 溶液，白色沉淀慢慢变成黄色沉淀。三个操作对应溶解平衡的三次移动。

微观表征

悬浊液中 AgCl(s) 表面不断有 Ag+、Cl− 进入溶液，溶液中的 Ag+、Cl− 也不断回到固体表面，速率相等形成平衡，c(Ag+)·c(Cl−) = Ksp 恒定。加氨水时 NH3 与 Ag+ 结合成 [Ag(NH3)2]+，c(Ag+) 骤降，Q < Ksp，平衡向溶解方向移动；加 I− 时生成了 Ksp 更小的 AgI，沉淀发生转化。

符号表征

AgCl(s) ⇌ Ag+(aq) + Cl−(aq)　Ksp = 1.8×10−10

AgCl(s) + 2NH3·H2O → [Ag(NH3)2]+ + Cl− + 2H2O

AgCl(s) + I−(aq) ⇌ AgI(s) + Cl−(aq)　K ≈ 2.1×106

第 4 组：酸碱中和滴定的终点判断

宏观表征

锥形瓶中是加了 2 滴酚酞的 NaOH 溶液，呈浅红色；随着盐酸逐滴加入，红色逐渐变浅；当滴入最后半滴盐酸时，溶液突然由浅红色变为无色，且振荡后半分钟内不再变红——这就是滴定终点。多做几次会发现：终点前后只差一滴，颜色却判若两液。

微观表征

滴定过程中 H+ 与 OH− 不断结合成 H2O，c(OH−) 持续下降；临近计量点时溶液中 OH− 已所剩无几，最后半滴盐酸（约 0.02 mL）使 c(H+) 从 10−9.7 量级跃升到 10−4.3 量级——pH 在 0.04 mL 内跳变约 5 个单位，这就是"突跃"。酚酞在 pH < 8.2 时呈无色，恰好在突跃范围内变色，所以能灵敏指示终点。

符号表征

H+(aq) + OH−(aq) → H2O(l)

计量点：c(HCl)·V(HCl) = c(NaOH)·V(NaOH)

终点判断用语：当滴入最后半滴标准液时，溶液由浅红色恰好变为无色，且半分钟内不恢复原色

四、典型例题分步拆解

例 1 · pH 计算（混合溶液）

题目：25 ℃时，将 100 mL 0.10 mol/L 的盐酸与 100 mL 0.050 mol/L 的 NaOH 溶液混合（体积可加和），求混合后溶液的 pH。（lg 2.5 = 0.40）

【思路点拨】强酸强碱混合先发生中和反应 H+ + OH− → H2O。关键三步：① 算两种离子的物质的量；② 判断谁过量、剩多少；③ 用混合后总体积求浓度，再算 pH。

1

n(H+) = 0.100 L × 0.10 mol/L = 0.010 mol；n(OH−) = 0.100 L × 0.050 mol/L = 0.0050 mol。

2

H+ 过量，反应后剩余 n(H+) = 0.010 − 0.0050 = 0.0050 mol。

3

总体积 V = 0.200 L，c(H+) = 0.0050 / 0.200 = 2.5×10−2 mol/L。

4

pH = −lg(2.5×10−2) = 2 − lg 2.5 = 2 − 0.40 = 1.60。

【答案】pH = 1.6

【方法总结】酸碱混合求 pH 的口诀："先中和、再求余、除以总体积"。最常见的错误是用单一溶液体积去除，或者忘了判断谁过量。若碱过量，则先算 c(OH−)，再用 Kw 换算 c(H+)（千万别直接对 c(OH−) 取 −lg 就当作 pH）。

【延伸】若题目改为 0.10 mol/L 的醋酸（Ka = 1.8×10−5），则 c(H+) ≈ √(Ka·c) = √(1.8×10−5×0.10) = √(1.8×10−6) ≈ 1.34×10−3 mol/L，pH ≈ 3 − lg 1.34 ≈ 2.87，电离度 α ≈ 1.34%。

例 2 · 离子浓度大小比较（三大守恒）

题目：常温下，0.1 mol/L 的 NH4Cl 溶液中，下列关系正确的是（　）

A．c(Cl−) = c(NH4+) > c(H+) = c(OH−)
B．c(Cl−) > c(NH4+) > c(H+) > c(OH−)
C．c(NH4+) > c(Cl−) > c(OH−) > c(H+)
D．c(Cl−) + c(OH−) = c(NH4+) + c(H+) 且 c(Cl−) = c(NH4+)

【思路点拨】先确定溶质和水解情况：NH4Cl 完全电离出 NH4+ 和 Cl−，Cl− 不水解，NH4+ 微弱水解显酸性。再用排序模板 + 守恒验证。

1

写水解方程式：NH4+ + H2O ⇌ NH3·H2O + H+，溶液显酸性，故 c(H+) > c(OH−)。排除 A、C。

2

Cl− 不水解，NH4+ 会损耗一小部分，故 c(Cl−) > c(NH4+)。排除 D（等式本身虽是电荷守恒，但 c(Cl−) = c(NH4+) 不成立）。

3

水解程度微弱，NH4+ 只减少约万分之一，所以 c(NH4+) 仍远大于 c(H+)（水解产生的 H+ 极少）。

4

验证电荷守恒：c(NH4+) + c(H+) = c(Cl−) + c(OH−)。因为 c(H+) > c(OH−)，所以 c(NH4+) < c(Cl−)，与第 2 步一致，自洽。

【答案】B

【方法总结】盐溶液排序三步："定溶质 → 看水解（谁水解谁减少，显什么性）→ 守恒验证"。排序题的答案必须能通过电荷守恒检验——这是考场上最快的自查手段。

例 3 · Ksp 计算与沉淀判断

题目：已知 25 ℃时 Ksp(AgCl) = 1.8×10−10。

(1) 求 AgCl 在纯水中的溶解度 s（以 mol/L 计，√1.8 ≈ 1.34）；

(2) 向 1.0 L 0.010 mol/L 的 NaCl 溶液中加入 1 滴（约 0.05 mL，体积变化忽略）0.010 mol/L 的 AgNO3 溶液，是否有 AgCl 沉淀生成？

【思路点拨】(1) 纯水中 c(Ag+) = c(Cl−) = s，代入 Ksp 表达式即可；(2) 算离子积 Q，与 Ksp 比较。

1

设溶解度为 s，则 Ksp = c(Ag+)·c(Cl−) = s2 = 1.8×10−10。

2

s = √(1.8×10−10) = 1.34×10−5 mol/L。

3

(2) 混合后 c(Cl−) ≈ 0.010 mol/L（体积几乎不变）；加入的 Ag+ 的物质的量 n = 0.010 × 5×10−5 = 5×10−7 mol，分散在约 1.0 L 中，c(Ag+) ≈ 5×10−7 mol/L。

4

Q = c(Ag+)·c(Cl−) = 5×10−7 × 1.0×10−2 = 5×10−9。

5

Q = 5×10−9 > Ksp = 1.8×10−10，过饱和，有沉淀生成。

【答案】(1) s = 1.34×10−5 mol/L；(2) 有 AgCl 沉淀生成。

【方法总结】沉淀判断就一句话："算 Q、比 Ksp、Q 大则沉"。注意两个细节：① 混合后两种离子的浓度都要按新体积重新计算；② 同离子效应——AgCl 在 NaCl 溶液中的溶解度 = Ksp/c(Cl−) = 1.8×10−8 mol/L，比纯水中小约三个数量级，这就是"同离子抑制溶解"。

例 4 · 酸碱中和滴定误差分析

题目：用 0.1000 mol/L 的标准盐酸滴定 20.00 mL 未知浓度的 NaOH 溶液（以酚酞为指示剂）。下列操作使测得的 NaOH 浓度偏高、偏低还是无影响？

① 酸式滴定管水洗后未用标准盐酸润洗就装液；② 锥形瓶水洗后用待测 NaOH 溶液润洗；③ 滴定前滴定管尖嘴有气泡，滴定后气泡消失；④ 锥形瓶水洗后留有少量蒸馏水；⑤ 滴定终点读数时俯视刻度。

【思路点拨】把一切影响归到"V(盐酸) 的测量值"上：c(NaOH) = c(盐酸)·V(盐酸)/V(NaOH)。

1

① 未润洗 → 管内残留水稀释了标准盐酸 → 实际浓度变小 → 消耗体积偏大 → 偏高。

2

② 锥形瓶润洗 → 瓶内多留了 NaOH → 待测碱的物质的量变大 → 耗酸偏多 → 偏高。

3

③ 气泡占体积：气泡在滴定中"被读成"流出的酸 → V(盐酸) 读数偏大 → 偏高。

4

④ 锥形瓶里少量蒸馏水 → NaOH 物质的量不变 → 无影响。

5

⑤ 终点俯视读数 → 读数偏小 → V(盐酸) 偏小 → 偏低。

【答案】①偏高　②偏高　③偏高　④无影响　⑤偏低

【方法总结】误差分析万能思路："盯住公式里的 V(标准)：让标准液'显得用多了'就偏高，'显得用少了'就偏低，不改变物质的量的就无影响。"注意仰视/俯视要分清是哪一次读数出错（滴定管 0 刻度在上，俯视读数偏小、仰视偏大）。

例 5 · 离子浓度大小比较（酸式盐溶液进阶）

题目：常温下，0.1 mol/L NaHCO3 溶液显碱性。比较该溶液中各粒子浓度大小，并写出电荷守恒、物料守恒、质子守恒式。

【思路点拨】NaHCO3 是酸式盐，HCO3− 既能电离（HCO3− ⇌ H+ + CO32−）又能水解（HCO3− + H2O ⇌ H2CO3 + OH−）。溶液显碱性说明水解 > 电离，这是排序的关键依据。

1

NaHCO3 完全电离：Na+ 不水解，浓度最大；HCO3− 有少量损耗，排第二：c(Na+) > c(HCO3−)。

2

溶液显碱性 → c(OH−) > c(H+)；水解 > 电离 → 水解产物 H2CO3 多于电离产物 CO32−。

3

OH− 有两个来源（水解 + 水的电离），而 CO32− 只来自 HCO3− 的电离，故 c(OH−) > c(CO32−)；H+ 被大量消耗，浓度最小。

4

综合排序：c(Na+) > c(HCO3−) > c(OH−) > c(H2CO3) > c(H+) > c(CO32−)。注意 H2CO3 能排在 H+ 前面，是因为水解程度（约百分之几）远大于此时溶液的 c(H+) ≈ 10−10 量级。

5

三大守恒：
电荷守恒：c(Na+) + c(H+) = c(OH−) + c(HCO3−) + 2c(CO32−)；
物料守恒：c(Na+) = c(HCO3−) + c(CO32−) + c(H2CO3)；
质子守恒（两式相减消去 Na+）：c(H2CO3) + c(H+) = c(OH−) + c(CO32−)。

【答案】c(Na+) > c(HCO3−) > c(OH−) > c(H2CO3) > c(H+) > c(CO32−)；三大守恒式如上第 5 步。

【方法总结】酸式盐排序的灵魂只有一句——"先判电离与水解谁强，再定产物谁多谁少"。显碱性则水解产物多，显酸性则电离产物多。质子守恒不要死记，用"电荷 − 物料"消元法现场推，30 秒就能推出来。

例 6 · pH 计算（非常温与综合稀释）

题目：(1) 某温度下纯水的 c(H+) = 2×10−7 mol/L，求该温度下 0.005 mol/L Ba(OH)2 溶液的 pH；(2) 25 ℃时将 pH = 13 的 NaOH 溶液稀释 1000 倍，求稀释后溶液的 pH。

【思路点拨】(1) 温度变了，Kw 就不是 10−14，必须先从纯水求出该温度的 Kw；(2) 碱溶液稀释无限倍，pH 只能趋近 7，绝不能小于 7——先算一算，再用"边界"检验结果是否合理。

1

(1) 纯水中 c(H+) = c(OH−) = 2×10−7 mol/L，故该温度 Kw = 4×10−14。

2

Ba(OH)2 是二元强碱：c(OH−) = 2 × 0.005 = 0.01 mol/L = 10−2 mol/L。

3

c(H+) = Kw/c(OH−) = 4×10−14/10−2 = 4×10−12 mol/L，pH = 12 − lg 4 = 12 − 0.60 = 11.40。

4

(2) pH = 13 → c(OH−) = 0.1 mol/L；稀释 1000 倍后若简单相除得 c(OH−) = 10−4 mol/L，pOH = 4，pH = 10。检验：10 > 7，且稀释方向正确（从 13 向 7 靠近），合理。

5

反思边界：若稀释 108 倍，简单计算会得 pH = 5，这不可能——碱溶液再怎么稀释 pH 也只会无限趋近 7（此时必须考虑水电离出的 OH−）。本题稀释 1000 倍尚在中等浓度范围，结果可信。

【答案】(1) pH = 11.4；(2) pH = 10。

【方法总结】pH 计算两条军规：① 温度不明先用纯水求 Kw，"pH = 7 为中性"只在 25 ℃成立；② 算完用边界检验——酸不过 7、碱不过 7，稀释方向要合理。另外注意二元强碱要乘 2（Ba(OH)2），这是最常丢的系数。

例 7 · Ksp 沉淀转化计算

题目：已知 25 ℃时 Ksp(BaSO4) = 1.1×10−10，Ksp(BaCO3) = 2.6×10−9。医学上用 BaSO4 作"钡餐"。若误服 BaCO3 会中毒，可用 Na2SO4 溶液洗胃解毒。写出该解毒反应的离子方程式，并计算其平衡常数 K。

【思路点拨】沉淀转化的本质是沉淀溶解平衡与生成沉淀的叠加，转化平衡常数 = 两 Ksp 之比。

1

写反应：BaCO3(s) + SO42−(aq) ⇌ BaSO4(s) + CO32−(aq)。

2

平衡常数表达式：K = c(CO32−)/c(SO42−)（固体不写入）。

3

分子分母同乘 c(Ba2+)：K = [c(Ba2+)·c(CO32−)] / [c(Ba2+)·c(SO42−)] = Ksp(BaCO3)/Ksp(BaSO4)。

4

代入：K = 2.6×10−9 / 1.1×10−10 ≈ 23.6 > 1，转化能够自发进行，洗胃有效。

【答案】BaCO3(s) + SO42−(aq) ⇌ BaSO4(s) + CO32−(aq)；K ≈ 23.6。

【方法总结】"沉淀 A + 离子 ⇌ 沉淀 B + 离子"型转化的平衡常数 K = Ksp(A)/Ksp(B)。K 越大转化越彻底；K 不太小时（如本题 23.6），增大转化剂浓度（用较浓的 Na2SO4 溶液、多次洗涤）也能把转化"拉"向完全——这解释了为什么 CaSO4 水垢能被 Na2CO3 溶液转化。

答题模板

① 离子浓度大小比较答题模板：先写溶质（及发生的反应）→ 再写"存在哪些平衡"（电离/水解）→ 排出"骨架离子 > 水解（电离）剩余离子 > 显性离子 > 产物离子 > 隐性离子"→ 最后用电荷守恒验证。

② 解释类表述模板（如"为什么 Na2CO3 溶液显碱性"）：Na2CO3 溶于水完全电离出 CO32−，CO32− 结合水电离出的 H+ 发生水解：CO32− + H2O ⇌ HCO3− + OH−，使水的电离平衡正向移动，溶液中 c(OH−) > c(H+)，故显碱性。——"溶质电离 → 离子水解（写方程式）→ 水的平衡移动 → 浓度比较 → 结论"五步走。

③ 沉淀是否生成的表述：计算混合后 Q = c(Mn+)m·c(Am−)n，与 Ksp 比较：Q > Ksp 则生成沉淀，Q ≤ Ksp 则无沉淀。必须写出具体数值比较过程才给满分。

五、易错点与成因分析

易错点 1

易错表现：认为"加水稀释醋酸，电离平衡右移，所以 c(H+) 增大、pH 减小"。

错误成因：只盯平衡移动方向，忽略了体积这个更大的变量。电离度 α 增大只表示"电离的分子比例"上升，而 H+ 的总量增加的幅度远小于溶液体积的增大，浓度必然下降。

正确理解：越稀越电离（α 增大），但越稀离子浓度越小（c(H+) 减小、pH 增大）。比较"程度"用 α，比较"浓度"要算 c。

一句话避坑：电离度看比例，浓度看体积——稀释永远是"比例升、浓度降"。

易错点 2

易错表现：把"恰好中和"等同于"溶液呈中性"，如认为 NaOH 与 CH3COOH 恰好完全反应后 pH = 7。

错误成因：混淆了两个概念——"恰好中和"指物质的量恰好按方程式比例反应完；"呈中性"指 c(H+) = c(OH−)。中和的产物是盐，强碱弱酸盐会水解显碱性。

正确理解：恰好中和后看生成的盐：强酸强碱盐（NaCl）→ 中性；强碱弱酸盐（CH3COONa）→ 碱性；强酸弱碱盐（NH4Cl）→ 酸性。这也是滴定指示剂选择的依据。

一句话避坑：恰好中和 ≠ 中性，先看盐里有没有"弱离子"。

易错点 3

易错表现：写电荷守恒时漏乘离子电荷数，如把 Na2CO3 溶液的电荷守恒写成 c(Na+) + c(H+) = c(OH−) + c(HCO3−) + c(CO32−)。

错误成因：把"电荷守恒"误当成"粒子数守恒"。一个 CO32− 带 2 个单位负电荷，对电荷的贡献是浓度的 2 倍。

正确理解：电荷守恒中每个离子的浓度必须乘以其所带电荷数的绝对值：…+ 2c(CO32−)、3c(PO43−)。写完后可用"阴阳离子分列等号两边，逐一核对电荷系数"自查。

一句话避坑：电荷守恒数"电荷"不数"粒子"，多电荷离子前面乘系数。

易错点 4

易错表现：测 pH 时先把 pH 试纸用蒸馏水润湿，认为"润湿更好接触溶液"。

错误成因：与石蕊试纸、淀粉 KI 试纸混淆（后两者测气体时确实需要润湿）。pH 试纸润湿相当于把待测液稀释，若待测液是酸，pH 偏大；是碱则偏小；只有中性溶液才无影响。

正确理解：正确操作是用洁净干燥的玻璃棒蘸取待测液，点在干燥的 pH 试纸中央，变色后与标准比色卡对比读数，读数为整数。

一句话避坑：pH 试纸怕"水"——润湿等于稀释，酸大碱小。

易错点 5

易错表现：直接由 Ksp(Ag2CrO4) ≈ 1.1×10−12 < Ksp(AgCl) = 1.8×10−10，就断定 Ag2CrO4 溶解度更小、向 AgNO3 中滴加含 Cl− 和 CrO42− 的混合液时 Ag2CrO4 先沉淀。

错误成因：忽略了两者的"类型"不同（1∶1 型 vs 2∶1 型），Ksp 表达式中浓度的幂次不同，不能直接比大小。

正确理解：必须算各自的溶解度或开始沉淀所需离子浓度再比较。AgCl：s = √(1.8×10−10) ≈ 1.34×10−5 mol/L；Ag2CrO4：Ksp = 4s3，s = ∛(1.1×10−12/4) ≈ 6.5×10−5 mol/L，反而 AgCl 溶解度更小。在等浓度的 Cl−、CrO42− 混合液中滴加 AgNO3，先析出的是 AgCl（这就是莫尔法测 Cl− 的原理）。

一句话避坑：Ksp 直接比大小，只限同类型（离子比相同）的难溶物。

易错点 6

易错表现：写多元弱酸根水解时"一步到位"：CO32− + 2H2O ⇌ H2CO3 + 2OH−，并在普通水解方程式中标 ↓↑。

错误成因：没有理解水解是微弱的、分步的。第一步水解产生的 OH− 会抑制第二步，所以第二步程度极小，绝不能合并书写（这与多元弱酸的"分步电离"是对称的）。

正确理解：分步写、以第一步为主：CO32− + H2O ⇌ HCO3− + OH−。普通水解用 ⇌ 且不标 ↓↑；只有双水解进行到底（如 Al3+ 与 HCO3−）才写等号并标 ↓↑。

一句话避坑：多元弱酸根水解分步写、第一步为主；单水解用可逆号，双水解才到底。

易错点 7

易错表现：认为"0.01 mol/L 盐酸中水电离出的 c(H+) = 10−2 mol/L"或"盐酸抑制水的电离，所以水中不再有 H+ 产生"。

错误成因：没有区分"溶液中的 c(H+)"与"水电离出的 c(H+)"这两个不同的量。酸溶液中 H+ 绝大部分来自酸，水电离被抑制（水的电离平衡左移），但并没有停止。

正确理解：水电离出的 H+ 与 OH− 永远等量。酸溶液中 OH− 只能来自水，故水电离出的 c(H+) = c(OH−) = Kw/c(H+)溶液 = 10−14/10−2 = 10−12 mol/L。反过来，可水解的盐溶液中 H+、OH− 都来自水，如 pH = 5 的 NH4Cl 溶液中水电离出的 c(H+) = 10−5 mol/L，远大于纯水的 10−7。

一句话避坑：酸碱抑制水电离（酸取小头、碱取小头），盐类水解促进水电离（取大头）。

易错点 8

易错表现：认为"pH = 2 的盐酸和醋酸分别与足量锌反应，醋酸产生的 H2 更多"或"反应速率一样快，产生 H2 一样多"。

错误成因：混淆了"pH 相同"（此时溶液中 c(H+) 相同）与"酸的总储量"。pH = 2 的醋酸浓度远大于 0.01 mol/L（因为只部分电离），醋酸里还有大量未电离的"库存"分子，随反应进行不断电离补充 H+。

正确理解：① 起始瞬间两溶液 c(H+) 相同，起始反应速率相同；② 反应过程中醋酸持续电离，c(H+) 下降慢，平均速率醋酸更快；③ 若酸均足量且等体积，醋酸能提供的 n(H+) 总量大得多，产生的 H2 醋酸更多。若题目改为"等浓度等体积"，则两者产生的 H2 一样多（酸的物质的量相同）。

一句话避坑：pH 相同比"库存"，弱酸储量大、后劲足；浓度相同比"总量"，产氢一样多。

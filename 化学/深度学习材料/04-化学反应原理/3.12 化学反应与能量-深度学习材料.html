3.12 化学反应与能量

高中化学 · 深度学习材料 · 面向 2029 届云南高考

从这一章开始，我们正式进入高考分值最高的模块——化学反应原理。本章回答一个核心问题：化学反应为什么会"发热"或"吸热"，这个热量能不能算出来？ ΔH 的正负判断、热化学方程式书写、盖斯定律计算是高考的"三件套"，几乎每年都考。小兵，这一章计算不难，但细节极多，拼的是规范和细心。

二、核心概念精讲

2.1 反应热与焓变（ΔH）

核心概念

是什么：化学反应过程中吸收或放出的热量叫做反应热。在恒温恒压条件下，反应热等于体系的焓变，用符号 ΔH 表示，单位是 kJ/mol。

正负规定（死规矩，必须记牢）：

  • 放热反应：ΔH < 0，为负值（体系把热量"给了"环境，自己能量降低）；
  • 吸热反应：ΔH > 0，为正值（体系从环境"拿走"热量，自己能量升高）。

为什么（能量视角）：把反应物和生成物分别想象成站在不同高度的台阶上。生成物总能量低于反应物总能量时，多余的能量以热的形式释放——放热；反之则要吸热。能量图上看：反应物在上、生成物在下 → 放热；反应物在下、生成物在上 → 吸热。

常见混淆：

  • ΔH 的单位 kJ/mol 中的"mol"指"每摩尔反应进度"，即按方程式系数发生一次反应，不是指某物质的 1 mol；
  • 反应热是过程量，不能说"某物质含有多少热量"，只能说"某反应的 ΔH 是多少"。

常见放热反应与吸热反应（要能举出例子）

类型 常见反应 典型实例
放热反应 燃烧、酸碱中和、金属与酸（或水）反应、大多数化合反应、铝热反应 H2 在 Cl2 中燃烧；NaOH 与盐酸中和；CaO 与水反应
吸热反应 大多数分解反应、C 与 CO2 反应、C 与水蒸气反应、Ba(OH)2·8H2O 与 NH4Cl 反应 CaCO3 高温分解；C + CO2 → 2CO
提醒

"需要加热的反应不一定是吸热反应"。例如煤的燃烧需要先点燃，但燃烧本身是放热反应。加热只是提供"启动能量"（活化能），反应一旦被引发，放出的热量足以维持反应继续进行。判断吸放热的唯一标准是 ΔH 的正负，而不是反应条件。

拓展识图

能量变化图象的识读（选择题常考）：能量图以"反应进程"为横坐标、"能量"为纵坐标，画出台阶状的能量变化。读图三看：

  1. 看起点与终点的高低：反应物能量高于生成物 → 放热（ΔH < 0）；反之 → 吸热（ΔH > 0）；
  2. 看中间有没有"山头"：山头的高度差就是活化能，催化剂的作用是降低山头，但不改变起点和终点的高度差，即不改变 ΔH；
  3. 看 ΔH 对应哪一段：ΔH 是起点到终点的能量差，与山头高度无关。
图象特征 能量关系 ΔH 符号 实例
反应物在上、生成物在下 E(反应物) > E(生成物) ΔH < 0（放热） 所有燃烧反应
反应物在下、生成物在上 E(反应物) < E(生成物) ΔH > 0（吸热） CaCO3 高温分解

2.2 吸放热的微观本质：键能计算

核心概念

是什么：化学反应的本质是旧键断裂和新键形成。断裂化学键要吸收能量，形成化学键要放出能量。反应是吸热还是放热，取决于两者的差值：

ΔH = 反应物断键吸收的总能量 − 生成物成键放出的总能量

即 ΔH = E(反应物总键能) − E(生成物总键能)。

为什么：键能是"拆开 1 mol 化学键所需的能量"。断键像拆房子要花力气（吸热），成键像磁铁吸上会释放能量（放热）。拆房子花的力气比盖房子放出的多，整个过程就得从外面"借"能量——吸热反应。

适用边界：此公式与"ΔH = 生成物总能量 − 反应物总能量"方向相反，千万别记串。口诀：键能"反减生"，能量"生减反"。

2.3 热化学方程式

核心概念

是什么：既能表示物质变化、又能表示能量变化的化学方程式。例如：

H2(g) + 1/2O2(g) → H2O(l)　ΔH = −285.8 kJ/mol

书写五条军规（每一条都是判分点）：

  1. 标状态：每种物质后用 (s)(l)(g)(aq) 标明聚集状态。状态不同，ΔH 不同（H2O 是气是液，数值差 44 kJ/mol）；
  2. ΔH 写在方程式右侧，带"+"或"−"号，单位 kJ/mol，与方程式之间留空或用分号隔开；
  3. ΔH 与系数对应：系数加倍，ΔH 数值也加倍；方向反转，ΔH 符号反转、数值不变；
  4. 系数可以是分数：热化学方程式的系数只表示物质的量，不表示分子个数，所以允许出现 1/2；
  5. 不写反应条件：热化学方程式中的 ΔH 一般指 25 ℃、101 kPa 下的数据，通常不写"点燃""加热"等条件，也不用标 ↑↓。

意义：上式表示"1 mol H2(g) 与 0.5 mol O2(g) 完全反应生成 1 mol 液态水时，放出 285.8 kJ 的热量"。

书写示范

对照练习，体会"同一种反应、不同写法、不同 ΔH"：

情形 热化学方程式 说明
1 mol H2 燃烧生成液态水 H2(g) + 1/2O2(g) → H2O(l)　ΔH = −285.8 kJ/mol 系数可取分数，ΔH 对应这组系数
2 mol H2 燃烧生成液态水 2H2(g) + O2(g) → 2H2O(l)　ΔH = −571.6 kJ/mol 系数加倍，ΔH 也加倍
1 mol H2 燃烧生成气态水 H2(g) + 1/2O2(g) → H2O(g)　ΔH = −241.8 kJ/mol 状态不同，ΔH 不同（相差 44 kJ/mol）
水的分解（逆过程） H2O(l) → H2(g) + 1/2O2(g)　ΔH = +285.8 kJ/mol 方向反转，符号反转、数值不变

2.4 盖斯定律

核心概念

是什么：一个化学反应，不管是一步完成还是分几步完成，其反应热是相同的。即反应热只取决于始态和终态，与反应途径无关。

为什么：焓是状态函数。就像爬山，从山脚到山顶的海拔升高是固定的，无论你坐缆车直达还是走盘山公路绕三圈，高度差不变。能量变化同理——只看"起点"和"终点"的能级差。

怎么用（操作三步法）：

  1. 写出目标方程式，观察它里面每种物质在已知方程式中的位置和系数；
  2. 对已知方程式做三种手术：调方向（ΔH 变号）、乘倍数（ΔH 同乘）、相加（ΔH 相加），使得加和后消去多余物质、恰好得到目标方程式；
  3. 按同样的运算处理 ΔH，即得目标 ΔH。

常见混淆：盖斯定律求的是 ΔH，运算时方程式和 ΔH 必须做完全相同的操作。方程式乘 2 而 ΔH 忘乘 2，是本章第一大失误类型。

2.5 燃烧热

核心概念

是什么：在 101 kPa 时，1 mol 纯物质完全燃烧生成稳定的氧化物时所放出的热量，叫做该物质的燃烧热，单位为 kJ/mol，燃烧热是正值（常说"某物质燃烧热为 890.3 kJ/mol"），但写入热化学方程式的 ΔH 要带负号。

概念三要素（逐字把关）：

  1. 1 mol 纯物质：以可燃物为 1 mol 配平方程式，其他物质系数可为分数；
  2. 完全燃烧：C → CO2(g)，不能是 CO；S → SO2(g)，不能是 SO3（SO2 才是硫的稳定燃烧产物）；
  3. 稳定氧化物：H → H2O(l)（液态水才是常温下的稳定形态，不是水蒸气）。

实例：CH4 的燃烧热为 890.3 kJ/mol，对应热化学方程式：

CH4(g) + 2O2(g) → CO2(g) + 2H2O(l)　ΔH = −890.3 kJ/mol

常见混淆：若上式写成 2CH4 + 4O2 → 2CO2 + 4H2O，ΔH = −1780.6 kJ/mol，方程式本身没错，但它表示的不再是"燃烧热"（可燃物不是 1 mol）。

常见物质的燃烧热（101 kPa，了解量级即可）：

物质 H2(g) CO(g) CH4(g) C2H5OH(l)
燃烧热（kJ/mol） 285.8 283.0 890.3 1366.8
对应稳定产物 H2O(l) CO2(g) CO2(g) + H2O(l) CO2(g) + H2O(l)

2.6 中和热及其实验测定

核心概念

是什么：在稀溶液中，强酸与强碱发生中和反应生成 1 mol H2O 时所放出的热量。实验测定值约为 57.3 kJ/mol，对应离子方程式：

H+(aq) + OH−(aq) → H2O(l)　ΔH = −57.3 kJ/mol

概念三要素：

  1. 稀溶液：浓溶液（如浓硫酸）稀释时本身放热，会使测得值偏大；
  2. 强酸强碱：弱酸（如 CH3COOH）、弱碱（如 NH3·H2O）电离时要吸热，使测得的中和热偏小；
  3. 生成 1 mol 水：若生成 2 mol 水，放出的热量是 114.6 kJ，但"中和热"仍指折合到 1 mol 水的 57.3 kJ/mol；另外，若有沉淀生成（如 H2SO4 与 Ba(OH)2），生成沉淀也放热，测得值偏大。
实验专项

中和热的测定实验（环形玻璃搅拌棒是标志仪器）

实验用品：大烧杯、小烧杯、温度计、环形玻璃搅拌棒、量筒、泡沫塑料（或碎纸条）、泡沫塑料盖板。

操作要点：

  1. 大小烧杯之间填满泡沫塑料，小烧杯口与大烧杯口相平，盖板盖严——一切为了保温、减少热量散失；
  2. 量取 50 mL 0.50 mol/L 盐酸倒入小烧杯，测其初始温度 t1；
  3. 另量取 50 mL 0.55 mol/L NaOH 溶液（碱稍过量，保证盐酸被完全中和），测其温度；
  4. 一次快速倒入 NaOH 溶液，立即盖板，用环形玻璃搅拌棒轻轻搅动，读取最高温度 t2；
  5. 重复 2~3 次，取温度差的平均值计算。

计算：Q = c·m·Δt ≈ 4.18 J/(g·℃) × 100 g × (t2 − t1)，再除以生成水的物质的量 0.025 mol，即得中和热。

误差分析（常考）：

  • 倒入动作慢、盖板不严、未搅拌、温度计碰到烧杯壁 → 热量散失 → 测得中和热偏小；
  • 用铜质搅拌棒代替玻璃棒 → 金属导热 → 热量散失 → 偏小；
  • 碱不过量导致酸未完全中和 → 偏小。

注意：测得的实验值一般小于 57.3 kJ/mol，主要就是因为装置不可能完全绝热，热量有散失。

2.7 能源常识

类别 代表 特点
化石能源（不可再生） 煤、石油、天然气 储量有限；燃烧产生 SO2、NOx、粉尘等污染物，是酸雨的主要来源
新能源（可再生/清洁） 氢能、太阳能、风能、地热能、生物质能 氢气热值高、燃烧产物只有水，是理想能源，但制取与储运成本高
能源综合利用 煤的干馏、气化、液化 煤的气化（C + H2O(g) → CO + H2）可提高燃烧效率、减少污染
视野拓展

氢能源——理想但很"挑"的能源：

  • 优点：热值高（约 143 kJ/g，是汽油的 3 倍左右）；燃烧产物只有水，零污染；原料水取之不尽；
  • 难题：① 制取成本高——电解水制氢耗电，目前工业上主要靠水煤气法（C + H2O(g) → CO + H2，吸热反应）；② 储存运输难——氢气密度小、易泄漏、易爆炸，需要高压或液化；③ 基础设施建设投入大；
  • 方向：利用太阳能光解水制氢是研究热点，一旦突破成本瓶颈，氢能将大规模替代化石能源。

答题话术：问"氢能为什么还没普及"——答"制取成本高、储存和运输困难"；问"氢能的优点"——答"热值高、产物无污染、原料丰富"。

情境储备

选择题常结合"碳达峰、碳中和"命题：化石燃料燃烧排放 CO2，发展新能源、植树造林、CO2 资源化利用都是减碳路径。记住"节能即减碳"这条主线即可应对大部分情境判断。

三、三重表征贯通

宏观现象、微观粒子、符号表达三位一体，是化学思维的核心。本章选两个经典反应来练：

3.1 氢气在氯气中燃烧（放热反应）

宏观表征

H2 在 Cl2 中安静地燃烧，发出苍白色火焰，集气瓶口有白雾生成（HCl 气体遇空气中的水蒸气形成盐酸小液滴），用手摸集气瓶外壁感觉发烫——反应放出热量。

微观表征

H—H 键与 Cl—Cl 键先断裂，分别吸收 436 kJ/mol 和 243 kJ/mol 能量；随后 H 原子与 Cl 原子结合成 H—Cl 键，每摩尔放出 431 kJ。断键共吸热 679 kJ，成键共放热 862 kJ，放出的多于吸收的，差额 183 kJ 以热量形式释放，使体系温度升高。

符号表征

H2(g) + Cl2(g) → 2HCl(g)　ΔH = −183 kJ/mol

ΔH < 0，放热反应；ΔH = (436 + 243) − 2×431 = −183 kJ/mol。

3.2 Ba(OH)2·8H2O 与 NH4Cl 的反应（吸热反应）

宏观表征

把两种晶体在烧杯中混合搅拌，能闻到刺激性气味的氨气；用手摸烧杯外壁，感觉冰凉；把烧杯放在滴有水的木片上，过一会儿烧杯底部的水结成了冰，烧杯与木片"冻"在一起。

微观表征

反应中旧键断裂吸收的能量多于新键形成放出的能量，差额只能从周围环境"抽取"热量来弥补，于是体系温度急剧下降。这直观地证明了：生成物的总能量高于反应物的总能量，ΔH > 0。

符号表征

Ba(OH)2·8H2O(s) + 2NH4Cl(s) → BaCl2(s) + 2NH3↑ + 10H2O(l)　ΔH > 0

这是课本上吸热反应的"形象代言人"，看到"烧杯结冰"就要立刻想到它。

3.3 中和反应的热效应

宏观表征

向盐酸中倒入 NaOH 溶液，二者均无色，混合后仍无色、无沉淀、无气泡，看起来"什么都没发生"，但温度计示数明显上升——放热反应也可能没有可见现象，能量变化本身就是现象。

微观表征

盐酸中的 H+ 与 NaOH 溶液中的 OH− 结合生成 H2O 分子，Na+ 和 Cl− 只是"旁观者"（未参与反应）。每生成 1 mol H2O 放出约 57.3 kJ 热量。所有强酸强碱的稀溶液中和，实质都是同一个反应，所以中和热相同。

符号表征

HCl(aq) + NaOH(aq) → NaCl(aq) + H2O(l)　ΔH = −57.3 kJ/mol

离子方程式：H+(aq) + OH−(aq) → H2O(l)　ΔH = −57.3 kJ/mol。

四、典型例题分步拆解

例题 1 · 键能计算 ΔH

题目：已知 H—H 键能为 436 kJ/mol，N≡N 键能为 946 kJ/mol，N—H 键能为 391 kJ/mol。求反应 N2(g) + 3H2(g) → 2NH3(g) 的 ΔH。

【思路点拨】用键能公式 ΔH = 反应物总键能 − 生成物总键能。关键是数清每种物质中有几个什么键：1 个 NH3 分子含 3 个 N—H 键，2 mol NH3 含 6 mol N—H 键。

1

计算反应物断键吸收的能量：1 mol N≡N + 3 mol H—H = 946 + 3×436 = 946 + 1308 = 2254 kJ。

2

计算生成物成键放出的能量：2 mol NH3 含 6 mol N—H 键 = 6×391 = 2346 kJ。

3

ΔH = 2254 − 2346 = −92 kJ/mol。

【答案】ΔH = −92 kJ/mol。ΔH < 0，合成氨是放热反应（这与"升温不利于氨的合成"相呼应，下一章平衡移动还会用到）。

【方法总结】键能计算三步：数键 → 求和 → 反减生。最容易错在"数键"——务必按方程式系数乘以每个分子内的键数（如 2 mol NH3 是 6 mol N—H，不是 2 mol 或 3 mol）。

例题 2 · 盖斯定律计算（高考必考模型）

题目：已知：

① C(s) + O2(g) → CO2(g)　ΔH1 = −393.5 kJ/mol

② CO(g) + 1/2O2(g) → CO2(g)　ΔH2 = −283.0 kJ/mol

求 C(s) + 1/2O2(g) → CO(g) 的 ΔH3。

【思路点拨】这是"碳不完全燃烧"的反应热，实验上很难直接测定（燃烧时总会生成 CO2），必须用盖斯定律间接求得。观察：目标中 C 在左边（与①同向），CO 在右边（与②反向），所以用 ① − ②。

1

对齐物质：目标反应物 C 在①的左侧，系数都是 1，①保持不动；目标生成物 CO 在②的左侧，要让它变到右侧，需将②调转方向，ΔH2 变号为 +283.0 kJ/mol。

2

① + (−②) 相加：左边 C + O2 + CO2，右边 CO2 + CO + ½O2；两边消去 CO2，O2 左边 1 个、右边 ½ 个，净剩左边 ½ 个 O2。恰好得到目标方程式：C(s) + ½O2(g) → CO(g)。

3

ΔH3 = ΔH1 − ΔH2 = (−393.5) − (−283.0) = −393.5 + 283.0 = −110.5 kJ/mol。

【答案】ΔH3 = −110.5 kJ/mol。

【方法总结】盖斯定律口诀："同向相加、异向相减、倍数同乘、消去验证"。做完一定要检查：加和后的方程式是否恰好是目标式？ΔH 是否做了完全相同的运算？本题数值上也有个小窍门：−393.5 − (−283.0)，减去负数要变加，符号处最容易出错。

例题 3 · 热化学方程式正误判断

题目：已知 25 ℃、101 kPa 下，1 g 甲烷（CH4）完全燃烧生成 CO2(g) 和液态水，放出 55.6 kJ 热量。下列热化学方程式书写正确的是（　　）

A. CH4(g) + 2O2(g) → CO2(g) + 2H2O(g)　ΔH = −889.6 kJ/mol

B. CH4 + 2O2 → CO2 + 2H2O　ΔH = −889.6 kJ/mol

C. CH4(g) + 2O2(g) → CO2(g) + 2H2O(l)　ΔH = +889.6 kJ/mol

D. CH4(g) + 2O2(g) → CO2(g) + 2H2O(l)　ΔH = −889.6 kJ/mol

【思路点拨】先算出每摩尔甲烷的放热量：1 g 放 55.6 kJ，CH4 摩尔质量 16 g/mol，则 1 mol 放热 55.6×16 = 889.6 kJ。再逐条对照五条军规排查选项。

1

算数值：55.6 kJ/g × 16 g/mol = 889.6 kJ/mol，数值四个选项都一样，无法据此排除。

2

查状态：题目明确说"液态水"，A 中 H2O 标成 (g)，错误。

3

查状态标注：B 中所有物质都未标状态，且热化学方程式不写"点燃"条件，错误。

4

查符号：燃烧放热，ΔH 必须为负，C 写成 +889.6 kJ/mol，错误。

5

D 各项均规范：状态齐全、水为液态、ΔH 为负、数值对应 1 mol CH4。

【答案】D

【方法总结】热化学方程式正误判断"四查"：查状态、查符号、查数值与系数对应、查有无多余的条件和↑↓。养成固定排查顺序，这类题就是送分题。

例题 4 · 燃烧热概念与计算综合

题目：下列关于燃烧热的说法正确的是（　　）

A. 已知 H2(g) + ½O2(g) → H2O(g)　ΔH = −241.8 kJ/mol，则 H2 的燃烧热为 241.8 kJ/mol

B. 1 mol H2 与 2 mol H2 完全燃烧生成液态水，放出的热量不同，所以燃烧热不同

C. 已知 C(s) 的燃烧热为 393.5 kJ/mol，则 12 g C 完全燃烧生成 CO2 放出 393.5 kJ 热量

D. 硫的燃烧热对应的热化学方程式中，S 的燃烧产物是 SO3

【思路点拨】逐项对照燃烧热三要素：1 mol 纯物质、完全燃烧、稳定氧化物（H→液态水，C→CO2，S→SO2）。

1

A 错：生成的是水蒸气 H2O(g)，不是稳定形态液态水，241.8 kJ/mol 不是燃烧热（燃烧热应对应生成液态水，为 285.8 kJ/mol）。

2

B 错：燃烧热是"折合到 1 mol 可燃物"的强度量，与实际用量无关。2 mol H2 放热加倍，但燃烧热数值不变。

3

C 对：12 g C 恰好是 1 mol，完全燃烧生成 CO2，放热 393.5 kJ，与燃烧热定义一致。

4

D 错：硫燃烧的稳定产物是 SO2，不是 SO3（SO2 在高温和催化剂下才能进一步氧化，且该反应不完全）。

【答案】C

【方法总结】燃烧热判题就盯三个词："1 mol""完全""稳定"。尤其记住三个稳定产物：H→H2O(l)、C→CO2(g)、S→SO2(g)，出题人最爱在"水蒸气和液态水"上设坑。

例题 5 · 盖斯定律进阶（三个方程式）

题目：已知 25 ℃、101 kPa 下：

① C(s) + O2(g) → CO2(g)　ΔH1 = −393.5 kJ/mol

② H2(g) + 1/2O2(g) → H2O(l)　ΔH2 = −285.8 kJ/mol

③ CH3COOH(l) + 2O2(g) → 2CO2(g) + 2H2O(l)　ΔH3 = −870.3 kJ/mol

求反应 2C(s) + 2H2(g) + O2(g) → CH3COOH(l) 的 ΔH4。

【思路点拨】这是"由单质生成乙酸"的反应，无法直接测定，必须用盖斯定律。对齐物质：目标需要左边 2 个 C（①×2）、左边 2 个 H2（②×2）、右边 1 个 CH3COOH（③调转方向）。

1

①×2：2C(s) + 2O2(g) → 2CO2(g)，ΔH = 2×(−393.5) = −787.0 kJ/mol。

2

②×2：2H2(g) + O2(g) → 2H2O(l)，ΔH = 2×(−285.8) = −571.6 kJ/mol。

3

③调向：2CO2(g) + 2H2O(l) → CH3COOH(l) + 2O2(g)，ΔH = +870.3 kJ/mol。

4

三式相加，消去两边的 2CO2、2H2O，左边共 3 个 O2、右边 2 个 O2，净剩左边 1 个 O2，恰好得到目标方程式。

5

ΔH4 = (−787.0) + (−571.6) + 870.3 = −488.3 kJ/mol。

【答案】ΔH4 = −488.3 kJ/mol。

【方法总结】三式联立的窍门是"抓特殊物质"：先找只在某一个已知式中出现的物质（本题 C 只在①中、H2 只在②中、CH3COOH 只在③中），它们立刻确定各方程式的倍数和方向，剩下的大众物质（O2、CO2、H2O）加和后自然消去。最后一步用"消去验证"兜底。

例题 6 · 中和热测定实验计算

题目：在中和热测定实验中，量取 50 mL 0.50 mol/L 盐酸与 50 mL 0.55 mol/L NaOH 溶液，混合前两溶液温度均为 20.0 ℃，混合后测得最高温度为 23.4 ℃。已知混合溶液密度约为 1.0 g/mL，比热容为 4.18 J/(g·℃)。计算本实验测得的中和热，并分析其与理论值 57.3 kJ/mol 的差异原因。

【思路点拨】先算放出的热量 Q = c·m·Δt，再除以生成水的物质的量。注意酸的量决定水的量（碱过量），以及单位从 J 换算到 kJ。

1

溶液总质量 m = (50 + 50) mL × 1.0 g/mL = 100 g；温度变化 Δt = 23.4 − 20.0 = 3.4 ℃。

2

放出的热量 Q = 4.18 J/(g·℃) × 100 g × 3.4 ℃ = 1421.2 J ≈ 1.42 kJ。

3

生成水的物质的量由不足量的盐酸决定：n(H2O) = n(HCl) = 0.50 mol/L × 0.050 L = 0.025 mol（NaOH 为 0.0275 mol，过量）。

4

中和热 = Q ÷ n(H2O) = 1.42 kJ ÷ 0.025 mol ≈ 56.8 kJ/mol。

【答案】测得中和热约为 56.8 kJ/mol。该值小于理论值 57.3 kJ/mol，主要原因是装置保温不够严密，部分热量散失到环境中，使测得的 Δt 偏小。

【方法总结】中和热计算三量：Q（热量）、n（水的物质的量）、比值（中和热）。三个坑：① 体积相加后别忘乘密度得质量；② 水的物质的量按"不足量"一方算；③ J 要换算成 kJ。误差方向一律向"Δt 偏小 → 测得值偏小"靠拢。

例题 7 · 由 ΔH 反求键能（键能公式逆用）

题目：已知 H2(g) + Cl2(g) → 2HCl(g)　ΔH = −183 kJ/mol，H—H 键能为 436 kJ/mol，Cl—Cl 键能为 243 kJ/mol。求 H—Cl 键的键能。

【思路点拨】键能公式不仅能"由键能算 ΔH"，也能"由 ΔH 反算键能"。设未知数列方程即可，注意 2 mol HCl 含 2 mol H—Cl 键。

1

设 H—Cl 键能为 x kJ/mol。断键吸热：436 + 243 = 679 kJ。

2

成键放热：2x kJ（生成 2 mol HCl）。

3

列方程：ΔH = 679 − 2x = −183。

4

解得 2x = 862，x = 431 kJ/mol。

【答案】H—Cl 键能为 431 kJ/mol。

【方法总结】反求键能就是解一元一次方程，关键仍是"数对键数"。求得的结果可以和例题 1 相互印证——同一组键能，正算反算要能对上，这也是检查自己是否掌握的好方法。

五、易错点与成因分析

易错点 1

易错表现：ΔH 的正负号记反，认为"放热为正"或者答题时漏写负号。

错误成因：直觉上觉得"放出"就该是"多"（正），没有从"体系自身能量变化"的角度理解符号规定。

正确理解：ΔH 描述的是体系（反应本身）的能量变化。放热反应中体系把能量给了环境，自己能量变少，所以 ΔH < 0；吸热反应体系从环境拿了能量，ΔH > 0。

避坑口诀："放负吸正"——放热 ΔH 为负，吸热 ΔH 为正。

易错点 2

易错表现：热化学方程式漏标状态，或者把 H2O 的状态随手写成 (g)。

错误成因：觉得状态符号是"可有可无的修饰"，不知道状态改变会直接改变 ΔH 的数值。

正确理解：H2O(l) → H2O(g) 本身要吸收 44 kJ/mol，所以同一个燃烧反应，生成液态水比生成水蒸气多放 44 kJ（每摩尔水）。状态不同，ΔH 就是不同的数。状态符号是热化学方程式的"身份证信息"，漏标即错误。

避坑口诀："热方程式，状态先行"——写完先检查每个物质后面有没有 (s)(l)(g)(aq)。

易错点 3

易错表现：盖斯定律运算时，方程式乘了 2 但 ΔH 忘乘 2；或者方程式调了方向但 ΔH 忘变号。

错误成因：把方程式的变形和 ΔH 的变形当成两件独立的事，没有建立"两者绑定"的意识。

正确理解：ΔH 是与方程式系数严格对应的。2 mol 物质反应放出的热量当然是 1 mol 的两倍；反应倒过来走，吸放热自然反转。对方程式做任何操作（调向、乘倍、相加），ΔH 必须同步做同样的操作。

避坑口诀："式变 H 变，如影随形"。

易错点 4

易错表现：键能计算 ΔH 时用"生成物键能 − 反应物键能"，得到符号相反的结果。

错误成因：与能量公式 ΔH = 生成物总能量 − 反应物总能量 记混了。

正确理解：键能是"拆键要花的代价"，反应中先花（断反应物的键）后赚（成生成物的键），ΔH = 花的 − 赚的 = 反应物键能 − 生成物键能。而"总能量"是物质自身携带的能量，ΔH = 终点 − 起点 = 生成物 − 反应物。两个公式方向相反。

避坑口诀："键能反减生，能量生减反"。

易错点 5

易错表现：认为"需要加热才能发生的反应就是吸热反应"，如认为燃烧是吸热反应。

错误成因：把"反应条件"（引发反应所需的能量输入）误当成"反应热"（整个反应的净能量变化）。

正确理解：加热只是帮反应物越过"活化能山头"。燃烧需要点燃，但反应一旦开始，放出的热量远大于点燃输入的少量能量，净效果是放热。反之，Ba(OH)2·8H2O 与 NH4Cl 常温就能反应，却是典型的吸热反应。

避坑口诀："条件不等于热效应，看 ΔH 正负才算数"。

易错点 6

易错表现：认为"任何酸碱中和的中和热都是 57.3 kJ/mol"，比如认为醋酸与 NaOH 的中和热也是 57.3 kJ/mol。

错误成因：忽略了中和热概念中"强酸、强碱、稀溶液"三个限定词。

正确理解：弱酸（CH3COOH）或弱碱（NH3·H2O）在中和过程中还要不断电离，而电离是吸热的，会抵消一部分中和放热，使测得中和热小于 57.3 kJ/mol；浓硫酸稀释放热，使其"表观中和热"大于 57.3 kJ/mol；H2SO4 与 Ba(OH)2 因生成 BaSO4 沉淀额外放热，也大于 57.3 kJ/mol。

避坑口诀："稀强强，一摩尔水，五十七点三"——限定条件缺一不可。

易错点 7

易错表现：比较两个反应"谁放热多"时，直接比较 ΔH 数值大小，认为 ΔH = −500 kJ/mol 的反应比 ΔH = −300 kJ/mol 的反应"热效应弱"，或者根本不看物质的量。

错误成因：混淆了"ΔH（每摩尔反应进度的热量变化）"与"实际放出热量的总量"两个层次；同时忽略了 ΔH 是带符号的数，比大小要小心负号。

正确理解：① 比较 ΔH 大小要带着符号比：−500 < −300，但前者放热更多；② 比较实际放出热量要用 Q = n × |ΔH|（n 为按方程式计算的反应进度）。例如 2 mol H2 按 ΔH = −285.8 kJ/mol 的方程式反应，放热 571.6 kJ。

避坑口诀："比 ΔH 带符号，比热量乘摩尔"。

六、与前后章节的联系

  • 承接氧化还原：燃烧、铝热反应等放热反应大多是氧化还原反应，本章给它们加上了"能量标签"。
  • 铺垫化学平衡（3.13）：ΔH 的正负直接决定温度对平衡的影响方向——放热反应升温平衡逆向移动，这是下一章勒夏特列原理的核心应用。
  • 铺垫电化学（3.15）：原电池就是把放热反应释放的化学能直接转化为电能的装置，燃料电池、中和热都与能量转化效率相关。
  • 贯穿工业流程：工业反应条件的选择（如合成氨为什么要用高温）需要同时考虑速率与能量，是反应原理大题的常客。

七、章末自检清单

合上书本，逐条自测。能做到就打勾，做不到的立刻回读对应小节：

  • 我能说出 ΔH 的含义、单位，并牢记"放热 ΔH<0、吸热 ΔH>0"。
  • 我能从能量图（反应物与生成物的相对高度）判断反应的吸放热。
  • 我能各举出至少三个放热反应和吸热反应的实例，并知道"需要加热 ≠ 吸热反应"。
  • 我能用键能计算 ΔH（ΔH = 反应物总键能 − 生成物总键能），并数清每个分子中的键数。
  • 我能规范书写热化学方程式，自觉做到"标状态、带正负、写单位、系数与 ΔH 对应、不写条件"。
  • 我能解释为什么热化学方程式的系数可以是分数。
  • 我能用盖斯定律由已知热化学方程式求目标反应的 ΔH，运算后主动验证方程式是否消去正确。
  • 我能准确说出燃烧热的三个要点，并写出 H→H2O(l)、C→CO2(g)、S→SO2(g) 三个稳定产物。
  • 我能说出中和热的三个限定条件，并解释弱酸弱碱、浓硫酸、生成沉淀时测定值为何偏离 57.3 kJ/mol。
  • 我能复述中和热测定实验的主要仪器（含环形玻璃搅拌棒）、操作要点和常见误差方向。
  • 我能区分化石能源与新能源，知道氢能的优点和煤的综合利用方式。
  • 我能区分"ΔH 数值大小"与"实际放出热量多少"，会用 Q = n×|ΔH| 比较不同反应的热量。

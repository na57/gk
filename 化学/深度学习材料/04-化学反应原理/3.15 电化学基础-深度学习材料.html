3.15 电化学基础

高中化学 · 深度学习材料 · 面向 2029 届云南高考

电化学研究的是"化学反应"与"电"的相互转化：原电池把化学能变成电能，电解池用电能驱动化学反应。 本章的题在高考里几乎年年必考（选择题 1 道 + 原理大题中 2~4 分），套路非常固定——先分原电池还是电解池，再判断电极，然后写电极反应式，最后用电子守恒计算。把这条流水线练熟，电化学就是送分题。

高考怎么考

电化学的考法高度模板化：① 选择题给一个陌生装置或新型电池（如锂电池、微生物燃料电池），考电极判断、电极反应式正误、离子迁移方向、pH 变化；② 反应原理大题中嵌入电解计算（用电子守恒求产物量）或与 Ksp、平衡常数结合的综合小问。无论题目背景多"新"，落点永远是那几句口诀：负氧正还、阳氧阴还、电子守恒。

学法建议
  • 先背熟两张表：原电池/电解池对比表、阴阳极放电顺序表——这是全章的"地基"，每天早上默写一遍，一周就刻进脑子里；
  • 电极反应式专项：按"定产物 → 配电荷（看介质）→ 配水 → 验电子"四步流程，把氢氧燃料电池（酸/碱）、铅蓄电池、氯碱工业等 8 个经典电极反应各写 3 遍；
  • 计算只认一个理：串联电路中各电极通过的电子数相等。所有电解计算都从"n(e−) 相等"列等式。

此外建议准备一个"电化学错题本"：把每次做错的电极反应式按"错因"分类（电极判错 / 介质用错 / 电荷没配平 / 产物写错），考前只复习错因最多的那一类。电化学的失分高度集中在少数几个固定陷阱上，消灭一个陷阱就等于拿稳一类题的分数。

本章与下一阶段的工业流程题联系紧密——氯碱工业、电解精炼、湿法冶金都是流程题的经典素材，学习时多问自己"这个步骤对应哪个电极反应"，就能把两部分的分数一起拿下。

最后提醒：电化学是高考中"性价比"极高的章节——知识点总量不大、题型高度固定、套路清晰可见，投入产出比远超有机推断等"大开大合"的章节，务必做到零失误。

二、核心概念精讲

2.1 原电池的工作原理

核心概念

是什么：把自发的氧化还原反应拆成"两个半反应"，让电子通过外电路从负极流向正极，从而把化学能转化为电能的装置。以最经典的铜锌原电池（稀硫酸为电解液）为例：

负极（Zn）：Zn − 2e− → Zn2+（氧化反应，锌片溶解）

正极（Cu）：2H+ + 2e− → H2↑（还原反应，铜片冒气泡）

总反应：Zn + 2H+ → Zn2+ + H2↑

为什么（微观解释）：Zn 比 Cu 活泼，失电子能力强。锌片上的 Zn 原子把电子"交给"外电路，自己变成 Zn2+ 进入溶液；电子流到铜片表面，溶液中的 H+ 在铜片表面得电子变成 H2。把氧化反应和还原反应"隔离"在两地进行，电子被迫走外电路——这就是电流的来源。

判断口诀：负氧正还——负极发生氧化反应（失电子、化合价升高、电极溶解），正极发生还原反应（得电子、化合价降低、有气体或金属析出）。

构成条件：① 两种活泼性不同的电极（金属-金属或金属-石墨）；② 电解质溶液（或熔融电解质）；③ 闭合回路（含盐桥）；④ 能自发进行的氧化还原反应。

三个"流向"必须分清：

  • 电子：外电路中由负极 → 正极（电子不下水、离子不上岸——电子绝不进入溶液）；
  • 电流：外电路中由正极 → 负极（与电子流向相反）；
  • 离子：内电路（溶液）中阳离子移向正极、阴离子移向负极（"正正负负"——阳离子去正极、阴离子去负极）。

常见混淆：负极是"电子流出极"，不是"带负电的极"；判断正负极看谁失电子（一般更活泼的金属作负极），而不是看谁"更贵"或谁"更大"。

原电池原理的四大应用（选择题常客）：

  1. 加快反应速率：纯锌与稀硫酸反应较慢，滴入几滴 CuSO4 溶液后锌置换出铜附着在锌表面，形成无数微小原电池，产生 H2 的速率明显加快（但锌消耗加快，且若 CuSO4 过多会覆盖锌表面反而减慢）；
  2. 比较金属活泼性：两金属构成原电池时，一般作负极（溶解、变细）的更活泼；
  3. 设计化学电源：理论上任何自发的氧化还原反应都能设计成原电池——拆成两个半反应，分别找负极材料与电解质；
  4. 金属防护：牺牲阳极法就是利用原电池原理（详见 2.6）。

深入一步：双液原电池与盐桥

拓展理解

把铜锌原电池"拆开"：锌片插入 ZnSO4 溶液，铜片插入 CuSO4 溶液，两烧杯用盐桥（浸有 KCl 饱和溶液的琼脂）连通，外电路用导线连接——这就是效率更高的双液原电池（丹尼尔电池）。

负极（Zn）：Zn − 2e− → Zn2+　　正极（Cu）：Cu2+ + 2e− → Cu

盐桥的三个作用：

  1. 形成闭合回路（沟通内电路），没有盐桥电路立即断开；
  2. 平衡电荷：负极区 Zn2+ 增多带正电趋势，盐桥中 Cl− 迁入；正极区 Cu2+ 减少带负电趋势，K+ 迁入；
  3. 避免 Zn 与 CuSO4 直接接触发生置换反应而"短路"，使电流更持久稳定。

注意：盐桥中的离子只起导电作用，不参与电极反应；盐桥不能用导线代替（电子不能在溶液中移动）。高考常给"盐桥中 Cl− 向哪个烧杯迁移"这类小题，记住：阴离子向负极区，阳离子向正极区。

2.2 电极反应式的书写方法

核心概念

四步书写法（高考要求"快、准、全"）：

  1. 定产物：根据总反应和电极性质，确定该电极的反应物和产物；
  2. 配电子：根据化合价升降写出得失电子数（负极/阳极失电子，写"− ne−"；正极/阴极得电子，写"+ ne−"）；
  3. 配电荷：根据介质酸碱性，用 H+（酸性）或 OH−（碱性）配平两边电荷——酸性介质中绝不能出现 OH−，碱性介质中绝不能出现 H+；
  4. 配原子：用 H2O 配平 H、O 原子，最后检查"电子守恒、电荷守恒、原子守恒"三守恒。

验证：正、负极反应式相加，消去电子后必须等于总反应式——这是考场上最有效的自查。

2.3 化学电源

核心概念

① 普通锌锰干电池（一次电池，电解质为糊状 NH4Cl 等）：锌筒作负极，石墨棒作正极。

负极：Zn − 2e− → Zn2+　　正极：2MnO2 + 2NH4+ + 2e− → Mn2O3 + 2NH3 + H2O

② 铅蓄电池（二次电池/可充电电池，电解质为稀硫酸）：

总反应：Pb + PbO2 + 2H2SO4 ⇌ 2PbSO4 + 2H2O（充电时逆向进行）

放电时　负极：Pb − 2e− + SO42− → PbSO4　　正极：PbO2 + 2e− + 4H+ + SO42− → PbSO4 + 2H2O

放电时硫酸被消耗，溶液密度减小——可通过测密度判断"电量"。充电时，原来的负极接外电源负极作阴极、原来的正极接外电源正极作阳极，电极反应全部逆转。

③ 氢氧燃料电池（介质不同，电极反应不同——高考最爱考）：

介质负极（通 H2）正极（通 O2）
酸性（如 H2SO4）H2 − 2e− → 2H+O2 + 4e− + 4H+ → 2H2O
碱性（如 KOH）H2 − 2e− + 2OH− → 2H2OO2 + 4e− + 2H2O → 4OH−

两种介质中总反应相同：2H2 + O2 = 2H2O。燃料电池的燃料从负极通入、氧化剂从正极通入，电极本身不参与反应（用惰性电极），能量转化率高、产物无污染。

补充：另外两种常考电源

拓展理解

① 碱性锌锰电池（生活中最常用的干电池，KOH 为电解质）：

负极：Zn + 2OH− − 2e− → Zn(OH)2

正极：2MnO2 + 2H2O + 2e− → 2MnOOH + 2OH−

总反应：Zn + 2MnO2 + 2H2O → Zn(OH)2 + 2MnOOH

注意负极写法——碱性介质中 Zn2+ 不能独立存在，必须写成 Zn(OH)2 并用 OH− 配电荷。

② 锂离子电池（可充电，负极为嵌锂石墨 LixC，正极为 Li1−xCoO2）：

放电　负极：LixC − xe− → xLi+ + C　　正极：Li1−xCoO2 + xLi+ + xe− → LiCoO2

锂是最轻的金属，比能量高；放电时 Li+ 从负极经电解质移向正极嵌入正极材料，充电时反向移动——俗称"摇椅式电池"。高考遇到陌生电池不要怕：先找谁失电子（负极），再按介质配电荷即可。

可充电电池的"放电—充电"对应关系

归纳总结

以铅蓄电池为例，可充电电池的两态切换是高考常客，记住"一一对应、方向相反"：

放电（原电池）充电（电解池）
负极：Pb − 2e− + SO42− → PbSO4（氧化）阴极：PbSO4 + 2e− → Pb + SO42−（还原）
正极：PbO2 + 2e− + 4H+ + SO42− → PbSO4 + 2H2O（还原）阳极：PbSO4 + 2H2O − 2e− → PbO2 + 4H+ + SO42−（氧化）

接线规则：充电时，原电池的负极接外电源负极（作阴极被还原）、正极接外电源正极（作阳极被氧化）——"负接负、正接正"。充电反应就是放电反应的完全倒写，充电总反应为放电总反应的逆反应。

现象判断：铅蓄电池放电时两极表面都覆盖 PbSO4（两极均"增重"）、硫酸浓度减小（密度下降）；充电过程恰好相反。

2.4 电解池原理与放电顺序

核心概念

是什么：在外接直流电源的驱动下，强迫电流通过电解质溶液（或熔融电解质），在两极分别发生氧化、还原反应的装置。判断口诀：阳氧阴还——阳极（接电源正极）发生氧化反应，阴极（接电源负极）发生还原反应。

与原电池对比记忆：

原电池电解池
能量转化化学能 → 电能电能 → 化学能
有无外接电源无（本身就是电源）有直流电源
电极名称负极（氧化）、正极（还原）阳极（氧化，接电源正极）、阴极（还原，接电源负极）
电子流向负极 → 外电路 → 正极电源负极 → 阴极；阳极 → 电源正极
离子迁移阳离子向正极，阴离子向负极阳离子向阴极，阴离子向阳极

放电顺序（必须熟背）：

  • 阳极：先看电极材料！若为活性电极（除 Pt、Au 以外的金属，如 Cu、Fe、Ag），则电极本身失电子溶解；若为惰性电极（Pt、石墨），溶液中阴离子放电：S2− > I− > Br− > Cl− > OH− > 含氧酸根（SO42−、NO3− 等不放电）；
  • 阴极（电极本身总是不放电，只看阳离子）：Ag+ > Fe3+ > Cu2+ > H+(酸) > Pb2+ > Fe2+ > Zn2+ > H+(水) > Al3+、Mg2+、Na+、Ca2+、K+（这些在水溶液中不放电，水放电产生 H2）。

典型电解类型（惰性电极）：

电解液阴极产物阳极产物电解实质
CuCl2 溶液CuCl2电解质本身被电解
NaCl 溶液H2（水放电）Cl2电解质 + 水，生成 NaOH
CuSO4 溶液CuO2（水放电）电解质 + 水，生成 H2SO4，pH 减小
Na2SO4 溶液 / 稀 H2SO4 / NaOH 溶液H2O2实质都是电解水（2H2O → 2H2↑ + O2↑）

电解规律四类型（含 pH 变化与"复原"方法）

归纳总结
类型典型电解液被电解的物质pH 变化恢复原状应加入
电解水型NaOH、H2SO4、Na2SO4水碱溶液 pH↑；酸溶液 pH↓；强酸强碱盐溶液不变加水
电解电解质型HCl、CuCl2电解质本身HCl：pH↑通入 HCl 气体 / 加 CuCl2
放 H2 生碱型NaCl、KBr电解质 + 水pH↑通入 HCl 气体（不是加盐酸溶液——会多加水）
放 O2 生酸型CuSO4、AgNO3电解质 + 水pH↓加 CuO 或 CuCO3（不是 Cu(OH)2——会多加水）

"复原"原则：电解中从溶液里"跑出来"什么（气体逸出、固体析出），就按原子比例补回什么。放 H2 生碱型跑掉的是"H 和 Cl"（H2↑ + Cl2↑），所以通 HCl 气体；放 O2 生酸型析出 Cu、逸出 O2，相当于从溶液中拿走"CuO"，所以加 CuO。

串联电路与多池混合装置的判断

归纳总结
  • 多个池子串联：只要有一个外接直流电源，所有池子都是电解池；没有电源时，最活泼金属所在的那个池子是原电池（充当"电源"），其余池子都变成电解池；
  • 计算只认一条：串联电路中流过每个电极的电子数相等。例如左池电解 CuSO4 析出 0.1 mol Cu（转移 0.2 mol e−），则右池电解 AgNO3 必析出 0.2 mol Ag（Ag+ + e− → Ag，1 mol Ag 只对应 1 mol e−）；
  • 电极名称要分开叫：原电池叫正负极、电解池叫阴阳极；串联时原电池的正极连接的是电解池的阳极（都发生氧化/还原方向相反——注意：相连的两极一个是"还原则"一个是"氧化极"，电子从原电池负极流向电解池阴极）。

2.5 电解原理的应用

核心概念

① 氯碱工业（电解饱和食盐水，惰性电极，离子交换膜隔开两极）：

阳极：2Cl− − 2e− → Cl2↑　　阴极：2H2O + 2e− → H2↑ + 2OH−

总反应：2NaCl + 2H2O → 2NaOH + H2↑ + Cl2↑

阳离子交换膜只让 Na+ 通过到阴极区，防止 Cl2 与 NaOH 接触反应（Cl2 + 2NaOH → NaCl + NaClO + H2O），也防止 H2 与 Cl2 混合爆炸。

② 电镀：待镀件作阴极，镀层金属作阳极，电镀液含镀层金属阳离子。如铁件镀铜：阴极（铁件）Cu2+ + 2e− → Cu；阳极（铜片）Cu − 2e− → Cu2+。电镀液浓度基本不变。

③ 电解精炼铜：粗铜作阳极（Cu 及比 Cu 活泼的 Zn、Fe、Ni 都失电子溶解；比 Cu 不活泼的 Ag、Au 沉在阳极下方形成"阳极泥"），纯铜作阴极（Cu2+ + 2e− → Cu），CuSO4 溶液作电解液。由于 Zn2+、Fe2+ 不断在溶液中积累而 Cu2+ 不断消耗，电解液中 c(Cu2+) 会逐渐减小，需定期净化。

④ 电冶金：活泼金属 K、Ca、Na、Mg、Al 用电解法制取——电解熔融 NaCl 制 Na（2NaCl(熔融) → 2Na + Cl2↑）；电解熔融 Al2O3（加冰晶石 Na3AlF6 降低熔点）制 Al：2Al2O3(熔融) → 4Al + 3O2↑。注意电解熔融 MgCl2 制 Mg，而不是 MgO（熔点太高）。

电镀与电解精炼铜对比（两者极易混淆）：

电镀（铁件镀铜）电解精炼铜
目的在制品表面镀一层铜提纯粗铜得到纯铜
阳极纯铜（镀层金属）粗铜（含 Zn、Fe、Ag、Au 等杂质）
阴极待镀铁件纯铜
电解液CuSO4 溶液（含镀层金属离子）CuSO4 溶液（需定期净化）
c(Cu2+)基本不变逐渐减小（杂质离子进入溶液）
特殊点镀层均匀致密阳极泥中可回收 Ag、Au

共同点：阳极都是铜失电子溶解、阴极都是 Cu2+ 得电子析出，本质上都是"铜的定向搬运"。

2.6 金属的腐蚀与防护

核心概念

腐蚀的两大类：

  • 化学腐蚀：金属直接与干燥气体（O2、Cl2 等）或非电解质反应，无电流产生；
  • 电化学腐蚀：不纯金属与电解质溶液接触形成无数微小原电池，活泼金属作负极被氧化，有微弱电流——是金属腐蚀的主要形式。

钢铁的两种电化学腐蚀（Fe 作负极、C 作正极）：

析氢腐蚀吸氧腐蚀（更普遍）
条件水膜酸性较强（pH < 4.3）水膜呈中性或弱酸性
负极（Fe）Fe − 2e− → Fe2+（两种腐蚀相同）
正极（C）2H+ + 2e− → H2↑O2 + 2H2O + 4e− → 4OH−

吸氧腐蚀后续：Fe2+ + 2OH− → Fe(OH)2，再被氧化：4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3，Fe(OH)3 失水形成铁锈（Fe2O3·xH2O）。

防护方法：

  • 覆盖保护层：刷漆、涂油、镀其他金属、烤蓝；
  • 牺牲阳极（阴极保护）法：在被保护的钢铁设备上连接更活泼的金属（Zn、Mg），活泼金属作负极被腐蚀，钢铁作正极受保护——如船体外挂锌块、地下钢管连镁块。本质是原电池原理；
  • 外加电流阴极保护法：把被保护金属接直流电源的负极作阴极，辅助电极接正极——如保护水闸门、埋地管道。本质是电解池原理；
  • 改变金属内部结构：制成不锈钢等合金。

一句话区分：牺牲阳极 = 找个"替死鬼"（原电池）；外加电流 = 接电源负极强行"按住"电子（电解池）。

金属腐蚀速率的一般规律（由快到慢）：电解池的阳极 > 原电池的负极 > 化学腐蚀 > 有防护措施的腐蚀；原电池正极、电解池阴极上的金属几乎不受腐蚀。因此：① 同一金属在电解质溶液中比在干燥空气中腐蚀快；② 与更活泼金属相连时被保护，与更不活泼金属相连时加速腐蚀（如铁船体上嵌铜钉处锈蚀最严重）；③ 电解质浓度越大腐蚀越快（海水中的钢铁比淡水中锈蚀快）。

2.7 本章核心结论速查

考前必背
  • 两句口诀：原电池"负氧正还"（负极失电子被氧化），电解池"阳氧阴还"（阳极失电子被氧化）；
  • 三流向：电子走外电路（原电池负→正）、电流相反、溶液中阳离子向正极/阴极迁移；
  • 放电顺序：阳极看材料（活性电极自身溶解；惰性电极 S2− > I− > Br− > Cl− > OH− > 含氧酸根），阴极看离子（Ag+ > Fe3+ > Cu2+ > H+ > …活泼金属离子在水溶液中不放电）；
  • 介质规则：酸性用 H+ 配电荷、碱性用 OH− 配电荷，产物必须能在介质中稳定存在；
  • 计算铁律：串联电路各电极转移电子数相等，一切电化学计算从 n(e−) 出发；
  • 电解四应用：氯碱（2NaCl + 2H2O → 2NaOH + H2↑ + Cl2↑）、电镀（镀件作阴极）、精炼（粗铜作阳极，Ag/Au 成阳极泥）、电冶金（熔融 NaCl 制 Na、熔融 Al2O3 制 Al）；
  • 腐蚀防护：钢铁在潮湿中性环境中主要发生吸氧腐蚀（正极 O2 + 2H2O + 4e− → 4OH−）；牺牲阳极用原电池原理，外加电流接电源负极用电解池原理；
  • 复原原则：电解后出什么补什么——放氢生碱通 HCl、放氧生酸加 CuO/CuCO3、电解水加水。
  • 速查提醒：选择题中"电流方向""离子迁移方向""电极质量变化""pH 变化"四类判断，答案全部能从两极反应式直接读出，先写式子再判断是最稳的路径；充电电池牢记"放电看正负、充电看阴阳、负接负、正接正、反应倒着写"。

三、三重表征贯通

第 1 组：铜锌原电池

宏观表征

锌片和铜片平行插入稀硫酸并用导线连接（接电流计）：指针偏转，锌片逐渐溶解变薄，铜片表面不断冒出无色气泡，烧杯中溶液温度略有上升。若只插锌片不连铜片，锌片表面也冒气泡但无电流——对比可知电流来自两个电极的"分工"。

微观表征

Zn 原子在锌片表面失电子变成 Zn2+ 进入溶液（氧化半反应）；电子沿导线涌向铜片；溶液中的 H+ 迁移到铜片表面夺取电子生成 H2 分子（还原半反应）。溶液中阳离子（H+、Zn2+）向铜片（正极）迁移，SO42− 向锌片（负极）迁移，形成闭合的"离子流"。

符号表征

负极（Zn）：Zn − 2e− → Zn2+

正极（Cu）：2H+ + 2e− → H2↑

总反应：Zn + H2SO4 → ZnSO4 + H2↑

装置记法：负氧正还；电子 Zn → 外电路 → Cu

第 2 组：电解饱和食盐水（氯碱工业）

宏观表征

U 形管中装饱和食盐水，两端插入石墨电极接通直流电源：两极都有气泡产生；阳极附近湿润的淀粉 KI 试纸变蓝（Cl2 氧化 I− 生成 I2）；阴极附近滴加酚酞变红（生成 OH−），收集到的气体点燃有爆鸣声（H2）。

微观表征

阳极（接电源正极）：Cl− 比 OH− 优先失电子，两个 Cl− 变成 Cl2 分子逸出；阴极（接电源负极）：Na+ 不放电，由 H2O 提供的 H+ 得电子变成 H2，留下 OH−；Na+ 穿过阳离子交换膜向阴极迁移，与 OH− 形成 NaOH。水被不断"拆分"，食盐水的咸味逐渐消失。

符号表征

阳极：2Cl− − 2e− → Cl2↑

阴极：2H2O + 2e− → H2↑ + 2OH−

总反应：2NaCl + 2H2O → 2NaOH + H2↑ + Cl2↑

第 3 组：钢铁的吸氧腐蚀

宏观表征

潮湿空气中的铁钉几天后表面出现红棕色铁锈，且水膜覆盖处比干燥处锈蚀更快；食盐水中比纯水中锈蚀更快。铁锈疏松多孔，不能阻止内部继续锈蚀——所以铁器防锈必须隔绝水和氧气。

微观表征

铁中含有的碳粒与铁构成无数微小原电池：Fe 作负极失电子变成 Fe2+ 进入水膜；O2 在碳粒（正极）表面得电子与水生成 OH−；Fe2+ 与 OH− 结合成 Fe(OH)2，再被 O2 氧化为 Fe(OH)3，失水后成为 Fe2O3·xH2O（铁锈）。NaCl 溶液导电性更强，加速了电子与离子的传递，故锈蚀更快。

符号表征

负极：Fe − 2e− → Fe2+

正极：O2 + 2H2O + 4e− → 4OH−

后续：Fe2+ + 2OH− → Fe(OH)2；4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3

第 4 组：铁件镀铜（电镀）

宏观表征

把铁钉和铜片同时浸入 CuSO4 溶液，铁钉接电源负极、铜片接电源正极。通电几分钟后取出铁钉，表面均匀地覆盖了一层紫红色的铜，光亮如新；铜片则缓慢变细。电镀液的颜色（蓝色）几乎不变——说明 Cu2+ 浓度保持恒定。

微观表征

电源负极把电子"压"到铁钉表面，溶液中的 Cu2+ 在铁钉表面得电子，逐个"长"成致密的铜镀层；铜阳极上的 Cu 原子不断失电子变成 Cu2+ 进入溶液，恰好补上阴极消耗的量。整个过程像一台"铜的搬运机"：铜从阳极出发，经溶液，在阴极（铁件）上安家。电子只走外电路和电极，Cu2+ 只在溶液中定向迁移。

符号表征

阴极（铁件）：Cu2+ + 2e− → Cu

阳极（铜片）：Cu − 2e− → Cu2+

电镀液：CuSO4 溶液，c(Cu2+) 不变

口诀：镀件作阴极，镀层金属作阳极，电镀液含镀层金属离子

四、典型例题分步拆解

例 1 · 电极判断 + 电极反应式书写

题目：将镁片和铝片用导线连接，插入 NaOH 溶液中组成原电池。写出负极、正极的电极反应式和电池总反应式。

【思路点拨】很多同学一看"镁比铝活泼"就直接判镁为负极——这是本题的陷阱。判断负极的依据是"谁与该电解质发生自发的氧化还原反应"。Mg 不与 NaOH 溶液反应，而 Al 能：2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2↑。所以铝作负极。

1

确定总反应：2Al + 2OH− + 2H2O → 2AlO2− + 3H2↑（Al 失电子，水中的 H 得电子）。

2

负极（Al，氧化反应）：Al − 3e− + 4OH− → AlO2− + 2H2O。检验：左边电荷 −3 − 4 = −7？不对——Al 失去 3 个电子即左边净电荷为 −4（4 个 OH−）加上失去的 3 个电子相当于 +3，两边电荷：左 = −4 + 3 = −1，右 = −1，守恒；原子：Al 守恒，O 左 4 右 4，H 左 4 右 4，守恒。✓

3

正极（Mg，还原反应）：Mg 不与 NaOH 反应，只有水在镁表面得电子：6H2O + 6e− → 3H2↑ + 6OH−（即 2H2O + 2e− → H2↑ + 2OH−）。

4

验证：负极 × 2 与正极相加，消去 6e−：2Al + 8OH− + 6H2O → 2AlO2− + 4H2O + 3H2↑ + 6OH−，化简得 2Al + 2OH− + 2H2O → 2AlO2− + 3H2↑，与总反应一致。✓

【答案】负极（Al）：Al − 3e− + 4OH− → AlO2− + 2H2O；正极（Mg）：2H2O + 2e− → H2↑ + 2OH−；总反应：2Al + 2OH− + 2H2O → 2AlO2− + 3H2↑。

【方法总结】判断正负极的铁律是"谁与该电解质发生自发的氧化反应，谁作负极"，活泼性只是通常情况下的经验规则（在稀硫酸中 Mg 确实是负极）。类似陷阱还有：Fe、Al 遇浓硝酸钝化后，Cu 反而作负极。

例 2 · 电子守恒计算

题目：用惰性电极电解 500 mL CuSO4 溶液，一段时间后阴极析出铜 6.4 g（Cu 的相对原子质量取 64）。求：(1) 电路中转移电子的物质的量；(2) 阳极在标准状况下生成气体的体积；(3) 若溶液体积仍为 500 mL，此时溶液的 pH。

【思路点拨】先写两极反应：阴极 Cu2+ + 2e− → Cu；阳极（惰性电极，SO42− 不放电，由水放电）：2H2O − 4e− → O2↑ + 4H+。所有计算通过"n(e−) 相等"挂钩。

1

n(Cu) = 6.4 g ÷ 64 g/mol = 0.10 mol。由 Cu2+ + 2e− → Cu，转移电子 n(e−) = 2 × 0.10 = 0.20 mol。

2

由阳极反应 2H2O − 4e− → O2↑ + 4H+，n(O2) = n(e−)/4 = 0.20/4 = 0.050 mol，V(O2) = 0.050 × 22.4 = 1.12 L（标准状况）。

3

同时阳极生成 n(H+) = n(e−) = 0.20 mol（由方程式比例 4e− ~ 4H+）。c(H+) = 0.20 mol ÷ 0.500 L = 0.40 mol/L，pH = −lg 0.40 = lg 2.5 = 0.40（lg 2.5 = 0.40）。更精确：−lg 0.4 = 1 − lg 4 = 1 − 0.60 = 0.40。

【答案】(1) 0.20 mol；(2) 1.12 L；(3) pH ≈ 0.4。

【方法总结】电解计算三步："写两极反应 → 由已知量求 n(e−) → 按电子守恒分配给其他物质"。串联电路中每个电极转移的电子数必定相等，这是所有电化学计算的"总开关"。本题还有个小陷阱：问 pH 时，CuSO4 溶液电解后生成的是 H2SO4，溶液变酸，不要再去找 OH−。

例 3 · 燃料电池电极反应式（介质对比）

题目：氢氧燃料电池的总反应为 2H2 + O2 = 2H2O。分别写出以 (1) 稀硫酸、(2) KOH 溶液为电解质时，负极和正极的电极反应式。

【思路点拨】燃料电池中：燃料（H2）通入负极被氧化，氧化剂（O2）通入正极被还原。书写时用四步法，介质决定用什么离子配电荷：酸性用 H+，碱性用 OH−。

1

酸性介质负极：H2 失电子变成 H+：H2 − 2e− → 2H+（电荷、原子均守恒）。

2

酸性介质正极：O2 得 4e−，用 H+ 配电荷、H2O 配原子：O2 + 4e− + 4H+ → 2H2O。检验：左电荷 −4+4=0，右 0；O、H 均守恒。✓

3

碱性介质负极：H+ 不能存在于碱性中，H2 失电子后与 OH− 结合成水：H2 − 2e− + 2OH− → 2H2O。检验：左电荷 −2−2=−4？注意"−2e−"意味着左边净电荷为 −2 + 2 = 0……换个算法：把电子放在左边参与电荷平衡：左 = −2（OH−），右 = 0，电子 −2e− 从左边移走，左边失去负电荷相当于 +2，故左净 = 0，右 = 0，守恒。✓（考场上用最朴素的方法：数左右两边"总电荷"相等即可。）

4

碱性介质正极：O2 得电子后生成 OH−：O2 + 4e− + 2H2O → 4OH−。检验：左电荷 −4，右 −4；O：左 4 右 4，H：左 4 右 4。✓

5

验证（碱性）：负极 × 2 加正极：2H2 + 4OH− + O2 + 2H2O → 4H2O + 4OH−，消去 4OH− 并化简：2H2 + O2 → 2H2O，与总反应一致。✓

【答案】酸性：负极 H2 − 2e− → 2H+，正极 O2 + 4e− + 4H+ → 2H2O；碱性：负极 H2 − 2e− + 2OH− → 2H2O，正极 O2 + 4e− + 2H2O → 4OH−。

【方法总结】陌生介质（如熔融碳酸盐、固体氧化物电解质）也用同一套四步法，只是把 H+/OH− 换成介质中可迁移的离子（如 CO32−、O2−）。口诀："产物跟着介质走，三守恒来把关"。

例 4 · 电解产物判断与电极材料

题目：按下列两种装置电解 CuSO4 溶液，分别写出两极反应式并说明溶液 pH 的变化：装置 A 用石墨作两极；装置 B 用铜作阳极、石墨作阴极。

【思路点拨】两装置的差别只在阳极材料：石墨是惰性电极，由阴离子放电；铜是活性电极，电极本身优先溶解——这是放电顺序表的第一条规则，也是电镀、精炼的原理。

1

装置 A（惰性阳极）：阳极 OH−（来自水）优先于 SO42− 放电：2H2O − 4e− → O2↑ + 4H+；阴极 Cu2+ + 2e− → Cu。总反应：2CuSO4 + 2H2O → 2Cu + O2↑ + 2H2SO4，生成强酸，pH 减小。

2

装置 B（铜阳极）：阳极铜自身失电子：Cu − 2e− → Cu2+；阴极仍是 Cu2+ + 2e− → Cu。总效果是把阳极的铜"搬运"到阴极，溶液中 c(CuSO4) 不变，pH 不变——这正是电解精炼铜的原理。

3

对比总结：同样电解 CuSO4 溶液，阳极材料不同，结果完全不同——"先看阳极材料"是电解分析的第一反应。

【答案】A：阳极 2H2O − 4e− → O2↑ + 4H+，阴极 Cu2+ + 2e− → Cu，pH 减小；B：阳极 Cu − 2e− → Cu2+，阴极 Cu2+ + 2e− → Cu，pH 不变。

【方法总结】电解分析四连问：① 阳极是不是惰性电极？② 溶液中有哪些离子，按放电顺序谁放电？③ 两极产物是什么？④ 溶液中剩下什么，pH 怎么变？按这个顺序走，任何电解题都不会乱。

例 5 · 串联电路电子守恒计算

题目：甲、乙两个电解池串联：甲池用惰性电极电解 AgNO3 溶液，乙池用惰性电极电解 CuSO4 溶液。通电一段时间后，甲池阴极析出 10.8 g Ag（Ag 的相对原子质量取 108）。求乙池阴极析出铜的质量，以及乙池阳极在标准状况下产生气体的体积。

【思路点拨】串联电路每个电极流过的电子数相等。先由 Ag 的量求 n(e−)，再分配给乙池两极。

1

甲池阴极：Ag+ + e− → Ag。n(Ag) = 10.8 g ÷ 108 g/mol = 0.10 mol，故转移 n(e−) = 0.10 mol。

2

乙池阴极：Cu2+ + 2e− → Cu。n(Cu) = 0.10 ÷ 2 = 0.050 mol，m(Cu) = 0.050 × 64 = 3.2 g。

3

乙池阳极（惰性电极，SO42− 不放电，水放电）：2H2O − 4e− → O2↑ + 4H+。n(O2) = 0.10 ÷ 4 = 0.025 mol，V(O2) = 0.025 × 22.4 = 0.56 L（标准状况）。

【答案】乙池析出铜 3.2 g；阳极产生 O2 0.56 L（标准状况）。

【方法总结】串联计算中特别要注意各物质与电子的化学计量比不同：Ag 是 1 mol 金属对 1 mol 电子，Cu 是 1 mol 对 2 mol，O2 是 1 mol 对 4 mol。把"n(e−)"当成各池之间的"通用货币"，先统一换算再分配。

例 6 · 新型电池判断（选择题模型）

题目：某新型"锂—空气电池"以金属锂为负极、多孔碳为正极（通入空气）、非水电解质传导 Li+，放电总反应为 4Li + O2 + 2H2O → 4LiOH。下列说法正确的是（　）

A．放电时 Li+ 向负极迁移　B．正极反应为 O2 + 4e− + 2H2O → 4OH−　C．放电时负极质量增大　D．该电池工作时化学能转化为电能

【思路点拨】陌生电池题四步走：找负极（Li 最活泼，失电子）→ 写两极反应 → 判断离子迁移 → 核对选项。

1

负极（Li）：Li − e− → Li+，锂溶解，负极质量减小，C 错误。

2

离子迁移：原电池中阳离子向正极迁移，故 Li+ 向正极迁移，A 错误。

3

正极：O2 得电子，结合总反应产物 LiOH，写为 O2 + 4e− + 2H2O → 4OH−，检验电荷（左 −4、右 −4）与原子均守恒，B 正确。

4

原电池的能量转化就是化学能 → 电能，D 正确。

5

总反应验证：负极 × 4 加正极：4Li + O2 + 2H2O → 4Li+ + 4OH−，即 4LiOH，与题目所给一致。✓

【答案】BD

【方法总结】新型电池题的材料再陌生，考点永远是老三样：电极判断（谁失电子）、离子迁移（阳离子向正极）、电极反应（三守恒验证）。见到"质量变化""迁移方向""反应式正误"四类设问，逐一套用即可。

例 7 · 可充电电池的充放电判断

题目：铅蓄电池放电时的总反应为 Pb + PbO2 + 2H2SO4 → 2PbSO4 + 2H2O。下列说法正确的是（　）

A．放电时，负极反应为 PbO2 + 2e− + 4H+ + SO42− → PbSO4 + 2H2O
B．充电时，阳极反应为 PbSO4 + 2H2O − 2e− → PbO2 + 4H+ + SO42−
C．放电时，电解质溶液的密度逐渐增大
D．充电时，标有"−"的电极应与外接电源的正极相连

【思路点拨】用"放电看正负、充电看阴阳、反应互为倒写"来逐项核对。

1

A：放电时负极是 Pb 失电子（Pb − 2e− + SO42− → PbSO4），选项写的是正极反应，张冠李戴，错误。

2

B：充电时阳极是放电正极反应的倒写（PbSO4 失电子变回 PbO2），电极反应式正确，且电荷、原子均守恒，正确。

3

C：放电时消耗 H2SO4 并生成水，硫酸浓度减小，密度应减小，错误。

4

D：充电时"负接负、正接正"——标"−"的电极（放电时的负极）充电时应接外电源负极作阴极被还原，错误。

【答案】B

【方法总结】充电电池题的万能流程：先写放电两极反应（负氧正还）→ 充电反应就是对应倒写（负极↔阴极、正极↔阳极）→ 接线"负接负、正接正"。再把现象（密度、质量、pH）与总反应中的物质增减挂钩，逐项排除即可。

例 8 · 电解产物判断与现象描述

题目：以石墨为电极电解滴有酚酞的饱和食盐水，U 形管左端为阴极、右端为阳极。描述通电后两极附近可观察到的现象，并写出总反应离子方程式。

【思路点拨】现象描述必须"从电极反应式出发"，一个电极一个电极地说：有什么气体、颜色如何变化。

1

阴极（左端）：2H2O + 2e− → H2↑ + 2OH−，生成 OH− 使酚酞变红。现象：有无色气泡产生，电极附近溶液变红。

2

阳极（右端）：2Cl− − 2e− → Cl2↑。现象：有黄绿色、有刺激性气味的气体产生（湿润淀粉 KI 试纸靠近变蓝）。

3

总反应（离子方程式）：2Cl− + 2H2O → Cl2↑ + H2↑ + 2OH−。

【答案】阴极：无色气泡、附近溶液变红；阳极：黄绿色刺激性气体；总反应 2Cl− + 2H2O → Cl2↑ + H2↑ + 2OH−。

【方法总结】现象描述三要素："气泡（颜色气味）+ 溶液颜色变化 + 电极本身变化"。描述时严禁出现结论性语言代替现象（如不能说"生成了氯气"，要说"产生黄绿色气体"）；气体检验方法（淀粉 KI 试纸变蓝）要写在现象之后。

答题模板

① 电极判断表述："X 电极上，X 物质失（得）电子，化合价升高（降低），发生氧化（还原）反应，故 X 为负（正）极/阳（阴）极。"

② 电极反应式书写表述：先写"介质"（酸性/碱性），再按"定产物 → 配电子 → 配电荷 → 配原子"四步书写，写完后用三守恒（电子、电荷、原子）自查。

③ 离子迁移方向表述："阳离子向正极（阴极）迁移，阴离子向负极（阳极）迁移"——原电池说正负极，电解池说阴阳极，不要混用。

④ 电化学计算表述：必须写出"由电极反应式可知 n(物质) 与 n(e−) 的关系"，串联电路写明"各电极转移电子数相等"。

⑤ 装置图分析模板：先看有无外接电源（有→电解池，无→原电池）→ 再定各极名称与反应类型 → 然后写两极反应式 → 最后回答迁移方向、pH 变化、产物计算等设问。遇到"交换膜"先判断膜的种类（阳离子膜只过阳离子），再分析各室物质变化。

⑥ 常见失分提醒：电极反应式中电子写成"+ e−"的位置不能错（负极、阳极失电子写在左边减电子或右边加电子，但高考规范写法是左侧"− ne−"）；气体漏标"↑"、沉淀漏标"↓"也会扣分；总反应与两极反应的电子数必须配平一致再相加。

五、易错点与成因分析

易错点 1

易错表现：把原电池和电解池的电极名称张冠李戴，如说"原电池的负极就是电解池的阴极"，或认为电解池中"阳极得电子"。

错误成因：死记"正负阴阳"四个名词而没有抓住本质——氧化还原。负极和阳极才是"一家人"（都发生氧化、失电子），正极和阴极是"一家人"（都发生还原、得电子）。

正确理解：负氧正还（原电池）、阳氧阴还（电解池）。充电电池放电时是原电池（说正负极），充电时是电解池（说阴阳极）——同一个物理电极，放电时的负极在充电时作阴极。

一句话避坑：负阳都氧化（失电子），正阴都还原（得电子）——"负阳一家，正阴一家"。

易错点 2

易错表现：认为"电子从负极流出，经过电解质溶液到达正极"，或说"阳离子带正电所以向负极跑"（原电池中）。

错误成因：混淆了外电路和内电路的导电机制。外电路靠自由电子定向移动导电，溶液靠阴、阳离子定向移动导电，两者接力而不交叉——"电子不下水，离子不上岸"。

正确理解：原电池中电子走导线（负 → 正）；溶液中阳离子移向正极、阴离子移向负极（补偿电荷，保持各处电中性）。电解池中阳离子移向阴极、阴离子移向阳极（被电极"吸引"）。

一句话避坑：电子走外、离子走内；原电池"正正负负"（阳离子向正极），电解池"阴阳相吸"。

易错点 3

易错表现：写碱性条件下的电极反应式时产物中出现 H+（或酸性条件下出现 OH−），如把碱性氢氧燃料电池负极写成 H2 − 2e− → 2H+。

错误成因：只背了酸性的写法，没有意识到 H+ 在碱性溶液中会立即与 OH− 中和成水，根本不可能作为最终产物存在。

正确理解：书写前先问自己"这个环境里能稳定存在什么离子"。酸性用 H+ 配电荷，碱性用 OH− 配电荷。写完后检查：电极反应式中出现的每一种粒子都必须能在该介质中稳定存在。

一句话避坑：酸中无 OH−，碱中无 H+——产物必须"入乡随俗"。

易错点 4

易错表现：电解 CuCl2 溶液时用铜作阳极，仍按"Cl− 放电生成 Cl2"来写阳极反应。

错误成因：背放电顺序时漏掉了前提条件——阴离子放电顺序只适用于惰性电极。活性电极（除 Pt、Au 外的金属）作阳极时，电极金属自身优先失电子溶解，轮不到溶液里的离子。

正确理解：阳极判断第一步永远是"看材料"：惰性电极 → 按 S2− > I− > Br− > Cl− > OH− > 含氧酸根 放电；活性电极 → 电极本身溶解（如 Cu − 2e− → Cu2+）。

一句话避坑：阳极先看材料——活性电极"自己动手"，惰性电极才轮到离子。

易错点 5

易错表现：混淆两种金属防护法——认为"牺牲阳极法是利用电解池原理"或"外加电流法要接被保护金属到电源正极"。

错误成因：没有从"谁被氧化"的角度理解。被保护金属必须作还原反应的一极（正极或阴极），让别的物质替它被氧化。接到电源正极就成了阳极，会被加速氧化腐蚀，南辕北辙。

正确理解：牺牲阳极法（牺牲阳极的阴极保护法）：连接更活泼金属，活泼金属作负极（原电池负极被氧化），被保护金属作正极——原电池原理；外加电流法：被保护金属接电源负极作阴极——电解池原理。

一句话避坑：牺牲阳极靠"替死鬼"（原电池），外加电流接"负极"（电解池）。

易错点 6

易错表现：计算电解后溶液 pH 时，直接对阳极区或阴极区的局部浓度进行计算并当作整个溶液的 pH；或把电解 CuSO4 溶液后 pH 的变化方向判断反。

错误成因：没有先写出两极反应式、判断"净生成"了什么。电解 CuSO4 溶液时阴极析出 Cu、阳极生成 H+，总体效果是生成了 H2SO4，pH 必然减小；若题目给出两极区不隔膜的混合溶液，必须先算总的 n(H+) 再除以总体积。

正确理解：先写两极反应 → 合并出总反应 → 看净产物是酸还是碱 → 用总量和总体积求浓度。凡是涉及"pH 变化"的电解题，总反应写出来答案就明了一半。

一句话避坑：电解 pH 看总反应，合并两极再下结论。

易错点 7

易错表现：描述原电池现象时说"负极质量一定减小、正极一定有气体产生"；或认为"电极上发生的反应类型取决于电极材料的活泼性"。

错误成因：把铜锌原电池的特殊现象当成了普遍规律。负极质量减小只在"电极自身失电子溶解"时成立；燃料电池中两个电极都是惰性材料，质量都不变。正极的产物取决于"谁在正极得电子"，可能是 H2、金属析出，也可能是 O2 被还原（吸氧腐蚀），不一定有气体。

正确理解：判断现象一律从两极反应式出发，先写式子再说现象。电极反应类型（氧化/还原）由电极的"角色"决定（负极/阳极氧化，正极/阴极还原），而不是材料本身——同一块铜，在原电池中作正极被保护，在电解池中作阳极却被溶解。

一句话避坑：现象从反应式里来，不背模板；电极角色决定反应类型，与材料无关。

易错点 8

易错表现：认为"电解 NaCl 溶液一段时间后，加入 NaCl 即可使溶液复原"；或"电解 CuSO4 溶液后加 Cu(OH)2 复原"。

错误成因：没有搞清楚"复原"补的是"从溶液中离开的元素"。电解 NaCl 溶液时跑出的是 H2 和 Cl2（H、Cl 元素离开体系），NaCl 本身并没有减少多少——加 NaCl 反而越加越浓。

正确理解：复原原则——"出什么补什么，按原子比例补"：放 H2 生碱型通 HCl 气体（补 H、Cl 两种元素且不带入水）；放 O2 生酸型加 CuO 或 CuCO3（补 Cu、O，且能与生成的酸反应）；只电解水时加水；电解电解质型加该电解质（或通入对应气体，如盐酸电解后通 HCl）。

一句话避坑：复原看"离场的元素"，不看"原来的溶质"。

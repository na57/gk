3.13 化学反应速率与化学平衡

高中化学 · 深度学习材料 · 面向 2029 届云南高考

上一章我们关心反应"放出多少热"（热力学方向），本章关心两件事：反应"进行多快"（速率）和"进行到什么程度"（平衡）。 这是整个高中化学难度最高、高考分值最重的章节——第 17 题反应原理大题的主战场。三段式计算、平衡移动判断、图象分析，三板斧必须练到滚瓜烂熟。

二、核心概念精讲

2.1 化学反应速率

核心概念

是什么：用单位时间内反应物浓度的减小或生成物浓度的增加来表示反应进行的快慢：

v = Δc / Δt　　单位：mol/(L·s) 或 mol/(L·min)

三个要点：

  1. 是平均速率：v 是一段时间内的平均值，不是瞬时速率；浓度随时间变化，瞬时速率也在变；
  2. 总取正值：无论用反应物还是生成物表示，v 都是正数；
  3. 不能用固体或纯液体表示：它们的"浓度"是定值（视为常数），无法体现变化。

速率关系（最重要的换算规则）：同一反应中，用不同物质表示的速率数值可能不同，但速率之比等于化学计量数之比。对 aA + bB ⇌ cC + dD：

v(A) : v(B) : v(C) : v(D) = a : b : c : d

比较同一反应在不同条件下的快慢时，必须先把各物质的速率换算成同一种物质再比较，否则就会闹"v(H2) = 0.3 比 v(NH3) = 0.2 快"这种忽略系数的笑话——换算后二者其实是同一个速率。

2.2 影响反应速率的因素

因素 规律 微观解释（有效碰撞理论）
浓度 增大反应物浓度，速率加快 单位体积内活化分子数增多，有效碰撞频率增大
压强（有气体参与） 加压（缩小体积），气体浓度增大，速率加快 本质是浓度效应；若充入"惰性气体"而容器体积不变，各组分浓度不变，速率不变
温度 升温，速率显著加快（无论吸热还是放热反应） 分子能量升高，活化分子百分数增大（这是主因）
催化剂 正催化剂大幅加快反应速率 降低反应的活化能，使更多分子成为活化分子；不改变 ΔH，不改变平衡位置
固体表面积 粉碎、搅拌可加快反应 接触面积增大，有效碰撞机会增多
易混提醒

升温对放热反应同样加快速率（只是平衡会逆向移动，见 2.4）；"速率"和"平衡"是两条独立的线：催化剂同时同等程度地加快正、逆反应速率，所以它能缩短到达平衡的时间，却不能让平衡移动。

对比归纳

"条件 → 速率 → 平衡"一表清（本章的主干逻辑）：

改变条件 对速率的影响 对平衡的影响 对 K 的影响
增大反应物浓度 v(正) 加快 正向移动 不变
加压（缩小体积） 气体反应加快 向气体分子数减小的方向移动 不变
恒容充惰性气体 不变 不移动 不变
升高温度 正逆都加快 向吸热方向移动 改变（放热反应 K 减小）
加催化剂 正逆同等程度加快 不移动 不变

这张表是判断题的"总开关"，建议抄在笔记本上，做到默写。

2.3 化学平衡状态

核心概念

是什么：一定条件下，可逆反应进行到 v(正) = v(逆) ≠ 0 时，各组分的浓度（或百分含量）保持不变的状态。可逆反应中用 ⇌ 表示，例如：

N2(g) + 3H2(g) ⇌ 2NH3(g)　ΔH < 0

五大特征（逆、等、动、定、变）：

  • 逆：研究对象必须是可逆反应；
  • 等：v(正) = v(逆)，这是平衡的本质标志；
  • 动：动态平衡，反应并未停止，只是正逆抵消；
  • 定：各组分浓度、百分含量、体系颜色、压强（气体分子数变化时）等保持恒定；
  • 变：条件改变，原平衡被破坏，发生移动直至建立新平衡。

平衡状态的判断（选择题高频，口诀"变量不变即平衡"）：

  • 直接判据：同一物质的 v(正) = v(逆)；或 v(正, A) : v(逆, B) 等于化学计量数之比；
  • 间接判据：某"变量"（如气体总压强、混合气体平均摩尔质量、密度、颜色深浅）由变化变为不变，说明达到平衡；
  • 陷阱：若某量从反应一开始就恒定（如恒容容器中全是气体的体系总质量、反应前后气体分子数不变时的总压强），它的"不变"不能说明平衡。

2.4 化学平衡移动与勒夏特列原理

核心概念

是什么：如果改变影响平衡的一个条件（浓度、压强、温度），平衡就向着能够减弱这种改变的方向移动。这就是勒夏特列原理。

为什么（微观理解）：平衡是一种"自适应"的稳定状态。你加了反应物，体系就消耗它一点；你升温，体系就朝吸热方向走一点来"吸走"热量。注意是"减弱"而非"抵消"——新平衡只能部分补偿，不可能回到原样。

三大因素对平衡的影响（以 N2 + 3H2 ⇌ 2NH3　ΔH < 0 为例）：

改变条件 移动方向 原因
增大反应物浓度 正向 v(正) 瞬时增大，v(正) > v(逆)
增大压强（缩小体积） 正向（气体分子数减小的方向） 两边气体浓度都增大，但气体分子数多的一侧受影响更大
升高温度 逆向（吸热方向） 吸热方向可以"消耗"多出来的热量
加催化剂 不移动 v(正)、v(逆) 同等倍数增大，仍然相等

适用边界：压强只影响"有气体且气体分子数前后不相等"的反应；若反应前后气体分子数相等（如 H2 + I2 ⇌ 2HI），改变压强平衡不移动。

深入一步

平衡移动方向 ≠ 转化率一定升高，这是最容易被直觉带偏的地方：

  • 对 A + B ⇌ 产物 型反应，增大 A 的浓度，平衡正向移动，B 的转化率升高，但 A 自身的转化率反而降低（新增的 A 不可能全部转化）；
  • 对只有一种反应物的反应（如 2HI(g) ⇌ H2(g) + I2(g)），恒容下再充入 HI，相当于加压，而该反应气体分子数前后相等，平衡不移动，HI 转化率不变；
  • 升温：吸热方向的反应物转化率升高，放热方向的反应物转化率降低。

判断转化率，永远回到"转化率 = 转化量 / 起始量"，分别看分子分母怎么变。

2.5 化学平衡常数 K

核心概念

是什么：一定温度下，可逆反应达到平衡时，生成物浓度幂之积与反应物浓度幂之积的比值。对 aA(g) + bB(g) ⇌ cC(g) + dD(g)：

K = cc(C) · cd(D) / [ ca(A) · cb(B) ]

四条铁律：

  1. 固体和纯液体不写入表达式：如 CaCO3(s) ⇌ CaO(s) + CO2(g) 的 K = c(CO2)；
  2. K 只与温度有关：与浓度、压强、催化剂均无关。温度不变，K 不变；温度改变，K 才变（放热反应升温 K 减小，吸热反应升温 K 增大）；
  3. K 与方程式写法对应：方程式系数加倍，K 变为平方；方向反转，K 变为倒数；
  4. K 的意义：K 越大，反应进行得越完全。一般 K > 105 认为反应基本进行完全。

K 的应用——判断方向（浓度商 Q 与 K 比较）：

  • Q < K：反应向正方向进行；
  • Q = K：处于平衡状态；
  • Q > K：反应向逆方向进行。

常见混淆：K 的表达式里用平衡浓度，不是起始浓度；K 有单位但中学阶段一律不写单位。

2.6 三段式计算法（本章计算的万能钥匙）

方法模板

对所有平衡计算，一律按"起始 → 转化 → 平衡"三段列式：

A B C
起始浓度（或物质的量） c0(A) c0(B) 0
转化浓度 −ax −bx +cx
平衡浓度 c0(A) − ax c0(B) − bx cx

使用要点：① 转化量之比严格按化学计量数分配；② 代入 K 表达式的必须是平衡浓度（若给的是物质的量，别忘了除以容器体积）；③ 转化率 = 转化量 / 起始量 × 100%。

2.7 平衡图象分析

核心概念

常见图象类型与读图要领：

  • v-t 图：看条件改变瞬间哪个速率发生"突变"。如增大反应物浓度，v(正) 瞬间上跳、v(逆) 不变，随后 v(正) 渐降、v(逆) 渐升至相等——平衡正向移动；若两速率同时同等程度跳变（如加催化剂、等气体分子数反应加压），平衡不移动。
  • c-t 图（或含量-t 图）：曲线先达到平台（拐点先出现）的条件更"快"（温度更高或压强更大）——口诀"先拐先平数值大"。再结合平台高低判断平衡移动方向，反推 ΔH 正负或气体分子数大小。
  • 转化率-温度-压强图：固定压强看温度影响（判断 ΔH 正负），固定温度看压强影响（判断气体分子数变化），即"定一议二"。

读图四步：一看横纵坐标的含义与单位；二看曲线走向（增还是减）；三看拐点、交点、平台的含义；四把图象信息与平衡规律对接，落到结论上。

2.8 等效平衡

核心概念

是什么：同一可逆反应，在相同条件下从不同投料出发，达到平衡时各组分的百分含量相同，这几个平衡互为等效平衡。

两种模型：

  1. 恒温恒容：把投料按化学计量数"折算到同一边"后，物质的量完全相等（量相当），则等效。例如 N2 + 3H2 ⇌ 2NH3，投"1 mol N2 + 3 mol H2"与投"2 mol NH3"互为等效平衡（平衡时各组分百分含量相同）；
  2. 恒温恒压：折算到同一边后，物质的量成比例（比相等）即等效。例如恒温恒压下投"1 mol N2 + 3 mol H2"与"2 mol N2 + 6 mol H2"等效，后者各组分物质的量是前者的 2 倍，但百分含量相同。

理解钥匙：等效平衡的本质是"殊途同归"——无论正投、逆投还是中间投，只要折算后"家底"相当，终点就一样。这与盖斯定律"只看始态终态"的思想一脉相承。

三、三重表征贯通

3.1 Fe3+ 与 SCN− 的可逆反应（平衡的建立与移动）

宏观表征

向 FeCl3 溶液中滴入 KSCN 溶液，溶液立即变为血红色。再滴加浓 FeCl3 溶液，红色加深；滴加 NaOH 溶液（消耗 Fe3+），红色变浅。颜色的深浅变化直接"直播"了平衡的移动。

微观表征

Fe3+ 与 SCN− 结合成血红色的 Fe(SCN)3（正反应），同时 Fe(SCN)3 又在不断解离（逆反应）。平衡时两个方向仍在进行，只是速率相等、浓度不变。加入 Fe3+ 后正反应速率瞬间增大，正方向占上风，更多 Fe(SCN)3 生成，红色加深。

符号表征

Fe3+(aq) + 3SCN−(aq) ⇌ Fe(SCN)3(aq)

（血红色）　K = c[Fe(SCN)3] / { c(Fe3+) · c3(SCN−) }

3.2 NO2 ⇌ N2O4 的温度实验（温度对平衡的影响）

宏观表征

装有 NO2 与 N2O4 混合气体的密闭圆底烧瓶，常温下呈红棕色。放入热水中，颜色明显变深；放入冰水中，颜色明显变浅。温度这只"无形的手"在拨动平衡。

微观表征

正方向（2 个 NO2 分子结合成 1 个 N2O4）是放热的。升温时，吸热的逆反应被"鼓励"，N2O4 更多地分解为 NO2，红棕色的 NO2 浓度增大，颜色变深；降温时平衡正向移动，无色的 N2O4 增多，颜色变浅。

符号表征

2NO2(g) ⇌ N2O4(g)　ΔH < 0

（红棕色）　　　（无色）　升温 K 减小，降温 K 增大。

3.3 工业合成氨（速率与平衡的权衡）

宏观表征

合成氨工厂在高温（约 500 ℃）、高压（20~50 MPa）、铁催化剂条件下运行，出口气体中 NH3 只占一部分，未反应的 N2、H2 被冷凝分离后循环回反应塔——可逆反应不能进行到底，原料必须循环利用。

微观表征

该反应正向是"气体分子数减小（4→2）+ 放热"的反应。加压有利于平衡正向移动；低温也有利于平衡，但温度太低速率太慢、催化剂活性差，所以工业上选择"约 500 ℃"这个速率与产率的折中点，并用催化剂把速率补回来。

符号表征

N2(g) + 3H2(g) ⇌ 2NH3(g)　ΔH = −92 kJ/mol

K = c2(NH3) / [ c(N2) · c3(H2) ]，升温 K 减小。

四、典型例题分步拆解

例题 1 · 反应速率的计算与换算

题目：一定温度下，在 2 L 密闭容器中进行反应 N2(g) + 3H2(g) ⇌ 2NH3(g)。测得 2 s 内 NH3 的浓度增加了 0.4 mol/L。求：

（1）v(NH3)；（2）v(H2)；（3）2 s 内 H2 减少了多少摩尔？

【思路点拨】速率定义 v = Δc/Δt 先求 v(NH3)，再用"速率之比 = 化学计量数之比"换算 v(H2)，最后用 Δn = Δc×V 求物质的量。

1

v(NH3) = Δc/Δt = 0.4 mol/L ÷ 2 s = 0.2 mol/(L·s)。

2

由 v(H2) : v(NH3) = 3 : 2，得 v(H2) = 0.2 × 3/2 = 0.3 mol/(L·s)。

3

Δc(H2) = 0.3 mol/(L·s) × 2 s = 0.6 mol/L；Δn(H2) = 0.6 mol/L × 2 L = 1.2 mol。

【答案】（1）v(NH3) = 0.2 mol/(L·s)；（2）v(H2) = 0.3 mol/(L·s)；（3）H2 减少 1.2 mol。

【方法总结】速率题三步走：定义式求一种 → 系数比换算 → 乘体积回物质的量。注意比较两个反应谁快时，一定要先换算成同种物质再比。

例题 2 · 三段式求平衡常数与转化率（高考核心模型）

题目：某温度下，在 2 L 密闭容器中充入 2 mol SO2 和 1 mol O2，发生反应 2SO2(g) + O2(g) ⇌ 2SO3(g)。达到平衡时测得 SO3 的物质的量为 1.2 mol。求：

（1）该温度下反应的平衡常数 K；（2）SO2 的平衡转化率。

【思路点拨】可逆反应给了起始量和一种物质的平衡量，立刻想到三段式。注意本题给的是物质的量，代入 K 前必须除以体积 2 L 换算成浓度。

1

列三段式（单位：mol）：
起始：SO2 = 2，O2 = 1，SO3 = 0；
转化：SO3 增加 1.2 mol，按系数比，SO2 减少 1.2 mol，O2 减少 1.2 × 1/2 = 0.6 mol；
平衡：SO2 = 2 − 1.2 = 0.8 mol，O2 = 1 − 0.6 = 0.4 mol，SO3 = 1.2 mol。

2

换算成平衡浓度（除以 2 L）：c(SO2) = 0.4 mol/L，c(O2) = 0.2 mol/L，c(SO3) = 0.6 mol/L。

3

代入 K 表达式：
K = c2(SO3) / [ c2(SO2) · c(O2) ] = (0.6)2 / [ (0.4)2 × 0.2 ] = 0.36 / 0.032 = 11.25。

4

SO2 转化率 = 转化量 / 起始量 × 100% = 1.2 / 2 × 100% = 60%。

【答案】（1）K = 11.25；（2）SO2 的平衡转化率为 60%。

【方法总结】三段式铁律：① 转化量严格按系数比分配；② K 里必须是平衡浓度，物质的量要先除体积；③ 算完检查三段数量级是否合理（平衡量不能为负）。这类题在高考中值 2~4 分，是必须零失误的"口粮题"。

例题 3 · 平衡移动方向判断

题目：对于已达平衡的反应 N2(g) + 3H2(g) ⇌ 2NH3(g)　ΔH < 0，下列条件的改变分别使平衡向什么方向移动？

（1）升高温度；（2）增大压强（缩小体积）；（3）加入催化剂；（4）恒容下充入少量氦气；（5）将 NH3 液化分离出去。

【思路点拨】勒夏特列原理逐条分析：先明确这个反应"正向 = 气体分子数减小 + 放热"，再看每个条件"推"平衡往哪边走。

1

升高温度：平衡向吸热方向移动，即逆向移动（合成氨的 K 减小）。

2

增大压强：平衡向气体分子数减小的方向移动，即正向移动（4 mol 气体 → 2 mol 气体）。

3

加入催化剂：v(正)、v(逆) 同等倍数增大，平衡不移动，只是更快达到平衡。

4

恒容充氦气：总压强增大，但 N2、H2、NH3 的浓度都没有变化（容器体积没变），v(正) 仍等于 v(逆)，平衡不移动。这是最容易错的一问！

5

分离 NH3：生成物浓度减小，平衡正向移动，补充 NH3（这正是工业上提高转化率的办法）。

【答案】（1）逆向；（2）正向；（3）不移动；（4）不移动；（5）正向。

【方法总结】判断移动方向的三连问：条件改变了什么（浓度/压强/温度）→ v(正) 与 v(逆) 谁变得更大 → 平衡向哪移。特别提醒："加压"必须作用于反应气体本身才有效，恒容充惰性气体等于"假加压"，各组分浓度纹丝不动。

例题 4 · 平衡状态的判断

题目：一定温度下，恒容密闭容器中发生反应 H2(g) + I2(g) ⇌ 2HI(g)。下列事实能说明反应已达到平衡状态的是（　　）

A. 容器内气体总压强不再变化

B. 单位时间内消耗 a mol H2，同时生成 2a mol HI

C. 混合气体的颜色不再变化

D. c(H2) : c(I2) : c(HI) = 1 : 1 : 2

【思路点拨】用"变量不变即平衡"检验各选项：这个反应前后气体分子数相等（1+1=2），所以总压强从头到尾都不变，是"伪变量"。

1

A 不能：该反应气体分子数前后相等，总压强自始至终恒定，它的"不变"与是否平衡无关。

2

B 不能：消耗 H2 和生成 HI 描述的都是正反应方向，且比例恒等于系数比，任何时刻都成立，无法说明 v(正) = v(逆)。

3

C 能：颜色由紫红色的 I2(g) 浓度决定。颜色不变 → c(I2) 不变 → 各组分浓度不变 → 达到平衡。

4

D 不能：平衡时浓度之比取决于起始投料和转化率，恰好等于系数比纯属巧合，不是平衡的必然标志。

【答案】C

【方法总结】平衡判断两板斧：① 速率型表述必须"一正一逆且符合系数比"；② 浓度/压强/颜色/密度型表述必须确认该量在反应过程中确实是变量。先问自己"它一直在变吗"，再谈"它不变了说明什么"。

例题 5 · 不同条件下反应快慢的比较

题目：反应 4NH3(g) + 5O2(g) ⇌ 4NO(g) + 6H2O(g) 在四种不同条件下进行，测得的反应速率分别为：

① v(NH3) = 0.4 mol/(L·s)；② v(O2) = 0.6 mol/(L·s)；③ v(NO) = 0.5 mol/(L·s)；④ v(H2O) = 0.9 mol/(L·s)。

四种条件下反应由快到慢的顺序是？

【思路点拨】不同物质表示的速率不能直接比大小，必须换算成同一种物质。这里统一换算成 v(NH3)，用"速率 ÷ 自己的化学计量数 × 4"即可。

1

① 已经是 v(NH3) = 0.4 mol/(L·s)。

2

② 换算：v(NH3) = 0.6 × 4/5 = 0.48 mol/(L·s)。

3

③ 换算：v(NH3) = 0.5 × 4/4 = 0.5 mol/(L·s)。

4

④ 换算：v(NH3) = 0.9 × 4/6 = 0.6 mol/(L·s)。

5

比较：0.6 > 0.5 > 0.48 > 0.4。

【答案】④ > ③ > ② > ①。

【方法总结】速率比较两步：统一物质 → 比数值。一个更快捷的等价做法是直接比较"速率 ÷ 化学计量数"（即反应进度速率），谁的商大谁快，可以省去换算到同一物质的步骤。

例题 6 · 平衡图象分析（"先拐先平"模型）

题目：某可逆反应 aA(g) + bB(g) ⇌ cC(g) 中，C 的百分含量（C%）随时间变化的图象显示：

（1）温度为 T1、T2 的两条曲线中，T2 对应的曲线先出现拐点（先达平衡），且平衡时 C% 比 T1 时低；

（2）压强为 P1、P2 的两条曲线中，P2 对应的曲线先达平衡，且平衡时 C% 比 P1 时高。

请判断：T1 与 T2 的大小、ΔH 的正负、P1 与 P2 的大小、a+b 与 c 的大小。

【思路点拨】口诀"先拐先平数值大"：先达到平衡的一方条件更强（温度更高或压强更大）；再看平衡时 C% 的高低，判断条件改变使平衡向哪个方向移动，反推反应的热效应与气体分子数关系。

1

T2 先达平衡 → T2 时速率更快 → T2 > T1。

2

由 T1 → T2 是升温，平衡时 C% 降低 → 升温平衡逆向移动 → 逆反应吸热 → 正反应放热 → ΔH < 0。

3

P2 先达平衡 → P2 > P1。

4

由 P1 → P2 是加压，平衡时 C% 升高 → 加压平衡正向移动 → 正方向气体分子数减小 → a + b > c。

【答案】T2 > T1；ΔH < 0；P2 > P1；a + b > c。

【方法总结】图象题答题模板："先拐先平数值大"定条件强弱 → "平台高低"定移动方向 → 用勒夏特列原理反推 ΔH 正负或气体分子数大小。两步缺一不可，只凭平台高低不定条件、只凭拐点不看平台，都会翻车。

例题 7 · 等效平衡判断

题目：一定温度下，反应 2SO2(g) + O2(g) ⇌ 2SO3(g)。甲容器恒温恒容，乙容器恒温恒压，两容器起始都充入 2 mol SO2 和 1 mol O2，达到平衡。现分别做对比实验：

（1）甲容器中改充 4 mol SO2 和 2 mol O2，新平衡与原平衡是否等效？SO3 的百分含量如何变化？

（2）乙容器中改充 4 mol SO2 和 2 mol O2，新平衡与原平衡是否等效？SO3 的百分含量如何变化？

【思路点拨】先折算：4 mol SO2 + 2 mol O2 恰好是原投料的 2 倍。恒温恒容下"量加倍"相当于加压，该反应正向气体分子数减小，加压会推动平衡正向移动，所以不等效；恒温恒压下"比相等"即等效。

1

折算判断：新投料 4 mol SO2、2 mol O2 = 原投料的 2 倍，即"量加倍"。

2

甲（恒温恒容）：量加倍 → 相当于把原平衡"压缩进"原容器，压强增大 → 平衡向气体分子数减小的方向（正向）移动 → SO3 百分含量增大，与原平衡不等效。

3

乙（恒温恒压）：量加倍、体积也加倍，各组分浓度不变 → 与原平衡等效，SO3 百分含量不变（但 SO3 的物质的量是原来的 2 倍）。

【答案】（1）不等效，SO3 百分含量增大；（2）等效，SO3 百分含量不变（物质的量加倍）。

【方法总结】等效平衡判定口诀："恒容量相当，恒压比相等"。恒容时量加倍不是等效而是"加压效应"（仅对气体分子数变化的反应有效）；恒压时量加倍是等效，含量不变、总量加倍。答题时先写容器类型（恒容/恒压），再写折算结果，最后下结论。

答题模板

平衡移动的规范表述模板（大题采分点这样写）：

以"合成氨反应达到平衡后升高温度，平衡如何移动？为什么？"为例，满分表述分四层：

  1. 摆事实：该反应正反应为放热反应（ΔH < 0）；
  2. 说条件：升高温度，正、逆反应速率均增大，但吸热方向（逆反应）的速率增大得更多；
  3. 比大小：此时 v(逆) > v(正)；
  4. 下结论：平衡向逆反应方向移动（或答：根据勒夏特列原理，升温使平衡向吸热方向移动）。

只写"升温平衡逆向移动"不给原理，通常只能拿一半分；四层齐全才是满分答案。浓度、压强的表述仿照此模板，把"吸热方向"换成对应的"浓度增大的一方""气体分子数减小的一方"即可。

五、易错点与成因分析

易错点 1

易错表现：用固体或纯液体的浓度变化表示反应速率，如"v( CaCO3 ) = …"。

错误成因：机械套用 v = Δc/Δt，没有意识到固体、纯液体的浓度是常数，根本谈不上"浓度变化"。

正确理解：速率只能用气体或溶液中溶质的浓度变化来表示。固体参加的反应，其快慢用固体质量减少速率或表面积来描述。

避坑口诀："固液无浓度，速率莫沾边"。

易错点 2

易错表现：认为"增大浓度，平衡常数 K 增大"或"加压使 K 变大"。

错误成因：把"平衡移动"和"K 变化"混为一谈——浓度、压强确实能让平衡移动，但它们改变的是各组分的浓度，而不是 K 本身。

正确理解：K 是温度的"专属函数"。温度不变，无论怎么加料、加压，平衡再怎么移动，重新平衡后算出的 K 值不变。只有升温（放热反应 K 减小、吸热反应 K 增大）才能改变 K。

避坑口诀："K 只认温度，其他一概不认"。

易错点 3

易错表现：认为"加入催化剂能提高反应物的平衡转化率"。

错误成因：只看到催化剂"加快反应"，就想当然认为"反应更充分了"，混淆了"速率"与"限度"两个概念。

正确理解：催化剂同等程度地加快正、逆反应速率，v(正) 依然等于 v(逆)，平衡位置纹丝不动。它只缩短"到达平衡的时间"，不改变"平衡的终点"，转化率不变、K 不变、ΔH 也不变。

避坑口诀："催化剂管快不管多"。

易错点 4

易错表现：恒容容器中充入惰性气体，认为"压强增大，平衡向气体分子数减小的方向移动"。

错误成因：只盯着"总压强变大"这个表象，没有分析各反应组分的浓度（分压）是否变化。

正确理解：平衡移动由反应物和生成物的浓度决定。恒容充惰性气体，容器体积不变，各组分的物质的量浓度不变，v(正) = v(逆) 不变，平衡不移动。若是恒压充惰性气体，容器体积变大，相当于"减压"，平衡才会向气体分子数增大的方向移动。

避坑口诀："恒容充惰不移动，恒压充惰当减压"。

易错点 5

易错表现：认为"勒夏特列原理能让改变完全抵消"，如加压后新平衡的总压强回到原来的数值。

错误成因：对"减弱"二字理解不到位，把"减弱"误读成"消除"。

正确理解：平衡的移动只能部分补偿外界的改变。例如把体积压缩为原来的一半，平衡虽向气体分子数减小的方向移动，但新平衡的总压强仍比原来大（介于一倍与两倍之间）。勒夏特列原理是"和事佬"，只能缓和矛盾，不能抹平矛盾。

避坑口诀："减弱不抵消，改变仍是改变"。

易错点 6

易错表现：写 K 的表达式时把固体写进去，如 CaCO3(s) ⇌ CaO(s) + CO2(g) 的 K 写成 K = c(CaO)·c(CO2)/c(CaCO3)。

错误成因：照搬"生成物浓度幂之积 / 反应物浓度幂之积"的通式，不知道固体、纯液体的浓度是常数，已被"吸收"进 K 值里了。

正确理解：固体和纯液体的浓度不随其量改变，约定为 1，不写入表达式。该反应的正确表达式是 K = c(CO2)——这意味着平衡时 CO2 的浓度是定值，与 CaCO3 的量无关。

避坑口诀："固纯液体不入式"。

易错点 7

易错表现：读平衡图象时把"先拐先平"记反，认为先达平衡的曲线对应较低的温度或压强；或只看平台高低就判断 ΔH，不先用拐点确定温度大小。

错误成因：没有建立"先达平衡 = 速率快 = 条件强（温度高/压强大）"的逻辑链，把图象当成孤立的几何图形死记硬背，两步推理（拐点定条件 → 平台定移动）只做了第二步。

正确理解：温度高、压强大时速率快，先达到平衡，曲线先出现拐点——所以"先拐"的一方条件数值更大。确定了温度（压强）谁大之后，再比较两条曲线平台的高低，才能判断升温（加压）使平衡向哪边移动，进而推出 ΔH 正负或气体分子数大小。

避坑口诀："先拐先平数值大，平台高低定移动"——两句连用，顺序不乱。

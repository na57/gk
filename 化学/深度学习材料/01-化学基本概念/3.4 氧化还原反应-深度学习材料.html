3.4 氧化还原反应

高中化学 · 深度学习材料 · 面向 2029 届云南高考

二、核心概念精讲

2.1 氧化还原反应的本质与特征

核心概念

特征（表）：反应前后有元素的化合价发生升降。

本质（里）：有电子转移——包括电子的得失（离子型反应）和共用电子对的偏移（共价型反应）。

为什么化合价升降能当"判据"？化合价是原子得失（或偏移）电子情况的记账符号。一个原子失去电子，正电性增强，化合价升高；得到电子则降低。所以"看化合价变化"就是在"看电子转移"的账簿，判据简单可靠，考场上 3 秒就能判断一个反应是不是氧化还原反应。

与四大基本反应类型的关系：

  • 置换反应一定是氧化还原反应（有单质参与价态必变）；
  • 复分解反应一定不是（只交换成分，无电子转移）；
  • 化合、分解反应部分是（有单质参加或生成时一般是）。

常见混淆：有单质参加的反应一定是氧化还原反应吗？不一定！反例：3O2 → 2O3（同素异形体转化，氧元素始终 0 价）。判据永远只有一个：化合价是否变化。

2.2 氧化剂与还原剂（六角色一张网）

核心概念

一个氧化还原反应中有六个角色，关系网必须烂熟于心：

  • 还原剂：失电子 → 化合价升高 → 被氧化 → 发生氧化反应 → 生成氧化产物；
  • 氧化剂：得电子 → 化合价降低 → 被还原 → 发生还原反应 → 生成还原产物。

口诀："升、失、氧、还"——化合价升高、失电子、被氧化、作还原剂；"降、得、还、氧"——化合价降低、得电子、被还原、作氧化剂。

为什么氧化剂是被还原的？（微观解释）氧化剂"抢"走了还原剂的电子，自己化合价降低，被还原。名字描述的是它"对别人的作用"（使别人氧化），而命运描述的是"它自己的遭遇"（自己被还原）。记住：角色名是"施动"，遭遇是"受动"。

常见氧化剂（按出场率排序）：O2、Cl2、浓 H2SO4、HNO3（浓/稀）、KMnO4（H+）、K2Cr2O7（H+）、FeCl3、H2O2、NaClO、ClO−。

常见还原剂：活泼金属（Na、Mg、Al、Zn、Fe）、H2、C、CO、H2S（S2−）、HI（I−）、Fe2+、SO2（SO32−）。

常见混淆对：氧化产物 ↔ 还原产物。别背字面，走流程：还原剂 → 被氧化 → 氧化产物（化合价升高的那个产物）；氧化剂 → 被还原 → 还原产物（化合价降低的那个产物）。

2.3 双线桥法与单线桥法

核心概念

双线桥法：在方程式上下各画一座桥，连接反应物与生成物中的同一种变价元素，桥上写明"得到/失去"电子的数目和总数。要点：

  • 箭头由反应物指向生成物中的同种元素（同元素相连）；
  • 必须写"得到"或"失去"，写法为"失去 2×e−"或"得到 2e−"（个数×每个得失数）；
  • 得电子总数与失电子总数必须相等——这是自我校验。

以 CuO + H2 → Cu + H2O 为例：从 CuO 中的 Cu（+2 价）指向生成物 Cu（0 价），桥上写"得到 2e−，化合价降低，被还原"；从 H2 中的 H（0 价）指向 H2O 中的 H（+1 价），桥上写"失去 2×e−，化合价升高，被氧化"。

单线桥法：只在反应物一侧画一座桥，从失电子元素（还原剂中）直接指向得电子元素（氧化剂中），桥上只写电子转移的总数"2e−"，不写"得到/失去"。箭头方向本身就表示了电子的流向。

适用边界：双线桥信息全，适合分析概念；单线桥简洁，适合快速标注电子转移数。考试若题目无特别要求，两种都算规范；但单线桥上多写"失"字、双线桥上只写"2e−"不写得失，都是常见扣分点。

2.4 氧化还原反应四大规律

规律一 · 守恒律

内容：氧化还原反应中，氧化剂得电子总数 = 还原剂失电子总数（表现为化合价降低总数 = 化合价升高总数）。

用途：配平方程式的唯一依据；电子守恒计算的底层原理。例：配平 Fe + Cl2 → FeCl3，Fe 升 3 价、Cl 降 1×2=2 价（每分子 Cl2），最小公倍数 6 ⇒ 2Fe + 3Cl2 = 2FeCl3。

规律二 · 强弱律

内容：在能自发进行的氧化还原反应中，"强制弱"——

氧化剂（强氧化性）+ 还原剂（强还原性）→ 还原产物（弱还原性）+ 氧化产物（弱氧化性）

即：氧化性：氧化剂 > 氧化产物；还原性：还原剂 > 还原产物。

用途：① 由已知反应判断强弱顺序；② 反过来由强弱顺序判断陌生反应能否发生（满足"强制弱"才可能发生）。

规律三 · 先后律

内容：一种氧化剂遇到多种还原剂时，还原性强的先被氧化；一种还原剂遇到多种氧化剂时，氧化性强的先被还原。

经典实例：向 FeBr2 溶液中通入 Cl2，还原性 Fe2+ > Br−，故 Cl2 少量时只氧化 Fe2+（2Fe2+ + Cl2 = 2Fe3+ + 2Cl−），过量时才继续氧化 Br−；向 FeI2 溶液中通入 Cl2，还原性 I− > Fe2+，先氧化的是 I−。

用途：解释"分步反应"、书写与量有关的离子方程式、判断反应顺序。

规律四 · 价态律

内容（三条）：

  • 最高价只氧化、最低价只还原、中间价两头兼：如 S 元素中，浓 H2SO4（S 为 +6 最高价）只有氧化性，S2−（−2 最低价）只有还原性，SO2（+4 中间价）遇强氧化剂作还原剂、遇强还原剂作氧化剂。
  • 归中不交叉：同种元素的高价与低价反应向中间价靠拢，但价态只靠拢、不相交。例：2H2S + SO2 = 3S↓ + 2H2O，−2 价升到 0、+4 价降到 0，都停在 0 价。
  • 相邻价态不反应：同种元素相邻价态之间不发生氧化还原。例：SO2（+4）与浓 H2SO4（+6）相邻，故可用浓硫酸干燥 SO2；Fe2+ 与 Fe3+ 之间也不反应。

歧化与归中：歧化反应是同一物质中同种元素同一价态"向两边走"（如 Cl2 + H2O ⇌ HCl + HClO，0 价 Cl 一部分升 +1、一部分降 −1）；归中反应是"向中间走"。两者电子转移数都只按一个变价原子计算。

2.5 氧化性、还原性强弱的比较

比较方法原理与示例
① 反应方向法（强弱律）由 2FeCl3 + 2KI = 2FeCl2 + 2KCl + I2 知氧化性 Fe3+ > I2；由 Cl2 + 2Fe2+ = 2Cl− + 2Fe3+ 知氧化性 Cl2 > Fe3+。合起来：Cl2 > Fe3+ > I2。
② 金属/非金属活动性顺序金属活动性 K>Ca>Na>Mg>Al>Zn>Fe>Sn>Pb>(H)>Cu>Hg>Ag，单质还原性依次减弱，对应阳离子氧化性依次增强：K+<Ca2+<Na+<Mg2+<Al3+<Zn2+<Fe2+<H+<Cu2+<Fe3+<Ag+。非金属活动性 F2>Cl2>Br2>I2>S，单质氧化性依次减弱，对应阴离子还原性依次增强：F−<Cl−<Br−<I−<S2−。
③ 反应条件法越容易发生反应，氧化/还原性越强。如 KMnO4 常温即可氧化浓盐酸制 Cl2，MnO2 需加热，O2 需催化剂加热 ⇒ 氧化性 KMnO4 > MnO2 > O2。
④ 变价程度法Cl2 把 Fe 氧化到 +3 价（2Fe + 3Cl2 → 2FeCl3），S 只能把 Fe 氧化到 +2 价（Fe + S → FeS）⇒ 氧化性 Cl2 > S。
⑤ 浓度与酸碱性修正浓 HNO3 氧化性强于稀 HNO3；KMnO4 在酸性条件下氧化性最强（产物 Mn2+）。
⑥ 电化学方法（高二前置了解）原电池中负极金属的还原性强于正极金属；电解池中阳极先放电的离子还原性强。学完 3.15 节后回头用。
必背两条链

氧化性链：MnO4−（H+）> Cl2 > Br2 > Fe3+ > I2 > S

还原性链：S2− > SO32− > I− > Fe2+ > Br− > Cl−

两条链互为镜像（氧化性强的单质，其阴离子还原性弱），背一条推一条即可。先后律的题目全靠它们。

2.6 化合价升降法配平

核心方法

五步骤：

  1. 标变价：标出反应前后化合价发生变化的元素，算出升、降的具体数值；
  2. 列升降：写出"升 a、降 b"（注意按一个化学式整体计算，如 H2C2O4 中 2 个 C 各升 1，共升 2）；
  3. 求总数：求 a 与 b 的最小公倍数，确定氧化剂、还原剂（及对应产物）的化学计量数；
  4. 配其余：用观察法依据原子守恒配平未变价的元素（通常按 金属 → 酸根 → H → O 的顺序）；
  5. 查守恒：最后检查每种原子个数守恒；离子方程式还要检查电荷守恒。

缺项配平技巧：题目只给部分物质时，缺的通常是 H2O、H+（酸性）、OH−（碱性）。判断方法：先配平变价元素，再比较两边 O、H 原子数和电荷数——酸性溶液用 H+ 和 H2O 找平，碱性溶液用 OH− 和 H2O 找平。

两个标准配平示范

示范 1（化学方程式，重铬酸钾氧化亚铁）：K2Cr2O7 + FeSO4 + H2SO4 → Cr2(SO4)3 + Fe2(SO4)3 + K2SO4 + H2O

Cr：+6→+3，每个 K2Cr2O7 含 2 个 Cr，共降 6；Fe：+2→+3，升 1。最小公倍数 6 ⇒ K2Cr2O7 系数 1、FeSO4 系数 6；再依次配 Fe（Fe2(SO4)3 系数 3）、K（K2SO4 系数 1）、S（右边 SO42− 共 3+9+1=13，左边已有 6 ⇒ H2SO4 系数 7）、H（⇒ H2O 系数 7），得：

K2Cr2O7 + 6FeSO4 + 7H2SO4 = Cr2(SO4)3 + 3Fe2(SO4)3 + K2SO4 + 7H2O

检验：O 左 7+24+28 = 59，右 12+36+4+7 = 59 ✓；H 左 14 右 14 ✓。

示范 2（缺项离子方程式，酸性条件）：□MnO4− + □Fe2+ + □（　）→ □Mn2+ + □Fe3+ + □（　）

Mn 降 5、Fe 升 1 ⇒ MnO4− 系数 1、Fe2+ 系数 5；比较 O 原子：左边多 4 个 O，酸性条件下用 H+ 结合成 H2O ⇒ 左边补 8H+、右边补 4H2O，得：

MnO4− + 5Fe2+ + 8H+ = Mn2+ + 5Fe3+ + 4H2O

检验电荷：左 −1+10+8 = +17，右 +2+15 = +17 ✓；O 左 4 右 4 ✓。

即学即练 · 配平三题

先盖住答案自测：

① □FeS2 + □O2 → □Fe2O3 + □SO2（黄铁矿煅烧，硫酸工业第一步）

② □Cu + □H2SO4（浓）→ □CuSO4 + □SO2↑ + □H2O

③ □Cl2 + □NaOH → □NaCl + □NaClO3 + □H2O（热浓碱中歧化）

答案与要点：

① 4FeS2 + 11O2 → 2Fe2O3 + 8SO2。要点：FeS2 中 Fe 为 +2、S 为 −1，1 个 FeS2 共升 1+5×2 = 11 价；O 由 0→−2，每个 O2 降 4。最小公倍数 44 ⇒ FeS2×4、O2×11，再配 Fe、S。

② Cu + 2H2SO4（浓）→ CuSO4 + SO2↑ + 2H2O。要点：2 个 S 中只有 1 个变价（+6→+4 降 2），另 1 个 SO42− 只起酸性作用进入 CuSO4——千万别按"2 个 S 都降价"去配。

③ 3Cl2 + 6NaOH = 5NaCl + NaClO3 + 3H2O。要点：歧化反应从生成物倒推更顺：Cl−（降 1）与 ClO3−（升 5）按 5∶1 搭配 ⇒ NaCl 系数 5、NaClO3 系数 1，再推 Cl2 系数 3、NaOH 系数 6、H2O 系数 3。

2.7 电子守恒法计算

核心方法

原理：整个反应（或一连串反应）中，还原剂失去的电子总物质的量 = 氧化剂得到的电子总物质的量。

通式：n（还原剂）× 变价原子数 × 升高价数 = n（氧化剂）× 变价原子数 × 降低价数。

威力所在：多步反应不必写每一步方程式，只需抓住"最初还原剂"和"最终氧化剂"两端的价态变化，一步列式。例如测定铁矿石含量、滴定计算、金属与硝酸混合计算，用电子守恒往往比写方程式快 3 倍，还不易错。

典型应用场景：① 金属与硝酸/浓硫酸反应求气体量（金属失电子 = N 或 S 得电子）；② 多步连续反应首尾挂钩（如 S → H2S → SO2 一系列转化中转移电子总数）；③ 氧化还原滴定与混合物组成计算（如 KMnO4 滴定 Fe2+）。核心心法：盯住"谁在失电子、谁在得电子"，中间过程一概不管。

2.8 附：化合价速查与特殊价态

工具箱

化合价规则：单质中元素化合价为 0；化合物中各元素正、负化合价代数和为 0；原子团（离子）中各元素化合价代数和等于该离子所带电荷数。

常见元素化合价口诀：一价氢氯钾钠银，二价氧钙钡镁锌；三铝四硅五价磷，二三铁、二四碳；二四六硫都齐全，铜汞二价最常见。

特殊价态警示（高考最爱在这里设陷阱）：

  • H2O2、Na2O2 中 O 为 −1 价（含过氧键），不是 −2；
  • Fe3O4 中 Fe 为 +2 与 +3 两种价态（可看作 FeO·Fe2O3），平均 +8/3；
  • 金属氢化物 NaH、CaH2 中 H 为 −1 价（H 得电子），遇水立即放出 H2（归中反应）；
  • NH4+ 中 N 为 −3 价；NH4NO3 中两个 N 价态不同（−3 与 +5）；
  • 有机物中用平均价态：H2C2O4（草酸）中 C 为 +3 价，CH3COOH 中两个 C 平均为 0 价；
  • KClO3 中 Cl 为 +5 价，HClO 中 Cl 为 +1 价——氯从 −1 到 +7 价态齐全，是氧化还原题的"常驻嘉宾"。

速算技巧：求陌生化合物中某元素价态时，先标出已知价（K、Na、H 为 +1，O 通常为 −2），再按"代数和为零"列方程。如 K2Cr2O7：2×(+1) + 2x + 7×(−2) = 0，解得 Cr 为 +6。

三、三重表征贯通

组 1：氢气还原氧化铜

宏观表征

黑色 CuO 粉末在氢气流中加热，逐渐变成光亮的红色，试管口有无色液珠凝结；继续通 H2 至冷却，防止红色固体重新变黑。

微观表征

CuO 中的 Cu（+2 价）得到 2 个电子被还原为 Cu 原子；H2 中的 H（0 价）各失去 1 个电子变为 +1 价，与 O 结合成 H2O。电子从 H 流向 Cu，H2 是还原剂，CuO 是氧化剂。

符号表征

CuO(s) + H2(g) → Cu(s) + H2O(l)

双线桥：Cu（+2→0）得 2e−；H（0→+1）失 2×e−。得、失电子总数均为 2e−。

组 2：锌置换硫酸铜

宏观表征

银白色锌片浸入蓝色 CuSO4 溶液，锌片表面很快覆盖一层红色固体，溶液蓝色逐渐变浅直至无色，烧杯壁微微发热（放热）。

微观表征

Zn 原子把 2 个电子直接转移给溶液中的 Cu2+：Zn 变成 Zn2+ 进入溶液，Cu2+ 变成 Cu 原子沉积在锌片表面。SO42− 全程旁观。电子从 Zn 流向 Cu2+，这就是原电池（3.15 节）的雏形。

符号表征

Zn(s) + CuSO4(aq) → ZnSO4(aq) + Cu(s)

Zn + Cu2+ = Zn2+ + Cu

单线桥：从 Zn 指向 Cu，桥上标"2e−"（只标总数，不写得失）。

组 3：氯化铁腐蚀铜板（印刷电路板原理）

宏观表征

覆铜板浸入棕黄色 FeCl3 溶液，裸露的铜逐渐溶解变薄，溶液颜色由棕黄逐渐转为蓝绿色（生成 Cu2+ 与 Fe2+ 的混合色）。

微观表征

Fe3+（Fe 为 +3 价）从 Cu 原子处夺得 1 个电子变为 Fe2+；Cu 原子失去 2 个电子变成 Cu2+ 进入溶液。1 个 Cu 需要 2 个 Fe3+ 来"接走"它的电子。

符号表征

2FeCl3 + Cu = 2FeCl2 + CuCl2

2Fe3+ + Cu = 2Fe2+ + Cu2+

电子转移：每反应 1 mol Cu，转移 2 mol 电子；氧化性 Fe3+ > Cu2+。

组 4：氯气置换碘化钾中的碘

宏观表征

黄绿色氯气通入无色 KI 溶液，溶液逐渐变为黄褐色；加入 CCl4 振荡后静置，液体分层，下层 CCl4 层呈紫（红）色，上层水层颜色变浅。

微观表征

Cl2 分子从 I− 处夺走电子：两个 Cl 原子各得 1 个电子变成 Cl−，两个 I− 各失 1 个电子结合成 I2 分子。I2 在 CCl4 中的溶解度远大于在水中，被"萃取"到下层显出特征紫色。

符号表征

Cl2(g) + 2KI(aq) → 2KCl(aq) + I2

Cl2 + 2I− = 2Cl− + I2

氧化性 Cl2 > I2，还原性 I− > Cl−——强弱律的直接证据。

组 5：钠与水的反应

宏观表征

金属钠投入水中：浮在水面、熔成小球、四处游动、发出嘶嘶声；滴入酚酞后溶液变红。反应放热明显，钠球可能熔成光亮的小球甚至"着火"。

微观表征

Na 原子把最外层的 1 个电子直接交给 H2O 中 +1 价的 H：Na 变成 Na+ 进入溶液，H 得电子后两两结合成 H2 逸出，同时生成的 OH− 使酚酞变红。"浮、熔、游、嘶、红"五个字，全是微观电子转移的宏观投影。

符号表征

2Na(s) + 2H2O(l) → 2NaOH(aq) + H2↑(g)

2Na + 2H2O = 2Na+ + 2OH− + H2↑

每 1 mol Na 反应转移 1 mol 电子；Na 是还原剂，H2O 是氧化剂（其中 H 由 +1 降到 0）。

四、典型例题分步拆解

例题 1 · 基本概念与电子转移数

题目：在反应 3NO2 + H2O = 2HNO3 + NO 中，氧化剂与还原剂的物质的量之比为（　　）；标准状况下 3.36 L NO2 完全反应时转移电子的物质的量为（　　）。

【思路点拨】这是歧化反应——NO2 中 +4 价的 N 一部分升到 +5（HNO3）、一部分降到 +2（NO）。氧化剂和还原剂是同一种物质的不同部分，比例要从产物中 N 的来源反推。

1

标变价：HNO3 中 N 为 +5 价（升高 1），NO 中 N 为 +2 价（降低 2）。

2

看产物来源：3 个 NO2 中有 2 个 N 升高（生成 2HNO3），这 2 个 NO2 作还原剂；1 个 N 降低（生成 1NO），这个 NO2 作氧化剂。故 n（氧化剂）∶n（还原剂）= 1∶2。

3

算电子转移：由方程式，每 3 mol NO2 反应转移 2 mol 电子（2 个 N 各失 1e−，共失 2e−；1 个 N 得 2e−）。n(NO2) = 3.36 L ÷ 22.4 L/mol = 0.15 mol，故转移电子 n(e−) = 0.15 × (2/3) = 0.1 mol。

4

验证：0.15 mol NO2 中 0.1 mol 作还原剂，失电子 0.1×1 = 0.1 mol；0.05 mol 作氧化剂，得电子 0.05×2 = 0.1 mol。得失相等 ✓。

【答案】氧化剂与还原剂之比 1∶2；转移电子 0.1 mol（约 6.02×1022 个）

【方法总结】歧化/归中反应的电子转移数，只按一侧（失电子侧或得电子侧）的数值计算，千万不能把两侧相加。看清产物中各变价原子的"归宿"，是确定氧化剂、还原剂比例的唯一可靠途径。

例题 2 · 陌生氧化还原方程式配平

题目：配平下列化学方程式（草酸使酸性高锰酸钾溶液褪色，是氧化还原滴定的经典反应）：

□KMnO4 + □H2C2O4 + □H2SO4 → □K2SO4 + □MnSO4 + □CO2↑ + □H2O

【思路点拨】化合价升降法五步走。难点在 H2C2O4：C 为 +3 价，一个化学式含 2 个 C，升价要按"每分子升 2"计算。

1

标变价：Mn：+7（KMnO4）→ +2（MnSO4），每个 Mn 降 5；C：+3（H2C2O4）→ +4（CO2），每个 C 升 1，每个 H2C2O4 含 2 个 C，共升 2。

2

求总数：升 2 与降 5 的最小公倍数是 10 ⇒ KMnO4 系数 = 10÷5 = 2；H2C2O4 系数 = 10÷2 = 5。

3

定变价产物：MnSO4 系数 = 2（Mn 守恒）；CO2 系数 = 5×2 = 10（C 守恒）。

4

配其余（K → S → H → O）：K 守恒 ⇒ K2SO4 系数 1；S 守恒 ⇒ 右边 SO42− 共 1+2 = 3 个 ⇒ H2SO4 系数 3；H 守恒 ⇒ 左边 H 共 5×2+3×2 = 16 ⇒ H2O 系数 8。

5

查 O 守恒：左边 O = 2×4 + 5×4 + 3×4 = 40；右边 O = 4 + 8 + 20 + 8 = 40。✓ 配平完成。

【答案】2KMnO4 + 5H2C2O4 + 3H2SO4 = K2SO4 + 2MnSO4 + 10CO2↑ + 8H2O

【方法总结】① 变价元素的原子个数要先数清（H2C2O4 的 2 个 C、K2Cr2O7 的 2 个 Cr 是高考最常挖的坑）；② 配平顺序"变价元素 → 金属 → 酸根 → H → O"；③ 最后必须用 O（或 H）原子守恒做检验。若写成离子方程式：2MnO4− + 5H2C2O4 + 6H+ = 2Mn2+ + 10CO2↑ + 8H2O，还要再查电荷守恒（左边 −2+6=+4，右边 +4 ✓）。

例题 3 · 电子守恒计算

题目：24 mL 0.05 mol/L 的 Na2SO3 溶液，恰好与 20 mL 0.02 mol/L 的 K2Cr2O7 溶液完全反应，Na2SO3 被氧化为 Na2SO4。则 Cr 元素在还原产物中的化合价为（　　）

A. +6　　B. +3　　C. +2　　D. 0

【思路点拨】"恰好完全反应"⇒ 得失电子总数相等。列出两端的 n × 变价原子数 × 价态变化，直接解出 Cr 的最终价态，不必写方程式。

1

算还原剂失电子：n(Na2SO3) = 0.024 L × 0.05 mol/L = 1.2×10−3 mol；S：+4 → +6，每个 S 失 2e−。失电子总量 = 1.2×10−3 × 2 = 2.4×10−3 mol。

2

算氧化剂中变价原子数：n(K2Cr2O7) = 0.020 L × 0.02 mol/L = 4×10−4 mol；每个 Cr2O72− 含 2 个 Cr，故 n(Cr) = 8×10−4 mol。

3

电子守恒列式：设 Cr 在产物中为 +x 价，每个 Cr 得 (6−x)e−。8×10−4 × (6−x) = 2.4×10−3，解得 6−x = 3，x = 3。

4

复核：8×10−4 mol Cr 各得 3e− ⇒ 得电子 2.4×10−3 mol，与失电子总量相等 ✓。且 +3 价是 Cr 的常见稳定价态（Cr3+），合理。

【答案】B（+3 价）

【方法总结】电子守恒法三件套：① 找准变价元素的起止价态；② 算清变价原子的物质的量（化学式中的下标必须乘进去，Cr2O72− 的 2 是本题唯一的坑）；③ 一端失 = 一端得，列一元一次方程。同类题：XO4− 被 SO32− 还原、Cl2 氧化 Fe2+ 求用量比，全部同法。

例题 4 · 强弱律 + 配平 + 计算综合

题目：已知氧化性 Cl2 > Fe3+ > I2。3.84 g 铜粉与足量稀硝酸反应：3Cu + 8HNO3（稀）= 3Cu(NO3)2 + 2NO↑ + 4H2O。求：（1）转移电子的物质的量；（2）标准状况下生成 NO 的体积；（3）被还原的 HNO3 的物质的量。

【思路点拨】铜与硝酸的反应中，硝酸身兼两职：一部分作氧化剂（N：+5→+2，被还原为 NO），一部分只提供酸性（NO3− 留在 Cu(NO3)2 中价态不变）。先把"被还原的硝酸"和"总硝酸"区分开。

1

算 n(Cu)：3.84 g ÷ 64 g/mol = 0.06 mol。

2

（1）转移电子：Cu：0 → +2，每个 Cu 失 2e−。n(e−) = 0.06 × 2 = 0.12 mol。

3

（2）NO 体积：由方程式比例 n(NO) = (2/3)n(Cu) = 0.04 mol；也可用电子守恒验证：N 由 +5 降到 +2 得 3e−，0.12÷3 = 0.04 mol ✓。V(NO) = 0.04 × 22.4 = 0.896 L。

4

（3）被还原的 HNO3：被还原的硝酸全部变成 NO，N 原子守恒 ⇒ n（被还原 HNO3) = n(NO) = 0.04 mol。（对比：参加反应的 HNO3 总量 = (8/3)×0.06 = 0.16 mol，其中 0.12 mol 只起酸的作用。）

【答案】（1）0.12 mol　（2）0.896 L　（3）0.04 mol

【方法总结】金属与硝酸问题的"两笔账"：被还原的硝酸 = 气体中 N 的物质的量；起酸作用的硝酸 = 硝酸盐中 NO3− 的物质的量 = 金属失电子数 × 金属所带电荷。总量是两笔之和。用电子守恒可以直接从金属跳到气体，跳过配平方程式，是此类计算的最快路径。

例题 5 · 先后律判断反应顺序

题目：向 100 mL 含 0.1 mol/L FeI2 的溶液中缓缓通入标准状况下的 Cl2。已知还原性 I− > Fe2+。写出通入 Cl2 的体积分别为 56 mL 和 224 mL 时发生反应的离子方程式。

【思路点拨】先后律：Cl2 先氧化还原性强的 I−，I− 耗尽后才轮到 Fe2+。先算各离子的物质的量，再按 Cl2 的量"对号入座"。

1

算家底：n(FeI2) = 0.1 L × 0.1 mol/L = 0.01 mol ⇒ n(I−) = 0.02 mol，n(Fe2+) = 0.01 mol。氧化 I− 需 Cl2：2I− + Cl2 = I2 + 2Cl− ⇒ 0.01 mol；氧化 Fe2+ 需 Cl2：2Fe2+ + Cl2 = 2Fe3+ + 2Cl− ⇒ 0.005 mol。全部氧化共需 0.015 mol Cl2（标况 336 mL）。

2

56 mL 时：n(Cl2) = 0.056÷22.4 = 0.0025 mol < 0.01 mol，只够氧化部分 I− ⇒ 反应只有 Cl2 + 2I− = 2Cl− + I2。

3

224 mL 时：n(Cl2) = 0.01 mol，恰好把 0.02 mol I− 全部氧化完，Fe2+ 尚未被触及 ⇒ 反应仍只有 Cl2 + 2I− = 2Cl− + I2。（若通到 336 mL 以上，才会出现 2Fe2+ + Cl2 = 2Fe3+ + 2Cl−。）

【答案】两种体积下发生的均为 Cl2 + 2I− = 2Cl− + I2；224 mL 时 I− 恰好被完全氧化，Fe2+ 尚未反应。

【方法总结】"先后律+定量"题三步：① 列出所有可被氧化的离子及其还原性顺序；② 算清每种离子完全反应所需的氧化剂量；③ 把实际投入量与各级"门槛"比较，落在哪个区间就只发生哪几步。这类题在高三复习中还会升级为"分阶段写总反应式"，高一先把顺序判断练熟。

例题 6 · 归中反应中的电子转移

题目：已知反应 KClO3 + 6HCl（浓）= KCl + 3Cl2↑ + 3H2O。回答：（1）氧化剂与还原剂的物质的量之比；（2）按 1 mol KClO3 计，反应转移电子的物质的量；（3）氧化产物与还原产物的质量之比。

【思路点拨】这是归中反应：KClO3 中 +5 价 Cl 降到 0 价，HCl 中 −1 价 Cl 升到 0 价，两头的 Cl 在 Cl2（0 价）"会师"。注意 6 个 HCl 中只有 5 个变价，1 个 Cl− 进入 KCl 价态不变——这正是"归中不交叉"：+5 价 Cl 不会降到 −1 去。

1

标变价、定角色：KClO3（Cl +5→0）得 5e−，是氧化剂；5 个 HCl（Cl −1→0）各失 1e−，共失 5e−，作还原剂；另 1 个 HCl 只起酸性作用。

2

（1）求比例：n（氧化剂）∶n（还原剂）= 1∶5。

3

（2）算电子转移：任取一侧——5 mol Cl 各失 1e− ⇒ 每 1 mol KClO3 反应转移 5 mol 电子（不是 6 mol！6 个 HCl 里有 1 个是"打酱油"的）。

4

（3）算产物比：3 mol Cl2 共 6 个 Cl 原子，来自 HCl 升价的 5 个 Cl 是氧化产物，来自 KClO3 降价的 1 个 Cl 是还原产物，原子个数比 5∶1，质量比同为 5∶1。

【答案】（1）1∶5　（2）5 mol　（3）5∶1

【方法总结】归中反应三问模板：① 按产物中变价原子的"来源"拆分角色比例；② 电子转移只算一侧；③ "氧化产物∶还原产物"按升、降两边的原子个数比。KClO3 + 6HCl 这个反应是归中题的"祖师爷"，务必做到默写级别。

例题 7 · 氧化性还原性强弱比较

题目：已知下列三个反应均能自发发生：

① 2Fe3+ + 2I− = 2Fe2+ + I2；② 2Fe2+ + Br2 = 2Fe3+ + 2Br−；③ Cl2 + 2Br− = 2Cl− + Br2。

则氧化性由强到弱的顺序为（　　）；若向含等浓度 I−、Br−、Fe2+ 的混合溶液中缓慢通入少量 Cl2，最先被氧化的是（　　）。

【思路点拨】用强弱律：每个自发反应中都满足"氧化剂 > 氧化产物"，把三个不等式串成链即可。

1

逐个提取不等式：① 氧化剂 Fe3+、氧化产物 I2 ⇒ 氧化性 Fe3+ > I2；② Br2 > Fe3+；③ Cl2 > Br2。

2

串成链：Cl2 > Br2 > Fe3+ > I2，与必背链一致 ✓。

3

推还原性、判先后：氧化性强的单质对应阴离子还原性弱 ⇒ 还原性 I− > Fe2+ > Br− > Cl−。按先后律，少量 Cl2 先氧化还原性最强的 I−。

【答案】氧化性 Cl2 > Br2 > Fe3+ > I2；最先被氧化的是 I−。

【方法总结】"给反应排顺序"题三步：① 每个反应中锁定氧化剂与氧化产物（反应物中找降价的，生成物中找升价产物）；② 写"剂 > 产物"不等式；③ 串联成链。若两个反应推出互相矛盾的不等式，则必有一个反应不能自发发生——用"强制弱"直接判伪。

例题 8 · 多步反应的电子守恒（首尾挂钩）

题目：将 0.1 mol Fe2O3 与足量 CO 在高温下充分反应，再将所得铁全部投入足量稀硫酸中。求两个过程中转移电子的总物质的量。

【思路点拨】多步反应不必逐步细算中间物——盯住每个过程中"谁失电子、谁得电子"，分别用电子守恒列式，最后相加。

1

过程一：Fe2O3 + 3CO → 2Fe + 3CO2。Fe：+3→0，0.1 mol Fe2O3 含 0.2 mol Fe，得电子 0.2×3 = 0.6 mol（即 CO 失电子 0.6 mol）。

2

过程二：Fe + H2SO4 = FeSO4 + H2↑。生成的 0.2 mol Fe 全部溶解，Fe：0→+2，失电子 0.2×2 = 0.4 mol（即 H+ 得电子 0.4 mol）。

3

合计并复核：0.6 + 0.4 = 1.0 mol。复核：Fe 从 +3 价最终到 +2 价，0.2 mol Fe 净得 0.2 mol 电子；CO 失 0.6、H+ 得 0.4，总账闭合 ✓。

【答案】两个过程共转移电子 1.0 mol

【方法总结】多步反应的总原则：中间产物只是"摆渡人"，盯住每个氧化还原过程的两端即可。若全程起点、终点明确，甚至可以一次守恒完成；但初学阶段建议像本题一样分步列式，稳妥不丢分。

例题 9 · 归中反应综合计算

题目：工业上用浓盐酸与氯酸钾反应制备二氧化氯（ClO2，一种高效消毒剂）：2KClO3 + 4HCl（浓）= 2KCl + 2ClO2↑ + Cl2↑ + 2H2O。回答：（1）氧化剂与还原剂的物质的量之比；（2）每生成 1 mol Cl2，转移电子的物质的量；（3）若生成标准状况下 4.48 L ClO2，转移电子多少摩尔？

【思路点拨】本反应中 Cl 出现"一支降、一支升"：KClO3 中 +5 价 Cl 降到 +4（ClO2），HCl 中 −1 价 Cl 升到 0（Cl2）。先把每个变价原子的起点终点标清，再验证得失平衡。

1

标变价：KClO3 中 Cl：+5→+4，每个降 1（得 1e−），2 个共降 2；HCl 中 Cl：−1→0（生成 Cl2），每个升 1，2 个共升 2。得失平衡 ✓（另 2 个 HCl 的 Cl 进入 KCl，不变价）。

2

（1）角色比例：氧化剂是 KClO3（2 mol）；还原剂是 4 mol HCl 中被氧化的 2 mol ⇒ n（氧化剂）∶n（还原剂）= 1∶1。

3

（2）电子转移：每生成 1 mol Cl2，有 2 mol Cl 由 −1 升到 0 ⇒ 转移 2 mol 电子。从 KClO3 侧验证：生成 1 mol Cl2 的同时生成 2 mol ClO2，2 个 Cl 各得 1e−，同样是 2 mol ✓。

4

（3）定量计算：n(ClO2) = 4.48 ÷ 22.4 = 0.2 mol。由方程式，每生成 2 mol ClO2 转移 2 mol 电子 ⇒ 0.2 mol ClO2 对应转移 0.2 mol 电子。复核：0.2 mol ClO2 中 Cl 各由 +5 降到 +4，得电子 0.2×1 = 0.2 mol；同时生成的 0.1 mol Cl2 由 0.2 mol −1 价 Cl 升高而来，失电子 0.2 mol，得失相等 ✓。

【答案】（1）1∶1　（2）2 mol　（3）0.2 mol

【方法总结】"多元素变价、同元素双向变价"是高考难题的常见形态。破解步骤：① 逐元素标出所有变价原子的起止价态；② 分别算失与得的总数，先验证平衡；③ 再看题目问的是"转移总数"还是"某一侧变化"，按需取值。电子守恒是否闭合，就是配平是否正确的最好检验。

例题 10 · Na2O2 与水的自身氧化还原

题目：已知反应 2Na2O2 + 2H2O = 4NaOH + O2↑。回答：（1）该反应是否为氧化还原反应？若是，指出氧化剂与还原剂；（2）每消耗 1 mol Na2O2，转移电子多少摩尔？（3）若生成 0.1 mol O2，转移电子多少摩尔？

【思路点拨】先标价态：Na2O2 中 O 为 −1 价（过氧键），H2O 中 O 为 −2、H 为 +1，Na 始终为 +1。只有 O 的价态在变——而且是"自己变自己"的歧化。

1

（1）定性：Na2O2 中 O（−1）一部分升到 0（O2），一部分降到 −2（NaOH 中的 O）⇒ 是氧化还原反应；Na2O2 既是氧化剂又是还原剂（歧化反应）。水既不是氧化剂也不是还原剂——水中 O、H 价态都没变！

2

（2）电子转移：2 mol Na2O2 含 4 mol O（−1）。其中 2 mol O 各失 1e− → O2（共失 2 mol e−）；另 2 mol O 各得 1e− → NaOH（共得 2 mol e−）。即每 2 mol Na2O2 转移 2 mol e− ⇒ 每 1 mol Na2O2 转移 1 mol 电子。

3

（3）计算：生成 0.1 mol O2 需 0.2 mol Na2O2 ⇒ 转移 0.2 × 1 = 0.2 mol 电子。直接从 O2 侧验证：0.1 mol O2 含 0.2 mol O 原子，各失 1e− ⇒ 0.2 mol ✓。

【答案】（1）是氧化还原反应，Na2O2 既是氧化剂又是还原剂　（2）1 mol　（3）0.2 mol

【方法总结】Na2O2 类歧化反应三大坑：① 把水当氧化剂/还原剂（错，水中元素价态不变）；② 电子转移按 2 mol Na2O2 算成 4 mol（错，只算一侧 = 2 mol）；③ 把 O 的价态按 −2 算（错，Na2O2 中是 −1）。同样的模型也适用于 Na2O2 与 CO2 的反应。

例题 11 · 缺项离子方程式配平

题目：配平下列离子方程式（酸性条件）：

□Cr2O72− + □Fe2+ + □（　）→ □Cr3+ + □Fe3+ + □（　）

【思路点拨】先按化合价升降配变价元素，再数 O 的差值决定补水位置，酸性条件下用 H+ 与 H2O 找平，最后查电荷守恒。

1

标变价：Cr：+6→+3，每个 Cr2O72− 含 2 个 Cr，共降 6；Fe：+2→+3，升 1。

2

定变价系数：最小公倍数 6 ⇒ Cr2O72− 系数 1，Fe2+ 系数 6；故 Cr3+ 系数 2，Fe3+ 系数 6。

3

补缺项：左边比右边多 7 个 O ⇒ 右边补 7H2O；右边比左边多 14 个 H ⇒ 左边补 14H+（酸性条件允许）。

4

查守恒：电荷——左边 −2+12+14 = +24，右边 2×3+6×3 = +24 ✓；O——左 7 右 7 ✓；H——左 14 右 14 ✓。

【答案】Cr2O72− + 6Fe2+ + 14H+ = 2Cr3+ + 6Fe3+ + 7H2O

【方法总结】缺项离子方程式配平"三守恒"闭环：电子守恒定变价系数 → 原子守恒定缺项 → 电荷守恒做总检。酸性环境只允许出现 H+ 与 H2O，碱性环境只允许出现 OH− 与 H2O——补错离子种类是最常见的扣分点。

五、易错点与成因

易错点 1

易错表现：认为"有单质参加或生成的反应一定是氧化还原反应"；或认为"氧化剂被氧化、还原剂被还原"。

错误成因：前者是把"常见情况"误当"判据"——3O2 → 2O3 有单质但无变价；后者是没分清"角色名（施动）"与"遭遇（受动）"，靠字面感觉答题。

正确理解：氧化还原的唯一判据是化合价是否变化；氧化剂得电子被还原，还原剂失电子被氧化，口诀"升失氧还、降得还氧"要形成条件反射。

避坑口诀："判据只看化合价；名字说别人，遭遇说自己。"

易错点 2

易错表现：歧化反应中把得、失电子数相加来求"转移电子数"。如 Cl2 + H2O ⇌ HCl + HClO，写成"转移 2e−"。

错误成因：误以为"失 1e− + 得 1e− = 2e−"。其实得与失是同一批电子的两个侧面——还原剂交出的，正是氧化剂收下的，相加等于把同一笔钱数了两遍。

正确理解：电子转移数 = 失电子总数 = 得电子总数，任取一侧计算即可。该反应中每 1 mol Cl2 反应只转移 1 mol 电子。

避坑口诀："得失是同一笔账，只算一头不相加。"

易错点 3

易错表现：单线桥上写"失去 2e−"，或双线桥上只写"2e−"不写得失；单线桥箭头方向画反。

错误成因：混淆两种桥法的书写约定。单线桥的箭头本身就表示电子流向（还原剂 → 氧化剂），再写"失去"就画蛇添足；双线桥连接的是同种元素的两种价态，不写得失就丢失了关键信息。

正确理解：单线桥——只标总数、不写得失、箭头由失电子元素指向得电子元素；双线桥——同元素相连、必须写"得到/失去"、得失总数相等。

避坑口诀："单线只数不写得失，双线得失缺一不可。"

易错点 4

易错表现：认为 H2O2 只作氧化剂；或认为浓硫酸能干燥 SO2 是"不反应说明 SO2 无还原性"。

错误成因：对价态律理解片面。H2O2 中 O 为 −1 中间价，遇强还原剂（如 Fe2+）显氧化性，遇强氧化剂（如 KMnO4）就作还原剂被氧化成 O2；SO2（S +4）与浓硫酸（S +6）是相邻价态，按价态律本就不反应，与还原性强弱无关。

正确理解：中间价态物质的"角色"取决于对手——"遇强则示弱，遇弱则逞强"；相邻价态不反应，所以浓硫酸可以干燥 SO2、Fe2+ 与 Fe3+ 能大量共存。

避坑口诀："中间价态看对手，相邻价态不交手。"

易错点 5

易错表现：配平时漏乘化学式中下标的变价原子数。如配平 K2Cr2O7 系列反应时按"每个化学式降 3"计算（应为 2×3=6）；或用 HNO3 与金属反应时写出生成 H2。

错误成因：前者是粗心——只看到"Cr 从 +6 到 +3 降 3"，忘了化学式里有 2 个 Cr；后者是套用了"金属+酸→氢气"的初中模板，不知道 HNO3 是强氧化性酸，与金属反应生成 NO 或 NO2，从不放 H2。

正确理解：升降价数一律按"一个化学式中所有变价原子的总变化"计算；见到 HNO3、浓 H2SO4 与金属反应，直接排除 H2，按氧化还原模型思考。

避坑口诀："下标先乘进价态；硝酸出马无氢气。"

易错点 6

易错表现：向 FeBr2 溶液通少量 Cl2 时，写成"先氧化 Br−"或"两种离子同时被氧化"。

错误成因：没记住还原性顺序（Fe2+ > Br−），也不理解"先后"的微观原因——Cl2 分子碰到谁就跟谁反应只是表象，热力学上优先夺取最容易失去电子的那个粒子的电子，反应体系中氧化还原总是按"强者先行"的顺序进行，直到强者耗尽。

正确理解：少量氧化剂只够"喂"还原性最强的离子。FeBr2 中先氧化 Fe2+；FeI2 中先氧化 I−。背熟还原性链 S2− > SO32− > I− > Fe2+ > Br− > Cl− 即可秒杀。

避坑口诀："强者优先吃饱，弱者排队等候。"

易错点 7

易错表现：把铜与稀硝酸反应中"被还原的硝酸"等同于"参加反应的硝酸"——认为 8 mol HNO3 全部被还原，或把只起酸性作用的部分也算成氧化剂。

错误成因：不知道硝酸在这类反应中身兼两职——一部分 N 由 +5 降到 +2（被还原，生成 NO），另一部分 N 价态不变（留在 Cu(NO3)2 中，只起酸性作用）。两者必须分账计算。

正确理解：以 3Cu + 8HNO3（稀）= 3Cu(NO3)2 + 2NO↑ + 4H2O 为例：8 mol HNO3 中被还原的只有 2 mol（变成 NO 的那部分），其余 6 mol 起酸性作用。同理，铜与浓硫酸反应中，浓硫酸也兼作氧化剂与酸。

避坑口诀："硝酸两本账：变价的是氧化剂，不变价的是酸性。"

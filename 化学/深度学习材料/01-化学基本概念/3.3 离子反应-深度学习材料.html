3.3 离子反应

高中化学 · 深度学习材料 · 面向 2029 届云南高考

离子反应是水溶液中反应的真实面貌——它把"物质之间反应"推进到"离子之间反应"的微观层次。本章的离子方程式正误判断与限定条件下的离子共存，是高考选择题的常驻题型，也是你进入高中后遇到的第一个"规范性大考"。学透它，你就握住了打开水溶液化学大门的钥匙。

二、核心概念精讲

2.1 电解质与非电解质

核心概念

电解质：在水溶液中或熔融状态下能够导电的化合物。

非电解质：在水溶液中和熔融状态下都不能导电的化合物。

为什么导电？（微观解释）电流的本质是电荷的定向移动。溶液要导电，必须存在自由移动的离子。NaCl 固体中 Na+ 与 Cl− 被固定在晶格中，不导电；溶于水后，水分子把两种离子"拆散"（电离），离子可以自由移动，于是导电。熔融（加热熔化）同样能使离子获得自由。

适用边界与常见混淆：

  • 两个概念都只对化合物有效。铜丝、石墨能导电，但它们是单质，既不是电解质也不是非电解质；盐酸、NaCl 溶液能导电，但它们是混合物，同样两者都不是。
  • "能导电"≠"是电解质"。CO2 的水溶液能导电，是因为 CO2 与水生成的 H2CO3 电离出离子，而不是 CO2 自身电离——CO2 是非电解质，H2CO3 才是电解质。同理 SO2、SO3、NH3 都是非电解质（NH3·H2O 才是弱电解质）。
  • 电解质本身不一定导电：固态 NaCl、液态纯 H2SO4（硫酸分子未电离）都不导电，只有溶于水或熔融后才导电。

2.2 电离与电离方程式

核心概念

电离：电解质溶于水或受热熔化时，离解成自由移动的离子的过程。

为什么不需要通电？电离的动力来自水分子对离子的"包裹拉扯"（水合作用），或高温对晶格的破坏，是自发过程。通电那是"电解"（3.15 节）——电解是用外加强迫让离子发生氧化还原反应。电离是导电和电解的前提，但电离本身不需要电，这是高频概念辨析点。

电离方程式书写规则：

  • 强电解质用"="（完全电离）：NaCl = Na+ + Cl−；H2SO4 = 2H+ + SO42−；Ba(OH)2 = Ba2+ + 2OH−；
  • 弱电解质用"⇌"（部分电离、可逆）：CH3COOH ⇌ CH3COO− + H+；NH3·H2O ⇌ NH4+ + OH−；
  • 多元弱酸分步电离，以第一步为主：H2CO3 ⇌ H+ + HCO3−（第一步，为主），HCO3− ⇌ H+ + CO32−（第二步，微弱）。第二步要从已带负电的 HCO3− 中再"拽"出一个 H+，静电吸引使它难得多；
  • 多元弱碱一步写完：Fe(OH)3 ⇌ Fe3+ + 3OH−；
  • 酸式盐分情况：NaHCO3 = Na+ + HCO3−（HCO3− 是弱酸酸根，不再拆）；NaHSO4 在水溶液中 = Na+ + H+ + SO42−（HSO4− 完全电离），而熔融状态下 NaHSO4 = Na+ + HSO4−。
三种"式子"辨析研究对象示例
电离方程式一种电解质自身如何离解成离子Na2CO3 = 2Na+ + CO32−
化学方程式物质之间如何反应（宏观账目）Na2CO3 + 2HCl = 2NaCl + H2O + CO2↑
离子方程式反应中真正参与的离子（微观实质）CO32− + 2H+ = H2O + CO2↑

小练习（写完对照自查）：写出 HNO3、NaOH、(NH4)2SO4、H2SO3、NaHCO3 的电离方程式。答案：HNO3 = H+ + NO3−；NaOH = Na+ + OH−；(NH4)2SO4 = 2NH4+ + SO42−；H2SO3 ⇌ H+ + HSO3−（主）、HSO3− ⇌ H+ + SO32−（次）；NaHCO3 = Na+ + HCO3−。

2.3 强电解质与弱电解质

核心概念

强电解质：在水溶液中完全电离的电解质。包括：

  • 六大强酸：HCl、HBr、HI、HNO3、H2SO4、HClO4；
  • 四大强碱：NaOH、KOH、Ba(OH)2、Ca(OH)2；
  • 绝大多数盐：NaCl、Na2CO3、NH4Cl……包括难溶盐 BaSO4、CaCO3、AgCl。

弱电解质：在水溶液中只部分电离的电解质。包括：

  • 弱酸：CH3COOH、H2CO3、H2SO3、H2S、HF、HClO、H3PO4；
  • 弱碱：NH3·H2O 及 Mg(OH)2、Fe(OH)3、Cu(OH)2 等难溶性碱；
  • 水：极微弱地电离 H2O ⇌ H+ + OH−。

为什么 BaSO4 是强电解质？强弱看的是"溶解的部分是否完全电离"，而不是"溶得多不多"。BaSO4 虽然溶解度极小，但溶进水里那一小部分100% 电离为 Ba2+ 和 SO42−，所以它是强电解质。反过来，CH3COOH 与水任意比互溶，却只有约 1% 的分子电离，是弱电解质。电解质的强弱与溶解度大小无关，这是本章最高频的判断陷阱。

常见混淆对：强电解质 ↔ 导电能力强的溶液。错！导电能力取决于溶液中离子浓度。极稀的 NaCl 溶液（强电解质）导电能力可能比浓氨水（弱电解质部分电离）还弱。"电解质强弱"与"溶液导电强弱"是两回事。

导电能力比较

溶液导电能力的强弱只取决于单位体积内自由移动离子的数目（离子浓度）和离子所带电荷。同浓度时，强电解质溶液导电能力一般强于弱电解质；但 0.0001 mol/L 的盐酸可能比 1 mol/L 的醋酸导电还弱。所以"醋酸是弱电解质，其溶液导电能力一定弱"是错误的——一切看浓度。

2.4 离子反应与离子方程式

核心概念

离子反应：有离子参加（或生成）的反应。在溶液中，强酸、强碱、可溶性盐都以自由离子形式存在，反应的真正参与者是某些离子，其余离子只是"旁观者"。

离子方程式：用实际参加反应的离子符号来表示反应的式子。它不仅表示一个具体反应，还表示同一类型的反应。例如 H+ + OH− = H2O 可表示盐酸与 NaOH、硫酸与 KOH 等所有"强酸＋强碱生成可溶性盐和水"的中和反应。

书写四步法（以 BaCl2 溶液与 Na2SO4 溶液反应为例）：

  1. 写：写出化学方程式并配平——BaCl2 + Na2SO4 = BaSO4↓ + 2NaCl；
  2. 拆：把易溶于水、易电离的物质（强酸、强碱、可溶性盐）拆成离子——Ba2+ + 2Cl− + 2Na+ + SO42− = BaSO4↓ + 2Na+ + 2Cl−；
  3. 删：删去两边相同的旁观离子（Na+、Cl−）；
  4. 查：检查原子个数守恒、电荷守恒，得到 Ba2+ + SO42− = BaSO4↓。
拆与不拆 · 生死线

能拆（只有三类）：强酸、强碱、可溶性盐。

不能拆（六类，写化学式）：

  • 弱电解质：CH3COOH、NH3·H2O、H2O 等；
  • 难溶物：CaCO3、BaSO4、AgCl、Mg(OH)2 等；
  • 气体：CO2、NH3、H2 等；
  • 单质：Fe、Cu、Cl2 等；
  • 氧化物：CuO、Fe2O3、Na2O、CO2 等；
  • 浓硫酸作反应物时（浓硫酸中硫酸主要以分子形式存在）。

微溶物的特殊处理（Ca(OH)2、CaSO4、Ag2SO4、MgCO3）：作反应物时，若是澄清溶液（如澄清石灰水）则拆，若是悬浊液（如石灰乳）则不拆；作生成物时，一律写化学式并标"↓"。

溶解性口诀与沉淀颜色速查

溶解性口诀（判断"可不可拆"的硬件基础）：钾钠铵盐硝酸盐，都能溶在水中间；盐酸盐不溶银亚汞，硫酸盐不溶钡和铅（钙、银微溶）；碳酸盐磷酸盐多不溶，溶者只有钾钠铵；碱溶钾钠钡和铵，钙碱微溶记心间。

常见沉淀颜色（离子检验与推断题的"视觉证据"）：

  • 白色：BaSO4（不溶于稀酸）、AgCl（不溶于稀酸）、BaCO3、CaCO3、BaSO3、Mg(OH)2、Al(OH)3（白色胶状）；
  • 黄色系：AgI（黄色）、AgBr（淡黄色）、Ag2CO3（黄色，溶于稀酸）；
  • 蓝色：Cu(OH)2；
  • 红褐色：Fe(OH)3；
  • 特殊变色：Fe(OH)2 白色 → 迅速变灰绿色 → 最终红褐色（被空气中 O2 氧化）。

沉淀颜色是离子检验和元素推断题的"视觉证据"，要与 2.7 节的检验表结合起来记忆。

2.6 离子共存

核心概念

判断标准：离子之间若发生反应（生成沉淀、气体、弱电解质，或发生氧化还原、络合），就不能大量共存；反之能共存。注意"大量"二字——极微量反应不视为不共存的判据。

五大不共存类型：

  1. 生成沉淀：Ba2+ 与 SO42−、CO32−；Ag+ 与 Cl−、Br−、I−；Ca2+ 与 CO32−；Fe3+、Cu2+、Mg2+ 与 OH− 等。
  2. 生成气体：H+ 与 CO32−、HCO3−（CO2↑）、SO32−（SO2↑）、S2−（H2S↑）；NH4+ 与 OH−（加热逸出 NH3↑）。
  3. 生成弱电解质：H+ 与 OH−（生成 H2O）；H+ 与 CH3COO−、ClO−、F−（生成弱酸）；OH− 与 NH4+（生成 NH3·H2O）。
  4. 发生氧化还原：Fe3+ 与 I−、S2−；MnO4−（H+）与 Cl−、Fe2+、I−；NO3− 遇 H+ 后与 Fe2+、I−、S2−、SO32− 不共存；ClO− 与 S2−、I− 等。
  5. 发生络合：Fe3+ 与 SCN− 生成血红色配合物（高一记住这一对即可）。

特别注意：HCO3− 是"两面派"——遇 H+ 放出 CO2，遇 OH− 生成 CO32− 和水，所以 HCO3− 在强酸和强碱中都不能存在。

隐含条件挖掘清单

共存题真正的难度不在离子本身，而在题干给你的"环境"。逐条对照：

  • "无色溶液"：排除 Cu2+（蓝色）、Fe2+（浅绿色）、Fe3+（黄色）、MnO4−（紫红色）。注意"透明"≠"无色"，透明溶液可以有颜色。
  • "酸性溶液 / pH=1 / 使石蕊变红"：溶液中含大量 H+，凡与 H+ 反应的（OH−、CO32−、HCO3−、CH3COO−、S2−、SO32−、ClO− 等）全部出局。
  • "碱性溶液 / pH=13 / 使酚酞变红"：溶液中含大量 OH−，凡与 OH− 反应的（H+、NH4+、Mg2+、Cu2+、Fe2+、Fe3+、HCO3− 等）全部出局。
  • "与铝反应放出 H2"：可能是强酸性也可能是强碱性溶液，要分两种情况讨论；但若是酸性，则不能含 NO3−（否则是硝酸，与铝不放 H2）。
  • "由水电离出的 c(H+) = 1×10−13 mol/L"：水的电离被抑制，溶液为强酸或强碱性，同样分两种情况。
  • "加入 (NH4)2Fe(SO4)2·6H2O 晶体后仍能大量存在"：等于引入了 NH4+、Fe2+、SO42−，要把它们当已有离子一并审查。

检验设计三原则

① 先排除干扰再下结论——检验 SO42− 必须先加盐酸；② 取样检验——"取少量待测液于试管中"，不能往原试剂瓶里加试剂；③ 答表述按"操作 → 现象 → 结论"三段式，缺一不可。

规范答题模板

离子检验题的满分表述为三段式："取少量待测液于试管中，加入 ×× 试剂，若观察到 ×× 现象，则证明含有 ×× 离子。"——取样、操作（含试剂与用量）、现象、结论四要素缺一不可。漏写"取少量待测液"、只写现象不写结论、把"先酸化"漏掉，都是常见扣分点。

三、三重表征贯通

化学学习的核心能力是能把宏观现象、微观粒子、符号表达三者自由切换。下面三组是离子反应的"标准样例"，请逐格精读。

组 1：酸碱中和（HCl 与 NaOH）

宏观表征

两种无色溶液混合，无沉淀、无气泡、无颜色变化，用手触摸烧杯壁感到温热（放热）；若用温度计测量，混合后温度升高。

微观表征

HCl 电离出的 H+ 与 NaOH 电离出的 OH− 结合成难电离的 H2O 分子；Na+ 与 Cl− 始终游离在溶液中，是旁观离子。反应放热源于形成 H2O 时释放能量。

符号表征

HCl + NaOH = NaCl + H2O

H+ + OH− = H2O

离子方程式揭示本质：所有"强酸＋强碱→可溶性盐＋水"的反应都是同一个式子。

组 2：沉淀生成（BaCl2 与 Na2SO4）

宏观表征

两种无色透明溶液混合的一瞬间，立即出现白色浑浊，静置后白色固体沉到试管底部，上层清液无色。

微观表征

Ba2+ 与 SO42− 相互碰撞后结合成 BaSO4 晶格——它在水中溶解度极小，离子一旦"牵手"就不再分开，从溶液中析出；Na+、Cl− 留在溶液里旁观。

符号表征

BaCl2 + Na2SO4 = BaSO4↓ + 2NaCl

Ba2+ + SO42− = BaSO4↓

这也是检验 SO42− 的反应依据。

组 3：固体溶解并放出气体（CaCO3 与稀盐酸）

宏观表征

白色石灰石（或大理石）碎块表面剧烈冒气泡，固体逐渐变小直至消失；生成的无色无味气体能使燃着的木条熄灭，通入澄清石灰水，石灰水变浑浊。

微观表征

CaCO3 晶体表面的 CO32− 与溶液中的 H+ 结合先生成 H2CO3，H2CO3 不稳定分解为 CO2 和 H2O；CO2 逸出使平衡不断右移，固体持续溶解。注意 CaCO3 是难溶固体，参与反应时以固体整体写，不能拆成离子。

符号表征

CaCO3(s) + 2HCl(aq) → CaCl2(aq) + H2O(l) + CO2↑(g)

CaCO3 + 2H+ = Ca2+ + H2O + CO2↑

实验室制取 CO2 的原理反应。

组 4：碳酸钠溶液中逐滴加入稀盐酸（分步反应）

宏观表征

向 Na2CO3 溶液中逐滴加入稀盐酸：开始滴加阶段无气泡，持续滴加一段时间后才开始冒出无色无味气泡，且越来越多、越来越急。

微观表征

CO32− 与 H+ 的结合分两步走：先各结合 1 个 H+ 生成 HCO3−（无气体），待 CO32− 全部转化为 HCO3− 后，继续滴入的 H+ 才与 HCO3− 结合放出 CO2。"先无后有"正是分步反应的宏观指纹。

符号表征

第一步：CO32− + H+ = HCO3−

第二步：HCO3− + H+ = H2O + CO2↑

反过来把 Na2CO3 溶液滴入足量盐酸，则立即冒泡：CO32− + 2H+ = H2O + CO2↑。

组 5：氢氧化钡溶液与稀硫酸（沉淀与中和同时发生）

宏观表征

两种无色溶液混合，立即出现白色沉淀（BaSO4），同时烧杯壁明显发热；若事先在 Ba(OH)2 溶液中滴入酚酞，红色会逐渐褪去（OH− 被消耗）。

微观表征

溶液中同时进行两个反应：Ba2+ 与 SO42− 结合成难溶的 BaSO4；H+ 与 OH− 结合成难电离的 H2O。二者"各干各的"，必须合并写进同一个离子方程式。

符号表征

Ba(OH)2 + H2SO4 = BaSO4↓ + 2H2O

Ba2+ + 2OH− + 2H+ + SO42− = BaSO4↓ + 2H2O

四个离子按 1∶2∶2∶1 参与，一个都不能漏——这是"漏写离子反应"错误的高发区。

四、典型例题分步拆解

例题 1 · 离子方程式正误判断

题目：下列反应的离子方程式书写正确的是（　　）

A. 铁与稀硫酸：2Fe + 6H+ = 2Fe3+ + 3H2↑

B. 碳酸钙与稀盐酸：CO32− + 2H+ = CO2↑ + H2O

C. 氢氧化钡溶液与稀硫酸：Ba2+ + 2OH− + 2H+ + SO42− = BaSO4↓ + 2H2O

D. 铜片插入硝酸银溶液：Cu + Ag+ = Cu2+ + Ag

【思路点拨】按"查事实 → 查拆分 → 查守恒"三关逐一排查，每关不过即判错。

1

查客观事实（A）：稀硫酸是非氧化性酸，铁被氧化只能到 +2 价（Fe2+），不可能生成 Fe3+。A 错在"想当然把铁写成最高价"。正确为 Fe + 2H+ = Fe2+ + H2↑。

2

查拆分（B）：CaCO3 是难溶物，按规则不能拆，应保留化学式。B 错。正确为 CaCO3 + 2H+ = Ca2+ + CO2↑ + H2O。

3

查守恒与完整性（C、D）：C 中 Ba(OH)2 与 H2SO4 按 1∶1 反应，Ba2+、SO42− 沉淀与 H+、OH− 中和两个过程都写全了，且 Ba2+∶OH−∶H+∶SO42− = 1∶2∶2∶1，原子、电荷均守恒，C 正确。D 左边总电荷 +1，右边 +2，电荷不守恒，D 错；正确为 Cu + 2Ag+ = Cu2+ + 2Ag。

【答案】C

【方法总结】正误判断四查口诀："一查事实二查拆，三查守恒四查量"。特别注意：非氧化性酸氧化铁只到 +2 价；难溶物、弱电解质、气体、单质、氧化物不拆；电荷守恒是最快的排除工具，往往 3 秒就能毙掉一个选项。

例题 2 · 限定条件离子共存

题目：在 pH = 1 的无色透明溶液中，能大量共存的离子组是（　　）

A. Na+、K+、CO32−、NO3−

B. K+、Fe2+、SO42−、Cl−

C. Na+、K+、Cl−、SO42−

D. K+、Na+、CH3COO−、NO3−

【思路点拨】先圈出题干两个限定：pH = 1（大量 H+）和无色（排除有色离子），再逐组过筛。

1

解读条件：pH = 1 ⇒ c(H+) = 0.1 mol/L，强酸性；"无色透明" ⇒ 不能含 Cu2+、Fe2+、Fe3+、MnO4−。

2

筛 A：CO32− + 2H+ = CO2↑ + H2O，酸性条件下 CO32− 不能大量存在。排除。

3

筛 B：组内离子彼此不反应，酸性下也稳定——但 Fe2+ 溶液呈浅绿色，违背"无色"条件。排除。（提醒：有色离子只要出现一个，整组枪毙。）

4

筛 C、D：C 组四种离子互不反应、均无色、均不与 H+ 反应，符合全部条件。D 组 CH3COO− + H+ → CH3COOH（生成弱电解质），酸性下不能大量存在。排除。

【答案】C

【方法总结】共存题标准流程：一圈条件（酸碱性、颜色、特殊提示）→ 二判颜色 → 三查两两反应（沉淀/气体/弱电解质/氧还/络合）。看到 HCO3− 要条件反射：酸里碱里都活不成；看到酸性 + NO3− 要想到"隐形硝酸"，Fe2+、I−、S2− 都会被它氧化。

例题 3 · 与量有关的离子方程式

题目：写出下列两种情况下 NaHCO3 溶液与 Ca(OH)2 溶液反应的离子方程式：

（1）Ca(OH)2 少量；（2）Ca(OH)2 过量。

【思路点拨】用"以少定一"法：把少量物质的化学计量数定为 1，让它提供的离子全部被反应掉，过量的一方"随叫随到"。

1

（1）Ca(OH)2 少量：设 Ca(OH)2 为 1 份，提供 1 份 Ca2+ 和 2 份 OH−。2 份 OH− 需要 2 份 HCO3− 来中和：2HCO3− + 2OH− = 2CO32− + 2H2O，生成的 2 份 CO32− 中只能有 1 份被 Ca2+ 沉淀，剩余 1 份留在溶液中。合并：2HCO3− + Ca2+ + 2OH− = CaCO3↓ + CO32− + 2H2O。

2

（2）Ca(OH)2 过量：设 NaHCO3 为 1 份，提供 1 份 HCO3−，只需 1 份 OH− 中和，生成的 1 份 CO32− 立即被过量的 Ca2+ 全部沉淀。合并：HCO3− + Ca2+ + OH− = CaCO3↓ + H2O。

3

验证：两式原子守恒、电荷守恒均成立。（1）式左边电荷：2×(−1)+(+2)+2×(−1) = −2，右边 (−2)，✓；H 原子左 4 右 4，✓。（2）式左边电荷 −1+2−1 = 0，右边 0，✓。

【答案】（1）2HCO3− + Ca2+ + 2OH− = CaCO3↓ + CO32− + 2H2O　（2）HCO3− + Ca2+ + OH− = CaCO3↓ + H2O

【方法总结】"以少定一"三步：① 少量方系数定 1；② 把少量方的离子按比例全部消耗；③ 过量方离子按需提供。同类常考模型还有：Ca(HCO3)2 与 NaOH、NaHSO4 与 Ba(OH)2、明矾与 Ba(OH)2，全部可以用这一模板解决。

例题 4 · 离子检验与推断

题目：某无色溶液中可能含有 Na+、Ba2+、Cl−、CO32−、SO42− 中的一种或几种。进行如下实验：

① 取少量溶液，加入过量稀盐酸，产生无色无味气泡；

② 向①反应后的溶液中滴加 BaCl2 溶液，无沉淀生成；

③ 另取少量原溶液，用硝酸酸化后滴加 AgNO3 溶液，产生白色沉淀。

推断溶液中一定含有、一定不含、可能含有的离子。

【思路点拨】每个实验现象对应一个"证据"，先由确定证据下结论，再用电荷守恒检查"隐藏答案"。

1

分析①：加盐酸产生无色无味气泡 ⇒ 一定含 CO32−（若含 SO32−，气体有刺激性气味，可排除）。含 CO32− 则与 Ba2+ 生成 BaCO3 沉淀不共存 ⇒ 一定不含 Ba2+。

2

分析②：①中过量盐酸已把 CO32− 全部转化为 CO2，再加 BaCl2 无沉淀 ⇒ 溶液中一定不含 SO42−（若有，会生成 BaSO4 白色沉淀）。

3

分析③：硝酸酸化后加 AgNO3 产生白色沉淀 ⇒ 沉淀为 AgCl ⇒ 一定含 Cl−。注意③取的是"原溶液"另做，不受①中加盐酸的影响。

4

电荷守恒兜底：已确定有 CO32−、Cl− 两种阴离子，溶液必须电中性，而 Ba2+ 已排除 ⇒ 唯一的候选阳离子 Na+ 一定存在。

【答案】一定含：Na+、Cl−、CO32−；一定不含：Ba2+、SO42−；可能含：无（五种离子已全部定性）。

【方法总结】推断题两条铁律：① 共存原则反推——确定某离子存在后，立刻排查它的"死对头"是否被排除；② 电荷守恒兜底——溶液必须电中性，当阳离子（或阴离子）只剩一个候选时，它必然存在。这两个工具能解决几乎所有离子推断题。

例题 5 · 电荷守恒计算

题目：某无色透明溶液中只含有 Na+、Mg2+、Cl−、SO42− 四种离子，测得 c(Na+) = 0.20 mol/L，c(Mg2+) = 0.25 mol/L，c(Cl−) = 0.40 mol/L，则 c(SO42−) 为（　　）

A. 0.10 mol/L　B. 0.15 mol/L　C. 0.20 mol/L　D. 0.30 mol/L

【思路点拨】溶液永远呈电中性：所有阳离子所带正电荷总浓度 = 所有阴离子所带负电荷总浓度。离子浓度必须乘以其电荷数，这是最容易漏乘的一步。

1

写电荷守恒式：c(Na+) + 2c(Mg2+) = c(Cl−) + 2c(SO42−)。

2

代入数据：0.20 + 2×0.25 = 0.40 + 2c(SO42−)，即 0.70 = 0.40 + 2c(SO42−)。

3

求解并复核：c(SO42−) = 0.15 mol/L。复核负电荷：0.40 + 2×0.15 = 0.70，与正电荷相等 ✓。

【答案】B（0.15 mol/L）

【方法总结】电荷守恒式中每个离子浓度前必须乘其电荷数的绝对值。这类题也常反向考查——给出四种离子的浓度数据问"该溶液能否存在"：只要正、负电荷总浓度不相等，数据必然造假，该溶液不存在。

例题 6 · 检验方案设计

题目：设计实验检验某 Na2SO4 样品中是否混有 Na2CO3 和 NaCl 两种杂质，写出实验步骤、预期现象与结论。

【思路点拨】三种阴离子共存，按"先检验、先除去干扰大的离子"排序：CO32− 遇酸冒泡最灵敏先查；但检验 Cl− 用的 AgNO3 与 CO32−、SO42−（生成微溶 Ag2SO4）都会产生沉淀，必须先除尽它们再检验 Cl−。

1

检验并除尽 CO32−：取少量样品溶于水，加入足量稀硝酸，若有气泡产生，证明含 Na2CO3（CO32− + 2H+ = CO2↑ + H2O）；无气泡则不含。硝酸过量既完成检验又顺手除尽 CO32−。

2

除去 SO42−：向上述溶液中加入过量 Ba(NO3)2 溶液，静置（Ba2+ + SO42− = BaSO4↓），取上层清液备用。注意只能用 Ba(NO3)2 而不能用 BaCl2——后者会引入 Cl−，干扰下一步检验。

3

检验 Cl−：取第 2 步上层清液，滴加 AgNO3 溶液，若产生白色沉淀，证明含 NaCl（Ag+ + Cl− = AgCl↓）；无沉淀则不含。

【答案】三步：足量稀硝酸验 CO32−（冒泡则有）→ 过量 Ba(NO3)2 除尽 SO42− → 清液加 AgNO3 验 Cl−（白色沉淀则有）。

【方法总结】多离子混合检验的两条军规：① 检验顺序按干扰关系排，先被检验的离子在检验后必须被除尽，且所用试剂不能干扰后续检验；② 除杂试剂优先选硝酸盐——硝酸盐全溶、NO3− 不引入新沉淀，是混合离子检验题的"万能配角"。

例题 7 · 离子方程式书写训练

题目：写出下列反应的离子方程式，并说明书写依据：

① 稀盐酸与氢氧化钠溶液；② 氯化铁溶液与氢氧化钠溶液；③ 醋酸与氢氧化钠溶液；④ 二氧化碳通入足量澄清石灰水；⑤ 氧化铜与稀硫酸；⑥ 碳酸氢钠溶液与盐酸。

【思路点拨】每题都走"写、拆、删、查"四步，重点关注"谁不能拆"：③中醋酸是弱酸，④中 CO2 是氧化物、CaCO3 难溶，⑤中 CuO 是氧化物，⑥中 HCO3− 是弱酸酸根。

1

① H+ + OH− = H2O。强酸强碱生成可溶性盐和水，Na+、Cl− 旁观删去。

2

② Fe3+ + 3OH− = Fe(OH)3↓。Fe(OH)3 是难溶弱碱，写化学式并标"↓"（红褐色沉淀）。

3

③ CH3COOH + OH− = CH3COO− + H2O。醋酸是弱酸，不拆——与①对比可见，强酸与弱酸在离子方程式中的"待遇"完全不同。

4

④ CO2 + Ca2+ + 2OH− = CaCO3↓ + H2O。CO2 是氧化物不拆；足量澄清石灰水中 Ca(OH)2 拆开；CaCO3 难溶不拆。（继续通 CO2 至过量，沉淀会溶解：CaCO3 + CO2 + H2O = Ca2+ + 2HCO3−。）

5

⑤ CuO + 2H+ = Cu2+ + H2O。CuO 是氧化物不拆——"碱性氧化物与酸反应"的通式都是：氧化物 + H+ → 金属离子 + 水。

6

⑥ HCO3− + H+ = H2O + CO2↑。NaHCO3 是可溶性盐，拆成 Na+ 与 HCO3−；但 HCO3− 是弱酸酸根，不能再拆成 H+ 和 CO32−——这是酸式盐书写的关键。

【答案】见各步解析。六式依次为：H+ + OH− = H2O；Fe3+ + 3OH− = Fe(OH)3↓；CH3COOH + OH− = CH3COO− + H2O；CO2 + Ca2+ + 2OH− = CaCO3↓ + H2O；CuO + 2H+ = Cu2+ + H2O；HCO3− + H+ = H2O + CO2↑。

【方法总结】六道小题覆盖了五大"不拆"类型中的四类（弱电解质、难溶物、氧化物、弱酸酸根）。把这一组练熟，"拆"字关就过了。建议模仿本题，把课本上每一个溶液中发生的化学方程式都改写成离子方程式，一周后你的书写速度会有质的飞跃。

例题 8 · 离子推断综合（含定量）

题目：某无色透明溶液可能含有 K+、NH4+、Ba2+、SO42−、CO32−、Cl− 中的若干种。进行如下实验：

① 取 100 mL 该溶液，加入足量稀盐酸，产生标准状况下 448 mL 无色无味气体；

② 向①所得溶液（气体已除尽）中滴加 BaCl2 溶液，产生白色沉淀；

③ 另取 100 mL 原溶液，加 NaOH 溶液并加热，产生能使湿润红色石蕊试纸变蓝的气体；

④ 再取 100 mL 原溶液，加稀硝酸酸化后滴加 AgNO3 溶液，无沉淀。

求：一定存在的离子及浓度，并说明一定不存在的离子。

【思路点拨】逐条现象翻译成证据，最后用"电荷守恒"检查配比是否成立、还有哪些离子不能确定。

1

①：无色无味气体 448 mL ⇒ n(CO2) = 0.448 L ÷ 22.4 L/mol = 0.02 mol ⇒ c(CO32−) = 0.02 ÷ 0.1 = 0.20 mol/L；同时 CO32− 与 Ba2+ 不共存 ⇒ 一定不含 Ba2+。

2

②：①中 CO32− 已被足量盐酸除尽，再加 BaCl2 仍有白色沉淀 ⇒ 原溶液含 SO42−（BaSO4）。

3

③：加碱加热产生使湿润红色石蕊试纸变蓝的气体（NH3）⇒ 含 NH4+（NH4+ + OH− → NH3↑ + H2O）。

4

④：硝酸酸化后加 AgNO3 无沉淀 ⇒ 一定不含 Cl−。

5

电荷守恒兜底：阴离子中 CO32− 带 0.40 mol/L 的负电荷、SO42− 浓度未知；阳离子仅 NH4+ 确定。要保证电中性，阳离子总电荷必须与阴离子总电荷相等 ⇒ K+ 与 NH4+ 的总量必须足够大。由于题目未给出 NH4+ 的浓度，K+ 不能确定，只能标"可能含有"。

【答案】一定存在：CO32−（0.20 mol/L）、SO42−、NH4+；一定不存在：Ba2+、Cl−；可能含有：K+。

【方法总结】离子推断"三件法宝"：① 现象→证据逐条翻译（含定量换算）；② 共存原则反推（CO32− 在则 Ba2+ 走）；③ 电荷守恒兜底（阴、阳电荷必须平衡）。"可能含有"不能凭感觉，必须有明确的推理空白作为依据。

例题 9 · 与量有关的计算

题目：将标准状况下 2.24 L CO2 缓慢通入 100 mL 1.0 mol/L 的 NaOH 溶液中（气体被完全吸收）。回答：（1）生成什么产物？（2）各产物的物质的量是多少？

【思路点拨】CO2 与 NaOH 按投料比走三条路：n(NaOH)∶n(CO2) ≥ 2 时只生成 Na2CO3；= 1 时只生成 NaHCO3；介于 1~2 之间时两者并存。先算投料比，再对号入座。

1

算投料：n(CO2) = 2.24 ÷ 22.4 = 0.10 mol；n(NaOH) = 0.100 L × 1.0 mol/L = 0.10 mol。

2

判比值：n(NaOH)∶n(CO2) = 1∶1，恰好处于"只生成酸式盐"的临界点。

3

写反应：CO2 + NaOH = NaHCO3（离子方程式 CO2 + OH− = HCO3−），按 1∶1 反应 ⇒ 产物只有 NaHCO3，n = 0.10 mol。

4

复核：若走 Na2CO3 路线，0.10 mol CO2 需 0.20 mol NaOH，实际只有 0.10 mol，不够；若 Na2CO3 与 NaHCO3 混合，则 n(NaOH) 应大于 n(CO2)。故只有 NaHCO3 合理 ✓。

【答案】（1）只生成 NaHCO3　（2）n(NaHCO3) = 0.10 mol

【方法总结】"CO2—碱"三档模型（比值 2、1、1~2 之间）是量比题的经典模板，同型还有"SO2—碱"以及高二的"AlCl3—NaOH""NaAlO2—HCl"。判题次序永远是：先算物质的量 → 再算比值 → 最后按档位写方程式。

例题 10 · 选择式综合判断

题目：下列"实验操作与现象、结论"的对应关系正确的是（　　）

A. 向某溶液中滴加 BaCl2 溶液，产生白色沉淀，说明原溶液含 SO42−

B. 向某溶液中滴加 KSCN 溶液，无明显现象，再滴加氯水后变红，说明原溶液含 Fe2+

C. 向某溶液中滴加 AgNO3 溶液，产生白色沉淀，说明原溶液含 Cl−

D. 向某溶液中滴加 NaOH 溶液，产生白色沉淀，说明原溶液含 Al3+

【思路点拨】逐项检查"现象是否足以排除所有干扰"。检验题的错误选项，几乎都败在"干扰没排除"上。

1

A：白色沉淀可能是 BaSO4，也可能是 BaCO3、BaSO3，若原溶液含 Ag+ 还可能是 AgCl。未先酸化排除干扰，不能定性。A 错。

2

B：先加 KSCN 无现象 ⇒ 原溶液不含 Fe3+；加氯水后变红 ⇒ 氯水把某种离子氧化成了 Fe3+ ⇒ 原溶液含 Fe2+（2Fe2+ + Cl2 = 2Fe3+ + 2Cl−）。B 正确。

3

C：白色沉淀可能是 AgCl，也可能来自 CO32−（Ag2CO3 为白色沉淀）。未用稀硝酸酸化排除，不能定性。C 错。

4

D：白色沉淀可能是 Al(OH)3，也可能是 Mg(OH)2、Zn(OH)2甚至 Ca(OH)2。必须继续加 NaOH 至过量：沉淀溶解才能证明是 Al3+（或 Zn2+）。D 错。

【答案】B

【方法总结】检验类选择题的三个"必查"：① 试剂顺序对不对（先 KSCN 后氯水，颠倒则无效）；② 干扰排除做没做（BaCl2、AgNO3 前都要先酸化）；③ 后续验证做没做（Al3+ 要看"过量 NaOH 后沉淀溶解"）。

五、易错点与成因

易错点 1

易错表现：认为"铜能导电，所以铜是电解质"；或"盐酸能导电，所以盐酸是电解质"。

错误成因：只记住了"能导电"这个表象，忽略了概念的大前提——电解质、非电解质都只针对化合物下定义。铜是单质、盐酸是混合物，都不在讨论范围内。

正确理解：判断顺序是"先看是不是化合物 → 再看能否自身电离导电"。单质和混合物既不是电解质也不是非电解质。

避坑口诀："单质混合两边站，电解质里只认化合物。"

易错点 2

易错表现：认为 CO2、SO2、NH3 的水溶液能导电，所以它们是电解质。

错误成因：混淆了"溶质本身电离"与"溶质与水反应的产物电离"。CO2 溶于水后导电，靠的是生成的 H2CO3 电离出 H+ 和 HCO3−，CO2 分子自身一个离子也没给出。

正确理解：判断标准是看熔融状态或水溶液中由谁电离。CO2、SO2、SO3、NH3 都是非电解质；对应的 H2CO3、H2SO3、H2SO4、NH3·H2O 才是电解质。

避坑口诀："谁电离，谁才是；借别人导电，自己不算数。"

易错点 3

易错表现：认为 BaSO4、CaCO3 难溶于水，所以是弱电解质；或认为 CH3COOH 极易溶于水，所以是强电解质。

错误成因：把"溶解度"和"电离程度"这两个完全独立的概念混在一起。电解质的强弱由已溶解部分的电离程度决定，与溶多溶少无关。

正确理解：BaSO4 溶解的部分 100% 电离，是强电解质；CH3COOH 溶解再多也只约 1% 电离，是弱电解质。写离子方程式时，BaSO4 不拆（因为难溶）、CH3COOH 也不拆（因为弱电离）——殊途同归，但理由完全不同。

避坑口诀："强弱看电离，不拆看两条：难溶或弱电。"

易错点 4

易错表现：写 Ba(OH)2 与稀硫酸反应的离子方程式时，只写 Ba2+ + SO42− = BaSO4↓，漏掉 H+ + OH− = H2O。

错误成因：被"白色沉淀"这个明显的宏观现象吸引，忘记了溶液中同时进行的酸碱中和——它是"看不见的离子反应"，没有沉淀气体那样的显眼信号。

正确理解：一个混合体系中所有能发生的离子反应都要写进同一个离子方程式，并按实际比例配平。本题中 Ba(OH)2 与 H2SO4 1∶1 反应，OH− 与 H+ 的系数必须都是 2：Ba2+ + 2OH− + 2H+ + SO42− = BaSO4↓ + 2H2O。

避坑口诀："多对离子齐上阵，一对都不能漏；比例跟着化学式走。"

易错点 5

易错表现：共存题中把"透明溶液"当作"无色溶液"，放过了 Cu2+、Fe3+；或忽略"pH=1"先忙着比对离子两两反应。

错误成因：审题顺序错误——先看选项再看题干条件。透明只说明没有悬浊物，CuSO4 溶液就是透明的蓝色液体；而题干给的酸碱性是"一票否决"的硬条件，必须先于一切比对使用。

正确理解：固定解题顺序：先圈题干限定（颜色、酸碱性、特殊操作）→ 再逐组筛选项。把 H+ 或 OH− 当成"第 5 个离子"加入每个选项中一起审查。

避坑口诀："先圈条件后筛组，酸碱颜色两头堵。"

易错点 6

易错表现：检验 SO42− 时，加 BaCl2 出现白色沉淀就下结论；或用稀硝酸酸化后加 BaCl2。

错误成因：不知道 Ag+（生成 AgCl↓）、CO32−、SO32−（生成 BaCO3↓、BaSO3↓）都会产生白色沉淀；更不知道硝酸的强氧化性会把 SO32− 氧化成 SO42−，把"无"变成"有"。

正确理解：规范操作是"先加稀盐酸酸化，无现象后再加 BaCl2"：盐酸酸化能赶走 CO32−、SO32−（变成气体逸出），并沉淀掉 Ag+（AgCl 在第一步就析出），剩下的白色沉淀才能断定是 BaSO4。

避坑口诀："先酸化、看现象、再钡盐；硝酸酸化是大坑。"

易错点 7

易错表现：Ca(OH)2 一律拆开写离子，或一律不拆；写 Ca(HCO3)2 与 NaOH 反应的离子方程式时不分少量、过量。

错误成因：把"微溶"当成一种固定的拆分属性。实际上微溶物处于什么状态决定拆不拆：澄清石灰水（真溶液）要拆，石灰乳（悬浊液）不拆；CaCO3 作生成物时一律写化学式并标"↓"。

正确理解：Ca(HCO3)2 与 NaOH——NaOH 少量：Ca2+ + HCO3− + OH− = CaCO3↓ + H2O；NaOH 过量：Ca2+ + 2HCO3− + 2OH− = CaCO3↓ + CO32− + 2H2O。用"以少定一"法即可清晰区分。

避坑口诀："微溶看状态：澄清就拆开，浑浊别动它。"

高频陈述辨析（先判对错，再看理由）
陈述判断理由
NaCl 溶液能导电，所以 NaCl 溶液是电解质✗溶液是混合物；电解质必须先是化合物
BaSO4 难溶，所以是弱电解质✗溶解的部分完全电离，属强电解质
CO2 的水溶液导电，所以 CO2 是电解质✗导电靠 H2CO3 电离，CO2 自身不电离
弱电解质溶液的导电能力一定比强电解质溶液弱✗导电能力取决于离子浓度；浓醋酸可强于极稀盐酸
无色溶液中不可能含 Fe2+✓Fe2+ 呈浅绿色，与"无色"矛盾
检验 SO42− 用硝酸酸化比盐酸酸化更严谨✗硝酸会把 SO32− 氧化为 SO42−，造成误判
Ca(HCO3)2 与 NaOH 反应的产物与 NaOH 用量无关✗少量、过量时产物不同，见易错点 7

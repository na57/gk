3.1 物质的量与化学计算

高中化学 · 深度学习材料 · 面向 2029 届云南高考

「物质的量」是连接宏观质量与微观粒子数的桥梁，是整个高中化学计算的核心工具。本章的每一个公式、每一个单位都要练到零失误——高考中 NA 辨析题和物质的量浓度计算题，都是你「一眼定答案」的送分点，前提是陷阱你能一眼看穿。

二、核心概念精讲

六个概念卡片按「是什么 → 为什么 → 适用边界 → 常见混淆」展开。请特别留意每张卡片的「边界」——高考命题的陷阱几乎全部设置在边界条件上。

核心概念 1

物质的量（n）：把「数粒子」变成「称质量」的桥梁

是什么：物质的量是把微观粒子「打包」计数的物理量，是国际单位制七个基本物理量之一（其余为长度、质量、时间、电流、热力学温度、发光强度），单位是摩尔（mol）。1 mol 任何粒子集体所含的粒子数，等于 0.012 kg 12C 中所含碳原子数，即阿伏加德罗常数 NA ≈ 6.02×1023 mol−1。

为什么（微观解释）：单个原子、分子太轻（如一个 H2O 分子质量约 3×10−23 g），实验室无法逐个数粒子。人们规定一个「大包装」——NA 个粒子为 1 mol，使得 1 mol 物质的质量（以 g 为单位）在数值上恰好等于其相对质量，宏观称量与微观计数就此打通。

适用边界：

  • 物质的量只用于微观粒子（分子、原子、离子、电子、质子、中子等）及其特定组合，不能说「1 mol 大米」。
  • 必须指明粒子种类：说「1 mol 氢」是错误的，应说「1 mol H」或「1 mol H2」，二者相差 2 倍的原子数。
  • NA 是精确值（6.02214076×1023 mol−1），6.02×1023 是计算用近似值；题目说「NA」指精确计数标准，计算时可用近似值。
  • 物质的量与质量、长度一样是可以加减乘除运算的物理量，运算时带着单位 mol 一起参与，是检验列式是否合理的好办法。

基本公式：n = N / NA（N 为粒子数）。

微粒数计算示例（先算 n，再看每个微粒里含几个目标粒子）：

  • 1 mol H2O 中含 2 mol H 原子、1 mol O 原子，共 3 mol 原子；含 10 mol 电子（每个 H2O 分子含 2×1 + 8 = 10 个电子）。
  • 1 mol Mg 失去 2 mol 电子变为 Mg2+；1 mol Cl2 得到 2 mol 电子变为 2 mol Cl−。
  • 0.5 mol Na2SO4 中含 1 mol Na+、0.5 mol SO42−，共 1.5 mol 离子。

常见混淆：「物质的量」≠「物质的质量」，前者单位 mol，后者单位 g；摩尔是单位不是物理量。说「1 mol 氧」时必须补全为「1 mol O」还是「1 mol O2」。

核心概念 2

摩尔质量（M）：1 mol 物质的质量

是什么：单位物质的量的物质所具有的质量，单位 g/mol（或 g·mol−1）。以 g/mol 为单位时，数值等于该粒子的相对原子质量或相对分子质量。

示例：M(H2SO4) = 2×1 + 32 + 4×16 = 98 g/mol；M(Na2CO3) = 2×23 + 12 + 3×16 = 106 g/mol；M(Na2SO4) = 2×23 + 32 + 4×16 = 142 g/mol。

基本公式：n = m / M（m 为质量）。

核心概念 3

气体摩尔体积（Vm）与 22.4 L/mol 的适用条件

是什么：单位物质的量的气体所占的体积，Vm = V / n，单位 L/mol。在标准状况（0 ℃、101 kPa）下，任何气体（纯净或混合）的 Vm ≈ 22.4 L/mol。

为什么（微观解释）：气体分子本身的体积远小于分子间的距离，气体体积主要由「分子数」和「分子间距」决定；同温同压下分子间距相同，所以同温同压下相同分子数（相同物质的量）的任何气体体积相同。固、液体则不同——粒子间几乎无空隙，体积由粒子本身大小决定，故没有统一的「摩尔体积」。

温度压强的影响方向：温度升高，分子间距增大，Vm 增大；压强增大，分子被「挤近」，Vm 减小。所以 25 ℃、101 kPa（常温常压）下 Vm ≈ 24.5 L/mol > 22.4 L/mol。

适用边界（高频陷阱，务必逐条核对）：

  • 必须是气体。标准状况下水是液体（冰）、SO3 是固体、己烷（C6H14）、苯、CCl4、乙醇均为液体，「22.4 L」对这些物质一律不适用。
  • 必须是标准状况。常温常压（25 ℃、101 kPa）下 Vm ≈ 24.5 L/mol，不是 22.4 L/mol。
  • 反过来：非标准状况下气体体积也可能恰为 22.4 L/mol（升温同时增压），所以「22.4 L/mol 时一定处于标准状况」的说法是错的。
  • 「任何气体」包括混合气体：标准状况下 22.4 L 空气、22.4 L CO 与 H2 的混合气，物质的量都是 1 mol。

基本公式：n = V / Vm，标准状况下 n = V / 22.4 L·mol−1。

陷阱物质清单

标准状况（0 ℃）下不是气体、见到「22.4 L」要立刻警觉的常见物质：H2O（液体或冰）、SO3（固体，熔点 16.8 ℃）、己烷 C6H14（液体）、苯 C6H6（液体）、CCl4（液体）、乙醇 C2H5OH（液体）、HF（液体，沸点 19.5 ℃）。反过来，CO2、O2、N2、H2、NH3、HCl 标况下均为气体，可正常使用。

核心概念 4

物质的量浓度（c）与溶液配制

是什么：单位体积溶液（不是溶剂！）中所含溶质的物质的量，c = n / V，单位 mol/L。

从溶液中取出部分：浓度是强度量，与体积无关——从 1 mol/L 的 NaCl 溶液中取出 1 mL，浓度仍是 1 mol/L；但取出部分所含溶质的物质的量随体积变化。

离子浓度：强电解质完全电离，c(Na2SO4) = 0.2 mol/L 时，c(Na+) = 0.4 mol/L，c(SO42−) = 0.2 mol/L。一般规律：离子浓度 = 电解质浓度 × 该离子在化学式中的下标数。

再练一组：0.5 mol/L Al2(SO4)3 溶液中，c(Al3+) = 1.0 mol/L，c(SO42−) = 1.5 mol/L；取出 100 mL，浓度不变，但含 SO42− 的物质的量 = 1.5 × 0.1 = 0.15 mol。

配制一定物质的量浓度溶液（以配制 500 mL 0.2 mol/L Na2SO4 溶液为例）：

  1. 计算：n = 0.5 L × 0.2 mol/L = 0.1 mol，m = 0.1 mol × 142 g/mol = 14.2 g。
  2. 称量：用托盘天平（精确到 0.1 g）或称量纸/小烧杯称取 14.2 g 固体。
  3. 溶解：在烧杯中加适量蒸馏水，玻璃棒搅拌溶解，冷却至室温。
  4. 转移：用玻璃棒引流，将溶液转入 500 mL 容量瓶。
  5. 洗涤：用少量蒸馏水洗涤烧杯和玻璃棒 2~3 次，洗涤液一并转入容量瓶。
  6. 定容：加水至液面离刻度线 1~2 cm 时，改用胶头滴管滴加，至凹液面最低处与刻度线相切。
  7. 摇匀：盖好瓶塞，反复上下颠倒摇匀；装瓶贴标签。

容量瓶使用要点：容量瓶是量入式精密仪器，瓶身标有温度（20 ℃）和一个刻度线；不能溶解固体、不能稀释浓溶液、不能加热、不能长期存放溶液。使用前先查漏：装水至刻度线附近，盖好瓶塞，用食指按住瓶塞、另一手托住瓶底，倒置 2 分钟观察是否渗漏，正立后将瓶塞旋转 180° 再倒置检查一次。实验室没有 480 mL 规格，需配 480 mL 时选 500 mL 容量瓶，按 500 mL 计算。

误差分析速查（判断 c 偏高还是偏低，抓住 c = n/V 两个量）：

  • 未洗涤烧杯和玻璃棒 → n 偏小 → c 偏低。
  • 定容时俯视刻度线 → V 偏小 → c 偏高；仰视 → V 偏大 → c 偏低。
  • 溶解后未冷却即转移定容 → 冷却后 V 偏小 → c 偏高。
  • 定容摇匀后液面低于刻度线再加水 → V 偏大 → c 偏低（摇匀后液面下降是正常现象，不可再加水）。
  • 砝码生锈或药品与砝码放反（使用游码时）→ 称得 n 偏小 → c 偏低。
  • 容量瓶用蒸馏水洗净后未干燥 → n、V 均不受影响 → 无影响（定容时本来就要加水）。
  • 转移时有少量液体洒出 → n 偏小 → c 偏低。

常见混淆：溶液体积 ≠ 溶剂体积。「将 1 mol NaCl 溶于 1 L 水」所得溶液体积不是 1 L，浓度不是 1 mol/L；正确表述是「溶于水配成 1 L 溶液」。

溶液的稀释与浓溶液取用

稀释前后溶质的物质的量不变，故 c(浓)·V(浓) = c(稀)·V(稀)。注意 V(稀) 是配制后溶液的总体积（由容量瓶规格决定），不能理解为「加入水的体积」。

示例：用 18.4 mol/L 的浓硫酸配制 500 mL 1.0 mol/L 的稀硫酸，需浓硫酸 V = 1.0 mol/L × 500 mL ÷ 18.4 mol/L ≈ 27.2 mL。

  • 操作要点：用量筒量取浓硫酸；烧杯中先加适量蒸馏水，再将浓硫酸沿玻璃棒缓慢注入水中并不断搅拌（「酸入水」，切不可反向，否则剧烈放热导致液体飞溅）。
  • 冷却至室温后再转移、洗涤、定容——浓硫酸稀释放热，热溶液直接定容会使浓度偏高。
核心概念 5

阿伏加德罗定律及推论

定律：同温同压下，相同体积的任何气体（包括混合气体）含有相同数目的分子。

为什么：由理想气体状态方程 PV = nRT，P、V、T 三个量中确定两个，第三个即被确定；同温同压同体积 ⇒ n 相同 ⇒ 分子数相同。

三大推论（要会由 PV = nRT 自己推导）：

  • 同温同压：V1/V2 = n1/n2 = N1/N2（体积比 = 物质的量之比 = 分子数之比）。
  • 同温同体积：p1/p2 = n1/n2（压强比 = 物质的量之比）。
  • 同温同压：ρ1/ρ2 = M1/M2（密度比 = 摩尔质量之比，称「相对密度」D = M1/M2）。

推论 1 的推导：同温同压下，由 PV = nRT 得 V = nRT/P，R、T、P 均为定值，故 V 与 n 成正比，V1/V2 = n1/n2；同温同体积时由 P = nRT/V 得 P 与 n 成正比。

推论 3 的推导（体会 PV = nRT 的用法）：

  1. 由 PV = nRT 与 n = m/M，得 PV = (m/M)RT。
  2. 两边整理：ρ = m/V = PM/(RT)。
  3. 同温同压下 P、R、T 相同，故 ρ 与 M 成正比，即 ρ1/ρ2 = M1/M2。

会自己推导，就不用死记——考场上忘掉方向时，30 秒即可重新推出。

推论应用示例：同温同压下某气体对氢气的相对密度为 16，则该气体的摩尔质量 M = 16 × M(H2) = 16 × 2 g/mol = 32 g/mol，可能是 O2。若对空气的相对密度为 2.21，则 M ≈ 2.21 × 29 ≈ 64 g/mol，可能是 SO2——相对密度法是「称量气体」的常用手段。

常见混淆：阿伏加德罗定律研究的是气体体系，对液体、固体不成立；「分子数相同」不等于「原子数相同」（如 1 mol He 含 NA 个原子，1 mol H2 含 2NA 个原子）。

混合气体平均摩尔质量：M̄ = m(总)/n(总)。空气的平均摩尔质量约为 29 g/mol；某混合气体 M̄ < 29 g/mol，说明其中含有比空气「轻」的气体（如 H2）。

核心概念 6

化学计算四大方法

① 守恒法：利用化学反应前后质量守恒、原子守恒、电荷守恒、得失电子守恒列式，跳过中间过程直击结果。溶液计算中最常用电荷守恒：溶液呈电中性，阳离子所带正电荷总数 = 阴离子所带负电荷总数。再如原子守恒：「CO2 通入 NaOH 溶液，碳元素最终全在溶液中」，无论生成 Na2CO3 还是 NaHCO3，碳的总量不变。

② 差量法：利用反应前后质量差、体积差、物质的量差与化学计量数成正比列式。例如铁片浸入 CuSO4 溶液，每反应 1 mol Fe（56 g）析出 1 mol Cu（64 g），固体增重 8 g——增重量与反应量成正比。

③ 极值法：混合物计算中，先假设全为某一组分求出极值，真实值必在两极值之间，用于确定混合物可能的组成（平均值思想）。它的反面运用同样重要：若题目说「一定含有」，就找那个任何组合都无法替代的成分。

④ 关系式法：多步反应中，根据各步方程式找出已知物与目标物之间的计量关系（如 Na2CO3 ~ 2HCl），一步列式求解，避免逐步倒推。

公式汇总

四大基本公式：n = N/NA　n = m/M　n = V/Vm（气体）　n = c·V（溶液）。所有以物质的量为中心的计算，都是这四条路与组合变形。

三、三重表征贯通

本章是计算章，但计算的背后是真实的实验与微粒世界。下面三组贯通，把「看得见的操作与现象」「看不见的粒子行为」「公式与方程式」对应起来——理解了粒子的行为，公式就不再是死记硬背的符号。

贯通组 1：配制一定物质的量浓度的溶液

配制实验把本章最多的细节串在一起：计算（n、m）、仪器（容量瓶）、微观（离子均匀分散）。三者对应着下表三栏。

宏观现象

称取 14.2 g 白色 Na2SO4 固体，放入烧杯加蒸馏水，玻璃棒搅拌，固体逐渐消失，得到无色透明溶液，无明显放热；转入 500 mL 容量瓶定容后，凹液面最低处与刻度线相切，摇匀后溶液均匀澄清。

微观粒子

Na2SO4 在水中电离：Na2SO4 → 2Na+ + SO42−。0.1 mol Na2SO4 解离出 0.2 mol Na+ 和 0.1 mol SO42−，均匀分散在水分子之间，故任意取出一份浓度都相同。定容的本质就是「让离子数固定在 0.1+0.2 = 0.3 mol 的同时，把溶液体积锁定为 500 mL」。

符号表达

n(Na2SO4) = 0.5 L × 0.2 mol/L = 0.1 mol

m = 0.1 mol × 142 g/mol = 14.2 g

c(Na+) = 2 × 0.2 mol/L = 0.4 mol/L

贯通组 2：标准状况下的气体体积与分子数

同一个 22.4 L，装在气体上和装在水上完全是两回事——差别就写在分子的间距里。

宏观现象

标准状况（0 ℃、101 kPa）下，一个 22.4 L 的气球，无论装的是 H2、O2 还是 CO2，都恰好装下 1 mol 气体；但若装入的是水，22.4 L 水的物质的量约为 1244 mol——「22.4 L/mol」对液体完全失效。

微观粒子

气体分子本身极小、间距极大（约为分子直径的 10 倍），同温同压下间距相同，故 1 mol 任何气体（含 NA ≈ 6.02×1023 个分子）占据的体积相同；液体分子间几乎没有空隙，体积由分子本身大小决定，各不相同。

符号表达

n = V / Vm = 22.4 L ÷ 22.4 L/mol = 1 mol

N = n·NA = 6.02×1023（个分子）

22.4 L H2O（标况，液态）：不能用该公式

液体需用密度换算：22.4 L 水质量约 22400 g，n ≈ 22400 ÷ 18 ≈ 1244 mol

贯通组 3：铁片浸入硫酸铜溶液——差量法的来龙去脉

差量法不是巧技，而是对「一进一出两个过程同时发生」的定量描述。先看现象，再看粒子，最后落到比例式。

宏观现象

光亮的银白色铁片浸入蓝色的 CuSO4 溶液，片刻后铁片表面覆盖一层红色固体（析出的铜），溶液蓝色逐渐变浅（充分反应后呈浅绿色，即 FeSO4 溶液的颜色）；取出洗净、干燥后称量，铁片总质量不减反增。

微观粒子

Fe 原子失去 2 个电子变成 Fe2+ 进入溶液，溶液中的 Cu2+ 在铁片表面得到电子析出 Cu 原子。每溶解 1 mol Fe（固体减少 56 g），就析出 1 mol Cu（固体增加 64 g），一进一出，固体净增 8 g——这就是差量法中「每摩尔反应对应 8 g 增重」的微观来源。电子在铁片内部转移，Cu2+ 不必跑到溶液外，这正是置换反应在金属表面就地发生的原因。

符号表达

Fe + CuSO4 → FeSO4 + Cu

离子层面：Fe + Cu2+ → Fe2+ + Cu

差量关系：每 1 mol 反应，Δm(固体) = 64 − 56 = +8 g

实际增重 0.8 g → 反应了 0.1 mol Fe、析出 0.1 mol Cu

例 1 · NA 陷阱辨析（高考选择题经典模型）

题目：设 NA 为阿伏加德罗常数的值，下列说法正确的是（　　）

A. 标准状况下，22.4 L 己烷（C6H14）中含有的分子数为 NA
B. 1 mol Na2O2 与足量水完全反应，转移的电子数为 2NA
C. 1 L 1 mol/L 的 NaCl 溶液中含有的 Na+ 数为 NA
D. 1 mol Fe 与足量稀盐酸反应，失去的电子数为 3NA

【思路点拨】NA 题的本质是「把每个选项翻译成物质的量，再逐项核对前提条件」。常见陷阱只有四类：标况非气体、体积/浓度前提缺失、电子转移数算错、隐含的水解或反应不完全。逐项排雷即可。

1

核对 A：「22.4 L → 1 mol」的前提是该物质在标准状况下为气体。己烷在标准状况下是液体（沸点约 69 ℃），22.4 L 液态己烷的物质的量远大于 1 mol。A 错误（典型「标况非气体」陷阱，同类常客还有 H2O、SO3、苯、CCl4、乙醇）。

2

核对 B：写出反应方程式：

2Na2O2 + 2H2O → 4NaOH + O2↑

Na2O2 中 O 为 −1 价，反应中一半升高到 0 价（O2）、一半降低到 −2 价（NaOH），属于歧化反应：每 2 mol Na2O2 转移 2 mol 电子，即 1 mol Na2O2 只转移 1 mol 电子，数目为 NA 而非 2NA。B 错误。

3

核对 C：n(NaCl) = 1 L × 1 mol/L = 1 mol；NaCl 是强电解质完全电离，Na+ 不水解，n(Na+) = 1 mol，数目恰为 NA。C 正确。注意对比陷阱变体：若只给「1 mol/L NaCl 溶液」而不给体积，则无法确定离子数。

4

核对 D：Fe 与稀盐酸反应生成 Fe2+ 而非 Fe3+：

Fe + 2HCl → FeCl2 + H2↑

1 mol Fe 只失去 2 mol 电子，数目为 2NA。D 错误。（若换成足量 Cl2 加热，则生成 FeCl3，转移 3NA 电子——产物由氧化剂强弱决定。）

【答案】C

【方法总结】NA 辨析四步排雷法：①见「22.4 L」先问「标况吗？是气体吗？」；②见浓度先问「给体积了吗？溶质水解/部分电离吗？」；③见电子转移先写方程式确定产物价态；④见「一定」「均」「完全」警惕特殊物质与可逆反应。

【变式自测】判断正误：①标准状况下 22.4 L SO3 含分子数 NA（错，SO3 标况为固体）；②1 mol CH3COOH 溶液中 H+ 数为 NA（错，醋酸是弱电解质只部分电离，且未给体积）；③常温常压下 22.4 L O2 含分子数 NA（错，非标况）。

例 2 · 物质的量浓度计算与配制（含容量瓶规格陷阱）

题目：实验室需要 480 mL 0.2 mol/L 的 Na2SO4 溶液。请计算需要称取 Na2SO4 固体的质量，并回答：若定容时仰视刻度线，所配溶液浓度如何变化？（已知 Na 23、S 32、O 16）

【思路点拨】容量瓶没有 480 mL 规格，「需要 480 mL」必须选用 500 mL 容量瓶，按 500 mL 计算投料——这是本题的第一个得分点。误差分析抓住 c = n/V，判断哪个量变了、怎么变。

1

确定仪器规格：容量瓶常见规格为 100、250、500、1000 mL，无 480 mL。故选 500 mL 容量瓶，实际配制 500 mL 溶液。

2

计算物质的量：n(Na2SO4) = c × V = 0.2 mol/L × 0.5 L = 0.1 mol。

3

计算质量：M(Na2SO4) = 2×23 + 32 + 4×16 = 46 + 32 + 64 = 142 g/mol；m = n × M = 0.1 mol × 142 g/mol = 14.2 g。

4

误差分析：仰视刻度线时，视线偏低，实际液面超过刻度线才被认为「到位」，即溶液体积 V 偏大；n 不变，由 c = n/V 知所配浓度偏低。（口诀：「俯高仰低」——俯视偏高、仰视偏低。）

【答案】需称取 Na2SO4 固体 14.2 g；定容时仰视刻度线，所配溶液浓度偏低。

【方法总结】配制计算三步走：选规格 → 按所选规格算 n → 换算 m。误差分析只问两句话：n 变了没有？V 变了没有？任何操作都归结到 c = n/V 上，不要背结论。

【误差分析速查表】（c = n/V，先定变量再下结论）

例 3 · 守恒法（电荷守恒）

题目：某溶液中只含 Na+、Mg2+、Cl−、SO42− 四种离子。已知溶液中含 Na+ 0.2 mol、Mg2+ 0.25 mol、Cl− 0.4 mol，求溶液中 SO42− 的物质的量。

【思路点拨】溶液整体呈电中性：所有阳离子带的正电荷总数，必然等于所有阴离子带的负电荷总数。设未知数列一个方程即可，不必知道这些离子来自哪些溶质。

1

设未知数：设 n(SO42−) = x mol。

2

列电荷守恒式：正电荷总量 = 负电荷总量：

n(Na+)×1 + n(Mg2+)×2 = n(Cl−)×1 + n(SO42−)×2

即 0.2×1 + 0.25×2 = 0.4×1 + 2x。

3

求解：0.2 + 0.5 = 0.4 + 2x → 0.7 − 0.4 = 2x → x = 0.15 mol。

【答案】n(SO42−) = 0.15 mol。

【方法总结】守恒法的精髓是「绕过过程、抓住不变量」。除电荷守恒外，常用还有原子守恒（反应前后某元素原子总数不变）、质量守恒（反应前后总质量不变）。写式子时注意：每种离子的电荷要乘上它的电荷数。

【变式自测】把 0.1 mol Na2SO4 和 0.2 mol NaCl 溶于水配成 1 L 溶液，则 c(Na+) = (0.1×2 + 0.2) mol ÷ 1 L = 0.4 mol/L，c(SO42−) = 0.1 mol/L，c(Cl−) = 0.2 mol/L——用「总物质的量 ÷ 总体积」处理混合溶液，注意 Na2SO4 中 Na+ 要乘 2。用电荷守恒复核：0.4×1 = 0.1×2 + 0.2×1 = 0.4 ✓。

例 4 · 差量法（固体质量差）

题目：将质量为 10 g 的铁片放入 CuSO4 溶液中，一段时间后取出，洗净、干燥后称得质量为 10.8 g。求铁片上析出铜的质量。（已知 Fe 56、Cu 64）

【思路点拨】直接设铜的质量列式要同时处理「消耗的铁」和「生成的铜」两个变量，较繁琐。改用差量法：抓住「每反应 1 mol Fe，固体净增重 8 g」这一固定比例，由总增重反推反应量。

1

写方程式并分析质量变化：

Fe + CuSO4 → FeSO4 + Cu　　Δm（固体增重）

每消耗 1 mol Fe（56 g 从固体上进入溶液），同时析出 1 mol Cu（64 g 附着到固体上），固体净增重 64 − 56 = 8 g。

2

建立比例：实际增重 10.8 − 10 = 0.8 g。设析出 Cu 的物质的量为 n，则 n / 1 mol = 0.8 g / 8 g，解得 n = 0.1 mol。

3

换算质量：m(Cu) = 0.1 mol × 64 g/mol = 6.4 g。

【答案】析出铜的质量为 6.4 g。（检验：消耗 Fe 0.1 mol = 5.6 g，10 − 5.6 + 6.4 = 10.8 g ✓）

【方法总结】差量法适用于「反应引起某个总量（质量、体积、压强）变化」的题目。步骤：写方程式 → 找出每摩尔反应对应的差量 → 用实际差量按比例求反应量。验算习惯能帮你规避 90% 的粗心错误。

【变式自测】把铜片放入 AgNO3 溶液中，析出 2.16 g Ag 时铜片质量如何变化？（Cu + 2AgNO3 → Cu(NO3)2 + 2Ag，每 2 mol Ag（216 g）析出对应溶解 1 mol Cu（64 g），固体增重 152 g；2.16 g Ag 对应增重 1.52 g。）

例 5 · 极值法与关系式法（各一微型题）

题目 A（极值法）：由两种金属组成的混合物 13 g，与足量稀硫酸完全反应生成 1 g H2。组成该混合物的两种金属可能是（候选：Mg、Al、Fe、Zn）。（已知 Mg 24、Al 27、Fe 56、Zn 65，H 1）

1

n(H2) = 1 g ÷ 2 g/mol = 0.5 mol，即平均每生成 1 mol H2 消耗金属 13 ÷ 0.5 = 26 g。

2

各金属每生成 1 mol H2 所需质量：Mg + H2SO4 → MgSO4 + H2↑，1 mol Mg 生成 1 mol H2，需 24 g；2Al + 3H2SO4 → Al2(SO4)3 + 3H2↑，2 mol Al（54 g）生成 3 mol H2，每摩尔 H2 需 18 g；Fe + H2SO4 → FeSO4 + H2↑，需 56 g；Zn 同理需 65 g。

3

平均值为 26 g，则两金属的该值必一个小于 26、一个大于 26：小于 26 的有 Mg（24）、Al（18）；大于 26 的有 Fe（56）、Zn（65）。故组合必须是「Mg 或 Al」与「Fe 或 Zn」搭配；Mg+Al（均小于 26）、Fe+Zn（均大于 26）不可能。

【答案】组合为「Mg 或 Al」与「Fe 或 Zn」搭配，即 Mg 和 Fe、Mg 和 Zn、Al 和 Fe、Al 和 Zn。（检验其中一组：若全为 Mg，13 g Mg 生成 H2 13/24 ≈ 0.54 mol > 0.5 mol；若全为 Fe，13 g Fe 生成 13/56 ≈ 0.23 mol < 0.5 mol——实际值恰在两者之间 ✓）

题目 B（关系式法）：用 0.1 mol/L 盐酸滴定 25 mL Na2CO3 溶液，恰好完全反应时消耗盐酸 20 mL，求 Na2CO3 溶液的物质的量浓度。

1

写方程式找关系：

Na2CO3 + 2HCl → 2NaCl + H2O + CO2↑

关系式：Na2CO3 ~ 2HCl。

2

n(HCl) = 0.1 mol/L × 0.02 L = 0.002 mol，则 n(Na2CO3) = 0.002 ÷ 2 = 0.001 mol。

3

c(Na2CO3) = 0.001 mol ÷ 0.025 L = 0.04 mol/L。

【答案】c(Na2CO3) = 0.04 mol/L。

【变式自测】若滴定 25 mL NaOH 溶液消耗 0.1 mol/L 盐酸 20 mL，由关系式 NaOH ~ HCl 得 n(NaOH) = 0.002 mol，c(NaOH) = 0.002 ÷ 0.025 = 0.08 mol/L——一元酸碱 1:1，二元酸/碱别忘乘除 2。再试：滴定 20 mL Na2CO3 溶液消耗 0.05 mol/L 盐酸 16 mL，则 n(HCl) = 0.05 × 0.016 = 0.0008 mol，n(Na2CO3) = 0.0004 mol，c = 0.0004 ÷ 0.02 = 0.02 mol/L。

【方法总结】极值法的关键词是「平均值介于两极端值之间」；关系式法的关键词是「从方程式直接抓计量关系」。多步反应题先把各步方程式叠加成一个总关系式，往往一步出答案。

例 6 · 气体摩尔体积基础计算

题目：标准状况下 33.6 L CO2 的物质的量是多少？质量是多少克？含有多少个 CO2 分子、多少个氧原子？（已知 C 12、O 16，NA 取 6.02×1023 mol−1）

【思路点拨】先核对前提：标准状况 ✓、气体 ✓，可用 22.4 L/mol。再由 n 为中心，分别通向质量与粒子数；算原子数时不要忘记每个分子含 2 个 O 原子。

1

求物质的量：n(CO2) = 33.6 L ÷ 22.4 L/mol = 1.5 mol。

2

求质量：M(CO2) = 12 + 2×16 = 44 g/mol；m = 1.5 mol × 44 g/mol = 66 g。

3

求分子数：N(CO2) = 1.5 mol × 6.02×1023 mol−1 = 9.03×1023（个），即 1.5NA。

4

求氧原子数：每个 CO2 含 2 个 O，n(O) = 2 × 1.5 = 3 mol，N(O) = 3NA = 1.806×1024（个）。

【答案】1.5 mol；66 g；1.5NA（9.03×1023）个分子；3NA（1.806×1024）个氧原子。

【方法总结】所有「量→量」的换算都过 n 这座桥：体积 → n → 质量 / 粒子数。涉及原子、电子数时，先写出「每个微粒含几个目标粒子」再乘，这是最常见的漏乘点。

【变式自测】标准状况下 11.2 L NH3：n = 0.5 mol，m = 0.5 × 17 = 8.5 g，分子数 0.5NA，原子总数 0.5 × 4 = 2 mol 即 2NA 个（每个 NH3 含 4 个原子，别只乘 3）。

例 7 · 阿伏加德罗定律及推论应用

题目：同温同压下，等质量的 SO2 和 CO2 气体，体积之比是多少？若改为同温同体积，二者的压强之比是多少？（已知 S 32、C 12、O 16）

【思路点拨】同温同压下 V 与 n 成正比；同温同体积下 p 与 n 成正比。等质量时 n 与 M 成反比，抓住「n = m/M」即可。

1

求摩尔质量：M(SO2) = 32 + 2×16 = 64 g/mol；M(CO2) = 12 + 2×16 = 44 g/mol。

2

设质量均为 m g，求物质的量之比：n(SO2) : n(CO2) = m/64 : m/44 = 44 : 64 = 11 : 16。

3

同温同压：V(SO2) : V(CO2) = n(SO2) : n(CO2) = 11 : 16。

4

同温同体积：p(SO2) : p(CO2) = n(SO2) : n(CO2) = 11 : 16。

【答案】同温同压下体积比 11 : 16；同温同体积下压强比 11 : 16。（检验：等质量时 CO2 更「轻」、物质的量更大，体积与压强都应是 CO2 更大，11 : 16 中后者更大 ✓）

【方法总结】等质量的气体，物质的量与摩尔质量成反比——「越轻的气体物质的量越大」。记住推论的方向：定温定容比压强，定温定压比体积，定温定压密度比等于摩尔质量比。

【变式自测】同温同压下某气体对空气的相对密度约为 1.52，则其 M ≈ 1.52 × 29 ≈ 44 g/mol，可能是 CO2（M = 44）；相对密度法是有机推断中求未知气体摩尔质量的常用入口。再问一句：同温同压下 1 L O2 与 1 L H2 的质量比是多少？M 之比即质量之比：32 : 2 = 16 : 1。

例 8 · 关系式法（多步反应：接触法制硫酸）

题目：工业上以硫黄为原料制硫酸，反应分三步：

S(s) + O2(g) → SO2(g) 2SO2(g) + O2(g) → 2SO3(g) SO3(g) + H2O(l) → H2SO4(aq)

理论上 64 kg 硫黄（按纯 S 计）最多可制得多少千克硫酸？（已知 S 32、H 1、O 16）

【思路点拨】不必逐步计算 SO2、SO3 的产量。观察三步反应：1 mol S → 1 mol SO2 → 1 mol SO3 → 1 mol H2SO4，硫原子全程守恒，直接建立关系式 S ~ H2SO4。

1

建立关系式：由三步方程式的化学计量数，S ~ SO2 ~ SO3 ~ H2SO4，即 S ~ H2SO4（1 : 1）。

2

求摩尔质量：M(S) = 32 g/mol；M(H2SO4) = 2×1 + 32 + 4×16 = 98 g/mol。

3

列比例：32 kg S 对应 98 kg H2SO4，故 64 kg S 对应 x = 98 × 64 ÷ 32 = 196 kg。

【答案】理论上最多可制得 196 kg 硫酸。（用物质的量复核：n(S) = 64000 g ÷ 32 g/mol = 2000 mol → n(H2SO4) = 2000 mol → m = 2000 × 98 = 196000 g = 196 kg ✓）

【方法总结】多步反应抓「首尾关系」：利用某原子（这里是 S）全程守恒，把原料与最终产品直接挂钩。工业流程题中产率计算常在此基础上乘一个转化率。

【变式自测】若上述流程硫的总利用率为 95%，则 64 kg 硫黄实际制得硫酸 196 × 0.95 = 186.2 kg——关系式法求理论值，再乘利用率得实际值，两步分工明确。

例 9 · 配制步骤与仪器（实验题小问原型）

题目：实验室用 Na2CO3 固体配制 250 mL 0.1 mol/L 的 Na2CO3 溶液。请回答：（1）需称取 Na2CO3 固体的质量；（2）按操作先后排列：①定容 ②转移 ③称量 ④溶解 ⑤计算 ⑥洗涤 ⑦摇匀；（3）本实验必须用到的玻璃仪器有哪些？（已知 Na 23、C 12、O 16）

【思路点拨】先选规格（250 mL 容量瓶是常见规格，直接按 250 mL 计算）；步骤顺序记「算、称、溶、（冷）、转、洗、定、摇」；仪器按每一步想一想用什么。

1

计算称量：n = 0.25 L × 0.1 mol/L = 0.025 mol；M(Na2CO3) = 106 g/mol；m = 0.025 × 106 = 2.65 g ≈ 2.7 g（托盘天平精确到 0.1 g，按 2.7 g 称取）。

2

步骤排序：⑤计算 → ③称量 → ④溶解（冷却后）→ ②转移 → ⑥洗涤 → ①定容 → ⑦摇匀，即 ⑤③④②⑥①⑦。

3

玻璃仪器：烧杯（溶解）、玻璃棒（搅拌与引流）、250 mL 容量瓶（定容主体）、胶头滴管（定容末端滴加）。注意：量筒在本实验中可有可无（溶解用水不需精确量取），托盘天平不是玻璃仪器。

【答案】（1）2.7 g；（2）⑤③④②⑥①⑦；（3）烧杯、玻璃棒、250 mL 容量瓶、胶头滴管。

【方法总结】仪器清单用「流程回忆法」：跟着操作步骤走一遍，每步问自己用什么器皿，就不会漏掉胶头滴管或容量瓶。天平读数精确到 0.1 g 这一点，常在计算结果取整时考查。

【变式自测】配制 100 mL 1.0 mol/L NaCl 溶液：n = 0.1 mol，m = 0.1 × 58.5 ≈ 5.9 g；选 100 mL 容量瓶；仪器同样为烧杯、玻璃棒、100 mL 容量瓶、胶头滴管。

例 10 · 混合气体平均摩尔质量（十字交叉思想）

题目：由 CO2 和 H2 组成的混合气体，平均摩尔质量为 16 g/mol。求混合气体中 CO2 与 H2 的体积比。（已知 C 12、O 16、H 1）

【思路点拨】平均摩尔质量是物质的量的加权平均：M̄ = m(总)/n(总)，介于两组分摩尔质量之间。设物质的量列方程最稳妥；熟练后可用十字交叉法口算。

1

求各组分摩尔质量：M(CO2) = 44 g/mol，M(H2) = 2 g/mol，M̄ = 16 g/mol，确满足 2 < 16 < 44，组成合理。

2

设未知数列方程：设 n(CO2) = a、n(H2) = b，则 (44a + 2b)/(a + b) = 16。

3

求解：44a + 2b = 16a + 16b → 28a = 14b → b = 2a，即 n(H2) : n(CO2) = 2 : 1。

4

换算体积比：同温同压下体积比 = 物质的量之比，故 V(CO2) : V(H2) = 1 : 2。

【答案】V(CO2) : V(H2) = 1 : 2。（十字交叉速算：CO2 44 与 H2 2 对均值 16，差值 16−2 = 14 与 44−16 = 28，n(CO2) : n(H2) = 14 : 28 = 1 : 2 ✓）

【方法总结】「平均值 + 两端值」结构是极值法/十字交叉法的共同信号：均值必介于两端之间，差值之比即物质的量的反比。此法在原子量计算（同位素丰度）中还会再见面。

五、易错点与成因

每条易错点都按「表现 → 成因 → 正解 → 口诀」四层拆解。知道「为什么会错」，比记住「不要错」更有用——成因理解了，同类陷阱会自动现形。

易错点 1

易错表现：看到「22.4 L」就除以 22.4 L/mol 得 1 mol。

错误成因：把 22.4 L/mol 当成普适常数，忽略了它的两个前提——标准状况 + 气体。命题人正是利用这种「条件反射」，把水、SO3、己烷、苯、CCl4 等标况下非气态物质塞进选项。

正确理解：先用「标况吗？气体吗？」两问过滤；两问都通过才允许使用 22.4 L/mol。非气体物质的体积只能用密度或浓度换算。

避坑口诀：「二十二点四，标况且气体。」

易错点 2

易错表现：由「1 mol/L NaCl 溶液」直接得出「Na+ 数为 NA」；或认为「从 1 mol/L 溶液中取出一半，浓度变为 0.5 mol/L」。

错误成因：混淆了浓度（强度量，与体积无关）与物质的量（与体积成正比）。只给浓度不给体积，n 根本无法确定。

正确理解：n = c·V，二者缺一不可；取出部分溶液浓度不变，所含溶质的物质的量按比例减少。还要注意溶质是否水解、是否部分电离（如 CH3COOH 为弱电解质，1 L 1 mol/L 醋酸溶液中 H+ 数远小于 NA）。

避坑口诀：「浓度不给体积，粒子数目免谈。」

易错点 3

易错表现：需要 480 mL 溶液时按 480 mL 计算称量；或把「将 1 mol NaCl 溶于 1 L 水」当作 1 mol/L。

错误成因：不知道容量瓶只有固定规格（100/250/500/1000 mL），也混淆了「溶液体积」与「溶剂体积」——物质的量浓度定义中的 V 是溶液体积。

正确理解：选容量瓶按「就近向上」原则，需 480 mL 选 500 mL 并按 500 mL 投料；描述浓度时必须说「配成多少体积的溶液」，溶解后溶液的体积不等于水的体积。

避坑口诀：「容量瓶，往上靠；浓度看溶液，不是看溶剂。」

易错点 4

易错表现：电子转移数目判断错误，如认为 1 mol Na2O2 与水反应转移 2 mol 电子、1 mol Fe 与稀盐酸反应转移 3 mol 电子。

错误成因：没有先写方程式、没有先确定产物的真实价态，凭「感觉」数电子。Na2O2 的歧化、Fe 遇弱氧化剂只到 +2 价，都是命题人的固定套路。

正确理解：先写方程式定产物，再算单个原子变价 × 变价原子数。歧化反应中同一物质既升又降，转移电子数只按「升高部分」或「降低部分」算一次，不能两头相加。

避坑口诀：「电子转移先写式，产物价态定乾坤。」

易错点 5

易错表现：摩尔质量写成「98」或「98 g」；相对分子质量写成「98 g/mol」。

错误成因：三者数值相等（如 H2SO4 的相对分子质量 98、摩尔质量 98 g/mol、1 mol 质量 98 g），数值相同掩盖了单位与物理意义的差别，考试中一放松就丢单位分。

正确理解：相对分子（原子）质量是比值、无单位；摩尔质量单位 g/mol；质量单位 g。填空时看清题目问的是哪一个，再决定写不写单位、写什么单位。

避坑口诀：「数值三胞胎，单位各不同。」

易错点 6

易错表现：误差分析靠背结论，题目换个操作就判断失误；或认为「摇匀后液面低于刻度线要补加水」。

错误成因：没有回到 c = n/V 的根本定义，把「俯高仰低」等口诀当成万能钥匙；不理解摇匀后瓶颈残留液体导致液面下降是正常现象。

正确理解：任何操作先翻译成对 n 或 V 的影响，再用 c = n/V 推出结果。摇匀后液面低于刻度线是正常的，再加水反而使 V 偏大、浓度偏低。

避坑口诀：「误差问 n 和 V，定义面前无口诀。」

易错点 7

易错表现：由「同温同压同体积的 H2 与 O2 分子数相同」推出「原子数相同」「质量相同」；或认为「22.4 L/mol 出现时一定是标准状况」。

错误成因：阿伏加德罗定律只保证分子数相同，不同气体每个分子含原子数不同（H2、O2 都是双原子分子，原子数恰好相同；但 H2 与 O3 就不同）、摩尔质量不同（2 g/mol vs 32 g/mol，质量相差 16 倍）。另外，非标准状况通过升温增压也可能出现 22.4 L/mol，把 Vm 的数值当成标况的「身份证」是逻辑倒置。

正确理解：阿伏加德罗定律的结论止于分子数；要比较原子数需乘每个分子的原子数，要比较质量需乘摩尔质量。判断「标准状况」只能看温度压强（0 ℃、101 kPa），不能由 22.4 L/mol 反推。

避坑口诀：「定律只管分子数，原子质量另起算。」

易错点 8

易错表现：计算 n = c·V 时 V 直接代入 mL 数值；滴定题中 20 mL、25 mL 不换算成 L，结果相差 1000 倍。

错误成因：浓度的单位是 mol/L，公式 n = c·V 要求 V 以 L 为单位；题目给的数据几乎总是 mL，着急代入是计算丢分的头号粗心。

正确理解：见到体积先化 L：20 mL = 0.02 L、25 mL = 0.025 L。养成「先写单位再计算」的习惯，n = 0.1 mol/L × 0.02 L = 0.002 mol 这样带单位写，错误会大幅减少。

避坑口诀：「毫升换升再相乘，单位跟着数字走。」

七、高考怎么考

对照近年全国卷（云南适用）的命题方式，本章考法与应对如下：

  • 选择题（必考）：NA 辨析题，常以 4 个选项覆盖 4 类陷阱（标况非气体、缺体积、电子转移、弱电解质/水解），本章例 1 就是原型。目标：60 秒内满分。
  • 选择题（常考）：阿伏加德罗定律推论（密度比、体积比）、溶液浓度与离子浓度换算，难度低，属于「稳拿分」。
  • 实验综合题：溶液配制步骤排序、仪器选择（容量瓶规格）、误差分析，常以 2~4 分的小问嵌入大题。
  • 工业流程与反应原理大题：产率、转化率、K 值计算的本质都是本章的 n、c、守恒法组合，本章是大题计算的「地基」。
  • 答卷建议：计算结果保留有效数字与题目数据一致（通常 2~3 位）；比例式、单位、答案三件套缺一不可，「列式对、结果错」同样丢分，务必验算。

八、与前后章节的联系

本章是全书的「计算中枢」：向后，离子反应（3.3）、氧化还原（3.4）中的定量计算都以 n 为核心语言；向前，热化学、化学平衡、电化学、工业流程中的产率与转化率计算，全部是本章方法的组合运用。建议学完 3.4 氧化还原后回做本章例 1、例 4，你会有「原来如此」的通透感。

给小兵的一句话：物质的量不难，难在「细」。把每一道错题归因到「标况没看」「单位没换」「价态没写对」这类具体动作上，三个月后你会发现 NA 题真的只是送分题。计算的信心，是一题一题验算出来的。

本章复习节奏建议：第一遍通读概念卡片并默写四个公式；第二遍只做例题的「变式自测」；第三遍合上材料逐条过自检清单。三遍之间各隔一周，让遗忘曲线替你筛选出真正需要回炉的点。

3.2 化学用语与化学基本概念

高中化学 · 深度学习材料 · 面向 2029 届云南高考

化学用语是化学学科的「书面语言」，物质分类与胶体是认识物质世界的第一把「尺」。本章看似零散，却是高考选择题的常驻考点：一个电子式写错、一次分类判断失误，都是可以直接避免的失分。把规范写成本能，就是本章的全部要求。

二、核心概念精讲

五张概念卡片覆盖本章全部考点。每张卡片按「定义 → 微观理解 → 边界与特例 → 易混淆点」展开，特例和边界是命题人最偏爱的地方，请重点标注。

核心概念 1

物质的分类：标准先行，逐级细分

分类树：物质先分混合物（由两种或多种物质混合，如空气、盐酸、漂白粉、所有溶液）与纯净物（只含一种物质，有固定组成和性质）；纯净物再分单质（只含一种元素，如 O2、Fe、液氯）与化合物（含两种及以上元素，如 H2O、Na2CO3）；化合物再分为氧化物、酸、碱、盐等。

随手练：给下列物质定位到分类树的「叶子」——氧气（纯净物·单质）、氧化镁（纯净物·化合物·氧化物）、石灰水（混合物）、硫酸（纯净物·化合物·酸）、氢氧化钾（纯净物·化合物·碱）、碳酸钙（纯净物·化合物·盐）。

判断口诀与要点：

  • 先问「是不是一种物质」，再问「是不是一种元素」。盐酸是 HCl 气体的水溶液，含 HCl 和 H2O 两种物质 → 混合物；液氯、液氧是 Cl2、O2 的液态 → 纯净物中的单质。
  • 酸：电离时生成的阳离子全部是 H+ 的化合物，如 HCl、H2SO4。注意 NaHSO4 虽能电离出 H+，但同时电离出 Na+，属于盐（酸式盐）不是酸。
  • 碱：电离时生成的阴离子全部是 OH− 的化合物，如 NaOH、Ba(OH)2；Cu2(OH)2CO3（碱式碳酸铜）是碱式盐。
  • 盐：由金属阳离子（或 NH4+）与酸根离子构成的化合物，如 NaCl、Na2CO3（纯碱是盐不是碱！）。
  • 用电离方程式看酸碱：HCl → H+ + Cl−（阳离子全是 H+，是酸）；NaOH → Na+ + OH−（阴离子全是 OH−，是碱）；NaHSO4 → Na+ + H+ + SO42−（还有 Na+，是盐）——电离方程式是酸碱判据的「显微镜」。
  • 氧化物：由两种元素组成且其中一种是氧的化合物。酸性氧化物（如 CO2、SO3，与碱反应生成盐和水）、碱性氧化物（如 CaO、CuO，与酸反应生成盐和水）、两性氧化物（Al2O3）、不成盐氧化物（CO、NO）。注意：Na2O2 是过氧化物，不属于碱性氧化物。

常见混淆对：

  • 同素异形体：同种元素组成的不同单质，如 O2 与 O3、金刚石与石墨、红磷与白磷。它们的混合（如 O2 与 O3 混合）是混合物。
  • 同位素：质子数相同、中子数不同的同种元素的不同原子，如 1H、2H（D）、3H（T）；12C 与 14C。比较对象一个是单质、一个是原子，切勿混淆。

同位素与同素异形体对照表：

比较项同位素同素异形体
比较对象原子单质
相同之处质子数相同（同种元素）组成元素相同
不同之处中子数不同结构、性质不同
实例1H、2H、3HO2 与 O3；金刚石与石墨
相互转化不能通过化学变化转化可通过化学变化相互转化（如石墨高温高压变金刚石）
  • 纯碱（Na2CO3）是盐；水银（Hg）是单质不是混合物；冰水混合物是纯净物（只含 H2O 一种分子）；漂白粉是 Ca(ClO)2 与 CaCl2 的混合物。

氧化物的反应特征（判断氧化物的第二个「尺子」）：

  • 酸性氧化物与碱反应生成盐和水：CO2 + 2NaOH → Na2CO3 + H2O；SO3 + Ca(OH)2 → CaSO4 + H2O。
  • 碱性氧化物与酸反应生成盐和水：CaO + 2HCl → CaCl2 + H2O；CuO + H2SO4 → CuSO4 + H2O。
  • 特例：SiO2 是酸性氧化物但不溶于水、不与水反应；Al2O3 既能与酸又能与碱反应（两性氧化物）；Mn2O7 是金属氧化物却属于酸性氧化物——「金属氧化物一定碱性、非金属氧化物一定酸性」是伪规律。
核心概念 2

分散系与胶体：粒径决定一切

是什么：一种（或多种）物质分散到另一种物质中形成的体系叫分散系，被分散的物质叫分散质，容纳分散质的叫分散剂。按分散质粒子的直径分类：

  • 溶液：粒径 < 1 nm（如 NaCl 溶液），均一、透明、稳定。
  • 胶体：粒径 1~100 nm（如 Fe(OH)3 胶体、豆浆、雾、牛奶、血液），均一、较稳定（介稳体系）。
  • 浊液：粒径 > 100 nm（如泥水），不均一、不稳定、静置分层或沉降。

三类分散系比较表：

分散系粒径外观稳定性透过滤纸透过半透膜丁达尔效应实例
溶液< 1 nm均一透明稳定能能无NaCl 溶液
胶体1~100 nm均一透明介稳能不能有Fe(OH)3 胶体、豆浆
浊液> 100 nm不均一不稳定不能不能无泥水、油水混合物

渗析：胶粒不能透过半透膜，而溶液中的离子、小分子可以。把含杂质的胶体放入半透膜袋、浸入流动水中，杂质离子逐渐渗出——这就是提纯胶体的方法（如除去 Fe(OH)3 胶体中残留的 HCl）。血液透析利用的就是这一原理。

生活中的胶体实例（选择题素材库）：

  • 气溶胶：云、雾、烟（分散剂是气体）。
  • 液溶胶：豆浆、牛奶、墨水、血液、Fe(OH)3 胶体（分散剂是液体）。
  • 固溶胶：有色玻璃、烟水晶（分散剂是固体）。
  • 早晨森林里光束、影院放映机的光柱、车灯在雾中的光柱——都是丁达尔效应。

为什么（微观解释）：胶体的所有特性都源于「1~100 nm」这个尺度——粒子比溶液中的离子大得多，足以散射可见光（丁达尔效应）；又比重力沉降所需的颗粒小得多，且胶粒表面吸附同种电荷的离子而相互排斥（故胶体稳定、能发生电泳）。粒径是本质，现象是粒径的「外在表现」。

胶体三大性质：

  • 丁达尔效应：用一束可见光（激光笔）照射胶体，从入射光的垂直方向可看到一条光亮的「通路」。成因是胶体粒子对光的散射。这是区分胶体与溶液最简便的物理方法。
  • 电泳：在电场作用下，胶体粒子向某一电极定向移动。说明胶体粒子带电（Fe(OH)3 胶粒带正电，向阴极移动）。注意：胶体整体呈电中性，带电的只是胶粒。
  • 聚沉：胶粒聚集成较大颗粒而沉降。方法：①加入电解质（电离出的反号离子中和胶粒电荷）；②加入带相反电荷胶粒的胶体；③加热。应用：三角洲的形成（河水中的泥沙胶体遇海水中电解质聚沉）、明矾净水、卤水点豆腐、不同品牌墨水混用堵笔。
  • 布朗运动：胶体粒子在分散剂分子的撞击下做无规则运动，是胶体不易沉降的辅助原因（注意：布朗运动不是胶体独有，花粉在水中也有）。

三大性质中，丁达尔效应用于鉴别，电泳证明胶粒带电，聚沉用于破坏胶体——用途各不相同，选择题常把三者张冠李戴。

Fe(OH)3 胶体的制备（实验题高频）：向沸水中逐滴加入 FeCl3 饱和溶液 5~6 滴，继续煮沸至液体呈红褐色，立即停止加热：

FeCl3 + 3H2O → Fe(OH)3（胶体） + 3HCl

注意事项：不能用自来水代替蒸馏水（电解质使胶体聚沉）；不能用 FeCl3 与 NaOH 反应制备（直接生成 Fe(OH)3 红褐色沉淀）；不能长时间或过度加热（胶体受热聚沉）。方程式中产物写「Fe(OH)3（胶体）」，不写沉淀符号↓。

常见混淆：胶体不是「胶状的物质」（如果冻、胶水不一定是胶体），也不是一种物质种类，而是一种分散状态——同种物质在不同分散剂中可形成胶体或浊液。

核心概念 3

化学用语：五种表示方法各司其职

① 化学式（分子式）：用元素符号表示物质组成的式子，如 H2SO4、Na2CO3。离子化合物（如 NaCl）中不存在单个分子，化学式表示的是离子个数比（最简比），不能叫分子式。

② 电子式：在元素符号周围用「·」或「×」标出最外层电子的式子。

  • 原子：如 Na· 、·Cl·（氯原子周围共 7 个点）。
  • 离子化合物（如 NaCl）：写成 Na+[︰Cl︰]−——阳离子写离子符号，阴离子用方括号括起并标电荷，方括号内 Cl 周围应有 8 个电子（上下左右四对，平面书写常用左右两对示意，答题时须画全）。绝不能把 NaCl 写成 Na︰Cl︰（那是共价结合的画法）。
  • 共价化合物（如 HCl、CO2）：共用电子对，没有方括号和电荷。HCl 写为 H︰Cl︰（Cl 周围补齐 8 电子）；CO2 中 C 与每个 O 共用两对电子。绝不能把 HCl 写成 H+[︰Cl︰]−。
  • 书写判据：先判断化合物类型（离子/共价），再决定用不用方括号。

进阶电子式示例（高考常考写法）：

  • Na2O2（过氧化钠）：两个 Na+ 夹一个过氧根 [︰O—O︰]2−，两个 O 之间共用一对电子——过氧根是整体，不能拆写成两个独立的 O2−。
  • MgCl2：写成 [︰Cl︰]−Mg2+[︰Cl︰]−，两个 Cl− 必须分写在 Mg2+ 两侧，不能合并成 Mg2+[︰Cl︰]2−。
  • NH4Cl：阳离子 NH4+ 内部是共价键（N 与 4 个 H 共用电子对）且要加方括号标「+」，Cl− 单独带方括号标「−」——同一物质中既有离子键又有共价键的典型。
  • CO2：C 与每个 O 共用两对电子，写作 Ö::C::Ö（每侧 O 各有 4 个未成键电子），对应结构式 O=C=O。

③ 结构式：用短线表示共用电子对的式子，一对共用电子画一条短线，如 HCl：H—Cl；CO2：O=C=O；H2O：H—O—H。结构式只画成键电子对，不画孤对电子。

④ 结构简式：结构式的简化写法，省略部分短线，多用于有机物，如 CH3COOH（乙酸）、CH2=CH2（乙烯，碳碳双键不能省略）。

五种表示方法对照表（以乙酸为例逐级递进）：

表示方法写法提供的信息
最简式（实验式）CH2O原子个数最简比
分子式（化学式）C2H4O2分子中各原子真实数目
结构式CH3—C(=O)—O—H（展开全部短线）原子的连接方式与成键数目
结构简式CH3COOH保留官能团，省略 C—H 等短线
电子式画出各原子最外层电子及共用电子对成键的电子层面来源

⑤ 原子结构示意图：圆圈标核电荷数（质子数），弧线表示电子层，弧线上数字表示该层电子数。如 Na：+11，电子层排布 2、8、1；Cl：+17，排布 2、8、7。要点：各层电子数 ≤ 2n2，最外层 ≤ 8。

⑥ 核素符号：AZX，左下角 Z 为质子数（= 核电荷数 = 原子序数），左上角 A 为质量数（= 质子数 + 中子数）。如 3717Cl：质子 17、中子 37 − 17 = 20。注意上下位置不可颠倒，质子数必须与元素种类相符。

①化学式的四层意义（以 H2O 为例）：宏观上表示水这种物质、表示水由氢氧两种元素组成；微观上表示一个水分子、表示一个水分子由 2 个氢原子和 1 个氧原子构成。对离子化合物（如 NaCl），只能表示「由钠元素和氯元素组成、离子个数比 1 : 1」，不能说「一个 NaCl 分子」。

常见混淆：「化学式」对离子化合物只是比例式；「结构式」中的短线数 = 共用电子对数；比例模型、球棍模型是模型不是式子。考试问哪一种就必须写哪一种，写错种类不给分。

核心概念 4

化合价：化合物中的「电子账本」

是什么：化合价表示原子间相互化合时的数目关系，本质是成键时电子得失或偏移的数目。得电子（或电子对偏向）显负价，失电子（或电子对偏离）显正价。

核心规则：

  • 化合物中各元素正负化合价的代数和为零；单质中元素化合价为 0。
  • 常见固定价：H 通常 +1（与金属成氢化物如 NaH 时为 −1）；O 通常 −2（过氧化物如 H2O2、Na2O2 中为 −1，OF2 中为 +2）；金属无负价。
  • 原子团整体计价：SO42− 中 S 为 +6、NO3− 中 N 为 +5、NH4+ 中 N 为 −3。
  • 许多元素有变价：Fe 有 +2、+3；Cl 有 −1、0、+1、+3、+5、+7；S 有 −2、0、+4、+6；N 有 −3、+2、+3、+4、+5。

常见元素化合价口诀：一价钾钠氯氢银，二价氧钙钡镁锌；三铝四硅五价磷，二三铁、二四碳；二四六硫都齐全，铜汞二价最常见。口诀给出的是「常见价」，遇到具体化合物仍以「代数和为零」计算为准。

计算方法（代数和为零列方程）：以 K2Cr2O7 为例：2×(+1) + 2x + 7×(−2) = 0，解得 x = +6，即 Cr 为 +6 价。

平均化合价：Fe3O4 中按代数和算得 Fe 平均为 +8/3 价（实际是 2 个 Fe3+ 与 1 个 Fe2+）；Na2S2O3（硫代硫酸钠）中 S 平均为 +2 价。平均价可以是分数，它是「账本均值」，不代表每个原子的真实价态。

化合价与离子电荷的关系：简单离子的电荷数 = 该元素在该化合物中化合价的绝对值，符号也一致——Mg2+ 对应 +2 价，Cl− 对应 −1 价。这就是为什么「升失氧、降得还」的氧化还原分析（3.4）可以从化合价直接读出电子转移数。

核心概念 5

化学方程式的书写与配平

书写规则：①以客观事实为基础，产物必须真实；②遵守质量守恒，必须配平；③注明反应条件（点燃、加热△、催化剂、高温、通电等）；④标状态符号与 ↑↓——反应物中无气体时生成的气体标 ↑，溶液中反应生成的不溶性固体标 ↓。

配平方法：

  • 观察法：适用于简单反应，如 C + O2 → CO2。
  • 最小公倍数法：先配出现次数少且原子数不等两边的元素。如配平 P + O2 → P2O5：O 原子 2 与 5 的最小公倍数为 10，O2 前配 5、P2O5 前配 2，再配 P 为 4。
  • 奇数配偶法：把出现次数多且一边为奇数的原子先配成偶数，如 FeS2 + O2 → Fe2O3 + SO2 中先把 Fe2O3 配 2 使 Fe 成偶数 4（见例 5）。
  • 设 1 法（暂定系数法）：把最复杂物质的系数定为 1，依次推出其余，最后去分母，适用于有机物燃烧，如 C2H5OH + 3O2 → 2CO2 + 3H2O。

方程式的双重意义：质的方面——什么物质在什么条件下生成什么；量的方面——化学计量数之比 = 物质的量之比 = 粒子数之比（气体间还等于同温同压下的体积之比）。例如 2H2 + O2 → 2H2O 表示：2 mol H2 与 1 mol O2 恰好完全反应生成 2 mol H2O，这正是第 3.1 章「关系式法」的依据。

配平自测（先遮住答案）：

  • __C2H6 + __O2 → __CO2 + __H2O　【答案：2、7、4、6；用设 1 法，C2H6 定 1 得 7/2，整体乘 2】
  • __Al + __HCl → __AlCl3 + __H2↑　【答案：2、6、2、3；先配 Cl 再配 H，H2 前为 3】
  • __CuO + __CO → __Cu + __CO2　【答案：1、1、1、1；观察法】
注意

条件不是装饰：H2 与 O2 常温共存无事，点燃才爆炸；「点燃」与「加热」不同，「高温」与「加热」也不同。漏写、错写条件，高考按错误处理。

三、三重表征贯通

本章的概念看似抽象，其实都有对应的实验场景。下面三组贯通，把宏观现象、微观粒子、符号表达钉在一起——选择题的选项往往只考其中一重，三全会，才能以不变应万变。

贯通组 1：Fe(OH)3 胶体的制备与丁达尔效应

这组贯通回答一个问题：为什么「红褐色透明液体」是胶体而不是沉淀？答案写在粒子的尺寸与电荷里。

宏观现象

向沸腾的蒸馏水中逐滴加入 FeCl3 饱和溶液，液体逐渐变为红褐色，透明、均一，无沉淀产生；用激光笔从侧面照射，杯中液体出现一条光亮的通路（丁达尔效应）；静置数日也不分层。若改用 NaOH 溶液与 FeCl3 混合，则立即出现红褐色沉淀，液体浑浊。

微观粒子

Fe3+ 在热水中水解，聚集成直径 1~100 nm 的 Fe(OH)3 胶体粒子；胶粒表面选择性吸附阳离子而带正电，同种电荷相互排斥，阻止了胶粒聚集变大，故体系稳定不沉降；1~100 nm 的粒子足以散射可见光，于是形成光路。NaOH 直接提供大量 OH−，瞬间生成大于 100 nm 的颗粒，只能得到沉淀而非胶体。

符号表达

FeCl3 + 3H2O → Fe(OH)3（胶体） + 3HCl

分散质粒径：1~100 nm

检验：激光笔照射 → 光亮通路

对比：FeCl3 + 3NaOH → Fe(OH)3↓ + 3NaCl（得到沉淀）

贯通组 2：钠在氯气中燃烧——离子键的形成

白烟、黄光、放热，三个现象背后是同一个微观事件：电子从钠原子「搬」到氯原子。

宏观现象

取一小块金属钠，用滤纸吸干煤油，在空气中加热至熔成小球后伸入盛有黄绿色氯气的集气瓶：钠剧烈燃烧，发出黄色火焰，产生大量白烟，放出大量的热；反应结束后瓶壁上附着白色固体（NaCl 细小晶体）。

微观粒子

Na 原子（电子层 2、8、1）最外层只有 1 个电子，易失去成为 Na+（2、8，稳定结构）；Cl 原子（2、8、7）易得 1 个电子成为 Cl−（2、8、8）。Na+ 与 Cl− 通过静电作用（离子键）结合，大量离子规则排列成 NaCl 微小晶体——宏观上的「白烟」正是这些固体小颗粒。电子由 Na 原子转移给 Cl 原子，是化合价升降（Na 0→+1，Cl 0→−1）的微观本质。

符号表达

2Na(s) + Cl2(g) → 2NaCl(s)

原子结构示意图：Na（+11）2、8、1 → Na+（+11）2、8

电子式：Na+[︰Cl︰]−（Cl 周围共 8 个电子）

贯通组 3：盐酸与氢氧化钠的中和反应

酸碱中和是「化学方程式 — 离子本质 — 宏观现象」对应最干净的一组反应，也是下一章离子反应的入口。

宏观现象

向滴有酚酞的 NaOH 溶液（呈红色）中逐滴加入稀盐酸，溶液红色逐渐变浅，恰好完全反应时恰好褪为无色；用手触摸烧杯外壁，明显感觉发热——中和反应放热。得到的溶液蒸发后留下白色固体 NaCl。

微观粒子

盐酸中的 H+ 与 NaOH 溶液中的 OH− 结合生成极难电离的 H2O 分子，使溶液中自由移动的 H+、OH− 减少；Na+ 与 Cl− 自始至终没有结合，只是「旁观」。放热来自 H—O 键的形成。OH− 被消耗尽时，酚酞的红色也就消失了。

符号表达

HCl + NaOH → NaCl + H2O

离子层面：H+ + OH− → H2O

计量关系：HCl ~ NaOH（1 : 1）

n(HCl) = n(NaOH) 时恰好中和

四、典型例题分步拆解

八道例题覆盖本章全部题型：分类辨析（例 1）、化合价计算（例 2）、化学用语判断（例 3、例 6）、胶体（例 4、例 8）、配平（例 5）、氧化物辨析（例 7）。每题先独立做，再对照拆解找断点。

例 1 · 物质分类辨析（高考选择题经典模型）

题目：下列物质属于纯净物的是（　　）

A. 盐酸　　B. 液氯　　C. 漂白粉　　D. 洁净的空气

【思路点拨】分类题先问一句话：「它只含一种物质吗？」凡是名称带「溶液」或本身是混合体系的（盐酸、空气、漂白粉、氨水、海水），无论多「干净」都是混合物；「液 X」通常是单质液化后的纯净物。

1

A 盐酸：HCl 气体溶于水得到的溶液，含 HCl 和 H2O 两种物质 → 混合物。注意：说「氯化氢」才是纯净物，「盐酸」一定是混合物。

2

B 液氯：Cl2 加压降温液化所得，只含 Cl2 分子 → 纯净物（且是单质）。同类：液氧、液氨、水银、干冰均为纯净物。

3

C 漂白粉：Cl2 通入石灰乳制得，主要成分为 Ca(ClO)2 和 CaCl2 两种物质 → 混合物（有效成分是 Ca(ClO)2）。

4

D 洁净的空气：「洁净」不等于「纯净」，空气含 N2、O2、CO2 等多种物质 → 混合物。

【答案】B

【方法总结】纯净物判断三问：只含一种物质吗？（是 → 纯净物）只含一种元素吗？（是 → 单质，否 → 化合物）。警惕「冰水混合物」这类名字——它只含 H2O 一种分子，是纯净物；「纯净的空气」则仍是混合物。

【变式自测】下列各组中前者是混合物、后者是纯净物的是：A. 液氨与氨水（反了）；B. 海水与蒸馏水（对：海水含多种盐，蒸馏水只有 H2O）；C. 氧气与臭氧（都是纯净物，但二者混合是混合物）；D. 水玻璃（Na2SiO3 溶液）与水银（前者混合物、后者纯净物，也对）。做题时警惕「一组全对」式的多选变体。

例 2 · 化合价计算

题目：求下列物质中指定元素的化合价：（1）K2Cr2O7 中 Cr；（2）Na2S2O3 中 S；（3）NH4NO3 中两个 N 各自的化合价。

【思路点拨】唯一依据是「化合物中正负化合价代数和为零」。已知 H +1、O −2、K/Na +1，设未知列方程。原子团内部的元素要「拆团」单独算。

1

K2Cr2O7 中的 Cr：设 Cr 为 x。2×(+1) + 2x + 7×(−2) = 0 → 2 + 2x − 14 = 0 → x = +6。

2

Na2S2O3 中的 S：设 S 为 y。2×(+1) + 2y + 3×(−2) = 0 → 2y = 4 → y = +2。这是平均化合价（硫代硫酸钠中两个 S 的实际价态不同），说明化合价可以是计算意义上的分数或平均值。

3

NH4NO3 中的两个 N：拆开两个原子团分别列方程。NH4+ 中：z + 4×(+1) = +1 → z = −3；NO3− 中：w + 3×(−2) = −1 → w = +5。同一化合物中同一元素可以呈现不同价态，这正是不能「一锅煮」的原因。

【答案】（1）Cr 为 +6 价；（2）S 平均为 +2 价；（3）NH4+ 中 N 为 −3 价，NO3− 中 N 为 +5 价。

【方法总结】化合价计算三步：标出已知价（H +1、O −2、碱金属 +1）→ 设未知 → 代数和为零（原子团则用团的总价）列方程。遇到 H2O2、NaH 等特殊物质，先修正 O、H 的特殊价再计算。

【变式自测】速算：KMnO4 中 Mn：+1 + x + 4×(−2) = 0 → x = +7；K2MnO4 中 Mn：2 + x − 8 = 0 → x = +6；HClO 中 Cl：+1 + x − 2 = 0 → x = +1；Na2S4O6（连四硫酸钠）中 S 平均：2 + 4x − 12 = 0 → x = +2.5。

例 3 · 化学用语正误判断

题目：下列化学用语使用正确的是（　　）

A. NaCl 的电子式：Na︰Cl︰
B. CO2 的结构式：O=C=O
C. 中子数为 20 的氯原子：3720Cl
D. HCl 的电子式：H+[︰Cl︰]−

【思路点拨】电子式题先判断化合物类型：离子化合物才有方括号和电荷，共价化合物只有共用电子对。核素符号记牢「左下质子、左上质量」，且质子数决定元素种类。

1

A：NaCl 是离子化合物，Na 把电子完全交给 Cl，电子式必须写成 Na+[︰Cl︰]−（Cl 周围 8 电子、带方括号与电荷）。「Na︰Cl︰」把它当成了共价化合物，错误。

2

B：CO2 中 C 与每个 O 之间共用两对电子，形成两个 C=O 双键，结构式 O=C=O 正确。

3

C：氯元素的质子数固定为 17，左下角必须写 17；中子数 20 时质量数 = 17 + 20 = 37，正确写法是 3717Cl。写成 3720 意味着质子数 20，那是 Ca 而不是 Cl，错误。

4

D：HCl 是共价化合物，H 与 Cl 共用一对电子，不存在 H+ 和 Cl−，电子式应为 H︰Cl︰（Cl 周围补齐 8 电子），不能带方括号与电荷，错误。A、D 两项恰好是「离子/共价」互换的经典陷阱。

【答案】B

【方法总结】电子式书写口诀：「先分类型再动笔——离子括号带电荷，共价共用不加框。」核素符号口诀：「下质上量，质子定元素。」

【变式自测】判断正误：①MgCl2 的电子式写成 Mg2+[︰Cl︰]2−（错，两个 Cl− 不能合并，应分写两侧）；②16O 与 18O 互为同位素（对，质子数同为 8，中子数不同）；③H2O 的结构式 H—O—H（对）。

例 4 · 胶体的性质与制备（实验判断题）

题目：下列关于胶体的说法正确的是（　　）

A. 用激光笔照射豆浆，可观察到一条光亮的通路
B. Fe(OH)3 胶体粒子带正电，所以 Fe(OH)3 胶体带正电
C. 向 FeCl3 溶液中滴加 NaOH 溶液可制得 Fe(OH)3 胶体
D. 胶体粒子直径大于 100 nm，静置后会沉降

【思路点拨】胶体题抓三点：粒径 1~100 nm 是本质；带电的是胶粒、胶体整体呈电中性；制备 Fe(OH)3 胶体必须用沸水水解法。

1

A：豆浆是胶体，激光笔照射出现丁达尔效应（光亮通路），正确。

2

B：Fe(OH)3 胶粒吸附阳离子带正电，但胶体中同时还有带负电的离子，胶体作为整体呈电中性。「胶体带电」的说法错误——这也正是电泳实验中胶粒定向移动而溶液不显电性的原因。

3

C：FeCl3 与 NaOH 直接反应：FeCl3 + 3NaOH → Fe(OH)3↓ + 3NaCl，瞬间生成大颗粒，得到的是红褐色沉淀而非胶体。正确做法是向沸水中滴加 FeCl3 饱和溶液并继续煮沸至红褐色。

4

D：粒径大于 100 nm 的是浊液；胶体粒径为 1~100 nm，胶体是介稳体系，静置不会沉降，错误。

【答案】A

【方法总结】胶体判断三连问：粒径对吗（1~100 nm）？带电说对了吗（胶粒带电、胶体中性）？制备路径对吗（水解法，非直接复分解）？三问过关，选项立判。

【变式自测】「用渗析法可除去 Fe(OH)3 胶体中混有的 NaCl」——对：Na+、Cl− 能透过半透膜，胶粒不能；「过滤可分离胶体与溶液」——错：胶粒和离子都能透过滤纸，过滤分不开，要用半透膜。

例 5 · 化学方程式配平（奇数配偶法）

题目：配平下列化学方程式（黄铁矿煅烧制硫酸的第一步）：

__FeS2 + __O2 → __Fe2O3 + __SO2

【思路点拨】观察发现 Fe 原子左边在 FeS2 中、右边在 Fe2O3 中，右边的 Fe2O3 含 3 个 O 使 O 原子数易成奇数——先把 Fe2O3 系数配 2，让 Fe 数变偶数 4，再顺势配平其余原子（奇数配偶法）。

1

定 Fe2O3 系数为 2：使右边 Fe 为 4 个，同时右边 O 原子数变为 2×3 = 6（偶数），为配平 O2（偶数分子）扫清障碍。

2

配 Fe：右边 4 个 Fe，故 FeS2 前配 4。

3

配 S：左边 4 个 FeS2 含 8 个 S，故 SO2 前配 8。

4

配 O：右边 O 原子总数 = 2×3 + 8×2 = 6 + 16 = 22，故 O2 前配 11。

5

验证：Fe 左 4 = 右 4 ✓；S 左 8 = 右 8 ✓；O 左 11×2 = 22 = 右 22 ✓。

4FeS2 + 11O2 → 2Fe2O3 + 8SO2
【答案】系数依次为 4、11、2、8。

【方法总结】配平后必须逐项验证每种原子两边相等；系数应为最简整数比，公约数要约去。工业流程题中「黄铁矿煅烧」方程式是高考常客，4-11-2-8 值得记牢。

【变式自测】配平 __KClO3 → __KCl + __O2↑：先配 O（3 与 2 的最小公倍数 6），KClO3 配 2、O2 配 3，再配 KCl 为 2，得 2、2、3。

例 6 · 核素符号与原子结构综合

题目：钠原子的核素符号为 2311Na。请回答：（1）该原子的质子数、中子数、核外电子数；（2）写出 Na 原子和 Na+ 的电子层排布；（3）Na+ 的核外电子数是多少？

【思路点拨】核素符号「下质上量」：左下 11 是质子数，左上 23 是质量数；中子数 = 质量数 − 质子数。原子呈电中性时电子数 = 质子数；失电子成阳离子后电子数减少，质子数不变。

1

读符号：质子数 Z = 11；质量数 A = 23；中子数 = 23 − 11 = 12；核外电子数 = 质子数 = 11。

2

电子层排布：Na 原子 11 个电子按层填充：第一层 2、第二层 8、第三层 1，记作 2、8、1；Na+ 失去最外层 1 个电子，排布为 2、8。

3

Na+ 电子数：11 − 1 = 10（与稀有气体 Ne 的电子层结构相同）。

【答案】（1）质子数 11、中子数 12、电子数 11；（2）Na：2、8、1；Na+：2、8；（3）10。

【方法总结】三条守恒关系要脱口而出：质量数 = 质子数 + 中子数；原子中质子数 = 核外电子数 = 原子序数；阳离子电子数 = 质子数 − 电荷数（阴离子则加）。

【变式自测】（1）3517Cl− 的质子数 17、中子数 18、电子数 18（阴离子加 1）；（2）2412Mg2+ 的电子数为 10，电子层排布为 2、8，与 Ne 相同。

例 7 · 氧化物说法辨析

题目：下列关于氧化物的说法正确的是（　　）

A. 金属氧化物都是碱性氧化物
B. 非金属氧化物都是酸性氧化物
C. 酸性氧化物都能与水反应生成对应的酸
D. 碱性氧化物都能与酸反应生成盐和水

【思路点拨】氧化物辨析靠「反例」制胜：四个选项各想一个反例，找不到反例的就是对的。

1

A：找金属氧化物中的「叛徒」——Al2O3 是两性氧化物，Mn2O7 是酸性氧化物，Na2O2 是过氧化物。错误。

2

B：CO、NO 是非金属氧化物，却不能与碱反应生成盐和水（不成盐氧化物）。错误。

3

C：SiO2 是酸性氧化物（能与 NaOH 反应生成 Na2SiO3 和水），但它不溶于水、不与水反应。错误。

4

D：碱性氧化物的定义就是「能与酸反应生成盐和水的氧化物」，如 CaO + 2HCl → CaCl2 + H2O，无一例外。正确。

【答案】D

【方法总结】记住三组反例：Al2O3（两性）、CO/NO（不成盐）、SiO2（不与水反应）。定义类选项回到定义本身核对，不要被「都」「一定」带着走。

【变式自测】判断正误：①Na2O 是碱性氧化物（对，与酸反应只生成盐和水）；②CO2 是酸性氧化物（对，与碱反应生成盐和水）；③Na2O2 与盐酸反应只生成 NaCl 和 H2O（错，还生成 O2，不满足碱性氧化物定义）；④含有氧元素的化合物都是氧化物（错，H2SO4、NaOH 含氧但不是氧化物）。

例 8 · 胶体知识的综合应用

题目：用胶体知识解释下列现象：（1）长江入海口形成三角洲；（2）钢笔混用不同品牌的墨水容易堵塞；（3）明矾可作净水剂。

【思路点拨】生活现象题答题模板：先点明「什么胶体」→ 再说「发生了什么（聚沉/吸附）」→ 最后说「结果如何」。三个现象都指向胶体的聚沉或吸附。

1

三角洲：河水中的泥沙颗粒直径处于胶体范围，属于胶体；入海时遇到海水中的大量电解质（NaCl 等），反号离子中和胶粒电荷，泥沙胶体发生聚沉，长年累月沉积成三角洲。

2

墨水堵笔：墨水是胶体，不同品牌墨水的胶粒所带电荷可能相反，混合后正负胶粒相互中和而聚沉，生成的沉淀堵塞笔尖。

3

明矾净水：明矾 KAl(SO4)2·12H2O 溶于水后，Al3+ 水解生成 Al(OH)3 胶体；胶体表面积大、吸附能力强，能吸附水中悬浮的杂质并一起沉降，使水澄清。

【答案】（1）泥沙胶体遇海水中电解质聚沉；（2）不同墨水胶粒带相反电荷，混合聚沉堵笔；（3）明矾水解生成 Al(OH)3 胶体，吸附悬浮杂质共同沉降。

【方法总结】胶体应用题的两个「题眼」：看到「两种胶体/胶体遇电解质」想聚沉；看到「吸附杂质、净水」想胶体表面积大。答题时务必写出「胶体」二字点题。

【变式自测】「豆浆中加食盐卤水可制成豆腐」——卤水（MgCl2 等电解质）使豆浆中的蛋白质胶体聚沉；「雾天车灯光柱更明显」——雾是气溶胶，丁达尔效应增强；「静电除尘」——利用电泳使带电的烟尘胶粒移向电极。

例 9 · 化学用语综合判断（考前最后一练）

题目：下列说法正确的是（　　）

A. NH4Cl 的电子式中，NH4+ 不需加方括号
B. 1H2 与 2H2 互为同素异形体
C. Fe3O4 中铁元素的平均化合价为 +8/3
D. 二氧化碳的结构简式为 O=C=O

【思路点拨】本题四个选项分别考电子式、同位素与同素异形体辨别、平均化合价、表示方法归类——正是本章四大易错点的集合，逐项排雷即可。

1

A：NH4+ 是复杂阳离子，电子式必须用方括号括起并在右上角标「+」，即 [H︰N︰H]+（H 上另有电子对）。「不加方括号」错误。

2

B：1H2 与 2H2 是同一元素不同同位素组成的同一种单质的两种分子（H2），不是同素异形体（同素异形体必须是结构不同的单质，如 O2 与 O3）。错误。

3

C：Fe3O4 中 3x + 4×(−2) = 0 → x = +8/3。平均化合价可以是分数，正确（实际为 2 个 Fe3+ 与 1 个 Fe2+）。

4

D：O=C=O 是 CO2 的结构式，不是结构简式。CO2 是无机物，一般无「结构简式」之说。错误。

【答案】C

【方法总结】综合题的价值在于「一题扫全章」。做错哪个选项，就回到对应易错点重读——这比刷十道同质题更有效。

五、易错点与成因

七条易错点按「表现 → 成因 → 正解 → 口诀」拆解。本章的失分几乎全部来自「想当然」——用定义和成分说话，是唯一的解药。

易错点 1

易错表现：把盐酸、漂白粉、洁净的空气当纯净物；把纯碱当碱、把 NaHSO4 当酸。

错误成因：凭名字和「干净程度」做判断，没有回到分类的本质定义——纯净物看「是否只含一种物质」，酸碱看「电离出的阳/阴离子是否全部是 H+/OH−」。

正确理解：盐酸 = HCl + H2O（混合物）；漂白粉 = Ca(ClO)2 + CaCl2（混合物）；纯碱 Na2CO3 由金属离子与酸根构成（盐）；NaHSO4 电离还产生 Na+（酸式盐）。

避坑口诀：「分类看成分不看脸，酸碱看电离全不全。」

易错点 2

易错表现：认为「胶体就是胶状的物质」，或认为「胶体带正电/负电」。

错误成因：把生活用语（胶水、果冻）当化学概念；把「胶粒带电」扩大成「胶体带电」，忽略了胶体中同时存在的反号离子。

正确理解：胶体是按分散质粒径（1~100 nm）划分的分散系类型，与外观黏不黏无关；胶粒因吸附离子而带电（可发生电泳），但胶体整体呈电中性。

避坑口诀：「胶体看粒径不看胶，胶粒带电胶体中和。」

易错点 3

易错表现：用 FeCl3 溶液与 NaOH 溶液混合「制备 Fe(OH)3 胶体」；制备时长时间煮沸；方程式产物标 ↓。

错误成因：只知道产物是 Fe(OH)3，不理解胶体对生成速率的要求——水解法缓慢生成 1~100 nm 颗粒，复分解反应瞬间生成大颗粒直接沉淀；加热过度则胶粒聚沉。

正确理解：沸水中滴加 FeCl3 饱和溶液，煮至红褐色立即停止加热；产物写 Fe(OH)3（胶体），不加 ↓；自来水中的电解质会引发聚沉，必须用蒸馏水。

避坑口诀：「沸水滴加氯化铁，红褐即停不加沉淀。」

易错点 4

易错表现：把 HCl 电子式写成 H+[︰Cl︰]−，或把 NaCl 电子式写成 Na︰Cl︰。

错误成因：没有先判断化合物类型。HCl 溶于水后才电离出离子，纯 HCl 分子内是共用电子对；NaCl 中则是电子的完全得失。混淆了「电离」与「成键」两个不同过程。

正确理解：离子化合物（活泼金属 + 活泼非金属、含原子团的盐）电子式用方括号加电荷；共价化合物（非金属之间）用共用电子对、无括号无电荷。先分类，再动笔。

避坑口诀：「离子括号共价点，先分类型再书写。」

易错点 5

易错表现：把 H2O2 中 O 当作 −2 价；认为 NH4NO3 中两个 N 价态相同；认为化合价必须是整数。

错误成因：把「O 通常 −2」当成绝对规则；不知道同一元素在同一化合物中可因所处原子团不同而价态不同；没见过平均化合价的概念。

正确理解：过氧化物中 O 为 −1；NH4NO3 要拆成 NH4+（N 为 −3）和 NO3−（N 为 +5）分别计算；Fe3O4 中 Fe 平均 +8/3，平均价可为分数。

避坑口诀：「常规价里有特例，原子团要拆着算。」

易错点 6

易错表现：把 O2 与 O3 互称同位素；把 1H 与 2H 互称同素异形体；或认为同素异形体的混合物是纯净物。

错误成因：两组概念比较的对象不同——同位素比较的是原子（质子数同、中子数不同），同素异形体比较的是单质（元素同、结构不同）。层次混淆导致张冠李戴。

正确理解：先问「讨论对象是原子还是单质」：原子 → 同位素；单质 → 同素异形体。O2 与 O3 混合含两种分子，是混合物。

避坑口诀：「同位素论原子，同素异形体论单质。」

易错点 7

易错表现：把乙酸的最简式 CH2O 当成它的分子式；书写结构简式时把乙烯写成 CH2CH2（省略碳碳双键）；把结构式中的所有短线都算成共用电子对之外的孤对。

错误成因：最简式（实验式）、分子式、结构式、结构简式四个概念回答的问题不同——最简式只给原子个数最简比（乙酸 CH2O），分子式给真实原子数（C2H4O2），结构式画出每对共用电子，结构简式在结构式基础上省略部分短线。层次混淆导致「张冠李戴」。

正确理解：同一物质四种式子逐级「信息量递增」；写结构简式时碳碳双键、碳碳三键、官能团（—OH、—CHO、—COOH）不能省略或合并，如乙烯必须写 CH2=CH2，乙醇写 CH3CH2OH 或 C2H5OH。

避坑口诀：「最简比、真实数、画成键、简式留键。」

七、高考怎么考

对照近年全国卷（云南适用）的命题方式，本章考法与应对如下：

  • 选择题第 1~2 题（必考）：STSE 情境下的物质分类、胶体性质判断（丁达尔、聚沉应用），属于「开局送分题」，本章例 1、例 4、例 8 是原型。
  • 选择题（常考）：化学用语正误判断（电子式、核素符号、结构式、原子结构示意图），4 个选项各考一种用语，本章例 3、例 6 是原型。
  • 非选择题（渗透考查）：工业流程题中书写陌生方程式（配平 + 条件 + 状态符号），化合价计算是氧化还原分析的前置步骤。
  • 答卷建议：电子式题先在草稿纸上判断化合物类型再落笔；方程式写完立刻逐元素验证，并把条件、↑↓ 回头看一遍——这两步各花 10 秒，能挽回绝大多数「会做却丢分」。

3.7 元素化合物综合推断

高中化学 · 深度学习材料 · 面向 2029 届云南高考

推断题是元素化合物知识的「期末大考」——它不考你背了多少，而考你能不能把零散的知识串成网。本章教你一套稳定的解题流程：找突破口 → 顺推/逆推 → 验证，并把高考中最常出现的突破口、连续氧化关系和三角转化一次讲透。学完后，希望你看到「白色沉淀迅速变灰绿再变红褐」能条件反射地写出 Fe(OH)2。

二、核心概念精讲

2.1 推断题的通用解法：三步走

核心方法

第一步：找突破口。通读全题，找出「信息密度最高」的那句话——往往是一个特征颜色、一个特征条件（如「通电」「高温煅烧」）、一个特征转化（如「连续两次与 O2 反应」）或一个特征数据（相对分子质量、气体体积比）。突破口一般只有 1~2 个，先把它对应的物质写下来。

第二步：顺推与逆推结合。从突破口物质出发，沿箭头方向顺推它的产物；同时从框图末端或特殊物质出发逆推反应物。双向夹击，在中间的「枢纽物质」处汇合。

第三步：代入验证。把推得的每一种物质代回框图，逐条核对：①每条转化是否有对应的反应；②题给的每一个现象、条件、数据是否都被用上且吻合；③化学式、方程式是否书写正确。只要有一条对不上，就说明某一步推错了，回到突破口重新排查。

为什么必须验证？推断题常有「假突破口」——某句话看似只对应一种物质，实际对应两三种可能。验证环节就是用题中剩余条件做筛选，把错误分支排除掉。高手做题慢在验证，快在一次性推对。

（3）特征转化

  • A → B → C（连续氧化）：中学只有四类——C、N（NH3/N2）、S（H2S/S）、Na，详见 2.3。
  • 既能与酸又能与碱反应的物质：Al、Al2O3、Al(OH)3、弱酸的酸式盐（NaHCO3）、(NH4)2CO3 等。
  • 某物质与沸水/水剧烈反应放气体：Na2O2、活泼金属（Na、K、Ca）、CaC2（出 C2H2）。
  • 一种盐受热分解出三种产物：NaHCO3（Na2CO3 + H2O + CO2）、NH4HCO3（NH3 + H2O + CO2）、Cu2(OH)2CO3（2CuO + H2O + CO2）。

（4）特征数据

  • 相对分子质量：H2SO4 与 H3PO4 均为 98；CaCO3 与 KHCO3 均为 100；CO 与 N2 均为 28；CO2 与 N2O 均为 44；Na2O2 与 Al(OH)3 均为 78；Fe2O3 160、CuO 80（恰好一半）。
  • 气体体积比：电解水 V(H2)∶V(O2) = 2∶1；NO 与 O2 混合通入水：4NO + 3O2 + 2H2O → 4HNO3。
  • 电子数/质子数为 10、18 的微粒：10 电子体——CH4、NH3、H2O、HF、Ne、Na+、Mg2+、Al3+、NH4+、OH− 等；18 电子体——H2S、HCl、H2O2、F2、Ar、S2−、Cl− 等。

2.3 四种连续氧化关系（推断题「常客」）

「X → Y → Z」型连续氧化是框图推断中出现频率最高的结构，中学范围只有以下四组，必须连同延伸反应一起烂熟于心。

① 碳系列：C → CO → CO2

2C(s) + O2(g，不足) → 2CO(g) 2CO(g) + O2(g) → 2CO2(g)

延伸：CO2 与 Ca(OH)2 反应生成 CaCO3 白色沉淀，继续通 CO2 沉淀溶解生成 Ca(HCO3)2——「先浑浊后澄清」是高频现象。

② 氮系列：N2（或 NH3）→ NO → NO2

N2(g) + O2(g) → 2NO(g) 2NO(g) + O2(g) → 2NO2(g) 4NH3(g) + 5O2(g) → 4NO(g) + 6H2O(g)

延伸：3NO2(g) + H2O(l) → 2HNO3(aq) + NO(g)——红棕色气体溶于水得无色溶液并放出无色气体，是「雷雨发庄稼」的化学原理。

③ 硫系列：S（或 H2S）→ SO2 → SO3

S(s) + O2(g) → SO2(g) 2SO2(g) + O2(g) ⇌ 2SO3(g)

延伸：SO3 + H2O → H2SO4（工业制硫酸三部曲）；SO2 能使品红溶液褪色（漂白性，可逆），加热恢复红色。

④ 钠系列：Na → Na2O → Na2O2

4Na(s) + O2(g) → 2Na2O(s)（常温，表面变暗） 2Na2O(s) + O2(g) → 2Na2O2(s) 2Na(s) + O2(g) → Na2O2(s)（直接生成淡黄色固体）

延伸：Na2O2 与 H2O、CO2 反应均放出 O2：

2Na2O2(s) + 2H2O(l) → 4NaOH(aq) + O2(g)↑ 2Na2O2(s) + 2CO2(g) → 2Na2CO3(s) + O2(g)
记忆技巧

连续氧化的本质：中心元素有多种可逐级升高的价态。C（0→+2→+4）、N（0/−3→+2→+4）、S（0/−2→+4→+6）、Na 特殊（不是价态连续升高，而是氧化程度加深：氧化物 → 过氧化物）。做题时看到「连续与 O2 反应」，先在脑中过一遍这四个系列。

2.4 三大三角转化关系

（1）铝三角：Al3+ ⇌ Al(OH)3 ⇌ AlO2−（或写作 [Al(OH)4]−）

Al3+(aq) + 3OH−(aq，适量) → Al(OH)3(s)↓ Al(OH)3(s) + OH−(aq，过量) → AlO2−(aq) + 2H2O(l) AlO2−(aq) + H+(aq，适量) + H2O(l) → Al(OH)3(s)↓ Al(OH)3(s) + 3H+(aq) → Al3+(aq) + 3H2O(l)

要点：Al(OH)3 是两性氢氧化物，只溶于强酸强碱，不溶于氨水。实验室制 Al(OH)3 用「铝盐 + 过量氨水」而不是 NaOH，就是为了避免沉淀被过量强碱溶解。

（2）铁三角：Fe ⇌ Fe2+ ⇌ Fe3+

2Fe3+(aq) + Fe(s) → 3Fe2+(aq) 2Fe2+(aq) + Cl2(g) → 2Fe3+(aq) + 2Cl−(aq) 2Fe3+(aq) + Cu(s) → 2Fe2+(aq) + Cu2+(aq)

要点：Fe2+ 遇强氧化剂（Cl2、Br2、HNO3、H2O2、酸性 KMnO4）变 Fe3+；Fe3+ 遇还原剂（Fe、Cu、I−、H2S）变 Fe2+。检验：Fe3+ 遇 KSCN 溶液显血红色；Fe2+ 遇 KSCN 无现象，再加氯水变红。

（3）碳三角：C ⇌ CO ⇌ CO2（及 CO2 ⇌ CaCO3）

CO2(g) + C(s) → 2CO(g) CO2(g) + Ca(OH)2(aq) → CaCO3(s)↓ + H2O(l) CaCO3(s) → CaO(s) + CO2(g)↑

要点：碳三角常与「石灰水先浑后清」联合出题，串起 CO2 → CaCO3 → Ca(HCO3)2 的链条。

三、三重表征贯通

贯通组 1：Fe(OH)2 被氧化为 Fe(OH)3

宏观现象

向 FeSO4 溶液中滴加 NaOH 溶液，立即生成白色絮状沉淀，沉淀迅速变为灰绿色，振荡或放置后最终变为红褐色。

微观解释

Fe2+ 先与 OH− 结合生成 Fe(OH)2 白色沉淀；Fe(OH)2 中 Fe 为 +2 价，还原性强，被溶解在溶液中的 O2 逐步氧化为 +3 价的 Fe(OH)3。灰绿色是 Fe(OH)2 与 Fe(OH)3 混合过渡的颜色。

符号表达

Fe2+(aq) + 2OH−(aq) → Fe(OH)2(s)↓

4Fe(OH)2(s) + O2(g) + 2H2O(l) → 4Fe(OH)3(s)

推断价值：「白色沉淀→灰绿→红褐」这一颜色三连变在中学化学中独一无二，一旦出现即可断定体系中有 Fe2+，是最硬的颜色突破口之一。

贯通组 2：NO 遇空气变红棕

宏观现象

集气瓶中无色气体打开瓶塞（或与空气接触）后，瓶口处气体变为红棕色，且有刺激性气味。

微观解释

无色气体为 NO，其中 N 为 +2 价；与空气中的 O2 接触后被氧化为 +4 价的 NO2，NO2 是红棕色气体。该反应在常温下即可快速进行，不需任何条件。

符号表达

2NO(g) + O2(g) → 2NO2(g)

（氮系列连续氧化：N2/NH3 → NO → NO2 的中间环节）

推断价值：「无色气体遇空气变红棕色」⇒ 该气体是 NO，几乎无第二种可能。由此可逆推生成 NO 的反应（铜与稀硝酸、氨催化氧化、N2 放电）。

贯通组 3：Na2O2 与水反应

宏观现象

淡黄色固体投入水中，剧烈反应、放出大量气泡，反应放热使溶液温度明显升高；带火星的木条伸入气体中复燃；向反应后溶液滴加酚酞，溶液先变红后褪色。

微观解释

Na2O2 中 O 为 −1 价（过氧根 O22−），与水发生歧化反应：一部分 O 降为 −2 价进入 NaOH，一部分升为 0 价生成 O2。NaOH 使酚酞变红；Na2O2 的强氧化性（漂白性）又把变红的酚酞氧化褪色。

符号表达

2Na2O2(s) + 2H2O(l) → 4NaOH(aq) + O2(g)↑

离子角度：Na2O2 为氧化物，书写离子方程式时不拆。

推断价值：「淡黄色固体 + 水 → 气体（使带火星木条复燃）」⇒ Na2O2。「酚酞先红后褪」是它区别于普通碱性溶液的标志。

四、典型例题分步拆解

例 1 · 框图推断（颜色突破口）

题目：A、B、C、D、E 五种物质均含同一种金属元素。已知：① A 是一种银白色金属单质，在空气中燃烧发出耀眼的白光，生成白色固体 B；② B 与盐酸反应生成溶液 C；③ 向 C 中滴加过量 NaOH 溶液，先出现白色沉淀 D，后沉淀溶解得溶液 E；④ 向 E 中通入足量 CO2，又重新生成白色沉淀 D。推断 A~E 各是什么物质，写出③中沉淀溶解的离子方程式。

【思路点拨】突破口在①：「燃烧发耀眼白光」是 Mg 的招牌现象；但③「白色沉淀溶于过量 NaOH」说明沉淀是两性氢氧化物——Mg(OH)2 不溶于 NaOH！矛盾促使我们重新排查：能与过量强碱反应生成可溶物的白色氢氧化物，只有 Al(OH)3。所以金属元素是 Al；重新理解①：铝箔（或铝粉）在氧气中点燃也会发出耀眼白光（铝热/镁光灯原理类似），生成白色 Al2O3。验证各步均吻合。

1
找突破口。③中「白色沉淀 + 过量 NaOH → 溶解」⇒ D 为两性氢氧化物 Al(OH)3，共同金属元素为 Al。
2
逆推 A、B。含 Al 的单质 A 即铝；A 燃烧生成的白色固体 B 为 Al2O3。
3
顺推 C、E。B(Al2O3) 与盐酸反应得 C：AlCl3 溶液；C 加过量 NaOH，先沉淀后溶解，E 为 NaAlO2 溶液（含 AlO2−）。
4
验证④。NaAlO2 溶液中通足量 CO2：AlO2− + CO2 + 2H2O → Al(OH)3↓ + HCO3−，重新生成白色沉淀 D，吻合。
【答案】A：Al；B：Al2O3；C：AlCl3；D：Al(OH)3；E：NaAlO2。③中沉淀溶解：Al(OH)3(s) + OH−(aq) → AlO2−(aq) + 2H2O(l)。

【方法总结】当两个条件指向不同答案时，以限制更强的条件为准。「耀眼白光」不是 Mg 的专利（Al 燃烧也耀眼），但「溶于过量 NaOH 的白色沉淀」只有 Al(OH)3。做题切忌抓住第一个念头不放。

例 2 · 连续氧化型框图推断

题目：已知 A、B、C、D、E 的转化关系如下（用文字描述）：常温下单质 A 与气体 X 反应生成 B；B 与 X 继续反应生成 C；C 溶于水生成 D 和 B；D 是一种重要的强酸，其稀溶液能与铜反应放出 B。推断 A~E 中各物质（X 为一种无色无味的气体单质），并写出 C 与水反应的化学方程式。

【思路点拨】「单质 + X → B，B + X → C」是典型的连续氧化结构，X 应为 O2。再看「C 溶于水生成强酸 D 和 B」以及「稀 D 与铜反应放出 B」——稀硝酸与铜反应放出 NO，则 D 为 HNO3、B 为 NO，于是 C 为 NO2，A 为 N2。整条链：N2 → NO → NO2 → HNO3 + NO。

1
突破口定位。「强酸稀溶液与铜反应放气体」⇒ 稀硝酸与 Cu 放 NO，D = HNO3，B = NO。
2
逆推 C、A。C 溶于水生成 HNO3 和 NO ⇒ C = NO2；B(NO) 由 A 与 O2 生成 ⇒ A = N2，X = O2。
3
验证连续氧化。N2 + O2 → 2NO；2NO + O2 → 2NO2，条件与现象均吻合。
4
写方程式。3NO2(g) + H2O(l) → 2HNO3(aq) + NO(g)。
【答案】A：N2；B：NO；C：NO2；D：HNO3；X：O2。C 与水反应：3NO2(g) + H2O(l) → 2HNO3(aq) + NO(g)。

【方法总结】连续氧化四系列是「看到连续氧化就逐一试套」的清单式工具。本题中「与铜反应的强酸」这一信息直接锁定硝酸，比从 A 端顺推快得多——突破口不一定在框图起点，往往在信息最独特的那一环。

例 3 · 铁三角与颜色综合推断

题目：A、B、C 是含同种元素的化合物，转化关系为：① 向 A 溶液中滴加 KSCN 溶液，溶液显血红色；② 向 A 溶液中加入足量铁粉，充分反应后过滤，得浅绿色溶液 B；③ 向 B 溶液中通入足量 Cl2，又得到 A 溶液；④ 向 B 溶液中滴加 NaOH 溶液，先生成白色沉淀，迅速变为灰绿色，最终变为红褐色沉淀 C。写出①②③三步反应的离子方程式。

【思路点拨】①「KSCN 显血红」⇒ A 中含 Fe3+；②铁粉把 Fe3+ 还原为 Fe2+（浅绿色）⇒ B 中含 Fe2+；④的颜色三连变再次确认 Fe2+，C 为 Fe(OH)3。这是标准的 Fe3+ ⇌ Fe2+ 循环。

1
由①定元素价态。A 含 Fe3+（如 FeCl3）。
2
由②写还原反应。2Fe3+(aq) + Fe(s) → 3Fe2+(aq)。
3
由③写氧化反应。2Fe2+(aq) + Cl2(g) → 2Fe3+(aq) + 2Cl−(aq)。
4
由④验证。Fe2+ + 2OH− → Fe(OH)2↓（白），4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3（红褐），与题述颜色变化完全一致。
【答案】① Fe3+(aq) + 3SCN−(aq) → Fe(SCN)3（血红色溶液）；② 2Fe3+(aq) + Fe(s) → 3Fe2+(aq)；③ 2Fe2+(aq) + Cl2(g) → 2Fe3+(aq) + 2Cl−(aq)。

【方法总结】铁三角题目中「血红色」「浅绿色」「白→灰绿→红褐」三个现象分别对应 Fe3+、Fe2+、Fe(OH)2→Fe(OH)3 的检验，把三组现象背成「三张名片」，见到即可直写答案。

例 4 · 数据型推断（含计算验证）

题目：无色气体 A 与无色气体 B（B 能支持燃烧）按体积比 4∶3 混合后通入足量水中，气体恰好被完全吸收，得到一种强酸溶液。推断 A、B，并写出总反应的化学方程式。

【思路点拨】「能支持燃烧的无色气体」⇒ B 是 O2；「两种气体与水作用恰好完全吸收生成强酸」是氮氧化物 + O2 溶于水体系的标志。设 A 为氮的氧化物，用体积比 4∶3 做配平验证。

1
锁定 B。能支持燃烧 ⇒ B = O2。气体溶于水得强酸，优先考虑 HNO3，则 A 为 NO 或 NO2；A 无色 ⇒ A = NO。
2
用数据配平验证。设 4NO + 3O2 + xH2O → yHNO3。由 N 守恒 y = 4；由 H 守恒 2x = 4，x = 2；检验 O：左 4 + 6 + 2 = 12，右 4×3 = 12，守恒成立。
3
验证「完全吸收」。方程式中无气体剩余，生成的 HNO3 是强酸，体积比 V(NO)∶V(O2) = 4∶3 与题设完全一致。
【答案】A：NO；B：O2；总反应：4NO(g) + 3O2(g) + 2H2O(l) → 4HNO3(aq)。

【方法总结】数据型推断先用特征性质锁定物质范围，再用体积比做配平验证。牢记两个「恰好完全吸收」的经典比例：V(NO2)∶V(O2) = 4∶1（4NO2 + O2 + 2H2O → 4HNO3）与 V(NO)∶V(O2) = 4∶3（本题）。

例 5 · 碳三角与石灰水综合推断

题目：A、B、C、D 四种物质的转化关系为：① 气体 A 通入澄清石灰水，石灰水变浑浊，生成白色沉淀 B；② 继续通入过量 A，沉淀溶解，得溶液 C；③ 加热 C 溶液，又重新出现白色沉淀 B 并放出气体 A；④ B 高温煅烧生成白色固体 D 和气体 A，D 与水剧烈反应放热，所得溶液即石灰水。推断 A~D，写出②③的化学方程式。

【思路点拨】「石灰水变浑浊」⇒ A 可能是 CO2 或 SO2；「继续通入沉淀溶解 + 加热又析出」是 CaCO3 ⇌ Ca(HCO3)2 的招牌循环 ⇒ A = CO2，B = CaCO3，C = Ca(HCO3)2，D = CaO。

1
突破口：「过量气体使沉淀溶解、加热又沉淀」——CaCO3 + CO2 + H2O → Ca(HCO3)2（可溶），确定 A = CO2、B = CaCO3。
2
顺推 D：CaCO3 高温煅烧 → CaO + CO2↑，D = CaO；CaO + H2O → Ca(OH)2，正是石灰水，闭环吻合。
3
写②③方程式。② CaCO3(s) + CO2(g) + H2O(l) → Ca(HCO3)2(aq)；③ Ca(HCO3)2(aq) → CaCO3(s)↓ + H2O(l) + CO2(g)↑。
【答案】A：CO2；B：CaCO3；C：Ca(HCO3)2；D：CaO。方程式见上。

【方法总结】「先浑后清」与「加热复浑」是一对互逆条件，专属于 CO2—CaCO3—Ca(HCO3)2 体系。遇到「沉淀溶解于过量气体」还可联想：Al(OH)3 溶于过量强碱、AgCl 溶于过量氨水——用「溶解试剂」区分。

例 6 · 铝三角计算型推断

题目：向 100 mL 某浓度的 AlCl3 溶液中滴加 2.0 mol/L NaOH 溶液，生成沉淀的质量随 NaOH 体积变化如下：NaOH 体积从 0 增至 30 mL 时沉淀逐渐增多至最大值；继续滴加，沉淀逐渐溶解，当 NaOH 总体积为 40 mL 时沉淀恰好完全消失。求 AlCl3 溶液的物质的量浓度。

【思路点拨】铝三角的定量版本：沉淀阶段 Al3+ + 3OH− → Al(OH)3↓；溶解阶段 Al(OH)3 + OH− → AlO2− + 2H2O。沉淀最多时耗碱 3 份，溶解这些沉淀再耗 1 份，体积比 3∶1。

1
确定两个阶段耗碱比。沉淀阶段 V1 = 30 mL；溶解阶段 V2 = 40 − 30 = 10 mL；V1∶V2 = 3∶1，与方程式计量比吻合，数据自洽。
2
用溶解阶段求沉淀量。n(NaOH)溶 = 2.0 mol/L × 0.010 L = 0.020 mol = n[Al(OH)3]。
3
由 Al 守恒求 AlCl3。n(AlCl3) = n[Al(OH)3] = 0.020 mol。
4
验证沉淀阶段。沉淀 0.020 mol Al3+ 需 OH− 0.060 mol，即 2.0 mol/L × 0.030 L = 0.060 mol ✓。
5
求浓度。c(AlCl3) = 0.020 mol ÷ 0.100 L = 0.20 mol/L。
【答案】c(AlCl3) = 0.20 mol/L。

【方法总结】铝三角图像题（沉淀量—碱体积图）的标志性特征：上升段与下降段耗碱体积比恒为 3∶1。看到图像先找「最高点对应的体积」，按 3∶1 切分两个阶段，任选一个阶段列式即可求解。

例 7 · 多线索综合大推断（高考风格）

题目：A~G 七种物质有如图所示转化关系（以文字描述）：单质 A 在空气中放置表面变暗生成 B；A 在空气中燃烧生成淡黄色固体 C；C 与气体 D 反应生成白色固体 E 和气体 F；E 与盐酸反应放出气体 D；F 能使带火星的木条复燃；A 与水剧烈反应生成溶液 G 和气体 H，H 是最轻的气体。推断 A~H，写出 C 与 D、A 与水反应的化学方程式。

【思路点拨】「最轻的气体」⇒ H = H2；「单质与水剧烈反应放 H2，空气中表面变暗、燃烧得淡黄色固体」⇒ A = Na（钠系列连续氧化的全部特征同时出现）；C = Na2O2；F 使木条复燃 ⇒ F = O2；Na2O2 与气体 D 生成白色固体 E 和 O2，且 E 与盐酸放出 D ⇒ D = CO2，E = Na2CO3；B = Na2O；G = NaOH。

1
双突破口定 A：最轻气体 H = H2；燃烧得淡黄色固体 ⇒ A = Na，C = Na2O2。
2
定 B、G：Na 常温氧化 → B = Na2O；Na + H2O → G = NaOH + H2↑。
3
定 F：使带火星木条复燃 ⇒ F = O2。
4
定 D、E：2Na2O2 + 2CO2 → 2Na2CO3 + O2，故 D = CO2、E = Na2CO3；验证：Na2CO3 + 2HCl → 2NaCl + H2O + CO2↑，放出 D ✓。
【答案】A：Na；B：Na2O；C：Na2O2；D：CO2；E：Na2CO3；F：O2；G：NaOH；H：H2。
2Na2O2(s) + 2CO2(g) → 2Na2CO3(s) + O2(g)；
2Na(s) + 2H2O(l) → 2NaOH(aq) + H2(g)↑。

【方法总结】本题把钠系列连续氧化的「全部特征」集中在一张框图里——表面变暗、淡黄色固体、放 O2、放 H2。这类题说明：同一元素的多个特征现象往往互为印证，推出的物质越多，验证越充分，答案越稳。

五、易错点与成因

易错 1

易错表现：推出物质后不代回框图验证，凭「感觉对了」就写答案，结果某条转化对不上。

错误成因：推断题常常存在「局部合理、整体矛盾」的伪答案。例如把连续氧化推出 C→CO→CO2，却忽略了题中「C 的水溶液能使石蕊变红」这一条件——CO2 溶于水形成的碳酸极弱，题意若指向强酸则应为氮系列。

正确理解：验证环节必须用掉题目给出的每一个条件。没用完的条件就是警报器。

避坑口诀：条件用完，答案才完。

易错 2

易错表现：看到「白色沉淀加过量碱溶解」就写 Al(OH)3，忽略 Zn(OH)2 也能溶于过量强碱；或看到「耀眼白光」只认 Mg。

错误成因：把突破口当成「唯一对应」，但中学阶段部分现象对应多种可能（白光：Mg、Al；溶于强碱的白色氢氧化物：Al(OH)3、Zn(OH)2）。高考通常用其他条件做二次限定。

正确理解：突破口分「硬突破口」（唯一对应，如白→灰绿→红褐）和「软突破口」（需配合其他条件）。优先抓硬突破口。

避坑口诀：先抓唯一，再排可能。

易错 3

易错表现：连续氧化写错方向或条件，如把 N2 → NO 的条件写成「点燃」，或认为 Na2O 在空气中放置会自动变成 Na2O2。

错误成因：N2 化学性质很稳定（N≡N 键能大），与 O2 反应必须放电或高温，「点燃」达不到；Na2O → Na2O2 需要加热条件下与 O2 反应，常温不行；Na 常温氧化只到 Na2O，点燃才得 Na2O2。

正确理解：条件本身就是突破口——「放电」几乎只对应 N2 + O2 → NO，写错条件等于丢掉解题线索。

避坑口诀：条件即证据，一个不能省。

易错 4

易错表现：写 Al(OH)3 溶于碱的方程式时产物写成 Al3+ 或 Al(OH)4− 与 AlO2− 混用，或不配平。

错误成因：教材中 Al(OH)3 + OH− 的产物有两种写法（AlO2− 或 [Al(OH)4]−），学生记得模糊就容易混搭；另外电荷、原子守恒未检查。

正确理解：按所用教材统一一种写法（人教版常用 AlO2−）：Al(OH)3 + OH− → AlO2− + 2H2O，左边电荷 −1、右边 −1，Al 1=1，O、H 均守恒。写完后必查电荷守恒。

避坑口诀：选定写法不混搭，电荷原子两头查。

易错 5

易错表现：把「使品红褪色」的气体一律答 Cl2，或认为 SO2 的漂白与 Cl2 相同，加热后现象判断错误。

错误成因：SO2 漂白是化合型（生成不稳定的无色物质），加热恢复红色；Cl2（实为 HClO）漂白是氧化型，加热不恢复。两者机理不同，题目常用「加热后是否复原」区分。

正确理解：推断中「褪色后加热又变红」⇒ SO2；「褪色后加热不变红」⇒ Cl2 等强氧化性漂白剂。

避坑口诀：加热复原是二氧化硫，不复原是氯。

易错 6

易错表现：写 Na2O2 与水反应的离子方程式时把 Na2O2 拆成离子，或把生成物写成 H2O2 收尾。

错误成因：Na2O2 是氧化物，按离子方程式书写规则「氧化物不拆」；另外反应机理中虽有过氧化氢中间过程，但最终产物是 O2，写总方程式不能停在中间产物。

正确理解：2Na2O2 + 2H2O → 4Na+ + 4OH− + O2↑，Na2O2 与 H2O 均不拆。

避坑口诀：氧化物不拆，产物写到底。

易错 7

易错表现：认为「能使澄清石灰水变浑浊的气体一定是 CO2」，忽略 SO2 也能生成 CaSO3 白色沉淀。

错误成因：CO2 + Ca(OH)2 → CaCO3↓ + H2O 印象太深，忘了 SO2 是同类酸性氧化物：SO2 + Ca(OH)2 → CaSO3↓ + H2O，现象几乎一样。

正确理解：鉴别用气味（SO2 有刺激性气味）或品红溶液（SO2 使其褪色，加热复原）。推断题中若只说「石灰水变浑浊」，两种气体都要考虑，用其他条件区分。

避坑口诀：石灰水变浑，碳硫皆可能；闻味或品红，一试见分晓。

5.1 推断题答题规范（写给阅卷老师看的答案）

答题规范

① 化学式书写：下标数字不得漏写、错写，Na2O2 不能写成 NaO2，Ca(HCO3)2 的括号不能丢。要求写名称时写「氢氧化铁」，要求写化学式时写 Fe(OH)3，审题圈出「化学式/名称/化学式或名称」。

② 方程式书写：必须配平；气体↑、沉淀↓ 标在生成物后；条件写在箭头上方（点燃/加热/高温/催化剂/通电）；离子方程式查「拆得对不对、电荷平不平、原子平不平」三关。可逆反应（SO2 催化氧化、NH3 合成）必须写 ⇌。

③ 现象描述：按「操作 + 现象 + 结论」三件套作答。如检验 Fe3+：「取少量待测液于试管中，滴加 KSCN 溶液，溶液变为血红色，证明含 Fe3+」。现象必须具体：颜色变化写全过程（白→灰绿→红褐），不写「产生现象」。

④ 推断过程表述：问「推断依据」时，答「因为……（特征现象/条件），所以……」。只写结论不写依据，高考要扣一半分。

六、与前后章节的联系

本章是元素化合物模块的「收口」章节，向前串联全部元素知识：

  • 与 3.4~3.6（非金属及其化合物）：C/N/S 三条连续氧化链、Cl2 与 SO2 的漂白对比、硅及其化合物的转化，是非金属章节知识的综合运用。
  • 与氧化还原反应（模块一）：连续氧化的本质是价态逐级升高，推断中常用「价态能不能再升」判断某一步转化是否可能发生。
  • 向后衔接 3.8~3.9（物质结构）：原子结构与周期律给出「为什么这个元素有这些价态」的理论解释，让推断从「背下来」升级为「推出来」。

七、高考怎么考

十、例 8 · 滴加顺序推断（补充例题）

例 8 · 试剂滴加顺序与现象差异

题目：现有两瓶失去标签的无色溶液：AlCl3 溶液和 NaOH 溶液。不用任何其他试剂，只用「互相滴加」的方法鉴别它们，写出操作、现象与结论。

【思路点拨】铝三角的用量控制：把 AlCl3 滴入过量 NaOH 中时，局部 OH− 过量，生成的 Al(OH)3 立即溶解，开始无沉淀，Al3+ 加到一定程度后才出现沉淀且不消失；反之把 NaOH 滴入 AlCl3 中，立即出现白色沉淀，持续滴加至过量沉淀又溶解。

1
操作甲：取 A 液少量于试管，逐滴加入 B 液。若立即产生白色沉淀，振荡不消失，继续滴加至过量时沉淀逐渐溶解，则 A 为 AlCl3 溶液，B 为 NaOH 溶液。
2
操作乙（验证）：反向滴加，若开始无现象，滴加较多后出现白色沉淀且不再溶解，则与甲的结论互证。
3
解释（用离子方程式）：过量碱中 Al3+ + 4OH− → AlO2− + 2H2O（无沉淀）；适量时 Al3+ + 3OH− → Al(OH)3↓；沉淀再溶 Al(OH)3 + OH− → AlO2− + 2H2O。
【答案】互滴鉴别：立即产生白色沉淀的滴加方式中，被滴入的试剂是 AlCl3；开始无沉淀的滴加方式中，被滴入的试剂是 NaOH。

【方法总结】中学「互滴可鉴别」的溶液组只有两类代表：① AlCl3/NaOH（沉淀先无后有 vs 先有后溶）；② Na2CO3/盐酸（先无气泡 vs 立即气泡）。本质都是「用量控制反应进程」。

十一、推断题专项训练（三道迷你题）

以下三题覆盖本章三种典型题型，建议按「30 秒找突破口 → 3 分钟推完 → 1 分钟验证」的节奏限时完成。

训练 1 · 连续氧化 + 漂白性鉴别

训练 1

题目：气体单质 M 在 O2 中燃烧生成气体 N；N 能继续与 O2 在催化剂加热条件下生成气体 P；P 与水反应生成强酸 Q。N 能使品红溶液褪色，加热后恢复红色。推断 M、N、P、Q，写出 N → P 的化学方程式。

【思路点拨】「品红褪色、加热复原」⇒ N = SO2，锁定硫系列连续氧化：S → SO2 → SO3。

1
突破口：N = SO2（可逆漂白）。
2
顺推：M = S（气体单质在 O2 中燃烧——注意 S 常温是固体，「气体单质」应理解为硫蒸气；P = SO3；Q = H2SO4。
3
验证：SO3 + H2O → H2SO4（强酸 ✓）；S 燃烧只能到 SO2 ✓。
【答案】M：S；N：SO2；P：SO3；Q：H2SO4。2SO2(g) + O2(g) ⇌ 2SO3(g)。

【方法总结】「可逆漂白」= SO2 是硬突破口；「不可逆漂白」= Cl2。先定漂白类型，再定系列。

训练 2 · 10 电子微粒推断

训练 2

题目：A、B、C、D 均为 10 电子微粒：A 是带 1 个单位正电荷的阳离子且含 5 个原子核；B 是带 1 个单位负电荷的阴离子且含 2 个原子核；A 与 B 加热反应生成 C 和 D，C 是碱性气体，D 是常见溶剂。推断并写出离子方程式。

【思路点拨】按「核数 + 电荷 + 性质」对号入座：A = NH4+，B = OH−，C = NH3，D = H2O。

1
A：五核 +1 价、10 电子 ⇒ NH4+（7+4−1=10）。
2
B：二核 −1 价、10 电子 ⇒ OH−（8+1+1=10）。
3
C：碱性气体 ⇒ NH3；D：溶剂 ⇒ H2O；验证均为 10 电子 ✓。
【答案】NH4+(aq) + OH−(aq) → NH3(g)↑ + H2O(l)。

【方法总结】本题与 3.8 章例 8 同源——10 电子推断只有一个核心反应，清单背熟即可秒杀。

训练 3 · 连续氧化与气体颜色

训练 3

题目：单质 A 与 O2 在放电条件下生成无色气体 B；B 接触空气立即变为红棕色气体 C；C 溶于水生成强酸 D 并重新放出 B。推断 A~D，写出 C 与水反应的化学方程式，并解释「雷雨发庄稼」的原理。

【思路点拨】「放电」+「无色→红棕」⇒ 氮系列：N2 → NO → NO2。

1
突破口：B = NO（无色遇空气变红棕）；A = N2；C = NO2；D = HNO3。
2
验证：3NO2 + H2O → 2HNO3 + NO（重新放出 B ✓）。
3
解释：雷电时 N2 与 O2 在放电下生成 NO，NO 氧化为 NO2，NO2 溶于雨水生成 HNO3 随雨水落地，转化为硝酸盐被植物吸收——把空气中的惰性 N2 变成了可利用的氮肥。
【答案】A：N2；B：NO；C：NO2；D：HNO3。3NO2(g) + H2O(l) → 2HNO3(aq) + NO(g)。

【方法总结】「放电/雷雨」是氮系列连续氧化的专属语境，见到即锁定。

模拟题

题目：短周期元素 X、Y、Z 均为主族元素。X 原子最外层电子数是次外层的 3 倍；Y 的氢化物与其最高价氧化物水化物能反应生成盐；Z 与 X 同主族且单质为淡黄色固体。回答：① 写出 X、Y、Z 的元素符号与名称；② 写出 Y 的氢化物与 Z 的最高价氧化物水化物反应的化学方程式；③ 比较 X、Z 的气态氢化物稳定性并说明理由。

1
X = O（最外层 6 = 次外层 2 × 3）。
2
Y = N（NH3 + HNO3 → NH4NO3）。
3
Z = S（淡黄色固体单质，ⅥA，与 O 同主族）。

【答案】① X：O（氧）；Y：N（氮）；Z：S（硫）。② 2NH3(g) + H2SO4(aq) → (NH4)2SO4(aq)。③ H2O 比 H2S 稳定，因非金属性 O > S。

十六、再补两条易错点

易错 8

易错表现：把「Al 与 NaOH 溶液反应」写成 2Al + 2NaOH → 2NaAlO2 + H2↑，漏掉水。

错误成因：只记「铝溶于碱」，忘了反应物中必须有 H2O 参与。正确：2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2↑（H 守恒：左 2+4=6，右 6 ✓）。

正确理解：该反应的氧化剂是水（Al 把 H2O 中的 H 还原为 H2），NaOH 只起「溶解氧化膜并生成偏铝酸盐」的作用。写方程式时必须补 H2O。

避坑口诀：铝溶碱，水必补。

易错 9

易错表现：认为铁与盐酸反应生成 FeCl3，或认为 Fe 在 Cl2 中燃烧生成 FeCl2。

错误成因：没有区分「非氧化性酸」与「强氧化性试剂」。盐酸中 H+ 氧化性弱，只能把 Fe 氧化到 +2；Cl2 是强氧化剂，直接把 Fe 氧化到 +3。

正确理解：Fe + 2HCl → FeCl2 + H2↑；2Fe + 3Cl2 → 2FeCl3。同理，Fe 与稀硝酸生成 Fe(NO3)3（硝酸足量时）。

避坑口诀：盐酸出亚铁，氯气出铁三。

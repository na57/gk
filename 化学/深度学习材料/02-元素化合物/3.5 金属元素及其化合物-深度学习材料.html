3.5 金属元素及其化合物

高中化学 · 深度学习材料 · 面向 2029 届云南高考

金属元素是高考无机化学的「半壁江山」：钠、铝、铁、铜四条主线贯穿选择题、工业流程题和实验探究题，分值约 20 分。本章内容多、方程式多，但规律性极强——抓住「单质 → 氧化物 → 氢氧化物 → 盐」这条主线，再辅以颜色、价态两个抓手，就能把零散知识织成网络。建议边学边画转化关系图，每周默写一次核心方程式。

本章按「钠 → 铝 → 铁 → 铜 → 金属通性」五条线展开。先看全局地图，再逐个击破。

学习方法

元素化合物的复习诀窍是「点—线—面」结合：每种元素的单质到化合物是一条线（如 Na → Na2O → Na2O2 → NaOH → Na2CO3），各元素之间通过对比（如 Na2O 与 Na2O2、Fe2+ 与 Fe3+）织成面。每个知识点都要落实到能默写方程式、能描述现象。

二、核心概念精讲

2.1 钠单质（Na）：最活泼的「遇水就着」的金属

核心概念

是什么：钠是银白色、质软（可用小刀切割）、密度比水小（0.97 g/cm³）、熔点低（97.8 ℃）的金属。新切开的钠表面有银白色金属光泽，在空气中迅速变暗（生成 Na2O）。

为什么活泼：钠原子最外层只有 1 个电子，原子半径在同周期中最大，极易失去电子形成 Na+，所以化学性质极活泼，在自然界中只以化合态（NaCl、Na2CO3 等）存在。

保存方法：保存在煤油中（钠的密度比煤油大，沉在底部，与空气、水隔绝）。不能用四氯化碳（钠浮在上面），更不能用水或乙醇。

钠与氧气的反应（条件不同，产物不同——高频考点）

4Na(s) + O2(g) → 2Na2O(s)　（表面变暗，生成白色固体） 2Na(s) + O2(g) → Na2O2(s)　（剧烈燃烧，黄色火焰，生成淡黄色固体）
易混提醒

钠与氧气反应的产物取决于条件而不是氧气用量：常温生成 Na2O，加热/点燃生成 Na2O2。这与量无关，是「条件控制产物」的经典案例。

钠与水的反应（现象口诀：浮、熔、游、响、红）

2Na(s) + 2H2O(l) → 2NaOH(aq) + H2(g)↑
现象原因（微观解释）
浮：钠浮在水面上钠的密度（0.97 g/cm³）比水小
熔：熔成闪亮的小球反应放热，钠的熔点低（97.8 ℃）
游：小球四处游动生成的 H2 推动小球，各方向受力不均
响：发出嘶嘶响声反应剧烈，H2 逸出并可能燃烧
红：滴有酚酞的溶液变红生成 NaOH，溶液呈碱性

钠与酸溶液反应更剧烈（直接与 H+ 反应）；钠投入盐溶液（如 CuSO4 溶液）时，钠先与水反应生成 NaOH 和 H2，NaOH 再与盐发生复分解反应（生成 Cu(OH)2 蓝色沉淀），不会置换出铜——因为钠太活泼，根本轮不到它与 Cu2+ 直接交换电子。

钠与氯气、硫的反应

2Na(s) + Cl2(g) → 2NaCl(s)　（剧烈燃烧，黄色火焰，产生白烟）

2.2 氧化钠与过氧化钠：一对「颜色不同、脾气迥异」的兄弟

核心概念

Na2O（白色固体）：典型的碱性氧化物，氧为 −2 价。与水、酸、酸性氧化物反应都只生成对应的碱或盐，不放氧气。

Na2O2（淡黄色固体）：过氧化物，氧为 −1 价，既具有强氧化性（漂白、杀菌），又能在与水、CO2 反应时自身歧化放出 O2。它不是碱性氧化物（与酸反应除了生成盐和水，还生成 O2）。

适用边界：Na2O2 可用作供氧剂（潜水艇、呼吸面具）、漂白剂；Na2O 没有这些用途。

常见混淆：① 颜色混淆——Na2O 白色，Na2O2 淡黄色；② 氧元素化合价混淆——Na2O 中 −2 价，Na2O2 中 −1 价；③ 阴阳离子个数比——Na2O2 中阴离子是 O22−（过氧根，一个整体），所以 Na2O2 中阴阳离子个数比为 1:2，不是 1:1。

对比项Na2ONa2O2
颜色状态白色固体淡黄色固体
氧的化合价−2−1
类别碱性氧化物过氧化物（不是碱性氧化物）
与水反应Na2O + H2O = 2NaOH2Na2O2 + 2H2O = 4NaOH + O2↑
与 CO2 反应Na2O + CO2 = Na2CO32Na2O2 + 2CO2 = 2Na2CO3 + O2

Na2O2 的「三大反应」（高考核心，必背）

2Na2O2(s) + 2H2O(l) → 4NaOH(aq) + O2(g)↑

现象：淡黄色固体逐渐溶解，剧烈反应、放出大量的热，产生大量气泡，生成的气体能使带火星的木条复燃；滴入酚酞先变红后褪色（NaOH 使酚酞变红，Na2O2 的强氧化性/生成的 H2O2 中间产物使其漂白褪色）。

2Na2O2(s) + 2CO2(g) → 2Na2CO3(s) + O2(g)

此反应是呼吸面具和潜水艇中供氧的原理：吸收 CO2，放出 O2。

2Na2O2(s) + 4HCl(aq) → 4NaCl(aq) + 2H2O(l) + O2(g)↑
氧化还原视角

Na2O2 与 H2O、CO2 的反应都是歧化反应：−1 价的氧一部分升高到 0 价（O2），一部分降低到 −2 价（H2O/Na2CO3 中的氧）。每 2 mol Na2O2 反应转移 2 mol 电子，生成 1 mol O2。记住比例：2 Na2O2 ~ 1 O2 ~ 2 e−，这是计算题的命脉。

2.3 氢氧化钠（NaOH）：俗名最多的强碱

核心概念

俗名：烧碱、火碱、苛性钠。白色固体，极易潮解（曝露在空气中吸收水分而逐渐溶解），易吸收 CO2 变质：2NaOH + CO2 = Na2CO3 + H2O，因此必须密封保存。

强腐蚀性：称量 NaOH 固体要放在小烧杯或表面皿中（不能放在纸上，会腐蚀纸并沾连），且要快速称量（防止潮解）。

试剂瓶：盛放 NaOH 溶液的试剂瓶用橡胶塞，不能用玻璃磨口塞——NaOH 与玻璃中的 SiO2 缓慢反应生成有黏性的 Na2SiO3，会把瓶塞粘住。

2.4 碳酸钠与碳酸氢钠：「苏打兄弟」对比是必考点

核心概念

Na2CO3：俗名纯碱、苏打，白色粉末，易溶于水，水溶液呈碱性（CO32− 水解）。注意：纯碱不是碱，是盐。

NaHCO3：俗名小苏打，白色细小晶体，溶解度比 Na2CO3 小，水溶液也呈碱性（HCO3− 水解程度大于电离程度），但碱性比 Na2CO3 弱。

热稳定性：Na2CO3 受热难分解；NaHCO3 受热易分解：

2NaHCO3(s) → Na2CO3(s) + H2O(l) + CO2(g)↑
对比项Na2CO3（纯碱）NaHCO3（小苏打）
溶解度较大较小（饱和 Na2CO3 溶液中通 CO2 会析出 NaHCO3 晶体）
热稳定性稳定，受热不分解不稳定，受热分解
与同浓度盐酸反应速率较慢（分两步：CO32−→HCO3−→CO2）更快，立即产生气泡
与酸反应耗酸量1 mol 耗 2 mol H+1 mol 耗 1 mol H+
与 NaOH 反应不反应NaHCO3 + NaOH = Na2CO3 + H2O
与 Ca(OH)2 反应Na2CO3 + Ca(OH)2 = CaCO3↓ + 2NaOH也生成 CaCO3↓（量不同方程式不同，高三再深究）
相互转化Na2CO3 + CO2 + H2O = 2NaHCO3；2NaHCO3 → Na2CO3 + H2O + CO2↑
鉴别方法

鉴别 Na2CO3 和 NaHCO3 的常用方法：① 加热法：加热固体，产生使澄清石灰水变浑浊的气体的是 NaHCO3；② 加 CaCl2/BaCl2 溶液：产生白色沉淀的是 Na2CO3（Ca2+ + CO32− = CaCO3↓），NaHCO3 无现象；③ 逐滴滴加盐酸：一开始无气泡、一段时间后才产生气泡的是 Na2CO3，立即产生气泡的是 NaHCO3。不能用 Ca(OH)2 溶液鉴别——两者都生成白色 CaCO3 沉淀。

2.5 铝单质（Al）：地壳中含量最高的金属

核心概念

是什么：银白色轻金属（密度 2.7 g/cm³），有良好的导电性、导热性、延展性。常温下铝表面生成致密的 Al2O3 薄膜，保护内部铝不被继续氧化（所以铝制品「耐腐蚀」）。

为什么能与强碱反应：铝位于金属与非金属交界处附近，具有一定的非金属性，其氧化物、氢氧化物都是两性的，铝单质也能与强碱溶液反应放出 H2——这是铝区别于 Mg、Fe 等「普通金属」的标志性性质。

常见混淆：铝与酸、碱反应都生成 H2，但产物不同：与盐酸生成 AlCl3，与 NaOH 生成 NaAlO2（偏铝酸钠）。2 mol Al 无论与足量酸还是足量碱反应，都生成 3 mol H2（Al 失去 3 个电子，2H+/2H2O 得电子生成 H2，电子守恒：2Al ~ 3H2）。

铝的主要反应

4Al(s) + 3O2(g) → 2Al2O3(s)　（剧烈燃烧，耀眼白光，放大量热） 2Al(s) + 6HCl(aq) → 2AlCl3(aq) + 3H2(g)↑ 2Al(s) + 2NaOH(aq) + 2H2O(l) → 2NaAlO2(aq) + 3H2(g)↑

铝与 NaOH 溶液反应的离子方程式：2Al + 2OH− + 2H2O = 2AlO2− + 3H2↑。注意水是反应物，H2 中的氢全部来自水。

铝热反应：铝粉与某些金属氧化物（如 Fe2O3）的混合物点燃，放出大量的热，可冶炼难熔金属或焊接钢轨：

2Al(s) + Fe2O3(s) → Al2O3(s) + 2Fe(l)　（火星四射，放出大量热，生成熔融铁）

2.6 氧化铝与氢氧化铝：两性是高考题眼

核心概念

两性氧化物的定义：既能与酸反应生成盐和水，又能与碱反应生成盐和水的氧化物。Al2O3 是最典型的两性氧化物。

两性氢氧化物：Al(OH)3 是白色胶状沉淀，难溶于水，既能与酸反应（表现碱性），又能与强碱反应（表现酸性）。微观本质：Al(OH)3 存在两种电离方式——酸式电离（Al(OH)3 ⇌ H+ + AlO2− + H2O）与碱式电离（Al(OH)3 ⇌ Al3+ + 3OH−），加酸平衡向碱式电离方向移动，加强碱向酸式电离方向移动。

适用边界：Al(OH)3 只溶于强碱（NaOH、KOH），不溶于弱碱（如氨水）；Al2O3 同理。所以实验室制 Al(OH)3 用「铝盐 + 氨水」而不是「铝盐 + NaOH」（NaOH 过量会溶解沉淀）。

Al2O3(s) + 6HCl(aq) → 2AlCl3(aq) + 3H2O(l) Al2O3(s) + 2NaOH(aq) → 2NaAlO2(aq) + H2O(l) Al(OH)3(s) + 3HCl(aq) → AlCl3(aq) + 3H2O(l) Al(OH)3(s) + NaOH(aq) → NaAlO2(aq) + 2H2O(l) 2Al(OH)3(s) → Al2O3(s) + 3H2O(l)

铝三角：Al3+、Al(OH)3、AlO2− 的相互转化

知识网络

铝三角是高考图像题、推断题、计算题的共同母体，务必把每条边对应的方程式背到条件反射：

  • Al3+ → Al(OH)3：加少量强碱或足量弱碱。Al3+ + 3OH−（少量）= Al(OH)3↓；Al3+ + 3NH3·H2O = Al(OH)3↓ + 3NH4+（氨水过量沉淀也不溶解，实验室制法）。
  • Al(OH)3 → Al3+：加足量酸。Al(OH)3 + 3H+ = Al3+ + 3H2O。
  • Al(OH)3 → AlO2−：加足量强碱。Al(OH)3 + OH− = AlO2− + 2H2O。
  • AlO2− → Al(OH)3：加少量强酸或通足量 CO2。AlO2− + H+（少量）+ H2O = Al(OH)3↓；AlO2− + CO2（足量）+ 2H2O = Al(OH)3↓ + HCO3−。
  • Al3+ → AlO2−：加足量强碱（一步 4 份 OH−）。Al3+ + 4OH−（足量）= AlO2− + 2H2O。
  • AlO2− → Al3+：加足量强酸（一步 4 份 H+）。AlO2− + 4H+（足量）= Al3+ + 2H2O。

数量关系口诀：「三沉一溶四溶解」——Al3+ 加 3 份 OH− 沉淀完全，再加 1 份（共 4 份）OH− 沉淀恰好溶解。

图像解读

向 AlCl3 溶液中逐滴滴加 NaOH 溶液：开始生成白色絮状沉淀并逐渐增多（Al3+ + 3OH− = Al(OH)3↓），沉淀达到最大值后继续滴加 NaOH，沉淀逐渐溶解直至消失（Al(OH)3 + OH− = AlO2− + 2H2O）。前后两段消耗 NaOH 的体积比为 3:1。反过来向 NaAlO2 溶液中滴加盐酸，先沉淀后溶解，前后耗酸比为 1:3。

2.7 铁单质（Fe）：变价金属的代表

核心概念

是什么：银白色金属（粉末为黑色），能被磁铁吸引。铁有 +2、+3 两种常见化合价，遇到强氧化剂（Cl2、Br2、浓 H2SO4、HNO3）生成 +3 价，遇到弱氧化剂（H+、Cu2+、S、I2）生成 +2 价。

为什么变价：铁原子可以失去最外层 2 个电子形成 Fe2+，也可以再失去次外层 1 个电子形成 Fe3+（Fe3+ 的 3d 轨道半充满，更稳定）。

钝化：常温下，铁、铝遇浓硫酸、浓硝酸表面生成致密氧化膜而「钝化」（化学变化！），所以可用铁罐车运输浓硫酸。

3Fe(s) + 2O2(g) → Fe3O4(s)　（剧烈燃烧，火星四射，生成黑色固体，放出大量热） 2Fe(s) + 3Cl2(g) → 2FeCl3(s)　（生成棕褐色的烟） Fe(s) + S(s) → FeS(s)　（放热反应，生成黑色固体） Fe(s) + 2HCl(aq) → FeCl2(aq) + H2(g)↑　（有气泡，溶液变浅绿色） Fe(s) + CuSO4(aq) → FeSO4(aq) + Cu(s)　（铁表面有红色物质析出，溶液由蓝色变浅绿色） 3Fe(s) + 4H2O(g) → Fe3O4(s) + 4H2(g)
易混提醒

铁在纯氧中燃烧生成 Fe3O4（不是 Fe2O3！）；铁与氯气反应无论铁是否过量都生成 FeCl3（因为反应在固体表面进行，过量的 Fe 不会与 FeCl3 固体接触反应）；但 FeCl3 溶液中加入 Fe 粉会发生 2Fe3+ + Fe = 3Fe2+。同样，铁与硫生成 FeS（+2 价），说明 S 的氧化性比 Cl2 弱。

2.8 铁的氧化物与氢氧化物

物质俗名/颜色铁的价态与盐酸反应
FeO黑色粉末+2FeO + 2H+ = Fe2+ + H2O
Fe2O3铁红，红棕色粉末+3Fe2O3 + 6H+ = 2Fe3+ + 3H2O

三种氧化物都不溶于水，都能被 CO、H2、Al 等还原为铁（高炉炼铁的原理）。FeO 不稳定，易被氧化。

Fe(OH)2 与 Fe(OH)3：一组颜色大戏

FeCl2(aq) + 2NaOH(aq) → Fe(OH)2(s)↓ + 2NaCl(aq) 4Fe(OH)2(s) + O2(g) + 2H2O(l) → 4Fe(OH)3(s)

向 FeSO4 溶液中滴加 NaOH 溶液：先生成白色絮状沉淀（Fe(OH)2），沉淀迅速变成灰绿色，最终变成红褐色（Fe(OH)3）。这组颜色变化是高考实验题和推断题的「黄金题眼」，务必逐字背熟。

FeCl3(aq) + 3NaOH(aq) → Fe(OH)3(s)↓（红褐色） + 3NaCl(aq) 2Fe(OH)3(s) → Fe2O3(s) + 3H2O(l)
实验改进

制备 Fe(OH)2 并想长时间观察到白色，关键是隔绝氧气：① 所用蒸馏水先煮沸除 O2；② 胶头滴管伸入液面以下挤出 NaOH 溶液；③ 液面上加苯或煤油液封；④ 用 H2 排尽装置内空气（氢气还原氧化铜装置的改进思路）。

2.9 Fe2+ 与 Fe3+：检验与相互转化（铁三角核心）

离子溶液颜色加 NaOH 溶液检验方法
Fe2+浅绿色白色沉淀→迅速灰绿→最终红褐先加 KSCN 溶液无现象，再加氯水后变血红色；或加 K3[Fe(CN)6] 生成蓝色沉淀

知识网络

铁三角转化（Fe、Fe2+、Fe3+）：

  • Fe → Fe2+：与弱氧化剂（H+、Cu2+、S、I2、Fe3+）反应。
  • Fe → Fe3+：与足量强氧化剂（Cl2、Br2、HNO3）反应。
  • Fe2+ → Fe3+：加氧化剂（Cl2、Br2、H2O2、KMnO4、HNO3、O2/H+）。
  • Fe3+ → Fe2+：加还原剂（Fe、Cu、H2S、SO2、I−、S2−）。
  • Fe2+ → Fe：被活泼金属（Zn、Al）置换或电解。
  • Fe3+ → Fe：先被 Zn 等还原为 Fe2+，再进一步被还原为 Fe（Zn 过量时一步完成）。
2FeCl2(aq) + Cl2(g) → 2FeCl3　　2Fe2+ + Cl2 = 2Fe3+ + 2Cl− 2FeCl3(aq) + Fe(s) → 3FeCl2　　2Fe3+ + Fe = 3Fe2+ 2FeCl3(aq) + Cu(s) → 2FeCl2 + CuCl2　　2Fe3+ + Cu = 2Fe2+ + Cu2+（刻蚀印刷电路板原理） 4Fe(OH)2 + O2 + 2H2O → 4Fe(OH)3　（Fe2+ 在空气中即被缓慢氧化）
除杂应用

① 除去 FeCl2 溶液中混有的 FeCl3：加足量铁粉，充分反应后过滤。② 除去 FeCl3 溶液中混有的 FeCl2：通入足量氯气或滴加适量 H2O2 溶液（不能用 KMnO4，会引入新杂质）。③ Fe2+ 溶液保存：加少量铁粉防止氧化，并密封。

2.10 铜及其化合物：颜色是它的名片

核心概念

铜单质：紫红色金属，导电性仅次于银。化学性质比较稳定，不与非氧化性酸（稀盐酸、稀硫酸）反应，但能与强氧化性酸（浓硫酸、硝酸）反应，也能被 FeCl3 溶液腐蚀。

颜色清单（推断题突破口）：Cu 紫红色；CuO 黑色；Cu2O 砖红色；Cu(OH)2 蓝色絮状；CuSO4·5H2O 蓝色晶体（胆矾/蓝矾）；无水 CuSO4 白色粉末（可检验水的存在）；Cu2+ 溶液蓝色；[Cu(NH3)4]2+ 深蓝色；Cu2(OH)2CO3 绿色（铜绿/铜锈）。

2Cu(s) + O2(g) → 2CuO(s)　（紫红色固体逐渐变黑） 2Cu(s) + O2(g) + H2O(l) + CO2(g) → Cu2(OH)2CO3(s)　（铜在潮湿空气中生成铜绿） Cu(s) + 2H2SO4(浓) → CuSO4(aq) + SO2(g)↑ + 2H2O(l) CuSO4(aq) + 2NaOH(aq) → Cu(OH)2(s)↓（蓝色絮状） + Na2SO4 Cu(OH)2(s) → CuO(s)（蓝色沉淀变黑） + H2O(l)

向 CuSO4 溶液中滴加氨水：先生成蓝色 Cu(OH)2 沉淀，继续滴加氨水，沉淀溶解，得到深蓝色溶液（生成 [Cu(NH3)4]2+ 配离子）——这是铜盐的特征反应之一，也常在推断题中出现。

2.11 金属活动性顺序与金属冶炼

核心概念

金属活动性顺序：K Ca Na Mg Al ｜ Zn Fe Sn Pb (H) ｜ Cu Hg Ag ｜ Pt Au。

三大应用：① 排在 H 前面的金属能与稀盐酸、稀硫酸反应放出 H2，排在 H 后面的不能；② 排在前面的金属（K、Ca、Na 除外）能把排在后面的金属从其盐溶液中置换出来；③ 金属越活泼，其阳离子越难被还原，冶炼越困难。

为什么冶炼方法与活动性相关：冶炼的本质是把化合态的金属阳离子还原为单质。金属越活泼，阳离子得电子能力越弱，需要的还原手段越强——所以活泼金属只能用电解法（最强的「电子泵」）。

金属冶炼方法原理方程式
K、Ca、Na、Mg、Al电解法（电解熔融化合物）2NaCl(熔融) → 2Na + Cl2↑；2Al2O3(熔融) → 4Al + 3O2↑
Zn、Fe、Sn、Pb、Cu热还原法（用 C、CO、H2、Al 作还原剂）Fe2O3 + 3CO → 2Fe + 3CO2；2CuO + C → 2Cu + CO2↑
Hg、Ag热分解法2HgO → 2Hg + O2↑
Pt、Au自然界中以游离态存在物理方法（沙里淘金）
细节提醒

① 电解铝用 Al2O3 而不用 AlCl3，因为 AlCl3 是共价化合物，熔融时不导电；加入冰晶石（Na3AlF6）是为了降低 Al2O3 的熔化温度。② 电解镁用 MgCl2 而不用 MgO，因为 MgO 熔点太高（2852 ℃）。这两个「选择」都是常考题。③ 合金：由两种或两种以上的金属（或金属与非金属）熔合而成，一般硬度比成分金属大、熔点比成分金属低（如生铁、钢、硬铝、黄铜）。

2.12 焰色反应：物理变化的「验身术」

核心概念

是什么：某些金属或它们的化合物在灼烧时使火焰呈现特殊颜色的现象。钠黄色、钾紫色（透过蓝色钴玻璃观察，滤去钠的黄色干扰）、钙砖红色、锶洋红色、钡黄绿色、铜绿色。

为什么是物理变化：焰色反应是原子中的电子吸收能量跃迁到高能级，再跃迁回低能级时放出特定波长的光，元素的种类没有改变，没有新物质生成，属于物理变化。

操作要点：用铂丝（或洁净铁丝）蘸取试样，在无色火焰上灼烧；每测一次要用盐酸洗净铂丝并灼烧至无色（不用硫酸，因为硫酸盐沸点高不易挥发，会干扰下次测定）。

2.13 合金：性能升级的「混合智慧」

核心概念

是什么：由两种或两种以上的金属（或金属与非金属）熔合而成的具有金属特性的物质，属于混合物。

性能规律：与成分金属相比，合金一般硬度更大、熔点更低、抗腐蚀性更好。微观解释：大小不同的原子混合后打乱了金属晶体中原有的规整排列，原子层之间更难滑动（硬度增大），金属键被削弱（熔点降低）。

常见合金：① 铁合金——生铁（含碳 2%~4.3%，硬而脆）和钢（含碳 0.03%~2%，不锈钢中还含 Cr、Ni）；② 铝合金——硬铝（含 Cu、Mg、Mn，密度小强度大，用于飞机制造）；③ 铜合金——青铜（Cu-Sn）、黄铜（Cu-Zn）、白铜（Cu-Ni）；④ 新型合金——钛合金（生物相容性好，用于人造骨骼）、储氢合金（如 LaNi5）、形状记忆合金（Ni-Ti）。

常见混淆：合金是混合物而不是化合物；「钢」不是纯铁；合金中各成分金属仍保持自身的化学性质（如铝合金中的铝仍能与盐酸反应放出 H2）。

三、三重表征贯通

「宏观现象 — 微观粒子 — 符号表达」三位一体，是学好元素化合物的核心思维。本章六组经典反应，请反复对着表格默写、互查。

3.1 钠与水的反应

宏观现象

金属钠浮在水面上，熔成闪亮的小球，四处游动，发出嘶嘶响声；反应后滴入酚酞，溶液变红。反应剧烈放热，钠块较大时甚至可使生成的 H2 燃烧。

微观粒子

Na 原子把最外层 1 个电子转移给 H2O 中的 H（H+），Na 被氧化为 Na+ 进入溶液；H 得到电子后两两结合成 H2 分子逸出；溶液中剩余大量 OH−，使酚酞变红。本质是 Na 与水电离出的 H+ 之间的氧化还原反应。

符号表达

2Na + 2H2O = 2NaOH + H2↑

离子方程式：2Na + 2H2O = 2Na+ + 2OH− + H2↑

电子转移：2Na ~ 2e− ~ H2

3.2 过氧化钠与水的反应

宏观现象

淡黄色固体与水接触即剧烈反应，放出大量的热，产生大量气泡；生成的气体能使带火星的木条复燃（O2）；反应后滴加酚酞，溶液先变红、后褪色（强氧化性漂白）。

微观粒子

Na2O2 中 −1 价的过氧根（O22−）发生歧化：一部分 O 原子失电子升为 0 价，两两结合成 O2 逸出；另一部分得电子降为 −2 价，进入 OH−。Na2O2 既是氧化剂又是还原剂，每 2 mol Na2O2 转移 2 mol 电子。

符号表达

2Na2O2 + 2H2O = 4NaOH + O2↑

2Na2O2 + 2CO2 = 2Na2CO3 + O2

比例关系：2Na2O2 ~ O2 ~ 2e−

3.3 氢氧化亚铁被氧化的「颜色大戏」

宏观现象

向 FeSO4 溶液中滴加 NaOH 溶液，立即生成白色絮状沉淀；沉淀在空气中迅速变为灰绿色（中间过渡色），最终变为红褐色。整个过程像一场「变色魔术」，是 Fe2+ 的标志性实验现象。

微观粒子

Fe2+ 与 OH− 结合生成白色的 Fe(OH)2 沉淀；Fe(OH)2 中的 Fe 为 +2 价，还原性强，被溶解在溶液中的 O2 氧化，Fe 从 +2 价升到 +3 价，逐步转化为红褐色的 Fe(OH)3；灰绿色是白色 Fe(OH)2 与红褐色 Fe(OH)3 混合的中间颜色。

符号表达

Fe2+ + 2OH− = Fe(OH)2↓（白色）

4Fe(OH)2 + O2 + 2H2O = 4Fe(OH)3（红褐色）

现象链：白色 → 灰绿色 → 红褐色

3.4 铝盐溶液中滴加强碱：沉淀的「先开后合」

宏观现象

向 AlCl3 溶液中逐滴滴加 NaOH 溶液：立即出现白色胶状沉淀并逐渐增多；沉淀达到最大值后，继续滴加 NaOH，沉淀逐渐溶解，最终得到无色澄清溶液。若改滴氨水，则沉淀生成后不再溶解。

微观粒子

第一阶段：Al3+ 与 OH− 按 1:3 结合生成 Al(OH)3 胶状沉淀；第二阶段：过量的 OH− 进攻 Al(OH)3，使其酸式电离，生成可溶的 AlO2−（偏铝酸根）而溶解。氨水中 NH3·H2O 电离出的 OH− 浓度太小，不足以让 Al(OH)3 酸式电离，故沉淀不溶。

符号表达

Al3+ + 3OH− = Al(OH)3↓

Al(OH)3 + OH− = AlO2− + 2H2O

总反应：Al3+ + 4OH− = AlO2− + 2H2O（两段耗碱比 3:1）

3.5 Fe3+ 的检验：一滴 KSCN 定乾坤

宏观现象

向含 Fe3+ 的（棕）黄色溶液中滴加 KSCN 溶液，溶液立即变为血红色（不是沉淀！是溶液整体显色）。Fe2+ 的浅绿色溶液滴加 KSCN 无现象，再滴入氯水后变为血红色。

微观粒子

Fe3+ 与 SCN− 通过配位键结合，生成血红色的配合物 Fe(SCN)3（也可写作 [Fe(SCN)]2+ 等一系列配离子），分散在溶液中使整体显色。Fe2+ 不能与 SCN− 显色，但可被 Cl2、H2O2 氧化为 Fe3+ 后显色。

符号表达

Fe3+ + 3SCN− = Fe(SCN)3（血红色）

2Fe2+ + Cl2 = 2Fe3+ + 2Cl−

检验 Fe2+ 顺序：先 KSCN（无现象）→ 后加氯水（变红）

3.6 铝与氢氧化钠溶液的反应

宏观现象

铝片放入 NaOH 溶液中，开始时几乎无现象（表面的氧化膜先被溶解）；随后铝片表面不断产生无色气泡，铝片逐渐溶解，试管壁发热。点燃产生的气体，能安静燃烧（气体不纯时发出爆鸣声），证明是 H2。

微观粒子

第一步：NaOH 溶解铝表面的 Al2O3 保护膜（Al2O3 + 2OH− = 2AlO2− + H2O），所以开始无气泡；第二步：裸露的 Al 原子把电子转移给 H2O 中的 H，Al 被氧化并以 AlO2−（偏铝酸根）形式存在于碱性溶液中，H 得电子结合成 H2 逸出。该反应的氧化剂是水，NaOH 本身不得电子，只起溶解氧化膜、提供碱性环境的作用。

符号表达

2Al + 2NaOH + 2H2O = 2NaAlO2 + 3H2↑

离子方程式：2Al + 2OH− + 2H2O = 2AlO2− + 3H2↑

电子转移：2Al ~ 6e− ~ 3H2

四、典型例题分步拆解

例题 1 · Na2CO3 与 NaHCO3 的鉴别与计算

题目：现有两瓶失去标签的白色固体，分别是 Na2CO3 和 NaHCO3。（1）设计三种不同的实验方法鉴别它们（写出操作、现象和结论）。（2）取某 Na2CO3 和 NaHCO3 的混合物 19.0 g，加热至质量不再变化，剩余固体质量为 15.9 g。计算原混合物中 Na2CO3 的质量分数。

【思路点拨】（1）抓住二者性质差异：热稳定性、与 CaCl2 的反应、与酸反应的先后顺序。（2）加热时只有 NaHCO3 分解，质量减少的部分就是生成的 H2O 和 CO2 的质量，用差量法求解。

1

方法一（加热法）：分别取少量固体加热，将产生的气体通入澄清石灰水。石灰水变浑浊（有 CO2 生成）的原固体是 NaHCO3；无明显现象的是 Na2CO3。

2

方法二（加 CaCl2 溶液）：分别配成溶液，滴加 CaCl2 溶液。立即产生白色沉淀（CaCO3）的是 Na2CO3；无现象的是 NaHCO3。

3

方法三（逐滴滴加稀盐酸）：向两种溶液中分别逐滴滴加稀盐酸。开始无气泡、滴加一定量后才开始产生气泡的是 Na2CO3（先发生 CO32− + H+ = HCO3−）；一滴入就立即产生气泡的是 NaHCO3。

4

计算：设混合物中 NaHCO3 的质量为 x。加热时只有 NaHCO3 分解：2NaHCO3 → Na2CO3 + H2O + CO2↑。每 2 mol NaHCO3（2×84 = 168 g）分解，固体质量减少（18 + 44）= 62 g。

5

质量减少量 = 19.0 g − 15.9 g = 3.1 g。列比例：168 g : 62 g = x : 3.1 g，解得 x = 8.4 g。

6

则 Na2CO3 的质量 = 19.0 g − 8.4 g = 10.6 g，质量分数 = 10.6 g ÷ 19.0 g × 100% ≈ 55.8%。

【答案】（1）如上三种方法；（2）原混合物中 Na2CO3 的质量分数约为 55.8%。

【方法总结】差量法是处理「反应前后质量变化」问题的利器：先写出方程式，找出理论差量（每摩尔反应对应的质量变化），再用实际差量列比例。NaHCO3 分解类题目的差量恒为「H2O + CO2 = 62 g/2 mol NaHCO3」。

例题 2 · 铝三角图像计算

题目：向 100 mL 1.0 mol/L 的 AlCl3 溶液中滴加 1.0 mol/L 的 NaOH 溶液。（1）当加入 NaOH 溶液 250 mL 时，生成沉淀的质量是多少？（2）若要使生成的沉淀恰好完全溶解，至少需要加入 NaOH 溶液多少毫升？

【思路点拨】先算 Al3+ 的物质的量，再按「先沉淀、后溶解」两段反应分步计算。关键比例：Al3+ 沉淀完全需 3 份 OH−，沉淀全部溶解再需 1 份 OH−。

1

n(Al3+) = 0.100 L × 1.0 mol/L = 0.10 mol。

2

沉淀完全时需 OH−：0.10 mol × 3 = 0.30 mol（反应① Al3+ + 3OH− = Al(OH)3↓），对应 NaOH 溶液 300 mL。

3

第（1）问：加入 250 mL NaOH，n(OH−) = 0.250 L × 1.0 mol/L = 0.25 mol < 0.30 mol，只发生反应①，OH− 不足，按 OH− 计算：n[Al(OH)3] = 0.25 mol ÷ 3 = 1/12 mol ≈ 0.0833 mol。

4

沉淀质量 = 1/12 mol × 78 g/mol = 6.5 g。

5

第（2）问：沉淀恰好完全溶解，总反应为 Al3+ + 4OH− = AlO2− + 2H2O，需 n(OH−) = 0.10 mol × 4 = 0.40 mol，V(NaOH) = 0.40 mol ÷ 1.0 mol/L = 0.40 L = 400 mL。

【答案】（1）生成 Al(OH)3 沉淀 6.5 g；（2）至少需要 NaOH 溶液 400 mL。

【方法总结】铝三角计算题的通用套路：① 求出 n(Al3+)；② 画出「沉淀量 — NaOH 体积」图像（先升后降，转折点在 3 份和 4 份处）；③ 判断所加 NaOH 落在哪一段，选对反应方程式计算。若 NaOH 体积在 300~400 mL 之间，说明先生成 0.10 mol 沉淀后又溶解了一部分，用总 OH− 减去沉淀用掉的 0.30 mol，剩余的用于溶解沉淀。

例题 3 · Na2O2 与 CO2、H2O 的增重计算

题目：将 2.24 L（标准状况）由 CO2 和水蒸气组成的混合气体，缓缓通过足量的 Na2O2 固体，充分反应后固体质量增加了 3.0 g。求原混合气体中 CO2 的体积分数。

【思路点拨】写出两个反应方程式，找出「通入什么、放出什么、留下什么」：2Na2O2 + 2CO2 = 2Na2CO3 + O2，相当于每吸收 2 mol CO2（88 g）只放出 1 mol O2（32 g），固体净增 56 g（即 2CO 的质量）；2Na2O2 + 2H2O = 4NaOH + O2↑，每吸收 2 mol H2O（36 g）放出 1 mol O2（32 g），净增 4 g（即 2H2 的质量）。

1

混合气体总物质的量 = 2.24 L ÷ 22.4 L/mol = 0.10 mol。设 CO2 为 a mol，H2O 为 b mol，则 a + b = 0.10。

2

CO2 引起的增重：由方程式，每 2 mol CO2 使固体增重 56 g，即每 mol CO2 增重 28 g（相当于吸收了「CO」），故 CO2 贡献增重 28a g。

3

H2O 引起的增重：每 2 mol H2O 使固体增重 4 g，即每 mol H2O 增重 2 g（相当于吸收了「H2」），故 H2O 贡献增重 2b g。

4

列方程组：a + b = 0.10；28a + 2b = 3.0。由第一式 b = 0.10 − a，代入第二式：28a + 2(0.10 − a) = 3.0 → 26a = 2.8 → a ≈ 0.1077？检查：26a = 2.8，a = 0.1077 > 0.10，不合理——重新核算数据。

5

核算：若 a = 0.10 mol 全为 CO2，增重应为 2.8 g；实际增重 3.0 g 介于 0.2 g（全为 H2O 时）与 2.8 g 之间——3.0 g 超出上限，说明题目数据需修正。将混合气体体积改为 4.48 L（0.20 mol），增重仍为 3.0 g：a + b = 0.20；28a + 2b = 3.0 → 26a = 2.6 → a = 0.10 mol，b = 0.10 mol。数据自洽。

6

CO2 体积分数 = 0.10 mol ÷ 0.20 mol × 100% = 50%。

【答案】原混合气体中 CO2 的体积分数为 50%（按 4.48 L 混合气体、增重 3.0 g 计算）。（本题原数据 2.24 L 与 3.0 g 不匹配，讲解时已修正为 4.48 L；同学们做题时也要养成「先验证数据合理性」的习惯。）

【方法总结】Na2O2 增重问题的万能结论：凡组成符合 (CO)m(H2)n 形式的气体（如 CO、H2、CH3COOH、葡萄糖等），完全燃烧产物通过足量 Na2O2 后，固体增重恰好等于原气体的质量——因为 CO2 留下的部分相当于「CO」，H2O 留下的部分相当于「H2」。记住「增重量 = 吸收的 CO + H2 的质量」即可秒杀此类题。

例题 4 · Fe2+/Fe3+ 转化实验探究

题目：某同学设计实验验证「Fe2+ 具有还原性、Fe3+ 具有氧化性」。供选试剂：FeSO4 溶液、FeCl3 溶液、氯水、KSCN 溶液、铜片、淀粉-KI 溶液、酸性 KMnO4 溶液。请完成下表：

实验目的实验操作预期现象与结论
验证 Fe2+ 有还原性？？
验证 Fe3+ 有氧化性？？

【思路点拨】验证某离子有还原性，就要加入氧化剂并证明它发生了化合价升高；验证有氧化性，就加入还原剂并证明它化合价降低。现象要「可视化」——借助 KSCN 显色、淀粉变蓝、KMnO4 褪色等。

1

验证 Fe2+ 有还原性：取 2 mL FeSO4 溶液于试管中，先滴加几滴 KSCN 溶液，溶液不变红（说明无 Fe3+）；再滴加少量氯水振荡，溶液变为血红色。说明 Fe2+ 被 Cl2 氧化为 Fe3+：2Fe2+ + Cl2 = 2Fe3+ + 2Cl−，Fe2+ 表现了还原性。

2

（替代方案）取 FeSO4 溶液滴加到酸性 KMnO4 溶液中，KMnO4 溶液紫色褪去：MnO4− + 5Fe2+ + 8H+ = Mn2+ + 5Fe3+ + 4H2O，也证明 Fe2+ 有还原性。

3

验证 Fe3+ 有氧化性（方法一）：取 2 mL FeCl3 溶液，加入一小片打磨过的铜片，振荡，铜片逐渐溶解，溶液由（棕）黄色逐渐变为蓝色（Cu2+）：2Fe3+ + Cu = 2Fe2+ + Cu2+，Fe3+ 被还原为 Fe2+，表现了氧化性。

4

验证 Fe3+ 有氧化性（方法二）：取 FeCl3 溶液滴加到淀粉-KI 溶液中，溶液变蓝：2Fe3+ + 2I− = 2Fe2+ + I2，生成的 I2 遇淀粉变蓝，证明 Fe3+ 有氧化性。

【答案】见上述步骤。核心方程式：2Fe2+ + Cl2 = 2Fe3+ + 2Cl−；2Fe3+ + Cu = 2Fe2+ + Cu2+；2Fe3+ + 2I− = 2Fe2+ + I2。

【方法总结】「性质验证」类实验题的答题模板：取样（2 mL）→ 加试剂（几滴）→ 描述现象（具体到颜色变化）→ 得出结论（呼应题干）→ 写方程式。现象描述一定要写「谁在变」：溶液由 × 色变为 × 色、有无沉淀/气体生成。

例题 5 · 铁与稀硝酸反应的先后（拓展）

题目：向含 0.3 mol HNO3 的稀硝酸中加入 5.6 g 铁粉，充分反应后，溶液中的溶质是什么？生成气体在标准状况下的体积是多少？（提示：稀硝酸的还原产物为 NO）

【思路点拨】Fe 与 HNO3 反应，HNO3 足量时生成 Fe(NO3)3；Fe 过量时，过量的 Fe 会把 Fe3+ 还原为 Fe2+（2Fe3+ + Fe = 3Fe2+）。先按「HNO3 全部生成 Fe3+」算一遍，再判断 Fe 是否过量。

1

n(Fe) = 5.6 g ÷ 56 g/mol = 0.10 mol，n(HNO3) = 0.30 mol。

2

假设生成 Fe(NO3)3：Fe + 4HNO3(稀) = Fe(NO3)3 + NO↑ + 2H2O，0.10 mol Fe 需 0.40 mol HNO3，而只有 0.30 mol，酸不足。

3

按酸计算：0.30 mol HNO3 可溶解 Fe 0.075 mol，生成 Fe(NO3)3 0.075 mol、NO 0.075 mol，剩余 Fe 0.025 mol。

4

剩余的 Fe 继续与 Fe3+ 反应：2Fe3+ + Fe = 3Fe2+。0.025 mol Fe 恰好与 0.05 mol Fe3+ 反应，生成 0.075 mol Fe2+，反应后 Fe3+ 剩余 0.075 − 0.05 = 0.025 mol。铁粉恰好无剩余。

5

所以溶液中溶质为 Fe(NO3)2（0.075 mol）和 Fe(NO3)3（0.025 mol）；气体 NO：0.075 mol × 22.4 L/mol = 1.68 L。

【答案】溶质为 Fe(NO3)2 和 Fe(NO3)3（物质的量之比 3:1）；生成 NO 1.68 L（标准状况）。

【方法总结】「Fe + 氧化性酸」的计算遵循「反应顺序」思维：第一步永远是 Fe → Fe3+（HNO3 是强氧化剂），第二步才是过量的 Fe 把 Fe3+ 还原为 Fe2+。用「区间法」判断终态：n(Fe)/n(HNO3) ≤ 1/4 全为 Fe3+；≥ 3/8 全为 Fe2+；介于两者之间则两种价态共存。

例题 6 · 工业流程：从铝土矿中提取铝

题目：工业上以铝土矿（主要成分为 Al2O3，含 Fe2O3、SiO2 等杂质）为原料生产铝，流程如下：铝土矿 → 加足量 NaOH 溶液，过滤 → 滤液中通入足量 CO2，过滤 → 滤渣灼烧 → 电解熔融产物（加冰晶石）→ 铝。请回答：（1）加入 NaOH 溶液后，滤渣的主要成分是什么？写出溶解反应的化学方程式。（2）通入足量 CO2 时发生反应的离子方程式。（3）电解时加入冰晶石的作用是什么？

【思路点拨】流程题的核心是「看走向、找转化」：Al2O3 是两性氧化物，能溶于 NaOH 生成可溶的 NaAlO2；Fe2O3 是碱性氧化物，不与 NaOH 反应，成为滤渣除去；再向滤液中通 CO2 把 AlO2−「变回」Al(OH)3 沉淀，灼烧得 Al2O3，电解得铝。

1

（1）Al2O3 与 NaOH 反应：Al2O3 + 2NaOH = 2NaAlO2 + H2O；Fe2O3 不与 NaOH 反应，故滤渣的主要成分为 Fe2O3（红色固体，工业上称为「赤泥」，可作炼铁原料）。

2

（2）向 NaAlO2 溶液中通入足量 CO2：AlO2− + CO2 + 2H2O = Al(OH)3↓ + HCO3−。注意 CO2 足量时生成 HCO3−，而不是 CO32−。

3

（3）滤渣 Al(OH)3 灼烧：2Al(OH)3 → Al2O3 + 3H2O；电解：2Al2O3(熔融) → 4Al + 3O2↑。加入冰晶石（Na3AlF6）的作用是作助熔剂，降低 Al2O3 的熔化温度（从约 2050 ℃ 降到约 1000 ℃），从而节约能源、降低成本。

【答案】（1）Fe2O3；Al2O3 + 2NaOH = 2NaAlO2 + H2O。（2）AlO2− + CO2 + 2H2O = Al(OH)3↓ + HCO3−。（3）作助熔剂，降低 Al2O3 的熔化温度。

【方法总结】工业流程题答题三问：每一步「加了什么、发生了什么、除掉了谁」。含铝流程的通用骨架是「溶（碱溶或酸溶）→ 滤（除去不溶杂质）→ 沉（通 CO2 或调 pH 得 Al(OH)3）→ 烧（得 Al2O3）→ 电解（得 Al）」，遇到流程变体也能对号入座。

五、易错点与成因

易错点 1

易错表现：认为「钠与氧气反应，氧气足量生成 Na2O2，氧气不足生成 Na2O」。

错误成因：把碳与氧气的反应（O2 足量生成 CO2、不足生成 CO）错误迁移过来，混淆了「用量控制产物」与「条件控制产物」两类反应。

正确理解：钠与氧气的产物只由温度/点燃条件决定——常温生成 Na2O，加热或点燃生成 Na2O2，与氧气用量无关。Na2O 在加热条件下还能继续与 O2 反应生成 Na2O2。

避坑口诀：「钠氧反应看温度，不看用量看条件。」

易错点 2

易错表现：把 Na2O2 当作碱性氧化物，认为它与酸反应只生成盐和水；或认为 Na2O2 中阴、阳离子个数比为 1:1。

错误成因：只记住了「金属氧化物 = 碱性氧化物」的粗糙归类，没有从反应产物（是否只生成盐和水）这一判据出发；对过氧根 O22− 是一个整体缺乏认识。

正确理解：碱性氧化物的定义是「与酸反应只生成盐和水的氧化物」。Na2O2 与酸反应除生成盐和水外还生成 O2，所以它是过氧化物而非碱性氧化物。Na2O2 由 2 个 Na+ 和 1 个 O22− 构成，阴阳离子个数比为 1:2。

避坑口诀：「过氧根是一个家，两个钠来陪着它；遇上酸水放出氧，碱性氧化物没它。」

易错点 3

易错表现：用 Ca(OH)2 溶液鉴别 Na2CO3 和 NaHCO3；或认为向 NaHCO3 溶液中滴加盐酸「先无现象后有气泡」。

错误成因：没有真正理解 CO32− 与 H+ 反应是分两步进行的（CO32− + H+ = HCO3−，HCO3− + H+ = H2O + CO2↑），把两步反应的顺序记反；也不知道 Ca(OH)2 与两者都生成 CaCO3 白色沉淀。

正确理解：逐滴滴加盐酸时，Na2CO3 先转化为 HCO3−（无气泡），再生成 CO2（有气泡）；NaHCO3 直接产生气泡。鉴别时应选 CaCl2/BaCl2 溶液（只与 Na2CO3 生成沉淀）或加热法，不能用 Ca(OH)2 溶液。

避坑口诀：「碳酸根遇酸分两步，碳酸氢根一步到位；鉴别用氯化钙，不用石灰水。」

易错点 4

易错表现：认为 Al(OH)3 能溶于氨水，或实验室用「AlCl3 + 过量 NaOH」制备 Al(OH)3。

错误成因：把「Al(OH)3 是两性氢氧化物」绝对化，忽略了两性的边界——它只溶于强碱，不溶于弱碱；对「过量强碱会溶解产物」缺乏警觉。

正确理解：Al(OH)3 只溶于强酸和强碱，不溶于氨水、碳酸等弱电解质。实验室制取 Al(OH)3 的最佳方案是 Al3+ + 3NH3·H2O = Al(OH)3↓ + 3NH4+（氨水过量沉淀也不溶解），或向 NaAlO2 溶液中通足量 CO2。

避坑口诀：「两性有边界，弱碱靠边站；制取氢氧化铝，氨水最保险。」

易错点 5

易错表现：认为铁与氯气反应「铁过量时生成 FeCl2」；或认为 Fe2+ 的溶液是黄色、Fe3+ 是绿色。

错误成因：把溶液中的均相反应规律（Fe 可把 Fe3+ 还原为 Fe2+）错误套用到固气反应中——固体 Fe 与 Cl2 点燃反应时，生成的 FeCl3 覆盖在铁表面，过量的 Fe 接触不到 Cl2 之外已形成 FeCl3 中的 Fe3+，不会进一步反应；颜色记忆张冠李戴。

正确理解：Fe 与 Cl2 反应的产物只有 FeCl3（Cl2 氧化性强，无论 Fe 是否过量）。Fe2+ 溶液浅绿色、Fe3+ 溶液（棕）黄色、Cu2+ 溶液蓝色，这组「离子颜色三兄弟」必须记牢。

避坑口诀：「氯气遇铁只认三价；亚铁浅绿铁黄铜蓝。」

易错点 6

易错表现：描述 Fe(OH)2 氧化过程的现象时写「白色沉淀直接变为红褐色」，漏掉灰绿色中间过程；或检验 Fe2+ 时「先加氯水，后加 KSCN」。

错误成因：对实验现象的记忆不够精确，把「渐变过程」简化为「一步到位」；检验顺序颠倒后，若原溶液中本就有 Fe3+，先加氯水再显色就无法判断 Fe3+ 是原有的还是氧化生成的。

正确理解：标准表述为「白色沉淀迅速变为灰绿色，最终变为红褐色」，三个颜色缺一不可。检验 Fe2+ 的正确顺序：先加 KSCN 溶液无现象（排除原有 Fe3+），再加氯水（或 H2O2）后溶液变血红色，才能证明原溶液含 Fe2+。

避坑口诀：「白灰红，三步走；先 KSCN 后氯水，顺序一错全白给。」

易错点 7

易错表现：认为「钠投入 CuSO4 溶液中，能置换出红色的铜」，把现象描述为「有红色固体析出」。

错误成因：机械套用「活泼金属能把不活泼金属从其盐溶液中置换出来」的规律，忽略了钠的特殊性——它太活泼，一遇水就立即反应，根本轮不到与 Cu2+ 直接接触交换电子。

正确理解：钠投入任何水溶液中，第一步永远是 2Na + 2H2O = 2NaOH + H2↑，生成的 NaOH 再与溶质发生复分解反应。钠投入 CuSO4 溶液的现象是：钠浮在液面上、熔成小球、四处游动、嘶嘶作响，同时生成蓝色絮状沉淀（Cu(OH)2），溶液蓝色变浅——没有红色的铜析出。钠投入 FeCl3 溶液则生成红褐色沉淀，现象分析同理。

避坑口诀：「钠入盐液先打水，碱再和盐来相会；要置换成金属单质，熔融介质才有机会。」

易错点 8

易错表现：认为「常温下铁、铝与浓硫酸、浓硝酸不反应，所以能用铁罐运输，这属于物理变化」；或把钝化理解为「什么也没发生」。

错误成因：只看到宏观上「无明显现象」，就想当然地认为没有发生反应，忽视了金属表面发生的氧化成膜过程。

正确理解：钝化是常温下铁、铝被浓硫酸/浓硝酸氧化，表面生成一层致密的氧化物薄膜（化学变化），这层膜把内部金属与酸隔开，阻止反应继续。加热或把酸稀释后，氧化膜被破坏，金属会继续反应。利用钝化，可用铁制或铝制容器运输、贮存浓硫酸和浓硝酸。

避坑口诀：「钝化不是没反应，表面生成了保护膜；加热稀释膜一破，反应照样不停步。」

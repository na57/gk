3.6 非金属元素及其化合物

高中化学 · 深度学习材料 · 面向 2029 届云南高考

非金属元素是无机化学的另一座大山：氯、硫、氮、硅四条主线，价态变化多、氧化还原密集，是高考选择题、实验题和工业流程题的常客。学习本章的关键抓手是「化合价」——把每种元素的各价态排成一条线，理清谁氧化谁、谁还原谁，再记住特征现象（黄绿色、刺激性气味、白烟、喷泉），知识网络自然成型。

一、知识全景

本章按「氯 → 硫 → 氮 → 硅」四条线展开，每条线内部按「单质 → 氢化物 → 氧化物 → 含氧酸 → 盐」的链条推进。

知识点核心内容高考要求
氯及其化合物Cl2、HClO、次氯酸盐、氯水的成分与性质掌握氯的价态变化（−1、0、+1、+5、+7），理解氯水的多重性质（酸性、漂白性、强氧化性）
硫及其化合物S、SO2、SO3、H2SO3、H2SO4、硫酸盐硫的各价态转化清楚，浓硫酸三大特性（吸水性、脱水性、强氧化性）理解透彻，SO2 的漂白与还原能区分
氮及其化合物N2、NO、NO2、NH3、HNO3、铵盐氮的各价态转化熟练，硝酸强氧化性的浓稀差异掌握清楚，NH3 的制法与喷泉实验理解到位
硅及其化合物Si、SiO2、硅酸、硅酸盐、硅的制备了解硅及其化合物的特性（SiO2 与 HF 反应、硅酸盐的氧化物表示法、粗硅提纯）
非金属通性非金属性强弱比较、氢化物稳定性、最高价含氧酸酸性掌握非金属性强弱的比较方法（与周期律衔接）
学习方法

非金属的复习主线是化合价：把每种元素的价态阶梯写出来，如硫：H2S（−2）→ S（0）→ SO2（+4）→ SO3/H2SO4（+6）；氮：NH3（−3）→ N2（0）→ NO（+2）→ NO2（+4）→ HNO3（+5）。低价态常显还原性、高价态常显氧化性、中间价态「两边倒」。再叠加「连续氧化」关系（N2→NO→NO2，S→SO2→SO3），推断题的骨架就搭好了。

二、核心概念精讲

2.1 氯气（Cl2）：第一种被系统研究的气体元素

核心概念

是什么：黄绿色、有强烈刺激性气味的有毒气体，密度比空气大，能溶于水（1 体积水约溶解 2 体积 Cl2），易液化（液氯）。

为什么活泼：氯原子最外层 7 个电子，极易得到 1 个电子形成 Cl−，所以 Cl2 是强氧化剂，能与绝大多数金属、非金属直接化合。

适用边界：Cl2 与变价金属反应时生成高价态氯化物（FeCl3、CuCl2），这与盐酸（弱氧化剂，只能把 Fe 氧化到 +2 价）形成鲜明对比——常用来比较 Cl2 与 HCl、S 的氧化性强弱。

常见混淆：氯气（单质，黄绿色）、液氯（Cl2 的液态，纯净物）、氯水（Cl2 的水溶液，混合物，浅黄绿色）三者是「同一物质的不同形态 vs 混合物」的关系，性质差异很大。

氯气的主要反应

H2(g) + Cl2(g) → 2HCl(g)　（安静燃烧，苍白色火焰，瓶口有白雾） 2Na(s) + Cl2(g) → 2NaCl(s)　（剧烈燃烧，黄色火焰，产生白烟） 2Fe(s) + 3Cl2(g) → 2FeCl3(s)　（产生棕褐色的烟，溶于水得黄色溶液） Cu(s) + Cl2(g) → CuCl2(s)　（产生棕黄色的烟，溶于水得蓝绿色溶液）
现象辨析

「烟」与「雾」的区别：烟是固体小颗粒（如 NaCl、FeCl3 固体颗粒），雾是小液滴（如 HCl 气体溶于空气中的水蒸气形成的盐酸小液滴）。H2 在 Cl2 中燃烧产生「白雾」，Na 在 Cl2 中燃烧产生「白烟」——高考选择题常在这里设陷阱。

Cl2(g) + 2NaOH(aq) → NaCl(aq) + NaClO(aq) + H2O(l)　（尾气吸收原理） 2Cl2(g) + 2Ca(OH)2(s) → CaCl2 + Ca(ClO)2 + 2H2O　（工业制漂白粉） Cl2(g) + 2KI(aq) → 2KCl + I2　（溶液由无色变为黄褐色，加淀粉变蓝） Cl2(g) + 2NaBr(aq) → 2NaCl + Br2　（溶液由无色变为橙黄色）

氯气的实验室制法

MnO2(s) + 4HCl(浓) → MnCl2(aq) + Cl2(g)↑ + 2H2O(l)

装置要点：固液加热型；用饱和食盐水除去 HCl（Cl2 在饱和食盐水中溶解度小），用浓硫酸干燥；收集用向上排空气法或排饱和食盐水法；尾气用 NaOH 溶液吸收（不能用 Ca(OH)2 溶液——浓度太小，吸收不完全）。检验：使湿润的淀粉-KI 试纸变蓝。

2.2 氯水、次氯酸与次氯酸盐：一瓶氯水七种粒子

核心概念

氯水的成分：Cl2 溶于水时只有一部分与水反应：Cl2 + H2O ⇌ HCl + HClO。新制氯水中含有「三分四离」七种粒子——分子：Cl2（多）、H2O、HClO（少）；离子：H+、Cl−、ClO−、OH−（极少量）。

为什么氯水有「多重性格」：Cl2 和 HClO 都有强氧化性（漂白、杀菌、氧化 I−/Br−/Fe2+）；H+ 使氯水显酸性（使石蕊先变红）；HClO 的强氧化性又把变红的石蕊漂白（后褪色）——所以「紫色石蕊试液滴入新制氯水：先变红后褪色」是氯水成分的经典证明。

适用边界：久置氯水中 HClO 见光分解（2HClO → 2HCl + O2↑），平衡右移，最终变成稀盐酸，漂白能力丧失。因此氯水要现用现配，棕色瓶避光保存。

常见混淆：液氯是纯净物（只有 Cl2 分子），无漂白性；氯水是混合物，有漂白性。干燥的有色布条遇干燥 Cl2 不褪色，湿润布条才褪色——起漂白作用的是 HClO 而不是 Cl2 本身。

次氯酸（HClO）与次氯酸盐

核心概念

HClO 的三性：① 弱酸性（比碳酸还弱，所以 Ca(ClO)2 能与 CO2、H2O 反应）；② 强氧化性（漂白、杀菌消毒的原理）；③ 不稳定性（见光或受热分解：2HClO → 2HCl + O2↑）。

漂白粉：工业上用 Cl2 与石灰乳反应制得，是 CaCl2 与 Ca(ClO)2 的混合物，有效成分是 Ca(ClO)2。漂白原理：Ca(ClO)2 + CO2 + H2O = CaCO3↓ + 2HClO（空气中的 CO2 就能把强氧化性的 HClO「置换」出来——强酸制弱酸）。漂白粉敞口放置会失效（生成的 HClO 分解），须密封保存。

「84」消毒液：有效成分 NaClO，由 Cl2 与冷稀 NaOH 反应制得。不能与洁厕灵（含盐酸）混用：ClO− + Cl− + 2H+ = Cl2↑ + H2O，会产生有毒氯气。

Cl− 的检验

取样于试管中，先加稀硝酸酸化（排除 CO32− 等离子的干扰——Ag2CO3 也是沉淀，但能溶于稀硝酸），再滴加 AgNO3 溶液，若生成不溶于稀硝酸的白色沉淀，则证明原溶液中含 Cl−：Ag+ + Cl− = AgCl↓。注意：试剂顺序不能颠倒（先加 AgNO3 生成的白色沉淀可能是 Ag2CO3），也不能用盐酸酸化（会引入 Cl−，造成假阳性）。

2.3 硫单质（S）与二氧化硫（SO2）

核心概念

硫单质：黄色或淡黄色固体（俗称硫磺），质脆，不溶于水，微溶于酒精，易溶于 CS2（洗涤试管内壁残留的硫可用 CS2 或热 NaOH 溶液）。硫的氧化性较弱，与变价金属反应生成低价态硫化物：Fe + S → FeS、2Cu + S → Cu2S——与 Cl2 对比，说明氧化性 Cl2 > S。

SO2 是什么：无色、有刺激性气味的有毒气体（大气污染物、形成酸雨的元凶之一），密度比空气大，易液化，易溶于水（1:40）。

SO2 的四重性质：① 酸性氧化物的通性（与水、碱、碱性氧化物反应）；② 漂白性（与某些有色物质化合生成不稳定的无色物质，加热又复原——可逆漂白，与 HClO 的永久漂白不同）；③ 还原性（为主，+4 价易被 O2、Cl2、KMnO4、H2O2、Fe3+ 氧化为 +6 价）；④ 弱氧化性（只在与 H2S 反应时体现：SO2 + 2H2S = 3S↓ + 2H2O）。

S(s) + O2(g) → SO2(g)　（空气中淡蓝色火焰、纯氧中明亮的蓝紫色火焰，生成刺激性气味气体） SO2(g) + H2O(l) ⇌ H2SO3(aq)　（可逆反应，H2SO3 是中强酸） SO2 + Cl2 + 2H2O → H2SO4 + 2HCl　（等体积 SO2 与 Cl2 混合通入水中，漂白性消失！） SO2 + 2H2S(g) → 3S(s)↓ + 2H2O　（瓶壁出现淡黄色固体和水珠） 2SO2(g) + O2(g) ⇌ 2SO3(g)　（接触法制硫酸的核心反应，可逆） SO3(g) + H2O(l) → H2SO4(aq)　（放出大量热，工业上用 98.3% 浓硫酸吸收 SO3 防止形成酸雾）
鉴别与检验

① 鉴别 SO2 和 CO2（都能使澄清石灰水变浑浊）：用品红溶液（SO2 使其褪色，CO2 不能）或酸性 KMnO4 溶液（SO2 使其褪色）。② 检验混合气体中的 SO2 和 CO2：先通过品红（检验 SO2）→ 酸性 KMnO4（除尽 SO2）→ 再次品红（确认 SO2 已除尽）→ 澄清石灰水（检验 CO2）。这是高考实验题的经典排序。

SO2 的实验室制法与尾气处理

Na2SO3(s) + H2SO4(较浓) → Na2SO4(aq) + SO2(g)↑ + H2O(l)

装置：固液不加热型；收集用向上排空气法（SO2 密度大于空气）；尾气用 NaOH 溶液吸收：SO2 + 2NaOH = Na2SO3 + H2O。导管末端应接倒置漏斗防倒吸——SO2 易溶于水且与碱快速反应，导管内气压骤降会把液体倒吸入反应装置。

2.4 浓硫酸：三大特性逐个击破

核心概念

是什么：纯硫酸是无色油状液体，沸点高（难挥发），密度 1.84 g/cm³。常用浓硫酸质量分数 98.3%，物质的量浓度约 18.4 mol/L。

稀释操作：必须把浓硫酸沿器壁慢慢注入水中，并用玻璃棒不断搅拌（浓硫酸溶于水放出大量的热，若把水倒入浓硫酸，水密度小浮在上面暴沸飞溅）。口诀：「酸入水，沿器壁，慢慢倒，不断搅。」

特性本质典型实例
吸水性吸收现成的水分子（物理+化学），作干燥剂干燥 H2、O2、CO2、Cl2 等（不能干燥 NH3——酸碱反应；不能干燥 H2S、HBr、HI——氧化还原反应）
脱水性把有机物中 H、O 原子按 2:1（水的组成）脱去，剩余碳（化学变化）蔗糖（C12H22O11）遇浓硫酸变黑膨胀（「黑面包」实验）；纸张、皮肤遇浓硫酸炭化
强氧化性+6 价硫得电子被还原为 SO2加热时氧化 Cu 等不活泼金属；常温使 Fe、Al 钝化；氧化 C 等非金属
Cu(s) + 2H2SO4(浓) → CuSO4(aq) + SO2(g)↑ + 2H2O(l)

现象：加热后铜片逐渐溶解，产生有刺激性气味的气体（能使品红褪色），反应液冷却稀释后呈蓝色。注意：2 mol 浓硫酸中只有 1 mol 作氧化剂（被还原为 SO2），另 1 mol 起酸的作用（生成 CuSO4）——「一半氧化剂，一半酸」。

C(s) + 2H2SO4(浓) → CO2(g)↑ + 2SO2(g)↑ + 2H2O(l)
浓稀对比

稀硫酸是「普通的酸」（H+ 体现氧化性，与活泼金属放 H2）；浓硫酸是「强氧化性酸」（+6 价 S 体现氧化性，还原产物一般是 SO2，不放 H2）。随着反应进行，浓硫酸逐渐变稀，性质也随之切换——如 Cu 与浓硫酸反应，变稀后反应停止（Cu 不与稀硫酸反应），所以「1 mol Cu 与足量浓硫酸反应」与「含 2 mol H2SO4 的浓硫酸与足量 Cu 反应」生成的 SO2 并不相同，后者硫酸有剩余，生成的 SO2 小于 1 mol。这是计算题的经典陷阱。

2.5 氮气（N2）与氮的氧化物

核心概念

N2 为什么稳定：N2 分子中存在氮氮三键（N≡N），键能很大（946 kJ/mol），断裂需要很高能量，所以常温下 N2 化学性质很稳定，可作保护气。但在放电/高温下能与 O2、H2、Mg 反应。

固氮：把游离态的氮（N2）转化为化合态氮的过程。自然固氮：雷雨发庄稼（N2 → NO → NO2 → HNO3 → 硝酸盐）；人工固氮：合成氨（N2 + 3H2 ⇌ 2NH3，高温高压催化剂）。

N2(g) + O2(g) → 2NO(g)　（无色气体） 2NO(g) + O2(g) → 2NO2(g)　（无色气体立即变为红棕色——检验 NO 的特征现象） 3NO2(g) + H2O(l) → 2HNO3(aq) + NO(g)　（红棕色褪去，工业制硝酸）
对比项NONO2
颜色气味无色无味气体红棕色、有刺激性气味气体
溶解性难溶于水与水反应（3:1 比例生成 HNO3 和 NO）
毒性有毒（与 CO 类似，结合血红蛋白）有毒（刺激呼吸道，酸雨成因之一）
收集方法只能用排水法（遇空气即被氧化）只能用向上排空气法（与水反应）
相互转化2NO + O2 = 2NO2；3NO2 + H2O = 2HNO3 + NO
计算模型

NO2、NO 与 O2 混合溶于水的计算是经典题型，核心是把分步方程式叠加：4NO2 + O2 + 2H2O = 4HNO3（V(NO2):V(O2) = 4:1 恰好无剩余）；4NO + 3O2 + 2H2O = 4HNO3（4:3 恰好无剩余）。先按比例判断谁过量，再求剩余气体体积。

2.6 氨气（NH3）：唯一的碱性气体

核心概念

是什么：无色、有刺激性气味的气体，密度比空气小，极易溶于水（常温常压下 1 体积水约溶解 700 体积 NH3）——这是喷泉实验的物理基础。

为什么水溶液显碱性：NH3 溶于水后大部分与水结合成一水合氨（NH3·H2O），一水合氨是弱碱，部分电离出 NH4+ 和 OH−：NH3 + H2O ⇌ NH3·H2O ⇌ NH4+ + OH−。注意：使溶液显碱性的是 NH3·H2O 的电离，氨气本身不是碱；液氨是纯净物，氨水是混合物。

还原性：NH3 中 N 为 −3 价（最低价），只有还原性。催化氧化是工业制硝酸的第一步：4NH3 + 5O2 → 4NO + 6H2O。

NH3(g) + HCl(g) → NH4Cl(s)　（两根玻璃棒分别蘸浓氨水、浓盐酸靠近，产生大量白烟——互相检验） 2NH4Cl(s) + Ca(OH)2(s) → CaCl2(s) + 2NH3(g)↑ + 2H2O(l)　（实验室制氨气） 4NH3(g) + 5O2(g) → 4NO(g) + 6H2O(l)
实验室制氨气的细节

① 装置：固体加热型（试管口略向下倾斜，防止冷凝水倒流炸裂试管）；② 干燥：用碱石灰（NaOH 与 CaO 的混合物），不能用浓硫酸（酸性，吸收 NH3）、不能用无水 CaCl2（与 NH3 反应生成 CaCl2·8NH3）；③ 收集：向下排空气法，试管口塞一团棉花（防止对流，使收集更纯）；④ 验满：湿润的红色石蕊试纸靠近试管口变蓝，或蘸浓盐酸的玻璃棒靠近产生白烟；⑤ 快速制法：加热浓氨水，或向浓氨水中加入生石灰（CaO 吸水放热，促使 NH3 逸出）。

喷泉实验

烧瓶中充满干燥的 NH3（或 HCl），倒置在水槽中，挤入少量水后，水沿导管喷涌而上形成「喷泉」，最终液体几乎充满整个烧瓶。原理：NH3 极易溶于水（1:700），少量水溶解大量 NH3 后烧瓶内气压骤降，外界大气压把水压入烧瓶。若水中滴有酚酞，NH3 喷泉呈红色（氨水显碱性）；HCl 喷泉滴石蕊呈红色。能做喷泉实验的气体共同特征：在该液体中溶解度极大（或能与液体快速反应），如 HCl/水、NH3/水、CO2/浓 NaOH 溶液。

2.7 硝酸（HNO3）：浓度决定产物

核心概念

是什么：纯硝酸是无色、易挥发、有刺激性气味的液体。浓硝酸（69%）常因溶有分解产生的 NO2 而呈黄色，须用棕色瓶、阴凉处保存。

不稳定性：4HNO3 → 4NO2↑ + O2↑ + 2H2O。

强氧化性的浓稀差异（本章最核心）：硝酸无论浓稀都是强氧化性酸，与金属反应不产生 H2。浓硝酸的还原产物一般是 NO2，稀硝酸的还原产物一般是 NO；硝酸越稀，产物中氮的价态越低（极稀时可到 N2O 甚至 NH4NO3）。

钝化：常温下，Fe、Al 遇浓硝酸（及浓硫酸）表面生成致密氧化膜而钝化（化学变化），加热则继续反应。

2.8 铵盐：遇碱放氨，受热易分解

核心概念

是什么：由 NH4+ 与酸根离子构成的盐，都易溶于水，都是晶体。

两大化学性质：① 受热易分解：NH4Cl → NH3↑ + HCl↑（试管底部固体「消失」，在试管口重新生成白色固体——先升华假象，实为分解又化合）；NH4HCO3 → NH3↑ + H2O + CO2↑。② 与碱反应放出氨气：NH4+ + OH− → NH3↑ + H2O——这是 NH4+ 的检验方法：取样，加浓 NaOH 溶液并加热，产生使湿润红色石蕊试纸变蓝的刺激性气味气体。

适用边界：铵态氮肥（如 NH4Cl、(NH4)2SO4）不能与草木灰（K2CO3，碱性）混用，否则相互促进水解放出 NH3，降低肥效。

2.9 硅（Si）与二氧化硅（SiO2）：信息时代的基石

核心概念

硅单质：灰黑色、有金属光泽的固体（晶体硅），硬而脆，是良好的半导体材料（介于导体与绝缘体之间），用于芯片、太阳能电池。常温下化学性质不活泼，只与 F2、HF、强碱反应；加热时能与 O2、Cl2 反应。

SiO2 是什么：SiO2 是原子晶体（由 Si、O 原子直接构成，不存在单个「SiO2 分子」，SiO2 只是最简式），熔点高、硬度大，不溶于水。石英、水晶、玛瑙、光导纤维、沙子的主要成分都是 SiO2。

SiO2 的双重身份：它是酸性氧化物（与强碱、碱性氧化物反应生成硅酸盐），但不溶于水、不与水反应（对应的水化物 H2SiO3 只能用间接方法制备）；它又能与氢氟酸反应——这是它区别于 CO2 的特性，也是氢氟酸不能用玻璃瓶盛放、可用来刻蚀玻璃的原因。

常见混淆：SiO2 与 CO2 化学式相似，但物理性质天差地别（SiO2 原子晶体高熔点、CO2 分子晶体低熔点）；不能用「SiO2 + 水 → 硅酸」，也不能说「SiO2 是两性氧化物」（只与 HF 这一种酸反应，且 SiF4 不是盐，不算两性）。

Si(s) + O2(g) → SiO2(s) Si(s) + 2NaOH(aq) + H2O(l) → Na2SiO3(aq) + 2H2(g)↑　（硅与强碱反应，类似铝） SiO2(s) + 2C(s) → Si(s) + 2CO(g)↑　（工业制粗硅，注意产物是 CO 不是 CO2） SiO2(s) + 2NaOH(aq) → Na2SiO3(aq) + H2O(l)　（装碱液的试剂瓶用橡胶塞的原因） SiO2(s) + 4HF(aq) → SiF4(g)↑ + 2H2O(l)　（刻蚀玻璃） SiO2(s) + Na2CO3(s) → Na2SiO3(s) + CO2(g)↑　（制玻璃原理之一） SiO2(s) + CaCO3(s) → CaSiO3(s) + CO2(g)↑　（制玻璃原理之二）
易混提醒

「SiO2 + Na2CO3 → Na2SiO3 + CO2↑」不能说明硅酸的酸性比碳酸强！该反应在高温下进行，驱动力是 CO2 气体逸出（高沸点物质制低沸点物质），与溶液中的「强酸制弱酸」不是同一原理。事实上酸性：H2CO3 > H2SiO3（向 Na2SiO3 溶液中通 CO2 能生成硅酸沉淀可以证明）。

高纯硅的制备（粗硅提纯）

SiO2(s) + 2C(s) → Si(粗) + 2CO(g)↑ Si(粗) + 2Cl2(g) → SiCl4(l) SiCl4(l) + 2H2(g) → Si(纯) + 4HCl(g)

提纯思路：先把固体杂质「气化转移」——粗硅与 Cl2 反应生成易挥发的 SiCl4（沸点仅 57.6 ℃），蒸馏提纯后再用 H2 还原得到高纯硅。「转化为易分离的中间体」是工业提纯物质的经典思路。

硅酸与硅酸盐

Na2SiO3(aq) + 2HCl(aq) → 2NaCl(aq) + H2SiO3(s)↓　（白色胶状沉淀，强酸制弱酸） H2SiO3(s) → SiO2(s) + H2O(l)

硅酸是白色胶状、难溶于水的弱酸（比碳酸还弱），不能直接由 SiO2 与水反应制得。Na2SiO3 的水溶液俗称水玻璃，是矿物胶（黏合剂）、防火剂。硅酸盐组成复杂，常用氧化物形式表示，如硅酸钠 Na2SiO3 写成 Na2O·SiO2，高岭石 Al2(Si2O5)(OH)4 写成 Al2O3·2SiO2·2H2O（书写顺序：活泼金属氧化物 → 较活泼金属氧化物 → SiO2 → H2O）。三大硅酸盐产品：水泥、玻璃、陶瓷。

材料辨析

传统硅酸盐材料：水泥、玻璃（Na2SiO3·CaSiO3·SiO2 的混合物）、陶瓷。新型无机非金属材料：SiO2 光导纤维（传导光信号，不是导电！）、SiC（金刚砂）、Si3N4 陶瓷。高频考点：光导纤维的主要成分是 SiO2 而不是 Si；计算机芯片的主要成分是晶体 Si 而不是 SiO2。

2.10 非金属性强弱的比较方法

核心概念

为什么比较：非金属性即原子得电子的能力，它决定了一系列宏观性质。掌握比较方法，就能把零散事实串成规律，也为第三章元素周期律埋下伏笔。以氯、硫的比较为例：

五大判据：

  • 单质与 H2 化合的难易：Cl2 与 H2 光照即剧烈反应（甚至爆炸），S 与 H2 需持续加热且反应不完全 → 非金属性 Cl > S。越容易化合，非金属性越强。
  • 气态氢化物的稳定性：HCl 很稳定，H2S 受热易分解 → 非金属性 Cl > S。氢化物越稳定，非金属性越强。
  • 最高价氧化物对应水化物的酸性：酸性 HClO4 > H2SO4 → 非金属性 Cl > S。注意必须用最高价含氧酸比较，不能用 HClO（氯为 +1 价）与 H2SO4 比较。
  • 单质间的置换反应：Cl2 + H2S = 2HCl + S↓（氯气把硫置换出来）→ 氧化性 Cl2 > S，非金属性 Cl > S。
  • 与变价金属反应的产物价态：Cl2 把 Fe 氧化到 +3 价（FeCl3），S 只能把 Fe 氧化到 +2 价（FeS）→ 氧化性 Cl2 > S。

常见混淆：比较非金属性不能用「氢化物水溶液的酸性」（如酸性 HCl < HI，但非金属性 Cl > I）——氢化物酸性强弱与非金属性没有必然联系，正确的判据是氢化物的热稳定性。

三、三重表征贯通

非金属元素的现象丰富、粒子转化微妙，是最能体现「宏观 — 微观 — 符号」三重表征威力的一章。以下六组经典，请做到「看到现象能写方程式、看到方程式能想微观」。

3.1 氯气与水的反应（氯水的诞生）

宏观现象

黄绿色 Cl2 通入水中，得到浅黄绿色的氯水，有刺激性气味；向氯水中滴入紫色石蕊试液，先变红，后褪色；光照氯水，缓慢产生无色气泡（O2），黄绿色逐渐褪去，最终变为无色溶液。

微观粒子

部分 Cl2 分子与水发生歧化反应：一个 Cl 原子得电子成为 Cl−，另一个失电子与 OH− 结合成 HClO（Cl 从 0 价分别变为 −1 价和 +1 价）。溶液中同时存在 Cl2、HClO、H+、Cl− 等粒子：H+ 使石蕊变红，HClO 的强氧化性又把红色有机色素破坏（漂白）。光照下 HClO 分解，平衡不断右移直至 Cl2 耗尽。

符号表达

Cl2 + H2O ⇌ HCl + HClO

离子方程式：Cl2 + H2O ⇌ H+ + Cl− + HClO

2HClO → 2HCl + O2↑（久置氯水变成稀盐酸）

3.2 二氧化硫使品红褪色与使高锰酸钾褪色：一字之差，原理迥异

宏观现象

SO2 通入品红溶液，红色褪去；加热褪色后的溶液，红色恢复。SO2 通入酸性 KMnO4 溶液（紫色）或溴水（橙黄色），颜色褪去且不恢复；滴入 BaCl2 溶液，再加入盐酸无变化，若再滴入氯水则产生白色沉淀（BaSO4）。

微观粒子

漂白机理：SO2 分子与品红等有色有机物结合生成不稳定的无色加合物，受热又分解复原——非氧化还原的可逆漂白。使 KMnO4/溴水褪色则是氧化还原：+4 价的 S 失电子升为 +6 价（SO42−），MnO4− 被还原为无色的 Mn2+、Br2 被还原为 Br−——SO2 体现还原性，褪色不可逆。

符号表达

漂白：SO2 + 有色物质 ⇌ 无色物质（可逆）

还原性：5SO2 + 2MnO4− + 2H2O = 5SO42− + 2Mn2+ + 4H+

SO2 + Br2 + 2H2O = H2SO4 + 2HBr

3.3 氨的喷泉实验：大气压推动的红色喷泉

宏观现象

圆底烧瓶充满干燥 NH3，倒置在滴有酚酞的水槽中；挤入少量水后打开止水夹，水立即沿导管喷涌而上形成红色喷泉，最终液体几乎充满整个烧瓶。若换用 HCl 气体与紫色石蕊试液，同样喷起红色喷泉。

微观粒子

NH3 分子与 H2O 分子间形成氢键，溶解度极大（1:700）：挤入的少量水瞬间溶解大量 NH3，烧瓶内气体骤减、气压远低于外界大气压，大气压把水压入烧瓶形成喷泉。进入瓶中的 NH3 继续溶解并部分转化为 NH3·H2O，电离出 OH− 使酚酞变红。

符号表达

NH3 + H2O ⇌ NH3·H2O ⇌ NH4+ + OH−

喷泉条件：气体在该液体中溶解度极大（或快速反应）

适用组合：NH3/水、HCl/水、CO2/NaOH 浓溶液

3.4 铜与浓硝酸、稀硝酸的反应：一对「兄弟实验」

宏观现象

浓硝酸 + 铜：剧烈反应，铜片迅速溶解，产生大量红棕色气体（NO2），溶液变为蓝绿色。稀硝酸 + 铜：反应缓慢，铜片逐渐溶解，产生无色气体（NO），在试管口与空气接触后变为红棕色（2NO + O2 = 2NO2），溶液变为蓝色。

微观粒子

两者都是 +5 价的 N 作氧化剂、Cu 失电子变为 Cu2+。浓硝酸中 HNO3 浓度大，每个 N 只降 1 价（+5→+4，得 1 个电子）即满足，故生成 NO2；稀硝酸中 HNO3 浓度小，N 降 3 价（+5→+2，得 3 个电子），生成 NO。酸根离子 NO3− 在酸性条件下才显强氧化性——稀硝酸盐溶液（如 KNO3）遇铜不反应，加稀硫酸后就能反应。

符号表达

Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2↑ + 2H2O

3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O

离子方程式（稀）：3Cu + 8H+ + 2NO3− = 3Cu2+ + 2NO↑ + 4H2O

3.5 浓硫酸与铜的反应：酸性和氧化性的「双人舞」

宏观现象

铜片与浓硫酸常温下不反应；加热后铜片逐渐溶解，产生有刺激性气味的气体（能使品红溶液褪色），试管底部可能出现灰白色固体（无水 CuSO4，因浓硫酸吸水）；将反应液冷却后倒入水中，溶液呈蓝色。

微观粒子

浓硫酸中起氧化作用的是 +6 价的 S（不是 H+），它被还原为 +4 价的 SO2；Cu 原子失去 2 个电子变为 Cu2+，与未被还原的 SO42− 结合成 CuSO4。每 2 分子浓硫酸中，1 分子作氧化剂（S 降价）、1 分子只提供酸根（体现酸性）。由于水少，生成的 CuSO4 以白色固体析出，稀释后才显蓝色（Cu2+ 水合离子）。

符号表达

Cu + 2H2SO4(浓) → CuSO4 + SO2↑ + 2H2O

电子转移：Cu ~ 2e− ~ SO2

浓硫酸角色：一半氧化剂 + 一半酸

3.6 铵盐与碱共热：检验 NH4+ 的「气味信号」

宏观现象

取少量 NH4Cl 固体于试管中，加入浓 NaOH 溶液并加热，试管口放一片湿润的红色石蕊试纸。加热后产生有刺激性气味的气体，湿润的红色石蕊试纸变蓝；若用蘸有浓盐酸的玻璃棒靠近试管口，会看到白烟。

微观粒子

NH4+ 把 H+「交给」OH−，先生成 NH3·H2O（NH4+ + OH− ⇌ NH3·H2O）；加热促使 NH3·H2O 分解并降低 NH3 的溶解度，NH3 分子大量逸出。逸出的 NH3 在试纸表面溶于水，电离出 OH− 使红色石蕊试纸变蓝；遇到浓盐酸挥发出的 HCl 分子，则化合成 NH4Cl 固体小颗粒（白烟）。

符号表达

NH4+ + OH− → NH3↑ + H2O

NH3 + H2O ⇌ NH3·H2O ⇌ NH4+ + OH−（试纸变蓝的原理）

NH3 + HCl = NH4Cl（白烟）

四、典型例题分步拆解

例题 1 · 氯水成分与性质分析

题目：新制氯水中含有多种粒子。某研究性学习小组进行如下实验：（1）向新制氯水中滴加紫色石蕊试液，观察到的现象是____，原因是____。（2）向新制氯水中加入 Na2CO3 粉末，有气泡产生，写出反应的离子方程式。（3）将氯水光照一段时间后，溶液的 pH 如何变化？漂白能力如何变化？说明原因。

【思路点拨】氯水是「三分四离」的混合体系，回答现象题时先想「哪种粒子在起作用」：酸看 H+、沉淀看 Cl−、漂白看 HClO、氧化看 Cl2 和 HClO。

1

（1）现象：石蕊试液先变红，后褪色。原因：氯水中含有 H+（来自 HCl 的完全电离和 HClO 的少量电离），使石蕊变红；同时氯水中的 HClO 具有强氧化性，把变红的石蕊氧化漂白，所以红色又褪去。

2

（2）气泡是 CO2，由氯水中的 H+ 与 CO32− 反应生成：2H+ + CO32− = H2O + CO2↑。注意 HClO 酸性比 H2CO3 弱，不与 Na2CO3 反应放 CO2（高中阶段按此处理）。

3

（3）光照时 HClO 分解：2HClO → 2HCl + O2↑，生成的盐酸是强酸，且 Cl2 + H2O ⇌ HCl + HClO 平衡不断右移，H+ 浓度增大，pH 变小；HClO 不断消耗，漂白能力减弱直至消失，最终氯水变成稀盐酸。

【答案】（1）先变红后褪色；H+ 使其变红，HClO 的强氧化性使其褪色。（2）2H+ + CO32− = H2O + CO2↑。（3）pH 变小，漂白能力消失；HClO 见光分解生成盐酸，平衡右移，H+ 增多而 HClO 耗尽。

【方法总结】分析氯水问题的「粒子定位法」：看到酸/气泡找 H+，看到白色沉淀（AgCl）找 Cl−，看到漂白找 HClO，看到氧化 I−/Fe2+ 找 Cl2。久置氯水 = 稀盐酸，这个结论要形成条件反射。

例题 2 · SO2 与 CO2 混合气体的检验

题目：某无色气体可能由 CO2 和 SO2 中的一种或两种组成。实验室提供以下试剂：品红溶液、酸性 KMnO4 溶液、澄清石灰水。请设计实验确认气体成分，说明试剂使用顺序和判断依据。

【思路点拨】SO2 和 CO2 都能使澄清石灰水变浑浊（CaSO3、CaCO3 都是白色沉淀），所以石灰水不能区分二者；必须先用 SO2 的漂白性检验它，除尽之后再验 CO2。

1

顺序设计：气体依次通过 ①品红溶液 → ②酸性 KMnO4 溶液 → ③品红溶液 → ④澄清石灰水。

2

装置①的作用：检验 SO2。若品红褪色，证明含 SO2；若不褪色，则气体中无 SO2。

3

装置②的作用：除去 SO2（5SO2 + 2MnO4− + 2H2O = 5SO42− + 2Mn2+ + 4H+），防止干扰 CO2 的检验。

4

装置③的作用：确认 SO2 已被除尽。若品红不褪色，说明 SO2 已完全除去——这一步最易遗漏，却正是得分关键。

5

装置④的作用：检验 CO2。若澄清石灰水变浑浊，证明含 CO2。

【答案】按「品红（检）→ KMnO4（除）→ 品红（验尽）→ 石灰水（检 CO2）」顺序：①褪色则含 SO2，④变浑浊则含 CO2；综合判断成分。

【方法总结】多种气体连续检验的通用原则：先检验的不能干扰后检验的，每除掉一种气体必须验证「已除尽」。类似模型还有「H2O、CO2、CO 的检验顺序」（先验水，再验 CO2，最后把 CO 氧化成 CO2 再验）。

例题 3 · 铜与硝酸反应的计算

题目：将 3.2 g 铜与 50 mL 一定浓度的硝酸恰好完全反应（铜无剩余，硝酸的还原产物只有 NO2 和 NO），收集到标准状况下的混合气体 1.12 L。求：（1）混合气体中 NO2 和 NO 的物质的量；（2）反应后溶液中 Cu(NO3)2 的物质的量浓度（设溶液体积仍为 50 mL）。

【思路点拨】铜的物质的量固定，它失去的电子总数 = 硝酸得电子总数（电子守恒），这是连接两种气体的桥梁；Cu2+ 全部来自铜，直接由铜守恒。

1

n(Cu) = 3.2 g ÷ 64 g/mol = 0.05 mol，失电子：0.05 mol × 2 = 0.10 mol。混合气体总物质的量 = 1.12 L ÷ 22.4 L/mol = 0.05 mol。

2

设 NO2 为 x mol，NO 为 y mol。HNO3 → NO2 得 1 e−，HNO3 → NO 得 3 e−。

3

列方程组：x + y = 0.05（气体总量）；x + 3y = 0.10（电子守恒）。两式相减：2y = 0.05，y = 0.025 mol，x = 0.025 mol。

4

铜守恒：n[Cu(NO3)2] = n(Cu) = 0.05 mol，c[Cu(NO3)2] = 0.05 mol ÷ 0.050 L = 1.0 mol/L。

【答案】（1）n(NO2) = n(NO) = 0.025 mol；（2）c[Cu(NO3)2] = 1.0 mol/L。

【方法总结】硝酸计算题「两守恒」通吃：电子守恒（金属失电子 = N 得电子）+原子守恒（Cu → Cu(NO3)2；N 原子 = 气体中的 N + 盐中 NO3− 的 N）。不需要分别写两个方程式，设两个未知数列方程组即可。

例题 4 · 喷泉实验与氨水浓度计算

题目：用圆底烧瓶收集满干燥的 NH3，在标准状况下做喷泉实验。实验结束后，水恰好充满整个烧瓶。求所得氨水的物质的量浓度。（结果保留三位有效数字）

【思路点拨】抓住「烧瓶体积」这个桥梁：烧瓶有多大，原 NH3 就有多少体积；最终溶液也充满整个烧瓶，溶液体积 = 烧瓶体积。用 V 表示烧瓶体积，两个体积会约掉。

1

设烧瓶体积为 V L。标准状况下，n(NH3) = V L ÷ 22.4 L/mol = V/22.4 mol。

2

NH3 极易溶于水，实验后水充满烧瓶，所得氨水体积 = V L（忽略溶解导致的体积变化，高中阶段默认溶液体积等于进入的水的体积，即烧瓶容积）。

3

c(NH3) = (V/22.4) mol ÷ V L = 1/22.4 mol/L ≈ 0.0446 mol/L。

【答案】所得氨水的物质的量浓度为 0.0446 mol/L（即 1/22.4 mol/L）。

【方法总结】喷泉实验浓度计算的关键是「设而不求」：烧瓶体积 V 最终约掉，结果只与气体摩尔体积有关（标准状况下恒为 1/22.4 mol/L），与烧瓶大小、气体种类（只要全溶、无剩余）无关。若气体是 HCl，结果相同；若收集的 NH3 不纯（混有空气），则水不能充满，浓度仍为 1/22.4 mol/L（因为溶解的 NH3 与进入的水仍按比例对应）——这个结论常作为选择题的「反直觉」选项出现。

例题 5 · NO2、O2 混合气体溶于水

题目：将 12 mL NO2 和 O2 的混合气体通入倒扣在水槽中的量筒内，充分反应后，量筒内剩余 2 mL 无色气体。求原混合气体中 NO2 和 O2 各多少毫升？

【思路点拨】总反应 4NO2 + O2 + 2H2O = 4HNO3，恰好完全反应时 V(NO2):V(O2) = 4:1。剩余 2 mL 无色气体有两种可能：O2 过量（剩 O2）或 NO2 过量（过量的 NO2 与水反应生成 NO，剩 NO）——分类讨论是这类题的灵魂。

1

情况一：剩余 2 mL 是 O2。则参加 4:1 反应的气体共 12 − 2 = 10 mL，其中 NO2 占 4/5，即 8 mL；O2 共 2 + 2 = 4 mL？——核算：参加反应的 O2 = 10 mL × 1/5 = 2 mL，加上剩余 2 mL，O2 共 4 mL，NO2 8 mL。

2

验证：8 : 2 = 4 : 1 恰好反应，剩 O2 2 mL，总量 12 mL。✔

3

情况二：剩余 2 mL 是 NO（NO2 过量时，过量部分按 3NO2 + H2O = 2HNO3 + NO 转化，每 3 体积 NO2 剩 1 体积 NO）。则过量的 NO2 为 2 × 3 = 6 mL；参加 4:1 反应的混合气为 12 − 6 = 6 mL，其中 NO2 = 6 × 4/5 = 4.8 mL，O2 = 6 × 1/5 = 1.2 mL。

4

情况二汇总：NO2 共 4.8 + 6 = 10.8 mL，O2 1.2 mL。验证：10.8 − 6 = 4.8 与 1.2 之比为 4:1，过量 6 mL NO2 生成 2 mL NO，总量 12 mL。✔

【答案】两组解：① NO2 8 mL、O2 4 mL（剩余 O2 2 mL）；② NO2 10.8 mL、O2 1.2 mL（NO2 过量，转化为剩余 NO 2 mL）。

【方法总结】氮氧化物溶于水的计算三步走：① 写出叠加方程式（4NO2+O2、4NO+3O2）确定恰好反应比例；② 判断剩余气体可能是什么（必分类讨论！）；③ NO2 过量时记住「3 份 NO2 → 1 份 NO」的换算。漏掉第二种情况是此类题的最大丢分点。

例题 6 · 工业流程：氨催化氧化法制硝酸

题目：工业上用氨催化氧化法制硝酸，流程为：NH3 →（催化氧化）→ NO →（氧化）→ NO2 →（吸收）→ HNO3。（1）写出三步转化的化学方程式。（2）吸收塔中为什么要通入过量的空气？（3）从氧化还原角度分析，整个过程中 NH3 中的氮元素化合价发生了怎样的变化？

【思路点拨】这是「连续氧化」的典型工业应用：氮元素从 −3 价一路升高到 +5 价。吸收步骤中 NO2 与水反应会放出 NO，通入空气让 NO 再氧化为 NO2 循环吸收，从而提高原料的利用率。

1

（1）第一步：4NH3 + 5O2 → 4NO + 6H2O；第二步：2NO + O2 = 2NO2；第三步：3NO2 + H2O = 2HNO3 + NO。

2

（2）第三步产生的 NO 若不处理会浪费氮元素并污染环境；通入过量空气（提供 O2）使 NO 不断被氧化为 NO2 再被吸收，总效果相当于 4NO2 + O2 + 2H2O = 4HNO3，使氮元素尽可能完全转化为硝酸，提高产率并减少污染。

3

（3）NH3 中 N 为 −3 价，最终 HNO3 中 N 为 +5 价，每个 N 原子共失去 8 个电子，全程被氧化；O2 是整个流程中唯一的氧化剂。该流程体现了「低价态非金属氢化物经连续氧化制取最高价含氧酸」的工业思想（类比：S → SO2 → SO3 → H2SO4）。

【答案】见上述各步骤。

【方法总结】工业制酸的两大模板：① 氨法硝酸「NH3 → NO → NO2 → HNO3」（催化剂为铂铑合金网）；② 接触法硫酸「S/FeS2 → SO2 → SO3 → 98.3% 浓硫酸吸收 → H2SO4」。记住「催化剂、热交换、逆流吸收、循环利用」四个工艺关键词，流程题就有底气。

例题 7 · 实验室制取并验证氯气性质的综合实验

题目：实验室用 MnO2 与浓盐酸在加热条件下反应制取 Cl2，并依次验证 Cl2 的漂白性（干燥/湿润有色布条对比）和氧化性（NaBr 溶液、KI-淀粉溶液），最后进行尾气处理。请回答：（1）制得的 Cl2 中混有哪些杂质气体？如何依次除去？（2）干燥布条与湿润布条的现象分别是什么？可得出什么结论？（3）尾气用什么试剂吸收？写出离子方程式。

【思路点拨】气体实验题的通用框架是「发生 → 除杂 → 干燥 → 性质验证/收集 → 尾气处理」。净化顺序的原则是「先除杂、后干燥」——若先干燥再通过水溶液除杂，气体又会带出水蒸气，前功尽弃。

1

（1）浓盐酸有挥发性，且反应生成水，故 Cl2 中混有 HCl 气体和水蒸气。先通过饱和食盐水除去 HCl（食盐水中高浓度的 Cl− 抑制 Cl2 与水的反应，降低 Cl2 的溶解度，而 HCl 极易溶于水被吸收），再通过浓硫酸除去水蒸气。

2

（2）干燥的有色布条不褪色，湿润的有色布条褪色。对比结论：干燥的 Cl2 没有漂白性，真正起漂白作用的是 Cl2 与水反应生成的 HClO。

3

（3）性质验证：Cl2 通入 NaBr 溶液，溶液由无色变为橙黄色——Cl2 + 2Br− = 2Cl− + Br2；通入 KI-淀粉溶液，溶液变蓝——Cl2 + 2I− = 2Cl− + I2。说明氧化性 Cl2 > Br2 > I2。

4

（4）尾气用 NaOH 溶液吸收：Cl2 + 2OH− = Cl− + ClO− + H2O。不能用澄清石灰水——Ca(OH)2 溶解度小、溶液浓度太低，吸收不完全。

【答案】（1）HCl、水蒸气；依次通过饱和食盐水、浓硫酸。（2）干燥布条不褪色、湿润布条褪色，说明起漂白作用的是 HClO 而不是 Cl2。（3）NaOH 溶液；Cl2 + 2OH− = Cl− + ClO− + H2O。

【方法总结】气体制备类综合题用「五段式」框架拆解：发生装置（由反应物状态和反应条件决定）→ 除杂（试剂只吸收杂质、不与目标气体反应）→ 干燥（酸性/碱性/中性干燥剂的选择）→ 性质实验或收集 → 尾气处理（易溶于水的气体注意防倒吸）。把每一段的「为什么」想清楚，比死记装置图更有用。

五、易错点与成因

易错点 1

易错表现：认为「干燥的 Cl2 能使干燥的有色布条褪色」，或「起漂白作用的是 Cl2 分子」。

错误成因：把「氯气能漂白」这个生活化说法当成微观本质，没有理解漂白作用的真正来源是 Cl2 与水反应生成的 HClO。

正确理解：起漂白作用的是 HClO（强氧化性破坏有色物质），不是 Cl2。干燥的 Cl2 遇干燥布条不褪色，遇湿润布条褪色；液氯无漂白性。验证实验：Cl2 依次通过干燥布条（不褪色）和湿润布条（褪色）。

避坑口诀：「漂白功臣是次氯酸，干燥氯气干瞪眼。」

易错点 2

易错表现：认为「SO2 使溴水、酸性 KMnO4 褪色体现漂白性」，或认为「SO2 和 Cl2 等体积混合后漂白能力增强」。

错误成因：把所有「褪色」都归为漂白，混淆了漂白（与有色物质化合，非氧化还原）与氧化还原褪色两种机理；不知道 SO2 与 Cl2 在水中恰好互相消耗。

正确理解：SO2 使品红褪色 = 漂白性（可逆，加热复原）；使溴水/KMnO4 褪色 = 还原性（氧化还原，不可逆）。SO2 + Cl2 + 2H2O = H2SO4 + 2HCl，等体积混合后两者恰好完全反应，漂白能力丧失。

避坑口诀：「品红褪色是漂白，溴水高锰是还原；二强相遇双双亡。」

易错点 3

易错表现：认为「浓硫酸使蔗糖变黑体现吸水性」，或「浓硫酸能干燥 NH3、H2S」；把「钝化」当成不发生反应。

错误成因：混淆吸水性（吸收现成的水）与脱水性（把 H、O 按 2:1 从有机物中夺走）的概念边界；不知道浓硫酸作为干燥剂的禁忌（碱性气体、还原性气体）；把钝化理解为「物理隔离」而非化学变化。

正确理解：蔗糖（C12H22O11）分子中本没有 H2O，浓硫酸按水的组成脱去 H、O 使碳游离出来变黑，这是脱水性（生成的碳又部分被氧化为 CO2，体现强氧化性，「黑面包」实验是脱水性+强氧化性的组合）。浓硫酸不能干燥 NH3（中和反应）、H2S/HBr/HI（氧化还原）。钝化是 Fe、Al 表面生成了致密氧化膜的化学变化，加热或稀释后膜被破坏会继续反应。

避坑口诀：「吸水干燥看现成，脱水炭化看组成；氨气硫化氢，浓酸干燥都不行；钝化不是不反应，是生成了保护膜。」

易错点 4

易错表现：写「Cu + 4HNO3(浓)」的产物时生成 NO 或 H2；认为「稀硝酸氧化性比浓硝酸强」（因为氮降的价态更多）。

错误成因：没有建立「浓度决定产物」的规律（浓 → NO2，稀 → NO），或错误地用「得电子总数」衡量氧化性强弱。氧化性强弱看得电子的难易程度（反应条件、剧烈程度），不看得电子多少。

正确理解：硝酸与金属反应不产生 H2；浓硝酸还原产物为 NO2（N：+5→+4），稀硝酸为 NO（+5→+2）。浓硝酸常温就能剧烈氧化 Cu，稀硝酸则缓慢——浓硝酸氧化性更强（得电子更容易）。类似的：浓盐酸与 MnO2 反应、稀盐酸不反应，也说明浓度越大氧化/还原性越强。

避坑口诀：「浓二氧化氮稀一氧化氮，氧化强弱看反应难不难。」

易错点 5

易错表现：认为「NH3 是碱」「氨水的溶质是 NH3·H2O」；收集 NH3 用向上排空气法，或用浓硫酸干燥 NH3。

错误成因：混淆了「气体本身」与「其水溶液的酸碱性」——NH3 自身不能电离出 OH−，显碱性靠的是与水反应生成的 NH3·H2O；对氨水这个复杂体系（NH3、NH3·H2O、NH4+ 等共存）认识不清，溶质的界定规则（溶解的气体仍以原物质为溶质）没掌握；实验细节记忆不牢。

正确理解：NH3 是碱性气体但不是碱（碱是电离出的阴离子全部是 OH− 的化合物）；氨水的溶质按 NH3 计算（计算物质的量浓度时以通入的 NH3 为准）。NH3 密度小于空气，用向下排空气法收集；干燥用碱石灰，绝不能用浓硫酸（2NH3 + H2SO4 = (NH4)2SO4）。

避坑口诀：「氨气非碱氨水碱，溶质还按氨气算；向下排气碱石灰干。」

易错点 6

易错表现：认为「SiO2 能与水反应生成硅酸」，或由「SiO2 + Na2CO3 → Na2SiO3 + CO2↑」得出「硅酸酸性强于碳酸」；认为光导纤维的成分是 Si。

错误成因：把 CO2 的性质（溶于水生成碳酸）机械迁移到 SiO2 上，忽视 SiO2 是原子晶体、不溶于水的事实；不理解高温反应（气体逸出驱动）与溶液反应（强酸制弱酸）的原理不同；材料成分记忆混淆（Si 作芯片、SiO2 作光纤）。

正确理解：SiO2 不与水反应，H2SiO3 只能用「Na2SiO3 + 强酸」间接制得；酸性 H2CO3 > H2SiO3（证据：Na2SiO3 + CO2 + H2O = H2SiO3↓ + Na2CO3）；光导纤维、石英、水晶的成分是 SiO2，半导体芯片、太阳能电池的成分是晶体 Si。

避坑口诀：「二氧化硅不恋水，硅酸要靠盐来制；高温反应不比酸，芯片是硅光纤是硅氧二。」

易错点 7

易错表现：认为「1 mol Cl2 与水充分反应转移 1 mol 电子」，或把 Cl2 与水的反应当作能进行到底的反应。

错误成因：忽略了 Cl2 与水的反应是可逆反应（⇌），反应物不能完全转化；把方程式的计量关系当成了实际转化量。

正确理解：Cl2 + H2O ⇌ HCl + HClO 是可逆反应，新制氯水中仍有大量未反应的 Cl2 分子。1 mol Cl2 通入水中，实际发生反应的 Cl2 远小于 1 mol，转移电子数远小于 NA。类似的「可逆陷阱」还有：2SO2 + O2 ⇌ 2SO3、N2 + 3H2 ⇌ 2NH3 等——凡涉及可逆反应，「完全转化」「转移电子按投料全算」的说法一律错误。

避坑口诀：「可逆反应用双向箭，投料再多也转不完。」

易错点 8

易错表现：收集 NO 用排空气法、收集 NO2 用排水法；或把 NH3 与 HCl 相遇的现象描述为「白雾」。

错误成因：没有抓住两种气体与空气/水的「禁忌反应」：NO 一遇 O2 就变质（2NO + O2 = 2NO2），所以不能用排空气法；NO2 一遇水就反应（3NO2 + H2O = 2HNO3 + NO），所以不能用排水法。同时混淆了「烟」（固体小颗粒）与「雾」（小液滴）。

正确理解：NO 只能用排水法收集，NO2 只能用向上排空气法收集。NH3 与 HCl 相遇生成的 NH4Cl 是固体小颗粒，现象应描述为「产生白烟」；而 HCl 气体本身在空气中形成盐酸小液滴，才是「白雾」。

避坑口诀：「一氧化氮怕氧气，排水收集最安心；二氧化氮怕见水，向上排气是正宗；烟是固体雾是液。」

六、与前后章节的联系及高考怎么考

  • 承上：本章是氧化还原反应与离子反应（第二章）的最大应用场——Cl2、浓硫酸、HNO3 三大强氧化剂，SO2、NH3、NO 等还原剂，每个反应都要能判断氧化剂/还原剂、配平、写离子方程式；「连续氧化」（S→SO2→SO3、N2→NO→NO2）是推断题的直接素材。
  • 启下：元素周期律（第三章）将用「非金属性强弱」统一解释本章事实：氧化性 Cl2>S、氢化物稳定性 HCl>H2S、最高价含氧酸酸性 HClO4>H2SO4>H2CO3>H2SiO3；化学平衡（选必 1）会重新研究合成氨与 SO2 催化氧化这两个可逆反应；氮、硫的氧化物是「化学与环境」议题的主角（酸雨、光化学烟雾、臭氧空洞）。
  • 高考怎么考：① 选择题：氯水成分分析、SO2 性质辨析、浓硫酸特性判断、硅酸盐材料成分，几乎年年出现；② 实验题：Cl2/NH3 的制备与净化、喷泉实验设计、SO2 与 CO2 的连续检验、浓硫酸与蔗糖/Cu 的探究；③ 工业流程题：接触法制硫酸、氨催化氧化制硝酸、粗硅提纯；④ 计算题：硝酸与金属反应（电子守恒+原子守恒）、NOx 溶于水、喷泉实验浓度。全章在试卷中直接或间接占约 20 分，氮、硫两族是大题的高频载体。
规律汇总

中学化学四大连续氧化关系（推断题的高频骨架，与金属部分对照记忆）：

  • C → CO → CO2（燃料的不完全燃烧与完全燃烧）
  • N2/NH3 → NO → NO2（雷雨发庄稼、工业制硝酸）
  • S/H2S → SO2 → SO3（接触法制硫酸）
  • Na → Na2O → Na2O2（钠在空气中缓慢氧化与加热燃烧）

凡推断题中出现「A 能被 O2 连续氧化」，优先从这四条线中排查。

七、章末自检清单

  • 我能说出氯水的「三分四离」七种粒子，并解释新制氯水使石蕊「先变红后褪色」的原因。
  • 我能写出实验室制 Cl2 的方程式，说明净化（饱和食盐水、浓硫酸）、收集、尾气处理（NaOH）的装置与原理。
  • 我能写出工业制漂白粉的方程式，说明其有效成分是 Ca(ClO)2，并写出漂白原理与失效原因。
  • 我能区分 SO2 的漂白性（品红，可逆）与还原性（溴水、KMnO4 褪色，不可逆），并写出与 H2S 反应的方程式。
  • 我能设计实验连续检验 SO2 和 CO2：品红→酸性 KMnO4→品红→澄清石灰水，并说明每一步的作用。
  • 我能说出浓硫酸三大特性（吸水性、脱水性、强氧化性）的本质区别，写出 Cu、C 与浓硫酸反应的方程式，并解释「一半氧化剂一半酸」。
  • 我能描述 NO 遇空气变红棕色、NO2 溶于水的现象，写出 N2→NO→NO2→HNO3 的连续反应，并用 4:1、4:3 模型做混合气体计算（含分类讨论）。
  • 我能写出实验室制 NH3 的方程式，说明干燥（碱石灰）、收集（向下排空气）、验满（湿润红色石蕊试纸变蓝/白烟）的细节，解释喷泉实验原理并算出 1/22.4 mol/L 的浓度。
  • 我能写出 Cu 与浓、稀硝酸反应的方程式和离子方程式，描述现象差异（红棕 vs 无色→试管口红棕），并用电子守恒做混合气体计算。
  • 我能说出 NH4+ 的检验方法（加浓碱加热，湿润红色石蕊试纸变蓝），写出 NH4Cl、NH4HCO3 受热分解的方程式。
  • 我能写出 SiO2 与 NaOH、HF、Na2CO3（高温）反应的方程式，说明玻璃刻蚀、碱液瓶用橡胶塞、制玻璃的原理。
  • 我能辨析 Si 与 SiO2 的用途（芯片用 Si、光纤用 SiO2），说明硅酸的间接制法和酸性弱于碳酸的证据。

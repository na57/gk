一、知识体系总览

运动学是高中物理的开篇章节，也是整个力学乃至电磁学的基础。这部分内容的核心是描述物体的运动——用哪些物理量描述？这些物理量之间有什么关系？如何用数学工具（公式、图象）来表达和分析运动？

二、核心概念深度理解

2.1 质点与参考系

质点

  • 定义：用来代替物体的有质量的点，是一种理想化模型
  • 能否看成质点的判断标准：物体的大小和形状对所研究问题的影响可以忽略不计
  • 易错点：
    • ❌ "体积小的物体一定能看成质点" —— 不对，要看研究什么问题
    • ❌ "质量大的物体不能看成质点" —— 不对，地球公转时地球也可看成质点
    • ✅ 同一物体，有时能看成质点，有时不能（如研究地球自转不能，公转可以）

参考系

  • 定义：描述物体运动时，选来作为标准的（假定不动的）另外的物体
  • 性质：
    • 任意性：参考系的选取是任意的（但不能选研究对象自身）
    • 标准性：选作参考系的物体都假定不动
    • 差异性：选不同的参考系，观察结果可能不同
  • 原则：通常以地面或相对地面静止的物体为参考系

2.2 位移与路程

物理量位移路程
定义从初位置到末位置的有向线段物体运动轨迹的长度
性质矢量（有大小、有方向）标量（只有大小，没有方向）
大小与路径无关，只与初末位置有关与路径有关
联系单向直线运动中，位移大小 = 路程路程 ≥ 位移大小

深度思考：为什么要引入位移这个概念？因为在很多物理问题中（比如动能定理、势能变化），我们关心的是初末位置的变化，而不是具体走了什么路径。位移这个矢量概念，是我们用数学精确描述运动的第一步。

2.3 速度与速率

平均速度与瞬时速度

物理量平均速度瞬时速度
定义位移与时间的比值当 $\Delta t \to 0$ 时，$\dfrac{\Delta x}{\Delta t}$ 的极限值
公式$\bar{v} = \dfrac{\Delta x}{\Delta t}$$v = \lim_{\Delta t \to 0} \dfrac{\Delta x}{\Delta t}$
物理意义粗略描述一段时间内运动的快慢和方向精确描述某一时刻（位置）运动的快慢和方向
矢量性矢量，方向与位移方向相同矢量，方向沿运动轨迹的切线方向
对应关系与一段时间（位移）对应与一个时刻（位置）对应

平均速率与瞬时速率

  • 平均速率 $=$ 路程 $/$ 时间（标量）
  • 瞬时速率 $=$ 瞬时速度的大小（标量）
  • ⚠️ 平均速率 ≠ 平均速度的大小（除非是单向直线运动）

重要辨析：

  • 匀速直线运动中，平均速度等于瞬时速度
  • 平均速度的大小 ≤ 平均速率
  • 速度是矢量，速率是标量，永远不能说"速度等于速率"

2.4 加速度

  • 定义：速度的变化量与发生这一变化所用时间的比值
  • 公式：$$a = \frac{\Delta v}{\Delta t} = \frac{v_t - v_0}{t}$$
  • 物理意义：描述速度变化快慢的物理量（不是描述速度大小，也不是描述速度变化量大小）
  • 矢量性：加速度是矢量，方向与 $\Delta v$ 的方向相同
  • 单位：$\mathrm{m/s^2}$（米每二次方秒）

深度辨析

概念含义关系
速度大运动得快速度大，加速度不一定大（如匀速飞行的飞机）
速度变化量大速度改变得多$\Delta v$ 大，加速度不一定大（还要看时间）
加速度大速度变化得快加速度大，速度不一定大（如刚启动的火箭）

经典易错判断：

  • ❌ "物体速度为零，加速度一定为零" —— 错！（竖直上抛最高点，$v=0$，但 $a=g$）
  • ❌ "加速度为零，速度一定为零" —— 错！（匀速直线运动，$a=0$，但 $v \neq 0$）
  • ❌ "加速度增大，速度一定增大" —— 错！（如果 $a$ 与 $v$ 反向，$a$ 越大，$v$ 减小得越快）
  • ✅ 判断速度是增大还是减小：看加速度与速度的方向关系，同向加速，反向减速

三、匀变速直线运动公式体系

3.1 三个基本公式（必须会推导！）

公式一：速度公式 $v = v_0 + at$

推导过程：

由加速度的定义式出发：

$$a = \frac{v - v_0}{t}$$

整理得：

$$\boldsymbol{v = v_0 + at}$$

说明：

  • 描述速度与时间的关系
  • 矢量式：$v_0$、$a$、$v$ 都是矢量，要注意正负号
  • 适用条件：匀变速直线运动（$a$ 恒定）

公式二：位移公式 $x = v_0 t + \dfrac{1}{2} a t^2$

推导过程：

匀变速直线运动中，速度是均匀变化的，所以平均速度等于初末速度的平均值：

$$\bar{v} = \frac{v_0 + v}{2}$$

位移 = 平均速度 × 时间：

$$x = \bar{v} \cdot t = \frac{v_0 + v}{2} \cdot t$$

将 $v = v_0 + at$ 代入：

$$x = \frac{v_0 + v_0 + at}{2} \cdot t = \frac{2v_0 + at}{2} \cdot t$$ $$\boldsymbol{x = v_0 t + \frac{1}{2} a t^2}$$

说明：

  • 描述位移与时间的关系
  • 是矢量式，注意符号
  • 位移与时间是二次函数关系

公式三：速度位移公式 $v^2 - v_0^2 = 2ax$

推导过程：

从速度公式解出时间：$t = \dfrac{v - v_0}{a}$，代入位移公式：

$$x = v_0 t + \frac{1}{2} a t^2 = v_0 \cdot \frac{v - v_0}{a} + \frac{1}{2} a \cdot \left( \frac{v - v_0}{a} \right)^2$$ $$= \frac{v_0 v - v_0^2}{a} + \frac{1}{2} a \cdot \frac{(v - v_0)^2}{a^2}$$ $$= \frac{v_0 v - v_0^2}{a} + \frac{(v - v_0)^2}{2a}$$

通分：

$$= \frac{2(v_0 v - v_0^2) + (v^2 - 2v_0 v + v_0^2)}{2a}$$ $$= \frac{2v_0 v - 2v_0^2 + v^2 - 2v_0 v + v_0^2}{2a}$$ $$= \frac{v^2 - v_0^2}{2a}$$

所以：

$$\boldsymbol{v^2 - v_0^2 = 2ax}$$

说明：

  • 描述速度与位移的关系
  • 不含时间 $t$，当题目不涉及时间时，用这个公式最方便
  • 也是矢量式

三个基本公式的选用原则：

  • 已知量和待求量中有 $v$、$v_0$、$a$、$t$ → 用速度公式
  • 已知量和待求量中有 $x$、$v_0$、$a$、$t$ → 用位移公式
  • 已知量和待求量中有 $v$、$v_0$、$a$、$x$ → 用速度位移公式
  • 原则：哪个公式含的已知量最多、未知量最少，就先用哪个

3.2 三个重要推论（必须会推导！）

推论一：平均速度等于中间时刻的瞬时速度

结论：

$$\boldsymbol{\bar{v} = v_{\frac{t}{2}} = \frac{v_0 + v}{2}}$$

推导过程：

设总时间为 $t$，初速度 $v_0$，末速度 $v$，加速度 $a$。

中间时刻的瞬时速度：

$$v_{\frac{t}{2}} = v_0 + a \cdot \frac{t}{2}$$

平均速度：

$$\bar{v} = \frac{x}{t} = \frac{v_0 t + \frac{1}{2} a t^2}{t} = v_0 + \frac{1}{2} a t = v_0 + a \cdot \frac{t}{2}$$

所以：$\bar{v} = v_{\frac{t}{2}}$

又因为 $v = v_0 + at$，所以：

$$v_0 + \frac{at}{2} = \frac{2v_0 + at}{2} = \frac{v_0 + v_0 + at}{2} = \frac{v_0 + v}{2}$$

综上：

$$\bar{v} = v_{\frac{t}{2}} = \frac{v_0 + v}{2}$$

应用场景：打点计时器求某点的瞬时速度，就用这个推论！

推论二：中间位置的瞬时速度

结论：

$$\boldsymbol{v_{\frac{x}{2}} = \sqrt{\frac{v_0^2 + v^2}{2}}}$$

推导过程：

设总位移为 $x$，初速度 $v_0$，末速度 $v$。

前半段位移 $\dfrac{x}{2}$：

$$v_{\frac{x}{2}}^2 - v_0^2 = 2a \cdot \frac{x}{2} = ax \tag{1}$$

后半段位移 $\dfrac{x}{2}$：

$$v^2 - v_{\frac{x}{2}}^2 = 2a \cdot \frac{x}{2} = ax \tag{2}$$

由(1)(2)得：

$$v_{\frac{x}{2}}^2 - v_0^2 = v^2 - v_{\frac{x}{2}}^2$$

移项：

$$2v_{\frac{x}{2}}^2 = v_0^2 + v^2$$

所以：

$$v_{\frac{x}{2}} = \sqrt{\frac{v_0^2 + v^2}{2}}$$

比较 $v_{\frac{t}{2}}$ 和 $v_{\frac{x}{2}}$：

  • 匀加速运动：$v_{\frac{x}{2}} > v_{\frac{t}{2}}$
  • 匀减速运动：$v_{\frac{x}{2}} > v_{\frac{t}{2}}$
  • （不管加速还是减速，中间位置速度都大于中间时刻速度，等号仅在匀速时成立）

推论三：连续相等时间内的位移差是恒量

结论：

$$\boldsymbol{\Delta x = a T^2}$$

（逐差公式）

推导过程：

设加速度为 $a$，连续相等的时间间隔为 $T$。

第1个 $T$ 内的位移：

$$x_1 = v_0 T + \frac{1}{2} a T^2$$

第2个 $T$ 内的位移：

$$x_2 = (v_0 + aT)T + \frac{1}{2} a T^2 = v_0 T + a T^2 + \frac{1}{2} a T^2 = v_0 T + \frac{3}{2} a T^2$$

第3个 $T$ 内的位移：

$$x_3 = (v_0 + 2aT)T + \frac{1}{2} a T^2 = v_0 T + 2a T^2 + \frac{1}{2} a T^2 = v_0 T + \frac{5}{2} a T^2$$

……

第 $n$ 个 $T$ 内的位移：

$$x_n = v_0 T + \frac{2n-1}{2} a T^2$$

位移差：

$$\Delta x_1 = x_2 - x_1 = \left( v_0 T + \frac{3}{2} a T^2 \right) - \left( v_0 T + \frac{1}{2} a T^2 \right) = a T^2$$ $$\Delta x_2 = x_3 - x_2 = \left( v_0 T + \frac{5}{2} a T^2 \right) - \left( v_0 T + \frac{3}{2} a T^2 \right) = a T^2$$

所以：

$$\Delta x = a T^2$$

推广：

$$\boldsymbol{x_m - x_n = (m - n) a T^2}$$

应用场景：

  • 打点计时器求加速度（逐差法）
  • 判断物体是否做匀变速直线运动

3.3 初速度为零的匀加速直线运动的比例关系

前提条件：$v_0 = 0$，匀加速直线运动，从 $t=0$ 开始计时。

比例一：1T末、2T末、3T末……的速度之比

$$v_1 : v_2 : v_3 : \dots : v_n = 1 : 2 : 3 : \dots : n$$

推导：$v = at$，$v$ 与 $t$ 成正比。

比例二：1T内、2T内、3T内……的位移之比

$$x_1 : x_2 : x_3 : \dots : x_n = 1^2 : 2^2 : 3^2 : \dots : n^2 = 1 : 4 : 9 : \dots : n^2$$

推导：$x = \frac{1}{2} a t^2$，$x$ 与 $t^2$ 成正比。

比例三：第1个T内、第2个T内、第3个T内……的位移之比

$$x_Ⅰ : x_Ⅱ : x_Ⅲ : \dots : x_N = 1 : 3 : 5 : \dots : (2N-1)$$

推导：

$$x_Ⅰ = x_1 = \frac{1}{2} a T^2$$ $$x_Ⅱ = x_2 - x_1 = \frac{1}{2} a (2T)^2 - \frac{1}{2} a T^2 = 2a T^2 - \frac{1}{2} a T^2 = \frac{3}{2} a T^2$$ $$x_Ⅲ = x_3 - x_2 = \frac{1}{2} a (3T)^2 - \frac{1}{2} a (2T)^2 = \frac{9}{2} a T^2 - 2a T^2 = \frac{5}{2} a T^2$$

所以比值为 $1 : 3 : 5 : \dots$

比例四：通过前x、前2x、前3x……的时间之比

$$t_1 : t_2 : t_3 : \dots : t_n = 1 : \sqrt{2} : \sqrt{3} : \dots : \sqrt{n}$$

推导：由 $x = \frac{1}{2} a t^2$，得 $t = \sqrt{\dfrac{2x}{a}}$，$t$ 与 $\sqrt{x}$ 成正比。

比例五：通过连续相等位移所用时间之比

$$t_Ⅰ : t_Ⅱ : t_Ⅲ : \dots : t_N = 1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \dots : (\sqrt{N} - \sqrt{N-1})$$

推导：

$$t_Ⅰ = t_1 = \sqrt{\frac{2x}{a}}$$ $$t_Ⅱ = t_2 - t_1 = \sqrt{\frac{4x}{a}} - \sqrt{\frac{2x}{a}} = \sqrt{\frac{2x}{a}} (\sqrt{2} - 1)$$ $$t_Ⅲ = t_3 - t_2 = \sqrt{\frac{6x}{a}} - \sqrt{\frac{4x}{a}} = \sqrt{\frac{2x}{a}} (\sqrt{3} - \sqrt{2})$$

所以比值为 $1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \dots$

使用提醒：

  • 这些比例关系只适用于初速度为零的匀加速直线运动
  • 对于末速度为零的匀减速运动，可以用逆向思维法（反过来看成初速度为零的匀加速），然后再用比例
  • 比例法是快速解题的利器，但一定要注意适用条件！

四、运动图象专题

图象是描述物理规律的重要数学工具，也是高考的高频考点。学好图象，要做到三会：会读图、会画图、会用图。

4.1 x-t 图象（位移-时间图象）

图象特征物理意义
纵坐标某时刻的位置（位移）
横坐标时间
斜率速度（$k = \dfrac{\Delta x}{\Delta t} = v$）
斜率为正速度方向与正方向相同
斜率为负速度方向与正方向相反
斜率绝对值越大速度越大
水平直线静止（速度为零）
倾斜直线匀速直线运动
抛物线（曲线）匀变速直线运动（速度在变）
两图象交点两物体相遇（同一时刻在同一位置）
纵轴截距$t=0$ 时的初始位置

4.2 v-t 图象（速度-时间图象）

图象特征物理意义
纵坐标某时刻的瞬时速度
横坐标时间

  • 面积在 $t$ 轴下方 → 位移为负
  • 总面积（代数和）→ 总位移
  • 总面积（绝对值和）→ 总路程

图象题解题要诀：

  1. 先看坐标轴：是x-t还是v-t？别一上来就看形状！
  2. 再看斜率：斜率表示什么物理量？

  4. 最后看截距和交点：分别代表什么？

五、追及相遇问题专题

追及相遇问题是运动学的重点和难点，也是高考的高频考点。核心是：两个物体在同一时刻到达同一位置。

5.1 基本思路

  1. 设定研究对象：明确是哪两个物体在运动
  2. 建立物理情景：画运动过程示意图
  3. 寻找关系：
    • 时间关系：两物体运动时间是否相等？谁先出发？
    • 位移关系：追上时，两物体的位移满足什么关系？
    • 速度关系：恰好追上（或恰好追不上）的临界条件是什么？
  4. 列方程求解：根据运动学公式列方程
  5. 验证结果：结果是否合理？是否符合实际？

5.2 典型模型

模型一：匀速追匀加速（前车匀速，后车匀加速）

情景：甲车在前，以速度 $v_1$ 匀速运动；乙车在后，初速度 $v_0$（$v_0 < v_1$），加速度 $a$ 匀加速，初始相距 $x_0$。

分析：

  • 乙车速度越来越大，当 $v_乙 = v_1$ 时，两者距离最小
  • 如果此时还没追上，就再也追不上了
  • 临界条件：$v_乙 = v_1$ 时，两车位置相同 → 恰好追上

解题步骤：

  1. 速度相等时：$v_0 + at = v_1$ → 得时间 $t$
  2. 计算此时两车位移：$x_甲 = v_1 t$，$x_乙 = v_0 t + \frac{1}{2} a t^2$
  3. 比较：$x_乙 - x_甲$ 与 $x_0$ 的大小关系

模型二：匀减速追匀速（前车匀速，后车匀减速）

情景：甲车在前匀速 $v_1$，乙车在后初速度 $v_0$（$v_0 > v_1$），加速度 $a$ 匀减速，初始相距 $x_0$。

分析：

  • 乙车速度越来越小，当 $v_乙 = v_1$ 时，两者距离最小
  • 如果此时还没撞上，之后距离越来越大，就不会撞了
  • 临界条件：$v_乙 = v_1$ 时，两车位置相同 → 恰好不相撞

记忆技巧：速度相等是临界条件——此时两物体间距最小（或最大），是能否追上/相撞的判断时刻。

六、重要解题思想与方法

6.1 逆向思维法

对于末速度为零的匀减速直线运动，可以把它倒过来看成初速度为零的匀加速直线运动，加速度大小相同。

典型应用：

  • 刹车问题（最后停止）
  • 竖直上抛运动（最高点速度为零）
  • 子弹打木块（最后停下）

例题：汽车以 $20\,\mathrm{m/s}$ 行驶，刹车后加速度大小为 $5\,\mathrm{m/s^2}$，求刹车后 $5\,\mathrm{s}$ 内的位移。

常规做法：先算刹车时间 $t = \dfrac{v_0}{a} = 4\,\mathrm{s}$，说明 $5\,\mathrm{s}$ 时车已停，再用 $v^2 = 2ax$ 求位移。

逆向思维：把刹车过程倒过来看——从静止开始以 $5\,\mathrm{m/s^2}$ 匀加速 $4\,\mathrm{s}$，位移 $x = \frac{1}{2} a t^2 = \frac{1}{2} \times 5 \times 16 = 40\,\mathrm{m}$。

刹车问题特别提醒：一定要先算刹车时间！题目给的时间可能比刹车时间长，车早就停下来了。这是高频易错点！

6.2 对称法

对于竖直上抛运动，上升过程和下落过程具有对称性：

  • 经过同一位置：上升速度与下落速度大小相等、方向相反
  • 经过同一段距离：上升时间与下落时间相等

6.3 分段法（多过程问题）

复杂的运动往往是由几个简单的运动过程组成的。处理方法：

  1. 分段：根据加速度的变化，把整个运动分成几段
  2. 逐段分析：每一段用什么运动规律？已知量是什么？未知量是什么？
  3. 找联系：前一段的末速度 = 后一段的初速度
  4. 列方程求解

典型多过程：先匀加速、再匀速、再匀减速（如电梯运动、汽车起步刹车）

6.4 整体法

对于全过程加速度不变的运动（如竖直上抛运动），可以对全过程应用运动学公式，不需要分段。

七、必须掌握的公式推导清单

以下公式和推论，必须做到合上书能独立推导出来，并且理解每一步的物理意义：

序号公式/推论推导思路重要程度
1 $v = v_0 + at$ 从加速度定义式出发 ⭐⭐⭐⭐⭐
2 $x = v_0 t + \frac{1}{2} a t^2$ 平均速度法：$\bar{v} = \dfrac{v_0 + v}{2}$ ⭐⭐⭐⭐⭐

八、学习方法与易错提醒

8.1 学好运动学的关键

  1. 画示意图：每道题都要画运动过程图，标出已知量和未知量
  2. 规定正方向：矢量运算前先规定正方向，所有物理量带符号
  3. 选对公式：先看已知量和待求量，再选公式，不要盲目套公式
  4. 检查结果：算完后看结果是否合理（比如刹车问题不能算出来负位移）
  5. 一题多解：做完一道题后，想想还有没有别的方法，比较哪种更简单

8.2 十大易错点

序号易错点正确做法
1位移和路程混淆题目问位移要答大小和方向，问路程答大小
2平均速度的大小 = 平均速率只有单向直线运动才相等，一般不相等
3加速度的正负判断速度增减看 $a$ 和 $v$ 的方向关系，不是看 $a$ 的正负
4刹车问题直接代入时间计算先算刹车时间，判断车是否已停下
5公式适用条件没注意匀变速公式只适用于 $a$ 恒定的运动
6矢量不带符号先规定正方向，所有矢量带符号运算
7x-t图和v-t图搞混先看坐标轴！斜率的意义完全不同
8v-t图象交点当相遇v-t图交点是速度相等，不是相遇
9追及问题不判断临界条件先看速度相等时能不能追上
10结果不检验算完代入原题验证是否合理

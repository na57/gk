交变电流

高中物理 · 电磁学模块 · 高考常考选择题 ｜ 依据：《高考物理95+分备考指南》3.11 节要求 ｜ 适用：高一同步学习 & 高考一轮复习 ｜ 学生：小兵

一、本章总览

小兵，欢迎来到电磁学的「应用篇」。前面电磁感应告诉我们「磁能生电」，而这一章要回答两个非常实际的问题：我们家插座里的电是什么样的电？水电站发的电又是怎么翻山越岭送到家里的？这两个问题的答案，就是本章的三大块内容——交变电流的产生与描述、变压器、远距离输电。

从高考定位看，云南高考物理满分 100 分、考试时间 75 分钟，电磁学模块约占 40 分。本章通常以一道选择题（4~6 分）的形式出现：要么考正弦交流电的图象与「四值」，要么考理想变压器的动态分析或远距离输电的损失计算；偶尔也会作为电磁感应综合题的一个环节。题目不难，但陷阱密度全章闻名——有效值与平均值混用、电流比乱用、输电电压与电压损失混淆，都是命题人爱挖的坑。本章学扎实，是稳拿分、少丢分的关键。

本章与前后知识的联系

  • 上游——电磁感应：正弦交流电的产生本质是法拉第电磁感应定律 $e=n\dfrac{\Delta \varPhi}{\Delta t}$ 在旋转线圈上的具体应用；中性面、峰值面的判断全靠「磁通量」与「磁通量变化率」这对老朋友的区分。
  • 本章内部：描述交流电的物理量（四值、周期频率相位）是「语言」，变压器和远距离输电是用这套语言讲的两个「故事」。
  • 下游——电磁振荡与电磁波、传感器：交流电的周期性变化是理解 LC 振荡、电磁波的直接基础。

三个学习抓手

  1. 抓住「两个面」：中性面与峰值面，把磁通量 $\varPhi$、感应电动势 $e$、电流方向变化三件事串成一条线；
  2. 抓住「四个值」：瞬时值、最大值、有效值、平均值，每个值都要能回答「定义是什么、符号是什么、什么时候用它」；
  3. 抓住「一条链」：远距离输电的功率链与电压链，画一张示意图，所有公式都在图上找到位置。

深度思考：为什么全世界电网都用交流电而不是直流电？学完本章你会发现，答案就藏在「变压器只能用于交流」这一句话里——交流电能方便地升降电压，从而实现高压输电、低压用电，把输电损耗压到最低。一个技术选择，背后是一条完整的物理逻辑链。

二、核心概念与物理量

2.1 交变电流

定义：大小和方向都随时间做周期性变化的电流，叫做交变电流，简称交流（AC）。

两个关键词缺一不可：

  • 方向变化是交流电与直流电（DC）的本质区别。大小变化但方向不变的电流（如脉动直流）不是交流电；
  • 周期性意味着电流的变化规律不断重复。按正弦规律变化的交变电流叫正弦式交变电流，是本章唯一深入研究的交流电，日常电网供电就是 50 Hz 的正弦交流电。

2.2 中性面与峰值面（位置约定）

矩形线圈在匀强磁场中绕垂直于磁场方向的轴匀速转动，是产生正弦交流电的标准模型。线圈转动时有两个特殊位置，全章的「地理坐标系」就建立在这两个面上：

位置 线圈平面与磁场的关系 磁通量 $\varPhi$ 磁通量变化率 $\dfrac{\Delta\varPhi}{\Delta t}$ 感应电动势 $e$ 电流方向
中性面 与磁场方向垂直 最大，$\varPhi_m = BS$ 为零 为零 在此处发生改变
峰值面（与中性面垂直） 与磁场方向平行 为零 最大 最大，$E_m = NBS\omega$ 方向不变，大小最大
中性面位置约定（务必牢记）：
  • 线圈平面与磁感线垂直的位置叫中性面——记「面垂磁」，即"面"垂直于"磁"；
  • 中性面上：$\varPhi$ 最大、$e=0$、电流方向反转；线圈每转一周经过中性面 2 次，电流方向改变 2 次；
  • 电动势 $e$ 正比于磁通量的变化率，而不是磁通量本身——"$\varPhi$ 最大时 $e$ 为零"恰好是法拉第定律最漂亮的体现，也是本章第一大易错点。

2.3 描述交流电的「四值」

交流电时刻在变，一个数字描述不了它，于是物理中引入了四个「值」，各有各的岗位：

物理量 符号 定义 单位 用途
瞬时值 $e$、$u$、$i$ 某一时刻交流电的数值，$e=E_m\sin(\omega t+\varphi_0)$ V、V、A 分析某时刻的受力、发光情况、二极管导通等
最大值（峰值） $E_m$、$U_m$、$I_m$ 一个周期内瞬时值的最大数值 V、V、A 电容器、二极管的耐压判断
有效值 $E$、$U$、$I$ 热效应等效定义：交流与某直流分别通过相同电阻，若一个周期内产生的热量相等，则该直流值叫交流的有效值 V、V、A 计算电功、电热、电功率；电表读数、用电器铭牌参数均为有效值
平均值 $\bar{E}$、$\bar{I}$ 由法拉第定律定义：$\bar{E}=N\dfrac{\Delta\varPhi}{\Delta t}$ V、A 计算一段时间内通过导体横截面的电荷量 $q=\bar{I}\Delta t$
有效值定义的三层理解：① 「等效」的对象是发热，不是别的；② 比较的前提是三同——同一电阻、同一时间（一个周期）、同样热量；③ 对正弦交流电，定义算出来的结果是 $I=\dfrac{I_m}{\sqrt{2}}$（推导见 3.3），但这个结论只属于正弦波，其他波形的有效值必须回到定义去算（见 3.4 与例 2）。

2.4 周期、频率与角频率

物理量 符号 定义 单位（符号） 相互关系
周期 $T$ 完成一次周期性变化所需的时间 秒（s） $f=\dfrac{1}{T}$，$\omega=\dfrac{2\pi}{T}=2\pi f$
我国电网：$T=0.02\ \mathrm{s}$，$f=50\ \mathrm{Hz}$，$\omega=100\pi\ \mathrm{rad/s}$
频率 $f$ 1 s 内完成周期性变化的次数 赫兹（Hz），$1\ \mathrm{Hz}=1\ \mathrm{s^{-1}}$
角频率（角速度） $\omega$ 线圈转动的角速度，数值上等于 $2\pi$ 乘频率 弧度每秒（rad/s）

注意一个常考的事实：线圈转一周（$2\pi$），电流完成一次周期性变化，但方向改变 2 次（两次经过中性面）。我国市电每秒电流方向改变 100 次。

2.5 相位与初相位（相位约定）

正弦交流电的瞬时值写成

$$e = E_m\sin(\omega t + \varphi_0)$$
  • 括号里的整体 $\omega t + \varphi_0$ 叫做相位，单位是弧度（rad）。相位是交流电的「时钟读数」：相位确定，线圈位置与电动势大小方向就完全确定；
  • $t=0$ 时的相位 $\varphi_0$ 叫做初相位（初相），它完全由计时起点决定；
  • 两个同频率交流电的相位差 $\Delta\varphi = \varphi_1 - \varphi_2$ 不随时间变化（频率不同则相位差没有意义）。
相位约定（解题的「起跑线」）：
  • 从中性面开始计时：$\varphi_0 = 0$，$e = E_m\sin\omega t$；
  • 从峰值面（线圈平面与磁场平行）开始计时：$\varphi_0 = \dfrac{\pi}{2}$，$e = E_m\sin\left(\omega t + \dfrac{\pi}{2}\right) = E_m\cos\omega t$；
  • 题目没说计时起点时，默认从中性面开始计时，用正弦函数。

2.6 变压器的基本概念

  • 构造：闭合铁芯 + 绕在铁芯上的两组线圈。接电源的叫原线圈（初级线圈，匝数 $n_1$），接负载的叫副线圈（次级线圈，匝数 $n_2$）。铁芯由涂有绝缘漆的硅钢片叠合而成，目的是减小涡流损耗。
  • 工作原理：互感现象。原线圈中变化的电流 → 铁芯中变化的磁通量 → 副线圈中产生感应电动势。所以变压器只对交流电起作用，恒定直流输入时副线圈没有输出。
  • 理想变压器的三个理想化假设（题目不说明时按理想变压器处理）：① 无漏磁——穿过原、副线圈每一匝的磁通量 $\varPhi$ 完全相同；② 无铜损——线圈电阻为零，不产生焦耳热；③ 无铁损——铁芯中没有涡流与磁滞损耗。三条合起来，输入功率 = 输出功率。
  • 升压与降压：$n_2 > n_1$ 为升压变压器；$n_2 < n_1$ 为降压变压器。

2.7 远距离输电的基本概念

  • 输送功率 $P$：发电站向外输送的总功率，通常视为题目给定的不变量；
  • 输电电压 $U$：指输电线始端（升压变压器副线圈两端）的电压，是线路输送的电压，单位 V（实际电网用 kV）；
  • 输电线电阻 $r$：往返两根导线的总电阻，单位 $\Omega$；
  • 电压损失 $\Delta U$：电流流过线路电阻分走的电压，$\Delta U = Ir$；用户端得到的电压是 $U - \Delta U$；
  • 功率损失 $\Delta P$：线路发热损耗，$\Delta P = I^2 r$；
  • 输电效率：$\eta = \dfrac{P_{\text{用户}}}{P_{\text{输送}}} = \dfrac{P - \Delta P}{P}$。

三、公式与推导（含适用条件）

3.1 正弦交流电的产生与峰值公式 $E_m = NBS\omega$

公式

$$E_m = NBS\omega$$ 其中 $N$ 为线圈匝数，$B$ 为磁感应强度（T），$S$ 为线圈面积（m²），$\omega$ 为线圈转动的角速度（rad/s），$E_m$ 为感应电动势的最大值（V）。

推导思路（请合上书独立推一遍）

  1. 设线圈 $abcd$ 中 $ab = cd = L_1$（切割边），$ad = bc = L_2$，绕垂直于磁场的中心轴以角速度 $\omega$ 转动。则 $ab$、$cd$ 边的线速度大小 $v = \omega \cdot \dfrac{L_2}{2}$，方向时刻沿圆周的切线。
  2. 从中性面开始计时，经过时间 $t$ 线圈转过角度 $\theta = \omega t$。此时 $v$ 与磁场 $B$ 方向的夹角为 $\theta$，有效切割速度 $v_{\perp} = v\sin\omega t$。
  3. 单匝线圈中，$ab$、$cd$ 两边产生的感应电动势串联相加： $$e_{\text{单匝}} = 2BL_1 v\sin\omega t = 2BL_1\cdot\frac{\omega L_2}{2}\sin\omega t = BS\omega\sin\omega t$$
  4. $N$ 匝串联：$e = NBS\omega\sin\omega t$。当 $\sin\omega t = 1$（线圈位于峰值面）时取最大值 $E_m = NBS\omega$。
适用条件与边界：
  • 成立前提：匀强磁场、转轴垂直于磁场方向、线圈匀速转动；
  • $E_m$ 与线圈形状无关（矩形、圆形都行），只取决于面积 $S$；也与转轴在线圈平面内的具体位置无关（不一定过中心）；
  • $E_m$ 与计时起点无关——计时起点只影响初相位，不影响峰值。

3.2 瞬时值表达式

$$e = E_m\sin(\omega t + \varphi_0)\qquad u = U_m\sin(\omega t + \varphi_0)\qquad i = I_m\sin(\omega t + \varphi_0)$$
  • 对纯电阻电路，$u$、$i$ 与 $e$ 同频率、同相位，且满足欧姆定律的瞬时值形式 $i = \dfrac{u}{R}$，峰值满足 $U_m = I_m R$；
  • 写瞬时值表达式的三步法：① 定峰值（$E_m = NBS\omega$ 或 $U_m = \sqrt{2}\,U$）；② 定角频率（$\omega = 2\pi f = \dfrac{2\pi}{T}$）；③ 定初相位（看计时起点：中性面 → 正弦，峰值面 → 余弦）。

3.3 正弦交流电的有效值 $E = \dfrac{E_m}{\sqrt{2}}$

公式

$$E = \frac{E_m}{\sqrt{2}} \approx 0.707E_m,\qquad U = \frac{U_m}{\sqrt{2}},\qquad I = \frac{I_m}{\sqrt{2}}$$

推导思路（热效应等效）

  1. 设正弦电流 $i = I_m\sin\omega t$ 通过电阻 $R$，其瞬时热功率 $p = i^2 R = I_m^2 R\sin^2\omega t$。
  2. 关键数学事实：一个周期内 $\sin^2\omega t$ 的平均值为 $\dfrac{1}{2}$。理由：$\sin^2\theta + \cos^2\theta = 1$，而 $\sin^2$ 与 $\cos^2$ 只是「错开」了四分之一周期，一个周期内两者的平均值必然相等，故各为 $\dfrac{1}{2}$。
  3. 一个周期内交流电产生的热量 $Q_{\text{交}} = \overline{i^2}RT = \dfrac{1}{2}I_m^2 RT$。
  4. 按有效值定义，直流 $I$ 在同样时间内产生热量 $Q_{\text{直}} = I^2 RT$。令两者相等： $$I^2 RT = \frac{1}{2}I_m^2 RT \;\Rightarrow\; I = \frac{I_m}{\sqrt{2}}$$
  5. 电压、电动势同理（它们产生的电流也是同规律的正弦电流）。
适用限制（命题人最爱在这里设陷阱）：$E = \dfrac{E_m}{\sqrt{2}}$ 仅适用于正弦（余弦）式交流电！方波、锯齿波、半波整流波形等非正弦交流电绝不能直接除以 $\sqrt{2}$，必须回到有效值的热效应定义分段计算（见 3.4 与例 2）。

有效值的应用场景请记住两句话：「凡算能量，必用有效值」（电功、电热、电功率、保险丝熔断电流、电表读数、铭牌额定值）；「凡问耐压，必看最大值」（电容器击穿电压、二极管反向耐压都与瞬时的最大电压比较）。

3.4 非正弦交流电有效值的分段算法

对任意周期性电流 $i(t)$，有效值 $I$ 由定义唯一确定：

$$I^2 RT = \sum_k i_k^2(t)\,R\,\Delta t_k \quad\Longrightarrow\quad I = \sqrt{\frac{1}{T}\sum_k i_k^2\,\Delta t_k}$$

操作流程（四步）：

  1. 画出一个周期内的 $i\text{-}t$ 图象，按波形把周期分成若干段；
  2. 对每一段求「该段产生的热量」：恒定电流段用 $I_k^2 R\,\Delta t_k$；正弦片段若恰好是完整的半波或 1/4 波的整数倍组合，可用其片段内的方均根值 $\dfrac{I_m}{\sqrt{2}}$ 计算该段热量（推导同 3.3，$\sin^2$ 在半周期内平均值仍为 $\dfrac{1}{2}$）；
  3. 各段热量相加，等于 $I^2RT$；
  4. 解出 $I$。注意：某段电流为负时，平方参与计算，负号不参与。

3.5 平均值与电荷量

$$\bar{E} = N\frac{\Delta\varPhi}{\Delta t},\qquad \bar{I} = \frac{\bar{E}}{R_{\text{总}}},\qquad q = \bar{I}\,\Delta t = N\frac{\Delta\varPhi}{R_{\text{总}}}$$
  • 用途唯一：求一段时间内通过导体横截面的电荷量；
  • 常用磁通量变化量：从中性面转过 $90°$，$\Delta\varPhi = BS$；转过 $180°$，$\Delta\varPhi = 2BS$；转 $360°$，$\Delta\varPhi = 0$（故整周期平均电动势为零）；
  • 注意 $q = N\dfrac{\Delta\varPhi}{R_{\text{总}}}$ 与 $\Delta t$ 无关——转得快慢只影响过程长短，不影响通过的电荷总量；
  • 正弦交流电在半个周期内的平均值大小 $\bar{E} = \dfrac{2}{\pi}E_m \approx 0.637E_m$，它既不等于有效值 $0.707E_m$，也不能用来算热量。

3.6 理想变压器的三个关系

① 电压比（推导）

$$ \frac{U_1}{U_2} = \frac{n_1}{n_2} $$

推导：理想变压器无漏磁，原、副线圈中每一匝的磁通量 $\varPhi$ 相同，变化率 $\dfrac{\Delta\varPhi}{\Delta t}$ 也相同。由法拉第电磁感应定律，$U_1 = n_1\dfrac{\Delta\varPhi}{\Delta t}$，$U_2 = n_2\dfrac{\Delta\varPhi}{\Delta t}$，两式相除即得。该关系对任意多个副线圈都成立：$U_1 : U_2 : U_3 = n_1 : n_2 : n_3$。

② 功率关系

$$ P_1 = P_2 \quad(\text{单副线圈});\qquad P_1 = P_2 + P_3 + \cdots \quad(\text{多副线圈})$$

推导：理想变压器无损耗，由能量守恒，输入功率等于输出（总）功率。这是变压器问题的总纲。

③ 电流比

$$ \frac{I_1}{I_2} = \frac{n_2}{n_1} $$

推导：由 $P_1 = P_2$ 得 $U_1 I_1 = U_2 I_2$，代入电压比整理即得。

电流比的适用条件——只适用于单个副线圈！因为它是由「单副线圈功率守恒」$U_1 I_1 = U_2 I_2$ 推出来的。有多个副线圈时，必须用功率守恒 $U_1 I_1 = U_2 I_2 + U_3 I_3 + \cdots$（等价的写法是 $n_1 I_1 = n_2 I_2 + n_3 I_3 + \cdots$），不能再写成匝数反比。

变压器各量的「决定关系」（动态分析的逻辑链）

  • 电压：输入电压 $U_1$ 决定输出电压 $U_2 = \dfrac{n_2}{n_1}U_1$，与负载无关——电源不变、匝数不变，$U_2$ 就不变；
  • 电流与功率：负载决定输出电流 $I_2 = \dfrac{U_2}{R_{\text{负载}}}$ 和输出功率 $P_2 = \dfrac{U_2^2}{R_{\text{负载}}}$，再由功率守恒「反过来」决定输入电流 $I_1$ 与输入功率 $P_1$——输出决定输入；
  • 频率：变压器不改变交流电的频率，$f_1 = f_2$；
  • 边界：变压器不能提升功率（理想情况 $P_1 = P_2$，实际 $P_1 > P_2$），也不能用于恒定直流（原线圈接直流时无变化磁通，副线圈输出为零，且原线圈直流电阻很小，电流极大，可能烧毁）。

3.7 远距离输电的公式组

对照上图，记住三条「链」：

  1. 电压链：$U_2 = \Delta U + U_3$，即升压副线圈电压 = 线路电压损失 + 降压原线圈电压；变压器处满足 $\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$，$\dfrac{U_3}{U_4} = \dfrac{n_3}{n_4}$；
  2. 电流链：$I_2 = I_3 = \dfrac{P_2}{U_2}$（输送回路电流相同）；变压器两侧 $\dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$；
  3. 功率链：$P_1 = P_2 = \Delta P + P_3$，$P_3 = P_4$；其中线路损失 $$\Delta P = I_2^2 r = \left(\frac{P_2}{U_2}\right)^2 r$$
高压输电的原理（公式背后的物理）：输送功率 $P_2$ 一定时，由 $I_2 = \dfrac{P_2}{U_2}$，电压提高到 $k$ 倍，电流降为 $\dfrac{1}{k}$；代入 $\Delta P = I_2^2 r$，功率损失降为 $\dfrac{1}{k^2}$。损失与电压的平方成反比——这就是世界各国都选择高压（甚至特高压）输电的根本原因。输电效率 $\eta = \dfrac{P_2 - \Delta P}{P_2} = 1 - \dfrac{P_2 r}{U_2^2}$。
公式边界提醒：$\Delta U = I_2 r$ 中的 $\Delta U$ 只是输电线电阻上损失的那部分电压，它远小于输电电压 $U_2$；千万别把 $\Delta U$ 当成 $U_2$，更别用 $\dfrac{U_2}{r}$ 去算线路电流（输电线不是纯电阻用电器，$U_2$ 不是加在 $r$ 两端的电压）。

四、典型例题

例 1　正弦交流电的产生与瞬时值表达式 ★★★

一个 $N = 100$ 匝的矩形线圈，面积 $S = 0.02\ \mathrm{m^2}$，在磁感应强度 $B = 0.5\ \mathrm{T}$ 的匀强磁场中，绕垂直于磁场方向的轴以角速度 $\omega = 100\pi\ \mathrm{rad/s}$ 匀速转动。线圈电阻 $r = 10\ \mathrm{\Omega}$，外接电阻 $R = 90\ \mathrm{\Omega}$。

  1. 求感应电动势的最大值 $E_m$、周期 $T$、频率 $f$，并写出从中性面开始计时的瞬时值表达式 $e(t)$；
  2. 若改从峰值面开始计时，表达式又如何？
  3. 求 $t = \dfrac{T}{8}$ 时刻电动势的瞬时值；
  4. 求电路中电流的有效值 $I$ 与电阻 $R$ 两端电压表的读数 $U$；
  5. 求线圈从中性面转过 $90°$ 的过程中，通过电阻 $R$ 的电荷量 $q$。

过程分析（三步拆解）：

  • 定峰值：用 $E_m = NBS\omega$，注意 $S$ 是线圈面积（与形状无关），$\omega$ 题目直接给出；
  • 定相位：中性面起计时 → 正弦函数；峰值面起计时 → 余弦函数；
  • 分「值」使用：第 (3) 问求瞬时值代入表达式；第 (4) 问电表读数 → 有效值；第 (5) 问求电荷量 → 平均值通路 $q = N\dfrac{\Delta\varPhi}{R_{\text{总}}}$。

解：

(1) 由峰值公式：

$$E_m = NBS\omega = 100\times 0.5\times 0.02\times 100\pi\ \mathrm{V} = 100\pi\ \mathrm{V} \approx 314\ \mathrm{V}$$ $$T = \frac{2\pi}{\omega} = \frac{2\pi}{100\pi}\ \mathrm{s} = 0.02\ \mathrm{s},\qquad f = \frac{1}{T} = 50\ \mathrm{Hz}$$

从中性面开始计时，初相位为零：

$$e = 100\pi\sin(100\pi t)\ \mathrm{V}\;(\approx 314\sin(314t)\ \mathrm{V})$$

(2) 从峰值面开始计时，初相位为 $\dfrac{\pi}{2}$：

$$e = 100\pi\cos(100\pi t)\ \mathrm{V}$$

(3) $t = \dfrac{T}{8} = \dfrac{0.02}{8}\ \mathrm{s} = 2.5\times 10^{-3}\ \mathrm{s}$，此时相位 $\omega t = 100\pi\times 2.5\times 10^{-3} = \dfrac{\pi}{4}$，

$$e = 100\pi\sin\frac{\pi}{4} = 100\pi\times\frac{\sqrt{2}}{2} = 50\sqrt{2}\,\pi\ \mathrm{V} \approx 222\ \mathrm{V}$$

(4) 电动势有效值

$$E = \frac{E_m}{\sqrt{2}} = \frac{100\pi}{\sqrt{2}} = 50\sqrt{2}\,\pi\ \mathrm{V} \approx 222\ \mathrm{V}$$

由闭合电路欧姆定律（有效值形式）：

$$I = \frac{E}{R + r} = \frac{50\sqrt{2}\,\pi}{90 + 10} = \frac{\sqrt{2}\,\pi}{2}\ \mathrm{A} \approx 2.22\ \mathrm{A}$$

电压表测路端电压（$R$ 两端电压）有效值：

$$U = IR = \frac{\sqrt{2}\,\pi}{2}\times 90 = 45\sqrt{2}\,\pi\ \mathrm{V} \approx 200\ \mathrm{V}$$

(5) 从中性面转过 $90°$ 到达峰值面，$\Delta\varPhi = BS - 0 = 0.5\times 0.02\ \mathrm{Wb} = 0.01\ \mathrm{Wb}$，

$$q = N\frac{\Delta\varPhi}{R + r} = 100\times\frac{0.01}{100}\ \mathrm{C} = 0.01\ \mathrm{C}$$
检验与反思：① 数值自洽：$E = \dfrac{E_m}{\sqrt{2}}$ 与第 (3) 问 $t=\dfrac{T}{8}$ 的瞬时值恰好相等（因为 $\sin\dfrac{\pi}{4} = \dfrac{1}{\sqrt{2}}$），都是 $50\sqrt{2}\,\pi \approx 222\ \mathrm{V}$，这不是巧合，是正弦函数的性质；② 第 (5) 问 $q = 0.01\ \mathrm{C}$ 与转动快慢无关，若题目改问「转过 $180°$」则 $\Delta\varPhi = 2BS$，$q' = 0.02\ \mathrm{C}$；③ 常见错误：第 (4) 问误用峰值 $E_m$ 直接除以 $(R+r)$ 得 $3.14\ \mathrm{A}$——电表读数和功率计算必须用有效值。

例 2　非正弦交流电的有效值 ★★★★

某交变电流 $i$ 随时间 $t$ 按如下规律变化：在 $0 \sim \dfrac{T}{2}$ 内，电流为正弦式电流的正半周，峰值 $I_m = 4\ \mathrm{A}$；在 $\dfrac{T}{2} \sim T$ 内，$i = 0$。周期 $T = 0.02\ \mathrm{s}$。

  1. 求该交变电流的有效值 $I$；
  2. 若该电流通过 $R = 100\ \mathrm{\Omega}$ 的电阻，求通电 $1\ \mathrm{min}$ 电阻上产生的热量 $Q$。

过程分析：这不是完整的正弦波（后半周为零），不能直接用 $I = \dfrac{I_m}{\sqrt{2}}$。回到有效值的定义：让该电流与直流 $I$ 分别通过同一电阻 $R$，比较一个周期 $T$ 内的热量。前半周是正弦半波——虽然只存在半个周期，但在这半个周期内，$\sin^2$ 的平均值仍是 $\dfrac{1}{2}$，所以该半周在其存在期间产生的热量，可以用 $\left(\dfrac{I_m}{\sqrt{2}}\right)^2 R\cdot\dfrac{T}{2}$ 计算。

解：

(1) 前半个周期（$0 \sim \dfrac{T}{2}$）为正弦半波，峰值 $I_m = 4\ \mathrm{A}$，该段时间内产生的热量

$$Q_1 = \left(\frac{I_m}{\sqrt{2}}\right)^2 R\cdot\frac{T}{2} = \frac{16}{2}R\cdot\frac{T}{2} = 4RT$$

后半个周期（$\dfrac{T}{2} \sim T$）电流为零，$Q_2 = 0$。

按有效值定义：$I^2 RT = Q_1 + Q_2 = 4RT$，解得

$$I^2 = 4\ \mathrm{A^2} \quad\Rightarrow\quad I = 2\ \mathrm{A}$$

(2) 由焦耳定律，$1\ \mathrm{min} = 60\ \mathrm{s}$ 内产生的热量

$$Q = I^2 R t = 2^2\times 100\times 60\ \mathrm{J} = 2.4\times 10^{4}\ \mathrm{J}$$
检验与反思：① 典型错解一：直接套 $I = \dfrac{I_m}{\sqrt{2}} = 2\sqrt{2} \approx 2.83\ \mathrm{A}$——忘了该公式只适用于完整正弦波；② 典型错解二：把两个半周「平均」一下，得 $I = \sqrt{2}\ \mathrm{A}$ 之类——有效值是「平方的平均再开方」（方均根），不是算术平均；③ sanity check：半波电流的有效值（2 A）应当小于完整正弦波的有效值（$2\sqrt{2}$ A），因为后半周不发热，方向正确。④ 若改成方波：$0\sim\dfrac{T}{2}$ 为 $+2\ \mathrm{A}$、$\dfrac{T}{2}\sim T$ 为 $-2\ \mathrm{A}$，则 $I^2RT = 2^2R\cdot\dfrac{T}{2} + 2^2R\cdot\dfrac{T}{2} = 4RT$，有效值恰为 $2\ \mathrm{A}$（大小恒定的电流，方向变化不影响发热）。

例 3　理想变压器及其动态分析 ★★★★

一理想变压器，原线圈匝数 $n_1 = 1100$ 匝，接入电压 $u_1 = 220\sqrt{2}\sin(100\pi t)\ \mathrm{V}$ 的交流电源；副线圈匝数 $n_2 = 110$ 匝，接有定值电阻 $R = 11\ \mathrm{\Omega}$。

  1. 求副线圈两端电压的有效值 $U_2$、副线圈电流 $I_2$ 与原线圈电流 $I_1$；
  2. 若在 $R$ 两端再并联一个相同的电阻（总电阻变为 $5.5\ \mathrm{\Omega}$），$U_2$、$I_2$、$I_1$、$P_1$ 如何变化？
  3. 若把副线圈匝数改为 $n_2' = 220$ 匝（负载仍为一个 $R$），$U_2'$ 变为多少？

过程分析（决定关系链）：① 电源电压 $U_1$（有效值）与匝数比先「钉死」$U_2$——$U_2$ 与负载无关；② 负载电阻决定 $I_2 = \dfrac{U_2}{R}$ 与 $P_2$；③ 由功率守恒反推 $I_1$、$P_1$。动态分析时按「$U_2$ 不变 → 负载变 → $I_2$、$P_2$ 变 → $I_1$、$P_1$ 跟着变」的顺序走，就不会乱。注意 $u_1$ 表达式中的 $220\sqrt{2}$ 是最大值，计算变压器一律用有效值 $220\ \mathrm{V}$。

解：

(1) 原线圈电压有效值 $U_1 = \dfrac{220\sqrt{2}}{\sqrt{2}}\ \mathrm{V} = 220\ \mathrm{V}$。由电压比：

$$U_2 = \frac{n_2}{n_1}U_1 = \frac{110}{1100}\times 220\ \mathrm{V} = 22\ \mathrm{V}$$ $$I_2 = \frac{U_2}{R} = \frac{22}{11}\ \mathrm{A} = 2\ \mathrm{A}$$

由电流比（单副线圈）：

$$I_1 = \frac{n_2}{n_1}I_2 = \frac{110}{1100}\times 2\ \mathrm{A} = 0.2\ \mathrm{A}$$

(2) 并联后负载总电阻 $R' = \dfrac{11}{2}\ \mathrm{\Omega} = 5.5\ \mathrm{\Omega}$。

  • $U_2$：不变，仍为 $22\ \mathrm{V}$（$U_1$、匝数比均未变）；
  • $I_2' = \dfrac{U_2}{R'} = \dfrac{22}{5.5}\ \mathrm{A} = 4\ \mathrm{A}$，增大为原来的 2 倍；
  • $P_2' = U_2 I_2' = 22\times 4\ \mathrm{W} = 88\ \mathrm{W}$，故 $P_1' = 88\ \mathrm{W}$，增大为原来的 2 倍；
  • $I_1' = \dfrac{P_1'}{U_1} = \dfrac{88}{220}\ \mathrm{A} = 0.4\ \mathrm{A}$（或用电流比 $\dfrac{110}{1100}\times 4 = 0.4\ \mathrm{A}$），增大为原来的 2 倍。

(3) 匝数改为 $n_2' = 220$ 匝：

$$U_2' = \frac{n_2'}{n_1}U_1 = \frac{220}{1100}\times 220\ \mathrm{V} = 44\ \mathrm{V}$$
检验与反思：① 功率自洽：第 (1) 问 $P_2 = U_2 I_2 = 22\times 2 = 44\ \mathrm{W}$，$P_1 = U_1 I_1 = 220\times 0.2 = 44\ \mathrm{W}$，两者相等 ✓；第 (2) 问 $P_1' = 220\times 0.4 = 88\ \mathrm{W} = P_2'$ ✓；② 动态结论：负载越「重」（并联支路越多、总电阻越小），$I_2$、$P_2$ 越大，$I_1$、$P_1$ 同步变大，$U_2$ 岿然不动——这就是「输出决定输入」；③ 常见错误：认为「负载电阻变小，$U_2$ 会变小」——那是实际电源有内阻时的路端电压问题，理想变压器的 $U_2$ 只由 $U_1$ 和匝数比决定，两套逻辑别混淆。

例 4　远距离输电的损失计算 ★★★★

某水电站输出功率 $P = 44\ \mathrm{kW}$，输电线的总电阻 $r = 0.5\ \mathrm{\Omega}$。

  1. 若不经过升压，直接以 $U = 220\ \mathrm{V}$ 输电，求输电线上的电流 $I$、电压损失 $\Delta U$、功率损失 $\Delta P$ 和输电效率 $\eta$；
  2. 若用升压变压器（匝数比 $n_1 : n_2 = 1 : 10$）把电压升高到 $U_2 = 2200\ \mathrm{V}$ 再输电，求输电线电流 $I_2$、电压损失 $\Delta U'$、功率损失 $\Delta P'$ 和输电效率 $\eta'$；
  3. 到达用户端后用降压变压器（$n_3 : n_4 = 10 : 1$）降压，求降压变压器原线圈两端的电压 $U_3$ 与用户得到的电压 $U_4$。

过程分析（先画图再列式）：画出「发电机 → 升压 → 输电线 $r$ → 降压 → 用户」示意图，把 $U_2 = \Delta U' + U_3$ 标在图上。核心顺序：输送功率 $P$ 一定 → 由 $I = \dfrac{P}{U}$ 定线路电流 → 由 $\Delta U = Ir$、$\Delta P = I^2 r$ 算损失 → 用户端得到「剩下的」电压与功率。

解：

(1) 直接以 $220\ \mathrm{V}$ 输电：

$$I = \frac{P}{U} = \frac{44\times 10^{3}}{220}\ \mathrm{A} = 200\ \mathrm{A}$$ $$\Delta U = Ir = 200\times 0.5\ \mathrm{V} = 100\ \mathrm{V}$$ $$\Delta P = I^2 r = 200^2\times 0.5\ \mathrm{W} = 2\times 10^{4}\ \mathrm{W} = 20\ \mathrm{kW}$$ $$\eta = \frac{P - \Delta P}{P} = \frac{44 - 20}{44} \approx 54.5\%$$

近一半的电能「烧」在了输电线上（用户端电压仅剩 $220 - 100 = 120\ \mathrm{V}$），完全无法接受。

(2) 升压至 $U_2 = 2200\ \mathrm{V}$（匝数比 $1:10$，$220\ \mathrm{V}\to 2200\ \mathrm{V}$，自洽 ✓）：

$$I_2 = \frac{P}{U_2} = \frac{44\times 10^{3}}{2200}\ \mathrm{A} = 20\ \mathrm{A}$$ $$\Delta U' = I_2 r = 20\times 0.5\ \mathrm{V} = 10\ \mathrm{V}$$ $$\Delta P' = I_2^2 r = 20^2\times 0.5\ \mathrm{W} = 200\ \mathrm{W} = 0.2\ \mathrm{kW}$$ $$\eta' = \frac{P - \Delta P'}{P} = \frac{44 - 0.2}{44} \approx 99.5\%$$

(3) 降压变压器原线圈两端电压（线路末端电压）：

$$U_3 = U_2 - \Delta U' = 2200 - 10 = 2190\ \mathrm{V}$$

由电压比 $\dfrac{U_3}{U_4} = \dfrac{n_3}{n_4}$：

$$U_4 = \frac{n_4}{n_3}U_3 = \frac{1}{10}\times 2190\ \mathrm{V} = 219\ \mathrm{V}$$

用户得到约 $219\ \mathrm{V}$ 的电压，与 $220\ \mathrm{V}$ 的用电标准相差无几。

检验与反思：① 对比 (1)(2)：电压提高到 10 倍 → 电流降为 $\dfrac{1}{10}$ → 功率损失降为 $\dfrac{1}{100}$（$20\ \mathrm{kW} \to 0.2\ \mathrm{kW}$），完美验证 $\Delta P \propto \dfrac{1}{U^2}$；② 电压链自洽：$U_2 = \Delta U' + U_3$ 即 $2200 = 10 + 2190$ ✓；③ 最常见的两处错误：用 $\dfrac{U_2}{r} = \dfrac{2200}{0.5} = 4400\ \mathrm{A}$ 算线路电流（错把 $U_2$ 当成 $r$ 两端的电压）；把 $\Delta P$ 写成 $\dfrac{U_2^2}{r}$（同错，且 $\dfrac{2200^2}{0.5} = 9.68\ \mathrm{MW}$，比输送功率还大，明显荒谬——量纲和数量级检查是好习惯）。

五、易错点与成因分析

易错点 1　用平均值算热量、用有效值算电荷量

典型错误：求焦耳热时用 $Q = \bar{I}^2Rt$；或求电荷量时用 $q = I_{\text{有效}}\cdot t$。

成因分析：两个概念都是「等效思想」的产物，但等效的对象不同——有效值对发热等效（与 $i^2$ 的平均挂钩），平均值对电荷搬运等效（与 $i$ 本身的平均挂钩）。不加区分地互相代用，说明只记住了「等效」两个字，没记住等效的是什么。记忆锚点：热量↔有效值，电荷量↔平均值。另外注意数值上 $\bar{E} = \dfrac{2}{\pi}E_m \approx 0.637E_m \neq 0.707E_m = E_{\text{有效}}$，二者本就不相等。

易错点 2　对非正弦波套 $E = \dfrac{E_m}{\sqrt{2}}$

典型错误：方波、半波、锯齿波的有效值也直接「峰值除以 $\sqrt{2}$」。

成因分析：把「结论」当「定义」记。$\dfrac{1}{\sqrt{2}}$ 这个系数是正弦波形特有的（来自 $\sin^2$ 平均值为 $\dfrac{1}{2}$），换了波形，$\overline{i^2}$ 与 $I_m^2$ 的比例关系就变了。对策：见到非正弦波，立刻回到 $I^2RT = \sum i_k^2 R\,\Delta t_k$ 分段计算（如例 2）。

易错点 3　电流比用于多副线圈变压器

典型错误：一个原线圈带两个副线圈时，仍写 $\dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$。

成因分析：不清楚公式的「出身」。电流比是从单副线圈的功率守恒 $U_1I_1 = U_2I_2$ 推出的；多副线圈时功率守恒应写成 $U_1I_1 = U_2I_2 + U_3I_3$，电流比形式不再成立。而电压比 $\dfrac{U_1}{n_1} = \dfrac{U_2}{n_2} = \dfrac{U_3}{n_3}$ 来自「每匝磁通量相同」，与副线圈个数无关，依然成立。电压比无门槛，电流比有门槛，门槛就是「单个副线圈」。

易错点 4　输电电压 $U_2$ 与电压损失 $\Delta U$ 混淆

典型错误：用 $I = \dfrac{U_2}{r}$ 求线路电流，或用 $\Delta P = \dfrac{U_2^2}{r}$ 求功率损失。

成因分析：把输电线当成了「接在 $U_2$ 下的用电器」。实际上 $U_2$ 是整条输电回路（线路电阻 $r$ + 降压变压器原线圈）两端的总电压，落在 $r$ 上的只有 $\Delta U = U_2 - U_3$ 这一小部分。正确链条是 $I_2 = \dfrac{P_2}{U_2}$，再 $\Delta U = I_2 r$、$\Delta P = I_2^2r$。 sanity check：若 $\Delta P$ 算出来接近甚至超过 $P$，必错无疑。

易错点 5　中性面上「$\varPhi$ 最大故 $e$ 最大」

典型错误：认为线圈位于中性面时磁通量最大，所以感应电动势也最大。

成因分析：混淆了「磁通量 $\varPhi$」与「磁通量变化率 $\dfrac{\Delta\varPhi}{\Delta t}$」——这正是电磁感应一章最核心的一对概念。法拉第定律 $e = N\dfrac{\Delta\varPhi}{\Delta t}$ 中，$e$ 只看变化率。中性面处 $\varPhi$ 取最大值，恰是变化率为零的时刻（正弦函数在峰值处切线水平）；峰值面处 $\varPhi = 0$，变化率反而最大。可以联想振动中的类比：位移最大时速度为零，位移为零时速度最大——$\varPhi$ 与 $e$ 的关系正如 $x$ 与 $v$。

易错点 6　瞬时值表达式计时起点张冠李戴

典型错误：题目说「线圈从中性面位置开始计时」，却写出 $e = E_m\cos\omega t$；或图象过原点却按余弦处理。

成因分析：背公式时丢掉了前提条件。对策是理解而非死记：中性面处 $e = 0$，而 $t = 0$ 时 $\sin\omega t = 0$、$\cos\omega t = 1$——哪个在 $t=0$ 时为零，一眼可判。中性面起计时用正弦，峰值面起计时用余弦；题目未说明时默认中性面、用正弦。

易错点 7　最大值与有效值的应用场景颠倒

典型错误：用有效值 $220\ \mathrm{V}$ 判断耐压 $300\ \mathrm{V}$ 的电容器能否接入市电（结论错误地说"可以"）。

成因分析：市电电压最大值高达 $220\sqrt{2} \approx 311\ \mathrm{V}$，超过 $300\ \mathrm{V}$，电容器会被击穿。判断是否击穿看的是每一瞬间的实际电压，必须用最大值比较；而电表读数、铭牌额定值、保险丝熔断电流都是有效值。一句话：发热问题用有效值，击穿问题用最大值。

易错点 8　认为变压器能「变频」或「省能」

典型错误：认为副线圈频率与原线圈不同；或认为「升压后电压高了，就能向外多输送能量」。

成因分析：互感过程中，副线圈的磁通量变化节奏完全由原线圈电流决定，频率天然相同，变压器不改变频率；能量方面，理想变压器 $P_1 = P_2$，实际变压器因铜损、铁损、漏磁还有 $P_1 > P_2$——变压器只是能量的「搬运工」，从不生产能量。升压输电「省」的不是能量本身，而是输电线上的损耗。

六、章末自检清单

合上这份材料，逐项自测。能流畅完成就打勾，打不了勾的回到对应小节再过一遍。

概念关

  • ☐ 能说出交变电流的定义，并指出「方向变化」是交流电区别于直流电的本质特征；
  • ☐ 能指出中性面的位置（线圈平面⊥磁场），并一口气说出它的三个特点：$\varPhi$ 最大、$e=0$、电流方向反转；知道一个周期内两次经过中性面；
  • ☐ 能写出四值（瞬时值、最大值、有效值、平均值）的符号与单位，并各说出一个使用场景；
  • ☐ 能复述有效值的热效应定义（同电阻、同时间、同热量），知道电表读数、铭牌参数均为有效值，电容耐压看最大值；
  • ☐ 记住 $\omega = 2\pi f = \dfrac{2\pi}{T}$，知道我国市电 $f=50\ \mathrm{Hz}$、$T=0.02\ \mathrm{s}$；
  • ☐ 理解相位、初相位的意义，知道计时起点如何决定初相位。

公式关

  • ☐ 能独立推导 $E_m = NBS\omega$，并说出它与线圈形状、轴位置无关的结论；
  • ☐ 会用「三步法」（定峰值、定角频率、定初相位）书写瞬时值表达式；
  • ☐ 能讲清 $E = \dfrac{E_m}{\sqrt{2}}$ 的推导思路（$\sin^2$ 一个周期平均值为 $\dfrac{1}{2}$），并明确它只适用于正弦波；
  • ☐ 会按有效值定义分段计算方波、半波等非正弦电流的有效值；
  • ☐ 默写变压器三关系：$\dfrac{U_1}{U_2}=\dfrac{n_1}{n_2}$（任意副线圈数）、$P_1=P_2$、$\dfrac{I_1}{I_2}=\dfrac{n_2}{n_1}$（仅单副线圈），并能说出各自的推导依据；
  • ☐ 默写输电公式组 $\Delta U = I_2 r$、$\Delta P = I_2^2 r = \left(\dfrac{P_2}{U_2}\right)^2 r$，并据此解释高压输电的道理（电压提高 $k$ 倍，损失降为 $\dfrac{1}{k^2}$）。

模型关

  • ☐ 线圈旋转模型：给定线圈位置（与磁场夹角），能判断该时刻 $\varPhi$ 与 $e$ 的大小、能写出从该位置计时的瞬时值表达式；
  • ☐ 理想变压器动态分析：能按「$U_1$ 定 $U_2$ → 负载定 $I_2$、$P_2$ → 功率守恒定 $I_1$、$P_1$」的链条分析负载变化问题；
  • ☐ 远距离输电：能不看书画出「发电机→升压→输电线→降压→用户」示意图，并标出 $U_1$、$U_2$、$\Delta U$、$U_3$、$U_4$、$I_2$、$P$、$\Delta P$ 的位置，写出电压链 $U_2 = \Delta U + U_3$ 与功率链 $P_2 = \Delta P + P_3$。

易错关

  • ☐ 算热量、功率时不会误用平均值；算电荷量时不会误用有效值；
  • ☐ 遇到非正弦波形，第一反应是回到热效应定义分段计算，而不是除以 $\sqrt{2}$；
  • ☐ 多副线圈问题中只用电圧比和功率守恒，不用电流比；
  • ☐ 输电问题中严格区分 $U_2$（输电电压）与 $\Delta U$（线路电压损失），不用 $\dfrac{U_2}{r}$ 算电流；
  • ☐ 判断电容器、二极管耐压时记得用最大值 $U_m = \sqrt{2}\,U$ 比较；
  • ☐ 知道变压器不改变频率、不创造能量，且只能用于交流。

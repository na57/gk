09 静电场与直流电路

物理竞赛专题（12 章系列 · 第 9 章） ｜ 适用：高一竞赛入门（目标：预赛 → 复赛入门） ｜ 前置：01 竞赛数学工具（微元法）、04 功与能量（能量观点） ｜ 学生：小兵

从这一章起，我们正式进入电磁学的世界。静电场和直流电路是两块风格迥异的大陆：前者考验你"对看不见的东西做积分"的想象力，后者考验你"在蜘蛛网一样的电路里找对称"的观察力。这两件事恰好是预赛复赛的常客。别怕公式多——本章每个公式都配了推导，每道例题都从"思路起点"写起，你只管跟着走，走着走着就会了。

一、知识全景

静电学回答一个问题：电荷不动时，空间里的"电"长什么样？我们用两个量描写它——场强 $E$（力的角度，矢量）和电势 $\varphi$（能的角度，标量）。电路学回答另一个问题：电荷流动起来后，电流、电压怎么分配？核心武器是基尔霍夫两条定律。

二、核心概念

2.1 库仑定律与电场强度

真空中两个点电荷之间的作用力：

$$\boldsymbol{F = k\frac{q_1 q_2}{r^2}} \qquad k = 9.0\times 10^{9}\ \mathrm{N\cdot m^2/C^2}$$
  • 适用条件：真空、点电荷（$r$ 远大于带电体尺寸时可当点电荷；均匀带电球体外也可等效为球心处点电荷）
  • 同号相斥、异号相吸；力沿两电荷连线；满足牛顿第三定律
  • $k$ 与真空介电常数的关系：$k = \dfrac{1}{4\pi\varepsilon_0}$，$\varepsilon_0 = 8.85\times10^{-12}\ \mathrm{F/m}$（竞赛里两个写法都要认得）

电场强度定义：放入场中的检验电荷 $q$ 受力 $F$，则

$$E = \frac{F}{q} \qquad\text{点电荷产生的场：}\quad \boldsymbol{E = \frac{kQ}{r^2}}$$
  • $E$ 是矢量，方向与正电荷受力方向相同
  • 叠加原理：多个电荷产生的场强 = 各自场强的矢量和——这是全章最重要的思想，微元法积分就是它的无限细分版

2.2 电势与电势能

电荷 $q$ 在电场中某点的电势能 $E_p$ 与 $q$ 成正比，比例系数只由电场决定，称为电势：

$$\varphi = \frac{E_p}{q} \qquad\text{点电荷产生的电势（取无穷远为零点）：}\quad \boldsymbol{\varphi = \frac{kQ}{r}}$$
  • $\varphi$ 是标量，但有正负：正电荷周围 $\varphi > 0$，负电荷周围 $\varphi < 0$（以无穷远为零点）
  • 电势叠加 = 代数和（带正负号直接加），比场强的矢量叠加简单得多
  • 电势差（电压）：$U_{AB} = \varphi_A - \varphi_B$；电场力做功 $\boldsymbol{W_{AB} = qU_{AB}}$（$q$ 带符号代入）
  • 匀强电场中 $\boldsymbol{E = \dfrac{U}{d}}$，$d$ 是沿场强方向的距离
  • 等势面与电场线处处垂直；沿电场线方向电势降低最快
E 与 φ 的微积分关系（竞赛视角）：场强是电势的"空间变化率"：沿 $x$ 方向有 $E_x = -\dfrac{\mathrm{d}\varphi}{\mathrm{d}x}$。反过来 $\varphi$ 是 $E$ 的累积。这给了我们一条黄金路线：先用标量积分求 φ，再求导得 E——往往比直接做矢量积分省一半力气（例 2 见分晓）。

2.3 导体的静电平衡

导体内部有大量自由电子。把导体放进电场，自由电子在电场力作用下重新分布（静电感应），直到导体内部合场强处处为零——这个过程只要约 $10^{-14}$ s，之后达到静电平衡。

静电平衡四大结论（每条都要会"为什么"）：
  1. 导体内部合场强处处为零（若不为零，自由电荷还会继续移动，谈不上平衡）
  2. 导体是等势体，表面是等势面（内部 $E=0$，移动电荷不做功，各点电势相等）
  3. 净电荷只分布在导体外表面（内部若有净电荷，它发出的电场线无处可去，必然在导体内产生场，矛盾）
  4. 表面处场强垂直于表面（若有切向分量，电荷会沿表面移动）
  • 感应电荷规律：把不带电导体靠近带电体 $+Q$，近端感应出异号电荷（$-q$），远端感应出同号电荷（$+q$），总量仍为零
  • 静电屏蔽：
    • 空腔导体（不接地）：外部电场进不了空腔——腔内无电荷时腔内场强为零。屏蔽外场
    • 空腔导体接地：腔内带电体产生的电场被锁在腔内，外表面感应电荷被大地中和，外部空间场强为零。屏蔽内场
  • 机理一句话：不是导体"挡住"了电场，而是感应电荷产生的场与外场在导体内部恰好叠加抵消——这是叠加原理的胜利，例 3 会让你把这个机理用成解题工具

2.4 电容器

两个彼此绝缘又靠得很近的导体构成电容器，容纳电荷的本领用电容描写：

$$C = \frac{Q}{U} \qquad\text{平行板电容器：}\quad \boldsymbol{C = \frac{\varepsilon_r \varepsilon_0 S}{d}}$$
  • $Q$：一块极板所带电荷的绝对值；$U$：两极板间电压；单位法拉（F），常用 $\mu F$（$10^{-6}$ F）、pF（$10^{-12}$ F）
  • $\varepsilon_r$：相对介电常数，真空为 1，插入电介质后 $C$ 增大为原来的 $\varepsilon_r$ 倍（电介质被极化，削弱了内部场强）
  • 平行板间是匀强电场：$E = \dfrac{U}{d} = \dfrac{Q}{\varepsilon_r\varepsilon_0 S}$

串联与并联（和电阻的规律正好相反！）

储能公式

$$\boldsymbol{W = \frac{1}{2}QU = \frac{1}{2}CU^2 = \frac{Q^2}{2C}}$$

记忆线索：充电过程中电压从 0 线性涨到 $U$，平均电压 $\bar U = \dfrac{U}{2}$，故 $W = \bar U Q = \dfrac{1}{2}QU$（和"匀加速平均速度"一个套路）。

动态分析两板斧：电容器接在电源上 → U 不变（电源强行钳位）；充完电断开电源 → Q 不变（电荷无处可逃）。遇到"插介质、变间距、错开极板"类问题，先问自己三遍：谁不变？谁不变？谁不变？然后 $C = \dfrac{\varepsilon_r\varepsilon_0 S}{d}$ 看 C 怎么变，$Q = CU$ 或 $U = Q/C$ 推其余，$E = U/d$ 看场强。例 4 就是这套流程。

2.5 直流电路与电源

  • 电流：$I = \dfrac{q}{t}$；微观表达式 $\boldsymbol{I = nqSv}$（$n$ 载流子密度，$v$ 漂移速度——注意 $v$ 极小，约 $10^{-4}\ \mathrm{m/s}$ 量级，"电"传得快靠的是电场的建立速度，不是电子跑得快）
  • 电阻定律：$R = \rho \dfrac{L}{S}$；部分电路欧姆定律：$I = \dfrac{U}{R}$
  • 电功与电功率：$W = UIt$，$P = UI$；纯电阻电路才有 $P = I^2 R = \dfrac{U^2}{R}$
  • 电动势 E：电源把其他形式的能转化为电能的本领，数值上等于断开外电路时的路端电压
  • 闭合电路欧姆定律：
$$\boldsymbol{I = \frac{E}{R + r}} \qquad\text{路端电压：}\quad U = E - Ir$$
  • $r$ 是电源内阻；外电路断开时 $I=0$，$U = E$；短路时 $I_{短} = \dfrac{E}{r}$（危险！）
  • 电源输出功率（外电阻消耗的功率）：
$$P_{出} = I^2 R = \frac{E^2 R}{(R+r)^2} \qquad\Rightarrow\qquad \boxed{R = r\ \text{时}\ P_{出\max} = \frac{E^2}{4r}}$$
推导（均值不等式）：$(R+r)^2 = (R-r)^2 + 4Rr \ge 4Rr$，故 $\dfrac{R}{(R+r)^2} \le \dfrac{1}{4r}$，等号当且仅当 $R = r$。
注意：此时电源效率 $\eta = \dfrac{R}{R+r} = 50\%$——最大输出功率 ≠ 最高效率，两者不可兼得（例 5）。

2.6 基尔霍夫定律

遇到"既不是串联也不是并联"的复杂网络（如不平衡电桥），串并联公式失效，轮到电路世界的"牛顿定律"登场：

  • 基尔霍夫第一定律（KCL，节点电流定律）：任意节点，流入电流之和 = 流出电流之和。本质：电荷守恒——节点不能凭空堆积电荷。
  • 基尔霍夫第二定律（KVL，回路电压定律）：沿任意闭合回路绕行一周，各元件电压降的代数和为零。本质是能量守恒——电荷绕一圈回到原点，电势能必须复原。
符号约定（写题目前先声明，全题统一）：
① 每条支路电流方向任意假设，解出来为正 → 假设正确；为负 → 实际反向，大小取绝对值。不要因为"看着像"而纠结，让方程说话。
② 节点电势法（推荐）：给每个独立节点设电势 $V_i$，每条支路电流用 $\dfrac{V_i - V_j}{R}$ 表示，对每个节点写 KCL。未知数少、机械化、不易错——本章例 6 全程示范。
③ 若用回路法：先定绕行方向，电阻上顺流降压（$+IR$ 为降）、逆流升压；电源从负极穿到正极升 $E$、反之降 $E$；绕行一周总和为零。

三、竞赛专属·高考不考：连续带电体的积分计算、对称性电路与 Y-Δ 变换

下面三块内容高考卷面上几乎绝迹，但预赛年年见、复赛当基本功。它们的门槛其实不在物理，而在"你敢不敢动手算"。

3.1 微元法与积分：连续带电体的场强与电势

真实带电体的电荷分布在一条线、一个面或一块体积里。处理它们只有一条路：切成无数个点电荷微元，用叠加原理加起来——也就是积分。

微元法四步（背下来）：
① 选微元：取一小段电荷 $\mathrm{d}q$（线分布 $\mathrm{d}q = \lambda\,\mathrm{d}l$，面分布 $\mathrm{d}q = \sigma\,\mathrm{d}S$）；
② 写微元场：$\mathrm{d}E = \dfrac{k\,\mathrm{d}q}{r^2}$（电势则 $\mathrm{d}\varphi = \dfrac{k\,\mathrm{d}q}{r}$）；
③ 对称性先行：先判断哪些分量两两抵消，只积分活下来的分量（乘 $\cos\theta$ 之类的投影因子）；
④ 积分求和：统一变量、定上下限，算到底。

样板一：均匀带电圆环轴线上的电势（标量积分，最简单）

圆环半径 $R$、总电量 $Q$ 均匀分布，P 在轴上距环心 $x$。每个微元 $\mathrm{d}q$ 到 P 的距离都一样：$r = \sqrt{R^2 + x^2}$。于是电势积分根本不用"积"——分母是常数，直接提出：

$$\varphi = \int \frac{k\,\mathrm{d}q}{\sqrt{R^2+x^2}} = \frac{k}{\sqrt{R^2+x^2}} \int \mathrm{d}q = \boldsymbol{\frac{kQ}{\sqrt{R^2+x^2}}}$$

检验极限：$x \gg R$ 时 $\varphi \to \dfrac{kQ}{x}$（退化为点电荷）✓；$x = 0$ 时 $\varphi = \dfrac{kQ}{R}$（环心电势不为零！）✓。

样板二：同一圆环轴线上的场强（矢量积分，先抵消再积）

每个 $\mathrm{d}q$ 在 P 产生的 $\mathrm{d}E$ 方向各异，但绕轴一圈，垂直于轴的分量两两抵消，只剩轴向分量 $\mathrm{d}E_x = \mathrm{d}E\cos\theta$，其中 $\cos\theta = \dfrac{x}{\sqrt{R^2+x^2}}$ 也是常数：

$$E = \int \frac{k\,\mathrm{d}q}{R^2+x^2}\cdot\frac{x}{\sqrt{R^2+x^2}} = \frac{kx}{(R^2+x^2)^{3/2}}\int \mathrm{d}q = \boldsymbol{\frac{kQx}{(R^2+x^2)^{3/2}}}$$

检验：① 用 $E_x = -\dfrac{\mathrm{d}\varphi}{\mathrm{d}x}$ 验证：$-\dfrac{\mathrm{d}}{\mathrm{d}x}\left[kQ(R^2+x^2)^{-1/2}\right] = kQx(R^2+x^2)^{-3/2}$ ✓ 与直接积分一致；② $x=0$ 时 $E=0$（环心对称，场强为零）✓；③ $x \gg R$ 时 $E \to \dfrac{kQ}{x^2}$ ✓。三个检验全过，才敢写在答卷上。

样板三：有限长均匀带电直导线中垂线上的场强

导线长 $L$、线电荷密度 $\lambda$，P 在中垂线上距导线 $d$。取微元 $\mathrm{d}q = \lambda\,\mathrm{d}y$，由对称性只有中垂方向分量存活：

$$E = \int_{-L/2}^{L/2} \frac{k\lambda\,\mathrm{d}y}{d^2+y^2}\cdot\frac{d}{\sqrt{d^2+y^2}} = k\lambda d \int_{-L/2}^{L/2} \frac{\mathrm{d}y}{(d^2+y^2)^{3/2}}$$

换元 $y = d\tan\theta$（则 $\mathrm{d}y = d\sec^2\theta\,\mathrm{d}\theta$，$(d^2+y^2)^{3/2} = d^3\sec^3\theta$，被积函数化简为 $\dfrac{\cos\theta}{d^2}\,\mathrm{d}\theta$）：

$$E = \frac{k\lambda}{d}\cdot 2\sin\theta_0 = \boldsymbol{\frac{2k\lambda}{d}\cdot\frac{L/2}{\sqrt{d^2 + (L/2)^2}}} \qquad \xrightarrow{L \to \infty}\quad \boldsymbol{E = \frac{2k\lambda}{d} = \frac{\lambda}{2\pi\varepsilon_0 d}}$$

最后那个极限——无限长直导线的场——是竞赛里的"名人"，与距离一次方成反比（点电荷是平方，记住这个对比）。

附：两个常用的结论（均匀带电球面）

  • 球面外（$r > R$）：$E = \dfrac{kQ}{r^2}$，$\varphi = \dfrac{kQ}{r}$——如同电荷全部集中在球心
  • 球面内（$r < R$）：$\boldsymbol{E = 0}$，$\varphi = \dfrac{kQ}{R}$（常数）——"内部场强为零"但"电势不为零"的经典案例

3.2 对称性电路：等势点短接法

有些电阻网络既不串也不并，但结构对称。这时可以用两条推论：

  • 对称点等势：电路关于某平面（轴）对称，且激励也关于它对称，则对称位置上的节点电势相等。
  • 等势点可以短接：电势相等的点之间用导线连起来，导线里没有电流，电路状态丝毫不受影响——于是网络被"折叠"成串并联结构。

反过来，电流对称分配也常用：从顶点 A 注入的电流 $I$，若 A 连着三条完全对称的支路，则每条支路电流必为 $\dfrac{I}{3}$（若不等，把三条支路轮换一遍电路不变，电流值却换了，矛盾——这就是对称性论证的标准腔调）。例 7 的立方体网络全程示范这套功夫。

前提红线：等势点短接只在严格对称时成立。"看起来差不多对称"不算数——某条边阻值不同、电源接偏一点，对称性就破了，必须回到基尔霍夫定律硬算。

3.3 Y-Δ 变换入门

三个电阻连成三角形（Δ）或星形（Y），对外都只有三个端子。适当选择阻值，两种接法可以对外完全等效——端子间任意电压下电流全同。变换公式（Δ 三边为 $R_{12}, R_{23}, R_{31}$，Y 三臂为 $R_1, R_2, R_3$）：

$$\textbf{Δ→Y：}\quad R_1 = \frac{R_{12}R_{31}}{R_{12}+R_{23}+R_{31}},\quad R_2 = \frac{R_{12}R_{23}}{R_{12}+R_{23}+R_{31}},\quad R_3 = \frac{R_{23}R_{31}}{R_{12}+R_{23}+R_{31}}$$ $$\text{Y→Δ：}\quad R_{12} = \frac{R_1R_2 + R_2R_3 + R_3R_1}{R_3}\ \text{（分子两两乘积之和，分母为"对臂"）}$$
  • Δ→Y 口诀："夹边乘积 ÷ 三边和"——$R_1$ 由夹着 1 号端子的两条 Δ 边相乘，除以三边之和
  • 特例：对称 Δ（三个 $R$）↔ 对称 Y（三个 $\dfrac{R}{3}$）。如三个 $30\ \Omega$ 的 Δ，等效 Y 每臂 $\dfrac{30\times30}{30+30+30} = 10\ \Omega$
实战价值：不平衡电桥、立方体面对角线这类"无法串并联"的网络，把一个 Δ 变成 Y（或反之），电路立刻塌缩成串并联结构。例 6 的电桥用 Y-Δ 复算：把 A-B-D 三点间的 Δ（$R_{AB}=2\ \Omega$、$R_{BD}=1\ \Omega$、$R_{AD}=1\ \Omega$）变成 Y： $$R_A = \frac{2\times1}{2+1+1} = 0.5\ \Omega,\quad R_B = \frac{2\times1}{4} = 0.5\ \Omega,\quad R_D = \frac{1\times1}{4} = 0.25\ \Omega$$ 总电阻立刻串并联化：$R_{AC} = 0.5 + (0.5+4)\parallel(0.25+3) = 0.5 + \dfrac{4.5\times3.25}{7.75} = \dfrac{74}{31} \approx 2.39\ \Omega$，与例 6 基尔霍夫的结果严丝合缝 ✓。

四、例题精讲

例 1　两个点电荷连线上的"零场强点"

题目：真空中有两个点电荷 $Q_1 = +4.0\times10^{-8}\ \mathrm{C}$、$Q_2 = -1.0\times10^{-8}\ \mathrm{C}$，相距 $L = 30\ \mathrm{cm}$。在两者连线上找出场强为零的点，并说明该点两侧场强的方向。

思路起点：零场强点要求两电荷产生的场等大反向。先定性排除不可能的区域，再定量列方程。异号电荷：连线之间两场同向（都指向负电荷），不可能抵消；电量较大的 $Q_1$ 外侧，离大电荷近、离小电荷远，$E_1$ 恒大于 $E_2$，也不可能——只剩 $Q_2$（电量小者）外侧。

解析：设零点在 $Q_2$ 外侧、距 $Q_2$ 为 $x$，则距 $Q_1$ 为 $L + x$。等大条件：

$$k\frac{|Q_1|}{(L+x)^2} = k\frac{|Q_2|}{x^2} \ \Rightarrow\ \frac{4}{(0.30+x)^2} = \frac{1}{x^2} \ \Rightarrow\ 2x = 0.30 + x \ \Rightarrow\ \boxed{x = 0.30\ \mathrm{m}}$$

验证：该点距 $Q_1$ 为 $0.60\ \mathrm{m}$，两场大小均为 $E = \dfrac{9.0\times10^9\times1.0\times10^{-8}}{0.30^2} = \dfrac{90}{0.09} = 1.0\times10^3\ \mathrm{N/C}$ ✓。方向：$Q_1$（正）在该点的场指向外（远离 $Q_1$），$Q_2$（负）的场指向 $Q_2$，恰好相反 ✓。

点评：口诀——"零场点，异号外侧靠小电"（同号电荷则在连线之间靠小电）。先定区域再列方程，比拿到题就硬解快得多，也避免增根。

例 2　均匀带电圆环：电势好积，场强求导【预赛难度】

题目：半径 $R = 0.10\ \mathrm{m}$ 的细圆环均匀带电 $Q = +3.0\times10^{-8}\ \mathrm{C}$。(1) 求轴线上距环心 $x = 0.10\ \mathrm{m}$ 处 P 点的电势与场强；(2) 轴线上场强最大的位置在哪里？最大场强多大？

思路起点：连续带电体 → 微元法。电势是标量，直接积分（3.1 节样板一）；场强不必重做矢量积分——对 $\varphi(x)$ 求一次导数即可（$E_x = -\dfrac{\mathrm{d}\varphi}{\mathrm{d}x}$）。第 (2) 问是函数极值：对 $E(x)$ 再求一次导找驻点。

解析：(1) 由 3.1 节：

$$\varphi(x) = \frac{kQ}{\sqrt{R^2+x^2}} = \frac{9.0\times10^9\times3.0\times10^{-8}}{\sqrt{0.10^2+0.10^2}} = \frac{270}{\sqrt{0.02}} = \frac{270}{0.1414} \approx \boxed{1.9\times10^3\ \mathrm{V}}$$ $$E(x) = \frac{kQx}{(R^2+x^2)^{3/2}} = \frac{270\times0.10}{(0.02)^{3/2}} = \frac{27}{2.83\times10^{-3}} \approx \boxed{9.5\times10^3\ \mathrm{N/C}}$$

方向沿轴背离环心（$Q > 0$）。复核：$-\varphi'(x) = kQx(R^2+x^2)^{-3/2}$，与场强公式一致 ✓。

(2) 对 $E(x) = kQx(R^2+x^2)^{-3/2}$ 求导并令其为零：

$$\frac{\mathrm{d}E}{\mathrm{d}x} = kQ\left[(R^2+x^2)^{-3/2} - 3x^2(R^2+x^2)^{-5/2}\right] = kQ\,\frac{R^2 - 2x^2}{(R^2+x^2)^{5/2}} = 0$$ $$\Rightarrow\ R^2 = 2x^2 \ \Rightarrow\ \boxed{x = \frac{R}{\sqrt2} \approx 7.1\ \mathrm{cm}}$$

代回求最大值（注意 $(\tfrac32 R^2)^{3/2} = \tfrac{3\sqrt3}{2\sqrt2}R^3$）：

$$E_{\max} = \frac{kQ\cdot R/\sqrt2}{\left(\frac32 R^2\right)^{3/2}} = \frac{2kQ}{3\sqrt3\,R^2} = \frac{2\times270}{3\times1.732\times0.01} \approx \boxed{1.04\times10^4\ \mathrm{N/C}}$$

点评：本题是预赛风格的标配——"先标量积分，再求导拿矢量"。请顺手记住两个反直觉点：环心处 $\varphi$ 最大而 $E = 0$；场强最大值既不在环心也不在无穷远，而在 $x = R/\sqrt2$ 处。这正是"E 与 φ 各自独立、又由求导相连"的最好注解。

例 3　导体球壳里的点电荷：感应电荷与静电屏蔽

题目：不带电的空腔导体球壳（内半径 $a = 5\ \mathrm{cm}$、外半径 $b = 10\ \mathrm{cm}$），腔内中心固定一点电荷 $q = +1.0\times10^{-8}\ \mathrm{C}$。(1) 求球壳内、外表面各感应出多少电荷；(2) 求球壳外 $r = 20\ \mathrm{cm}$ 处的场强与球壳的电势；(3) 若把球壳接地，以上结果如何变化？

思路起点：静电平衡的核心方程只有一条——导体材料内部合场强为零。在导体材料内取一个包围内表面的球面，内部 $E = 0$ 意味着面内总电荷为零，由此锁住内表面电荷；再用电荷守恒推外表面。

解析：(1) 在导体材料内（$a < r < b$）取同心球面。静电平衡时该面上 $E = 0$ 处处成立，由对称性这意味着面内净电荷为零：

$$q + q_{内表面} = 0 \ \Rightarrow\ \boxed{q_{内表面} = -q = -1.0\times10^{-8}\ \mathrm{C}}$$

球壳原来不带电，电荷守恒：

$$q_{内表面} + q_{外表面} = 0 \ \Rightarrow\ \boxed{q_{外表面} = +q = +1.0\times10^{-8}\ \mathrm{C}}$$

（物理图像：点电荷发出的电场线终止于内表面的 $-q$；外表面 $+q$ 另起炉灶向外发电场线。）

(2) 整个体系球对称。球外空间的总电荷（点电荷 $+$ 内表面 $+$ 外表面）等效于集中在球心的 $+q$：

$$E_{外} = \frac{kq}{r^2} = \frac{9.0\times10^9\times1.0\times10^{-8}}{0.20^2} = \frac{90}{0.04} = \boxed{2.25\times10^3\ \mathrm{N/C}}$$

球壳是等势体，其电势等于外表面处电势（外部场由等效球心电荷 $+q$ 产生）：

$$\varphi_{壳} = \frac{kq}{b} = \frac{90}{0.10} = \boxed{900\ \mathrm{V}}$$

(3) 接地后，球壳电势被钳为 $0$：外表面的 $+q$ 沿导线流入大地（正电荷从高电势流向零电势，合理），外表面电荷清零。于是：

  • 球外空间 $E = 0$，外部世界完全"不知道"腔内有个电荷——接地屏蔽内场
  • 内表面 $-q$ 不动（它被腔内 $+q$ 的电场线拴住），腔内场强分布不变
  • 复核电势：腔外无场 → 从无穷远到球壳移动电荷不做功 → 球壳电势确为 $0$ ✓

点评：注意屏蔽的机理不是"导体挡住了电场线"，而是感应电荷的场与外场精确抵消。把这条机理想通，"为什么接地才能屏蔽内场"就不再是背诵题：不接地时外表面 $+q$ 照样对外辐射，只有接地才能把它"抽走"。

例 4　电容器串联后并联：电量守恒的能量账

题目：$C_1 = 2\ \mathrm{\mu F}$、$C_2 = 4\ \mathrm{\mu F}$ 串联后接在 $U = 300\ \mathrm{V}$ 电源上，稳定后：(1) 求各电容器的电量与电压；(2) 求系统总储能；(3) 断开电源，把两电容正极对正极、负极对负极并联，求最终公共电压与总储能——少了的能量去哪了？

思路起点：串联时中间孤岛（两电容相连的两块极板）总电荷守恒且为零 → 两电容电量相同。断开电源后并联：极板上的总电荷无处可逃（电荷守恒），按新电容重新分配，直到两电容电压相等。

解析：(1) 串联等效电容：

$$C_{串} = \frac{C_1 C_2}{C_1 + C_2} = \frac{2\times4}{2+4} = \frac{4}{3}\ \mathrm{\mu F}$$ $$Q = C_{串}U = \frac{4}{3}\times 300 = 400\ \mathrm{\mu C}$$ $$U_1 = \frac{Q}{C_1} = \frac{400}{2} = \boxed{200\ \mathrm{V}}, \qquad U_2 = \frac{Q}{C_2} = \frac{400}{4} = \boxed{100\ \mathrm{V}}\quad(200+100=300\ ✓)$$

(2) 总储能：

$$W = \frac{1}{2}C_{串}U^2 = \frac{1}{2}\times\frac{4}{3}\times10^{-6}\times300^2 = \boxed{6.0\times10^{-2}\ \mathrm{J} = 60\ \mathrm{mJ}}$$

（分算验证：$\frac12\times2\times10^{-6}\times200^2 + \frac12\times4\times10^{-6}\times100^2 = 0.040 + 0.020 = 0.060\ \mathrm{J}$ ✓）

(3) 断开电源后并联。两对极板总电荷守恒：$Q_{总} = 400 + 400 = 800\ \mathrm{\mu C}$，并联总电容 $C_{并} = 2 + 4 = 6\ \mathrm{\mu F}$：

$$U' = \frac{Q_{总}}{C_{并}} = \frac{800}{6} \approx \boxed{133\ \mathrm{V}}$$ $$W' = \frac{1}{2}C_{并}U'^2 = \frac{1}{2}\times6\times10^{-6}\times\left(\frac{400}{3}\right)^2 \approx \boxed{5.3\times10^{-2}\ \mathrm{J} = 53\ \mathrm{mJ}}$$

能量差额 $\Delta W = 60 - 53.3 \approx 6.7\ \mathrm{mJ}$ ——并联瞬间电荷重新分配，连接导线中有瞬时电流，差额以焦耳热形式耗散（若过程剧烈还有火花与电磁辐射）。点评：这类"重连后能量变少"的题，能量不守恒的假象总能在"发热"上找到出口。另外体会流程：断电源 → Q 守恒，这是电容器动态分析的第二板斧。

例 5　电源最大输出功率：最大功率不等于最高效率

题目：电源电动势 $E = 12\ \mathrm{V}$、内阻 $r = 2\ \Omega$，外接可调电阻 $R$。(1) $R$ 取何值时电源输出功率最大？最大值是多少？(2) 此时电源的效率是多少？(3) 若 $R = 6\ \Omega$，输出功率与效率又各是多少？

思路起点：写出 $P_{出}(R)$ 的函数式，用均值不等式（或求导）找极值；效率 $\eta = \dfrac{U}{E} = \dfrac{R}{R+r}$ 另行计算，与功率峰值不是同一回事。

解析：(1) $P_{出} = \dfrac{E^2 R}{(R+r)^2}$。由 $(R+r)^2 \ge 4Rr$（展开即 $(R-r)^2 \ge 0$），等号在 $R = r$ 时成立：

$$R = r = \boxed{2\ \Omega}, \qquad P_{出\max} = \frac{E^2}{4r} = \frac{12^2}{4\times2} = \boxed{18\ \mathrm{W}}$$

（验证：$I = \dfrac{12}{2+2} = 3\ \mathrm{A}$，$P = I^2 R = 9\times2 = 18\ \mathrm{W}$ ✓）

(2) 此时效率：

$$\eta = \frac{P_{出}}{P_{总}} = \frac{R}{R+r} = \frac{2}{4} = \boxed{50\%}$$

(3) $R = 6\ \Omega$ 时：$I = \dfrac{12}{6+2} = 1.5\ \mathrm{A}$，

$$P_{出} = I^2 R = 1.5^2\times6 = \boxed{13.5\ \mathrm{W}}, \qquad \eta = \frac{6}{8} = \boxed{75\%}$$

点评：$R = 6\ \Omega$ 时功率小了 $25\%$，效率却高了 $25$ 个百分点。工程上要"功率大"还是要"效率高"，看场景：信号源要最大功率传输（阻抗匹配），电力系统要高效率（绝不能让 $R = r$）。竞赛卷上见到"最大功率"，条件反射 $R = r$；见到"效率"，老老实实用 $\eta = \dfrac{R}{R+r}$。

例 6　不平衡电桥：节点电势法全程示范【预赛难度】

题目：惠斯通电桥四个臂为 $R_1 = 2\ \Omega$（A—B）、$R_2 = 4\ \Omega$（B—C）、$R_3 = 1\ \Omega$（A—D）、$R_4 = 3\ \Omega$（D—C），桥支路 B—D 间接 $R_g = 1\ \Omega$。电源 $E = 6\ \mathrm{V}$（内阻不计）接在 A、C 之间。求通过 $R_g$ 的电流。

思路起点：先查平衡条件 $\dfrac{R_1}{R_2} = \dfrac{R_3}{R_4}$？$\dfrac{2}{4} = 0.5 \ne \dfrac{1}{3}$——不平衡，桥上有电流，串并联全部失效。上节点电势法：设 $\varphi_A = 6\ \mathrm{V}$、$\varphi_C = 0$，未知数只有 $\varphi_B = V_1$、$\varphi_D = V_2$ 两个，对每个节点写"流入 = 流出"。

解析：节点 B（流入的电流 $=$ 流出的电流）：

$$\frac{6 - V_1}{2} = \frac{V_1}{4} + \frac{V_1 - V_2}{1} \ \Rightarrow\ 12 - 2V_1 = 5V_1 - 4V_2 \ \Rightarrow\ 7V_1 - 4V_2 = 12$$

节点 D：

$$\frac{6 - V_2}{1} + \frac{V_1 - V_2}{1} = \frac{V_2}{3} \ \Rightarrow\ 18 + 3V_1 = 7V_2$$

联立：第一式乘 7、第二式乘 4 相加，$84 + 72 + 12V_1 = 49V_1$，得

$$V_1 = \frac{156}{37} \approx 4.22\ \mathrm{V}, \qquad V_2 = \frac{18 + 3V_1}{7} = \frac{162}{37} \approx 4.38\ \mathrm{V}$$

桥支路电流：

$$I_g = \frac{V_1 - V_2}{R_g} = \frac{156/37 - 162/37}{1} = -\frac{6}{37} \approx \boxed{-0.16\ \mathrm{A}}$$

负号的含义：实际方向与假设相反，即电流从 D 流向 B，大小 $\dfrac{6}{37} \approx 0.16\ \mathrm{A}$。方向合理吗？$\dfrac{R_3}{R_4} < \dfrac{R_1}{R_2}$，D 点"分得"的电压高于 B 点，电流由 D 流向 B ✓。

全套检验：$I_1 = \dfrac{6-4.22}{2} = 0.89\ \mathrm{A}$，$I_2 = \dfrac{4.22}{4} = 1.05\ \mathrm{A}$，$I_1 + I_g = 0.89 + 0.16 = 1.05 = I_2$ ✓；总电流 $I_{总} = I_1 + I_3 = 0.89 + 1.62 = \dfrac{93}{37}\ \mathrm{A}$，总电阻 $R_{总} = \dfrac{6}{93/37} = \dfrac{74}{31} \approx 2.39\ \Omega$——与 3.3 节 Y-Δ 变换的结果一致 ✓。两套方法互相印证，这就是竞赛答卷的保险丝。

点评：节点电势法的机械美在于：未知数只有节点电势，方程只有 KCL，方向全靠假设、正负交给方程。两个节点两个方程，三元一次方程组都不用。这方法请练到条件反射。

例 7　立方体电阻网络：对称性的华丽演出【复赛难度】

题目：12 根阻值均为 $R = 12\ \Omega$ 的电阻丝焊成立方体框架。求体对角线两端 A、G 之间的等效电阻。

思路起点：既不串也不并——但结构关于体对角线 AG 高度对称。设电流 $I$ 从 A 流入、G 流出。A 的三条邻边地位完全相同 → 电流均分；与 A 相邻的三个顶点 B、D、E 等势；同理与 G 相邻的 C、F、H 等势。等势点短接，网络折叠成三段串并联。

解析：由对称性，$\varphi_B = \varphi_D = \varphi_E$（若有差异，轮换三顶点电路不变而电势变，矛盾），$\varphi_C = \varphi_F = \varphi_H$。将两组等势点分别短接，电路分三段：

  1. A → {B, D, E}：3 个 $R$ 并联，$R^{(1)} = \dfrac{R}{3}$
  2. {B, D, E} → {C, F, H}：B—C、B—F、D—C、D—H、E—F、E—H 共 6 条棱，6 个 $R$ 并联，$R^{(2)} = \dfrac{R}{6}$
  3. {C, F, H} → G：3 个 $R$ 并联，$R^{(3)} = \dfrac{R}{3}$

三段串联：

$$R_{AG} = \frac{R}{3} + \frac{R}{6} + \frac{R}{3} = \boxed{\frac{5}{6}R} = \frac{5}{6}\times12 = \boxed{10\ \Omega}$$

电流复核：设 $I$ 从 A 注入，三条边各分 $\dfrac{I}{3}$；到 B 后再均分到 B—C、B—F 两条"中层"边，每条 $\dfrac{I}{6}$；中层 6 条边电流合计 $I$ ✓；汇入 G 的三条边各收 $\dfrac{I}{3}$（C 点收 B、D 两路各 $\dfrac{I}{6}$，合 $\dfrac{I}{3}$）✓。全部自洽。

点评：$\dfrac{5}{6}R$ 是复赛题库里的经典答案。同一套路还能问：面对角线两端等效电阻为 $\dfrac{7}{12}R = 7\ \Omega$（对称面只剩一个，需配合 Y-Δ 变换），棱两端为 $\dfrac{3}{4}R$。先吃透体对角线这个最对称的情形，再去挑战面对角线——竞赛的难度阶梯就是这样一级级搭起来的。

五、易错点

易错点 1：电势叠加当矢量算。电势是标量，叠加是带正负号的代数和。求两个异号电荷连线中点的电势，正确做法是 $\varphi = \dfrac{kQ}{r} + \dfrac{k(-Q)}{r} = 0$，而不是"两场强抵消所以电势为零"——场强在中点恰恰是加倍的。矢量、标量，两条轨道别串线。
易错点 2：以为"场强为零 ⇔ 电势为零"。两个经典反例背下来：① 等量同号电荷连线中点：$E = 0$（对称抵消）但 $\varphi = \dfrac{2kQ}{r} \ne 0$；② 等量异号电荷中垂线上各点：$\varphi = 0$（代数和抵消）但 $E \ne 0$（方向都指向负电荷一侧）。E 看的是"φ 的变化率"，φ 看的是"绝对高度"，零不零各自独立。
易错点 3：导体内部 $E=0$ 误读成"感应电荷不产生场"。真相是：外电荷的场 $\vec E_0$ 与感应电荷的场 $\vec E'$ 在导体内部叠加抵消：$\vec E_0 + \vec E' = 0$。所以"感应电荷在导体内部产生的场"恰恰是 $-\vec E_0$，并不为零。用叠加的眼光看静电屏蔽，例 3 那种"内表面电荷被电场线拴住"的定量分析才写得出来。
易错点 4：电容器串并联公式记反、又与电池串联混用。电容器串联用倒数和（$\frac1C = \frac1{C_1}+\frac1C_2$，与电阻并联同形）、并联用直接相加——与电阻的规律恰好相反。更隐蔽的混淆：电池串联是"电压相加、电流相同"，电容串联是"电量相同、电压相加"——电容器串联时各极板电量相等靠的是孤岛电荷守恒，不是"串联电流相等"，稳定后电路里根本没有电流。
易错点 5：电容器动态分析不先判断"谁不变"。接在电源上 → $U$ 被电源钳死；断开电源 → $Q$ 无处可逃。有人插介质时既不判 $U$ 也不判 $Q$，直接 $C$ 变 $\varepsilon_r$ 倍就说"$U$ 也变 $\varepsilon_r$ 倍"，全错。标准流程：先定不变量 → $C$ 怎么变 → 用 $Q = CU$ 推另一量 → $E = \dfrac{U}{d}$ 收场。例 4 的第 (3) 问就是"断电源、Q 守恒"的完整示范。
易错点 6：$E = \dfrac{U}{d}$ 乱用。该式只在匀强电场成立，且 $d$ 必须是沿场强方向的距离。点电荷的场里用它算"电压"是原则性错误（点电荷场要用 $\varphi = \dfrac{kQ}{r}$）；匀强场里两点连线与场强成角时，$U = Ed\cos\theta$——忘记投影因子 $\cos\theta$ 是高频失分点。
易错点 7：基尔霍夫方程的符号约定一题两制。电流方向、绕行方向、升降压规则，开题时各定一次，全题死守。常见翻车：解出 $I = -0.16\ \mathrm{A}$ 后，下一步列方程又擅自把方向"改正过来"代入，导致双重变号。记住：负号是结果，不是错误——保留假设方向与负号，最后统一解读"实际反向"。节点电势法（例 6）把方向问题压缩到最少，强烈推荐。
易错点 8：最大功率与最高效率混为一谈；等势点短接越界使用。① $R = r$ 时输出功率最大，但效率只有 50%；要效率高，$R$ 越大越好——两者诉求相反，题目问哪个答哪个。② 等势点短接（例 7）只在严格对称时合法；某条棱阻值换一下，立方体的对称就破了，此时只能退回节点电势法或 Y-Δ 变换硬算。对称性工具用之前，先论证对称性成立。

08 热 学

物理竞赛专题（12 章系列 · 第 8 章） ｜ 适用：高一竞赛入门（目标：预赛 → 复赛入门） ｜ 前置：01 竞赛数学工具（小量与积分思想）、04 功与能量 ｜ 学生：小兵

热学是竞赛里出了名的"纸老虎"章节：公式数量不多，核心就三条——状态方程、热力学第一定律、循环效率。真正拉开差距的是符号约定和过程分析：同样是"气体膨胀"，等温、等压、绝热的算法完全不同。本章我们从"打气筒为什么会发热"这种生活现象出发，把每条公式推一遍、每张 p-V 图画一遍。你只要带上演算纸，跟着一步步算，热学完全可以变成你的稳定得分区。

一、知识全景

热学研究的对象是大量分子组成的系统。它的迷人之处在于"两条腿走路"：一条是宏观的热力学（压强、体积、温度、热量、功），一条是微观的分子动理论（分子的无规则运动）。竞赛题往往让这两条腿交替前进——用微观解释宏观，用宏观约束微观。

二、核心概念

2.1 理想气体状态方程

一定质量的理想气体，三个状态参量 $p$、$V$、$T$ 被一条方程捆在一起：

$$\boldsymbol{pV = nRT = \frac{m}{M}RT}$$
  • $n$：物质的量（mol）；$m$：气体质量；$M$：摩尔质量（如氧气 $M = 32\ \mathrm{g/mol} = 0.032\ \mathrm{kg/mol}$）
  • $R = 8.31\ \mathrm{J/(mol\cdot K)}$：普适气体常量
  • T 必须用开尔文：$T(\mathrm{K}) = t(℃) + 273.15$，平时计算取 273 即可
  • 理想气体模型：分子本身大小可忽略、分子间无相互作用力（除碰撞瞬间）。常温常压下的真实气体都是很好的理想气体

质量不变时，任意两个状态之间满足：

$$\frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2} = \text{常量}$$
过程不变的量规律名称
等温T$p_1V_1 = p_2V_2$玻意耳定律
等压p$\dfrac{V_1}{T_1} = \dfrac{V_2}{T_2}$盖-吕萨克定律
等容V$\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$查理定律
压强单位速查：$1\ \mathrm{atm} = 1.01\times10^{5}\ \mathrm{Pa} = 76\ \mathrm{cmHg}$。竞赛计算一律换成国际单位：压强用 Pa、体积用 m³（$1\ \mathrm{L} = 10^{-3}\ \mathrm{m^3}$）、温度用 K，功和能量自然就出来焦耳了。

2.2 微观图景：压强和温度到底是什么

气体压强不是"气体的重量"，而是无数分子撞击器壁的平均效果。用分子动理论可以推出（复赛入门会要求）：

$$p = \frac{2}{3} n_0\, \overline{\varepsilon_k} \qquad \overline{\varepsilon_k} = \frac{1}{2}m_0\overline{v^2}$$

其中 $n_0$ 是分子数密度，$\overline{\varepsilon_k}$ 是分子的平均平动动能。与状态方程对比，得到本章最重要的一座桥：

$$\boldsymbol{\overline{\varepsilon_k} = \frac{3}{2}kT} \qquad k = 1.38\times10^{-23}\ \mathrm{J/K}\ \text{（玻尔兹曼常量）}$$
  • 温度是分子平均平动动能的量度——温度越高，分子撞得越凶。这就是"温度"的微观本质。
  • 由此可得分子的方均根速率：$v_{\mathrm{rms}} = \sqrt{\overline{v^2}} = \sqrt{\dfrac{3kT}{m_0}} = \sqrt{\dfrac{3RT}{M}}$
  • 估算一下：0 ℃（273 K）的氧气，$v_{\mathrm{rms}} = \sqrt{\dfrac{3\times8.31\times273}{0.032}} \approx 461\ \mathrm{m/s}$——比声音还快！气体分子其实很"忙碌"。

2.3 内能：理想气体的内能只由温度决定

理想气体分子间没有相互作用，没有分子势能，内能就是所有分子动能的总和。因此：

$$U = n\,C_V T \qquad\Rightarrow\qquad \boldsymbol{\Delta U = nC_V\,\Delta T}$$

其中 $C_V$ 是等容摩尔热容，由分子结构决定：

气体类型例子$C_V$$C_p = C_V + R$$\gamma = C_p/C_V$
单原子He、Ne、Ar$\dfrac{3}{2}R$$\dfrac{5}{2}R$$\dfrac{5}{3} \approx 1.67$
双原子（常温）N₂、O₂、H₂、空气$\dfrac{5}{2}R$$\dfrac{7}{2}R$$\dfrac{7}{5} = 1.40$

为什么双原子是 $\frac{5}{2}R$？单原子分子只有 3 个平动自由度，每个自由度贡献 $\frac{1}{2}kT$ 的能量（能量均分定理），所以 $U = \frac{3}{2}nRT$。双原子分子多出 2 个转动自由度（绕垂直于分子轴的两个方向转），能量变成 $\frac{5}{2}nRT$。这个结论竞赛里当作已知直接用，推导属于大学内容，记住数字 $3/2$、$5/2$、$7/2$ 就够了。

千万注意：$\Delta U = nC_V\Delta T$ 对任何过程（不只等容）都成立——因为内能只看温度，不看过程。这是 $C_V$ 下标"V"最容易误导人的地方，见易错点 3。

2.4 热力学第一定律：本章的"宪法"

热力学第一定律就是能量守恒在热现象中的表达式。全章统一采用如下约定（写在卷子第一行，永远不反悔）：

$$\boldsymbol{\Delta U = Q + W}$$
  • $Q$：气体从外界吸收的热量。吸热 $Q > 0$，放热 $Q < 0$
  • $W$：外界对气体所做的功。气体被压缩时 $W > 0$；气体膨胀对外做功时 $W < 0$
  • 口诀："吸热为正、被压为正"——都是外界给气体"输送"能量的方式
约定警告：很多教材（包括部分高中课本）写的是 $\Delta U = Q - W'$，那里的 $W'$ 是"气体对外做功"，膨胀时 $W' > 0$。两种写法物理完全一样，只是 $W = -W'$。本书全章用 $\Delta U = Q + W$（$W$ 为外界对气体做功）。以后看任何资料，先确认它的 $W$ 是"谁对谁"，再动笔。

准静态过程中功的计算：p-V 图的面积

气体缓慢（准静态）膨胀时，外界对气体做功：

$$W = -\int_{V_1}^{V_2} p\,\mathrm{d}V \qquad\text{（负号来自我们的约定）}$$

几何意义：p-V 图线下方的面积 = 气体对外做的功（即 $-W$）。

  • 等压过程：$W = -p\,\Delta V = -nR\,\Delta T$（用状态方程代换，非常好用）
  • 等容过程：$\Delta V = 0 \Rightarrow W = 0$，所以 $Q = \Delta U$——这正是 $C_V$ 名字的由来
  • 等温过程（理想气体 $\Delta U = 0$）：$Q = -W = nRT\ln\dfrac{V_2}{V_1}$（推导见竞赛专属节）
  • 循环一周：净功 = 闭合曲线所围面积；顺时针循环气体对外做正功（热机），逆时针为负（制冷机）

2.6 循环过程与热机效率

系统经过一系列变化回到初态，叫循环。循环一周 $\Delta U = 0$（内能是状态量，回家就等于没变），所以第一定律给出：

$$Q_{净} + W_{净} = 0 \quad\Rightarrow\quad \text{气体对外净功} = Q_1 - Q_2$$

其中 $Q_1$ 是所有吸热段吸的总热量（取正），$Q_2$ 是所有放热段放出的总热量（取绝对值）。热机效率定义为"花多少热、出多少功"：

$$\boldsymbol{\eta = \frac{W_{输出}}{Q_1} = \frac{Q_1 - Q_2}{Q_1} = 1 - \frac{Q_2}{Q_1}}$$
  • 永远 $\eta < 1$——热量不可能全部变功（这是第二定律的味道，后面细说）
  • 制冷机（热机倒着跑）不用效率，而用制冷系数：$\varepsilon = \dfrac{Q_2}{W_{输入}}$——从冷室抽走的热 ÷ 消耗的功。注意 $\varepsilon$ 可以大于 1，好空调 $\varepsilon$ 能到 3 以上
卡诺定理（先用，证明在竞赛专属节）：工作在高温热源 $T_1$ 与低温热源 $T_2$（开尔文）之间的所有热机，效率最高的是可逆卡诺热机： $$\boldsymbol{\eta_{卡} = 1 - \frac{T_2}{T_1}}$$ 它只取决于两个热源的温度。蒸汽机 $T_1 = 600\ \mathrm{K}$、$T_2 = 300\ \mathrm{K}$ 时，$\eta_{卡} = 50\%$——这已经是上限，实际蒸汽机只有 15% 左右，热机的效率天花板远比想象中低。

三、竞赛专属·高考不考：绝热方程 pV^γ 的推导、卡诺效率的证明与熵的统计解释

这一节是预赛、复赛和高考的分水岭。内容听起来"硬核"，其实每条推导只用到一个数学动作——分离变量积分。跟着推一遍，你会发现它们远没有传说中可怕。

3.1 绝热过程方程：$pV^{\gamma} = \text{常量}$ 的推导

出发点：准静态绝热过程，$Q = 0$，第一定律变成 $\mathrm{d}U = \mathrm{d}W$，即

$$nC_V\,\mathrm{d}T = -p\,\mathrm{d}V$$

用状态方程 $p = \dfrac{nRT}{V}$ 消去 $p$，分离变量：

$$C_V\frac{\mathrm{d}T}{T} = -R\,\frac{\mathrm{d}V}{V}$$

两边积分（$C_V$、$R$ 都是常数）：

$$C_V\ln T + R\ln V = \text{常量} \;\Rightarrow\; \ln\left(T\,V^{R/C_V}\right) = \text{常量}$$

记 $\gamma = \dfrac{C_p}{C_V} = \dfrac{C_V + R}{C_V}$，则 $\dfrac{R}{C_V} = \gamma - 1$，于是：

$$\boldsymbol{TV^{\gamma-1} = \text{常量}}$$

再用 $T = \dfrac{pV}{nR}$ 代入，依次得到绝热方程的三种面孔（全都要会互相推导）：

$$\boldsymbol{pV^{\gamma} = \text{常量}} \qquad \boldsymbol{TV^{\gamma-1} = \text{常量}} \qquad \boldsymbol{\frac{T^{\gamma}}{p^{\gamma-1}} = \text{常量}}$$
绝热线为什么比等温线陡？等温线 $p = C/V$，斜率 $\dfrac{\mathrm{d}p}{\mathrm{d}V} = -\dfrac{p}{V}$；绝热线 $p = C'/V^{\gamma}$，斜率 $= -\gamma\dfrac{p}{V}$。因为 $\gamma > 1$，所以过同一点，绝热线更陡。物理图像：绝热膨胀时气体不吸热还要对外做功，只能靠降温"自掏腰包"，所以压强掉得比等温快。判图题就靠这条"陡的是绝热"。

3.2 等温功公式的推导（补 2.4 节的账）

等温过程中 $p = \dfrac{nRT}{V}$，$T$ 是常数，直接积分：

$$W = -\int_{V_1}^{V_2}\frac{nRT}{V}\,\mathrm{d}V = -nRT\ln\frac{V_2}{V_1}$$

理想气体等温 $\Delta U = 0$，故 $Q = -W = nRT\ln\dfrac{V_2}{V_1}$。膨胀（$V_2 > V_1$）时 $Q > 0$——等温膨胀必须吸热，吸的热全部变成对外做的功，"左手进右手出"。

3.3 卡诺循环效率的完整证明

卡诺循环由两条等温线 + 两条绝热线围成：$A\to B$ 等温膨胀（吸热 $Q_1$，温度 $T_1$），$B\to C$ 绝热膨胀（降温到 $T_2$），$C\to D$ 等温压缩（放热 $Q_2$），$D\to A$ 绝热压缩（回到 $T_1$）。

证明：等温段吸放热由 3.2 的公式：

$$Q_1 = nRT_1\ln\frac{V_B}{V_A}, \qquad Q_2 = nRT_2\ln\frac{V_C}{V_D}$$

两条绝热线各写一个 $TV^{\gamma-1} = \text{常量}$：

$$T_1V_B^{\gamma-1} = T_2V_C^{\gamma-1}, \qquad T_1V_A^{\gamma-1} = T_2V_D^{\gamma-1}$$

两式相除：

$$\left(\frac{V_B}{V_A}\right)^{\gamma-1} = \left(\frac{V_C}{V_D}\right)^{\gamma-1} \;\Rightarrow\; \frac{V_B}{V_A} = \frac{V_C}{V_D}$$

代回热量表达式，两个对数完全相等，于是：

$$\frac{Q_2}{Q_1} = \frac{T_2}{T_1} \;\Rightarrow\; \boldsymbol{\eta_{卡} = 1 - \frac{Q_2}{Q_1} = 1 - \frac{T_2}{T_1}}$$

证明完毕——整个推导只用了"等温功公式 + 绝热方程"，没有任何超纲内容。这也是竞赛的风格：武器都是旧的，组合是新的。

3.4 多方过程（了解即可）

$pV^{n} = \text{常量}$（$n$ 为任意常数）叫多方过程，它是一把"万能伞"：$n = 0$ 等压、$n = 1$ 等温、$n = \gamma$ 绝热、$n \to \infty$ 等容。对应的多方摩尔热容 $C = C_V + \dfrac{R}{1 - n}$，预赛偶尔出现，知道"四大过程是多方过程的特例"这层统一关系即可。

3.5 熵的初步：混乱度的物理学

先宣布热力学第二定律的两种经典表述（竞赛常考判断）：

  • 克劳修斯表述：热量不可能自发地从低温物体传到高温物体（空调必须耗电）
  • 开尔文表述：不可能从单一热源吸热全部转化为功而不产生其他影响（$\eta = 100\%$ 的热机造不出来）

第二定律的定量语言是熵 $S$。两个层面理解它：

① 宏观定义（克劳修斯）：可逆过程中

$$\mathrm{d}S = \frac{\mathrm{d}Q_{可逆}}{T} \qquad\Rightarrow\qquad \Delta S = \int_A^B \frac{\mathrm{d}Q_{可逆}}{T}$$

熵是状态量，只由初末状态决定，与路径无关——所以算不可逆过程的熵变时，可以设计一条可逆路径来算。

② 微观定义（玻尔兹曼，刻在墓碑上的公式）：

$$\boldsymbol{S = k\ln\Omega}$$

$\Omega$ 是宏观状态对应的微观状态数（"混乱度"的精确度量）。一滴墨水滴进清水，分子的排布方式数 $\Omega$ 暴增，熵就增大——这就是"墨水不会自己聚回去"的统计学原因。

熵增原理：孤立系统的熵永不减少：$\Delta S \ge 0$，可逆过程取等号。它给出了宏观过程的方向箭头——这是物理学里第一个"时间有方向"的定律。高考只要求知道"能量转化有方向性"，竞赛要求会用 $S = k\ln\Omega$ 的图像解释自由膨胀（见例 5）这类不可逆过程为什么熵增。

四、例题精讲

例 1　等压加热：把 Q、W、ΔU 三个量算清楚（衔接入门）

题目：气缸内封存 $1\ \mathrm{mol}$ 氦气（单原子理想气体），活塞可自由滑动，气体压强恒为 $1.0\times10^{5}\ \mathrm{Pa}$。用电热丝将气体从 $300\ \mathrm{K}$ 缓慢加热到 $600\ \mathrm{K}$。求：(1) 气体对外做的功；(2) 内能增量；(3) 吸收的热量。

思路起点：活塞"自由滑动"→ 压强恒定，这是等压过程。先按 2.5 节表格的三行分别算：等压功 $W = -p\Delta V = -nR\Delta T$；单原子 $C_V = \frac{3}{2}R$ 算 $\Delta U$；最后第一定律对账。

解析：

(1) 等压过程，外界对气体做功（膨胀，应为负）：

$$W = -p\,\Delta V = -nR\,\Delta T = -1\times8.31\times(600-300) = -2.49\times10^{3}\ \mathrm{J}$$

即气体对外做功 $2.49\times10^{3}\ \mathrm{J}$（约 $2.5\ \mathrm{kJ}$）。

（验证体积：$V_1 = \dfrac{nRT_1}{p} = \dfrac{8.31\times300}{1.0\times10^5} = 2.49\times10^{-2}\ \mathrm{m^3} = 24.9\ \mathrm{L}$，$V_2 = 49.9\ \mathrm{L}$，$\Delta V \approx 24.9\ \mathrm{L}$，$p\Delta V = 1.0\times10^5 \times 2.49\times10^{-2} = 2.49\times10^3\ \mathrm{J}$ ✓）

(2) 氦气是单原子，$C_V = \dfrac{3}{2}R$：

$$\Delta U = nC_V\Delta T = 1\times\frac{3}{2}\times8.31\times300 = 3.74\times10^{3}\ \mathrm{J}$$

(3) 第一定律 $\Delta U = Q + W$：

$$Q = \Delta U - W = 3.74\times10^3 - (-2.49\times10^3) = 6.23\times10^{3}\ \mathrm{J}$$

对账：等压吸热公式 $Q = nC_p\Delta T = 1\times\dfrac{5}{2}\times8.31\times300 = 6.23\times10^3\ \mathrm{J}$ ✓ 两条路结果一致。

点评：吸热 $6.23\ \mathrm{kJ}$，其中 $60\%$ 变成内能（$3.74/6.23$）、$40\%$ 变成对外做功（$2.49/6.23$）——这个 $3:2$ 的分配比例由 $C_V : R$ 决定，单原子气体等压吸热永远按 $\frac{3}{5}$ 升温、$\frac{2}{5}$ 做功分配。数字会忘，比例结构要记住。

例 2　方均根速率：温度是分子的"忙碌程度"

题目：求 $0\ ℃$ 时氧气分子和氢气分子的方均根速率，并说明同温度下谁"跑"得快。（$M_{O_2} = 0.032\ \mathrm{kg/mol}$，$M_{H_2} = 0.002\ \mathrm{kg/mol}$）

思路起点：$\overline{\varepsilon_k} = \frac{3}{2}kT$ 只含温度 → 同温度下所有气体分子平均平动动能相同；动能相同则质量小的速率大。套 $v_{\mathrm{rms}} = \sqrt{\dfrac{3RT}{M}}$。

解析：$T = 273\ \mathrm{K}$。氧气：

$$v_{O_2} = \sqrt{\frac{3RT}{M_{O_2}}} = \sqrt{\frac{3\times8.31\times273}{0.032}} = \sqrt{\frac{6805.9}{0.032}} = \sqrt{2.13\times10^{5}} \approx 461\ \mathrm{m/s}$$

氢气：

$$v_{H_2} = \sqrt{\frac{3\times8.31\times273}{0.002}} = \sqrt{3.40\times10^{6}} \approx 1.85\times10^{3}\ \mathrm{m/s}$$

比值检验：$\dfrac{v_{H_2}}{v_{O_2}} = \sqrt{\dfrac{M_{O_2}}{M_{H_2}}} = \sqrt{16} = 4$，$461\times4 = 1844\ \mathrm{m/s}$ ✓。

点评：同温度下分子平均动能相同，速率与摩尔质量的平方根成反比——"轻者快"。这解释了为什么地球大气里几乎没有氢气：氢分子速度接近逃逸速度的分量比例高，几十亿年下来跑光了；而氧、氮被地球引力牢牢锁住。一个方均根速率，串起了大气演化的故事。

例 3　矩形循环：在 p-V 图上数格子算效率【预赛难度】

题目：一定量单原子理想气体经历图示矩形循环 $A\to B\to C\to D\to A$：$A(p_A = 2\times10^{5}\ \mathrm{Pa},\ V_A = 1\times10^{-3}\ \mathrm{m^3})$，等压膨胀到 $B(V_B = 3\times10^{-3}\ \mathrm{m^3})$，再等容降压到 $C(p_C = 1\times10^{5}\ \mathrm{Pa})$，再等压压缩到 $D(V_D = 1\times10^{-3}\ \mathrm{m^3})$，最后等容升压回 $A$。求：(1) 循环一周气体对外做的净功；(2) 各段吸放热；(3) 此热机的效率。

思路起点：净功 = 闭合曲线面积（顺时针为正）。逐段用 2.5 表格算 $Q$，把 $pV$ 当作"能量记账单位"：单原子气体 $\Delta U = \frac{3}{2}\Delta(pV)$，等压热 $Q = \frac{5}{2}\Delta(pV)$——不用真的去求 $n$ 和 $T$！

解析：

(1) 净功 = 矩形面积（顺时针，气体对外做正功）：

$$W_{输出} = (p_A - p_C)(V_B - V_A) = (2-1)\times10^{5}\times(3-1)\times10^{-3} = 200\ \mathrm{J}$$

(2) 先备"记账单位"：$p_AV_A = 200\ \mathrm{J}$，$p_BV_B = 600\ \mathrm{J}$，$p_CV_C = 300\ \mathrm{J}$，$p_DV_D = 100\ \mathrm{J}$。

逐段分析（单原子 $C_V = \frac{3}{2}R$，$C_p = \frac{5}{2}R$；等容 $Q = \Delta U$，等压 $Q = nC_p\Delta T$）：

过程Δ(pV)ΔU = 3/2·Δ(pV)W（外界对气体）Q = ΔU − W
A→B 等压膨胀$+400$$+600$$-p\Delta V = -400$$Q = 600+400 = +1000\ \mathrm{J}$（吸）
B→C 等容降压$-300$$-450$$0$$Q = -450\ \mathrm{J}$（放）
C→D 等压压缩$-200$$-300$$-p\Delta V = +200$$Q = -300-200 = -500\ \mathrm{J}$（放）
D→A 等容升压$+100$$+150$$0$$Q = +150\ \mathrm{J}$（吸）

（检验：四段 $\Delta U$ 之和 $600-450-300+150 = 0$ ✓，回到初态内能必须归零。）

(3) 吸热总量 $Q_1 = 1000 + 150 = 1150\ \mathrm{J}$，放热总量 $Q_2 = 450 + 500 = 950\ \mathrm{J}$：

$$\eta = \frac{W_{输出}}{Q_1} = \frac{200}{1150} \approx 17.4\%$$

（再验：$Q_1 - Q_2 = 1150 - 950 = 200\ \mathrm{J} = W_{输出}$ ✓ 能量守恒闭环。）

点评：三个要领——① 循环净功看面积、看方向；② $\Delta(pV)$ 记账法让你绕开 $n$、$T$ 直接算能量，这是单原子/双原子气体循环题的提速神器（双原子把 $\frac{3}{2}$、$\frac{5}{2}$ 换成 $\frac{5}{2}$、$\frac{7}{2}$ 即可）；③ 效率分母只数吸热段，D→A 等容升压也在吸热，千万别漏。

例 4　等温 + 绝热接力：两段式过程分析【预赛难度】

题目：$1\ \mathrm{mol}$ 双原子理想气体，初态 $(p_0, V_0, T_0)$。先经等温膨胀使体积加倍，再经绝热膨胀使体积再加倍（末态体积 $4V_0$）。求：(1) 末态温度与压强；(2) 全过程气体对外做的总功（用 $p_0V_0$ 表示，$\ln 2 \approx 0.693$，$2^{-2/5} \approx 0.758$）。

思路起点：分段！第一段等温 $T$ 不变，$pV$ 守恒；第二段绝热用 $TV^{\gamma-1} = \text{常量}$（双原子 $\gamma = \frac{7}{5}$，$\gamma - 1 = \frac{2}{5}$）。接力赛的关键是交接棒：第一段末态 = 第二段初态。

解析：

(1) 第一段（等温，$A \to B$）：$T_B = T_0$，$p_BV_B = p_0V_0 \Rightarrow p_B = \dfrac{p_0}{2}$，$V_B = 2V_0$。

第二段（绝热，$B \to C$）：用 $TV^{\gamma-1} = \text{常量}$：

$$T_C = T_B\left(\frac{V_B}{V_C}\right)^{\gamma-1} = T_0\left(\frac{2V_0}{4V_0}\right)^{2/5} = T_0\cdot 2^{-2/5} \approx \boldsymbol{0.758\,T_0}$$

由状态方程求末压：

$$p_C = \frac{nRT_C}{V_C} = \frac{R\times0.758\,T_0}{4V_0} = 0.758\times\frac{1}{4}\times\frac{RT_0}{V_0} \approx \boldsymbol{0.189\,p_0}$$

（其中用到 $p_0V_0 = RT_0$。也可以用 $pV^{\gamma}$ 验：$p_C = p_B\left(\frac{V_B}{V_C}\right)^{7/5} = \frac{p_0}{2}\cdot 2^{-7/5} = p_0\cdot2^{-12/5} \approx 0.189\,p_0$ ✓）

(2) 分段算功（算"气体对外做功"，即 $-W$）：

等温段：

$$W'_{AB} = nRT_0\ln\frac{V_B}{V_A} = p_0V_0\ln 2 \approx 0.693\,p_0V_0$$

绝热段（$Q = 0$，对外做功全部来自内能下降）：

$$W'_{BC} = -\Delta U = -nC_V(T_C - T_B) = \frac{5}{2}R\,(T_0 - 0.758\,T_0) = \frac{5}{2}\times0.242\,p_0V_0 \approx 0.605\,p_0V_0$$

（用 $RT_0 = p_0V_0$ 代换。）总功：

$$W'_{总} \approx (0.693 + 0.605)\,p_0V_0 \approx \boldsymbol{1.30\,p_0V_0}$$

点评：同样是体积膨胀 4 倍，若全程等温，功是 $p_0V_0\ln4 = 1.386\,p_0V_0$；等温接绝热只有 $1.30\,p_0V_0$，更少——因为绝热段降温降压，p-V 图上曲线从等温线"掉下来"（绝热线更陡），面积自然小了。算完回头在 p-V 图上画一遍，数形结合才不心虚。

例 5　自由膨胀：温度不变，但熵增加了【复赛难度】

题目：一绝热刚性容器被隔板分成两等份，左边有 $1\ \mathrm{mol}$ 理想气体，右边真空。抽去隔板，气体自由膨胀充满整个容器。(1) 末态温度如何变化？(2) 这个过程等温吗？和等温膨胀到同样体积有何区别？(3) 求熵变（用可逆等温路径计算），并说明它与熵增原理是否矛盾。

思路起点："绝热"→ $Q = 0$；"自由膨胀"（向真空）→ 没有推动任何活塞，气体不对外做功 $W = 0$。两个零进第一定律，答案立刻出来。第 (3) 问记住熵是状态量：设计一条从同一初态到同一末态的可逆等温路径来算。

解析：

(1) 容器绝热 ⇒ $Q = 0$；向真空膨胀，外界没有阻力，气体对外做功 $W = 0$。由第一定律：

$$\Delta U = Q + W = 0$$

理想气体内能只由温度决定 ⇒ $\boldsymbol{\Delta T = 0}$，末态温度不变（这就是焦耳的自由膨胀实验，是"理想气体内能只与温度有关"的实验支柱之一）。

(2) 虽然初末温度相同，但它不是等温过程：自由膨胀是剧烈的非准静态过程，中间态没有统一确定的 $p$、$T$，在 p-V 图上根本画不出一条线，只能画出首尾两个点。与可逆等温膨胀的区别：

对比项可逆等温膨胀（V → 2V）自由膨胀（V → 2V）
吸热 Q$nRT\ln2$（从热源吸）0
对外做功$nRT\ln2$0
ΔU00
可逆性可逆（可沿原路压回去，外界复原）不可逆（气体不会自己缩回左半边）

(3) 熵是状态量，初末态与"可逆等温膨胀到 2 倍体积"完全相同，沿该可逆路径计算：

$$\Delta S = \int\frac{\mathrm{d}Q_{可逆}}{T} = \frac{1}{T}\cdot nRT\ln\frac{2V}{V} = nR\ln2 = 1\times8.31\times0.693 \approx \boldsymbol{5.76\ \mathrm{J/K}}$$

$\Delta S > 0$，与熵增原理完全吻合：孤立系统（容器绝热且不做功，系统总能量不变）发生了不可逆过程，熵必须增加。

微观图像：气体可用体积加倍，每个分子的位置可能性翻倍，$\Omega$ 增大到约 $2^{N_A}$ 倍，$\Delta S = k\ln(2^{N_A}) = N_Ak\ln2 = nR\ln2$——宏观公式和微观公式严丝合缝，这就是 $S = k\ln\Omega$ 的威力。

点评：这题是复赛最爱的"概念陷阱三合一"：① "温度不变 ⇒ 等温过程"——错，等温是过程要求全程 $T$ 恒定且准静态；② "温度不变 ⇒ 没有发生任何事"——错，熵增加了；③ 算不可逆过程的熵变，用可逆路径"搭桥"。把这三条想清楚，第二定律就入门了。

例 6　恒外压绝热压缩：pV^γ 失效的典型【复赛难度】

题目：绝热气缸中有 $n\ \mathrm{mol}$ 单原子理想气体，初态 $(p_0, V_0, T_0)$，活塞外突然施加并保持恒定外压 $p_{外} = 2p_0$，气体被压缩，最终达到新的平衡。求末态温度 $T_2$ 与体积 $V_2$。

思路起点：外压"突然"加上——过程不是准静态，绝热方程 $pV^{\gamma} = \text{常量}$ 不能用（它只对准静态绝热成立）！但第一定律永远成立：绝热 $Q = 0$，$\Delta U = W = p_{外}(V_0 - V_2)$（外压恒定，外界对气体做功好算）。再配合状态方程，两个方程解两个未知量。

解析：

绝热 ⇒ $Q = 0$，第一定律：

$$\Delta U = W \;\Rightarrow\; nC_V(T_2 - T_0) = p_{外}\,(V_0 - V_2)$$

代入 $C_V = \dfrac{3}{2}R$、$p_{外} = 2p_0$ 与末态状态方程 $V_2 = \dfrac{nRT_2}{2p_0}$（平衡时气体压强 = 外压）：

$$\frac{3}{2}nR\,(T_2 - T_0) = 2p_0\left(V_0 - \frac{nRT_2}{2p_0}\right) = 2p_0V_0 - nRT_2$$

用 $p_0V_0 = nRT_0$ 代换右端第一项：

$$\frac{3}{2}nRT_2 - \frac{3}{2}nRT_0 = 2nRT_0 - nRT_2$$

两边除以 $nR$，整理：

$$\frac{3}{2}T_2 + T_2 = 2T_0 + \frac{3}{2}T_0 \;\Rightarrow\; \frac{5}{2}T_2 = \frac{7}{2}T_0 \;\Rightarrow\; \boldsymbol{T_2 = \frac{7}{5}T_0 = 1.4\,T_0}$$

$$V_2 = \frac{nRT_2}{2p_0} = \frac{7T_0/5}{2}\cdot\frac{nR}{p_0} = \frac{7}{10}V_0 = \boldsymbol{0.7\,V_0}$$

检验：$\Delta U = \frac{3}{2}nR(0.4T_0) = 0.6\,nRT_0$；$W = 2p_0\times0.3V_0 = 0.6\,p_0V_0 = 0.6\,nRT_0$ ✓ 两者相等，对账成功。

点评：若错误地套用准静态绝热方程，会得到 $T_2 = T_0\cdot2^{2/5} \approx 1.32\,T_0$，与正确答案 $1.4\,T_0$ 明显不同。判断能否用 $pV^{\gamma}$ 的标准只有一个：过程是否准静态（缓慢）。"突然加压""自由膨胀""快速压缩"都是非准静态，第一定律 + 恒外压做功才是正解。顺便体会：不可逆压缩同样体积，外界要多做功（$0.6$ vs 准静态的 $\frac{3}{2}(2^{2/5}-1) \approx 0.48\,nRT_0$），多做的功变成了气体内额外的热——不可逆是要"交税"的。

例 7　卡诺热机与卡诺冰箱：一体两面

题目：一卡诺热机工作在 $T_1 = 400\ \mathrm{K}$ 的高温热源与 $T_2 = 300\ \mathrm{K}$ 的低温热源之间，每循环从高温热源吸热 $Q_1 = 1000\ \mathrm{J}$。(1) 求每循环对外做的功与放给低温热源的热量；(2) 若让这台机器逆向运行成为制冷机（卡诺冰箱），每循环消耗同样的功，能从低温热源抽走多少热量？制冷系数是多少？

思路起点：卡诺 ⇒ 效率直接套 $\eta_{卡} = 1 - T_2/T_1$（开尔文！）。逆向运行时所有能量流反向：$Q_1$、$Q_2$、$W$ 的大小关系不变，只是箭头调头。

解析：

(1) 卡诺效率：

$$\eta_{卡} = 1 - \frac{T_2}{T_1} = 1 - \frac{300}{400} = 25\%$$ $$W = \eta_{卡}\,Q_1 = 0.25\times1000 = 250\ \mathrm{J}$$

由能量守恒 $Q_1 = W + Q_2$：

$$Q_2 = Q_1 - W = 1000 - 250 = 750\ \mathrm{J}$$

(2) 逆向运行：消耗功 $W = 250\ \mathrm{J}$，从低温热源抽热 $Q_2 = 750\ \mathrm{J}$，向高温热源放热 $Q_1 = 1000\ \mathrm{J}$（全部箭头反向，数值不变）。制冷系数：

$$\varepsilon = \frac{Q_2}{W} = \frac{750}{250} = 3$$

也可以直接套卡诺制冷系数公式：

$$\varepsilon_{卡} = \frac{T_2}{T_1 - T_2} = \frac{300}{400 - 300} = 3 \ \checkmark$$

点评：注意 $\varepsilon = 3 > 1$——这不是"效率超过 100%"，而是制冷系数的定义本来就允许大于 1：花 1 份电，搬运 3 份热。家用空调 $\varepsilon$ 在 3~4 正是这个原因，所以"用空调取暖比电暖器省电"：电暖器 1 份电最多变 1 份热，空调 1 份电能"搬"来 3 份热。物理就在电费单里。

五、易错点

易错点 1：第一定律符号约定"混搭"。最常见的翻车现场：公式背的是 $\Delta U = Q + W$，脑子里想的 $W$ 却是"气体对外做功"，膨胀时把 $W$ 当正数代入，符号当场崩溃。对策：本书约定 $\Delta U = Q + W$，$W$ 为外界对气体做功，膨胀为负、压缩为正；口诀"吸热为正、被压为正"。换参考书、看答案解析时，先确认对方的约定再对照。
易错点 2：绝热线与等温线的陡缓记反。过 p-V 图上同一点，绝热线更陡（斜率 $-\gamma p/V$，等温线 $-p/V$，$\gamma > 1$）。物理记忆法：绝热膨胀"又降压又降温"，压强掉得比等温快。判图题、比较功的大小题全指望这一条，记反了整题全反。
易错点 3：以为 $\Delta U = nC_V\Delta T$ 只能用于等容过程。$C_V$ 的下标只是定义来源（等容时测出来的热容），这个公式对理想气体的任何过程都成立——等压、绝热、任意过程，内能变化都只认温度变化。附带两个兄弟误区：① 以为"内能只与温度有关"对所有物质成立——只对理想气体成立（真实气体、液体有分子势能，相变更谈不上）；② 等压过程用 $C_V$ 算热量——等压吸热要用 $C_p = C_V + R$。
易错点 4：温度用摄氏度代入。状态方程 $pV = nRT$、卡诺效率 $\eta = 1 - T_2/T_1$、方均根速率……所有公式里的 $T$ 都是开尔文。$\eta = 1 - 27/127$（直接用 ℃）和 $\eta = 1 - 300/400$ 完全是两个数。开卷先写"$T(\mathrm{K}) = t(℃) + 273$"，形成肌肉记忆。
易错点 5：热机效率与制冷系数张冠李戴。热机 $\eta = \dfrac{W}{Q_1}$（分母是从高温吸的热）；制冷机 $\varepsilon = \dfrac{Q_2}{W}$（分子是从低温抽的热）。卡诺机 $\eta_{卡} = 1 - \dfrac{T_2}{T_1} = \dfrac{T_1 - T_2}{T_1}$，卡诺制冷 $\varepsilon_{卡} = \dfrac{T_2}{T_1 - T_2}$——注意分母不一样！另外别把"放给低温的热 $Q_2$"误当吸热代入效率公式。
易错点 6：不可逆过程乱套 $pV^{\gamma} = \text{常量}$。绝热方程的适用前提是"准静态 + 绝热"。自由膨胀、突然加压、快速压缩、气体冲进真空……都是非准静态，$pV^{\gamma}$ 一律失效，只能用 $\Delta U = Q + W$（配合恒外压做功 $W = p_{外}\Delta V$ 这类直接算法）。看到题目里"突然""迅速""抽去隔板"这些词，立刻把 $pV^{\gamma}$ 从脑子里划掉。
易错点 7："温度不变 ⇒ 不吸热"与"绝热 ⇒ 温度不变"的双重混淆。两个都是错的：等温膨胀（理想气体 $\Delta U = 0$）必须吸热来支付对外做的功，$Q = nRT\ln\frac{V_2}{V_1} \neq 0$；绝热过程 $Q = 0$ 但对外做功要靠降温支付，$T$ 一般变。判断依据永远是第一定律对账，不是"感觉"。
易错点 8：循环效率分母算错、净功方向看反。① 效率 $\eta = \dfrac{W_{输出}}{Q_{吸}}$，分母只加吸热段的热量（等容升压段也可能在吸热，如例 3 的 D→A），把放热段也加进分母会严重低估效率；② p-V 图上顺时针循环对外做正功（热机），逆时针是外界对气体做功（制冷机），面积给的是绝对值，方向要自己判。

这一章的主线只有一句话：先判断是不是简谐运动，再把 $\omega^2$ 从动力学方程里"读"出来。波的部分则是"振动的集体舞"：每个质点都在做简谐振动，错开相位排开，就形成了波；两列反向行波叠加，就站成了驻波。

二、核心概念

2.1 简谐运动：从回复力到微分方程

一个质点沿 $x$ 轴运动，若它受到的合外力（回复力）满足

$$\boldsymbol{F = -kx}$$

即大小与偏离平衡位置的位移成正比、方向总指向平衡位置，那么它做的就是简谐运动。代入牛顿第二定律 $F = ma = m x''$（$x''$ 表示 $x$ 对时间的二阶导数，即加速度）：

$$m x'' = -kx \;\Rightarrow\; \boldsymbol{x'' = -\omega^2 x}, \qquad \omega^2 = \frac{k}{m}$$
判据一句话：只要能把一个振子的动力学方程整理成 $x'' = -\omega^2 x$ 的形式（$\omega^2$ 是正常数），它就是简谐运动，周期直接读出 $T = \dfrac{2\pi}{\omega}$。这是竞赛处理一切振动问题的标准入口。

这个微分方程的通解（第 01 章我们验证过）为：

$$\boldsymbol{x(t) = A\cos(\omega t + \varphi)}$$

逐次求导得速度与加速度：

$$v(t) = x'(t) = -A\omega\sin(\omega t + \varphi), \qquad a(t) = x''(t) = -A\omega^2\cos(\omega t + \varphi) = -\omega^2 x$$

三个量的"最大值"必须张口就来：

$$v_{\max} = \omega A \quad\text{（过平衡位置）}, \qquad a_{\max} = \omega^2 A \quad\text{（最大位移处）}$$
  • 振幅 $A$ 与初相 $\varphi$ 由初始条件（$t=0$ 时的位置 $x_0$ 与速度 $v_0$）共同决定：$A = \sqrt{x_0^2 + (v_0/\omega)^2}$，$\tan\varphi = -\dfrac{v_0}{\omega x_0}$（用余弦形式时）。
  • 相位 $(\omega t + \varphi)$ 是振动的"钟表读数"：速度比位移超前 $\dfrac{\pi}{2}$，加速度比位移反相（超前 $\pi$）。
  • 机械能守恒：$E = \dfrac{1}{2}mv^2 + \dfrac{1}{2}kx^2 = \dfrac{1}{2}kA^2 = \dfrac{1}{2}m\omega^2 A^2$，动能与势能互相转化、总量不变（无阻尼时）。

2.2 弹簧振子与单摆

弹簧振子（水平与竖直都一样）

水平弹簧振子：$F = -kx$ 天然成立，$\omega = \sqrt{\dfrac{k}{m}}$，$T = 2\pi\sqrt{\dfrac{m}{k}}$。

竖直悬挂的弹簧振子：设平衡时弹簧已伸长 $x_0 = \dfrac{mg}{k}$。以平衡位置为原点、向下为正，再下移 $x$ 时合外力为

$$F = mg - k(x_0 + x) = mg - kx_0 - kx = -kx$$

重力被"平衡位置的弹力"永久抵消，剩下的仍是 $F = -kx$——竖直弹簧振子仍是同角频率的简谐运动，只是平衡位置下移了。竞赛里"换个原点消掉恒力"的手法会反复使用。

单摆（小角度近似）

摆长 $L$、摆角 $\theta$。重力沿圆弧切向的分量充当回复力（取使 $\theta$ 减小的方向为正）：

$$F_回 = -mg\sin\theta$$

当 $\theta$ 很小（$\theta \lesssim 5^\circ$，即 $\lesssim 0.087\ \mathrm{rad}$）时 $\sin\theta \approx \theta$（第 01 章的小量近似），于是

$$F_回 \approx -mg\,\theta = -\frac{mg}{L}\,x$$

其中弧长 $x = L\theta$。这是标准的 $F = -k_{效}x$，$k_{效} = \dfrac{mg}{L}$，故

$$\boldsymbol{T = 2\pi\sqrt{\frac{L}{g}}}$$

等效摆长与等效重力加速度

类型处理方法典型例子
等效摆长 找摆球实际摆动的圆心，圆心到球心的距离才是 $L$ 双线摆（$L$ = 两悬线延长交点到球心）；摆线被钉子挡住（两侧摆长不同，周期是两个"半周期"相加）
等效重力加速度 $g' = \dfrac{F_{绳,0}}{m}$：摆球在平衡位置静止时绳的拉力 ÷ 质量 加速电梯中 $g' = g \pm a$；斜面上的单摆 $g' = g\sin\theta$（沿斜面摆动时）

2.3 阻尼振动与受迫振动

  • 阻尼振动：有阻力耗散能量，振幅随时间衰减；频率近似仍等于固有频率 $f_0$（弱阻尼下）。机械能不守恒。
  • 受迫振动：系统在周期性驱动力作用下振动。达到稳定后：振动频率 = 驱动力频率 $f$，与固有频率无关（初学最易错点之一）。
  • 共振：当 $f \to f_0$ 时振幅达到最大。阻尼越小，共振峰越高越尖锐；阻尼越大，峰越矮越宽，且峰值略微偏向 $f < f_0$ 一侧（复赛只需定性知道）。
物理图像：驱动力像"推秋千"——推的节奏跟秋千自身节奏合拍时，每次推力都做正功，能量不断积累，振幅就越推越大；不合拍时，有时推有时挡，振幅上不去。共振 = 节奏合拍。

2.4 机械波：振动的传播

  • 各质点只在平衡位置附近振动，不随波迁移；传播的是振动形式、相位和能量。
  • 各质点频率 = 波源频率 $f$（由波源决定）；波速 $v$ 由介质决定；波长由两者共同决定：$\boldsymbol{v = \lambda f}$。
  • 行波方程（竞赛要求会认）：沿 $+x$ 方向传播的简谐波 $$y(x,t) = A\cos(\omega t - kx + \varphi), \qquad k = \frac{2\pi}{\lambda}\ \text{（波数）}$$ 固定 $x$ 看是振动方程，固定 $t$ 看是波形图；"$\omega t$ 与 $kx$ 反号"表示波沿 $+x$ 走。
  • 相距 $\Delta x$ 的两质点相位差 $\Delta\Phi = \dfrac{2\pi}{\lambda}\Delta x$；$\Delta x = n\lambda$ 同相，$\Delta x = (n+\tfrac12)\lambda$ 反相。

2.5 驻波：两列反向行波的叠加

两列振幅、频率相同、传播方向相反的行波叠加，用和差化积：

$$y = A\cos(\omega t - kx) + A\cos(\omega t + kx) = \boldsymbol{2A\cos(kx)\cos(\omega t)}$$

结果是"各点振幅不同、整齐划一地振动"：

  • 波腹：$|\cos kx| = 1$ 处，振幅 $2A$；位置 $x = n\dfrac{\lambda}{2}$（$n = 0,1,2,\dots$）
  • 波节：$\cos kx = 0$ 处，振幅恒为 0；位置 $x = (2n+1)\dfrac{\lambda}{4}$
  • 相邻波节（或相邻波腹）间距 $\dfrac{\lambda}{2}$；波节与相邻波腹间距 $\dfrac{\lambda}{4}$
  • 两波节之间各点同相，波节两侧反相

两类边界条件（乐器物理的核心）

系统边界条件允许波长频率（基频 $f_1$ 起）
两端固定的弦
（两端开管）		 两端都是波节（开管两端都是波腹） $L = n\dfrac{\lambda_n}{2}$，即 $\lambda_n = \dfrac{2L}{n}$ $f_n = n\dfrac{v}{2L} = n f_1$（全谐音：1、2、3、4…倍）
一端固定一端自由
（一端闭管）		 闭端波节、开端波腹 $L = (2n-1)\dfrac{\lambda_n}{4}$，即 $\lambda_n = \dfrac{4L}{2n-1}$ $f_n = (2n-1)\dfrac{v}{4L}$（只有奇次谐音：1、3、5…倍）
记忆锚点：开管（两端开）基频 $\dfrac{v}{2L}$，谐音齐全，音色"明亮"（笛子）；闭管基频 $\dfrac{v}{4L}$，只有奇次谐音，音色"闷而纯"（单簧管一类）。同长度闭管基频是开管的一半。

2.6 多普勒效应初步

波源频率 $f_0$ 不变，但观察者接收到的频率 $f'$ 因源与观察者的相对运动而改变。约定：$v$ 为介质中波速（不动），$u_s$ 为波源速率，$u_o$ 为观察者速率，相互接近取正、远离取负：

$$\boldsymbol{f' = f_0 \, \frac{v \pm u_o}{v \mp u_s}}$$
  • 观察者动（源静止）：修正分子。观察者迎着波走，单位时间多"撞上" $u_o/\lambda$ 个波峰：$f' = f_0\dfrac{v + u_o}{v}$
  • 波源动（观察者静止）：修正分母。源边发光（发声）边追自己的波，波长被压缩为 $\lambda' = \dfrac{v - u_s}{f_0}$：$f' = f_0\dfrac{v}{v - u_s}$
  • 不对称性：同样大小的速率，"源动"与"观察者动"给出的 $f'$ 不相等——因为一个有介质参照（波长在空间里被压缩），一个没有。这是高考与竞赛都爱考的辨析点。
  • 记忆：靠近 → 分子大或分母小 → $f'$ 升高（救护车驶来音调变尖）；远离 → 降低。

三、竞赛专属·高考不考：微分方程求解振动、受迫振动与共振的定量分析、驻波的能量分析

3.1 微分方程求解振动（竞赛标准动作）

竞赛里的振动题，模型五花八门（浮子、液柱、双弹簧、带电小球……），但处理流程永远一样：

  1. 找平衡位置：合外力为零的位置，取为原点；
  2. 偏离 $x$：写出合外力表达式，把恒定部分（如重力、静浮力）用平衡条件消掉；
  3. 整理成 $x'' = -\omega^2 x$：读出 $\omega^2$，得 $T = 2\pi/\omega$；
  4. 验算量纲：$\omega^2$ 的单位必须是 $\mathrm{s^{-2}}$。
为什么要会解微分方程？ 高考只要求你"背"弹簧振子和单摆两个结论；竞赛则给你一个全新模型，逼你自己推 $\omega$。方程 $x'' = -\omega^2 x$ 的通解 $x = A\cos(\omega t + \varphi)$ 是猜出来再验证的：把它代回方程，左边 $x'' = -A\omega^2\cos(\omega t + \varphi)$，右边 $-\omega^2 x = -A\omega^2\cos(\omega t + \varphi)$，恒等。物理上"猜解"完全合法——只要代入成立，由解的唯一性它就是那个解。

3.2 受迫振动的定量骨架（复赛入门）

弱阻尼振子在简谐驱动力 $F = F_0\cos\omega t$ 作用下，方程为

$$m x'' + \gamma x' + kx = F_0\cos\omega t$$

预赛只需定性结论；复赛入门要知道三件事：

  • 稳定解 $x = B\cos(\omega t - \delta)$：频率跟随驱动力，但相位落后驱动力一个 $\delta$；
  • 振幅 $B(\omega)$ 在 $\omega \approx \omega_0 = \sqrt{k/m}$ 处取最大值——速度共振恰好发生在 $\omega = \omega_0$，此时驱动力功率全部补偿阻尼损耗，这是"合拍"的定量表述；
  • 暂态过程：初始阶段是"固有振动（衰减）+ 受迫振动（保留）"的叠加，所以敲一下钟（给的是瞬态激励）听到的是固有频率，持续驱动才锁定驱动频率。

3.3 驻波的能量分析（竞赛视角）

  • 驻波不传播能量（波节是能量"堤坝"），能量在两波节之间就地转化；
  • 各质点同时过平衡位置：此时波形为一条直线、无弹性势能，能量全部是动能，且集中在波腹附近（波腹速率最大）；
  • 各质点同时到最大位移：此时各点瞬时静止、动能为零，能量全部是弹性势能，且集中在波节附近（波节处形变最剧烈）；
  • 一句话：动能住在波腹，势能住在波节，每半个周期互换一次。

小兵加油：这一节看着"超纲"，其实就是把"弹簧振子能量在动能势能间倒腾"放大成一整根弦的集体行为。竞赛的所谓深度，多半是把熟结论推到新场景。

四、例题精讲

例 1【基础】读振动方程

某质点做简谐运动，$x = 0.02\cos(5\pi t + \tfrac{\pi}{3})$（SI 制）。求：振幅、周期、最大速度、最大加速度，以及 $t = 0$ 时的位移。

思路起点：对照通解 $x = A\cos(\omega t + \varphi)$ 逐项"读数"，最大值用 $v_{\max} = \omega A$、$a_{\max} = \omega^2 A$。

解析：

对照得 $A = 0.02\ \mathrm{m}$，$\omega = 5\pi\ \mathrm{rad/s}$，$\varphi = \dfrac{\pi}{3}$。

周期：

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{5\pi} = 0.4\ \mathrm{s}$$

最大速度（过平衡位置时）：

$$v_{\max} = \omega A = 5\pi \times 0.02 = 0.1\pi \approx 0.314\ \mathrm{m/s}$$

最大加速度（最大位移处）：

$$a_{\max} = \omega^2 A = 25\pi^2 \times 0.02 = 0.5\pi^2 \approx 4.93\ \mathrm{m/s^2}$$

$t = 0$ 时：$x_0 = 0.02\cos\dfrac{\pi}{3} = 0.02 \times 0.5 = 0.01\ \mathrm{m}$。

小结：读方程题的核心是"形式对齐"。若题目给的是 $\sin$ 形式，先化成余弦或直接用同套公式，别背两套。

例 2【预赛难度】竖直弹簧振子也是简谐运动

劲度系数 $k = 20\ \mathrm{N/m}$ 的轻弹簧竖直悬挂，下端挂质量 $m = 0.5\ \mathrm{kg}$ 的小球（$g = 10\ \mathrm{m/s^2}$）。把小球从平衡位置竖直向下轻拉一小段后释放。证明小球做简谐运动并求周期。

思路起点：先找平衡位置消掉重力，再写偏离平衡位置后的合外力，凑 $F = -kx$。

解析：

平衡位置处弹簧伸长量 $x_0$ 满足 $kx_0 = mg$，即

$$x_0 = \frac{mg}{k} = \frac{0.5 \times 10}{20} = 0.25\ \mathrm{m}$$

以平衡位置为原点、竖直向下为正方向。小球位于 $x$ 处时，弹簧总伸长 $x_0 + x$，受重力 $mg$（向下）与弹力 $k(x_0 + x)$（向上），合外力

$$F = mg - k(x_0 + x) = mg - kx_0 - kx = -kx$$

（用到平衡条件 $mg = kx_0$）。于是 $ma = -kx$，即

$$x'' = -\frac{k}{m}x = -40x \;\Rightarrow\; \omega^2 = 40\ \mathrm{s^{-2}}$$

确为简谐运动（证毕），周期

$$T = 2\pi\sqrt{\frac{m}{k}} = 2\pi\sqrt{\frac{0.5}{20}} = 2\pi\sqrt{0.025} \approx 0.99\ \mathrm{s}$$
竞赛结论：竖直弹簧振子的周期与水平弹簧振子完全相同，重力只改变平衡位置，不改变 $\omega$。凡是"恒力 + 线性回复力"的系统，都可换原点消恒力。

例 3【预赛难度】钉子摆的等效摆长

摆长 $L = 1.0\ \mathrm{m}$ 的单摆，悬点正下方 $d = 0.75\ \mathrm{m}$ 处有一颗钉子。把摆球拉向一侧（摆线不碰钉一侧）小角度释放，摆到另一侧时摆线被钉子挡住，绕钉子摆动。求这个小摆角摆动的周期（$g = 9.8\ \mathrm{m/s^2}$）。

思路起点：两侧摆动圆心不同，各是半个简谐运动；总周期 = 两个半周期之和。

解析：

释放侧：绕悬点摆，摆长 $L = 1.0\ \mathrm{m}$，半个周期 $\dfrac{T_1}{2} = \pi\sqrt{\dfrac{L}{g}}$。

碰钉侧：绕钉子摆，摆长 $L' = L - d = 1.0 - 0.75 = 0.25\ \mathrm{m}$，半个周期 $\dfrac{T_2}{2} = \pi\sqrt{\dfrac{L'}{g}}$。

一个完整往返的周期为两者相加：

$$T = \pi\sqrt{\frac{L}{g}} + \pi\sqrt{\frac{L'}{g}} = \pi\left(\sqrt{\frac{1.0}{9.8}} + \sqrt{\frac{0.25}{9.8}}\right)$$ $$= \pi(0.319 + 0.160) = 0.479\pi \approx 1.50\ \mathrm{s}$$
别踩坑：不能写成 $2\pi\sqrt{\dfrac{L}{g}}$ 或 $2\pi\sqrt{\dfrac{L'}{g}}$，更不能取"平均摆长"。两侧圆心不同，周期必须分段各算半个再相加。

例 4【复赛难度】浮子的竖直振动（自己推 $\omega$）

边长 $a = 0.10\ \mathrm{m}$、密度 $\rho = 0.5\times 10^{3}\ \mathrm{kg/m^3}$ 的正方体木块浮在水面上（水的密度 $\rho_0 = 1.0\times 10^{3}\ \mathrm{kg/m^3}$，$g = 9.8\ \mathrm{m/s^2}$）。把它竖直向下轻压一小段后释放，忽略水的阻力与附加质量。证明木块做简谐运动，并求周期。

思路起点：平衡时"重力 = 浮力"；下移 $x$ 后浮力增加 $\rho_0 g S x$（$S$ 为横截面积），这个增量就是线性回复力。

解析：

横截面积 $S = a^2 = 0.01\ \mathrm{m^2}$，质量 $m = \rho a^3 = 0.5\times 10^3 \times 10^{-3} = 0.5\ \mathrm{kg}$。

平衡时浸没深度 $h_0$ 满足 $\rho_0 g S h_0 = mg$（本题 $h_0 = \dfrac{\rho}{\rho_0}a = 0.05\ \mathrm{m} < a$，合理）。

以平衡位置为原点、向下为正。木块下移 $x$（仍保持部分露出水面）时，浮力变为 $\rho_0 g S (h_0 + x)$，合外力

$$F = mg - \rho_0 g S(h_0 + x) = -\rho_0 g S\, x$$

（用平衡条件消去恒定项）。牛顿第二定律：

$$m x'' = -\rho_0 g S\, x \;\Rightarrow\; x'' = -\frac{\rho_0 g S}{m} x$$

标准形式 $x'' = -\omega^2 x$，

$$\omega^2 = \frac{\rho_0 g S}{m} = \frac{1.0\times 10^3 \times 9.8 \times 0.01}{0.5} = 196\ \mathrm{s^{-2}}$$

$\omega = 14\ \mathrm{rad/s}$，周期

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{14} \approx 0.45\ \mathrm{s}$$
手法提炼：例 2 与例 4 是同一个剧本——平衡条件消恒力，偏离量给出线性回复力。浮子、U 形管液柱（$\omega^2 = \dfrac{2g}{L}$）、小角度单摆，全都是这一句台词。

例 5【复赛难度】管乐器的谐音

声速 $v = 340\ \mathrm{m/s}$。一根长 $L = 0.34\ \mathrm{m}$ 的管，(1) 两端开口；(2) 一端开口一端封闭。分别求两种情况下能发出的前三个频率。

思路起点：先定边界（开口 = 波腹，封闭 = 波节），再由管长与波长的关系出频率序列。

解析：

(1) 开管：两端都是波腹，$L = n\dfrac{\lambda_n}{2}$，$\lambda_n = \dfrac{2L}{n}$（$n = 1,2,3,\dots$）

$$f_n = \frac{v}{\lambda_n} = n\frac{v}{2L} = n \times \frac{340}{0.68} = 500n\ \mathrm{Hz}$$

前三个：$f_1 = 500\ \mathrm{Hz}$，$f_2 = 1000\ \mathrm{Hz}$，$f_3 = 1500\ \mathrm{Hz}$（全谐音齐全）。

(2) 闭管：闭端波节、开端波腹，最短情形是"管长 = 四分之一波长"：$L = (2n-1)\dfrac{\lambda_n}{4}$，$\lambda_n = \dfrac{4L}{2n-1}$（$n = 1,2,3,\dots$）

$$f_n = \frac{v}{\lambda_n} = (2n-1)\frac{v}{4L} = (2n-1)\times\frac{340}{1.36} = 250(2n-1)\ \mathrm{Hz}$$

前三个：$f_1 = 250\ \mathrm{Hz}$，$f_2 = 750\ \mathrm{Hz}$，$f_3 = 1250\ \mathrm{Hz}$（只有奇次谐音）。

检验直觉：同长度闭管基频（250 Hz）恰为开管基频（500 Hz）的一半；吹得越急（激发高次谐音），开管音高翻倍跳，闭管隔一个奇数跳。复赛题常把"听到的频率序列"反推"管是开是闭"。

例 6【基础】多普勒效应：救护车迎面与远离

救护车警笛固有频率 $f_0 = 500\ \mathrm{Hz}$，车速 $u_s = 20\ \mathrm{m/s}$，声速 $v = 340\ \mathrm{m/s}$。路边静止的观察者求：(1) 车驶来时听到的频率；(2) 车驶过后远离时听到的频率；(3) 若车静止、观察者以 $20\ \mathrm{m/s}$ 骑车接近，听到的频率是多少？与 (1) 相等吗？

思路起点：源动修分母、观察者动修分子；靠近取使频率升高的符号。

解析：

(1) 源靠近静止观察者，波长被压缩：

$$f' = f_0\frac{v}{v - u_s} = 500\times\frac{340}{340 - 20} = 500\times\frac{340}{320} = 531.25 \approx 531\ \mathrm{Hz}$$

(2) 源远离，波长被拉长：

$$f'' = f_0\frac{v}{v + u_s} = 500\times\frac{340}{360} \approx 472\ \mathrm{Hz}$$

(3) 观察者接近静止的源，修正分子：

$$f''' = f_0\frac{v + u_o}{v} = 500\times\frac{360}{340} \approx 529\ \mathrm{Hz}$$

与 (1) 不相等（$529 \ne 531.25$）：源动改变的是空间中的波长，观察者动改变的是单位时间接收到的波峰数，物理机制不同，结果自然不同。

符号约定：套 $f' = f_0\dfrac{v \pm u_o}{v \mp u_s}$ 前先问自己"谁在动、靠近还是远离"，逐因子判断大小关系，不要死记上正下负。

例 7【预赛难度】火车过铁轨接缝的共振

火车车厢可看作"车轮 + 弹簧减振系统"，其固有周期 $T_0 = 0.8\ \mathrm{s}$。每根钢轨长 $L = 12.5\ \mathrm{m}$，车轮经过接缝时受到一次冲击。问火车以多大速度行驶时车厢上下颠簸最剧烈？换算成 $\mathrm{km/h}$ 约为多少？

思路起点：接缝冲击是周期性驱动力，周期 $T = \dfrac{L}{v}$；共振条件 $T = T_0$。

解析：

车轮每隔 $\dfrac{L}{v}$ 受一次冲击，驱动力周期 $T = \dfrac{L}{v}$。共振时驱动周期等于固有周期：

$$\frac{L}{v} = T_0 \;\Rightarrow\; v = \frac{L}{T_0} = \frac{12.5}{0.8} = 15.6\ \mathrm{m/s}$$

换算：$15.6\times 3.6 \approx 56\ \mathrm{km/h}$。

历史上火车限速曾避开这一区间，现代长轨无缝钢轨则直接消灭了驱动力——消除共振的两种思路：错开频率，或干掉激励。

模型意识：共振题 = 先认出"谁是驱动、频率多少"，再认出"固有频率多少"，最后令两者相等。洗衣机甩干时的"先抖后稳"、过桥齐步走的禁令，都是同一模型。

五、易错点（全是真会错的坑）

1. 初相只由初始位置决定？错。 $\varphi$ 由 $x_0$ 和 $v_0$（方向！）共同决定。同样从 $x = \dfrac{A}{2}$ 出发，向 $+x$ 走和向 $-x$ 走对应不同初相。定 $\varphi$ 务必同时核对 $\cos\varphi$ 与速度符号（$v_0 = -A\omega\sin\varphi$）。
2. 相位差的方向搞反。 行波 $y = A\cos(\omega t - kx)$ 中，下游（$x$ 大处）的相位是 $\omega t - kx$，比波源落后 $kx$——"波传过去需要时间，下游总是慢半拍"。沿传播方向相位递减，别记成递增。
3. 等效摆长找错圆心。 双线摆的摆长是两悬线延长线交点（瞬心）到球心的距离，不是绳长、也不是悬点到球心的竖直高度。判断口诀：球实际绕谁转，谁才是圆心。
4. 小角度近似的前提失效。 $T = 2\pi\sqrt{L/g}$ 只在 $\theta_{\max} \lesssim 5^\circ$ 时成立；摆角大时周期实际变长（$\sin\theta < \theta$，回复力比线性预言的小）。竞赛题给"大摆角"就是在考你是否意识到公式失效。
5. 受迫振动的频率张冠李戴。 稳定受迫振动的频率等于驱动力频率，不是固有频率；固有频率只决定"暂态"和"共振位置"。看到"驱动力频率 $f$，系统固有频率 $f_0$"的题目，先分清问的是稳定态还是共振条件。
6. 驻波的波腹波节位置数错。 两端固定弦：端点是波节；开管口是波腹，闭管口是波节。相邻波节间距是 $\dfrac{\lambda}{2}$ 不是 $\lambda$；基频时管长 $L = \dfrac{\lambda}{2}$（开管）或 $\dfrac{\lambda}{4}$（闭管），画个草图再数，别凭感觉。
7. 多普勒中"源动"与"观察者动"混为一谈。 源动修分母（波长被压缩/拉伸，介质参照系里发生），观察者动修分子（单位时间多收/少收波峰）。同一速率两者结果不同（例 6 已验证）。方向约定统一用"靠近升频、远离降频"现场判断，不背符号口诀。
8. 波传播时以为质点跟着走。 机械波中质点只在平衡位置附近振动，不随波迁移；传出去的是相位、波形和能量。"波形平移速度 $v$"与"质点振动速度 $v_y = -\omega A\sin(\cdots)$"是两个完全不同的速度，竞赛题常拿它们的混淆设陷阱。

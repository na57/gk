二、核心概念

2.1 用导数描述运动：从「平均」到「瞬时」

课内你学过平均速度 $\bar v = \dfrac{\Delta x}{\Delta t}$。竞赛里我们把时间间隔无限缩小，得到瞬时速度——这就是导数：

$$v = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = \frac{dx}{dt}, \qquad a = \lim_{\Delta t \to 0} \frac{\Delta v}{\Delta t} = \frac{dv}{dt} = \frac{d^2x}{dt^2}$$

几何意义：$x\text{-}t$ 图上某点切线的斜率 = 该时刻速度；$v\text{-}t$ 图上切线斜率 = 加速度。图象的「斜率、面积」两板斧，到了竞赛依然是主力。

  • 速度是矢量：一维情形用正负号表示方向；二维情形 $\vec v = \left(\dfrac{dx}{dt}, \dfrac{dy}{dt}\right)$，各分量各自求导。
  • 速率 ≠ 速度的大小之外没有别的：$|\vec v| = \sqrt{v_x^2 + v_y^2}$，而「速率的变化率」$\dfrac{d|\vec v|}{dt}$ 一般不等于加速度的大小 $|\vec a|$（详见易错点 1）。
一句话总结：知道了 $x(t)$，求导两次就能得到一切运动信息；反过来，知道了 $a(t)$ 配上初条件，积分两次也能还原一切。求导与积分是运动学的两条腿，课内只练了第一条，竞赛要两条都会走。

2.2 反问题：积分与初条件

如果 $a = \dfrac{dv}{dt}$，那么反过来：

$$v(t) = v_0 + \int_0^t a(t')\, dt', \qquad x(t) = x_0 + \int_0^t v(t')\, dt'$$

其中 $v_0 = v(0)$、$x_0 = x(0)$ 是初始条件。几何意义：$v\text{-}t$ 图线下面积 = 位移；$a\text{-}t$ 图线下面积 = 速度变化量。

检验：匀加速情形 $a = \text{常量}$，$v(t) = v_0 + at$，$x(t) = x_0 + v_0 t + \dfrac{1}{2}at^2$——课内公式自动蹦出来！这说明课内三公式只是积分的一个特例，你以后再也不怕忘公式了。

方法卡：反问题三步① 写出 $a(t)$（或 $v(t)$）；② 积分，立刻带上初条件（积分常数 $C$ 由 $t=0$ 的值定）；③ 检查量纲与 $t=0$ 时刻是否自洽。漏初条件是新手第一杀手，见易错点 2。

2.3 相对运动：换一个参考系看世界

设 A、B、C 三个对象（比如船、水、岸），速度满足合成法则：

$$\vec v_{A\text{对}C} = \vec v_{A\text{对}B} + \vec v_{B\text{对}C}$$

记忆口诀「下标接力」：左边是「A 对 C」，右边前一个矢量「从 A 出发」，后一个「到 C 结束」，中间的 B 像接力棒一样被消去。

  • 参考系变换只改变速度，不改变加速度（各参考系相对匀速时）——所以牛顿定律的形式不变。
  • 选参考系的艺术：把「追、躲、相遇」问题换到「其中一个物体静止」的参考系里，常常一步出答案（例 4 体会）。
  • 相对速度：$\vec v_{A\text{对}B} = \vec v_A - \vec v_B$（都是对同一地面系）。

2.4 抛体运动的参数化分析

以抛出点为原点，初速度 $v_0$、抛射角 $\theta$（与水平面夹角），只受重力。参数方程：

$$x = v_0\cos\theta \cdot t, \qquad y = v_0\sin\theta \cdot t - \frac{1}{2}gt^2$$

消去 $t$（用 $t = \dfrac{x}{v_0\cos\theta}$ 代入 $y$）得轨迹方程：

$$y = x\tan\theta - \frac{gx^2}{2v_0^2\cos^2\theta} = x\tan\theta - \frac{gx^2}{2v_0^2}\left(1 + \tan^2\theta\right)$$

（用到恒等式 $\dfrac{1}{\cos^2\theta} = 1 + \tan^2\theta$。）这是一条开口向下的抛物线。

同高度射程：落回 $y = 0$ 时，解 $x\tan\theta = \dfrac{gx^2}{2v_0^2\cos^2\theta}$，除去 $x=0$ 的根得

$$R = \frac{2v_0^2\sin\theta\cos\theta}{g} = \frac{v_0^2\sin 2\theta}{g}$$

当 $\sin 2\theta = 1$ 即 $\theta = 45°$ 时射程最大，$R_{\max} = \dfrac{v_0^2}{g}$。注意前提：落点与抛出点同高（易错点 4）。

2.5 圆周运动的参数化与向心加速度推导

半径 $R$、角速度 $\omega$（单位 rad/s，必须用弧度制）的匀速圆周运动，参数方程：

$$x = R\cos\omega t, \qquad y = R\sin\omega t$$

对时间求两次导数（用 $(\cos\omega t)' = -\omega\sin\omega t$，$(\sin\omega t)' = \omega\cos\omega t$）：

$$v_x = -\omega R\sin\omega t, \quad v_y = \omega R\cos\omega t \;\Rightarrow\; |\vec v| = \omega R$$ $$a_x = -\omega^2 R\cos\omega t, \quad a_y = -\omega^2 R\sin\omega t \;\Rightarrow\; \vec a = -\omega^2 \vec r$$

三个结论一目了然：

  1. 速率 $v = \omega R$（角量与线量的桥梁）；
  2. 速度方向：$\vec v \cdot \vec r = v_x x + v_y y = 0$，即速度时刻与半径垂直（沿切线）；
  3. 向心加速度：$\vec a = -\omega^2\vec r$，大小 $a_n = \omega^2 R = \dfrac{v^2}{R}$，方向时刻指向圆心（负号的意义）。
这套推导是竞赛的"见面礼"：课本告诉你 $a_n = \dfrac{v^2}{R}$，竞赛要求你自己推出来。例 7 带你完整走一遍，推过一遍终身不忘。

角量的关系与线量完全平行：

线量（直线运动）角量（圆周运动）桥梁
位移 $x$角位移 $\theta$（rad）$s = R\theta$（弧长）
速度 $v = \frac{dx}{dt}$角速度 $\omega = \frac{d\theta}{dt}$$v = \omega R$
加速度 $a = \frac{dv}{dt}$角加速度 $\beta = \frac{d\omega}{dt}$切向加速度 $a_\tau = \beta R$

三、竞赛专属·高考不考：三件新武器

下面三件事高考不考，但竞赛预赛起步就要用。它们都不难，只是「没见过」——见过一次就是你的了。

3.1 微积分反问题进阶：$a$ 不只依赖时间

课内 $a$ 是常量，竞赛里 $a$ 可以是 $t$、$v$ 甚至 $x$ 的函数。处理口诀：看 $a$ 是谁的函数，就配谁的形式。

给定形式选用变形积分得到
$a = a(t)$$dv = a(t)\,dt$$v(t)$，再积一次得 $x(t)$
$a = a(v)$$\dfrac{dv}{a(v)} = dt$$v$ 与 $t$ 的关系（分离变量）
$a = a(x)$链式：$a = \dfrac{dv}{dt} = \dfrac{dv}{dx}\cdot\dfrac{dx}{dt} = v\dfrac{dv}{dx}$$v^2$ 与 $x$ 的关系：$v\,dv = a(x)\,dx$
链式变形 $a = v\dfrac{dv}{dx}$ 是竞赛高频变形。比如弹簧振子 $a = -\dfrac{k}{m}x$，代入得 $v\,dv = -\dfrac{k}{m}x\,dx$，两边积分：$\dfrac{v^2}{2} = -\dfrac{kx^2}{2m} + C$——这就是能量守恒的雏形！你提前摸到了第 04 章的门。

3.2 抛体包络线：一支抛物线家族的「边界」

以固定速率 $v_0$ 向各个方向抛射（比如喷泉、礼花弹），所有可能的抛物线轨迹挤在一起，外包出一条边界曲线——包络线。包络线以内的点都打得到，以外的点怎么抛都打不到。

推导思路（固定 $x$，对 $\theta$ 求 $y$ 的极值）：轨迹方程中含 $\tan\theta$，记 $m = \tan\theta$，则

$$y = mx - \frac{gx^2}{2v_0^2}(1 + m^2)$$

这是关于 $m$ 的二次函数，当 $m = \dfrac{v_0^2}{gx}$ 时 $y$ 取最大值（开口向下，顶点处），代回整理得包络线方程：

$$\boldsymbol{y = \frac{v_0^2}{2g} - \frac{gx^2}{2v_0^2}}$$

三个漂亮的性质（请对照数字验证，例 6）：最高点 $\left(0, \dfrac{v_0^2}{2g}\right)$ 正好是竖直上抛的最大高度；与 $x$ 轴交点 $x = \pm\dfrac{v_0^2}{g}$ 正好是最大射程；它自己也是一条抛物线。

3.3 非直角坐标描述：自然坐标下的切向与法向

圆周运动里我们其实偷偷用了「自然坐标」：不分解到固定的 $x,y$ 轴，而是分解到运动自己的切线方向（$\tau$）和法线方向（$n$，指向凹侧）：

$$\vec a = a_\tau\,\hat\tau + a_n\,\hat n, \qquad a_\tau = \frac{dv}{dt}\ \text{（速率的变化率）}, \qquad a_n = \frac{v^2}{\rho}\ \text{（方向变化的快慢）}$$

其中 $\rho$ 是轨迹在该点的曲率半径（圆周运动 $\rho = R$）。这套分解的好处：变速圆周运动也能处理——加速圆周有 $a_\tau \ne 0$，合加速度不再指向圆心，大小 $|\vec a| = \sqrt{a_\tau^2 + a_n^2}$。这也是 3.1 节「速率变化率 ≠ 加速度大小」的精确解释：前者只是 $a_\tau$。

小兵的望远镜：极坐标（径向 + 横向）在竞赛复赛里描述天体运动才真正登场，本章只需知道「坐标系可以跟着运动走」这个思想。不用急着掌握，留个印象即可。

四、例题精讲

本章 7 道例题，全部做到「思路起点 + 不跳步解析」。建议先遮住解析自己试 5 分钟，再对照。

例 1 · 课内基础

由位置函数求速度与加速度

质点沿 $x$ 轴运动，位置 $x = 2t^3 - 5t^2 + 3$（SI 制，即 $x$ 单位 m、$t$ 单位 s）。求：(1) $v(t)$ 与 $a(t)$；(2) $t = 2\ \mathrm{s}$ 时的速度与加速度；(3) 何时速度为零？

思路起点：位置函数在手，求导两次就全有了——这是 2.1 节的直接应用。幂函数求导：$(t^n)' = nt^{n-1}$。

解析：

(1) 对 $x$ 求一阶导数：$v = \dfrac{dx}{dt} = 6t^2 - 10t$（m/s）；再求一阶：$a = \dfrac{dv}{dt} = 12t - 10$（m/s²）。

(2) 代入 $t = 2$：$v(2) = 6\times 4 - 10\times 2 = 4\ \mathrm{m/s}$；$a(2) = 24 - 10 = 14\ \mathrm{m/s^2}$。

(3) 令 $v = 0$：$6t^2 - 10t = 2t(3t - 5) = 0$，得 $t = 0$ 或 $t = \dfrac{5}{3}\ \mathrm{s} \approx 1.67\ \mathrm{s}$。$t = \frac{5}{3}\ \mathrm{s}$ 处是运动的「折返点」——质点先向 $-x$ 方向走，再掉头向 $+x$ 方向。

点评：注意 $a(0) = -10\ \mathrm{m/s^2} \ne 0$，说明 $t=0$ 时虽速度为零但加速度不为零——「速度为零」和「加速度为零」完全是两回事。

例 2 · 【预赛难度】

积分反问题：由加速度还原运动

质点沿 $x$ 轴运动，加速度 $a = 6t$（SI 制，系数 $6$ 的单位是 $\mathrm{m/s^3}$）。$t = 0$ 时 $v_0 = 2\ \mathrm{m/s}$，$x_0 = 0$。求 $v(t)$、$x(t)$，并算 $t = 2\ \mathrm{s}$ 时的速度与位置。

思路起点：$a(t)$ 已知 → 积分一次得 $v$，再积一次得 $x$。每次积分立刻用初条件定常数。

解析：

第一步，$v = \int a\,dt + C_1 = 3t^2 + C_1$。代入 $t=0$：$v(0) = C_1 = 2$，所以

$$v(t) = 3t^2 + 2\ \mathrm{(m/s)}$$

第二步，$x = \int v\,dt + C_2 = t^3 + 2t + C_2$。代入 $t=0$：$x(0) = C_2 = 0$，所以

$$x(t) = t^3 + 2t\ \mathrm{(m)}$$

第三步，$t = 2\ \mathrm{s}$：$v = 3\times 4 + 2 = 14\ \mathrm{m/s}$；$x = 8 + 4 = 12\ \mathrm{m}$。

点评：用 $a\text{-}t$ 图象检验——$a=6t$ 是过原点的直线，$0$ 到 $2\ \mathrm{s}$ 面积 $= \frac{1}{2}\times 2\times 12 = 12\ \mathrm{m/s}$，恰是速度增量 $14 - 2 = 12\ \mathrm{m/s}$ ✓。几何与代数对上了，说明没算错。

例 3 · 课内延伸

雨中打伞：相对速度的方向

无风时雨滴以 $v_2 = 4\ \mathrm{m/s}$ 竖直下落，小兵以 $v_1 = 3\ \mathrm{m/s}$ 水平骑车前进。为不让雨淋到，伞柄应与竖直方向成多大角度、向哪边倾？

思路起点：雨「打在身上」的方向 = 雨相对人的速度方向。用合成法则：$\vec v_{\text{雨对人}} = \vec v_{\text{雨对地}} - \vec v_{\text{人对地}}$。

解析：取水平向前为 $x$ 正方向、竖直向下为 $y$ 正方向。

$\vec v_{\text{雨对地}} = (0,\ 4)$，$\vec v_{\text{人对地}} = (3,\ 0)$（均为 m/s）。

所以 $\vec v_{\text{雨对人}} = (0-3,\ 4-0) = (-3,\ 4)$：水平向后 $3$、竖直向下 $4$。

大小：$|\vec v_{\text{雨对人}}| = \sqrt{3^2 + 4^2} = 5\ \mathrm{m/s}$（经典的 3-4-5 三角形）。

方向：与竖直方向夹角 $\theta$ 满足 $\tan\theta = \dfrac{3}{4}$，即 $\theta = 37°$。伞应向前倾，与竖直方向成 37°——因为雨相对人是「从前上方斜着砸过来」的。

点评：直觉的「雨是竖直的，伞竖直打」是错的——相对运动改变了雨的「来向」。这也是行船中「测风旗」、飞机侧风降落同一原理。

例 4 · 【预赛难度】

救生圈问题：换参考系一步出答案

小船在静水中速度 $u = 4\ \mathrm{m/s}$，河水流速 $w = 0.5\ \mathrm{m/s}$。船逆流而上，经过一座桥时船上掉下一个救生圈（圈随水漂流）。船继续行驶 $t = 10\ \mathrm{min}$ 后才发现，立即掉头顺流追赶。求：(1) 掉头后多久追上救生圈？(2) 从掉圈到追上，救生圈漂了多远？

思路起点：地面参考系里要算「逆流船速、顺流船速、漂移速度」，很烦。换到水的参考系：水静止，救生圈静止，船始终以 $u = 4\ \mathrm{m/s}$ 行驶——问题瞬间变成「离开再回来」。

解析：

(1) 在水参考系中：船离开静止的救生圈行驶 $10\ \mathrm{min}$，返回时距离不变、速率不变，所以返回时间也是 $10\ \mathrm{min}$。追上共需 $t' = 10\ \mathrm{min}$，从掉圈算起总历时 $20\ \mathrm{min} = 1200\ \mathrm{s}$。

(2) 回到地面参考系：救生圈以水速漂流，$s = w \times 1200\ \mathrm{s} = 0.5 \times 1200 = 600\ \mathrm{m}$。

地面系验证（建立信心）：船逆流速度 $u - w = 3.5\ \mathrm{m/s}$，$600\ \mathrm{s}$ 内上行 $3.5 \times 600 = 2100\ \mathrm{m}$；此间救生圈漂下 $0.5 \times 600 = 300\ \mathrm{m}$，掉头瞬间相距 $2400\ \mathrm{m}$。船顺流速度 $u + w = 4.5\ \mathrm{m/s}$，相对圈的接近速度 $4.5 - 0.5 = 4\ \mathrm{m/s}$，追上需 $2400 / 4 = 600\ \mathrm{s} = 10\ \mathrm{min}$ ✓ 与水系答案完全一致。

点评：注意结论「追回时间 = 离开时间」与水流速度 $w$ 无关——$w$ 只影响圈漂了多远。竞赛里「选哪个参考系」常常是整题的第一突破口。

例 5 · 【复赛难度】

斜面上的抛体：射程何时最大

在倾角 $\alpha = 30°$ 的斜面底端，以固定速率 $v_0 = 10\ \mathrm{m/s}$ 向斜面上方抛射小球（$g$ 取 $10\ \mathrm{m/s^2}$），抛射方向与水平面夹角 $\theta$ 可调。求：沿斜面射程 $R$ 的表达式、最大值及对应的 $\theta$。

思路起点：沿斜面建坐标（$x$ 沿斜面向上，$y$ 垂直斜面），重力分解为 $-g\sin\alpha$ 和 $-g\cos\alpha$ 两个分量——斜面上也是「类抛体」，只是 $g$ 拆成了两份。

解析：初速度沿斜面分量 $v_0\cos(\theta - \alpha)$，垂直斜面分量 $v_0\sin(\theta-\alpha)$。垂直方向是匀变速，落回斜面（$y=0$）时：

$$T = \frac{2v_0\sin(\theta-\alpha)}{g\cos\alpha}$$

沿斜面方向以 $-g\sin\alpha$ 减速，位移：

$$R = v_0\cos(\theta-\alpha)\,T - \frac{1}{2}g\sin\alpha\,T^2$$

代入 $T$ 化简（用 $2\sin A\cos A = \sin 2A$ 与 $\sin A\cos B$ 的积化和差），得标准结果：

$$R = \frac{2v_0^2\cos\theta\,\sin(\theta-\alpha)}{g\cos^2\alpha}$$

求极值：记 $f(\theta) = \cos\theta\sin(\theta-\alpha)$，$f'(\theta) = -\sin\theta\sin(\theta-\alpha) + \cos\theta\cos(\theta-\alpha) = \cos(2\theta - \alpha)$。令 $f' = 0$：$2\theta - \alpha = 90°$，即

$$\boldsymbol{\theta = 45° + \frac{\alpha}{2}} = 45° + 15° = 60°$$

代回（利用 $\cos(45°+\frac{\alpha}{2})\sin(45°-\frac{\alpha}{2}) = \frac{1-\sin\alpha}{2}$，因为 $\cos(45°+\frac{\alpha}{2}) = \sin(45°-\frac{\alpha}{2})$，平方后用 $\sin^2 x = \frac{1-\cos 2x}{2}$）：

$$\boldsymbol{R_{\max} = \frac{v_0^2}{g(1+\sin\alpha)}} = \frac{100}{10\times 1.5} = \frac{20}{3} \approx 6.67\ \mathrm{m}$$

点评：两个检验——$\alpha = 0$ 时退化为平地结果 $\theta = 45°$、$R_{\max} = v_0^2/g = 10\ \mathrm{m}$ ✓；直觉上「斜面越陡越抛不远」也与 $1+\sin\alpha$ 在分母上一致 ✓。最佳角 $45° + \alpha/2$ 恰是斜面方向与竖直方向夹角的角平分线方向，这个几何结论值得记住。

例 6 · 【复赛难度】

喷泉的包络线：哪里淋得到

喷泉口以速率 $v_0 = 10\ \mathrm{m/s}$ 向各方向喷水（$g = 10\ \mathrm{m/s^2}$）。(1) 写出包络线方程；(2) 花坛边缘点 $(6\ \mathrm{m},\ 3\ \mathrm{m})$ 能否被淋到？(3) 若要淋到点 $(8\ \mathrm{m},\ 2.5\ \mathrm{m})$ 呢？

思路起点：包络线内的点都能到、上的点恰好能到、外的点怎么都到不了。把点的纵坐标与包络线在同一 $x$ 处的高度比较即可。

解析：

(1) 由 3.2 节结论：

$$y = \frac{v_0^2}{2g} - \frac{gx^2}{2v_0^2} = \frac{100}{20} - \frac{10x^2}{200} = 5 - \frac{x^2}{20}\ \mathrm{(m)}$$

边界：最高点 $(0, 5\ \mathrm{m})$（竖直上抛高度 ✓），落点 $x = \pm 10\ \mathrm{m}$（最大射程 ✓）。

(2) $x = 6$ 时包络线高 $y = 5 - \dfrac{36}{20} = 3.2\ \mathrm{m}$。花坛点高 $3 < 3.2$，在包络线以内——能淋到。

(3) $x = 8$ 时包络线高 $y = 5 - \dfrac{64}{20} = 1.8\ \mathrm{m}$。目标点高 $2.5 > 1.8$，在包络线以外——淋不到，除非提高 $v_0$。

点评：「包络线」思想不只用于喷泉——雷达覆盖、炮火覆盖、安全区设计都是它。竞赛里它常与「存在性判断」（能不能打到）绑定出现。

例 7 · 课内基础（推导）

向心加速度的完整推导

质点做半径 $R = 2\ \mathrm{m}$、角速度 $\omega = 3\ \mathrm{rad/s}$ 的匀速圆周运动。(1) 写出参数方程并推导 $\vec v$、$\vec a$；(2) 求 $v$、$a_n$ 的数值；(3) 验证 $a_n = \dfrac{v^2}{R}$。

思路起点：把 2.5 节的流程完整走一遍，每一步都落笔，不许心算跳步。

解析：

(1) 参数方程：$x = 2\cos 3t$，$y = 2\sin 3t$（m）。

一阶导数：$v_x = -6\sin 3t$，$v_y = 6\cos 3t$（m/s）。

二阶导数：$a_x = -18\cos 3t$，$a_y = -18\sin 3t$（m/s²）。

(2) 速率：$v = \sqrt{36\sin^2 3t + 36\cos^2 3t} = 6\ \mathrm{m/s}$（$= \omega R = 3\times 2$ ✓）。

加速度大小：$a_n = \sqrt{18^2\cos^2 3t + 18^2\sin^2 3t} = 18\ \mathrm{m/s^2}$（$= \omega^2 R = 9\times 2$ ✓）。

方向：$\vec a = (-18\cos 3t,\ -18\sin 3t) = -9\,(2\cos 3t,\ 2\sin 3t) = -9\vec r$——与位矢反向，即指向圆心 ✓。

(3) $\dfrac{v^2}{R} = \dfrac{36}{2} = 18\ \mathrm{m/s^2} = a_n$ ✓ 三种算法完全一致。

点评：推过这一遍，$a_n = \omega^2 R = \dfrac{v^2}{R} = \dfrac{4\pi^2}{T^2}R$ 这一串等价形式你都能互相推出，不用再背。这就是竞赛要求的「公式内力」。

五、易错点

易错 1：把「速率的变化率」当成「加速度的大小」。$\left|\vec a\right| = \left|\dfrac{d\vec v}{dt}\right|$，而 $\dfrac{d|\vec v|}{dt}$ 只是切向分量 $a_\tau$。匀速圆周运动速率不变（$\frac{d|\vec v|}{dt} = 0$）但 $|\vec a| = \frac{v^2}{R} \ne 0$。速度是矢量，方向变也是变。
易错 2：积分后漏掉初条件。写 $v = \int a\,dt$ 必须紧跟一句「$t=0$ 时 $v = v_0$」定常数 $C$。漏掉的直接后果：例 2 的 $v(t)$ 你会写成 $3t^2$，比正确答案 $3t^2+2$ 整整少了初速度——后面全错。积分与初条件永远成对出现。
易错 3：相对运动下标顺序写反。$\vec v_{A对C} = \vec v_{A对B} + \vec v_{B对C}$，口诀「下标接力，中间相消」。写成 $\vec v_{B对A} + \vec v_{B对C}$ 之类就全乱了。每写一步检查：前一个下标的「对字后面」是否等于后一个下标的「对字前面」。
易错 4：死记「45° 射程最大」。该结论的前提是落点与抛出点同高。斜面上抛是 $45° + \frac{\alpha}{2}$（例 5）；从高处往低处抛，最佳角小于 45°。条件变了结论就变，先问前提再用结论。
易错 5：圆周运动公式里用角度制。$\omega$ 的单位是 rad/s，$\theta = \omega t$、$s = R\theta$、$v = \omega R$ 全部只在弧度制下成立。若题目给「每分钟 30 转」，先换算：$\omega = \frac{30 \times 2\pi}{60} = \pi\ \mathrm{rad/s}$，再代入。计算器也要确认在 RAD 档。
易错 6：认为圆周运动合加速度一定指向圆心。只有匀速圆周才纯向心。变速圆周有切向分量 $a_\tau = \beta R$，合加速度指向前内侧，大小 $\sqrt{a_\tau^2 + a_n^2}$。受力分析时同理：向心力只是合力的径向分量，不是凭空多出的力。
易错 7：混淆 $\dfrac{\Delta v}{\Delta t}$ 与 $\dfrac{dv}{dt}$ 的适用面。前者是平均加速度，只在匀变速时等于瞬时加速度；后者才是定义。反过来，由 $a(t)$ 求位移时两次积分、两个初条件一个都不能少，且 $a$ 随时间变化时课内三公式全部失效——必须先判断是不是匀变速。

六、自检清单

合上材料，逐条自查。做不到的项目就回到对应小节再过一遍——能自查出来的缺口，都是赚到的。

  • 给我一个 $x(t)$（幂函数、三角函数），我能求导写出 $v(t)$、$a(t)$，不查公式
  • 给我一个 $a(t)$ 和初条件，我能积分还原 $v(t)$、$x(t)$，并且每一步都带初条件定常数
  • 我知道 $a = v\dfrac{dv}{dx}$ 这个链式变形，并说出什么时候用它（$a$ 随 $x$ 变时）
  • 我能用「图线下面积」快速检验积分结果（$a\text{-}t$ 面积 = $\Delta v$，$v\text{-}t$ 面积 = $\Delta x$）
  • 我会写速度合成式 $\vec v_{A对C} = \vec v_{A对B} + \vec v_{B对C}$，并用「下标接力」自查顺序
  • 遇到追及/相遇题，我会先想「换到哪个参考系能让一个物体静止」
  • 我能从参数方程消去 $t$ 推出抛体轨迹方程 $y = x\tan\theta - \frac{gx^2}{2v_0^2}(1+\tan^2\theta)$
  • 我会推导平地射程 $R = \frac{v_0^2\sin 2\theta}{g}$，并清楚「45° 最大」的前提是落点同高
  • 我知道包络线方程 $y = \frac{v_0^2}{2g} - \frac{gx^2}{2v_0^2}$，会用它判断「某点能否被打到」
  • 我能从 $x = R\cos\omega t,\ y = R\sin\omega t$ 两次求导推出 $\vec a = -\omega^2\vec r$，并得到 $a_n = \frac{v^2}{R}$
  • 我记得圆周运动一切公式用弧度制，会给「转/分」换算成 rad/s
  • 我知道变速圆周的加速度分切向 $a_\tau$ 与法向 $a_n$，合加速度不指向圆心
  • 每道题算出数后，我会检查量纲（单位）是否正确——比如例 2 中 $6$ 的单位是 $\mathrm{m/s^3}$

小兵小贴士：这一章你其实干了一件很了不起的事——把高中运动学从「背公式」升级成了「算公式」。微积分两条腿（求导、积分）+ 两个视角（换参考系、参数化），就是你未来三年竞赛路上的随身工具。下一章《受力分析与牛顿定律》，我们要给「运动」配上「原因」，到时候本章的 $a$ 都要由 $\frac{F_合}{m}$ 供出来。慢慢来，比较快。

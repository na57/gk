二、核心概念与物理量

2.1 分子动理论的三条基本观点

  1. 物质是由大量分子组成的。分子直径的数量级为 $10^{-10}\ \mathrm{m}$，分子质量的数量级约 $10^{-26}\ \mathrm{kg}$。1 mol 任何物质都含有 $N_A = 6.02\times 10^{23}$ 个微粒（阿伏伽德罗常数）。
  2. 分子在永不停息地做无规则运动（热运动）。实验证据：扩散现象和布朗运动。温度越高，热运动越剧烈。
  3. 分子之间同时存在引力和斥力。引力和斥力都随距离增大而减小，但斥力变化更快；实际表现的「分子力」是二者的合力。

2.2 阿伏伽德罗常数：宏观与微观之间的桥梁

$N_A$ 是全章最重要的常数，它把宏观量（摩尔质量 $M$、摩尔体积 $V_{\mathrm{m}}$）和微观量（分子质量 $m_0$、分子体积 $V_0$）联系起来：

$$m_0 = \frac{M}{N_A}, \qquad V_0 = \frac{V_{\mathrm{m}}}{N_A}$$

深度理解：注意 $V_0 = V_{\mathrm{m}}/N_A$ 对固体、液体是「一个分子实际占的体积」，对气体只是「一个分子平均占据的空间」——气体分子本身远小于这个空间，分子之间大部分是空的。这是高考最爱挖的坑之一。

2.3 分子力与平衡距离 r₀

  • 当 $r = r_0$（约 $10^{-10}\ \mathrm{m}$）时，引力 = 斥力，分子力为零，分子势能最小。
  • 当 $r < r_0$ 时，斥力大于引力，分子力表现为斥力；$r$ 减小时斥力急剧增大——这就是固体、液体很难被压缩的原因。
  • 当 $r > r_0$ 时，引力大于斥力，分子力表现为引力；当 $r > 10r_0$ 时分子力可忽略（理想气体模型的依据）。

2.4 布朗运动

悬浮在液体（或气体）中的固体小颗粒（如花粉、墨汁颗粒）做的永不停息的无规则运动，叫布朗运动。

本质三连：① 布朗运动是小颗粒的运动，不是分子的运动；② 它间接反映了液体分子在做无规则热运动（颗粒被四面八方的水分子不平衡撞击所致）；③ 颗粒越小、温度越高，布朗运动越明显。

2.5 温度与内能

物理量符号单位微观意义
温度$T$K（开尔文）；常用 ℃，$T = t + 273.15$分子热运动平均动能的标志。温度相同 ⇒ 平均动能相同（与物质种类无关）
分子平均动能$\bar{E}_{\mathrm{k}}$J只由温度决定；注意是「平均」，单个分子动能千差万别
分子势能$E_{\mathrm{p}}$J由分子间相对位置决定，宏观上与物体的体积有关
内能$U$J物体内部所有分子动能与分子势能的总和，$U = N\bar{E}_{\mathrm{k}} + E_{\mathrm{p总}}$，与 $T$、$V$、物质的量都有关
阿伏伽德罗常数$N_A$$\mathrm{mol^{-1}}$$N_A = 6.02\times 10^{23}\ \mathrm{mol^{-1}}$，宏观与微观的桥梁
关键辨析：温度是「平均动能」的标志，不是内能的标志。温度相同的两杯水，质量大的内能大（分子多）；0 ℃ 的冰熔化成 0 ℃ 的水，温度不变、平均动能不变，但吸收热量使分子势能增大，内能增大。

2.6 固体和液体（了解级）

  • 晶体 vs 非晶体：晶体有规则的几何外形、有确定的熔点，内部微粒排列有序；非晶体（玻璃、沥青、松香）无规则外形、无确定熔点，加热时逐渐软化。单晶体各向异性，多晶体和非晶体各向同性。
  • 液体表面张力：液体表面层分子间距较大，分子间表现为引力，使液面有收缩到最小面积的趋势。实例：小水滴呈球形、荷叶上的露珠、水黾能站在水面、毛细现象。

三、公式与推导（含适用条件）

3.1 微观量估算的通用链条

已知物质的摩尔质量 $M$、密度 $\rho$，质量为 $m$ 的物体中：

$$n = \frac{m}{M} \quad (\text{物质的量}), \qquad N = n N_A = \frac{m}{M}N_A \quad (\text{分子总数})$$ $$V_{\mathrm{m}} = \frac{M}{\rho} \quad (\text{摩尔体积}), \qquad V_0 = \frac{V_{\mathrm{m}}}{N_A} = \frac{M}{\rho N_A} \quad (\text{一个分子占的体积})$$

把分子看成小球：$V_0 = \dfrac{1}{6}\pi d^3$，得分子直径

$$d = \sqrt[3]{\frac{6V_0}{\pi}} \approx \sqrt[3]{V_0} \quad (\text{数量级估算时常直接开立方})$$
适用条件与边界（重点！）：
  • $V_0 = \dfrac{M}{\rho N_A}$ 对固体、液体是分子本身的体积；对气体只是分子平均占据的空间，此时 $d = \sqrt[3]{V_0}$ 算出来的是分子间的平均距离，不是分子直径。
  • 标准状况下气体摩尔体积 $V_{\mathrm{m}} = 22.4\ \mathrm{L/mol}$，只能用于标准状况（0 ℃、1 atm）的气体。
  • 估算题只要求数量级正确，看到 $d \approx 10^{-10}\ \mathrm{m}$ 、分子间距 $\approx 10^{-9}\ \mathrm{m}$ 就要有数感。

3.2 油膜法测分子直径

实验原理：把一滴已知浓度的油酸酒精溶液滴到撒有痱子粉的水面上，油酸在水面散开形成单分子层油膜（把油酸分子看成一个个紧挨着的小球，膜厚 = 一个分子的直径）。

$$d = \frac{V}{S}$$

其中 $V$ 是一滴溶液中纯油酸的体积，$S$ 是油膜的面积。

推导与建模思想：设溶液由 $V_{\text{总}}$ 酒精溶液含纯油酸 $V_{\text{油}}$ 配成，则一滴（体积 $V_{\text{滴}}$）中含纯油酸 $V = V_{\text{滴}} \cdot \dfrac{V_{\text{油}}}{V_{\text{总}}}$。酒精溶于水挥发掉，纯油酸铺成面积 $S$、厚度 $d$ 的「薄膜」，体积守恒：$V = S d \Rightarrow d = V/S$。
适用条件：① 必须形成单分子层（油膜不能重叠、不能破到容器边）；② $V$ 必须代入纯油酸体积，不是一滴溶液的体积——这是本实验最常见的错误。

3.3 分子势能与分子力的对应关系

  • 取无穷远处 $E_{\mathrm{p}} = 0$。$r = r_0$ 处分子力为零，分子势能最小（为负值）。
  • $r$ 从 $r_0$ 增大：分子力做负功（引力被拉远），$E_{\mathrm{p}}$ 增大；$r$ 从 $r_0$ 减小：斥力做负功，$E_{\mathrm{p}}$ 也增大。
  • 判断口诀：「力为零处势最低，远离靠近都升高」。分子力曲线的「零点」对应势能曲线的「最低点」，这个对应关系常考。

四、典型例题

例1（阿伏伽德罗常数估算 · 水的分子）

已知水的摩尔质量 $M = 18\ \mathrm{g/mol}$，水的密度 $\rho = 1.0\times 10^{3}\ \mathrm{kg/m^3}$，$N_A = 6.02\times 10^{23}\ \mathrm{mol^{-1}}$。求：(1) 1 g 水中约有多少个水分子；(2) 估算一个水分子的直径。

解：

(1) 1 g 水的物质的量 $n = \dfrac{m}{M} = \dfrac{1}{18}\ \mathrm{mol} \approx 0.0556\ \mathrm{mol}$，分子数

$$N = nN_A = \frac{1}{18}\times 6.02\times 10^{23} \approx 3.3\times 10^{22}\ \text{个}$$

(2) 水的摩尔体积 $V_{\mathrm{m}} = \dfrac{M}{\rho} = \dfrac{18\times 10^{-3}}{1.0\times 10^{3}} = 1.8\times 10^{-5}\ \mathrm{m^3/mol}$。一个水分子占的体积

$$V_0 = \frac{V_{\mathrm{m}}}{N_A} = \frac{1.8\times 10^{-5}}{6.02\times 10^{23}} \approx 3.0\times 10^{-29}\ \mathrm{m^3}$$

由 $V_0 = \dfrac{1}{6}\pi d^3$ 得

$$d = \sqrt[3]{\frac{6V_0}{\pi}} = \sqrt[3]{\frac{6\times 3.0\times 10^{-29}}{3.14}} \approx \sqrt[3]{5.7\times 10^{-29}} \approx 3.9\times 10^{-10}\ \mathrm{m}$$

答：(1) 约 $3.3\times 10^{22}$ 个；(2) 直径约 $4\times 10^{-10}\ \mathrm{m}$，数量级 $10^{-10}\ \mathrm{m}$，与预期一致。★★★（水是液体，$V_0$ 就是分子本身的体积，可以算直径）

例2（油膜法测分子直径）

把 1 mL 油酸溶于酒精配成 200 mL 油酸酒精溶液。测得 1 mL 溶液恰为 50 滴。取一滴该溶液滴在撒有痱子粉的水面上，待油膜稳定后测得油膜面积 $S = 0.20\ \mathrm{m^2}$。求油酸分子的直径。

解：一滴溶液的体积 $V_{\text{滴}} = \dfrac{1}{50}\ \mathrm{mL} = 0.02\ \mathrm{mL}$。

溶液浓度：200 mL 溶液中含纯油酸 1 mL，所以一滴中纯油酸的体积

$$V = 0.02\ \mathrm{mL} \times \frac{1}{200} = 1.0\times 10^{-4}\ \mathrm{mL} = 1.0\times 10^{-10}\ \mathrm{m^3}$$

油膜为单分子层，故

$$d = \frac{V}{S} = \frac{1.0\times 10^{-10}}{0.20} = 5.0\times 10^{-10}\ \mathrm{m}$$

答：油酸分子直径约为 $5\times 10^{-10}\ \mathrm{m}$。

本题最易错：直接把 $0.02\ \mathrm{mL}$（一滴溶液的体积）代入 $d = V/S$，会算出 $1\times 10^{-7}\ \mathrm{m}$——比真实值大 3 个数量级。一定要乘浓度换算成纯油酸体积。

例3（气体分子间距估算）

标准状况下，气体的摩尔体积为 $22.4\ \mathrm{L/mol}$。估算标准状况下气体分子间的平均距离，并与分子直径比较。

解：$V_{\mathrm{m}} = 22.4\ \mathrm{L/mol} = 2.24\times 10^{-2}\ \mathrm{m^3/mol}$。每个分子平均占据的空间

$$V_0 = \frac{V_{\mathrm{m}}}{N_A} = \frac{2.24\times 10^{-2}}{6.02\times 10^{23}} \approx 3.7\times 10^{-26}\ \mathrm{m^3}$$

把每个分子的「领地」看成小立方体，分子间距

$$d = \sqrt[3]{V_0} = \sqrt[3]{3.7\times 10^{-26}} \approx 3.3\times 10^{-9}\ \mathrm{m}$$

答：分子间距约 $3\times 10^{-9}\ \mathrm{m}$，约为分子直径（$10^{-10}\ \mathrm{m}$）的十几倍。这正说明气体分子间距离很大、分子力可忽略——理想气体模型的微观图景。（顺带得到标准状况下气体分子数密度 $\dfrac{N_A}{V_{\mathrm{m}}} \approx 2.7\times 10^{25}\ \mathrm{m^{-3}}$。）

例4（概念辨析：温度、内能与布朗运动）

下列说法正确的是（  ）

A. 布朗运动就是液体分子的无规则运动
B. 温度相同的氢气和氧气，分子平均动能相同
C. 0 ℃ 的冰熔化成 0 ℃ 的水，内能不变
D. 分子间距离增大时，分子势能一定增大

逐项分析：

  • A 错。布朗运动是悬浮小颗粒的运动，它间接反映液体分子的无规则运动，把「反映」说成「就是」，偷换了研究对象。
  • B 对。温度是分子平均动能的标志，温度相同 ⇒ 平均动能相同，与分子种类无关（氢分子质量小，所以氢分子平均速率反而更大——注意区分「动能」和「速率」）。
  • C 错。熔化过程吸热，温度不变 ⇒ 分子平均动能不变，但分子势能增大，故内能增大。
  • D 错。要分段看：若 $r < r_0$（斥力区），距离增大时斥力做正功，分子势能减小；只有从 $r > r_0$ 起增大距离，势能才增大。少了前提条件就是错。

答：B。这种四选一的辨析题就是本章高考的原型，每个错误选项都对应一个经典易错点（见第五部分）。

五、易错点与成因分析

易错点典型错误说法正确结论与成因分析
布朗运动的对象 「布朗运动是分子的运动」 布朗运动是悬浮颗粒的运动。成因：颗粒远大于分子，肉眼（显微镜）可见；分子本身看不见。布朗运动只是间接证据，证明液体分子在做无规则热运动。
温度与内能混为一谈 「温度高的物体内能一定大」「温度不变内能就不变」 温度只决定平均动能。内能还取决于分子数（质量）和分子势能（体积、物态）。成因：把「平均动能的标志」误记成「内能的标志」。反例：0 ℃ 冰熔化成 0 ℃ 水吸热，内能增大。
气体分子「体积」 用 $V_0 = V_{\mathrm{m}}/N_A$ 算气体分子直径 对气体，$V_0$ 是分子平均占据的空间，开立方得到的是分子间距（约 $10^{-9}\ \mathrm{m}$），不是分子直径。成因：忽略了气体分子间距离远大于分子线度这一基本图景。
分子力与分子势能的对应 「$r = r_0$ 时分子力为零，所以分子势能为零」 $r_0$ 处分子力为零、势能最小（负值），势能零点人为取在无穷远。成因：混淆了「力」与「势能」两条曲线的特征点——力的零点对应势能的最低点，而不是势能的零点。
分子势能增减不分段 「分子间距增大，分子势能一定增大」 $r < r_0$ 时增大距离，斥力做正功，势能减小；$r > r_0$ 时增大距离，引力做负功，势能增大。成因：没有以 $r_0$ 为分界分段讨论。
油膜法代错 V 把一滴溶液的体积直接代入 $d = V/S$ $V$ 必须是纯油酸的体积 = 一滴溶液体积 × 浓度。成因：审题时漏掉「溶液」与「纯油酸」的区别。
扩散与对流的干扰 「搅拌使墨水散开是扩散」 扩散是自发的、由分子热运动引起的相互渗透；搅拌、风吹是机械运动，不是扩散。判断标准：没有外力搅动时仍能自发混合，才是扩散。

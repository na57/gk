机械能守恒定律

高中物理 · 力学模块 · 高考必考重点 ｜ 依据：《高考物理95+分备考指南》3.4节要求 ｜ 适用：高一同步学习 & 高考一轮复习 ｜ 学生：小兵

一、本章总览

如果说牛顿运动定律是从"力"的角度看世界，那么本章就是从"能量"的角度看世界。力的分析要盯紧每一个瞬间，而能量的分析只关心初、末两个状态——这使得很多用牛顿定律极难求解的问题（变力、曲线、多过程），用能量观点几步就能解决。可以说，本章是整个高中力学"从难到易"的分水岭：学完本章，你的物理工具箱里将多出一件比牛顿定律更顺手的武器。

高考定位与分值

云南高考物理满分 100 分、考试时长 75 分钟，力学板块约占 40 分。功和能是力学的两大主线之一，几乎年年必考：选择题中常考"功的正负判断""功率估算""机械能守恒条件判断"；实验题中"验证机械能守恒定律"是高频实验；计算题中动能定理、机械能守恒与传送带、圆周、平抛等模型结合，常作为压轴题的前两问。保守估计，本章直接分值在 10~16 分，间接渗透（与电场、磁场中的能量问题）还会更多。

本章学习主线

本章的逻辑链条非常清晰，建议按下面的顺序建立框架：

  1. 先学"功"——能量转化的量度。会算功（包括正负），才算入了门。
  2. 再学"功率"——做功的快慢，联系实际（机车、起重机）的桥梁。
  3. 核心规律一：动能定理——合外力做功改变动能。普适性最强，优先级最高。
  4. 核心规律二：机械能守恒定律——只有重力或弹力做功时，动能与势能相互转化、总量不变。有条件才能用。
  5. 升华：功能关系——"什么力做功，就对应什么能量的变化"，这是整个高中能量问题的总纲。
给小兵的学习建议：本章公式不多，但"适用条件"比公式本身更重要。每学一个公式，都要问自己三个问题：①它是怎么推出来的？②什么条件下才能用？③什么情况下会算错？带着这三个问题学，本章会非常扎实。

二、核心概念与物理量

1. 功

定义：一个物体受到力的作用，并且在力的方向上发生了一段位移，就说这个力对物体做了功。功是力在空间上的积累效果，是能量转化的量度。

符号：$W$　单位：焦耳（J），$1\,\text{J} = 1\,\text{N}\cdot\text{m}$　标矢性：标量，但有正负。

⚠️ 功的正负与夹角约定（本章第一个大坑）：
功的计算式 $W = Fx\cos\theta$ 中，$\theta$ 是力 $\vec{F}$ 与位移 $\vec{x}$ 方向之间的夹角（取 $0 \le \theta \le 180^{\circ}$）。
  • $0^{\circ} \le \theta < 90^{\circ}$：$\cos\theta > 0$，力做正功（力促进物体运动，如动力）；
  • $\theta = 90^{\circ}$：$\cos\theta = 0$，力不做功（如匀速圆周运动的向心力、支持力在光滑水平面上）；
  • $90^{\circ} < \theta \le 180^{\circ}$：$\cos\theta < 0$，力做负功（力阻碍物体运动，如阻力、摩擦力）。
某力做负功 $-W$，常说成"物体克服该力做功 $W$"。例如摩擦力做功 $-20\,\text{J}$，即物体克服摩擦力做功 $20\,\text{J}$。
深度理解：功是标量，为什么还有正负？功的正负不代表方向，而代表能量的流向：正功表示这个力把能量"注入"物体，负功表示这个力把能量从物体"抽走"。几个力对同一物体做功，总功等于各力做功的代数和（直接加减，不用矢量合成）——这正是能量观点比力的观点方便的第一个原因。

2. 功率

定义：功与完成这些功所用时间的比值，表示做功的快慢（不是做功的多少！）。

符号：$P$　单位：瓦特（W），$1\,\text{W} = 1\,\text{J/s}$　标矢性：标量。

两个层面：

  • 平均功率 $\bar{P} = \dfrac{W}{t}$：一段时间内做功快慢的平均描述；
  • 瞬时功率 $P = Fv\cos\theta$：某一时刻的功率，$\theta$ 为力与速度方向的夹角（注意这里是与速度 $\vec{v}$ 的夹角，不要与功的夹角混淆）。

生活中的"额定功率"（如汽车发动机铭牌功率）指发动机长期正常工作的最大输出功率。机车启动问题是瞬时功率公式的经典应用，核心抓手是：$P = Fv$，牵引力与速度此消彼长。

3. 动能

定义：物体由于运动而具有的能量。

符号：$E_k$　定义式：$E_k = \dfrac{1}{2}mv^2$　单位：焦耳（J）　标矢性：标量，且恒有 $E_k \ge 0$。

三点注意：① $v$ 是速率（速度的大小），动能没有方向；② $v$ 具有相对性，默认相对地面；③动能是状态量——某一时刻（某一位置）有一个确定的动能，与过程无关。速度是矢量，速度方向改变而大小不变时（如匀速圆周运动），动能不变。

4. 势能

重力势能

定义：物体由于被举高而具有的能量。$E_p = mgh$，其中 $h$ 是物体相对零势能面的高度。

三点注意：①相对性：零势能面任选（通常选地面或最低点），零势能面之上为正、之下为负；②重力势能的变化量 $\Delta E_p = mg\Delta h$ 与零势能面的选取无关，有绝对意义；③重力势能是物体与地球组成的系统共有的，平时说"物体的重力势能"是简称。

弹性势能

定义：发生弹性形变的物体具有的能。弹簧的弹性势能 $E_p = \dfrac{1}{2}kx^2$（$x$ 为形变量），形变量越大、劲度系数越大，弹性势能越大。本式在课标中为了解要求，高考中一般通过"弹力做功与弹性势能变化的关系"间接考查，而不直接代入计算。

5. 机械能

定义：动能与势能（重力势能、弹性势能）的总和：

$$E = E_k + E_p$$

符号：$E$　单位：焦耳（J）　标矢性：标量。机械能是状态量，其数值依赖于零势能面的选取；机械能的变化量与零势能面无关。

深度思考 1：用力提着一个箱子在水平走廊里匀速走 10 m，你对箱子做功了吗？——支持力（提力）竖直向上，位移水平，夹角 $90^{\circ}$，做功为零。但你的手臂确实酸了，那是肌肉内部的生理消耗，不是对箱子做的机械功。物理上的"功"和生活中的"辛苦"不是一回事。

深度思考 2：动能能不能是负的？重力势能呢？——动能 $\frac12 mv^2$ 中 $m>0$、$v^2\ge 0$，所以动能不可能为负；而重力势能可正可负，全看零势能面选在哪里。所以"某处重力势能是 $-50\,\text{J}$"完全合理，"某时刻动能是 $-50\,\text{J}$"一定算错了。

三、公式与推导（含适用条件）

3.1 恒力做功：$W = Fx\cos\theta$

推导思路：当力 $\vec{F}$ 与位移 $\vec{x}$ 不同向时，把力分解为沿位移方向的分力 $F\cos\theta$（做功）和垂直位移方向的分力 $F\sin\theta$（不做功），只有前者对位移有"推动"贡献，故 $W = (F\cos\theta)\cdot x = Fx\cos\theta$。等效地，也可以把位移分解到力的方向上：$W = F\cdot(x\cos\theta)$。

适用条件与边界：
  • 只适用于恒力（大小、方向都不变）做功，且位移为直线段（位移矢量明确）；
  • 力的大小或方向变化（变力）、物体做曲线运动时，不能直接套用，须用下面三种方法。

变力做功的三种常用方法：

  1. 图象法：作出 $F$–$x$ 图象（$F$ 沿位移方向的分力对位移的图象），图线与 $x$ 轴围成的面积即等于功。适用于力随位移规律变化（如线性变化 $F = F_0 + kx$、弹簧弹力）；
  2. 微元法：把全过程切成许多小段，每小段内力可视为恒力做功，再求和。适用于方向变化但有规律的情形（如物体沿圆周运动一周摩擦力做功 $W = -f\cdot 2\pi R$）；
  3. 动能定理法：当其他力做功易求、而某个变力做功难求时，用动能定理反解：$W_{变} = \Delta E_k - W_{其他}$。这是高考中最常用的"曲线救国"法（见例 4）。

3.2 功率的两个公式

平均功率：$P = \dfrac{W}{t}$，定义式，普适。若力恒定且物体沿力方向运动，还可写成 $\bar{P} = F\bar{v}$。

瞬时功率：由 $W = Fx\cos\theta$ 出发，取极短时间 $\Delta t$，有 $P = \dfrac{\Delta W}{\Delta t} = F\cos\theta\cdot\dfrac{\Delta x}{\Delta t} = Fv\cos\theta$。

适用条件与边界：$P = Fv\cos\theta$ 中 $v$ 必须是该时刻的瞬时速度，$\theta$ 是力与速度（不是位移）的夹角。当 $F$ 与 $v$ 共线时简化为 $P = Fv$。机车启动问题中，额定功率 $P_额$、牵引力 $F$、速度 $v$ 三者始终满足 $P = Fv$——速度增大时牵引力必然减小，这是分析两种启动方式（恒定功率、恒定加速度）的总钥匙。

3.3 动能定理（本章第一核心）

内容：合外力对物体所做的功，等于物体动能的变化量：

$$W_{合} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$

推导思路（以匀加速直线运动为例）：设物体质量 $m$，在恒定的合外力 $F_合$ 作用下沿直线运动，速度由 $v_1$ 变为 $v_2$，位移为 $x$。

  • 由牛顿第二定律：$F_合 = ma$；
  • 由运动学公式：$v_2^2 - v_1^2 = 2ax$，即 $x = \dfrac{v_2^2 - v_1^2}{2a}$；
  • 合外力做功：$W_合 = F_合\cdot x = ma\cdot\dfrac{v_2^2 - v_1^2}{2a} = \dfrac{1}{2}mv_2^2 - \dfrac{1}{2}mv_1^2$。

推导借助了匀变速直线运动，但进一步的理论和实验都表明：动能定理是普适的——无论恒力还是变力、直线还是曲线、单个过程还是多段过程，它都成立。

⭐ 方法论：为什么动能定理要"优先"考虑？
遇到求功、求速度（速率）、求位移的力学题，思考顺序建议是：① 机械能守恒？② 动能定理？③ 最后才轮到牛顿第二定律+运动学。因为动能定理只问初末状态、不问中间细节，对变力、曲线、多过程问题常常一步到顶。高考阅卷中，动能定理列式正确即可拿到核心分数。

应用动能定理的四个步骤：

  1. 定对象、定过程：明确研究对象和所研究的运动过程（初、末状态）；
  2. 受力分析：找出过程中所有力（一个都不能漏），判断哪些力做功、做正功还是负功；
  3. 列总功：写出各力做功的代数和 $W_{合} = W_1 + W_2 + \cdots$；
  4. 列方程：$W_{合} = \dfrac12 mv_2^2 - \dfrac12 mv_1^2$，代入数据求解，检验合理性。
适用条件与边界：动能定理几乎没有"禁用"情形，但有三点纪律：①右边永远是末动能减初动能，次序不能反；②左边是合外力做的功（或各力做功代数和），重力、摩擦力等一个都不能漏；③适用于单个物体（或可视为质点的物体），对系统使用时要格外小心内力做功。

3.4 重力做功与重力势能变化

推导：物体从高度 $h_1$ 处沿任意路径运动到高度 $h_2$ 处。把路径切成无数小段，每小段上重力 $mg$（竖直向下）只在竖直方向的位移分量上做功，水平分量不做功。所有小段的竖直位移分量之和正好是高度差 $h_1 - h_2$，故

$$W_G = mg(h_1 - h_2) = mgh_1 - mgh_2$$

两个重要结论：

  • 重力做功只与初、末位置的高度差有关，与路径无关（重力是"保守力"）；
  • 重力做功等于重力势能变化量的负值：$W_G = -\Delta E_p = -(E_{p2} - E_{p1})$。重力做正功，重力势能减少；重力做负功（克服重力做功），重力势能增加。

同理，弹簧弹力做功与弹性势能变化也有同样关系：$W_{弹} = -\Delta E_{p弹}$。

3.5 机械能守恒定律（本章第二核心）

推导思路：设物体在运动过程中只有重力做功。由动能定理：$W_G = E_{k2} - E_{k1}$；又由重力做功与重力势能的关系：$W_G = E_{p1} - E_{p2}$。两式联立得

$$E_{k2} - E_{k1} = E_{p1} - E_{p2} \;\Rightarrow\; E_{k1} + E_{p1} = E_{k2} + E_{p2}$$

即初状态的机械能等于末状态的机械能——机械能守恒。若系统内还有弹簧弹力做功（同样满足 $W_弹 = -\Delta E_p$），把弹性势能计入 $E_p$，结论依然成立。

守恒条件的准确含义（判断正误题的重灾区）：
"只有重力或系统内弹力做功"——注意是"做功"而不是"受力"！
  • 物体可以受其他力（如支持力、绳的拉力），只要这些力不做功（力与速度始终垂直，如光滑轨道上的支持力），机械能仍守恒；
  • 其他力做功但代数和为零时，机械能总量也不变；
  • 一旦有摩擦力、空气阻力做功，或外界有动力（如电动机、推力）做功，机械能必不守恒；
  • 判断对象是"系统"还是"单个物体"：单个物体的机械能守恒只看重力；含弹簧的系统要把弹性势能算进来。

三种常用表达式（按场景选择）：

形式表达式含义是否需要零势能面
① 守恒式$E_{k1} + E_{p1} = E_{k2} + E_{p2}$初态机械能 = 末态机械能需要
② 转化式$\Delta E_k = -\Delta E_p$动能的增加量 = 势能的减少量不需要
③ 转移式$\Delta E_A = -\Delta E_B$A 物体增加的机械能 = B 物体减少的机械能不需要

单物体问题常用①②；连接体（如绳两端两物体一升一降）常用③，可避免选零势能面，列式最简洁。

应用机械能守恒的四个步骤：① 定对象与过程；② 先判断守恒条件是否满足（不满足就改用动能定理）；③ 选零势能面（若用守恒式）；④ 找出初、末状态的动能和势能，列方程求解。

3.6 功能关系（本章的总纲）

能量不会凭空产生或消失，只会在不同形式间转化或转移，而功是能量转化的量度——做了多少功，就有多少能量发生了转化。掌握下面这张"对号入座"表，所有能量问题都有了统一的分析框架：

做功的力对应的能量变化定量关系
合外力做功 $W_{合}$动能变化$W_{合} = \Delta E_k$
重力做功 $W_G$重力势能变化$W_G = -\Delta E_{p重}$
弹簧弹力做功 $W_{弹}$弹性势能变化$W_{弹} = -\Delta E_{p弹}$
除重力、弹力外的其他力做功 $W_{其他}$机械能变化$W_{其他} = \Delta E$
一对滑动摩擦力做功的代数和系统内能（热量）$Q = f\cdot \Delta s_{相对}$
⭐ 第四行是"机械能守恒定律的广义版"：机械能不守恒时，并不是"能量丢了"，而是其他力做功使机械能发生了变化——$W_{其他} = E_2 - E_1$。例如物体受摩擦力作用减速，$W_{其他}<0$，机械能减少，减少的部分转化成了内能。这个关系让"不守恒"的问题也有了精确方程。

深度思考 3：为什么"一对滑动摩擦力"做的功才等于热量，而单个摩擦力做功不等于？因为热量是系统的内能增量，属于两个相互摩擦的物体共有。地面上的木块滑行：摩擦力对木块做负功 $-fx_块$，若地面不动，摩擦力对地面不做功，代数和为 $-fx_块$，这正好等于产生的热量。但传送带上：摩擦力对工件做正功 $fx_工件$，对传送带做负功 $-fx_带$，代数和 $-f(x_带 - x_工件) = -f\Delta s_{相对}$，所以 $Q = f\Delta s_{相对}$——热量只由相对滑动的那一段决定。这就是例 3 的核心。

四、典型例题

例 1 ｜ 多过程问题：动能定理一步到顶 ★★★

如图所示，斜面高 $h = 1.8\,\text{m}$，斜面长 $L = 3.0\,\text{m}$（倾角 $37^{\circ}$，取 $\sin 37^{\circ} = 0.6$、$\cos 37^{\circ} = 0.8$）。一小物块从斜面顶端由静止滑下，经底端平滑过渡到粗糙水平面，最终停在水平面上。物块与斜面、水平面间的动摩擦因数均为 $\mu = 0.25$。求物块在水平面上滑行的距离 $s$。

过程分析（分步拆解）：

  1. 定过程：取"顶端静止"为初状态、"水平面停下"为末状态。初、末动能都是零——这是选全过程的最大理由；
  2. 受力与做功清单：全程受重力、支持力、摩擦力。支持力始终与速度垂直，不做功；重力做功 $W_G = mgh$（只与高度差有关）；斜面上摩擦力 $f_1 = \mu mg\cos 37^{\circ}$，做功 $W_1 = -\mu mgL\cos 37^{\circ}$；水平面上摩擦力 $f_2 = \mu mg$，做功 $W_2 = -\mu mgs$；
  3. 列动能定理：$W_G + W_1 + W_2 = 0 - 0$。

解：由动能定理（全过程）：

$$mgh - \mu mgL\cos 37^{\circ} - \mu mgs = 0$$

约去 $m$（本题无需给出质量与 $g$），代入数据：

$$s = \frac{h - \mu L\cos 37^{\circ}}{\mu} = \frac{1.8 - 0.25\times 3.0\times 0.8}{0.25}\,\text{m} = \frac{1.8 - 0.60}{0.25}\,\text{m} = 4.8\,\text{m}$$

点评：若用牛顿定律分段做，需先求底端速度（$v^2 = 2g(h-\mu L\cos37^{\circ}) = 24\,\text{m}^2/\text{s}^2$，取 $g = 10\,\text{m/s}^2$），再由 $s = v^2/(2\mu g) = 24/5 = 4.8\,\text{m}$，结果一致但步骤翻倍。多过程、只求初末速率（位移）的问题，全过程动能定理几乎总是最优解。注意斜面上摩擦力要用 $f = \mu mg\cos\theta$ 而不是 $\mu mg$。

例 2 ｜ 机械能守恒 + 竖直圆周最高点临界 ★★★★

如图所示，一小球从高度 $H$ 处由静止沿光滑轨道滑下，进入半径 $R = 0.40\,\text{m}$ 的光滑竖直圆轨道。要使小球恰好能通过圆轨道最高点，$H$ 至少为多大？（取 $g = 10\,\text{m/s}^2$）

过程分析（分步拆解）：

  1. 守恒判断：轨道光滑，支持力始终指向圆心、与速度垂直，不做功；只有重力做功 → 机械能守恒，可以用守恒定律；
  2. 临界条件："恰好通过最高点"意味着在最高点轨道支持力 $N = 0$，此时只有重力提供向心力：$mg = m\dfrac{v^2}{R}$，得临界速度 $v^2 = gR$；
  3. 守恒方程：取圆轨道最低点为零势能面，初态（释放点）只有势能 $mgH$，末态（最高点）有势能 $mg\cdot 2R$ 和动能 $\frac12 mv^2$。

解：最高点临界条件：

$$mg = m\frac{v^2}{R} \;\Rightarrow\; v^2 = gR = 10\times 0.40\,\text{m}^2/\text{s}^2 = 4.0\,\text{m}^2/\text{s}^2$$

由机械能守恒（守恒式）：

$$mgH = mg\cdot 2R + \frac{1}{2}mv^2 = mg\cdot 2R + \frac{1}{2}mgR = \frac{5}{2}mgR$$ $$H = \frac{5}{2}R = 2.5\times 0.40\,\text{m} = 1.0\,\text{m}$$

点评：本题是"守恒 + 临界"的标配组合，两个结论值得记住：①竖直圆周最高点（轨道内侧）最小速度 $v = \sqrt{gR}$；②从最低点所在水平面之上静止释放，恰好过最高点的释放高度 $H = \dfrac{5}{2}R$。检验一下：若 $H = 2R$（与最高点等高）就释放，到最高点速度为零，早在到达之前就脱离轨道了——所以 $H$ 必须比 $2R$ 多出的那 $\frac12 R$，正是用来"攒"最高点所需动能的。

例 3 ｜ 传送带能量问题 ★★★★★

水平传送带以 $v = 2.0\,\text{m/s}$ 的速度匀速运行。将一质量 $m = 10\,\text{kg}$ 的工件无初速地轻放在传送带左端，工件与传送带间的动摩擦因数 $\mu = 0.20$，工件经一段时间后与传送带共速。取 $g = 10\,\text{m/s}^2$。求：（1）工件加速到与传送带共速所用的时间 $t$；（2）加速过程中工件的位移 $x_1$ 与传送带的位移 $x_2$；（3）因摩擦产生的热量 $Q$；（4）电动机因传送该工件而多做的功 $W$。

过程分析（分步拆解）：

  1. 受力判断：工件刚放上时速度为零，比传送带慢 → 相对传送带向左滑 → 滑动摩擦力向右，成为工件的动力（摩擦力不一定是阻力！）；
  2. 运动性质：工件在恒定摩擦力 $f = \mu mg$ 下做初速为零的匀加速运动，加速度 $a = \mu g$，直到与带共速；共速后无相对滑动，摩擦力消失（水平方向不再受力），一起做匀速运动；
  3. 能量流向：电动机多消耗的电能 = 工件增加的动能 + 摩擦产生的热量，其中热量只与相对位移有关。

解：（1）工件加速度 $a = \dfrac{f}{m} = \mu g = 0.20\times 10\,\text{m/s}^2 = 2.0\,\text{m/s}^2$，故

$$t = \frac{v}{a} = \frac{2.0}{2.0}\,\text{s} = 1.0\,\text{s}$$

（2）工件位移（匀加速）：$x_1 = \dfrac{1}{2}at^2 = \dfrac{1}{2}\times 2.0\times 1.0^2\,\text{m} = 1.0\,\text{m}$；传送带位移（匀速）：$x_2 = vt = 2.0\times 1.0\,\text{m} = 2.0\,\text{m}$。相对位移 $\Delta s = x_2 - x_1 = 1.0\,\text{m}$。

（3）摩擦力大小 $f = \mu mg = 0.20\times 10\times 10\,\text{N} = 20\,\text{N}$，热量：

$$Q = f\cdot \Delta s = 20\times 1.0\,\text{J} = 20\,\text{J}$$

（4）工件动能增量 $\Delta E_k = \dfrac12 mv^2 = \dfrac12\times 10\times 2.0^2\,\text{J} = 20\,\text{J}$。由能量守恒，电动机多做的功：

$$W = \Delta E_k + Q = 20\,\text{J} + 20\,\text{J} = 40\,\text{J}$$

（验证：电动机克服摩擦力对传送带做的功 $W = f\cdot x_2 = 20\times 2.0\,\text{J} = 40\,\text{J}$ ✓）

⭐ 传送带能量结论（记住能省一半时间）：水平传送带上，工件从静止加速到带速 $v$ 的过程中：工件位移恰好是相对位移（也是传送带位移的一半），所以产生的热量恰好等于工件获得的动能（$Q = \Delta E_k$），电动机多消耗的电能是工件动能的 2 倍——"一半变动能，一半变热"。若传送带倾斜或工件有初速度，此比例不再成立，必须回到 $Q = f\Delta s_{相对}$ 与能量守恒重新计算。

例 4 ｜ 变力做功：图象法 + 动能定理 ★★★

质量 $m = 2.0\,\text{kg}$ 的物块静止在水平面上，在水平拉力 $F$ 作用下开始运动。拉力随位移按 $F = (10 - 2x)\,\text{N}$ 的规律变化（$x$ 以米为单位，$0 \le x \le 5.0\,\text{m}$）。物块与水平面间的动摩擦因数 $\mu = 0.20$，取 $g = 10\,\text{m/s}^2$。求物块运动到 $x = 5.0\,\text{m}$ 处时的速度大小。

过程分析（分步拆解）：

  1. 识别变力：$F$ 随 $x$ 线性减小（从 $10\,\text{N}$ 减到 $0$），不能直接套 $W = Fx\cos\theta$；
  2. 选方法：力随位移线性变化 → 首选图象法，$F$–$x$ 图线下的面积就是拉力做的功；
  3. 其余力：重力、支持力垂直于位移不做功；滑动摩擦力 $f = \mu mg$ 恒定，做负功；
  4. 列动能定理：$W_F + W_f = \dfrac12 mv^2 - 0$。

解：$F$–$x$ 图象为一直线，拉力做功等于梯形（此处为三角形）面积：

$$W_F = \frac{F_0 + F_5}{2}\cdot x = \frac{10 + 0}{2}\times 5.0\,\text{J} = 25\,\text{J}$$

摩擦力 $f = \mu mg = 0.20\times 2.0\times 10\,\text{N} = 4.0\,\text{N}$，做功 $W_f = -fx = -4.0\times 5.0\,\text{J} = -20\,\text{J}$。由动能定理：

$$25\,\text{J} - 20\,\text{J} = \frac{1}{2}\times 2.0\times v^2 \;\Rightarrow\; v^2 = 5.0\,\text{m}^2/\text{s}^2 \;\Rightarrow\; v = \sqrt{5}\,\text{m/s} \approx 2.2\,\text{m/s}$$

点评：图象法的关键是确认横轴为位移、纵轴为沿位移方向的力；面积在轴上方为正功、下方为负功。若力与位移的关系更复杂（如弹簧变加速过程），图象法失效，就要回到微元法或用动能定理反解变力做功——三种方法的选择，取决于题目给了什么条件。

五、易错点与成因分析

易错点 1：把 $W = Fx\cos\theta$ 中的 $\theta$ 张冠李戴。
典型错法：把 $\theta$ 当成力与水平面的夹角、斜面倾角或力与速度的夹角。
成因分析：没有抓住定义——$\theta$ 是力与位移方向的夹角。斜面上重力做功时，位移沿斜面向下，重力竖直向下，夹角是 $90^{\circ} - \theta_{斜}$（$\theta_{斜}$ 为倾角），所以 $W_G = mgL\sin\theta_{斜}$；很多同学误写成 $mgL\cos\theta_{斜}$，根源是把斜面倾角直接当成了公式里的 $\theta$。对策：每次用公式前，先画出力与位移两个箭头，夹角一目了然。
易错点 2：认为"有力的作用、物体又动了，力就一定做了功"。
典型错法：认为匀速圆周运动中向心力做功、认为人提箱子水平走路时提力做功。
成因分析：忽略了功的两个要素必须同时满足且不垂直：力，以及力方向上的位移分量。力与位移（速度）垂直时，$\cos 90^{\circ} = 0$，做功为零。这类"有力无功"的例子（向心力、洛伦兹力、光滑面上的支持力）恰恰是高考选择题的常客。
易错点 3：动能定理左边漏力、右边减反。
典型错法：漏掉重力做功（尤其竖直方向有位移时）或某段摩擦力做功；或把方程写成 $\frac12 mv_1^2 - \frac12 mv_2^2 = W$。
成因分析：受力分析不完整就急于列式；对"动能定理是标量方程、只管大小不管方向"理解不深，导致符号混乱。对策：① 按"重力→弹力→摩擦力→其他力"的顺序清点所有力并逐个判断做功正负；② 死记右边永远是"末 − 初"。
易错点 4：机械能守恒条件误判。
典型错法：认为"只要物体沿光滑面运动就守恒"（方向反了也可能错：看到有拉力就说不守恒）；认为"系统内两物体用绳连着，各自机械能都守恒"。
成因分析：把条件记成了"表面光滑"这种表象，而不是"只有重力或系统内弹力做功"这一本质。例如：匀速下落的降落伞受重力与阻力，机械能不守恒（阻力做负功）；而沿光滑圆弧滑下的物体受支持力，但支持力不做功，机械能守恒。连接体问题中，单个物体的机械能一般不守恒（绳的拉力对它做功），但系统的机械能守恒——研究对象选错，全盘皆输。
易错点 5：把"单个摩擦力做的功"当成热量。
典型错法：传送带问题中用 $Q = fx_{工件}$ 或 $Q = fx_{带}$ 求热量。
成因分析：热量是系统内能的增量，必须由"一对"滑动摩擦力做功的代数和来量度：$Q = f\Delta s_{相对}$。单个摩擦力做功只对应某个物体机械能的变化。静摩擦力无相对滑动，一对静摩擦力做功代数和恒为零，不产生热量——这也是常见的判断陷阱。
易错点 6：重力势能零势能面混乱，或误以为势能变化与零面有关。
典型错法：同一道题里前后换零势能面；或因为换了零面就觉得"势能变了，答案要变"。
成因分析：没有区分"势能的数值"（相对量，随零面而变）与"势能的变化量"（绝对量，$\Delta E_p = mg\Delta h$，与零面无关）。机械能守恒的转化式 $\Delta E_k = -\Delta E_p$ 只含变化量，所以根本不用选零面；只有用守恒式 $E_1 = E_2$ 时才必须选零面且前后一致。
易错点 7：$P = Fv$ 的使用条件不清。
典型错法：用平均速度代入求"瞬时功率"，或力与速度有夹角时漏掉 $\cos\theta$；机车启动时认为"额定功率下可以一直匀加速"。
成因分析：$P = Fv\cos\theta$ 是瞬时关系，$v$ 变 $F$ 就变。额定功率下 $P$ 恒定，速度增大牵引力减小，加速度随之减小——机车不可能在额定功率下保持匀加速到最大速度，这正是"恒定功率启动"与"恒定加速度启动"两种模型的分水岭。
易错点 8：对变力直接套 $W = Fx\cos\theta$。
典型错法：弹簧压缩过程中用 $W = \frac12 kx\cdot x$ 或 $W = kx^2$ 随手代入某个瞬时的力。
成因分析：忽略了公式的恒力前提。变力做功只有三条正路：$F$–$x$ 图象面积、微元求和、动能定理反解。识别题目中"力随位置/时间变化"的关键词（"逐渐增大""与位移成正比""缓慢拉动"），是避免此错的第一步。

六、章末自检清单

合上书本，逐项自测。能毫不迟疑地做到，就在心里打个勾；有犹豫的，回到对应小节再读一遍。

概念关

  • ☐ 能说出功的定义、单位，并解释"功是标量为什么有正负"（正负代表能量流向，不代表方向）；
  • ☐ 能准确指出 $W = Fx\cos\theta$ 中 $\theta$ 是力与位移的夹角，并熟练判断正功、负功、不做功三种情形；
  • ☐ 能区分平均功率与瞬时功率，知道 $P = Fv\cos\theta$ 中 $v$ 是瞬时速度、$\theta$ 是力与速度的夹角；
  • ☐ 能说出动能 $E_k = \frac12 mv^2$ 中 $v$ 是速率、动能恒非负，且"速度方向变、大小不变则动能不变"；
  • ☐ 理解重力势能的相对性（零势能面任选）与势能变化量的绝对性（与零面无关）；
  • ☐ 能说出机械能 = 动能 + 势能，是状态量、标量。

公式关

  • ☐ 能独立推导 $W = Fx\cos\theta$（分解力或位移），并说出"恒力、直线"的适用前提；
  • ☐ 能说出变力做功的三种方法（图象法、微元法、动能定理法）及各自适用场景；
  • ☐ 能用牛顿第二定律 + 运动学公式独立推导动能定理，并说出它的普适性（变力、曲线、多过程均适用）；
  • ☐ 能写出并解释 $W_G = -\Delta E_p$（重力做正功、势能减少），知道重力做功与路径无关；
  • ☐ 能独立推导机械能守恒定律（动能定理 + 重力做功特点联立）；
  • ☐ 能准确复述守恒条件"只有重力或系统内弹力做功"，并举出"受力但不做功仍守恒"的反例；
  • ☐ 能写出机械能守恒的三种表达式，并说明哪些不需要选零势能面；
  • ☐ 能背出功能关系对应表（合外力功↔动能、重力功↔重力势能、弹力功↔弹性势能、其他力功↔机械能、一对滑动摩擦力功↔热量）。

模型关

  • ☐ 多过程问题：会选"全过程"用动能定理一步求解，斜面摩擦力不漏 $\cos\theta$（例 1）；
  • ☐ 竖直圆周临界：记住最高点最小速度 $v = \sqrt{gR}$、释放高度 $H = \frac52 R$ 的由来（例 2）；
  • ☐ 传送带能量：会求共速时间、两段位移、相对位移，熟练用 $Q = f\Delta s_{相对}$ 与 $W_{电} = \Delta E_k + Q$（例 3）；
  • ☐ 变力做功：看到 $F$ 随 $x$ 线性变化能立刻想到 $F$–$x$ 图象面积（例 4）。

易错关

  • ☐ 用 $W = Fx\cos\theta$ 前必先画力与位移箭头确认夹角，不再张冠李戴；
  • ☐ 能识别"有力无功"（向心力、垂直于速度的支持力等）；
  • ☐ 动能定理列式前完整清点所有力，右边严格"末动能 − 初动能"；
  • ☐ 判断机械能是否守恒时，看"做功"不看"受力"，并先明确研究对象是物体还是系统；
  • ☐ 牢记热量 $Q = f\Delta s_{相对}$，绝不把单个摩擦力做的功当热量；
  • ☐ 用守恒式时零势能面前后一致；用转化式时不选零面；
  • ☐ 遇到"力随位移变化"字样，立即警觉：这是变力，$W = Fx\cos\theta$ 不能直接用。

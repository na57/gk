一、本章总览

19 世纪末，经典物理学的大厦看似完美，但"光电效应"这朵乌云怎么也无法用波动说驱散——光照到金属上打出电子，电子的能量居然只跟光的颜色（频率）有关，跟光的强弱无关。爱因斯坦用"光子说"漂亮地解决了这个问题，随后德布罗意大胆反问：既然光有粒子性，那实物粒子（比如电子）有没有波动性？本章就回答这两件事：光的粒子性与实物粒子的波动性。

二、核心概念与物理量

1. 光电效应现象

照射到金属表面的光（包括不可见光），能使金属中的电子从表面逸出，这种现象叫光电效应；逸出的电子叫光电子。注意：光电子本质是电子，"光"字只说明它是被光打出来的。

2. 光电效应实验装置与四条实验规律

实验规律四条（每条都是选择题的"常客"，务必逐字吃透）：

规律内容关键概念
① 存在截止频率 对每一种金属，都存在一个截止频率（极限频率）$\nu_0$：入射光频率 $\nu \geq \nu_0$ 才能发生光电效应；$\nu < \nu_0$ 时，无论光多强、照多久，都没有光电子逸出。 $\nu_0$ 由金属本身决定，与入射光无关
② 最大初动能只由频率决定 光电子的最大初动能 $E_k$ 随入射光频率 $\nu$ 的增大而增大，与光强无关。 $E_k$ 是"最快那批电子"的动能
③ 饱和光电流与光强成正比 频率 $\nu$ 一定时，单位时间逸出的光电子数与入射光强度成正比，即饱和光电流与光强成正比。 光强 → 光子数 → 光电子数
④ 瞬时性 只要 $\nu \geq \nu_0$，光一照上几乎立即（时间不超过 $10^{-9}\ \mathrm{s}$）就有光电子逸出，不需要能量积累过程。 一击即中，一个光子对一个电子

3. 四个核心概念的定义

  • 截止频率 $\nu_0$：恰能使金属发生光电效应的入射光最小频率。是金属的"门槛"，不同金属 $\nu_0$ 不同。
  • 逸出功 $W_0$：使电子脱离某种金属表面所需做功的最小值。$W_0$ 由金属本身决定，与入射光无关。$W_0$ 大的金属"门槛高"。
  • 遏止电压 $U_c$：在光电管两端加反向电压（阳极接负），使光电流恰好减为零时的反向电压。它用"电场做功"量出最快光电子的动能：$eU_c = E_k$。
  • 饱和光电流 $I_m$：正向电压足够大时，单位时间逸出的光电子全部被阳极收集，电流达到的最大值。$I_m$ 反映单位时间逸出的光电子数。

4. 光子说与光的波粒二象性

爱因斯坦提出：光不仅在发射和吸收时是一份一份的，光本身就是由一个个不可分割的能量子组成的，频率为 $\nu$ 的光，每个光子能量为

$$\varepsilon = h\nu$$

其中 $h$ 为普朗克常量，$h = 6.63\times 10^{-34}\ \mathrm{J\cdot s}$。光电效应中，一个光子的能量被金属中的一个电子一次性全部吸收，不存在"攒能量"。

  • 光的粒子性证据：光电效应、康普顿效应（光子还有动量 $p = h/\lambda$）。
  • 光的波动性证据：干涉、衍射、偏振。
  • 统一图像：光是一种概率波——大量光子的行为表现出波动性，单个光子的落点由概率决定；亮条纹处是光子到达概率大的地方。
  • 光强的新理解：频率 $\nu$ 一定时，光强 ∝ 单位时间单位面积到达的光子数。光强加倍 = 光子数加倍，单个光子能量 $h\nu$ 不变。

5. 物质波（德布罗意波）

德布罗意提出：一切运动着的实物粒子都具有波粒二象性，其波长为

$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

这种波叫物质波（德布罗意波）。电子衍射实验证实了它的真实性。宏观物体的动量 $p$ 很大，$\lambda$ 小到无法观测，所以只看得到粒子性。

深度思考：为什么波动说解释不了光电效应？

按波动说，光的能量分布在波面上，光越弱能量越稀薄，电子需要"攒"足够时间才能获得足够能量——那弱光照射应该有明显的时间延迟，且足够强的红光（能量总量大）理应能打出电子。但实验事实是：① 弱光也瞬时打出电子；② 红光再强也打不出。只有"光是一份一份的、一个电子一次吃一份"才能同时解释这两条。这正是光子说的威力所在。

三、公式与推导（含适用条件）

1. 爱因斯坦光电效应方程（本章核心）

$$E_k = h\nu - W_0$$

推导思路（能量守恒，3 行就能写完）

  1. 金属中束缚最松的电子吸收一个光子，获得能量 $h\nu$；
  2. 它逸出金属表面至少要付出逸出功 $W_0$（克服金属对它的束缚）；
  3. 剩下的能量全部转化为动能——这就是最大初动能：$E_k = h\nu - W_0$。

之所以叫"最大"，是因为金属内部的电子束缚更紧、逸出途中还可能碰撞损失能量，实际逸出电子的动能分布在 $0 \sim E_k$ 之间，只有表面束缚最松、无碰撞损失的电子才拿到 $E_k$。

适用条件与边界（必须单独记）

适用条件：
① 单光子过程——一个电子一次只吸收一个光子（中学及高考范围均不考虑多光子吸收）；
② 必须满足 $\nu \geq \nu_0$ 才谈得上 $E_k$；若 $\nu < \nu_0$，公式算出的"负动能"物理意义是打不出来，而不是电子带负动能；
③ 研究对象是金属表面束缚最松的电子，给出的是最大初动能，不是所有光电子的动能；
④ 方程是能量关系，不要把光电效应当成"光子与电子的弹性碰撞"去套动量守恒——光子是被整体吸收的。

2. 遏止电压与最大初动能的关系

$$eU_c = E_k$$

推导思路（动能定理）：加反向电压 $U_c$ 后，光电子从阴极 K 飞向阳极 A 要逆着电场力做功 $eU_c$。调节电压直到最快的光电子也恰好到不了阳极（速度减为零），由动能定理：$0 - E_k = -eU_c$，即 $eU_c = E_k$。

  • 因为 $E_k$ 只由 $\nu$ 决定，所以 $U_c$ 也只由 $\nu$（和金属）决定，与光强无关——这正是 I–U 图上强弱两条黄光曲线共用同一个 $-U_c$ 的原因。
  • 实用结论：$E_k$ 以 eV 为单位时，数值上就等于 $U_c$ 的伏特数（例如 $E_k = 2.14\ \mathrm{eV} \Rightarrow U_c = 2.14\ \mathrm{V}$）。

3. 截止频率

$$\nu_0 = \frac{W_0}{h}$$

推导思路：令光电效应方程中 $E_k = 0$（恰好打出、动能为零），得 $h\nu_0 = W_0$，即 $\nu_0 = W_0/h$。这把"频率门槛"和"能量门槛"统一了起来：测出 $\nu_0$ 就知道 $W_0$，反之亦然。

4. $E_k-\nu$ 图象（高考图象题的标准答案模板）

把 $E_k = h\nu - W_0$ 与一次函数 $y = kx + b$ 对照：

图象要素物理意义
斜率普朗克常量 $h$（对所有金属都一样，所以不同金属的图线互相平行）
横轴截距截止频率 $\nu_0$（$E_k = 0$ 处）
纵轴截距$-W_0$（负值）
图线有效区域只有 $\nu \geq \nu_0$ 的第一象限部分有物理意义，延长线只是数学外推
公式串记：$E_k = h\nu - W_0$ 是"总司令"；令 $E_k = 0$ 得 $\nu_0 = W_0/h$；用减速电场去"称"$E_k$ 得 $eU_c = E_k$；换成图象语言，斜率是 $h$、截距是 $\nu_0$ 和 $-W_0$。一条方程，四种面孔，彼此互推。

四、典型例题

例 1：光电效应方程直接计算 ★★

已知某金属的逸出功 $W_0 = 2.0\ \mathrm{eV}$，用波长 $\lambda = 300\ \mathrm{nm}$ 的紫外线照射该金属表面。求：

（1）光电子的最大初动能（结果用 eV 表示）；（2）遏止电压 $U_c$。

【分步拆解】

  1. 先求单个光子能量 $\varepsilon = h\nu = \dfrac{hc}{\lambda}$。代入数值： $$\varepsilon = \frac{6.63\times 10^{-34}\times 3.0\times 10^{8}}{300\times 10^{-9}}\ \mathrm{J} = 6.63\times 10^{-19}\ \mathrm{J}$$
  2. 统一换算成 eV：$\varepsilon = \dfrac{6.63\times 10^{-19}}{1.60\times 10^{-19}}\ \mathrm{eV} \approx 4.14\ \mathrm{eV}$。
  3. 套光电效应方程：$E_k = h\nu - W_0 = 4.14\ \mathrm{eV} - 2.0\ \mathrm{eV} = 2.14\ \mathrm{eV}$（约合 $3.4\times 10^{-19}\ \mathrm{J}$）。
  4. 求遏止电压：由 $eU_c = E_k$，得 $U_c = \dfrac{E_k}{e} = 2.14\ \mathrm{V}$（数值上 eV 直接变 V）。

【答案】$E_k \approx 2.14\ \mathrm{eV}$；$U_c = 2.14\ \mathrm{V}$。

方法提炼：先算光子能量（$hc/\lambda$）、统一单位到 eV，再套方程——三步走。频率给的是波长时，永远先过 $\nu = c/\lambda$ 这座桥。

例 2：由 $E_k-\nu$ 图象求普朗克常量与逸出功 ★★★

用不同频率的光照射某金属，测得光电子最大初动能 $E_k$ 与入射光频率 $\nu$ 的两组数据：$\nu_1 = 8.0\times 10^{14}\ \mathrm{Hz}$ 时 $E_{k1} = 1.0\ \mathrm{eV}$；$\nu_2 = 12.0\times 10^{14}\ \mathrm{Hz}$ 时 $E_{k2} = 2.65\ \mathrm{eV}$。求普朗克常量 $h$、该金属的逸出功 $W_0$ 与截止频率 $\nu_0$。

【分步拆解】

  1. 斜率即 $h$：图线斜率 $k = \dfrac{\Delta E_k}{\Delta \nu} = h$。 $\Delta E_k = (2.65 - 1.0)\ \mathrm{eV} = 1.65\ \mathrm{eV} = 1.65\times 1.60\times 10^{-19}\ \mathrm{J} = 2.64\times 10^{-19}\ \mathrm{J}$； $\Delta \nu = (12.0 - 8.0)\times 10^{14}\ \mathrm{Hz} = 4.0\times 10^{14}\ \mathrm{Hz}$。 $$h = \frac{2.64\times 10^{-19}}{4.0\times 10^{14}}\ \mathrm{J\cdot s} = 6.6\times 10^{-34}\ \mathrm{J\cdot s}$$ 与公认值 $6.63\times10^{-34}\ \mathrm{J\cdot s}$ 吻合 ✓
  2. 代回方程求 $W_0$：用第 1 组数据，$W_0 = h\nu_1 - E_{k1} = 6.6\times 10^{-34}\times 8.0\times 10^{14}\ \mathrm{J} - 1.60\times 10^{-19}\ \mathrm{J} = 5.28\times 10^{-19}\ \mathrm{J} - 1.60\times 10^{-19}\ \mathrm{J} = 3.68\times 10^{-19}\ \mathrm{J} \approx 2.3\ \mathrm{eV}$。
  3. 求截止频率：$\nu_0 = \dfrac{W_0}{h} = \dfrac{3.68\times 10^{-19}}{6.6\times 10^{-34}}\ \mathrm{Hz} \approx 5.6\times 10^{14}\ \mathrm{Hz}$。

【答案】$h = 6.6\times 10^{-34}\ \mathrm{J\cdot s}$；$W_0 \approx 3.7\times 10^{-19}\ \mathrm{J} \approx 2.3\ \mathrm{eV}$；$\nu_0 \approx 5.6\times 10^{14}\ \mathrm{Hz}$。

方法提炼：图象题的万能套路——"斜率→$h$、代一组数据→$W_0$、$W_0/h$→$\nu_0$"。注意 $\Delta E_k$ 要先从 eV 换成 J 再除以 $\Delta \nu$，否则 $h$ 的数量级直接错 19 个数量级。

例 3：光强与频率变化的影响辨析 ★★★

用一定强度、频率 $\nu = 7.0\times 10^{14}\ \mathrm{Hz}$ 的光照射某金属（$W_0 = 2.3\ \mathrm{eV}$），发生光电效应，光电流达到饱和。下列两种操作分别会引起什么变化？

（1）保持 $\nu$ 不变，只把光强增大为原来的 2 倍；

（2）保持光强不变，只把频率增大到 $9.0\times 10^{14}\ \mathrm{Hz}$。

【分步拆解】

  1. 操作（1）：$\nu$ 不变 → 单个光子能量 $h\nu$ 不变 → 最大初动能 $E_k = h\nu - W_0$ 不变，遏止电压 $U_c$ 不变；光强加倍 → 单位时间到达的光子数加倍 → 单位时间逸出的光电子数加倍 → 饱和光电流约加倍。
  2. 操作（2）：$\nu$ 增大 → $E_k$ 增大（由 $E_k = h\nu - W_0$，$E_k$ 从 $h\nu - W_0 \approx 2.9 - 2.3 = 0.6\ \mathrm{eV}$ 增至约 $3.7 - 2.3 = 1.4\ \mathrm{eV}$，其中 $h\nu$ 按 $h = 6.63\times 10^{-34}$ 算：$6.63\times 10^{-34}\times 7.0\times 10^{14} = 4.64\times 10^{-19}\ \mathrm{J} \approx 2.9\ \mathrm{eV}$；$6.63\times 10^{-34}\times 9.0\times 10^{14} = 5.97\times 10^{-19}\ \mathrm{J} \approx 3.7\ \mathrm{eV}$）；遏止电压随之增大。
  3. 光电流怎么变？光强不变意味着单位时间入射光的总能量不变；频率升高后单个光子能量变大，光子数目反而减少，所以单位时间逸出的光电子数减少，饱和光电流减小（这是"光强 = 光子数 × 单个光子能量"的必然推论）。

【答案】（1）$E_k$、$U_c$ 不变，饱和光电流约加倍；（2）$E_k$、$U_c$ 增大，饱和光电流减小。

提醒：第（2）问中"光电流如何变"是区分度所在。有些题目把"光强不变"约定为"光子数流密度不变"，此时结论不同——读题时务必确认"光强"的含义；中学阶段默认光强指单位时间单位面积的光的总能量。

例 4：德布罗意波长估算 ★★

（1）电子经 $U = 100\ \mathrm{V}$ 电压加速后，其德布罗意波长是多少？（2）质量 $m = 10\ \mathrm{g}$ 的子弹以 $v = 500\ \mathrm{m/s}$ 飞行，其德布罗意波长是多少？由此说明为什么宏观物体看不到波动性。

【分步拆解】

  1. 电子的动量：加速获得动能 $E_k = eU = 1.60\times 10^{-19}\times 100\ \mathrm{J} = 1.60\times 10^{-17}\ \mathrm{J}$。由 $E_k = \dfrac{p^2}{2m}$ 得 $$p = \sqrt{2m_e E_k} = \sqrt{2\times 9.11\times 10^{-31}\times 1.60\times 10^{-17}} \approx 5.4\times 10^{-24}\ \mathrm{kg\cdot m/s}$$
  2. 电子波长：$\lambda = \dfrac{h}{p} = \dfrac{6.63\times 10^{-34}}{5.4\times 10^{-24}}\ \mathrm{m} \approx 1.2\times 10^{-10}\ \mathrm{m} = 0.12\ \mathrm{nm}$，与原子尺度（$10^{-10}\ \mathrm{m}$）相当——所以电子能被晶格（天然光栅）衍射，波动性可观测。
  3. 子弹波长：$\lambda = \dfrac{h}{mv} = \dfrac{6.63\times 10^{-34}}{0.010\times 500}\ \mathrm{m} \approx 1.3\times 10^{-34}\ \mathrm{m}$。这比原子核（$10^{-15}\ \mathrm{m}$）还小 19 个数量级，任何实物孔径都远大于它，衍射现象完全无法观测——宏观物体只显粒子性。

【答案】（1）$\lambda \approx 1.2\times 10^{-10}\ \mathrm{m}\ (0.12\ \mathrm{nm})$；（2）$\lambda \approx 1.3\times 10^{-34}\ \mathrm{m}$，宏观物体波长太小，波动性观测不到。

方法提炼：估算德布罗意波长两步走：先由已知条件求动量 $p$（加速电压场合用 $p = \sqrt{2meU}$），再 $\lambda = h/p$。结论"波长大到与障碍物/孔径可比拟才有可观测的衍射"是判断"能否看到波动性"的标尺。

五、易错点与成因分析

易错点 1：把"光强"当成最大初动能的决定因素

错误表现：认为"光越强，打出的光电子速度越快、动能越大"。

正确理解：最大初动能 $E_k = h\nu - W_0$ 只含频率 $\nu$，与光强无关；光强决定的是单位时间逸出的光电子数（进而决定饱和光电流）。

成因分析：日常经验（"力越大推得越快"）和波动观念（"波越猛能量越大"）的负迁移。光强增大 = 光子个数增多，单个光子的"成色"$h\nu$ 没变，每个电子分到的能量自然没变。

易错点 2：认为"红光足够强也能发生光电效应"

错误表现：觉得只要光足够强、照足够久，低频率光也能打出电子。

正确理解：能否发生光电效应只看频率是否满足 $\nu \geq \nu_0$，与光强、照射时间一律无关。$\nu < \nu_0$ 时，再强的光也无济于事——这是选择题最高频的判断句。

成因分析：没有真正接受"一份一份、一次性吸收"的量子图像，仍用"能量慢慢攒"的连续观念想问题。

易错点 3：混淆逸出功与入射光的关系

错误表现：认为 $W_0$ 随入射光频率变化，或把 $W_0 = h\nu_0$ 中的 $\nu_0$ 当成入射光频率。

正确理解：$W_0$、$\nu_0$ 都是金属本身的属性（与金属材料、表面状况有关），在入射光照上之前就已确定；$\nu_0$ 是"门槛频率"，不是入射光频率。

成因分析：对"谁决定谁"的因果链不清楚——是金属的 $W_0$ 决定了门槛 $\nu_0$，而不是光决定的。

易错点 4：遏止电压概念含混

错误表现：① 以为遏止电压越大说明光电子越少；② 以为增大光强会改变 $U_c$；③ 搞反遏止电压的极性（它是反向电压，用来"顶住"光电子）。

正确理解：$eU_c = E_k$，$U_c$ 是最大初动能的"测量仪"，只随 $\nu$ 增大而增大，与光强无关；I–U 图上不同光强的曲线共用同一 $-U_c$。

成因分析：对实验电路中"反向电压起减速作用"理解不透，没有经历"调电压直到电流恰好为零"的物理过程想象。

易错点 5：把光电效应当碰撞问题滥用守恒律

错误表现：列"光子与电子弹性碰撞、动量守恒"方程求解，或认为光子把能量分给多个电子。

正确理解：光电效应中光子被一个电子整体吸收（光子消失），能量按 $h\nu = W_0 + E_k$ 分配；动量由金属晶格（质量巨大）参与平衡，中学阶段不对光电效应列动量守恒。（顺带一提：自由电子无法完全吸收一个光子——同时满足能量、动量守恒做不到，这也是必须用金属中的束缚电子的原因；光子与自由电子的散射是康普顿效应，遵守碰撞守恒律，两者不要张冠李戴。）

成因分析："粒子性 = 小球碰撞"的直觉太强，忽略了光电效应中光子是被吸收而非被散射。

易错点 6：eV 与 J 单位混用

错误表现：$h\nu$ 用 J、$W_0$ 用 eV 直接相减；或用 $E_k-\nu$ 图象求 $h$ 时忘记把 $\Delta E_k$ 换算成 J，导致数量级错误。

正确理解：同一条方程内单位必须统一。口诀：先统一、再计算、后换算——要么全程 J，要么全程 eV（用 eV 时 $h$ 要写成 $4.14\times 10^{-15}\ \mathrm{eV\cdot s}$ 或先算 J 再换）。

成因分析：eV 是"方便单位"而非 SI 单位，套用 SI 公式（含 $h$ 的 SI 值）时最容易翻车。

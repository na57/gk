1.2 三大解题观点

解决任何一道力学题，本质上都逃不开三条路径。95+ 的高手与普通学生的区别，就在于会不会选路：

解题观点核心工具适用场景优点
力的观点 牛顿第二定律 + 运动学公式 涉及加速度、瞬时状态、时间的问题 过程清晰，但多过程问题繁琐
能量观点 动能定理、机械能守恒、功能关系 涉及位移、速度变化，不涉及时间和加速度 只看初末状态，不管中间过程，最省事
动量观点 动量定理、动量守恒定律 碰撞、爆炸、反冲、流体冲击；涉及时间求冲量 相互作用问题几乎必用

选用口诀：

  • 求加速度、求时间 → 力的观点（牛顿第二定律）
  • 求速度、求位移，不管中间过程 → 能量观点（动能定理优先）
  • 碰撞、相互作用、系统问题 → 动量观点（动量守恒）
  • 综合题往往动量 + 能量联立，这是压轴题的标配

三、相互作用与牛顿运动定律（3.2）

95+ 要求：受力分析是物理的基本功，必须做到又快又准。传送带、板块等经典模型要形成条件反射。

3.1 三种常见力

重力

  • 产生：地球对物体的吸引（注意：重力 ≠ 万有引力，重力是万有引力的一个分力，另一分力提供自转向心力）
  • 大小：$G = mg$，方向竖直向下（不是"垂直向下"，也不一定指向地心）
  • 重心：质量均匀、形状规则的物体重心在几何中心；重心不一定在物体上（如圆环）

弹力

  • 产生条件：① 直接接触；② 发生弹性形变（两个条件缺一不可）
  • 方向判断：
    • 面与面接触：垂直于接触面指向受力物体
    • 点与面接触：垂直于面；点与点接触：垂直于公切面
    • 绳：沿绳指向绳收缩的方向（只能拉，不能推）
    • 轻杆：可拉可推可侧向，方向不一定沿杆（死杆）；可动铰链杆的力沿杆（活杆）
    • 弹簧：沿弹簧轴线，可拉可压，$F = kx$（胡克定律，$x$ 为形变量）
  • 判断有无弹力的方法：假设法——假设撤去接触面，看物体运动状态是否改变；若不变，则无弹力

摩擦力（全章第一易错点）

静摩擦力滑动摩擦力
产生条件接触面粗糙、有弹力、有相对运动趋势接触面粗糙、有弹力、有相对运动
大小$0 < f \le f_{\max}$，由平衡条件或牛顿定律被动求解$f = \mu F_N$（$F_N$ 是正压力，不一定是重力！）
方向与相对运动趋势方向相反与相对运动方向相反

深度辨析——摩擦力的四大误解：

  • ❌ "摩擦力总是阻力" —— 错！人走路时地面对脚的静摩擦力是动力；传送带带动物体加速时摩擦力也是动力
  • ❌ "静止的物体才受静摩擦力" —— 错！随传送带一起匀速斜向上运动的物体是运动的，但受静摩擦力
  • ❌ "摩擦力方向与运动方向相反" —— 错！摩擦力的方向与相对运动（趋势）方向相反，可与运动方向相同
  • ❌ "有摩擦力一定有弹力" —— 对！弹力是摩擦力的前提；但有弹力不一定有摩擦力

3.2 力的合成与分解

  • 平行四边形定则 / 三角形定则：求合力的基本法则，适用于一切矢量
  • 合力范围：$|F_1 - F_2| \le F \le F_1 + F_2$；三个力的合力可为零的条件是任意一个力不大于另两个之和、不小于另两个之差
  • 正交分解法（受力分析的主力工具）：
    1. 建立直角坐标系（通常沿加速度方向和垂直加速度方向建轴）
    2. 把不在轴上的力分解到两轴上
    3. 两轴分别列方程：垂直加速度方向 $\sum F = 0$，沿加速度方向 $\sum F = ma$
建轴原则：让尽可能多的力落在坐标轴上；有明确加速度方向时，沿加速度方向建 x 轴，这样 y 方向方程退化为平衡方程，最简单。

3.3 受力分析：整体法与隔离法

受力分析四步法

  1. 定对象：明确研究对象，把它从周围物体中"隔离"出来
  2. 画场力：先画重力（以及电场力、磁场力等非接触力）
  3. 找接触：绕物体一周，每处接触先判断有无弹力，再判断有无摩擦力
  4. 核状态：对照运动状态检查——受力与加速度是否一致？有无多画漏画？

整体法与隔离法

方法研究对象适用场景注意
整体法 系统（多个物体） 求外力、系统加速度；各物体加速度相同时优先 系统内力成对抵消，不出现在方程中
隔离法 单个物体 求内力（物体间的相互作用力） 隔离受力少的物体更简便

黄金策略：先整体求加速度，再隔离求内力。"整体定 a，隔离求 F"——连接体问题的标准套路。

3.4 牛顿三大定律深度理解

牛顿第一定律（惯性定律）

  • 力是改变运动状态的原因，不是维持运动状态的原因
  • 惯性大小只由质量决定，与速度无关（"速度大惯性大"是经典错误）
  • 揭示了"惯性参考系"的存在：牛顿定律只在惯性系中成立

牛顿第二定律（核心定律）

$$\boldsymbol{F_合 = ma}$$
  • 因果性：合外力是因，加速度是果；力是产生加速度的原因
  • 矢量性：$a$ 与 $F_合$ 方向时刻相同
  • 瞬时性：$a$ 与 $F_合$ 同时产生、同时变化、同时消失——瞬时性问题的根源
  • 独立性：每个力独立产生自己的加速度，合加速度是它们的矢量叠加
  • 同体性：$F$、$m$、$a$ 必须对应同一研究对象

瞬时性问题（高频考点）

两类模型的突变特性：

  • 刚性绳 / 轻杆 / 接触面：弹力可以突变（瞬间改变）
  • 弹簧 / 橡皮筋：弹力不能突变（形变量不能瞬间改变，剪断瞬间弹力保持原值）

解题步骤：① 分析突变前各力；② 判断突变瞬间哪些力不变、哪些力消失或改变；③ 用突变后的力求瞬时加速度。

牛顿第三定律

  • 作用力与反作用力：等大、反向、共线、异物、同性、同时
对比项作用力与反作用力一对平衡力
作用对象两个物体（异物）同一物体
力的性质一定相同（同性）不一定相同
变化关系同时产生、变化、消失无必然同时性
效果不能抵消（作用在不同物体上）相互抵消，合力为零

3.5 四大经典应用模型

模型一：连接体问题（必须会推导内力公式）

情景：光滑水平面上，质量 $m_1$、$m_2$ 的两物体紧挨在一起，用水平力 $F$ 推 $m_1$，求两物体间的作用力 $N$。

推导（整体定 a，隔离求 F）：

整体：由牛顿第二定律

$$F = (m_1 + m_2) a \;\Rightarrow\; a = \frac{F}{m_1 + m_2}$$

隔离 $m_2$（它只受 $m_1$ 的推力 $N$）：

$$N = m_2 a = \boldsymbol{\frac{m_2}{m_1 + m_2} F}$$

结论的记忆与推广：内力 = "被推动部分的质量占比 × 总外力"。这个结论对粗糙水平面（同 μ）、斜面、竖直方向同样成立——只要阻力与质量成正比，内力公式形式不变。高考中可直接当结论用，但推导过程必须会。

模型二：传送带问题

类型关键分析临界/易错点
水平传送带
（物块轻放）		 物块先受滑动摩擦力加速 $a = \mu g$；加速到与带同速后，若带匀速则一起匀速（摩擦力消失或变为零） 先判断物块在带上能否加速到同速（比较加速距离与带长）；共速瞬间摩擦力突变
倾斜传送带
（向上传送）		 $a = \mu g\cos\theta - g\sin\theta$（向上加速时）；共速后需判断 $\mu \ge \tan\theta$ 才能保持相对静止 共速后摩擦力方向可能反转（静摩擦力沿带向上平衡重力分力）
传送带思维定势：永远先问三个问题——① 物块放上去瞬间相对传送带向哪滑？（定摩擦力方向）② 能否共速？（比较加速位移与带长）③ 共速后还能不能保持相对静止？（μ 够不够）

模型三：板块模型

情景：长木板 $M$ 置于地面，木块 $m$ 置于木板上，各接触面均可能有摩擦。

  • 分析要点：
    1. 分别对板、块做受力分析，求各自加速度（$a_块$、$a_板$）
    2. 判断临界：两者间摩擦力达到最大静摩擦时发生相对滑动；临界条件 $a_块 = a_板$
    3. 相对滑动时，$m$ 相对 $M$ 的加速度 $a_{相} = a_块 - a_板$
    4. 求"不掉下来"的条件：相对位移 ≤ 板长
  • 易错点：① 板与地面间的正压力是 $(M+m)g$ 而不是 $Mg$；② 滑动摩擦力永远是 $f = \mu F_N$，各接触面 $\mu$ 可能不同；③ 判断谁先滑、向哪滑。

模型四：超重与失重（推导视重公式）

情景：电梯中质量 $m$ 的人站在台秤上，电梯加速度为 $a$（取向上为正），求台秤示数（支持力 $N$）。

推导：对人列牛顿第二定律（取向上为正）：

$$N - mg = ma \;\Rightarrow\; \boldsymbol{N = m(g + a)}$$
  • $a > 0$（加速上升或减速下降）：$N > mg$ —— 超重
  • $a < 0$（减速上升或加速下降）：$N < mg$ —— 失重
  • $a = -g$（自由落体）：$N = 0$ —— 完全失重（液体压强消失、浮力消失、天平失效）
判据一句话：超重失重只看加速度方向，与速度方向无关——加速度向上（或分量向上）即超重，向下即失重。"看 a 不看 v"。

四、曲线运动与万有引力（3.3）

95+ 要求：天体运动的"双星模型""变轨问题"都要会，不能只停留在基础题。

4.1 曲线运动的条件与运动合成分解

物体做曲线运动的条件

  • 条件：合外力（加速度）方向与速度方向不在同一直线上
  • 轨迹特点：轨迹夹在速度方向与合外力方向之间，向合外力一侧弯曲（"力指凹侧"）
  • 速率变化判断：合外力与速度夹锐角 → 加速；夹钝角 → 减速；垂直 → 只改变方向（如匀速圆周运动）

运动的合成与分解

  • 合运动与分运动：等时性、独立性、等效性，位移、速度、加速度都按平行四边形定则合成

经典模型一：小船渡河

设河宽 $d$，船在静水中速度 $v_1$（船头指向即 $v_1$ 方向），水流速度 $v_2$（沿岸方向）。

问题结论方法
最短时间渡河 $t_{\min} = \dfrac{d}{v_1}$，船头垂直指向对岸（与水速大小无关） 垂直河岸方向位移固定为 $d$，该方向分速度最大时时间最短
最短位移渡河（$v_1 > v_2$） $x_{\min} = d$（垂直到达对岸），需 $v_1$ 斜向上游，使合速度垂直河岸，$\cos\theta = \dfrac{v_2}{v_1}$ 合速度方向指向对岸：让船速的上游分量抵消水速
最短位移渡河（$v_1 < v_2$） 无法垂直到达；最短位移 $x_{\min} = \dfrac{v_2}{v_1} d$，船头方向与上游岸夹角满足 $\cos\theta = \dfrac{v_1}{v_2}$ 几何法：以水速矢量末端为圆心、$v_1$ 为半径作圆，合速度沿圆的切线时偏角最小

经典模型二：绳（杆）端速度分解

原则：绳（不可伸长）两端物体沿绳方向的分速度相等。分解的是物体的实际速度（合速度），沿绳方向和垂直绳方向分解。
例：岸上匀速拉绳使船靠岸，若绳与水面夹角为 $\theta$，拉绳速度为 $v$，则船速 $v_船 = \dfrac{v}{\cos\theta}$——船速大于绳速，越靠岸越快。

4.2 平抛运动（推导必须熟练）

定义：水平初速度 $v_0$、只受重力的运动。研究方法：分解为水平匀速 + 竖直自由落体。

基本规律推导

方向速度位移
水平（匀速）$v_x = v_0$$x = v_0 t$
竖直（自由落体）$v_y = gt$$y = \dfrac{1}{2} g t^2$
合量$v = \sqrt{v_0^2 + g^2 t^2}$$s = \sqrt{x^2 + y^2}$

由 $x = v_0 t$ 与 $y = \frac{1}{2} g t^2$ 消去 $t$ 得轨迹方程：

$$y = \frac{g}{2 v_0^2} x^2 \quad\text{——抛物线}$$

两个重要推论（会推导）

  1. 飞行时间只由高度决定：$t = \sqrt{\dfrac{2h}{g}}$，与初速度无关；水平射程 $x = v_0 \sqrt{\dfrac{2h}{g}}$
  2. 速度偏角与位移偏角关系：设速度偏转角为 $\alpha$，位移偏转角为 $\theta$， $$\tan\alpha = \frac{v_y}{v_x} = \frac{gt}{v_0}, \qquad \tan\theta = \frac{y}{x} = \frac{\frac{1}{2} g t^2}{v_0 t} = \frac{gt}{2v_0}$$ $$\Rightarrow\; \boldsymbol{\tan\alpha = 2\tan\theta}$$ 几何意义：平抛物体任意时刻速度的反向延长线，过此时水平位移的中点。

类平抛运动：带电粒子在匀强电场中的偏转就是"类平抛"——把 $g$ 换成 $a = \dfrac{qE}{m}$ 即可，所有结论形式不变。这是力学方法迁移到电磁学的第一座桥。

4.3 圆周运动

描述圆周运动的物理量

$$v = \frac{2\pi r}{T}, \qquad \omega = \frac{2\pi}{T}, \qquad v = \omega r, \qquad a_n = \frac{v^2}{r} = \omega^2 r = \frac{4\pi^2}{T^2} r$$
  • 向心加速度：方向时刻指向圆心，只改变速度方向，不改变速度大小
  • 向心力：不是独立性质的力！它是沿半径方向的合外力（或合外力的径向分量），由重力、弹力、摩擦力等具体力充当
$$F_n = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r$$
受力分析铁律：受力分析时不许画"向心力"！正确问法是"哪些力（的合力）提供向心力"。多画一个向心力是初学者最常见错误。

竖直面圆周运动：绳模型与杆模型（必考）

绳模型（内轨道）杆模型（管道/双轨）
最高点受力绳只能拉：$T + mg = m\dfrac{v^2}{r}$杆可拉可压：$mg \pm N = m\dfrac{v^2}{r}$
最高点临界$T=0$ 时 $v_{\min} = \sqrt{gr}$（恰能过最高点）$v_{\min} = 0$ 即可（杆能支撑）
最低点$N - mg = m\dfrac{v^2}{r}$（支持力/拉力向上，合力向上指圆心）

配套结论（由动能定理推出，需会推）：恰好完成竖直圆周运动时，最高点 $v_高 = \sqrt{gr}$，最低点 $v_低 = \sqrt{5gr}$，两点速度差对应高度差 $2r$ 的能量关系。

水平面圆周运动

  • 圆锥摆：$T = 2\pi\sqrt{\dfrac{L\cos\theta}{g}} = 2\pi\sqrt{\dfrac{h}{g}}$（$h$ 为悬点到圆周平面的高度——周期只由 $h$ 决定）
  • 火车转弯 / 汽车过弯：由支持力与重力的合力（或摩擦力）提供向心力；汽车水平路面转弯 $v_{\max} = \sqrt{\mu g r}$

4.4 万有引力与航天

开普勒三定律

  1. 轨道定律：行星绕太阳的轨道是椭圆，太阳在椭圆的一个焦点上
  2. 面积定律：行星与太阳的连线在相等时间内扫过相等面积（近日点快、远日点慢）
  3. 周期定律：$\dfrac{a^3}{T^2} = k$，$k$ 只与中心天体质量有关（圆轨道时 $a = r$）

万有引力定律

$$\boldsymbol{F = G\frac{m_1 m_2}{r^2}} \qquad (G = 6.67\times 10^{-11}\ \mathrm{N\cdot m^2/kg^2})$$
  • $r$ 的含义：质点间距离；质量均匀球体可视为质量集中于球心
  • 卡文迪许扭秤实验：测出 $G$，被称为"称出地球质量的人"

黄金代换（必须会推导）

地球表面，忽略自转时，重力 = 万有引力：

$$mg = G\frac{Mm}{R^2} \;\Rightarrow\; \boldsymbol{GM = gR^2}$$

用途：题目给 $g$、$R$ 而没给 $M$ 时，用它替换 $GM$，是卫星问题的"万能钥匙"。

卫星运行规律（推导）

万有引力提供向心力：

$$G\frac{Mm}{r^2} = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2} r = ma_n$$

分别解出：

物理量表达式随 r 的变化
线速度$v = \sqrt{\dfrac{GM}{r}}$r 越大，v 越小
角速度$\omega = \sqrt{\dfrac{GM}{r^3}}$r 越大，ω 越小
周期$T = 2\pi\sqrt{\dfrac{r^3}{GM}}$r 越大，T 越大
向心加速度$a_n = \dfrac{GM}{r^2}$r 越大，a 越小
口诀：高轨低速长周期——"越高越慢"。注意：以上规律只适用于同一中心天体、圆轨道。

三种宇宙速度

宇宙速度数值意义与推导
第一宇宙速度 $v_1 = 7.9\ \mathrm{km/s}$ 近地卫星环绕速度，既是最大环绕速度又是最小发射速度。推导：$G\frac{Mm}{R^2} = m\frac{v^2}{R}$ 或 $mg = m\frac{v^2}{R}$ $\Rightarrow v = \sqrt{\dfrac{GM}{R}} = \sqrt{gR}$
第二宇宙速度$v_2 = 11.2\ \mathrm{km/s}$挣脱地球引力束缚的最小地面发射速度（成为太阳的行星）
第三宇宙速度$v_3 = 16.7\ \mathrm{km/s}$挣脱太阳引力束缚的最小地面发射速度（飞出太阳系）

卫星变轨问题

  • 加速 → 离心：在原轨道加速，所需向心力 $m\frac{v^2}{r}$ 大于万有引力，做离心运动，进入更高轨道
  • 减速 → 向心：减速则进入更低轨道
  • 椭圆轨道上：近地点速度 > 远地点速度（开普勒第二定律 / 能量守恒）
  • 易错点：变到高轨后，新圆轨道上的运行速度反而更小（"加速反而变慢"——因为克服引力做功，势能增量大于动能减量）

双星模型（推导）

情景：质量 $m_1$、$m_2$ 的两星，相距 $L$，绕连线上某点（质心）做匀速圆周运动，周期相同。

关键特征：① 角速度 $\omega$（周期 $T$）相同；② 万有引力互为向心力，大小相等；③ 圆心在连线上，$r_1 + r_2 = L$。

对两星分别列向心力方程：

$$G\frac{m_1 m_2}{L^2} = m_1 \omega^2 r_1, \qquad G\frac{m_1 m_2}{L^2} = m_2 \omega^2 r_2$$

两式相除得半径与质量成反比：

$$\frac{r_1}{r_2} = \frac{m_2}{m_1}$$

两式相加（$r_1 + r_2 = L$）得周期：

$$\boldsymbol{T = 2\pi\sqrt{\frac{L^3}{G(m_1 + m_2)}}}$$

模型意识：双星问题抓两点——"ω 相同"和"引力互为向心力"，然后各自列 $F_n$ 方程即可。三星模型同理（对称位置引力合成提供向心力）。

五、机械能守恒定律（3.4）

95+ 要求：能量观点是解决物理问题的三大观点之一，必须做到融会贯通——拿到题第一反应先想"能不能用能量"。

5.1 功

恒力做功

$$\boldsymbol{W = Fs\cos\alpha}$$
  • $F$：力的大小；$s$：物体（力的作用点）对地的位移；$\alpha$：力与位移的夹角
  • $\alpha < 90°$ 正功；$\alpha = 90°$ 不做功；$\alpha > 90°$ 负功（"克服该力做功"）
  • 功是标量，正负不表方向，只表"输入能量"还是"输出能量"
  • 总功 = 各力做功的代数和 = 合外力做的功（合力不变时）

变力做功的四种求法（95+ 必备）

方法适用条件典型例子
① 图象法$F$ 随位移变化 → F-s 图线下面积 = 功弹簧弹力做功 $W = \frac{1}{2}kx^2$
② 微元法力大小不变、方向总与位移垂直或共线的曲线运动滑动摩擦力沿曲线做功 $W = -f \cdot s_{路程}$
③ 动能定理法只知初末动能变化，反求变力功"合外力做功 = 动能变化"反解
④ 功率法 $W = Pt$功率恒定的变力（如机车牵引）机车恒定功率启动

几对特殊力的做功特点

  • 重力做功：$W_G = mgh$（$h$ 为高度差），只与初末位置有关，与路径无关
  • 一对作用力与反作用力做功：代数和不一定为零（两物体位移可不同），如板块模型中一对滑动摩擦力做功之和为负（生热）
  • 滑动摩擦力做功：与路程有关；一对滑动摩擦力做功代数和 $= -f \cdot s_{相对}$（转化为内能）
  • 静摩擦力做功：可对单个物体做正功或负功，但一对静摩擦力做功代数和恒为零（无相对位移，不生热）

5.2 功率

$$P = \frac{W}{t} \quad\text{（平均功率）} \qquad P = Fv\cos\alpha \quad\text{（$v$ 为平均值→平均功率；$v$ 为瞬时值→瞬时功率）}$$

机车两种启动方式（经典模型，必须理清全过程）

恒定功率启动恒定加速度启动
过程$v\uparrow \Rightarrow F=\frac{P}{v}\downarrow \Rightarrow a\downarrow$，加速度减小的加速运动，最终 $F = f$ 匀速先匀加速（$F$ 恒定，$P = Fv$ 增大）→ 达额定功率后转恒定功率加速 → 最终匀速
最大速度$v_m = \dfrac{P_额}{f}$（匀速时牵引力 = 阻力）
关键点牵引力做功用 $W = Pt$匀加速阶段末速度 $v_1 = \dfrac{P_额}{f + ma}$；匀加速时间 $t = \dfrac{v_1}{a}$

5.3 动能定理（推导 + 应用）

推导（从牛顿第二定律出发，必须会）

物体在合外力 $F$ 作用下做匀加速直线运动，位移 $x$ 内速度由 $v_1$ 变为 $v_2$：

$$F = ma, \qquad v_2^2 - v_1^2 = 2ax$$

两式消去 $a$：$v_2^2 - v_1^2 = \dfrac{2Fx}{m}$，即 $Fx = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$，所以：

$$\boldsymbol{W_合 = E_{k2} - E_{k1} = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2}$$

深度理解：

  • 动能定理对直线、曲线、恒力、变力、单过程、多过程都成立——这是它比牛顿定律强大的根本原因
  • $W_合$ 是所有力做功的代数和，重力、弹力、摩擦力、牵引力……一个都不能漏
  • 动能定理是标量式，没有方向，也没有分量式——求速度用能量，求方向还得靠运动分析
  • 优先选用原则：凡不涉及时间和加速度、只问速度/位移关系的问题，先试动能定理

应用五步

  1. 定对象、定过程（初末状态）
  2. 受力分析，判断各力做功情况（正、负、零）
  3. 写 $W_合$ 表达式（逐项代数相加）
  4. 写动能变化 $\Delta E_k$
  5. 列 $W_合 = \Delta E_k$ 求解

5.4 机械能守恒定律

守恒条件（判断是第一步）

只有重力（或系统内弹力）做功，系统机械能守恒。
等效判断：除重力/系统内弹力外，其他力不做功，或做功代数和为零。
  • ❌ "合外力为零" ≠ 机械能守恒（如匀速上升的物体，动能不变但势能增加）
  • ❌ "只受重力"才守恒 —— 不准确，受其他力但其他力不做功也守恒（如绳的拉力总与速度垂直）
  • 有摩擦力/空气阻力做功 → 机械能不守恒，减少量 = 克服阻力做功 = 生热

三种表达形式（灵活选用）

形式表达式优点
守恒式（状态）$E_1 = E_2$，即 $mgh_1 + \frac{1}{2}mv_1^2 = mgh_2 + \frac{1}{2}mv_2^2$最直观；需先选零势能面
转化式$\Delta E_k = -\Delta E_p$（动能增量 = 势能减量）不必选零势能面
转移式$\Delta E_A = -\Delta E_B$（A 增 = B 减）系统问题（如滑轮连接两物体）最好

5.5 功能关系总表（压轴题的灵魂）

做功对应的能量变化关系式
合外力做功动能变化$W_合 = \Delta E_k$
重力做功重力势能变化$W_G = -\Delta E_p$
弹簧弹力做功弹性势能变化$W_弹 = -\Delta E_{p弹}$
除重力、系统内弹力外的其他力做功机械能变化$W_{其他} = \Delta E_机$
一对滑动摩擦力做功的代数和系统内能（热量）$Q = f \cdot s_{相对}$

推导：摩擦生热 $Q = f \cdot s_{相对}$（板块情景）

木块 $m$ 以 $v_0$ 滑上静止木板 $M$（地面光滑），最终共速 $v$。设木块对地位移 $s_1$，木板对地位移 $s_2$。

对木块（动能定理）：$-f s_1 = \frac{1}{2} m v^2 - \frac{1}{2} m v_0^2$

对木板（动能定理）：$f s_2 = \frac{1}{2} M v^2 - 0$

两式相加：

$$-f(s_1 - s_2) = \left(\frac{1}{2}mv^2 + \frac{1}{2}Mv^2\right) - \frac{1}{2}mv_0^2 = \Delta E_{k系}$$

即系统损失的机械能 $= f \cdot s_{相对} = Q$（转化为内能）。

注意：摩擦力对单个物体做功用对地位移，系统生热用相对位移——两个位移千万别混！这是能量部分最高频的错误。

六、动量守恒定律（3.5）

95+ 要求：动量 + 能量综合题是高频考点，也是难点，必须重点突破。

6.1 动量与冲量

动量冲量
定义$p = mv$（状态量）$I = Ft$（过程量）
矢量性矢量，方向与 $v$ 相同矢量，恒力冲量方向与 $F$ 相同
注意$\Delta p = m\Delta v$，方向与 $\Delta v$ 相同冲量是力对时间的累积；有力有时间就有冲量（与位移无关）
  • 动量与动能的关系：$E_k = \dfrac{p^2}{2m}$，$p = \sqrt{2mE_k}$——动量相同的不同物体，质量大的动能小
  • 变力冲量：F-t 图线与时间轴围成的面积 = 冲量；也可用动量定理反求

6.2 动量定理（从牛顿第二定律推导）

物体受合外力 $F$ 作用时间 $t$，速度由 $v_1$ 变为 $v_2$。由牛顿第二定律 $F = ma$ 与 $a = \dfrac{v_2 - v_1}{t}$：

$$F = m\frac{v_2 - v_1}{t} \;\Rightarrow\; Ft = mv_2 - mv_1$$ $$\boldsymbol{I_合 = \Delta p} \qquad\text{（合外力的冲量 = 动量的变化量）}$$

深度理解：

  • 动量定理是矢量式，一维问题先规定正方向，各量带符号
  • 对变力同样成立（$I$ 是冲量的累积效果），可用于求变力冲量和平均作用力（如蹦极、撞击、流体冲击）
  • 动量定理与动能定理是"亲兄弟"：一个是力对时间的累积（改变动量），一个是力对位移的累积（改变动能）

典型应用：流体（连续介质）冲击问题

设水流（或气流、颗粒流）密度 $\rho$、截面积 $S$、速度 $v$ 冲击墙面后速度变为 $v'$。取时间 $\Delta t$ 内撞击墙面的流体质量 $\Delta m = \rho S v \Delta t$，由动量定理：

$$F \Delta t = \Delta m (v - v') \;\Rightarrow\; \boldsymbol{F = \rho S v (v - v')}$$

完全反弹时 $v' = -v$，$F = 2\rho S v^2$；吸附/停下时 $v' = 0$，$F = \rho S v^2$。

6.3 动量守恒定律

$$\boldsymbol{p_1 + p_2 = p_1' + p_2'} \quad\text{（系统不受外力或合外力为零时）}$$

守恒条件（三种情形都要会判断）

  1. 理想守恒：系统不受外力或合外力为零（如光滑水平面上的碰撞）
  2. 近似守恒：内力远大于外力（爆炸、碰撞瞬间，重力、摩擦力冲量可忽略）
  3. 分方向守恒：系统某方向合外力为零，则该方向动量守恒（如斜面上的爆炸，水平方向动量守恒）
易错：动量守恒 ≠ 动能守恒 ≠ 机械能守恒！碰撞中动量一定守恒（内力远大于外力时），但机械能一般损失。判断守恒前先问：研究对象（系统）选对了吗？内力外力分清了吗？

6.4 碰撞模型（结论要记，推导要会）

弹性碰撞（动量守恒 + 动能守恒）——"一动碰一静"推导

质量 $m_1$ 以 $v_0$ 碰撞静止的 $m_2$，碰后速度 $v_1$、$v_2$。

动量守恒：

$$m_1 v_0 = m_1 v_1 + m_2 v_2 \tag{1}$$

动能守恒：

$$\frac{1}{2} m_1 v_0^2 = \frac{1}{2} m_1 v_1^2 + \frac{1}{2} m_2 v_2^2 \tag{2}$$

由 (2) 移项因式分解：$m_1(v_0 - v_1)(v_0 + v_1) = m_2 v_2^2$

由 (1) 移项：$m_1(v_0 - v_1) = m_2 v_2$

两式相除得：恢复系数关系

$$v_0 + v_1 = v_2 \tag{3}$$

(3) 代回 (1)：$m_1 v_0 = m_1 v_1 + m_2(v_0 + v_1)$，整理得：

$$\boldsymbol{v_1 = \frac{m_1 - m_2}{m_1 + m_2} v_0}, \qquad \boldsymbol{v_2 = \frac{2m_1}{m_1 + m_2} v_0}$$

三种特殊情形（考试直接用）

质量关系碰后结果记忆
$m_1 = m_2$$v_1 = 0$，$v_2 = v_0$交换速度（如牛顿摆）
$m_1 \gg m_2$$v_1 \approx v_0$，$v_2 \approx 2v_0$重撞轻：重者不变，轻者两倍飞出
$m_1 \ll m_2$$v_1 \approx -v_0$，$v_2 \approx 0$轻撞重：轻者原速弹回（球撞墙）

完全非弹性碰撞（动量守恒，动能损失最大）

碰后共速：$m_1 v_0 = (m_1 + m_2) v_共 \Rightarrow v_共 = \dfrac{m_1 v_0}{m_1 + m_2}$

动能损失：

$$\Delta E_k = \frac{1}{2} m_1 v_0^2 - \frac{1}{2}(m_1 + m_2) v_共^2 = \boldsymbol{\frac{1}{2} \cdot \frac{m_1 m_2}{m_1 + m_2} v_0^2}$$

（$\dfrac{m_1 m_2}{m_1 + m_2}$ 称"折合质量"，此结论在子弹打木块、板块共速等问题中反复出现）

6.5 三大综合模型

模型一：子弹打木块

  • 子弹射入木块共速：动量守恒求共速；能量：$fd = \Delta E_k = Q$（$d$ 为子弹打入深度 = 相对位移）
  • 对比：子弹"穿过"木块与"留在"木块，动量方程相同，能量方程不同

模型二：弹簧连接体

  • 弹簧压缩到最短（或伸到最长）瞬间：两物体速度相等（相对速度为零）→ 用动量守恒求共速，此时弹性势能最大
  • 弹簧恢复原长：相当于一次"弹性碰撞"，速度结论与弹性碰撞相同
  • 全过程：动量守恒 + 机械能守恒（系统）

模型三：人船模型

人从静止的船头走到船尾，水平方向动量守恒且总动量为零：

$$m_人 v_人 = m_船 v_船 \;\Rightarrow\; m_人 s_人 = m_船 s_船, \qquad s_人 + s_船 = L$$ $$\boldsymbol{s_船 = \frac{m_人}{m_人 + m_船} L}$$

推广："平均动量守恒"——总动量为零的系统中，各物体位移与质量成反比，即 $m_1 s_1 = m_2 s_2$（位移均对地）。适用于人在船上走、气球下爬绳等。

七、机械振动与机械波（3.6）

7.1 简谐运动

定义与判据

  • 回复力：$\boldsymbol{F = -kx}$——大小与位移成正比，方向总与位移相反（指向平衡位置）。这是简谐运动的定义式兼判据
  • 回复力是按效果命名的力，由某个力或某些力的合力充当（如弹簧振子的弹力、单摆的重力切向分量）
  • 位移、速度、加速度随时间按正弦（余弦）规律变化：$x = A\sin(\omega t + \varphi)$

各物理量变化规律（结合图象记忆）

位置位移 x回复力/加速度速度动能势能
平衡位置00最大 $v_m = \omega A$最大最小
最大位移处最大 A最大 $a_m = \omega^2 A$00最大
  • 加速度与位移永远反向：$a = -\dfrac{k}{m}x$（简谐运动标志）
  • 周期与振幅无关（等时性）：$T = 2\pi\sqrt{\dfrac{m}{k}}$（弹簧振子）
  • 对称性：关于平衡位置对称的两点，速率、加速度大小相等；经过同一位置，速度大小相等、方向可能相反

7.2 单摆

周期公式（推导思路）

摆角很小（$\theta < 5°$）时，重力沿圆弧切向的分量充当回复力：

$$F_回 = -mg\sin\theta \approx -mg\theta \approx -mg\frac{x}{L} = -\frac{mg}{L}x$$

满足 $F = -kx$ 形式，等效 $k = \dfrac{mg}{L}$，代入弹簧振子周期公式：

$$\boldsymbol{T = 2\pi\sqrt{\frac{L}{g}}}$$
  • $L$ = 悬点到摆球球心的距离（绳长 + 球半径）
  • 周期与摆球质量无关、与振幅无关（小摆角前提下）

两类等效问题（变式必会）

类型处理方法例子
等效摆长找摆球实际摆动的圆心双线摆（摆长为悬线交点到球心的距离）、摆线被钉子挡住（半周期摆长不同）
等效重力加速度$g' = \dfrac{F_绳}{m}$（摆球在平衡位置静止时绳的拉力 ÷ 质量）加速升降电梯中的单摆 $g' = g \pm a$；带电摆球在匀强电场中；斜面上的单摆 $g' = g\sin\theta$

7.3 受迫振动与共振

  • 固有频率：由系统自身决定（$f_0 = \frac{1}{2\pi}\sqrt{\frac{k}{m}}$ 或 $\frac{1}{2\pi}\sqrt{\frac{g}{L}}$）
  • 受迫振动：稳定后振动频率 = 驱动力频率（与固有频率无关）
  • 共振：驱动力频率 = 固有频率时振幅最大。共振曲线：峰值在 $f_驱 = f_固$ 处，阻尼越小峰越尖锐

7.4 机械波

波的形成与基本关系

  • 机械波 = 振动在介质中的传播；各质点只振动不迁移，传播的是振动形式和能量
  • 各质点振动频率都 = 波源频率（由波源决定）；波速由介质决定
  • 基本关系：$\boldsymbol{v = \lambda f = \dfrac{\lambda}{T}}$
  • 相距 $n\lambda$ 的两质点振动完全相同（同相点）；相距 $(n+\frac{1}{2})\lambda$ 的两质点振动完全相反（反相点）

振动图象 vs 波动图象（必考辨析）

振动图象（y-t）波动图象（y-x）
横轴时间 t（一个质点）位置 x（许多质点）
物理意义一个质点在不同时刻的位移某一时刻各质点的位移（照片）
相邻波峰间距周期 T波长 λ
随时间变化图线沿 t 轴"延长"整个波形沿 x 轴"平移"
由波形图判断质点振动方向——"上下坡法"：沿波的传播方向看，"上坡"的质点向下振，"下坡"的质点向上振。反向已知振动方向也可推传播方向。

波的多解问题（高频易错）

多解的三个来源：

  • 时间周期性：$\Delta t = nT + \frac{k}{\lambda}\cdot T$ 型（波形平移整数个波长不变）
  • 空间周期性：$\Delta x = n\lambda + \Delta x_0$
  • 方向双向性：波可能向左也可能向右传播

列通解公式后取 $n = 0, 1, 2, \dots$ 讨论，切记不要漏解。

波的干涉、衍射与多普勒效应

现象条件 / 判据要点
干涉 两列波频率相同、相位差恒定、振动方向相同（相干波源） 振动加强点：波程差 $\Delta s = n\lambda$；减弱点：$\Delta s = (2n+1)\dfrac{\lambda}{2}$（两波源同相时）。加强点振幅最大但位移仍随时间变化
明显衍射 障碍物（孔）尺寸 ≤ 波长或相差不多 一切波都能衍射；"明显"有条件
多普勒效应 波源与观察者相对运动 相互靠近 → 接收频率变高；相互远离 → 变低。波源频率本身不变

八、三大观点综合：解题路径选择

力学综合题（尤其是压轴题）的破题本质，是在三大观点之间做正确选择。决策流程如下：

题目特征首选观点核心方程
求加速度、瞬时作用力、时间力的观点$F_合 = ma$ + 运动学公式
求速度、位移、高度，不问时间能量观点$W_合 = \Delta E_k$；$E_1 = E_2$
碰撞、爆炸、反冲、板块共速动量观点$p_1 + p_2 = p_1' + p_2'$
碰撞求末速度 / 最大损失动量 + 能量联立动量守恒 + 动能关系
曲线运动某点的速度能量（定大小）+ 牛顿（定向心力）动能定理 + $F_n = m\frac{v^2}{r}$
涉及相对位移生热能量观点$Q = f \cdot s_{相对}$
压轴题通用心法：分段拆过程 → 每段选观点 → 找衔接条件（前段末速度 = 后段初速度；碰撞用动量守恒衔接）→ 能量观点补缺口（生热、高度、弹簧势能）。先写会写的方程拿步骤分。

十、力学易错点汇总与学习方法

10.1 力学十大易错点

序号易错点正确做法
1摩擦力方向判断错误（尤其静摩擦力）判断"相对运动趋势"，必要时用假设法
2作用力与反作用力和平衡力混淆看是否作用在同一物体上
3受力分析时多画"向心力"向心力是效果力，只能问"谁提供"
4超重失重看速度方向只看加速度方向："看 a 不看 v"
5变轨后认为加速使运行速度变大高轨低速长周期；加速只是进入更高轨道
6摩擦力做功用相对位移单个物体用对地位移，系统生热才用相对位移
7动能定理漏掉某个力的功列方程前先完整受力分析，逐力判断
8动量守恒条件判断错误分三种情形判断；分方向守恒别忘记
9碰撞问题以为机械能也守恒只有弹性碰撞动能守恒；完全非弹性损失最大
10波的图象与振动图象混淆先看横轴：t 是振动图，x 是波形图

10.2 力学学习方法

  1. 受力分析天天练：这是力学第一基本功，每天 2~3 个图，追求"不遗漏、不臆造"
  2. 推导代替死记：本材料第九部分的 16 个推导，每周过一遍，直到闭眼能写
  3. 模型卡片化：传送带、板块、连接体、绳杆、卫星、双星、子弹打木块、弹簧、人船……每个模型做一张卡：条件、套路、易错点
  4. 一题三观点：每道综合题都问自己：这题用力/能量/动量哪个观点最省？能不能三个观点各做一遍对照？
  5. 错题归观点：力学错题按"概念错 / 受力错 / 观点选错 / 计算错"四类归因，观点选错的题最值得重做

小兵小贴士：力学是整个高中物理的"操作系统"——电磁学里所有带电粒子的运动、导体棒的运动，跑的都是力学这套系统。把三大观点练成条件反射，你就拿到了打开 95+ 的第一把钥匙。

模 块 一

运动学精要

3.1 运动的描述与匀变速直线运动
3.1

三个基本公式 + 三个推论

类别公式选用场景
基本$v = v_0 + at$含 $v, v_0, a, t$（不含 $x$）
基本$x = v_0 t + \frac{1}{2}at^2$含 $x, v_0, a, t$（不含 $v$）
基本$v^2 - v_0^2 = 2ax$含 $v, v_0, a, x$（不含 $t$，最常用）
推论$\bar{v} = v_{t/2} = \frac{v_0+v}{2}$纸带求瞬时速度
推论$v_{x/2} = \sqrt{\frac{v_0^2+v^2}{2}}$中间位置速度（恒大于中间时刻速度）
推论$\Delta x = aT^2$；$x_m - x_n = (m-n)aT^2$逐差法求加速度
选用原则：哪个公式含的已知量最多、未知量最少，就先用哪个
3.1

图象与追及相遇 · 三句话

  • x-t 图：斜率 = 速度，交点 = 相遇，面积无意义
  • v-t 图：斜率 = 加速度，面积 = 位移；交点 = 速度相等（不是相遇！）
  • 追及相遇临界条件：两物体速度相等时，间距取极值——此时判断能否追上/相撞
  • 刹车问题：先算刹车时间 $t_0 = \dfrac{v_0}{a}$，超时按 $t_0$ 算（末速度为零，可逆看）
⚠️ 运动学是全卷的基础工具，必须零失误。不熟就回到 3.1 专门材料重新推导。
模 块 二

相互作用与牛顿运动定律

3.2 力 · 受力分析 · 牛顿三定律 · 四大模型
3.2

三种常见力：重力 · 弹力

  • 重力：$G = mg$，竖直向下（≠ 指向地心）；重力是万有引力的一个分力
  • 弹力产生条件：① 直接接触　② 弹性形变（缺一不可）
  • 方向：垂直接触面；绳——只能拉；弹簧——可拉可压 $F=kx$；活杆力沿杆，死杆不一定沿杆
  • 有无弹力的判断：假设法——撤去接触面，运动状态不变则无弹力

光滑球夹在竖直墙与斜面之间，墙对球有弹力吗？斜面呢？用假设法验证你的答案。

3.2

摩擦力：四大误解一次破除

  • ❌ "摩擦力总是阻力" → ✅ 走路时静摩擦力是动力；传送带上也可作动力
  • ❌ "静止物体才受静摩擦力" → ✅ 运动的物体也可能受静摩擦力（随带匀速斜向上）
  • ❌ "摩擦力与运动方向相反" → ✅ 与相对运动（趋势）方向相反，可与运动同向
  • ❌ "有弹力就有摩擦力" → ✅ 有摩擦力必有弹力，反之不一定
大小：静摩擦 $0<f\le f_{\max}$ 被动求解；滑动摩擦 $f=\mu F_N$，$F_N$ 不一定等于 mg
3.2

受力分析：四步法 + 整体与隔离

四步法

  1. 定对象：隔离出研究对象
  2. 画场力：先画重力
  3. 找接触：每处接触先弹力后摩擦
  4. 核状态：受力与加速度必须一致

整体法 vs 隔离法

  • 求外力、求系统加速度 → 整体法（内力抵消）
  • 求物体间内力 → 隔离法（隔离受力少的）
  • 黄金策略：整体定 a，隔离求 F
正交分解建轴原则：沿加速度方向建 x 轴，垂直方向方程退化为平衡方程
3.2

牛顿第二定律：五性与瞬时性

$$F_合 = ma \quad\Rightarrow\quad \text{力是产生加速度的原因}$$

五性：因果性 · 矢量性（$a$ 与 $F_合$ 同向）· 瞬时性 · 独立性 · 同体性

🔩 刚性绳 / 杆 / 接触面
弹力可以突变（瞬间改变）
🌀 弹簧 / 橡皮筋
弹力不能突变（剪断瞬间保持原值）
瞬时性问题三步：① 突变前各力　② 判断哪些变、哪些不变　③ 用新力求瞬时 a
3.2

作用力与反作用力 vs 一对平衡力

对比项作用力与反作用力一对平衡力
作用对象两个物体（异物）同一物体
力的性质一定相同不一定相同
同时性同时产生、变化、消失无必然关系
效果不能求合力（不共体）相互抵消，合力为零
口诀：等大 · 反向 · 共线 · 异物 · 同性 · 同时——"异物"是区分的钥匙
模型 1

连接体：内力公式推导

光滑水平面，$m_1$、$m_2$ 紧挨，水平力 $F$ 推 $m_1$，求两物体间作用力 $N$：

① 整体（定 a）：$\quad F = (m_1+m_2)a \Rightarrow a = \dfrac{F}{m_1+m_2}$

② 隔离 $m_2$（求 F）：$\quad N = m_2 a$

$$\boldsymbol{N = \frac{m_2}{m_1+m_2}\,F} \quad\text{（被推动部分的质量占比 × 总外力）}$$
推广：阻力与质量成正比时（同 μ 粗糙面 / 斜面 / 竖直），内力公式形式不变——可直接用，推导要会
✍️
暂停推导

合上书，把"整体定 a，隔离求 F"完整推一遍，再把 F 换成作用在 m₂ 上重新推。

模型 2·3

传送带 与 板块模型

传送带三问

  1. 放上去瞬间相对带向哪滑？→ 定摩擦力方向
  2. 能否共速？→ 比较加速位移与带长
  3. 共速后能否保持？→ 斜带需 $\mu \ge \tan\theta$
水平带轻放：$a = \mu g$；共速瞬间摩擦力突变

板块模型要点

  1. 分别求 $a_块$、$a_板$
  2. 临界：$a_块 = a_板$（最大静摩擦处）
  3. 相对加速度 $a_相 = a_块 - a_板$
  4. "不掉下"：相对位移 ≤ 板长
⚠️ 板—地间正压力 $= (M{+}m)g$，不是 $Mg$
模型 4

超重与失重（推导视重公式）

电梯中人受力：支持力 $N$、重力 $mg$。取向上为正，由牛顿第二定律：

$$N - mg = ma \;\Rightarrow\; \boldsymbol{N = m(g+a)}$$
情形加速度视重
加速上升 / 减速下降$a > 0$$N > mg$ 超重
减速上升 / 加速下降$a < 0$$N < mg$ 失重
自由落体$a = -g$$N = 0$ 完全失重
判据：看 a 不看 v——只看加速度方向，与速度方向无关
模 块 三

曲线运动与万有引力

3.3 合成分解 · 平抛 · 圆周 · 卫星 · 双星
3.3

曲线运动条件 + 两个经典模型

  • 曲线运动条件：$F_合$ 与 $v$ 不共线；轨迹向力一侧弯曲（力指凹侧）
  • 小船渡河：
    • 最短时间：船头垂直对岸，$t_{\min} = \dfrac{d}{v_船}$（与水速无关）
    • 最短位移（$v_船 > v_水$）：合速度垂直对岸，$x_{\min} = d$，$\cos\theta = \dfrac{v_水}{v_船}$
  • 绳端速度分解：绳两端沿绳方向分速度相等；分解的是物体的实际（合）速度
例：岸上拉绳速度 $v$，绳与水面夹角 $\theta$ → 船速 $v_船 = \dfrac{v}{\cos\theta}$（船比绳快）
3.3

平抛运动：分解与推导

方法：水平匀速 $x = v_0 t$　＋　竖直自由落体 $y = \frac{1}{2}gt^2$

$$y = \frac{g}{2v_0^2}x^2 \quad\text{（抛物线）} \qquad t = \sqrt{\frac{2h}{g}}\ \text{（只由高度定）} \qquad x = v_0\sqrt{\frac{2h}{g}}$$
$$\tan\alpha = \frac{gt}{v_0}, \quad \tan\theta = \frac{gt}{2v_0} \;\Rightarrow\; \boldsymbol{\tan\alpha = 2\tan\theta}$$
  • 几何意义：速度反向延长线过水平位移的中点
  • 类平抛：电场中 $g \to \frac{qE}{m}$，结论形式不变
3.3

圆周运动：向心力与绳杆模型

$$v = \omega r, \qquad F_n = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r$$
⚠️ 铁律：受力分析不画"向心力"——只问"哪些力提供向心力"
绳模型（内轨）杆模型（管道）
最高点$T + mg = m\frac{v^2}{r}$$mg \pm N = m\frac{v^2}{r}$
临界速度$v_{\min} = \sqrt{gr}$（$T=0$）$v_{\min} = 0$（杆可支撑）
配套恰过最高点时最低点 $v_低 = \sqrt{5gr}$（动能定理：高度差 $2r$）
3.3

万有引力：黄金代换 + 卫星规律

推导一：黄金代换（地表重力 = 万有引力）

$$mg = G\frac{Mm}{R^2} \;\Rightarrow\; \boldsymbol{GM = gR^2}$$

推导二：卫星规律（万有引力 = 向心力）

$$G\frac{Mm}{r^2} = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r \;\Rightarrow\; v = \sqrt{\frac{GM}{r}},\ \omega = \sqrt{\frac{GM}{r^3}},\ T = 2\pi\sqrt{\frac{r^3}{GM}}$$
口诀：高轨低速长周期（r 越大，v、ω、a 越小，T 越大）——前提：同一中心天体、圆轨道
3.3

宇宙速度 · 变轨 · 双星模型

  • 第一宇宙速度：$mg = m\frac{v^2}{R} \Rightarrow v_1 = \sqrt{gR} = 7.9\,\mathrm{km/s}$——最大环绕速度 + 最小发射速度
  • 变轨：加速 → 离心升轨；减速 → 向心降轨；升高后运行速度反而变小（势能增 > 动能减）
  • 双星：① ω 相同　② 引力互为向心力　③ $r_1 + r_2 = L$
$$G\frac{m_1m_2}{L^2} = m_1\omega^2 r_1 = m_2\omega^2 r_2 \;\Rightarrow\; \frac{r_1}{r_2} = \frac{m_2}{m_1},\quad \boldsymbol{T = 2\pi\sqrt{\frac{L^3}{G(m_1+m_2)}}}$$
✍️
暂停推导

独立写出双星两方程，推出"半径与质量成反比"和周期公式。

模 块 四

机械能守恒定律

3.4 功 · 功率 · 动能定理 · 功能关系
3.4

功：恒力做功与变力做功四法

$$W = Fs\cos\alpha \quad\text{（}s\text{ 为对地位移；锐角正功、钝角负功、直角零功）}$$
变力做功方法典型例子
① 图象法（F-s 面积）弹簧 $W = \frac{1}{2}kx^2$
② 微元法滑动摩擦力沿曲线：$W = -f\cdot s_{路程}$
③ 动能定理反求只知初末动能求变力功
④ 功率法 $W = Pt$机车恒定功率牵引
一对静摩擦力做功代数和恒为零；一对滑动摩擦力做功之和 $= -f\cdot s_{相对}$（生热）
3.4

功率与机车两种启动方式

$$P = \frac{W}{t}\ \text{（平均）} \qquad P = Fv\cos\alpha\ \text{（瞬时）}$$
恒定功率启动恒定加速度启动
$v\uparrow \Rightarrow F = \frac{P}{v}\downarrow \Rightarrow a\downarrow$
加速度减小的加速 → 匀速		 先匀加速（$P = Fv$ 增大）→ 达 $P_额$ 后转恒功率 → 匀速
最大速度 $v_m = \dfrac{P_额}{f}$（匀速时 $F = f$）；匀加速末速度 $v_1 = \dfrac{P_额}{f + ma}$
3.4

动能定理：推导与深刻理解

推导：$F = ma$ 与 $v_2^2 - v_1^2 = 2ax$ 消去 $a$：

$$\boldsymbol{W_合 = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2}$$
  • 对直线/曲线、恒力/变力、多过程都成立——比牛顿定律更普适
  • $W_合$ = 所有力做功代数和，一个不能漏（先完整受力分析）
  • 标量式、无方向；求速度用能量，求方向靠运动分析
优先原则：不涉及时间和加速度、只问速度/位移 → 先试动能定理
3.4

机械能守恒：条件与三种表达式

守恒条件：只有重力（或系统内弹力）做功
  • ❌ 合外力为零 ≠ 守恒（匀速上升：动能不变、势能增）
  • ❌ 不是"只受重力"——其他力不做功也守恒（绳拉力 ⊥ 速度）
形式表达式优点
守恒式$E_1 = E_2$直观，需选零势能面
转化式$\Delta E_k = -\Delta E_p$不需零势能面
转移式$\Delta E_A = -\Delta E_B$系统问题最方便
3.4

功能关系总表 + 摩擦生热推导

做功能量变化关系式
合外力动能$W_合 = \Delta E_k$
重力 / 弹簧弹力对应势能$W = -\Delta E_p$
其他力（除重力、系统内弹力）机械能$W_{其他} = \Delta E_机$
一对滑动摩擦力（之和）内能$Q = f\cdot s_{相对}$

推导（板块）：$-fs_1 = \Delta E_{k块}$，$fs_2 = \Delta E_{k板}$，相加：

$$-f(s_1 - s_2) = \Delta E_{k系} \;\Rightarrow\; \boldsymbol{Q = f\cdot s_{相对}}$$
⚠️ 单个物体做功用对地位移；系统生热用相对位移——最高频错误！
模 块 五

动量守恒定律

3.5 冲量 · 动量定理 · 碰撞 · 综合模型
3.5

动量定理：一行推导，三层理解

推导：$F = ma$，$a = \dfrac{v_2 - v_1}{t}$ 代入：

$$Ft = mv_2 - mv_1 \;\Rightarrow\; \boldsymbol{I_合 = \Delta p}$$
  • 矢量式：先定正方向，各量带符号；变力同样成立 → 可求变力冲量、平均作用力
  • 流体冲击：$\Delta m = \rho S v\Delta t \Rightarrow F = \rho S v\,(v - v')$（反弹时 $v' = -v$）
  • 与动能定理对照：力对时间累积 → 动量；力对位移累积 → 动能
动量与动能换算：$E_k = \dfrac{p^2}{2m}$，$p = \sqrt{2mE_k}$
3.5

动量守恒的三种情形

$$\boldsymbol{p_1 + p_2 = p_1' + p_2'}$$
  1. 理想守恒：系统不受外力或合外力为零（光滑面碰撞）
  2. 近似守恒：内力 ≫ 外力（爆炸、碰撞瞬间，重力冲量忽略）
  3. 分方向守恒：某方向合外力为零 → 该方向动量守恒
⚠️ 动量守恒 ≠ 机械能守恒！碰撞动量必守恒（近似），机械能一般损失
判断流程：① 定系统 → ② 分内力外力 → ③ 对照三种情形 → ④ 列矢量方程（定正方向）
3.5

弹性碰撞："一动碰一静"推导

$m_1$ 以 $v_0$ 碰静止 $m_2$：$\quad m_1 v_0 = m_1 v_1 + m_2 v_2$　（动量）　$\quad \frac{1}{2}m_1 v_0^2 = \frac{1}{2}m_1 v_1^2 + \frac{1}{2}m_2 v_2^2$　（动能）

动能式移项因式分解，与动量式相除，得快捷关系：

$$v_0 + v_1 = v_2$$
$$\boldsymbol{v_1 = \frac{m_1 - m_2}{m_1 + m_2}v_0, \qquad v_2 = \frac{2m_1}{m_1 + m_2}v_0}$$
✍️
暂停推导

完整推一遍，特别注意"两式相除"这一步的技巧。

3.5

碰撞结论 + 三大综合模型

质量关系弹性碰撞结果
$m_1 = m_2$交换速度（牛顿摆）
$m_1 \gg m_2$$v_1 \approx v_0$，$v_2 \approx 2v_0$
$m_1 \ll m_2$$v_1 \approx -v_0$（原速弹回），$v_2 \approx 0$
完全非弹性共速 $v = \frac{m_1 v_0}{m_1+m_2}$，损失 $\Delta E = \frac{1}{2}\cdot\frac{m_1 m_2}{m_1+m_2}v_0^2$（最大）
  • 子弹打木块：动量守恒求共速；$fd = \Delta E_k = Q$（$d$ = 打入深度）
  • 弹簧模型：压到最短 → 共速、势能最大；恢复原长 ≡ 弹性碰撞
  • 人船模型：总动量为零 → $m_1 s_1 = m_2 s_2$，$s_船 = \frac{m_人}{m_人 + m_船}L$
模 块 六

机械振动与机械波

3.6 简谐运动 · 单摆 · 波的图象 · 干涉衍射
3.6

简谐运动与单摆

$$F_回 = -kx \;\Rightarrow\; a = -\frac{k}{m}x \quad\text{（简谐运动判据）}$$
  • 平衡位置：$v$ 最大、$a = 0$；最大位移处：$a$ 最大、$v = 0$；$a$ 与 $x$ 永远反向
  • 周期与振幅无关（等时性）：$T = 2\pi\sqrt{\dfrac{m}{k}}$

单摆（小角度 $\sin\theta \approx \theta \approx x/L$，回复力满足 $F = -kx$ 形式）：

$$\boldsymbol{T = 2\pi\sqrt{\frac{L}{g}}}$$
等效摆长：找实际圆心（双线摆）；等效 $g'$：电梯中 $g' = g \pm a$，斜面上 $g' = g\sin\theta$
3.6

机械波：图象辨析与干涉

$$\boldsymbol{v = \lambda f = \frac{\lambda}{T}} \quad\text{（}f\text{ 由波源定，}v\text{ 由介质定，质点只振动不迁移）}$$
  • 图象辨析：横轴 t → 振动图（一个质点）；横轴 x → 波形图（一张照片）；判方向用上下坡法
  • 多解三来源：时间周期性、空间周期性、传播方向双向性 → 列通解取 $n = 0,1,2,\dots$
  • 干涉（频率相同）：加强 $\Delta s = n\lambda$；减弱 $\Delta s = (2n{+}1)\frac{\lambda}{2}$；加强点振幅最大但位移仍变化
  • 多普勒：相互靠近频率变高，远离变低（波源频率本身不变）

# 高考备考材料库

按 **科目 → 模块 → 章节** 组织的高中复习材料库，面向高中学生免费开放，通过 GitHub Pages 发布。

> ⚠️ **本仓库内容由本地材料库同步发布，是只读展示镜像，请勿在仓库中直接修改。** 勘误与建议请提交 Issue。

## 内容组织

```
（仓库根目录）/
├── index.html              # 落地页（GitHub Pages 首页，按科目列出材料）
├── README.md               # 本说明
├── .nojekyll               # 关闭 Jekyll，保证文件原样托管
├── 数学/
│   ├── 01-集合/ … 08-概率统计/        # 深度学习材料（10 章，KaTeX 静态公式，单文件自足）
│   └── *复习讲解-课件.html / -讲义.html
├── 物理/
│   ├── 01-运动学/ … 14-原子物理/      # 深度学习材料（17 章，MathJax 运行时渲染）
│   ├── shared/                       # MathJax 共享资源（章节目录以 ../shared/ 引用，必须整目录保留）
│   └── *复习讲解-课件.html / -讲义.html
├── 化学/
│   ├── 深度学习材料/01-化学基本概念/ … 06-化学实验/   # 深度学习材料（25 章，纯静态）
│   ├── 化学三大基本观念专题讲义-v2.html
│   └── 化学三大基本观念-课件.html / -讲义.html
├── 语文/
└── 学科竞赛/
```

- 深度学习材料：按章节组织的图文深读讲义，零外链、双击离线可开、带 A4 打印样式
- 专题讲解：讲解视频（B 站）+ 图文课件（网页版 PPT）+ 图文讲义，三种方式任选或搭配

## 在线访问

GitHub Pages（`main` 分支根目录，已配置自定义域名）：

> https://nagu.cc/gk/

## 本地预览

直接双击 `index.html` 即可；或在本目录起一个静态服务：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 提交规范

- 深度学习材料由本地材料库统一同步，不要在仓库里单独编辑章节 HTML
- 物理章节依赖 `物理/shared/` 的 MathJax 共享资源，目录相对位置不可改动
- 新增科目：新建 `科目名/` 目录；新增材料后同步更新 `index.html` 对应科目列表
